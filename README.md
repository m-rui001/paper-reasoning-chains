# 论文推理链

这里收录从论文提取文本生成的中文论证分析，目标是把论文的主张、证据、关键推理和适用边界讲清楚。分析角度包括主张与证据关联、推理补全、限定条件、反例与失败模式，以及术语辨析；它们是帮助阅读的视角，不是要求每篇文章照填的固定栏目。正文使用自然流畅的中文 Markdown，不输出 JSON。

## 内容

- `papers/`：1,824 篇 Markdown 笔记，文件名为对应来源记录的 SHA-1 标识；合计约 20.7 MB。
- `scripts/`：生成与输入准备脚本，以及旧流程兼容所需模块。
- `logs/`：运行状态记录。服务配额响应已省略。
- `COLLABORATION.md`：公开版协作说明与抽样复核记录。

这些笔记是模型辅助整理的二手分析，并非逐篇独立认证的学术结论。内容可能继承来源论文、文本抽取或生成过程中的错误；涉及关键数值、公式、因果关系和边界时，请回到论文原文核查。笔记尽可能引用原文页码、图表或公式编号，并保留 DOI 等来源信息。

本仓库不包含论文 PDF、全文抽取文本、输入队列或 JSON 数据文件。SHA-1 文件名只用于关联工作流记录，不代表内容校验或论文质量背书。

## 生成笔记

使用 Python 3.10 或更新版本。将论文提取文本放入 `out/txt/<sha>.txt`，或按 `prepare_inputs.py` 生成器预期放入 `out/in/`，然后设置 Ark API 环境变量：

```powershell
$env:ARK_API_KEY = "你的 API 密钥"
python scripts\pi_rc.py --shas <sha> --workers 1
```

脚本会在 `out/rc/<sha>.md` 写入 Markdown。密钥只从环境变量读取；不要将密钥写入脚本、提交到 Git 或粘贴到日志中。模型、接口地址可通过 `ARK_MODEL`、`ARK_BASE_URL` 环境变量配置。调用需要可用的服务账户、网络和配额。

单独使用 `prepare_inputs.py` 时，它会按原设计写入 `out/in/`。生成器还会导入 `pi_summarize.py`、`prepare_inputs.py` 和 `summarize.py`，因此这些支持模块一并收录。
