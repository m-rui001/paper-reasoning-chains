# 无限维哈伯德模型中的关联格点费米子：一篇论证分析

**原文题名**：Correlated Lattice Fermions in d = ∞ Dimensions
**作者**：Walter Metzner, Dieter Vollhardt
**发表**：Physical Review Letters, Vol. 62, No. 3, 16 January 1989, pp. 324–327
**DOI**：未在提取文本中给出

---

## 一、作者要主张什么

这篇短文的中心主张是：在空间维度趋于无穷（d = ∞）的极限下，单带哈伯德模型（Hubbard model）经过恰当的标度变换后，仍然描述非平凡的费米子关联，而且这个极限在解析上比有限维更容易处理，同时又能作为 d = 3 的良好近似 [page 1]。

围绕这一中心主张，作者给出四条具体结论，在文末总结中明确列出 [page 4]：

1. 在 d = ∞ 中，基态性质的图（diagram）计算被极大简化；
2. 至少在弱耦合极限下，d = 3 的关联能与 d = ∞ 的关联能非常接近；
3. 平均场式的反铁磁哈特里–福克（Hartree-Fock）解即使在 d = ∞ 也不是精确结果；
4. 用逐级精细化的变分波函数进行的计算在解析上是可处理的，并由此"复原"了若干已知近似（如 Gutzwiller 近似、Kotliar–Ruckenstein 的从玻色子结果）。

这四条结论分别由不同的论证路径支撑：前两条来自微扰论，后两条来自变分波函数与图论论证。下面按论证逻辑展开。

---

## 二、为什么必须"恰当标度"：论证的起点

作者首先指出，d = ∞ 时在位相互作用 U 仍然良定义，但动能中的跃迁率必须重新标度，否则模型会变得平凡 [page 1]。这一判断的依据是非相互作用态密度（DOS）。

对于 d 维简单立方晶格、最近邻跃迁、晶格常数为 1 的情形，色散关系为

$$\varepsilon_k = -2t\sum_{j=1}^{d}\cos k_j \quad (2)$$

在 d → ∞ 时，由中心极限定理，U = 0 的态密度趋于高斯形式：

$$D(\varepsilon) = \frac{1}{t\sqrt{2\pi d}}\exp\left[-\left(\frac{\varepsilon}{2t\sqrt{d}}\right)^2\right] \quad (3)$$

作者由此得出关键判断：只有标度 $t = t^*/(2d)^{1/2}$（固定 $t^*$，此后取 $t^* = 1$）才能给出有限的 DOS，从而对任意密度 $n_\uparrow, n_\downarrow$ 给出有限的非相互作用平均动能 $\varepsilon_0(n_\uparrow, n_\downarrow)$。任何其他标度都会使 $\varepsilon_0$ 趋于零或无穷，模型立即变得平凡 [page 1]。

**这是整篇论证的桥接步骤**：它把"d = ∞ 是否有非平凡物理"这一问题，转化为"动能与态密度是否保持有限"的技术问题。作者没有展开证明"其他标度必然平凡"的细节，但从 DOS 表达式 (3) 的分母 $\sqrt{d}$ 可以直接看出：若 t 不随 $1/\sqrt{d}$ 衰减，则 DOS 的宽度 $2t\sqrt{d}$ 会发散，能量尺度失控。这一步是后续所有计算的合法性前提。

## 三、微扰论路径：二阶关联能与 d = 3 的接近

### 3.1 图计算的简化机制

作者引用其先前工作 [page 1, 参考文献 5、6]，说明弱耦合下 d = 1, 2, 3 的哈伯德模型关联能可在普通 Goldstone 微扰论中计算，而在 d → ∞ 极限下相应图的求值被极大简化。他们以二阶贡献为例：

$$E_2 = -\frac{U^2}{3d}\int \frac{d^d k\, d^d k'\, d^d q}{(2\pi)^{3d}} \frac{n_k n_{k'}(1-n_{k+q})(1-n_{k'+q})}{\varepsilon_k + \varepsilon_{k'} - \varepsilon_{k+q} - \varepsilon_{k'+q}} \quad (4)$$

其中 $n_k = 1$（$|k| < k_F$）否则为零，L 为晶格站点数 [page 1]。

作者将能量分母写成指数积分，并用 $\delta$ 函数把动量守恒显式表达为格点和：

$$\delta(k) = (2\pi)^{-d}\sum_f \exp(ik\cdot f)$$

由此 (4) 改写为含 $F_\pm(\lambda; f)$ 的形式 (5)，其中 $F_+$、$F_-$ 分别是 $n_k \exp(\lambda\varepsilon_k)$ 与 $(1-n_k)\exp(-\lambda\varepsilon_k)$ 的傅里叶变换 [page 1]。

**关键推理步骤**：作者利用 $F_-(\lambda; f=0)$ 有限这一事实，数出格点 $f=0$ 的最近邻、次近邻等数目，得出 $F_-(\lambda; f \neq 0)$ 至少以 $1/\sqrt{d}$ 衰减。因此 (5) 中所有离位（$f \neq 0$）贡献以 $1/d$ 消失，只剩 $f = 0$ 项。再用 DOS (3)，得到

$$E_2/LU = -\int d\varepsilon\, \Phi^2(\varepsilon_F - \varepsilon)\, P(\varepsilon_F - \varepsilon) \quad (6)$$

其中 $P(x)$ 是高斯概率函数 [page 2]。

作者对这一简化的物理机制给出解释：在 d = ∞ 中，对 (4) 中任意选定的动量 $k, k', q$，能量 $\varepsilon_k, \varepsilon_{k'}, \varepsilon_{k+q}, \varepsilon_{k'+q}$ 被格点动量相加时产生的 umklapp 过程随机化，因而彼此独立，允许把动量积分替换为对 DOS (3) 的能量积分 [page 2]。**这是全文最核心的建模简化**：高维极限把动量空间的关联"洗掉"，使多动量积分退化为单变量积分。

### 3.2 与 d = 1, 3 的数值对照

作者将 $E_2$ 作为密度 n（取 $n_\uparrow = n_\downarrow = n/2$）的函数绘于 Fig. 1，并与 d = 1 和 d = 3 的数值结果比较 [page 2]。结论是：d = ∞ 的结果与 d = 3 非常接近，因此可视为一个易于处理且可靠的近似 [page 2]。

**这里需要注意论证力度**：作者说的是"非常接近"（very close），并据此称其为"可靠近似"（reliable approximation）。这是基于单一量（二阶关联能）在弱耦合下的数值比较，而非对全部参数区域的证明。作者在文末总结中把这一条限定为"至少在弱耦合极限下"（at least in the weak-coupling limit）[page 4]，措辞是谨慎的。

### 3.3 一个附带结论：反铁磁 HF 不精确

作者指出，二阶贡献非零这一事实本身，就说明反铁磁哈特里–福克近似即使在 d = ∞ 也不是精确结果，因为后者的渐近展开在 U 的线性项之后终止 [page 2]。这是一个由微扰论结构直接推出的否定性结论，不依赖数值比较。

## 四、变分波函数路径：从 Gutzwiller 到 Kotliar–Ruckenstein

### 4.1 出发点：密度矩阵的衰减性质

作者考虑一类变分波函数

$$|\Psi\rangle = \prod_f (1 + g\, n_{f\uparrow} n_{f\downarrow}) |\Phi_0\rangle \quad (7)$$

其中 $|\Phi_0\rangle$ 是任意（不必平移不变）的单粒子波函数，g 为变分参数（$0 \leq g \leq 1$），$D = \sum_f D_f = \sum_f n_{f\uparrow} n_{f\downarrow}$ 是双占据数算符 [page 2]。这是 Gutzwiller 波函数的推广。

作者回忆，非相互作用基态 $|\Phi_0\rangle$ 的单粒子密度矩阵 $\rho_{fh} = \langle c^\dagger_f c_h \rangle$ 在 $f \neq h$ 时至少以 $1/\sqrt{d}$ 衰减 [page 2]。这一性质即使把 $|\Phi_0\rangle$ 换成更一般的单粒子波函数（如 Hartree-Fock 自旋密度波）仍然成立 [page 2]。**这是变分路径的桥接前提**：它保证了在 d = ∞ 中，不同格点之间的密度矩阵关联可以忽略。

### 4.2 图论论证：自能的对角化

作者引入与格林函数自能形式相同的"自能" $S_{fh}$ 和"正规"自能 $S^*_{fh}$，由 Dyson 方程联系，密度矩阵写作

$$\rho_{fh} = \rho^0_{fh} + \sum_{f'h'} \rho^0_{ff'} S_{f'h'} \left(\frac{1}{1+gS}\right)_{h'h} \quad (8)$$

相互作用项的期望值可表为

$$L^{-1}\langle D\rangle = L^{-1}[g/(1-g^2)]\,\mathrm{Tr}(P S) \quad (9)$$

其中 $\mathrm{Tr}(\cdot) = \int (\cdot)_{ff}$ [page 2]。

**关键推理**：考虑一个图中两个顶点 f、h 由三条或更多独立路径连接。该图的求值涉及对 f、h 及所有其他顶点的格点和。但由于 $\rho_{fh}$（$f \neq h$）的贡献被 $1/\sqrt{d}$ 因子压低，在 d → ∞ 极限下只有在位项（$f = h$）存活，即两个顶点塌缩为单一顶点。由于正规图的外顶点总是由三条独立路径连接，$S^*_{fh}$ 被证明是对角的：$S^*_{fh} = \delta_{fh} S^*_f$ [page 2]。

**这是变分路径的核心论证**：它把无限维的矩阵问题约化为单个数（或少数几个数）的问题。作者明确说，这一塌缩使得骨架图（Fig. 2 所示的前三阶正规自能图）可以被精确求和 [page 3]。

### 4.3 简单 Gutzwiller 波函数：复原已知结果

取 $|\Phi_0\rangle$ 为费米海，由平移不变性 $S^*_f = S^*$ 对所有 f 成立。求值约化为计算单个数 $S^*$，由二次方程确定：

$$S^* = \left[A - [A^2 - 4(1-g^2)(1-n)n]^{1/2}\right] / [2(1-n)] \quad (10)$$

其中 $A = 1 - (1-g^2)(n-1)$（原文写作 $A = 1 - (1-g)(n-n-)$，OCR 可疑，此处按上下文推断为 $1-(1-g^2)(n-1)$ 形式，但符号存疑，不宜作为确定证据）[page 3]。

由 Dyson 方程，自能 $S(k)$ 在 $k < k_F$ 时为 $S^*/(1-S^*)$，在 $k > k_F$ 时为 $S^*$。动量分布因此是阶跃函数，其不连续性为

$$q = 1 - [S^*/(1+g)][1 - g^2/(1-S^*)]$$

且 $\langle D\rangle = L[g^2 n/(1-g^2)] S^*/(1-S^*)$ [page 3]。

作者指出，这些正是 Gutzwiller 近似的结果，因此 Gutzwiller 近似在 d = ∞ 极限下成为 Gutzwiller 波函数期望值的精确结果 [page 3]。**这是一个"复原"型结论**：不是发现新结果，而是证明一个已知近似在特定极限下严格成立。

### 4.4 一般波函数与骨架图求和

对一般 $|\Phi_0\rangle$，作者引入修饰线 $P = P^0 + P^0 S P^0$，并给出骨架展开中前三阶图（Fig. 2）[page 3]。由于塌缩后的骨架图结构简单，可精确求和：

$$S^{*f} = -\left[1 - [1 + 4(1-g^2)P^0_{ff} P^0_{ff}]^{1/2}\right] / [2 P^0_{ff}] \quad (11)$$

作者强调，Fig. 2 中的图系列包含所有图，不构成特定子类 [page 3]。**这一点很重要**：它意味着 (11) 不是某种选择性求和，而是精确的。

### 4.5 反铁磁情形与 Kotliar–Ruckenstein 结果的复原

作者进一步取 $|\Phi_0\rangle$ 为允许反铁磁长程序的形式

$$|\Phi_{AF}\rangle = \prod_{|k| < k_F} [\cos\theta_k\, a^\dagger_{k\uparrow} + \sin\theta_k\, a^\dagger_{k+Q\downarrow}] |0\rangle \quad (12)$$

其中 Q 是半个倒格矢，满足完美嵌套 $\varepsilon_{k+Q} = -\varepsilon_k$（AB 晶格）[page 3]。

对 $\theta_k$ 的变分可精确执行，得到

$$|\sin 2\theta_k| = \frac{[\rho/(\rho^2-1)]\varepsilon_k + \Delta}{[(\varepsilon_k^2 + \Delta^2)]^{1/2}} \quad (13)$$

其中 $\rho$ 与 g 相关，$\Delta$ 参数化子晶格磁化 $m = |n_\uparrow - n_\downarrow| = 2\Delta L^{-1}\sum_{|k|<k_F}(\varepsilon_k^2 + \Delta^2)^{-1/2}$ [page 3]。

基态能可写成

$$E(m,d)/L = q\,\varepsilon_{HF}(m) + U d \quad (14a)$$

其中 $\varepsilon_{HF}(m)$ 是反铁磁 Hartree-Fock 动能，重整化因子

$$q = \frac{4(n-2d)[d(d+1-n)]^{1/2} + 2(2d+1-n)[(n-2d)^2 - m^2]^{1/2}}{(n^2 - m^2)[(2-n)^2 - m^2]^{1/2}} \quad (14b)$$

（原文公式 (14b) 的 OCR 形式较乱，此处按上下文重构，数值细节存疑）[page 3]。

作者指出，结果 (14) 与 Kotliar 和 Ruckenstein 用从玻色子（slave-boson）技术得到的结果完全相同，而本文构造了显式波函数 $|\Psi_{AF}\rangle$，使该结果在 d = ∞ 极限下精确 [page 3]。**这是第二个"复原"型结论**，且比 Gutzwiller 情形更强：它不仅证明已知结果，还给出了对应的显式变分波函数。

### 4.6 反铁磁情形的物理结论与边界

对 n = 1（半满），最小化表明对所有 U > 0 有 m > 0 且 q < 1，即在 U = 0 处发生向反铁磁绝缘体的转变，这与完美嵌套性质一致 [page 3]。作者强调，这与早期把 Gutzwiller 近似推广到反铁磁情形的尝试形成对比 [page 3]。

能量总是低于 Gutzwiller 波函数或 Hartree-Fock 结果。对 U → ∞，$|\Psi_{AF}\rangle$ 趋于 Neel 态，后者确实是 d = ∞ 半满哈伯德模型在大 U 下的精确基态 [page 3]。

**作者明确承认的局限**：对较小的 U，$|\Psi_{AF}\rangle$ (12) 和 Gutzwiller 波函数都不是 d = ∞ 的精确基态，例如它们只给出精确二阶关联能 $E_2$ (6) 的 85% [page 3–4]。这是一个重要的负面结果，作者主动给出，说明变分波函数路径在弱耦合区域并不精确。

对低于半满的情形，存在临界密度 $n_c = 0.85$，低于它时对所有 U 有 m = 0；对 $n_c < n < 1$ 存在 m > 0 的有界 U 区域。对所有 n 和 U > 0 都有 q > 1 [page 4]。

## 五、结论成立的条件与边界

综合两条路径，可以梳理出这篇论文结论的适用条件：

**第一，标度条件**。所有结论都依赖于 $t = t^*/(2d)^{1/2}$ 这一特定标度 [page 1]。这不是一个技术细节，而是模型在 d = ∞ 下保持非平凡的必要条件。若采用其他标度，模型平凡，本文所有结论不适用。

**第二，弱耦合限制**。d = 3 与 d = ∞ 关联能接近这一结论，作者明确限定在弱耦合极限 [page 4]。Fig. 1 比较的是二阶贡献，未涉及强耦合区域。

**第三，变分波函数的精度限制**。作者自己指出，对较小 U，所构造的变分波函数只给出精确二阶关联能的 85% [page 3–4]。这意味着变分路径在弱耦合下不是定量精确的，其价值在于解析可处理性和对已知近似的严格化。

**第四，反铁磁结论的晶格条件**。反铁磁部分依赖完美嵌套性质 $\varepsilon_{k+Q} = -\varepsilon_k$，作者明确限定为 AB 晶格 [page 3]。对非嵌套晶格，结论可能不同。

**第五，d = ∞ 与有限维的对应关系**。作者主张 d = ∞ 可作为 d = 3 的近似，但这一主张的证据是二阶关联能的数值比较 [page 2]，而非对全部物理量的系统证明。作者在总结中把这一条列为独立结论 (ii)，措辞为"至少"（at least）在弱耦合极限 [page 4]，保留了谨慎。

## 六、论证的整体结构

这篇论文的论证可以概括为两条平行路径，共享同一个核心机制：

**核心机制**：在 d = ∞ 中，不同格点之间的关联（密度矩阵 $\rho_{fh}$，$f \neq h$）至少以 $1/\sqrt{d}$ 衰减，因此所有离位贡献消失，多顶点图塌缩为在位项。这一机制在微扰论中表现为动量空间的 umklapp 随机化 [page 2]，在变分路径中表现为自能的对角化 [page 2–3]。

**路径一（微扰论）**：利用上述机制，把二阶关联能的动量积分约化为对高斯 DOS 的单变量积分 (6)，数值上与 d = 3 比较，得出 d = ∞ 可作为 d = 3 弱耦合近似的结论 [page 2]。

**路径二（变分波函数）**：利用同一机制，证明正规自能对角化，精确求和骨架图，得到 (11)；对反铁磁情形得到 (14)，与 Kotliar–Ruckenstein 的从玻色子结果一致，并给出显式波函数 [page 3]。

两条路径的结论互相独立，但共同支撑中心主张：d = ∞ 哈伯德模型在恰当标度下非平凡、可解析处理，且与有限维有可对照的物理内容。

**作者省略的桥接**（分析者重建）：从"$\rho_{fh}$ 以 $1/\sqrt{d}$ 衰减"到"多顶点图塌缩"这一步，作者在正文中只给出简要论证（"contributions from $f \neq h$ are suppressed by factors of order $1/\sqrt{d}$"）[page 2]，未展开对所有图拓扑的严格证明。这一步骤的严格性依赖于图论论证的完整性，读者需接受作者对"外顶点总由三条独立路径连接"这一拓扑事实的断言 [page 2]。

## 七、术语说明

- **Hubbard model（哈伯德模型）**：描述格点上相互作用费米子的模型，含动能项 $H_{kin}$ 与在位相互作用 $U n_{f\uparrow} n_{f\downarrow}$ [page 1]。
- **DOS（density of states，态密度）**：非相互作用系统的单粒子能级密度，d = ∞ 时为高斯形式 (3) [page 1]。
- **Gutzwiller 波函数**：形如 (7) 的变分波函数，通过参数 g 抑制双占据 [page 2]。
- **slave-boson（从玻色子）技术**：一种处理强关联系统的场论方法，Kotliar 和 Ruckenstein 曾用其得到 (14) 的结果 [page 3, 参考文献 12]。
- **Hartree-Fock（哈特里–福克）**：平均场近似，作者证明其在 d = ∞ 也不是精确的 [page 2]。

---

## 八、总结

这篇论文的核心贡献不在于发现新的物理现象，而在于证明：在 d = ∞ 极限下，哈伯德模型的图计算和变分计算都变得解析可处理，且若干已知近似（Gutzwiller 近似、Kotliar–Ruckenstein 结果）在这一极限下成为精确结果。论证的关键步骤是密度矩阵离位分量的 $1/\sqrt{d}$ 衰减，它使多顶点图塌缩为在位项。结论的适用条件包括特定标度、弱耦合限制、AB 晶格嵌套条件，以及变分波函数在弱耦合下仅约 85% 精度的自我限定。作者对 d = ∞ 与 d = 3 的对应关系持谨慎态度，明确限定在弱耦合极限。
