# 从经验常数到可分解的电子效应：Hansch、Leo 与 Taft 对 Hammett 取代基常数的系统整理

**原文题名**：A Survey of Hammett Substituent Constants and Resonance and Field Parameters
**年份**：1991　**DOI**：https://doi.org/10.1021/cr00002a004

## 一篇综述要论证什么

这篇发表于 *Chemical Reviews* 的文章，表面上是把 530 个取代基的 $\sigma_m$、$\sigma_p$ 值以及 660 余个含 F NMR 推导值的取代基常数汇编成表，但它真正的论证目标不止于"收集数据"。作者要说明的是：Hammett 常数虽然源自一个极窄的经验体系（25 °C 水中苯甲酸的离子化），却可以被系统地分解为场/诱导（field/inductive）与共振（resonance）两个分量，而且这些分量可以从彼此完全不同的实验体系中独立获得，并在相当好的精度上相互印证 [page 1, page 26]。

支撑这一主张的，是三条相互交织的论证线：其一，用刚性双环体系（bicyclooctane carboxylic acids）和 quinuclidine 体系定义"纯"场/诱导参数 $F$（或 $\sigma_I$），并证明不同来源的 $F$ 值高度一致；其二，用 F NMR 化学位移这一独立方法获取 $\sigma_F$ 与 $\sigma_R$，并与溶液平衡法得到的 $F$、$R$ 对照；其三，用气相质子转移平衡数据揭示水溶液 Hammett 常数中隐含的溶剂效应，从而界定 $\sigma$ 常数的适用边界。三条线最终汇聚为一个结论：在明确区分 $\pi$-给体/$\pi$-受体相互作用和取代基溶剂化效应的前提下，$F$ 与 $\sigma_I$、$\sigma_F$、$\sigma_L$ 可以视为基本等价，$R$ 与 $\sigma_R$、$\sigma_D$ 也可以视为基本等价 [page 26]。

## 场/诱导参数：从刚性分子到统一标度

论证的起点是一个化学直觉上很干净的选择。双环辛烷羧酸（结构 I）中，取代基 X 被刚性骨架固定在羧基附近，几乎不可能与羧基发生共振或极化相互作用，因此 X 对羧基质子化的影响只能通过空间（场效应）和 $\sigma$ 键链（诱导效应）传递 [page 2]。Roberts 和 Moreland 用 50% 乙醇作溶剂，定义 $d = \log K_X - \log K_H$ [page 3, eq 3]。Taft 随后将 $d$ 与其广义极性参数 $\sigma^*$ 关联，得到 $\sigma_I$，再通过 $\sigma_p = \sigma_I + \sigma_R$（eq 2）反推 $\sigma_R$ [page 2, eq 2]。

Swain 和 Lupton 走了一条不同的路：他们用 $F = d = a\sigma_m + b\sigma_p + t$（eq 4）做最小二乘拟合，但最初没有把 $F$ 和 $R$ 标度到水相苯甲酸离子化的 Hammett 标度上。Hansch 等人用 Stock 的双环辛烷羧酸数据做了标度转换 $F = d/1.65$ [page 3, eq 5]。后来 Charton 认为 1.65 应改为 1.56，作者据此重新计算了 $\sigma_I = \Delta pK_a/1.56$ [page 3]。

这里的关键推理步骤是：如果双环体系确实排除了共振，那么从它导出的 $F$ 就应该与从其他"纯场/诱导"体系导出的值一致。作者用 quinuclidine 体系（结构 II）做了独立检验。Grob 和 Schlageter 的 quinuclidine 数据对 X 的敏感性远高于双环羧酸，作者将两套数据关联得到 eq 7（$n = 14$，$r = 0.992$，$s = 0.029$）[page 3]。在此基础上，作者用 38 个数据点重新推导了 eq 8（$n = 38$，$r = 0.968$，$s = 0.046$），与 eq 5 相比参数变化很小，尽管新增了 24 个数据点、改变了归一化因子、并放弃了 $\text{N}^+(\text{CH}_3)_3$ 的 $R = 0$ 假设 [page 3]。

Table II 集中展示了八种不同方法得到的 $\sigma_I$（或 $F$）值 [page 11]。作者指出，对于常见偶极取代基，这些值之间"没有大的差异" [page 3]。更值得注意的是，Charton 从取代乙酸（$\text{XCH}_2\text{COOH}$）的 $pK_a$ 出发定义的 $\sigma_I$，与作者从 eq 8 得到的 $F$ 之间的关联（eq 9：$n = 129$，$r = 0.944$，$s = 0.067$）[page 12]，以及 F NMR 方法得到的 $\sigma_F$ 与 $F$ 之间的关联（eq 11：$n = 136$，$r = 0.960$，$s = 0.067$）[page 12]，都支持同一个结论：场/诱导参数可以从多种独立来源可靠地获得。

## 共振参数：$\sigma_R$、$R$、$R^+$、$R^-$ 的分工

共振参数的论证比场/诱导参数复杂得多，因为共振效应本身依赖于反应中心的电子需求。作者明确区分了几种情形。

**中性共振参数 $R$（或 $\sigma_R$）**：由 eq 2 从 $\sigma_p - \sigma_I$ 得到。Swain 和 Lupton 曾假设 $\text{N}^+(\text{CH}_3)_3$ 的 $R = 0$，并据此确定 eq 6 中的 $\alpha = 0.921$ [page 3]。作者指出，由于 $\alpha$ 接近 1，用 Taft 的 eq 2 直接计算 $R$ 与用 eq 6 差别不大，因此他们用 eq 8 重新计算了 $F$，用 eq 2 重新计算了 $R$ [page 13]。$R$ 与 Charton 的 $\sigma_D$ 之间的关联（eq 13：$n = 117$，$r = 0.923$，$s = 0.085$；eq 14 去掉 12 个最差拟合点后：$n = 105$，$r = 0.959$，$s = 0.057$）表明两套共振参数基本一致 [page 13]。

**$R^+$ 和 $R^-$**：当取代基与反应中心发生强共振相互作用时，单一的 $\sigma_p$ 不再适用。作者汇编了 113 个 $R^+$ 值和 143 个 $R^-$ 值（Table V）[page 20-22]。关键发现是：对于 $\pi$-给体取代基，$R^+$ 值显著大于对应的 $R$ 值（eq 19：$R^+ = 1.90R - 0.07$，$n = 29$，$r = 0.945$，$s = 0.170$）；而对于 $\pi$-受体取代基，$R^+$ 与 $R$ 几乎相等（eq 20：$R^+ = 1.16R - 0.01$，$n = 16$，$r = 0.829$，$s = 0.060$）[page 23]。类似地，对于 $\pi$-受体取代基，$R^-$ 值有显著增强（eq 21：$R^- = 1.93R + 0.19$，$n = 34$，$r = 0.758$，$s = 0.173$），但对于 $\pi$-给体取代基，$R^-$ 与 $R$ 之间没有有用的一般关联 [page 23]。

这一不对称性本身就是一个论证要点：它说明共振效应不能用一个统一的 $R$ 值来概括，而必须根据反应中心的电子需求和取代基的电子性质来选择适当的参数。作者明确表示"我们从未接受"Swain 和 Lupton 关于单一 $R$ 值足以描述所有共振效应的观点 [page 23]。

## F NMR 方法：一个独立的验证渠道

F NMR 化学位移方法在论证中扮演了特殊角色。间位和对位取代氟苯的相对化学位移差 $-\Delta\delta_{R}^{p} + \Delta\delta_{R}^{m} = -\Delta\delta_{R}^{p,m}$ 可以消去场/诱导贡献，给出本质上的 $\sigma_R$ 共振效应 [page 24]。作者用 18 个 $\pi$-受体或非活性取代基得到 eq 22（$n = 18$，$r = 0.982$，$s = 0.02$），用 15 个 $\pi$-给体取代基得到 eq 23（$n = 15$，$r = 0.978$，$s = 0.94$）[page 24-25]。eq 23 的系数是 eq 22 的 1.29 倍，作者解释为 F 检测原子本身是苯环的 $\pi$-给体，因此增强了给体-受体共振效应但减弱了给体-给体共振效应 [page 25]。

将 F NMR 得到的 $\sigma_R$ 与 Table I 中的 $R$ 对照（eq 24：$n = 125$，$r = 0.865$，$s = 0.068$），作者发现对于大多数取代基，两者接近相等；但对于 11 个强 $\pi$-给体取代基（F、OH、NH$_2$、NHNH$_2$、OCH$_3$、OCH=CH$_2$、NHCOCH$_3$、N(CH$_3$)$_2$、OC$_6$H$_5$、NHC$_6$H$_5$、N=P(C$_6$H$_5$)$_3$），$R$ 值显著增强（eq 25：$R = 1.68\sigma_R(\text{F NMR}) + 0.04$，$n = 12$，$r = 0.920$，$s = 0.13$）[page 25]。eq 25 的系数（1.68 ± 0.23）与 eq 18 中 $R^+$ 对 $R$ 的系数（1.41 ± 0.06）在置信区间内一致，这进一步确认了水相苯甲酸离子化中强 $\pi$-给体取代基的共振增强效应 [page 25]。

## 气相数据揭示的边界：水溶液 Hammett 常数不是"纯"电子效应

论证中最具批判性的一步，是利用气相质子转移平衡数据来界定水溶液 $\sigma$ 常数的适用条件。Figure 1 比较了间位和对位取代苯甲酸在气相和水相中的离子化 [page 13]。对于非共轭取代基，两者线性相关（eq 17：$n = 14$，$r = 0.974$，$s = 1.0$ kcal/mol），但共轭的 $\pi$-给体取代基（4-NH$_2$、4-OCH$_3$、4-CH$_3$、4-F）在水相中显示出增强的共振效应，偏离直线 [page 13, page 19]。

作者的解释是：水的高介电常数和氢键溶剂化能力，使得未离子化苯甲酸的羰基氧被水氢键溶剂化，通过反式醌式共振（结构 III）增强了 $\pi$-给体的共振效应 [page 19]。这一解释得到多个独立证据的支持：Figure 2 显示气相酚的相对酸度对气相苯甲酸相对酸度的图中，$\pi$-受体取代基显示大的酸度增强，而 $\pi$-给体取代基不显示增强，说明在没有水介质时不存在反式醌式共振 [page 19]；苯中与 1,3-二苯胍形成离子对的苯甲酸酸度数据也显示，对位 $\pi$-给体取代基的酸弱化效应显著小于从水相 $\sigma_m$ 和 $\sigma_p$ 预期的值 [page 19]；F NMR 数据显示，强 $\pi$-给体取代基的 $-\sigma_R$ 值（Table IV）显著小于对应的水相 $R$ 值（Table I）[page 19]。

Table X 直接比较了气相、苯溶液和水溶液中苯甲酸的 $\sigma_m$ 和 $\sigma_p$ 值 [page 26]。气相中的取代基效应比水相大约 11 倍（eq 17 的系数），但除了共轭 $\pi$-给体取代基外，两种体系的关联出奇地好 [page 26]。作者由此得出结论：水溶液 Hammett 常数的主要特征确实涉及固有的电子效应，但强 $\pi$-给体取代基的负 $\sigma_p$ 值被水溶剂化显著增强 [page 13]。

## 共线性问题与 Hammett 常数的局限

作者在讨论部分提出了一个重要的警告。$\sigma_m$ 和 $\sigma_p$ 之间存在高度共线性（eq 28：$\sigma_p = 1.19\sigma_m - 0.08$，$n = 530$，$r = 0.941$，$s = 0.137$，$F_{1,528} = 4095$）[page 27]。这种共线性的原因是：在 529 个取代基中，有 287 个的 $R$ 值在 +0.12 到 -0.12 之间，即几乎没有共振相互作用，因此 $\sigma_m$ 和 $\sigma_p$ 几乎相同 [page 27]。即使只用 eq 8 所依赖的 38 个取代基，共线性仍然很高（eq 30：$n = 38$，$r = 0.879$，$s = 0.176$）[page 27]。

这一共线性带来一个方法论后果：从未分解的 $\sigma$ 常数中，不应得出关于共振或诱导效应相对重要性的确定结论 [page 27]。相比之下，$F$ 和 $R$ 之间的共线性很低（eq 29：$F = 0.41R + 0.34$，$n = 529$，$r = 0.336$，$s = 0.257$），因此可以作为独立变量使用 [page 27]。

## 结论成立的条件与作者承认的局限

综合全文，作者的核心结论——$F$ 与 $\sigma_I$、$\sigma_F$、$\sigma_L$ 基本等价，$R$ 与 $\sigma_R$、$\sigma_D$ 基本等价——在以下条件下成立：

第一，必须明确区分 $\pi$-给体和 $\pi$-受体取代基。对于强 $\pi$-给体取代基，水相 $R$ 值因溶剂化而增强，与 F NMR 得到的 $\sigma_R$ 不一致（eq 25 vs eq 24）[page 25]。对于 $\pi$-受体取代基，$R^+$ 值的不确定性较大（eq 20 的 $r = 0.829$，$s = 0.060$），在强 $\pi$-电子缺陷中心的气相质子转移平衡中，$\pi$-受体的共振效应很小，$\sigma_R^+$ 可以可靠地取为零 [page 23]。

第二，必须考虑取代基溶剂化效应。对于含氧阴离子取代基等，与电子丰富反应中心强共轭时会创造新的溶剂化位点（SSAR 效应），这在 DMSO 中比在水中更重要 [page 23]。F NMR 方法得到的某些 $\sigma_F$ 值包含小的特定磁贡献（通常小于 0.10 单位），这些在质子转移平衡或其他反应中观察不到 [page 12]。

第三，同系链中偶极效应的衰减因子在不同介质中不同：气相中为每亚甲基碳 1/1.95，某些溶液平衡中可能高达 1/2.8 [page 12]。

作者也承认，Table I 中的值并非质量均等，使用不常见取代基时应核查原始文献 [page 27]。对于带电取代基，简单 Hammett 方程适用性差 [page 3]。Swain 和 Lupton 的归一化 $F$ 和 $R$ 值虽然在某些情况下可用，但作者不推荐使用，因为 $\sigma_m^+$ 和 $\sigma_p^+$ 不仅能给出更好的关联，还常常能提供关于反应机理的洞察 [page 13]。

最后，作者指出，虽然 $\sigma$ 常数的各种获取方法在多个精度水平上显示出显著的一致性，但对于需要更高精度的 QSAR 研究，还需要考虑取代基溶剂化和溶剂效应对场/诱导参数的额外修正 [page 26]。
