# 用贝叶斯因子检验在神经科学中确立“效应不存在”的证据

**原文题名：** Using Bayes factor hypothesis testing in neuroscience to establish evidence of absence（2020，*Nature Neuroscience* 23(7): 788–799，DOI: 10.1038/s41593-020-0660-4）

## 问题的起点：P 值无法对称地度量证据

作者的核心关切很直接：神经科学既需要知道某个操纵“有效应”，也同样需要知道它“没有效应”。阻断一条候选通路若无效果，就说明该通路不参与；失活脑区 X 若不影响行为 B，就说明 X 与 B 无关。但主流的频率派零假设显著性检验（NHST）只能量化“反对 H0”的证据，无法量化“支持 H0”的证据 [page 2]。

作者用一个模拟结果把这一不对称性讲得很清楚。当从两个完全相同的分布抽样（H0 为真）时，P < 0.05 很少出现，但**所有 P 值出现的概率是均等的**；随着样本量增大，高 P 值并不会变得更频繁（Fig. 1a 最左列，[page 3]）。也就是说，样本量增加本应让我们更有把握认为两组均值相同，但 P 值分布却是平的，高 P 值并不因此成为“支持 H0”的可靠指标。由此得出那句被反复引用的判断：不显著的结果既可能来自“证据不足”（设计功效不够），也可能来自“效应确实为零”，而 P 值本身无法区分二者——"absence of evidence is not evidence of absence" [page 2]。

## 贝叶斯因子如何给出第三种逻辑状态

作者的解决方案是把假设检验从“只看 H0”转为“比较 H0 与 H1 的相对预测能力”。以 t 检验为例（Fig. 2，[page 4]）：把两个假设都表达为关于总体标准化效应量 δ 的分布——H0: δ = 0 是 δ = 0 处的一个尖峰，H+: δ > 0 则是一条截断的、偏向小效应的先验分布（Fig. 2b）。每个 δ 值对应一条非中心 t 分布，按先验概率加权求和后，就得到 H+ 下每个可观测 t 值的预测概率（Fig. 2c）。数据到来后，计算观测 t 值在两个分布下的纵坐标之比，即贝叶斯因子 BF+0 = p(t1 | H+) ÷ p(t1 | H0)（Fig. 2e）。

关键的一步在于：这个比值是**对称**的。t1 处蓝分布是红分布的四倍，BF+0 = 4，支持 H+；t2 处两分布等高，BF ≈ 1，属于“证据不足”；t3 处红分布是蓝分布的四倍，BF0+ = 4，支持 H0——这就是“效应不存在的证据”。于是 BF 具有三种定性状态：BF10 > x（支持效应）、1/x < BF10 < x（数据不够有诊断力）、BF10 < 1/x（支持效应不存在）[page 4]。作者采用 Jeffreys 的参考值：BF > 3 为中等证据，BF > 10 为强证据，对应地 BF < 1/3、BF < 1/10 支持分母假设 [page 5]。

模拟对比进一步支撑这一主张。在无效应（μ = 0）时，贝叶斯检验误判为有效应的比例低于 4%，与频率派相当；但不同于频率派的是，**随着样本量增加，支持 H0 的证据（BF+0 < 1/3）稳步上升**（Fig. 1b 最左列绿色百分比，[page 3]）。在有效应时，贝叶斯检验检出效应的频率略低于频率派，但差异不大；而当样本量极大时两者分道扬镳——P 值会对 d = 0.05 这种实际无关的微小效应也变得显著，BF 则仍要求更相关的效应量 [page 6]。

## 两个模拟数据集：从“证据不存在”到“证据不足”

作者用受 ref. 15 启发的 ACC 失活实验做教程式演示，但明确说明用的是**合成数据**（muscimol1.csv 与 muscimol2.csv），以便读者修改数据观察分析变化 [page 7]。设计是两组独立样本 t 检验，比较生理盐水与 muscimol 在 ShockObs（观察同类受电击）和 CS（非社会性条件）两种条件下的冻结行为，采用单尾 H+: saline > muscimol。

在 muscimol1 中，ShockObs 的 BF+0 = 162.282，属极强证据支持效应；CS 的 BF+0 = 0.223，低于 1/3，即 BF0+ = 4.494，属中等证据支持 H0——ACC 失活不降低非社会性冻结 [page 7]。而在 muscimol2 中，ShockObs 仍为极强证据（BF+0 = 120），但 CS 的 BF+0 = 0.97，落在 1/3 与 3 之间，是**证据不足**，而非证据不存在 [page 7]。这一对照正是全文论证的缩影：同样的非显著频率派结果，在贝叶斯框架下可以区分出两种截然不同的结论。

稳健性检验（Fig. 3a，[page 8]）显示，除极窄先验外，ShockObs 支持 H+、CS 支持 H0 的结论在合理的先验宽度范围内都成立。作者据此认为结论对先验选择不敏感，可以较有信心地报告。

## 交互作用的贝叶斯 ANOVA：模型比较而非参数拟合

作者进一步用贝叶斯重复测量 ANOVA 检验组别（saline vs muscimol）与条件（ShockObs vs CS）的交互 [page 7]。其逻辑与 t 检验不同：不是比较某个参数值下的拟合优度，而是比较模型在**所有合理参数值上的平均预测表现**。零模型把预测全部集中在 β = 0，因此两组间的小差异在零模型下反而更可能出现，从而为“效应不存在”提供证据 [page 7]。

对 muscimol1，全模型（含交互）的后验概率 P(M|data) = 0.983，交互项的 BFincl = 96，说明含交互的模型比不含的高 96 倍，即 ACC 失活对 ShockObs 的影响远强于 CS [page 9]。对 muscimol2，交互的 BFincl = 1.16，属证据不足——与 t 检验中 CS 结论不确定相一致 [page 9]。作者推荐使用“matched models”选项，因为它对每个因素的贡献给出更保守的估计 [page 9]。

## 先验：主观性如何被约束

贝叶斯分析必须指定 H1 的先验分布，这引入了主观性，也是许多科学家的顾虑。作者给出两步方案：先用满足一般统计要求的默认先验，再检验结论对先验变化的稳健性 [page 9]。t 检验的默认先验是尺度参数 r = √2/2 ≈ 0.707 的 Cauchy 分布，即一半效应量落在 ±0.707 内，小效应比大效应更可能 [page 10]。ANOVA 中固定效应 r = 0.5、随机效应 r = 1、协变量 r = 0.354 [page 10]。

作者强调，当先验尺度为零时 H+ 退化为 H0，BF 恒等于 1，这解释了稳健性曲线为何都收敛到 1 [page 10]。此外，后验中位数与 95% 可信区间提供了效应量的估计：ShockObs 的后验中位数 δ = 1.109，95% CI [0.406, 1.810]，比样本 Cohen's d = 1.24 略向零收缩，作者认为这是先验带来的合理保守性，可抵消低功效下频率派效应量的系统性高估 [page 10]。

## 方向性假设与证据累积

作者特别推荐使用方向性 H+ 而非双尾 H1，理由在小组样本时尤为明显：n = 8 时，双尾贝叶斯单样本 t 检验中 t > 2.8 可支持 H1，但即使 t = 0（对 H0 最有利的数据）也达不到支持 H0 的适度证据（BF01 = 2.97）；而使用 H+ 后，即使 t = –0.3 也能给出 BF0+ = 3.62 [page 11]。作者认为单尾检验在支持 H0 与 H1 之间提供了更公平的平衡。

“序贯分析”选项展示了 BF 随样本量累积的变化（Fig. 3c，[page 8]）。muscimol1 中 ShockObs 稳定上升支持 H+，CS 稳定下降支持 H0；muscimol2 中 CS 则无陡峭一致的趋势，作者据此推断需要数百只动物才可能检出效应，这与传统功效分析对 δ = 0.4 的估计一致 [page 12]。作者提出可以用 BF 临界值（如 BF+0 > 6 或 < 1/6）作为数据收集的停止规则，并称在示例中可为 CS 条件节省 n = 20 只动物 [page 12]。作者同时指出，这种灵活性在 NHST 中不可接受，因为 NHST 只能提供反对 H0 的证据，测到显著为止必然总能找到“证据” [page 12]。

## 结论成立的条件与作者承认的边界

作者明确列出了若干限制。神经影像需要在数千体素上做多重比较校正，而贝叶斯因子的相应框架“仍处于起步阶段” [page 12]。贝叶斯 t 检验和 ANOVA 假设数据正态分布，但神经科学数据常高度非正态；非参数贝叶斯检验目前仅在某些应用（部分 t 检验和回归）中存在，ANOVA 等仍在开发中 [page 12]。ANOVA 的效应量可信区间在 JASP 中尚在开发，作者建议用事后贝叶斯 t 检验或报告频率派 η² 作为替代 [page 11]。此外，某些场景需要用户自定义先验，例如检验“效应量 δ > 0.8”这类主张时需设定 H0: δ < 0.8 对 H1: δ > 0.8 [page 12]。

作者也承认先验选择本身带有主观性，但主张通过默认先验加稳健性检验来约束，并认为报告 BF 而非后验几率可以避免先验几率带来的争议 [page 5]。

## 论证的关键转折与整体判断

这篇综述的论证力量不在于引入新方法，而在于把“P 值无法对称度量证据”这一统计事实，转化为神经科学实践中可操作的替代方案。关键推理链是：P 值在 H0 为真时分布平坦（Fig. 1a）→ 因此高 P 值不能作为支持 H0 的证据 → 贝叶斯因子通过比较 H0 与 H1 的预测能力，天然具有对称性（Fig. 2）→ 模拟显示 BF 在无效应时随样本量增加而积累支持 H0 的证据（Fig. 1b）→ 两个模拟数据集演示了“证据不存在”与“证据不足”的可区分性 → JASP 使这一分析在标准场景中易于执行。

需要留意的是，全文的核心演示基于**合成数据**而非真实实验数据 [page 7]，因此这些具体 BF 数值应视为方法演示而非实证结论。作者对“证据不存在”的推荐阈值（BF < 1/3 为中等、< 1/10 为强）沿用 Jeffreys 的参考值，作者本人也承认这些是连续量上的离散化标签，实际报告应反映 BF 的连续强度 [page 5]。在适用条件上，这套方法目前最成熟的场景是正态分布数据下的 t 检验和 ANOVA；对于神经科学中大量存在的非正态数据和大规模多重比较，作者坦承工具尚不完善 [page 12]。因此，本文的结论应理解为：在标准统计场景中，贝叶斯因子为“效应不存在”提供了频率派无法提供的原则性证据；而在更复杂的神经科学数据场景中，这一优势的兑现仍待方法学发展。
