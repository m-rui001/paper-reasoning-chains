# 兰伯特 W 函数：从多值逆函数到可计算、可积、可渐近展开的标准工具

原文题名：On the Lambert W function（1996），DOI: https://doi.org/10.1007/bf02124750

## 一篇“收拢散落结果并补上新结果”的论文

这篇论文的定位不是提出一个全新函数，而是把历史上零散出现、名称各异的一个函数收拢到统一记号下，并补上作者认为缺失的三块内容：复平面上的分支结构、全分支可用的渐近展开、任意精度数值算法与符号积分方法。作者在结论中明确说，论文“重要的一部分”是提出复平面上所有分支的标准记号 [page 27]。因此，理解这篇论文的关键，不是记住某个公式，而是看清作者如何用“分支—渐近—数值—积分”这条链条，把一个原本只在各领域局部露面的函数变成可被普遍调用的标准工具。

核心结论可以概括为三点。第一，函数 $W$ 定义为 $w \mapsto we^w$ 的多值逆，即满足 $W(z)e^{W(z)}=z$ [page 2]；它在实轴上恰有两个实值分支，在复平面上有无穷多个分支，作者给出一套统一编号 $W_k$ 与分支割线约定 [page 15–19]。第二，作者给出对所有分支在 $z\to\infty$ 和 $z\to 0$ 都成立的渐近展开，并证明该级数绝对收敛 [page 20–22]。第三，作者给出任意精度下计算所有分支的实用算法（以 Halley 方法为最优）以及含 $W$ 表达式的符号积分方法 [page 23–27]。

## 从历史方程到现代定义：为什么是 $W$

论文开篇用相当篇幅追溯历史，这不是装饰。Lambert 1758 年解三项方程 $x = q + x^m$，Euler 将其改写为对称形式 $x^\alpha - x^\beta = (\alpha-\beta)vx^{\alpha+\beta}$（式 1.1）[page 1]。当取 $\alpha=\beta$ 并令 $\beta\to\alpha$ 时，得到 $\log x = vx^\alpha$（式 1.3）[page 1]。Euler 进一步令 $\alpha=1$，把解写成级数，得到 $\log x = v + \frac{3}{2}v^2 + \frac{8}{3}v^3 + \cdots$（式 1.4）[page 2]。作者指出，这个级数在 $|v|<1/e$ 收敛，定义树函数 $T(v)$，且 $T(v) = -W(-v)$ [page 2]。

这段历史的作用是双重的。一方面，它说明 $W$ 并非人为构造，而是从经典方程求解中自然浮现；另一方面，它给出 $W$ 与 $T$ 的精确关系，使论文后面关于树枚举、随机图、算法分析的应用都能挂到同一个函数上。作者也借此解释命名：称其为 Lambert W 函数，是因为它是 Lambert 级数在 $\beta=\alpha=-1$ 时的对数；字母 W 又恰好呼应 Wright 对该函数多方面工作的贡献 [page 2]。

## 分支结构：论证中最需要读者跟上的技术步骤

论文对复分支的处理是全文最细致、也最容易被略读的部分。作者先回顾复对数的分支约定，用 $p$-平面与 $z$-平面的对应图（图 2、图 3）建立“逆时针连续”（CCC）原则 [page 14–15]。然后把这套做法搬到 $W$：令 $w=W(z)$，$z=we^w$，写出实部与虚部

$$x = e^{\xi}(\xi\cos\eta - \eta\sin\eta),\quad y = e^{\xi}(\eta\cos\eta + \xi\sin\eta) \quad (4.1)(4.2)$$

[page 15]。要确定分支割线，就要找负实 $z$ 轴在 $w$-平面的原像。由 $y=0$ 得 $\eta=0$ 或 $\xi=-\eta\cot\eta$（式 4.3）[page 15]。满足 $x<0$ 的这些曲线就是分支边界。作者据此把 $w$-平面分区并编号，得到图 4 的分支范围 [page 16]。

关键推理在于：这些边界曲线把 $w$-平面划分后，每一块是否恰好双射到 $z$-平面？作者用 Jacobian

$$e^{2\xi}((\xi-1)^2+\eta^2)$$

除分支点外处处非零，配合反函数定理说明每块区域到 $z$-平面的映射是一一的 [page 16]。这一步是分支编号合法性的基础，也是后面渐近展开能“按分支”写出的前提。

由此得到的具体结论是：主分支 $W_0$ 在 $z=0$ 解析，$W_0(0)=0$，分支割线为 $\{z:-\infty<z\le -1/e\}$，割线取上闭（CCC）[page 16–17]；$W_{-1}$ 与 $W_1$ 各有一条双割线，$W_{-1}$ 在 $[-1/e,0)$ 上取实值，因此 $W_0$ 与 $W_{-1}$ 是仅有的两个取实值的分支 [page 17]。作者也坦承这套选择的代价：式 (4.22) 的展开因此比另一种割线选择更复杂 [page 19]。这是一个作者主动交代的取舍，而非疏漏。

## 渐近展开：把“对数主导”变成对所有分支都成立的级数

渐近部分的核心观察是：在 $z\to\infty$ 和 $z\to 0$ 两种极限下，$we^w=z$ 中指数项主导，因此展开的首项必然是某种对数。作者写 $w = \log z + u$（式 4.6），代入得 $(1+u/\log z)e^u = 1/\log z$（式 4.8），在 $|u|\ll|\log z|$ 假设下得 $u\sim 1/\log\log z$（式 4.9）[page 19–20]。这里作者特别强调两个对数的分支可以不同，用 $\mathrm{Log}$ 标记内层对数 [page 20]。

真正的技术步骤是 de Bruijn 式论证。作者令 $w = \mathrm{Log}\,z - \log\mathrm{Log}\,z + v$（式 4.11），代入后得到

$$e^{-\zeta} - 1 - \sigma\zeta + \tau = 0 \quad (4.13)$$

其中 $\sigma=1/\mathrm{Log}\,z$，$\tau=\log\mathrm{Log}\,z/\mathrm{Log}\,z$ [page 20]。作者把 $\sigma,\tau$ 当作独立小参数，用 Rouché 定理证明在 $|\zeta|=\pi$ 圆内方程恰有一个解 $v$，且 $v$ 是 $\sigma,\tau$ 的解析函数，再由 Cauchy 定理把 $v$ 写成绝对收敛的双重幂级数（式 4.17）[page 20–21]。这一步的推理力度很强：它不是形式展开，而是证明了解的存在性、唯一性与级数收敛性。作者还指出，这同时证明了无穷多个根 $W_k(z)$ 的存在，而这一点 de Bruijn 原文并未指出 [page 21]。

最终得到对所有非主分支在无穷与零点都成立的展开

$$W(z) = \mathrm{Log}\,z - \log\mathrm{Log}\,z + \sum_{k=0}^{\infty}\sum_{m=1}^{\infty} c_{km}\frac{(\log\mathrm{Log}\,z)^m}{(\mathrm{Log}\,z)^{k+m}} \quad (4.18)$$

[page 21]。系数 $c_{km}$ 由 Lagrange 反演定理给出，Comtet 已用 Stirling 循环数表示 [page 21]。作者还给出按 $L_1=\mathrm{Log}\,z$、$L_2=\log\mathrm{Log}\,z$ 重排的显式前几项（式 4.19），并说明这修正了 de Bruijn 书中式 (2.4.4) 的一个排印错误 [page 21]。最后，通过分析前两项虚部，作者把分支编号与对数分支对应起来，得到

$$W_k(z) = \log z + 2\pi i k - \log(\log z + 2\pi i k) + \sum\cdots \quad (4.20)$$

[page 22]。这里的推理关键是一个“离散—连续”论证：分支指标使近似成为 $k$ 的离散函数，而在任一给定分支上它又是连续的，因此若在 $z\to\infty$ 时成立，就在整个区域成立 [page 22]。这是作者补足的桥接，原文只以一句话带过。

## 数值计算：为什么 Halley 方法胜出

数值部分先做条件数分析。对 $y=W(z)$，条件数

$$C = \frac{1}{1+W(z)} \quad (5.1)$$

[page 23]。作者指出 $W$ 在分支点 $z=-1/e$ 附近病态，但在 $z=0$ 附近并不病态——这是相对误差视角下的结论 [page 24]。更有价值的是作者给出可计算的误差界：定义残差 $r=\tilde w e^{\tilde w}-z$（式 5.2），则 $\tilde w = W(z+r)$ 精确成立，前向误差可写成积分 $\int_z^{z+r}W'(\zeta)d\zeta$（式 5.3）[page 24]。于是问题转化为估计 $|W'|$。作者解出 $|W'(z)|=\rho$ 的曲线

$$z = \rho^{-1}e^{-i\varphi}(1 - W(\rho^{-1}e^{-i\varphi})) \quad (5.7)$$

[page 24–25]。对大的 $k$，这条曲线近似以原点为中心、半径 $\rho^{-1}$ 的圆，因此只要 $z$ 在半径 $1/10$ 的圆外，前向误差就小于残差的约十倍 [page 25]。在分支点附近，作者改用式 (4.22) 的级数，并说明残差 $O(p^{n+1})$ 与前向误差 $O(p^{n-1})$ 之间损失一阶精度（式 5.8）[page 25]。

算法比较部分，作者在 Maple V Release 3、DEC Alpha 3000/800S 上比较 Newton、Halley 与 Fritsch 等人的四阶方法，结论是 Halley 方法在该环境下最优，四阶方法次之，Newton 通常最慢，且这一排序在广泛精度、分支与参数范围内一致 [page 26]。作者也解释了为什么高阶方法未必更省：高阶导数计算成本高，而变精度环境下低阶方法在中间步骤可用的精度折扣更大 [page 26]。Halley 迭代的具体形式为

$$w_{j+1} = w_j - \frac{w_je^{w_j}-z}{e^{w_j}(w_j+1) - \frac{(w_j+2)(w_je^{w_j}-z)}{2w_j+2}} \quad (5.9)$$

[page 27]。初始猜测按区域选择：多数参数用式 (4.18) 前两项；分支点附近用式 (4.22) 前两项；$W_0$ 在 0 附近用 (3,2)-Padé 近似；$W_{-1}$ 在远离两个分支点时用简单有理逼近 [page 27]。作者承认这些区域边界是经验确定的 [page 27]。

## 符号积分：一个“重新发现”的通用技巧

积分部分从一个流体力学例子切入。Ranger 处理 $x=pe^p$、$dy/dx=p$（式 3.9–3.10），得到 $dy/dp = p(p+1)e^p$（式 3.12），积分得 $y=(p^2-p+1)e^p+C$（式 3.13）[page 12–13]。作者指出这其实就是 $W$ 的反导数：

$$\int W(x)\,dx = (W^2(x)-W(x)+1)e^{W(x)}+C = x\left(W(x)-1+\frac{1}{W(x)}\right)+C \quad (3.14)$$

[page 13]。更一般地，令 $w=W(x)$，$x=we^w$，$dx=(w+1)e^w\,dw$，可把含 $W$ 的积分化为 $w$ 的有理—指数积分，例如

$$\int xW(x)\,dx = \tfrac{1}{2}(W(x)-\tfrac{1}{2})(W^2(x)+\tfrac{1}{2})e^{2W(x)}+C \quad (3.15)$$

[page 13]。作者强调这适用于所有分支，因为 $d(we^w)/dw$ 在任一分支内部非零 [page 13]。这一技巧的本质是反函数积分公式

$$\int f^{-1}(x)\,dx = yf(y) - \int f(y)\,dy \quad (3.16)$$

[page 13]。作者还指出，这使 Risch 算法可用于判定含 $W$ 的积分是否为初等 [page 13]。这一节的论证力度相对温和：它主要是方法展示与例子，而非定理证明；但式 (3.16) 的适用性依赖 $f$ 在相关区间上可逆且导数非零，这一点作者以“任一分支内部”一笔带过。

## 应用：论证的支撑面而非装饰

论文第二节列出大量应用，它们的作用是证明 $W$ 的普遍性，从而支撑“应建立标准记号”这一主张。这些应用包括：树枚举中 $T(x)=-W(-x)$ 与 $t_n=n^{n-1}$ [page 3]；迭代指数 $h(z)=z^{z^{\cdot^{\cdot}}}$ 收敛时 $h(z)=W(-\log z)/(-\log z)$（式 2.5）[page 4]；方程 $x^x=b$ 的解为 $\exp(W(a\log b)/a)$ [page 4]；喷气机燃油问题中 $w$ 由 $W_0$ 或 $W_{-1}$ 给出（式 2.10）[page 5]；燃烧模型 $y=1/(1+W(ue^{u-t}))$（式 2.13）[page 6]；酶动力学 $S_0=-\frac{1}{\sigma}W(\sigma e^{\sigma-(\sigma+1)\tau})$（式 2.16）[page 6]；延迟方程 $\dot y=ay(t-1)$ 的解由 $s=W_k(a)$ 与级数 $\sum c_k e^{W_k(a)t}$（式 2.18）构成 [page 6–7]；氢分子离子模型 $c_\pm = q + W(\pm qRe^{-qR})/R$（式 2.23）[page 7]；Richards 方程相似解（式 2.26）[page 8]；Volterra 种群方程相平面解（式 2.28）[page 8]；三项式渐近根 $y_n=W(-e^{a+b}f(n))$（式 2.32）[page 9]；流行病与随机图巨分量 $\gamma = 1+W(-\alpha e^{-\alpha})/\alpha$（式 2.34）[page 9]；算法分析中哈希均匀探测与随机二叉搜索树高度 $c=1/T(1/(2e))$（式 2.40）[page 10]。

这些应用在论证中承担的角色不同。延迟方程被作者称为“也许是最重要的应用” [page 6]，因为它直接要求复分支，从而为第 4 节的分支分析提供动机。随机图与流行病则把 $W$ 与 $T$ 联系起来，支撑树函数部分的必要性。教学应用一节 [page 10–11] 则说明 $W$ 是“同时具有代数与对数奇性的最简单函数”，这为论文的另一个隐含主张服务：$W$ 值得成为标准教学与计算工具。

## 结论成立的条件与边界

论文的结论有明确的适用条件，作者也主动交代了若干限制。

分支编号与渐近展开依赖于作者选择的割线约定。作者明说，多值函数的分支划分“在某种程度上是任意的”，连初等函数都没有普遍接受的割线 [page 18]。他们选择让 $W$ 在 0 处的割线与对数割线一致、并采用 CCC，好处是渐近展开在 0 与无穷都“漂亮”，且满足近似共轭对称 $W_k(\bar z)=\overline{W_{-k}(z)}$ [page 18]。代价是式 (4.22) 在分支点附近更复杂 [page 19]。因此，式 (4.18)–(4.20) 的“对所有分支成立”是在这套约定下成立，换一套割线需要重新对应分支编号。

渐近展开的收敛性证明依赖 Rouché 定理与 $\sigma,\tau$ 足够小的条件，即 $z$ 足够大或足够小 [page 20–21]。作者指出，对 $z$ 充分大和充分小，$|\sigma|<a$、$|\tau|<a$ 成立，因此展开在这两个极限下有效 [page 21]。这不是对全平面一致有效的展开。

数值算法的排序结论有环境依赖。作者明确说比较是在 Maple V Release 3、DEC Alpha 3000/800S 上做的，并说排序“与其他平台所得一致”，但未给出其他平台的详细数据 [page 26]。初始猜测的区域边界是“经验确定的” [page 27]。因此“Halley 最优”应理解为在该实现与测试范围内成立，而非普遍定理。

积分方法方面，式 (3.16) 的推导假设 $f$ 可逆且 $f'$ 在相关区间非零；作者以“任一分支内部”说明式 (3.15) 对所有分支成立 [page 13]，但未讨论积分路径跨越割线时的情形。

论文没有讨论的限制，不应算作作者结论。例如，作者未给出 $W$ 在复平面上的全局误差界，只给出基于 $|W'|$ 的局部界与分支点附近的级数误差估计；作者也未证明 Halley 方法对所有初始猜测都收敛，只说初始猜测按区域选择 [page 27]。

## 这篇论文真正的论证转折

如果要用一句话概括这篇论文的论证策略：它把“$W$ 是什么”这个问题，转化为“如何给 $W$ 一个能同时服务复分析、数值计算与符号积分的标准表示”。历史部分说明 $W$ 不可避免；应用部分说明 $W$ 无处不在；分支部分给出标准编号；渐近部分给出可计算展开；数值部分给出任意精度算法；积分部分给出符号处理规则。每一块都服务于同一个目标：让 $W$ 从“各领域各自遇到的隐函数”变成“有标准名字、标准分支、标准算法、标准积分规则的一等公民”。

最关键的推理转折有两个。第一个是分支部分用 Jacobian 非零证明每块区域双射 [page 16]，这使分支编号不是任意贴标签，而是有几何依据。第二个是渐近部分用 Rouché 定理把形式展开升级为存在唯一性与收敛性证明 [page 20–21]，这使式 (4.18) 不只是渐近记号，而是绝对收敛级数。这两个转折共同支撑了论文最核心的主张：$W$ 可以被系统地、可靠地计算与操作，而不仅是被定义。
