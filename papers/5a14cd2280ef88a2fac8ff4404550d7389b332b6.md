# 高维不平衡数据中的 SMOTE：一个“看似有益、实则大多无效”的方法

**原文题名**：SMOTE for high-dimensional class-imbalanced data
**年份**：2013
**DOI**：https://doi.org/10.1186/1471-2105-14-106

## 论文要解决的问题与核心主张

类别不平衡的分类问题中，分类器倾向于把新样本判给多数类。已有研究表明，当数据同时是高维的（变量数远超样本数）时，这种偏向会被进一步放大；而简单的欠采样（undersampling）通常有效，随机过采样则无效 [page 1]。SMOTE（Synthetic Minority Oversampling TEchnique）是一种通过合成少数类样本来平衡训练集的过采样方法，被广泛使用，但它在高维数据上的行为此前没有被系统研究过——除了 SVM 之外，其他分类器上几乎没有专门考察 [page 2]。

作者的核心结论可以概括为一句话：**SMOTE 在低维数据上对多数分类器有益，但在高维数据上对绝大多数分类器几乎没有帮助，甚至有害；唯一在高维下能实质性受益的是 k-NN，且前提是先做变量选择** [page 12, page 13]。这个结论不是靠单一实验得出的，而是由一组理论性质、系统的模拟实验和三套乳腺癌基因表达数据的分析共同支撑。

## 理论部分：SMOTE 在高维下改变了什么

作者首先推导了 SMOTE 合成样本的几个统计性质，汇总在 Table 1 [page 3]。这些性质构成了后续所有经验结果的解释框架。

**均值不变、方差缩小。** SMOTE 样本的期望值等于原少数类样本的期望值（E(SMOTE) = E(X)），但方差只有原来的 2/3（var(SMOTE) = (2/3)var(X)）[page 3]。这一对性质直接决定了哪些分类器会受影响：依赖类别均值和总体方差的分类器（如 DLDA）几乎不受影响；而依赖类别特定方差的分类器（如 DQDA）会因方差被低估而产生偏差 [page 3]。此外，方差缩小加上样本量增大，会使 t 检验的标准误变小，p 值被低估——这意味着在 SMOTE 增强后的数据上做变量选择时，显著性检验的结果不能按常规解读，只能用于排序 [page 3, page 13]。

**引入样本间相关。** SMOTE 样本与生成它的原始少数类样本高度正相关，同一对原始样本生成的多个 SMOTE 样本之间也正相关 [page 3]。这违反了大多数分类器和变量选择方法所假设的样本独立性。作者指出，这对惩罚逻辑回归、判别分析等方法以及基于 t 检验或 Mann-Whitney 检验的变量选择都构成隐患 [page 3]。

**改变了欧氏距离的结构。** 这是解释 k-NN 异常行为的关键。在高维且用欧氏距离度量相似性时，测试样本平均而言更靠近 SMOTE 样本而非原始少数类样本 [page 3]。Figure 1 展示了这一现象：在类别不平衡程度很温和（k₂ = 36/80 = 0.45）、且类别间无真实差异的零假设下，随着变量数增加，测试样本到 SMOTE 样本的距离分布与到原始样本的距离分布之间的差距越来越大；当 p = 300 时，任何测试样本的“最近邻”几乎必然是某个 SMOTE 样本，而它属于少数类 [page 3, Figure 1]。这就解释了为什么在高维下不加变量选择地使用 SMOTE 会让 k-NN 严重偏向少数类——不是因为 SMOTE 修正了不平衡，而是因为它系统性地拉近了测试样本与少数类合成样本的距离。

值得注意的是，这些推导依赖 xR 与 x 独立且同分布的假设。作者通过模拟验证了这一假设在高维数据下近似成立，但在低维数据下不成立（低维时样本间正相关）[page 3]。附加文件 1 中给出了不依赖独立同分布假设的推广推导。

## 模拟实验：理论预测的验证

模拟设置的核心参数是：p = 1,000 个变量，n = 100 个样本，训练集 ntrain = 80，测试集为平衡的 20 个样本；变量按块相关结构生成（块内相关 ρ = 0.8、0.5、0.2 或 0），类别不平衡程度从 k₁ = 0.05 变化到 0.95 [page 14]。零假设下类别随机分配、所有变量来自 N(0,1)；备择假设下 20 个非零变量在两类间有均值差 μ(2) = 0.5、0.7、1 或 2 [page 14]。每个模拟重复 1,000 次，总共训练了超过 1,100 万个分类器 [page 14]。

**低维对照。** 在 p = G = 5、ntrain = 40/80/200、k₁ = 0.10 的设置下，SMOTE 确实有效：它减小了 k-NN（尤其是 5-NN）、PLR-L1、PLR-L2 和 PAM 对多数类的偏向，在备择假设下还提高了整体预测准确率；对 CART、SVM、RF 有较弱但方向一致的效果；对 DLDA 和 DQDA 几乎没有影响 [page 4, Figure 2]。这与高维结果形成鲜明对照。

**高维结果。** Figure 3（零假设）和 Figure 4（备择假设）展示了高维下的分类结果。所有未修正的分类器都把大多数测试样本判给多数类，无论是否做变量选择 [page 4]。SMOTE 对 k-NN 和 PAM 之外的分类器影响很小：它要么进一步增加了判给多数类的概率（DQDA 和 SVM），要么略微减小（RF、PLR-L1、PLR-L2、CART），但总体效果几乎可以忽略 [page 5]。对 k-NN 而言，效果则取决于是否做了变量选择：不做变量选择时，SMOTE 使绝大多数新样本被判给少数类；做了变量选择后，两类各自的预测准确率在很宽的不平衡范围内大致相等，3-NN 和 5-NN 尤其明显 [page 8]。

用 AUC 和 G-mean 衡量也得到类似结论：不做变量选择时，SMOTE 降低了 k-NN、DQDA 和 SVM 的 G-mean，提高了 RF、PLR-L1、PLR-L2 和 PAM（在不平衡严重时）的 G-mean，对 DLDA 和 CART 无变化；做变量选择后，SMOTE 提高了 k-NN 和 PAM 的 AUC 与 G-mean [page 8]。变量选择在 SMOTE 之前还是之后进行，对分类性能没有显著影响 [page 8]。

作者还检验了所有变量都有差异的情况（附加文件 4）和变量来自指数分布的情况（附加文件 5），结论一致 [page 8]。Figure 5 以颜色和箭头给出了模拟结果的视觉汇总 [page 8]。

## 真实数据：结论的一致性

三套乳腺癌基因表达数据（Sotiriou、Pittman、Miller）各做两个分类任务（ER 状态和肿瘤分级），变量数从 7,650 到 22,283，样本数从 99 到 249，少数类比例从 0.14 到 0.45 [page 9, Table 2]。分类器用 G = 40 个变量训练，性能用留一交叉验证评估，每个分类器用 50 个不同的 SMOTE 增强或欠采样训练集训练以考虑抽样变异 [page 15]。

实验结果与模拟高度一致 [page 8]。未修正的分类器对类别不平衡敏感，多数类的分类准确率通常更高，在不平衡严重时（Miller 和 Pittman 数据）或分类任务较难时（grade）差异更大 [page 8]。SMOTE 对 k-NN 的效果最为显著：做变量选择时，它大幅缩小了两类分类准确率的差距，提高了 G-mean，在 Miller 数据上还提高了 AUC；但不做变量选择时，SMOTE 使 k-NN 的性能急剧恶化——大多数样本被判给少数类，AUC 和 G-mean 大幅下降 [page 9]。Table 3 给出了 Miller 数据上不做变量选择时 k-NN 的详细数值：例如 1-NN 在 ER 任务上，SMOTE 后 PA1 仅为 0.156，PA2 为 0.996，AUC 为 0.576，G-mean 为 0.393，而简单欠采样的对应值为 PA1 = 0.742、PA2 = 0.761、AUC = 0.693、G-mean = 0.689 [page 10, Table 3]。

对其他分类器（RF、SVM、PAM、PLR-L1、PLR-L2、CART），SMOTE 缩小了两类准确率的差距，但简单欠采样的效果与之相当（PAM）或更好（其余）[page 9]。Figure 6 汇总了所有数据集上各方法的类别特定准确率、AUC 和 G-mean [page 9]。

作者还用 Sotiriou 数据构造了不同水平的不平衡（固定少数类样本数为 5 或 10，变化多数类样本数），进一步隔离不平衡程度的影响。Figure 7 显示：未修正分类器的少数类准确率随不平衡加剧而显著下降；SMOTE 改善了多数分类器的少数类准确率，但未能消除不平衡问题，且总体上仍不如欠采样——例外是 PAM 和 5-NN 在 ER 分类上的表现 [page 10]。

## 关键推理链与适用边界

整篇论文的论证逻辑可以这样串联：SMOTE 的合成机制（在少数类样本与其近邻之间线性插值）在高维空间中有三个可推导的后果——均值不变、方差缩小、测试样本到合成样本的欧氏距离系统性地小于到原始样本的距离。前两个后果解释了为什么依赖均值和总体方差的分类器（DLDA）几乎不受影响、依赖类别方差的分类器（DQDA）反而受害；第三个后果解释了为什么 k-NN 在不做变量选择时会严重偏向少数类。变量选择的作用在于去除大量无区分力的噪声变量，使得欧氏距离重新由真正有区分力的变量主导，从而消除 SMOTE 合成样本在距离上的“虚假优势”。

结论成立的条件需要明确。第一，这些结果针对的是**二分类问题**和作者考察的**有限几种分类器**（CART、k-NN、DLDA、DQDA、RF、SVM、PAM、PLR-L1、PLR-L2），作者明确承认不能排除其他未纳入的分类器在高维下可能从 SMOTE 受益 [page 13]。第二，理论推导假设 xR 与 x 独立同分布，虽然模拟表明这一假设在高维下近似成立，但它仍是一个限制 [page 3]。第三，作者只考察了原始版本的 SMOTE，但指出在零假设下 Borderline-SMOTE 和 Safe-Level-SMOTE 的理论结果应当相同，在类别间存在差异时则需要进一步研究 [page 13]。第四，实验数据仅限于乳腺癌基因表达数据，虽然模拟覆盖了不同的相关结构、分布和差异模式，但外部推广仍需谨慎。

作者在讨论中也指出，简单欠采样虽然只用了数据的一个子集，但在高维下有效，且其估计变异性大的缺点可以通过 bagging 技术缓解；已有研究表明 bagged 欠采样在高维下优于简单欠采样，也优于 SMOTE（对 SVM 而言）[page 12]。因此作者预期本文报告的分类结果还可以通过 bagged 欠采样进一步提升 [page 12]。

## 实践含义

论文的结论对实践有直接指导意义：在高维不平衡数据的分类任务中，SMOTE 不应作为默认的过采样方法。如果使用 k-NN 且基于欧氏距离，必须先做变量选择再使用 SMOTE，且使用更多邻居（如 5-NN）时收益更大；不做变量选择的 SMOTE + k-NN 应避免使用 [page 12, page 13]。对于判别分析类分类器（DLDA、DQDA），SMOTE 即使在低维下也无益，高维下 DQDA 还会因方差估计偏差而受害 [page 12]。在 SMOTE、欠采样和阈值调整三种策略中，高维场景下欠采样（对某些分类器则是阈值调整）通常是更可取的选择 [page 13]。
