# 生物特征密码系统与可撤销生物特征：一篇综述的论证结构

**原文题名**：A survey on biometric cryptosystems and cancelable biometrics（2011，DOI: 10.1186/1687-417x-2011-3）

## 一篇综述要论证什么

综述论文通常不提出单一假说，而是通过分类、比较和批判性评估来支撑一个总体判断。Rathgeb 与 Uhl 这篇综述的总体判断可以概括为：生物特征密码系统（biometric cryptosystems, BCS）和可撤销生物特征（cancelable biometrics, CB）是应对生物特征模板存储与滥用风险的两类新兴技术，它们在概念上紧密相关、在安全目标上共享不可逆性与不可链接性两项要求，但截至 2010 年前后，两者都尚未达到"可证明安全/隐私 + 实用识别率"的理想状态 [page 1, 20]。

这个判断不是靠一个实验支撑的，而是靠对大量方案的分类梳理、性能数据汇总和安全性分析逐步建立起来的。下面按论证的实际推进方式来展开。

## 问题起点：模板一旦泄露就无法更换

论证的起点是一个已被证伪的行业假设。业界长期声称从存储模板无法重建原始生物特征信号，但作者引用多项研究指出这一说法已被推翻 [page 1]。生物特征在很大程度上不可更改，因此模板一旦泄露就是永久性损失。标准加密算法又不支持在加密域中比较模板，导致每次认证时模板都处于暴露状态（同态加密和非对称加密是例外）[page 1]。

由此引出 ISO/IEC FCD 24745 的两项核心要求：**不可逆性**（从受保护模板重建原始模板在计算上不可行）和**不可链接性**（同一生物特征可生成不同版本用于更新，且不同版本之间不能交叉匹配）[page 1]。这两项要求是后文评估所有方案的基准。

## BCS 的内部分类与关键推理

BCS 被分为密钥绑定（key-binding）和密钥生成（key-generation）两类，分类依据是辅助数据（helper data）如何产生 [page 2, Figure 2]。这个分类不是任意的，它对应一个实质差异：密钥绑定中密钥独立于生物特征，因此密钥可撤销但更新通常需要重新注册；密钥生成中密钥直接来自生物特征，辅助数据不存储时密钥不可更新 [page 2-3]。

这里有一个贯穿全文的关键推理：**BCS 改变了性能度量的含义**。传统生物特征系统做"模糊比较"，用分数阈值判定；BCS 要求密钥 100% 正确，因此 FRR 变成"向真实用户返回错误密钥的比率"，FAR 变成"向非真实用户返回正确密钥的比率" [page 3, Figure 3]。作者明确指出 BCS 的识别性能通常明显低于传统系统，原因有二：注册模板在比较时不可见、无法正确对齐；多数 BCS 在特征提取时引入了更高程度的量化 [page 3-4]。这个推理很重要，它解释了为什么后文汇总的性能数据普遍不理想——不是实现不佳，而是范式本身带来的代价。

### 四类核心方案的论证角色

**模糊承诺（fuzzy commitment）** 用纠错码消除生物特征方差。Hao 等将其用于虹膜码，绑定 140 位密钥，在 70 人 700 张图像上取得 FRR 0.47%、FAR 0 [page 5, Table 1]。这是当时最好的结果之一。但作者随即指出，该方案绑定的密钥熵偏低（44 位），降低了暴力破解复杂度 [page 16]。这里体现了综述的一个典型手法：先呈现性能亮点，再从安全角度施加限制。

**屏蔽函数（shielding functions）** 通过 δ-收缩函数计算残差，在 $||X - Y|| \leq \delta$ 时能正确恢复密钥 [page 5-6, Figure 6]。其指纹应用报告 FRR 0.054%、FAR 0.032% [page 6]。

**模糊保险库（fuzzy vault）** 的核心优势是**顺序不变性**，能处理无序特征集（如指纹细节点）[page 6, Figure 7]。Clancy 等的首个实用实现假设指纹预对齐，作者指出这在实践中很少成立 [page 6]。Nandakumar 等用高曲率点辅助对齐，取得 FRR 4%、FAR 0.04% [page 6, Table 2]。这个从"假设预对齐"到"解决对齐"的推进，是模糊保险库论证线上的关键转折。

**量化方案** 为每个特征元素基于其方差定义区间，作者认为这比屏蔽函数更贴合生物特征的本质 [page 8]。但量化方案多用于行为特征，密钥较短（如 24 位 [page 8, Table 3]），性能也不理想（如 FRR 28% [page 8]）。

## 安全性的量化边界：一个关键不等式

BCS 安全性讨论中最重要的推理是 Buhan 等给出的关系：

$$k \leq -\log_2(\text{FAR})$$

即密钥最大长度 $k$ 与系统错误率直接相关 [page 10]。这意味着理想 BCS 需维持 $\text{FAR} \leq 2^{-k}$，作者评价这是一个"相当严格的上界，实践中可能无法达到" [page 10]。这个不等式的论证作用在于：它把"密钥长度"和"识别性能"从两个独立指标变成了相互约束的量，从而解释了为什么很多方案报告的长密钥实际上不可信——如果 FAR 不够低，密钥的有效熵就不够高。

作者进一步指出，BCS 存在密钥长度与隐私泄露之间的根本权衡，而这一权衡"很少被估计" [page 11]。这是综述对领域的一个批评性判断，而非作者自己的实验结论。

## CB 的论证线：不可逆变换与生物特征加盐

CB 分为不可逆变换和生物特征加盐（biometric salting）两类 [page 11]。核心区别在于：不可逆变换即使被攻破也无法重建原始数据，但通常损失精度；加盐变换是可逆的，变换参数必须保密，一旦参数泄露原始模板可能被恢复 [page 11-12]。

### 偷换令牌场景：一个方法论的转折点

CB 论证中最关键的转折是**偷换令牌场景（stolen-token scenario）**。作者论证：如果使用用户特定变换，在类间比较时必须假设变换已泄露，否则系统可以仅依赖秘密令牌而不依赖生物特征，生物特征就变得无意义 [page 12]。Figure 13 展示了这一场景如何改变类间距离分布：不考虑偷换令牌时类间分布清晰分离（零 EER），考虑后精度下降 [page 12]。

这个论证直接解释了 BioHashing 的问题。早期 BioHashing 报告零 EER [page 10]，但 Kong 等指出零 EER 源于假设令牌化随机数在受试者间唯一 [page 10]。在偷换令牌场景下，180 位 fingercode 的 EER 从 0% 升至 5.31% [page 13]。作者由此得出一个方法论结论：CB 的性能评估必须在偷换令牌场景下进行，否则会"不真实地获得性能" [page 12]。

## 攻击分析如何支撑总体判断

综述用一整节梳理针对 BCS 和 CB 的具体攻击 [page 16-18, Table 6]。这些攻击不是罗列，而是支撑"可证明安全仍然缺失"这一判断的证据。

对 BCS 而言，反复出现的攻击模式是**记录多重性攻击（attack via record multiplicity）**：攻击者获取同一秘密的多个实例后可重建秘密甚至生物特征模板 [page 16]。这一攻击影响模糊承诺、屏蔽函数、模糊保险库和密钥生成方案。模糊保险库还面临额外问题：它不隐藏原始模板，只是通过添加 chaff 点来掩盖，辅助数据中包含明文生物特征 [page 17]。Chang 等发现可区分细节点和 chaff 点，因为后创建的 chaff 点周围空白区域更小 [page 17]。作者由此指出模糊保险库的安全性"高度依赖 chaff 点的生成方法" [page 17]。

对 CB 而言，攻击目标是暴露秘密变换及参数。不可逆变换面临覆盖最终决策、记录多重性、已知变换的替换攻击；生物特征加盐在令牌被盗时面临假接受攻击、替换攻击和伪装攻击 [page 17, Table 6]。

这些攻击分析共同支撑了一个结论：**关键方案已被证明无法满足高安全需求，且由于缺乏形式化安全证明和严格的安全表述，这些技术声称的安全性仍不清晰** [page 20]。

## 结论成立的条件与边界

这篇综述的结论有明确的适用边界，作者自己也承认了若干限制：

**性能数据的可信度有限。** 报告实用性能的方案多在较小数据集上测试（如 70 人 [page 19]），作者明确说这"不能解释为显著" [page 19]。引入额外令牌（随机数或 PIN）常常"模糊了报告结果的图景" [page 19]。

**对齐问题是共同瓶颈。** 两种技术中模板都被遮蔽，无泄露地对齐非常困难。虹膜尚可对齐，指纹则需要存储额外信息 [page 20]。作者指出，传统生物特征系统已有对齐不变方法，但"几乎没有人提出构建对齐不变的 BCS 或 CB" [page 20]。

**纠错码不是为生物特征设计的。** 实用纠错码是为通信和数据存储设计的，针对所需码长的完美纠错码"仍然难以实现" [page 20]。而且纠错能力下界约束了 FRR，无限制使用纠错反而使系统更脆弱 [page 20]。

**chaff 点生成问题未解决。** 生成与真实点不可区分的 chaff 点的技术"尚未被提出" [page 20]。

**形式化安全证明缺失。** 作者反复强调这一点，认为这是领域面临的核心挑战 [page 20]。

需要区分的是：以上是作者明确承认的局限。作为分析者可以补充一点推断——综述覆盖至 2010 年，此后深度学习特征提取和新的密码学工具可能改变了部分结论的适用性，但这是文本之外的推断，不应归为作者观点。

## 论证的整体形状

把上述线索合起来看，这篇综述的论证不是"BCS 和 CB 很好"或"它们不好"，而是一个有条件的评估：两种技术在概念上正确回应了模板保护的不可逆性和不可链接性要求，提供了传统生物特征系统不具备的密钥释放和假名认证能力 [page 15, Table 5]；但截至综述时点，没有任何方案同时实现可证明的安全/隐私和实用识别率，即使在小数据集上也没有 [page 20]。这个结论的力度被作者谨慎地限定在"当前技术水平"和"已发表方案"的范围内，其支撑来自性能数据的系统汇总、安全攻击的具体分析，以及一个关键的量化约束（$k \leq -\log_2(\text{FAR})$）所揭示的内在张力。
