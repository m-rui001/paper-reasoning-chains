# 用小型周期结构模拟随机合金：Zunger 等人的“特殊准随机结构”论证

**原文题名**：Special Quasirandom Structures
**作者**：Alex Zunger, S.-H. Wei, L. G. Ferreira, James E. Bernard
**出处**：Physical Review Letters, Vol. 65, No. 3, 16 July 1990, pp. 353–356
**DOI**：未在提取文本中给出

## 问题与核心主张

置换式随机合金 A₁₋ₓBₓ 的性质计算面临一个根本困难：即使只有 N 个格点，也存在 2^N 种原子构型，逐一做结构弛豫再平均在计算上不可行 [page 1]。实践中通常有两条退路：要么抽取少量“代表性”构型（如蒙特卡洛），要么在单个周期胞内随机占据 N 个格点。作者指出，这类做法的统计误差随 N⁻¹ᐟ² 缓慢收敛，因此需要大量构型（如蒙特卡洛中约 10³ 个）或很大的胞（如 >10³ 原子），而当时第一性原理自洽计算仅能处理 N ≲ 50 原子 [page 1]。

作者的核心主张是：与其用统计抽样逼近随机合金，不如**主动设计**一个小的周期结构 S，使其自身的关联函数尽可能匹配无限随机合金的系综平均关联函数。这样的结构被称为“特殊准随机结构”（Special Quasirandom Structures, SQS）。作者声称，SQS 在 N 小至 8 时就能比标准随机占据法更好地再现随机合金的前几个径向关联函数，从而让精确电子结构方法可用于计算随机合金的结构、光学和热力学性质 [page 1]。

## 论证的形式框架

论证的骨架建立在统计格点理论的集团展开之上。作者将合金构型 σ 分解为“图形” f(k,m)——k 个顶点、相隔第 m 近邻距离的原子对、三角形等。每个格点 i 赋予伊辛型自旋变量 Sᵢ：A 为 −1，B 为 +1。图形 f 在位置 l 的自旋乘积为 Π_f(l,σ)，格点平均为 Π̄_f(σ) = (1/ND_f) Σ_l Π_f(l,σ) [page 2, Eq. (1)]。物理性质 P 的系综平均可严格展开为 (P) = Σ_{k,m} D_{k,m} (Π_{k,m}) p_{k,m}，其中 p_{k,m} 是相互作用参数，(Π_{k,m}) 是关联函数 [page 2, Eq. (2)]。

对完美随机合金，多体关联函数 (Π_f)_R = (2x−1)^k，在 x = ½ 时除 Π₀ = 1 外全部为零 [page 2]。这提供了一个清晰的判据：好的有限 N 代表结构，其关联函数应尽可能接近零（在 x = ½ 时）。

关键推理步骤在于 Eq. (3)：性质误差可表示为 (P) − P(S) = Σ'_{l,m} D_{l,m} [(2x−1)^k − Π_{l,m}(S)] p_{l,m}，其中撇号表示省略 k = 0 和 1 [page 2]。这一展开式将“结构误差”与“性质误差”联系起来，但联系依赖于相互作用参数 p_{k,m} 的层级结构。作者明确采用的指导原则是：近邻相互作用对总能的贡献一般大于远邻，因此应优先让最近几个壳层的关联函数匹配随机网络，将周期性误差推迟到更远的邻居 [page 1]。这是一个物理假设，而非数学定理——它决定了 SQS 构造的优先级顺序。

## 从证据到结论

**关联函数匹配的证据**（Table I, [page 2]）。作者在 fcc 格点上构造了 N = 2, 4, 6, 8 的 SQS，并给出各近邻对关联函数的绝对值 |Π_{k,m}|。对完美随机合金在 x = ½ 时这些值应为零，因此偏离零即误差。SQS-8 的单元胞被描述为沿 [113] 方向的 A₂B₃A₂B₁ 超晶格。Table I 显示 SQS-8 在第一、第二和第六近邻关联函数上等效于 N → ∞，在第三近邻上等效于 N = 64，而标准随机占据法在 N = 8 时第一近邻误差已达 0.215，且出现周期性误差（关联函数值为 −1 而非 0）出现在相当短的距离上 [page 2]。作者还给出异类近邻数的分布：完美随机结构中 ⟨θ_m⟩ = D_m/2，SQS-8 在标准偏差范围内再现了这一分布 [page 3]。

**热力学性质的证据**（Table II, [page 3]）。作者用 LAPW 方法对 x = ½ 的 SQS 做自洽计算，得到混合焓 ΔH。对 GaP₀.₅As₀.₅，SQS-2、-4、-8 分别给出 26.1、13.9、16.5 meV/(4 atoms)，实验值为 18 ± 10 meV [page 3]。对 Al₀.₅Ga₀.₅As，三个尺寸给出 13.7、10.5、10.5 meV/(4 atoms)，收敛更快 [page 3]。Table II 还将 SQS-4 的结果与 Ising 模型在 T = 800 K 和 T → ∞（随机合金）下的计算对比，后者与实验混合焓吻合良好 [page 3]。这里的关键推理是：如果 SQS-4 的直接计算能再现 Ising 模型对随机合金的统计力学结果，而后者又已与实验验证，那么 SQS 就间接获得了实验支持。

**光学性质的证据**（Table II 下半部分及 [page 4]）。作者计算了七个半导体合金的光学弯曲系数 b。以 GaP₀.₅As₀.₅ 为例，SQS-2、-4、-8 给出 0.14、0.19、0.19 eV，实验值为 0.21 eV [page 4]。Table II 中 SQS-4 的弯曲系数与实验范围总体吻合，而 CuPt 结构（一种有序结构）的结果则显著偏离 [page 3]。作者还做了一个收敛性测试：用 N_s = 5, 6, 7 个有序结构的带隙通过 Eq. (2) 拟合相互作用参数，再预测 SQS-8 的带隙，得到 1.42、1.34、1.37 eV，直接计算给出 1.38 eV，与六近邻集团展开的 1.37 eV 吻合 [page 4]。

**一个特别有说服力的对照**（[page 4]）。作者用 2304 原子随机胞和仅 16 原子的 SQS-8，在相同紧束缚哈密顿量下计算 Al₀.₅Ga₀.₅As 的带隙。2304 原子给出 Γ₁ᵥ = 2.215 eV、L₁ᵥ = 2.185 eV、X₁ᵥ = 2.145 eV、X₃ᵥ = 2.645 eV；SQS-8 给出 2.217、2.196、2.160、2.640 eV，全部在 0.015 eV 以内 [page 4]。这个对照直接展示了 SQS 以极小胞达到大胞统计精度的能力。

**结构弛豫重要性的证据**（[page 4]）。作者指出，忽略结构弛豫（如 VCA 和 SCPA 所做）在尺寸失配合金中导致巨大误差：未弛豫的 Ga₂SbAs 的 b(SQS-2) 为 0.32 eV，而弛豫结构为 1.30 eV；ΔH 为 237 meV 而非 115 meV。对 GaAsP，ΔH 为 60.2 meV 而非 16.5 meV [page 4]。这一对照说明 SQS 方法的一个关键优势：它允许在常规能带结构方法中直接纳入原子弛豫和电荷重分布，而这是 VCA/SCPA 无法做到的 [page 3]。

## 关键推理步骤与省略的桥接

从证据到结论的推理链可以重构如下：

1. 随机合金的性质由 Eq. (2) 的关联函数展开严格描述。
2. 在 x = ½ 时，完美随机合金的多体关联函数为零。
3. 因此，一个有限 N 周期结构若其关联函数接近零，就应能较好地再现随机合金的性质——**这一步依赖于 Eq. (3) 中相互作用参数 p_{k,m} 随距离衰减的假设**。作者明说“近邻相互作用一般比远邻对总能的贡献更大”[page 1]，但并未给出 p_{k,m} 衰减的定量证明。这是整个论证的关键桥接，也是其适用边界所在。
4. SQS 构造通过优先最小化最近壳层的关联函数误差来实现这一目标。
5. 数值证据（Table I、Table II、2304 原子对照）表明，SQS-8 在关联函数、混合焓和带隙上确实快速收敛。

作者省略的一个桥接是：为什么 Eq. (3) 中的 p_{k,m} 层级结构与距离的对应关系在具体合金中成立。作者引用了他们之前的工作（Ref. 7）来支持 Ising 模型相互作用参数的收敛性，但并未在本文中展示 p_{k,m} 随距离衰减的具体数据。读者需要接受这一物理直觉：近邻相互作用更重要。

## 适用条件、边界与局限

**作者明说的条件**：
- SQS 方法在本文中仅对半导体合金进行了演示，但作者认为可推广到其他组分和格点类型（bcc、金刚石型等）[page 4]。
- SQS 会引入人工长程有序，但作者认为这仍能描述阈值附近的光学性质 [page 4]。
- 收敛性测试（N_s = 27）确认 SQS-8 对 GaAlAs 和 GaAsP 的带隙预测在 ~0.05 eV 以内 [page 4]。

**作者承认的局限**：
- 周期结构必然引入“周期性误差”，即超出一定距离的虚假关联 [page 1]。SQS 的策略是将这些误差推迟到更远的邻居，而非消除它们。
- N = 2 通常太小，不足以代表随机合金 [page 3]。

**未讨论但影响结论的边界**（分析者推断）：
- SQS 的构造依赖于具体格点和组分。本文的 SQS-8 是针对 fcc 格点和 x = ½ 设计的。对其他组分或格点，需要重新构造 SQS，其收敛速度可能不同。
- Eq. (3) 的收敛性依赖于 p_{k,m} 的快速衰减。对相互作用较长程的体系（如某些金属合金），SQS 的优势可能减弱。
- 本文的数值证据集中在 x = ½。对偏离 ½ 的组分，关联函数不再为零，SQS 的构造判据需要调整。
- Table I 中部分数值（如 SQS-6 的某些关联函数值）在提取文本中可能存在 OCR 疑点（如“1 d”标注），但核心结论不依赖于这些个别数值。

## 结论的力度

作者的核心结论——SQS 能在小 N 下比标准随机占据法更好地再现随机合金的关联函数和性质——得到了多组合金、多种性质（关联函数、混合焓、光学弯曲、带隙）的一致支持。2304 原子与 16 原子 SQS-8 的带隙对照尤其有力，因为它直接展示了 SQS 以极小计算量达到大胞统计精度的能力。

然而，这一结论的普适性受限于两个条件：一是相互作用参数随距离衰减的物理假设，二是 SQS 构造对具体格点和组分的依赖性。作者在文末承认 SQS 仅对半导体合金进行了演示，其推广到其他体系是“可以轻易实现”的预期，而非已证实的结论 [page 4]。因此，SQS 方法的有效性在本文中是一个有充分数值支持但边界明确的主张：对 fcc 基半导体合金在 x = ½ 附近，SQS-8 能以约 16 原子的胞达到与数千原子随机胞相当的精度；对更一般的体系，其收敛速度需要逐案验证。
