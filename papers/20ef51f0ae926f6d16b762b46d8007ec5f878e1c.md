# 用“阳离子势”预测钠离子层状氧化物的堆垛结构：从描述符到可合成材料

原文题名：Rational design of layered oxide materials for sodium-ion batteries
作者：Chenglong Zhao, Qidi Wang, Zhenpeng Yao 等
期刊/年份：Science 370, 708–711 (2020)
DOI：10.1126/science.aay9972

## 问题的起点：P2 与 O3 之争

钠离子电池被视为电网级储能的候选技术，原因在于钠资源丰富、成本低 [page 1]。但电池性能受限于可用的电极材料，尤其是钠离子层状氧化物 NaxTMO2。这类材料的结构由共边的 TMO6 八面体构成，碱金属离子位于层间。与锂离子层状氧化物几乎只形成八面体（O 型）配位不同，钠离子层状氧化物还可以形成棱柱体（P 型）配位，其中研究最多的是 P2 型和 O3 型：前者对应 ABBA 氧堆垛，后者对应 ABCABC 氧堆垛 [page 1]。

这两种堆垛方式带来截然不同的电极性能。P2 型通常具有更高的钠离子电导和更好的结构完整性，因而功率密度高、循环稳定性好；但 P2 型初始钠含量较低，首次充电的储钠容量受限。O3 型则相反，钠含量高、容量大，但结构稳定性往往较差。充放电过程中 O 型与 P 型之间还可能发生相变，进一步损害循环寿命 [page 1]。因此，如果能事先预测某一给定组成会形成 P2 还是 O3，就能有针对性地设计材料。论文的核心主张正是：存在一个简单描述符——“阳离子势”（cationic potential），可以准确预测层状氧化物的堆垛结构，并据此理性设计出性能更优的新材料 [page 1]。

## 阳离子势：一个从离子势改造而来的描述符

作者的理论出发点是离子势（ionic potential）概念。离子势 Φ 定义为电荷数 n 与离子半径 R 之比，由 Cartledge 提出，反映离子表面的电荷密度和阳离子极化能力 [page 2]。作者在此基础上定义“阳离子势”：

Φcation = ΦTM · ΦNa / ΦO  (式 1)

其中 ΦTM 是过渡金属离子势的加权平均，ΦTM = Σ wi·ni/Ri，wi 是第 i 种过渡金属的含量，ni 和 Ri 分别是其电荷数和半径；ΦNa 是钠的加权平均离子势，ΦNa = x/RNa，x 为钠含量。电荷平衡要求 Σ wi·ni = 4 − x，其中 4 是补偿 O2− 所需的总氧化态 [page 2]。

这个描述符的物理含义是：它同时捕捉了过渡金属电子云的延展程度（通过 ΦTM）和钠离子对层间静电排斥的屏蔽能力（通过 ΦNa），并以氧的离子势 ΦO 作归一化。作者将已报道的 P2 型和 O3 型层状氧化物的 Φcation 对 ΦNa 作图，得到 Fig. 1B 的相图。相图中 P2 和 O3 各自占据清晰可分的区域，说明阳离子势确实能区分两种堆垛结构 [page 2]。

其机制解释是：较大的阳离子势意味着过渡金属电子云更延展、层间静电排斥更强，倾向于形成 P2 型，同时伴随更强的共价 TM–O 键和更大的 d(O-Na-O) 距离；反之，较大的平均钠离子势（即更高的钠含量）增强了对 TMO2 层间静电排斥的屏蔽，倾向于 O3 型 [page 2]。这一解释与早期观察一致：P2 型较大的 d(O-Na-O)/d(O-TM-O) 比值源于 TMO2 板层内更局域的电子分布，导致相邻 NaO2 板层间排斥较弱、相邻 TMO2 板层间排斥较强 [page 2]。

## 与既有方法的对比：为什么需要新描述符

作者明确指出，Delmas 等人曾用 Rouxel 图来区分 NaxTMO2 的堆垛结构，并证明钠含量以及键的离子性/共价性是重要因素 [page 3]。但该方法只考虑 Pauling 电负性差异，无法预测同一过渡金属处于不同氧化态的氧化物（例如 Na0.7MnO2 中的 Mn4+ 和 Mn3+），也无法处理多组分体系 [page 3]。阳离子势则能正确预测这些情况，为钠离子层状氧化物的开发提供了指导 [page 3]。这一对比是论文论证的关键一步：它说明新描述符不只是对已知数据的重新拟合，而是能覆盖旧方法失效的情形。

## 从预测到合成：两个方向的验证

论文的说服力不仅在于相图的区分度，更在于作者用阳离子势指导合成了两种此前难以获得的结构。

**设计 O3 型材料。** 起点是 NaLi1/3Mn2/3O2，它是 Li2MnO3（LiLi1/3Mn2/3O2）的钠类似物，理论上被认为稳定于 O3 型 [page 3]。但作者尝试多种实验条件，始终得到 P2 型组分和其他相，无法合成纯 O3 型。根据阳离子势，降低 Φcation 可能有助于形成 O3 型，途径是用离子势较低的 Ti4+ 部分取代 Mn4+（Fig. 2A）。作者用典型固相反应成功制备了 NaLi1/3Ti1/6Mn1/2O2，且预测的 O3 型结构得到确认；而 NaLi1/3Mn2/3O2 用同样方法无法得到 O3 型（Fig. 2B）[page 3]。XRD 精修确认了层状岩盐结构（Fig. 2C），NaO2 层与混合的 [Li1/3Ti1/6Mn1/2]O2 板层交替排列（Fig. 2D）。20°–30° 的超结构峰表明 Li/Mn(Ti) 呈蜂窝状有序排列，像差校正 STEM 也证实了这一点 [page 3]。这种在纯 3d 过渡金属 O3 型钠离子氧化物中未曾观察到的有序排列，是阳离子势指导设计的一个额外收获。电化学测试显示能量密度约 630 Wh kg−1，高于已报道的 O3 型电极 [page 3]。

**设计 P2 型材料。** 这一次作者反过来追求高钠含量（x > 0.67）的 P2 型结构，仍从 NaLi1/3Mn2/3O2 出发。根据 Fig. 1B 的分界线，若保持钠含量不变，需要提高阳离子势，即提高过渡金属位点的离子势。但计算表明，x = 1 的 P2 型结构（ΦNa = 9.8）需要极大的 TM 离子势，超过 Mn4+（常用过渡金属中最大者）[page 3]。因此必须降低钠含量，通过减少 Li、增加 Mn 来实现电荷补偿。沿此路线，阳离子势预测 Na5/6Li5/18Mn13/18O2 应具有 P2 型结构（Fig. 3A），实验成功制备（Fig. 3B）[page 3]。此前如此高钠含量的层状氧化物通常结晶为 O3 型。与 O3 型 NaLi1/3Ti1/6Mn1/2O2 相比，P2 型的 (002) 峰向低衍射角移动，表明 c 轴增大（Fig. 3B）。XRD 精修表明该 P2 型结构可指标化为六方 P63 空间群（Fig. 3C, D），EELS 映射显示 Na、Mn、O 均匀分布 [page 3]。该高钠含量材料的容量超过 200 mAh g−1 [page 3]。

这两个案例构成了论文的核心经验证据：阳离子势不仅能事后区分已知结构，还能事前预测并指导合成出违反常规预期的新结构。

## 推广到其他碱金属与大规模筛选

作者将阳离子势推广到锂离子（fig. S12）和钾离子（fig. S13）层状氧化物，得到 Fig. 4 的相图。阳离子势从 K 到 Na 到 Li 递增，因为屏蔽 TMO2 层间相互作用的能力依次增强。结果是 KxTMO2 主要结晶为 P2 型，LixTMO2 为 O3 型，而 NaxTMO2 恰好处于 P2 与 O3 的临界点附近，成为最引人注目的体系 [page 3]。已报道的层状电极材料在相图中明显聚集于分界线附近（Fig. 4）。作者还对超过 100,000 个新组成（过渡金属位点最多到四元）用阳离子势计算最稳定堆垛结构，得到的组成分布同样围绕分界线（figs. S14, S15）[page 3]。这一大规模筛选展示了该方法在新材料预测上的实用潜力。

## 结论成立的条件与边界

作者在讨论部分明确列出了阳离子势方法的适用边界，这些限制对理解结论的适用范围至关重要。

首先，对于熵主导的相、机械球磨产生的无序化合物、在特定条件下制备的氧化物、亚稳结构或非平衡相，以及过渡金属的局域畸变（例如 Mn3+ 的 Jahn-Teller 效应），阳离子势方法不提供有意义的指导 [page 4]。其次，阳离子势只预测材料会结晶为 P 型还是 O 型，且一个组成只对应一个结构；实际获得的相强烈依赖于前驱体性质、热处理条件和气氛等，这些因素可能导致化学计量比和动力学过程的差异，进而引起结构变化 [page 4]。因此，要判断材料是否稳定、是否可实际合成，还需要进一步的结构信息，需要大量研究 [page 4]。此外，作者指出密度泛函理论方法在预测堆垛结构方面存在困难，因为难以预测过渡金属轨道的局域性质，尤其是过渡金属组成复杂、构型空间巨大时 [page 4]。

值得注意的还有相图本身的边界含义。作者指出，远离分界线的其他区域也可能导致其他类型的过渡金属氧化物相（如岩盐、尖晶石），或者根本不能形成稳定结构，这是正在进行的研究的主题 [page 3]。这意味着阳离子势的预测能力集中在分界线附近，而非全组成空间。

## 论证的关键一步与整体评估

回顾整篇论文的论证链条：作者从 P2/O3 结构差异的物理起源（层间静电排斥与电子分布）出发，构造了一个同时包含过渡金属离子势和钠离子势的复合描述符；用已报道材料的相图验证其区分能力；再通过与 Rouxel 图的对比说明其覆盖旧方法失效的情形；最后用两个方向的合成案例（O3 型和 P2 型）证明其预测能力，并推广到其他碱金属和大规模组成筛选。

其中最关键的一步，是将“层间静电相互作用的微妙平衡”这一物理图像，压缩为一个仅依赖电荷数、离子半径和化学计量比的标量。这一步之所以成立，是因为作者论证了 P 型与 O 型的主要差异确实源于 AO2 与 TMO2 板层间的静电极化 [page 4]。但这也正是方法的边界所在：一旦体系偏离这一主导机制（如熵主导、动力学捕获、局域畸变），描述符就失去预测力。作者对此有清醒认识，并在讨论中明确划定了适用范围。

从证据强度看，相图（Fig. 1B, Fig. 4）提供了统计层面的支持，两个合成案例（Fig. 2, Fig. 3）提供了因果层面的验证，而 100,000 个组成的筛选（figs. S14, S15）展示了方法的可扩展性。但论文也承认，预测的结构是否实际可合成，仍需实验检验，且实际相受前驱体和热处理条件影响 [page 4]。因此，阳离子势更适合被理解为一个高效的筛选和指导工具，而非对最终产物的确定性预言。论文最后建议进一步探索高钠含量 P2 型和低钠含量 O3 型氧化物 [page 4]，这既是方法的应用方向，也暗示了当前已知材料在相图上的分布仍不完整。
