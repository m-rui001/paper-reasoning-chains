# 深度学习能否在药物靶点预测中胜出：一项规避三类偏差的大规模 ChEMBL 基准比较

**原文题名**：Large-scale comparison of machine learning methods for drug target prediction on ChEMBL（2018，DOI: 10.1039/c8sc00148k）

## 论文要回答的问题，以及它为什么认为以往比较不可信

作者的核心主张是：在药物靶点预测这一任务上，深度学习（尤其是前馈神经网络 FNN）显著优于其他被比较的方法，并且其预测精度在许多情况下可与湿实验室（in vitro）测定相媲美 [page 1]。但这个结论之所以值得单独做一次大规模研究，是因为作者认为既有的方法比较研究普遍受三类偏差污染，从而无法回答"深度学习是否真的更好"这一问题 [page 1–2]。

第一类是**数据集规模与任务覆盖不足**。许多比较研究只涉及单个或极少数 assay 或靶点，这既把结论限制在特定子集上，也低估了多任务学习（multitask learning）的潜在收益——因为当某些靶点测量数据极少时，单任务模型难以构建有效表示，而多任务模型可以跨任务共享隐层表示 [page 1–2]。作者用 Fig. 1 说明这一前提：大量化合物被多个 assay 测量过（左图），且这些共同测量的 assay 之间存在强相关（右图）[page 1]。这为"多任务学习有用"提供了数据基础，但注意这只是支持多任务建模合理性的观察，本身不是性能证据。

第二类是**化合物系列偏差（compound series bias）**。化学家通常先合成新的骨架（scaffold），再在其上添加官能团衍生新化合物；因此，若训练集与测试集中含有同一系列的化合物，预测会被人为地变得容易，性能估计会过于乐观，无法反映"预测全新系列化合物"的真实使用场景 [page 2]。

第三类是**超参数选择偏差（hyperparameter selection bias）**。若测试集标签以任何方式影响了超参数调整，性能估计就会偏乐观；而不同算法拥有的超参数数量和调节能力不同，因此受此偏差影响的比较"通常是不公平的" [page 2]。作者特别指出，这一问题在深度学习上尤为突出，因为其架构、激活函数、学习率、正则化参数的组合极多 [page 2]。

## 三项偏差如何被逐一处理：这是全文论证的关键一步

作者的论证策略不是直接比较算法，而是先构造一个"无偏"的比较框架，再在其中比较。理解这一点，才能理解为什么他们的结论比一般基准测试更有分量。

针对第一类偏差，作者从 ChEMBL 提取了一个大规模基准数据集，包含约 500 000 个化合物和 1000 多个 assay，覆盖酶、离子通道、受体等多种靶点类别，且 assay 规模差异很大——既有仅数百次测量的 assay，也有数万次测量的 assay [page 2]。最终用于比较的数据集为 456 331 个化合物 [page 4]。

针对第二类偏差，作者采用**聚类交叉验证（cluster-cross-validation）** [page 2–3]。其做法是：先用单链接聚类（single-linkage clustering）对 ChEMBL 全部 1 456 020 个化合物聚类，距离度量采用二值化 ECFP4 特征的 Jaccard 距离；然后把整个簇分配到不同折，使同一簇的化合物要么全在训练集、要么全在测试集 [page 3, page 7]。单链接聚类能保证任意两簇之间的最小距离，从而避免训练集化合物与测试集化合物距离过近 [page 7]。作者还给出了这一处理的效果证据：随机交叉验证的性能估计平均比聚类交叉验证高 0.02（配对 Wilcoxon 符号秩检验 p = 2.8E-51），说明随机交叉验证确实更乐观 [page 7–8, Table 3]。这是全文少见的、直接量化"偏差有多大"的证据。

针对第三类偏差，作者采用**嵌套交叉验证（nested cross-validation）** [page 3]。外层循环测量性能，内层循环调整超参数；内层用三折中的一折训练、一折验证超参数组合、留一折作外层测试折，外层再用内层选出的超参数训练模型 [page 3]。这样得到的性能估计不受超参数选择偏差影响 [page 3, page 8]。超参数选择标准是内层各折 assay-AUC 的均值 [page 8]。

这里有一个值得读者注意的推理桥接：作者并未证明"嵌套聚类交叉验证"是唯一正确的评估方式，而是论证它同时规避了三类已知偏差。因此，其结论的强度依赖于"这三类偏差是主要威胁"这一判断。若存在作者未识别的第四类偏差，结论的适用范围就会相应收窄——这是基于文本的分析推断，不是作者原话。

## 比较结果：FNN 胜出，但"深度学习"内部并不一致

作者把靶点预测建模为二分类问题：每个 ChEMBL assay 视为一个独立的分类问题，即使多个 assay 共享同一生物靶点也不合并，以避免把不可比的 assay 类型（如结合 assay、拮抗剂 assay、激动剂 assay）混在一起 [page 3]。由于原始测量信号常为实数、没有现成二值标签，作者自行制定了二值化协议（细节见 ESI Section S2.1）[page 3]。

比较对象包括：深度学习方面有前馈网络（FNN）、图卷积网络（GC 与 Weave）、以及以 SMILES 字符串为输入的 LSTM（SmilesLSTM）；传统方法方面有支持向量机（SVM）、K 近邻（KNN）、随机森林（RF）、朴素贝叶斯（NB），以及专为药物发现构建的 SEA [page 3]。性能指标为 ROC-AUC（文中简称 AUC）[page 3]。

主要结果见表 1 与 Fig. 2 [page 4–5]。FNN 在每一个特征类别上都显著优于其他方法（α = 0.01），并且在几乎所有特征类别上显著优于图卷积和 SmilesLSTM，唯一例外是 StaticF 特征 [page 5]。第二好的是 SVM；在 ECFP6、ECFP6 + ToxF 或 SemiF 特征下，SVM 显著优于图卷积网络和 SmilesLSTM [page 5]。一个有意思的细节是：SmilesLSTM 的平均 AUC 高于两种基于图的深度方法 [page 5]。此外，经典机器学习方法（SVM、RF）整体优于典型的化学信息学方法 [page 5]。最佳单点性能来自基于 SemiF 特征的 FNN（0.743 ± 0.124），而 ECFP6 + ToxF 对多数算法都表现良好 [page 4–5, Table 1]。

这里需要提醒读者注意"深度学习"一词的内部异质性：作者的核心结论实际上是"FNN 最好"，而不是"所有深度架构都最好"。图卷积和 SmilesLSTM 并未稳定超过 SVM。因此，把本文结论简化为"深度学习全面胜出"会丢失作者论证的关键区分。

## 从"算法比较"到"虚拟 assay"：结论如何被推到临床/实验语境

作者进一步追问：FNN 的预测精度能否达到另一个测量同一靶点的替代（surrogate）in vitro assay 的水平 [page 5–6]。他们用严格标准和人工审核找到 22 对测量同一生物效应的 assay 对，把测量化合物较少的 assay 作为待预测的"真值"，测量化合物较多的作为替代 assay [page 3–4, page 6]。

结果（Table 2、Fig. 3）[page 5–6]：替代 in vitro assay 的平均准确率为 0.81 ± 0.17，深度学习模型为 0.82 ± 0.10。22 对中有 13 对两者无显著差异；5 对中计算方法显著更好；4 对中替代 in vitro assay 显著更好 [page 6]。作者据此得出结论：深度学习对某一靶点的预测性能与测量同一靶点的替代 assay 相当 [page 6]。

这一结论的边界值得明确。首先，它比较的是"替代 assay"而非"金标准 assay"——替代 assay 本身可能不完美，因此"相当"不等于"达到真实生物效应测量的上限"。其次，22 对 assay 是经过严格筛选和人工监督得到的，样本量有限，且其中若干对的置信区间很宽（如 CHEMBL1737863 的替代 assay 准确率 0.62 [0.3869, 0.8105]）[page 5, Table 2]。第三，在 4 对中替代 assay 显著更好，说明"相当"是平均意义上的，并非普遍成立。作者自己的措辞是"on par with"（与……相当），而非"优于"，这一谨慎语气应被保留。

## 数据量、靶点类别与 assay 类型：结论在哪些条件下更稳

作者考察了训练集大小与性能的关系（Fig. 4）[page 6–7]：训练集越大，预测通常越好，这一趋势在 FNN、SVM、RF 三种方法上一致 [page 6–7]。但即使样本很少，AUC 也几乎总是优于随机分类 [page 7]。这支持了"ChEMBL 这类大型化合物-assay 数据库足以构建高精度深度学习模型"的结论，也解释了作者为何在结论中展望使用制药公司内部的高质量大型数据库可能进一步提升性能 [page 9]。

按 ChEMBL 靶点类别（Fig. 5）和 assay 类型（Fig. 6）分组的性能显示：所有类别的预测性能都明显优于随机，作者据此推断深度网络的应用范围可能很广，不限于某些知名靶点；深度学习在功能 assay 和结合 assay 上都表现良好 [page 7]。需要注意，Fig. 5 仅基于有注释的 assay，且一个 assay 可能属于多个类别 [page 7]，因此这些分组结果应视为描述性而非严格的分层结论。

## 结论成立的条件与作者承认的局限

综合来看，本文结论在以下条件下成立：使用大规模、多 assay 的数据集；采用聚类交叉验证以模拟"预测新骨架"的场景；采用嵌套交叉验证以避免超参数选择偏差；以 ROC-AUC 为指标；以 FNN 为深度学习的代表。在这些条件下，FNN 显著优于被比较的其他方法，且其精度与替代 in vitro assay 相当。

作者明确承认或文本中可识别的限制包括：NB 无法在静态特征上运行（需要二值特征），SEA 只计算了 ECFP6 特征的结果，且因性能低、计算需求不可忽略而跳过了其他特征类别 [page 5]——这意味着 SEA 与 NB 的比较覆盖不完整，可能影响它们在总排名中的位置。此外，二值标签由作者自定协议生成，其合理性依赖于该协议（ESI Section S2.1），而协议细节不在正文中 [page 3]。22 对 assay 的样本量有限，部分置信区间较宽 [page 5, Table 2]。

需要区分的是：作者并未声称深度学习在所有药物发现任务上都优于所有方法，也未声称虚拟 assay 可以替代真实实验。他们的结论严格限定在"药物靶点预测"这一二分类任务、这一数据集、这一评估框架内。将结论外推到其他化学任务（如毒性预测、ADMET）或更小的数据集，超出了本文证据范围。

一个基于文本的分析推断是：本文最有方法论价值的部分，可能不是"FNN 最好"这一排名，而是它展示了如何用聚类交叉验证与嵌套交叉验证同时控制化合物系列偏差和超参数选择偏差，并量化了随机交叉验证的乐观程度（约 0.02 AUC）[page 7–8, Table 3]。这一量化结果为后续基准研究提供了可参照的偏差量级，但其普适性仍需在其他数据集上验证。
