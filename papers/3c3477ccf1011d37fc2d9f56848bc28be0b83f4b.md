# 加权ENO格式的高效实现：从精度分析到权重简化

**原文题名**：Efficient Implementation of Weighted ENO Schemes
**作者**：Guang-Shan Jiang, Chi-Wang Shu（Brown University）
**年份**：1995（据致谢与资助信息推断）

## 论文要解决的核心问题

Liu、Osher和Chan提出的WENO（加权本质无振荡）格式，用候选模板的凸组合代替ENO格式的"选最光滑模板"逻辑，从而消除了ENO中大量逻辑判断语句，在向量机上更快。但这套格式存在两个问题：一是其实际精度表现与截断误差分析不符，误差表中出现了"超收敛"现象；二是对Euler方程组，权重计算必须经过局部特征投影，浮点运算量很大。Jiang和Shu的工作正是针对这两点：重新分析精度、提出新的光滑度量、并给出绕过特征投影的权重计算方案。

## 精度分析：超收敛是假象

作者首先用通量版本的ENO格式重新表述WENO格式。核心构造是：将$r$个候选模板上的$r$阶ENO逼近$q_k^r$做凸组合（式2.10），权重$\omega_k$在光滑区趋近最优权重$C_k^r$（表2），使得组合结果逼近$(2r-1)$阶上游中心格式（式2.9、2.11）。关键条件是式(2.14)：$\omega_k = C_k^r + O(h^{r-1})$。

Liu等人的光滑度量$IS_k$（式2.18）在光滑区给出$IS_k = (f'h)^2(1+O(h))$（式2.21），因此$\omega_k = C_k^r + O(h)$（式2.22），代入式(2.12)后WENO格式在光滑单调区达到$(r+1)$阶精度 [page 8]。对$r=2$这是最优的（$2r-1=3$），但对$r=3$，$(r+1)=4$阶低于最优的5阶。

作者进一步指出，Liu等人误差表中看似高于理论阶的"超收敛"，实际是因为粗网格上误差偏大、细网格上误差偏小，以5阶中心格式误差为参照时造成的假象 [page 8]。当$r=3$时，式(2.20)的Taylor展开（式2.23–2.25）显示二阶项因模板而异，在$f'(u(x))$的临界点处式(2.22)失效，格式退化为3阶 [page 8]。这解释了为何ENO格式在$u_0(x)=\sin^4(\pi x)$这类含临界点的问题上会损失精度。

## 新光滑度量：让$r=3$达到最优阶

作者提出的新度量（式3.1）是对插值多项式各阶导数在区间$(x_{j-1/2}, x_{j+1/2})$上$L^2$范数的加权求和，权重$h^{2l-1}$用于消除导数中的$h$因子。这一构造模拟了"最小化逼近的总变差"的思想，但比基于$L^1$范数的总变差度量更光滑 [page 9]。

对$r=3$，新度量给出显式表达式（式3.2–3.4）。Taylor展开（式3.5–3.7）显示：当$f'\neq 0$时$IS_k = (f'h)^2(1+O(h^2))$（式3.8），满足式(2.14)对$r=3$的要求，从而得到5阶最优精度；当$f'=0$时$IS_k = \frac{13}{12}(f''h^2)^2(1+O(h^2))$（式3.9），在临界点处仍保持5阶 [page 10]。图1直观对比了两种度量在$f_j = \sin(2\pi x_j)$（含临界点$x=1/4, 3/4$和间断$x=1/2$）上的权重行为：新度量的权重在临界点附近明显更接近最优值，而在间断附近两者都给出接近零的权重 [page 10–11]。

精度验证见表3（$u_0=\sin(\pi x)$）和表4（$u_0=\sin^4(\pi x)$）。表3中WENO-RF-5从约40个网格点起达到预期阶，而WENO-RF-4在粗网格（N=10）上更准、细网格上被反超 [page 12]。表4中WENO-RF-5的阶数"稳定得晚得多"，作者明确指出这正是ENO格式损失精度的经典算例 [page 12]。

## 权重计算的简化：用压力和熵替代特征投影

对Euler方程组，标准做法是在每个特征场中计算权重（式4.2–4.4），这需要大量局部投影（向量-向量乘积），是WENO格式浮点运算的主要来源。作者的关键观察是：WENO格式唯一的非线性环节就是权重计算，其余部分（$q_k^r$）是线性的 [page 13]。

因此，如果能用不依赖特征投影的量来计算权重，就可以利用其余部分的线性性来减少运算。作者建议：在真正非线性特征场（$s=1,m$）用压力计算权重，在线性退化场（$1<s<m$）用熵计算权重 [page 14]。动机是：压力在接触间断处不跳变但在激波处跳变；熵在接触间断处跳变但在弱激波处仅轻微跳变。由于线性退化场的特征速度相同、权重都从熵计算，可以合并投影（式4.6），最终只需两次正投影和两次逆投影，加上计算$F_{j+1/2;s}$（$s=1,2,m$）的少量运算 [page 14]。

这一简化记为WENO-LF-5-PS。作者明确指出其适用范围：**不适用于含强激波或强反射波的问题** [page 14, page 38]。在1D Riemann问题（Sod和Lax，图4）中WENO-LF-5-PS表现良好，但在2D前台阶问题（图10–11）和双Mach反射问题（图12–13）中完全失效，原因是反射边界处法向速度跳变无法被压力或熵指示，导致权重分布不稳定，甚至密度变负 [page 35]。作者在Remark中详细解释了这一机制，并指出一个"即时修复"方案（用法向速度计算某个线性退化场的权重）只能治标 [page 35]。在反射边界非本质的激波-涡相互作用问题中（图15），WENO-LF-5-PS工作良好 [page 36–37]。

## 结论成立的条件与边界

论文的核心结论——新光滑度量使$r=3$的WENO格式达到5阶最优精度——成立条件是通量函数在光滑区有足够光滑性，且在临界点处$f'=0$时仍满足式(3.9)。在间断处，所有WENO格式都只退化为$r$阶（基础ENO格式的阶数）[page 38]。

权重简化方案（WENO-LF-5-PS）的适用边界被作者明确限定为"不含强激波或强反射波的问题"。2D前台阶和双Mach反射的失败表明，当反射边界起关键作用时，压力和熵无法指示法向速度跳变，方案失效。作者也承认，对一般方程组，"能替代投影量的合适物理量尚待发现" [page 14]。

人工压缩方法（第5节）能锐化接触间断，但使用Lax-Friedrichs构建块时CPU成本增加高达100% [page 38]。作者在结论中表示，将压缩思想直接融入权重定义以降低开销是未来工作 [page 38]。

一个值得注意的边界是：论文的精度分析和数值验证主要针对$r=2,3$，新度量对更大$r$是否仍给出最优阶，论文未做一般性证明，仅指出"至少对$r=2,3$"成立 [page 38]。
