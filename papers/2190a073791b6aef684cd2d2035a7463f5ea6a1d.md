# 集成紧凑型光学涡旋光束发射器：从角相位匹配到可测的轨道角动量

**原文题名**：Integrated Compact Optical Vortex Beam Emitters（2012，Science 338, 363；DOI: 10.1126/science.1226528）

这篇补充材料围绕一个核心主张展开：在绝缘体上硅（SOI）平台上，通过在微环谐振腔上刻写角向光栅，可以把腔内回音壁模式（WGM）的轨道角动量（OAM）以自由空间涡旋光束的形式辐射出来，并且辐射光束的拓扑荷 $l$ 由 WGM 方位角模数 $p$ 与光栅元数 $q$ 之差决定。支撑这一主张的，是一条从耦合模理论推导出的角相位匹配条件，加上干涉条纹、近场强度、发射效率与偏振模拟等多路证据。下面按论证本身的逻辑来梳理。

## 结论的骨架：$l = p - q$

作者要证明的最关键关系是辐射光束的方位角传播常数 $\nu_{rad} = p - q$ [page 4, page 7]。这里 $p$ 是 WGM 的方位角模数（即腔内绕行一周的光学周期数），$q$ 是角向光栅的元数，$\nu_{rad}$ 对应辐射光束携带的 OAM 量子数 $l$。这个关系不是拟合出来的，而是从微扰耦合模理论推出的相位匹配条件。

推导的路径是：把角向光栅视为对介电常数的周期性微扰 $\Delta\varepsilon(r,z,\theta)$，将扰动场展开为无扰动本征模的线性组合，代入波动方程并在缓变振幅近似下取模场内积，得到振幅演化方程 (s7)。由于扰动在 $\theta$ 方向周期，展开为傅里叶级数 (s10)，代入后积分只有在指数项为零时才不消失，于是得到相位匹配条件 $\nu_s - \nu_n + gq = 0$ (s13)。取 $s$ 为辐射模、$n$ 为 WGM，即 $\nu_{rad} = \nu_{WGM} - gq$ (s14)，其中 $g$ 是衍射级次 [page 6]。

关键的一步在于确定 $g$ 只能取 1。由相位匹配式 (s14) 和辐射模方位角分量的自由空间波矢约束 (s15)、WGM 有效折射率关系 (s16)，可得 $(n_{eff}-1)\Lambda/\lambda < g < (n_{eff}+1)\Lambda/\lambda$（式 s17）[page 7]。代入 $\lambda \approx 1550$ nm、$\Lambda \approx 650$ nm、$n_{eff} \approx 2.5$，范围约为 $0.63 < g < 1.47$，其中唯一的整数是 $g=1$。因此结合 $\nu_{WGM}=p$，得到 $\nu_{rad}=p-q$。这把一般的多衍射级相位匹配条件收束为本器件的一级衍射。

需要留意的是，这个结论依赖若干建模简化：忽略弯曲波导的辐射损耗（作者称在强限制 SOI 结构中很小）[page 5]；把光栅元等效为位于同一位置的偶极振子、相邻偶极相位差设为 $2\pi l/q$ 来做半解析模拟 [page 3]；以及 $g$ 的取值依赖 $n_{eff}$、$\Lambda$、$\lambda$ 的具体数值。这些是结论成立的条件，而非普适定理。

## 证据如何支撑结论

**干涉条纹直接读出 $l$。** 实验用马赫–曾德尔式干涉仪，把芯片辐射的涡旋光束与一束圆偏振高斯参考光（LHCP 或 RHCP）在分束器上合束，投到红外相机上 [page 2, Fig. S1]。当参考光关闭时，可拍到辐射光束的近场强度分布（Fig. S2B）；打开参考光后，干涉条纹显现相位结构（Fig. S2C、S2E），与正文中更大器件的 Fig. 3 结果类似 [page 3]。螺旋臂的数目与旋向随参考光偏振态改变：Movie S1 中 $l=-4$ 配 LHCP 参考光可见三条臂，Movie S2 中同一 $l=-4$ 配 RHCP 参考光可见五条臂 [page 15]。这种"臂数随参考光手性变化"正是涡旋光束与圆偏振参考光干涉的特征，为辐射光束确实携带 OAM 提供了直接证据。半解析偶极模型给出的模拟干涉图（Fig. S2D、S2F）与实测吻合良好 [page 3]，说明"相邻偶极相位差 $2\pi l/q$、绕行一周总相位 $2l\pi$"这一图像与实验一致。

**近场强度与偏振。** 近场强度呈同心环状（Fig. S2B、Fig. S7 左）[page 3, page 14]。3D-FDTD 模拟把总强度分解为两个正交线偏振分量后，显示任意点的偏振态是方位角方向（azimuthal），即辐射光束是方位角偏振的柱矢量光束 [page 7, Fig. S7]。这一偏振结论有独立的物理依据：在强限制硅波导中，传播（方位角）方向的电场分量 $E_{az}$ 在垂直于主横向电场 $E_T$ 的波导边界处最大，而光栅元恰好位于内壁，那里电场以方位角方向为主（Fig. S6）[page 7]。作者据此指出，把光栅放在波导顶部则会主要散射 $E_T$、产生径向偏振——也就是说，光栅位置可以用来"工程化"辐射光束的偏振态 [page 7, page 13]。这是对结论适用条件的一个明确说明：偏振态取决于光栅元的位置选择，而非固定不变。

**发射效率。** 效率测量用两端耦合、分别测输入输出功率的方式（Fig. S3），定义 $\eta$ 为辐射功率与波导中光功率之比，并做了全谱校准 [page 3]。结果：$q=36$ 器件 $\eta$ 最高约 10%，$q=72$ 器件最高约 13%；光纤到波导传输损耗（含耦合与片上损耗）测得 3 dB，因此光纤到发射效率约 5% [page 3]。作者特别强调，5%–13% 是"进入每一个 OAM 态"的效率，谱图中每个波长点的辐射功率已对输入功率归一化，可直接读出该 OAM 态的效率；例如 Fig. 3 中 $l=-3$ 处辐射功率约 $-9$ dBm，对应 $\eta = -9$ dBm $- 0$ dBm $= -9$ dB，即 12.6% [page 3–4]。这里有一个值得注意的限定：效率是"每个 OAM 态"的，不是所有态之和；谱图按输入功率归一化至 0 dBm 展示，而 $\eta$ 表示辐射功率与输入功率之比。

## 边界、假设与未决之处

作者明确承认或文本中可辨识的限制包括：$g=1$ 的结论依赖具体材料与几何参数，换一套 $\lambda$、$\Lambda$、$n_{eff}$ 可能不成立 [page 7]；偏振态由光栅位置决定，是可设计的而非唯一 [page 7]；效率数值是单态效率，且含 3 dB 传输损耗的扣除方式 [page 3]。此外，推导中忽略了弯曲辐射损耗、采用缓变振幅近似、把光栅元简化为偶极振子，这些都是模型层面的假设 [page 3, page 5]。

文本中还有一处需要谨慎对待：式 (s1) 及后续公式在抽取文本中存在符号与排版残缺（如 (s1) 中 $\varepsilon$ 与 $\Delta\varepsilon$ 的对应、式 (s7) 与 (s11) 中求和指标与系数的书写），部分数值和符号可能因 OCR 而可疑。不过，这些公式所承载的物理结论——相位匹配条件 (s13)/(s14) 与 $g$ 的取值限制 (s17)——在文字叙述中是自洽且反复出现的，因此核心结论 $l=p-q$ 的强度不因个别符号的抽取疑点而动摇；但若要把某条具体公式当作精确证据引用，应回到原文核对。
