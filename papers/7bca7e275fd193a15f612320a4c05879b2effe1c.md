# 晶格氧参与析氧反应：从同位素证据到非协同质子—电子转移机制

**原文题名**：Activating lattice oxygen redox reactions in metal oxides to catalyse oxygen evolution（2017，DOI: 10.1038/nchem.2695）

## 论文要解决的问题与核心主张

传统上，金属氧化物上析氧反应（oxygen evolution reaction, OER）的机制被描述为：在表面金属离子上发生四个协同的质子—电子转移步骤，产物氧气全部来自水。这一图景预测OER活性在可逆氢电极（RHE）标度上与pH无关，且反应仅发生在表面金属位点 [page 1]。

Grimaud、Diaz-Morales、Han等人提出一个根本不同的主张：在某些高共价性Co基钙钛矿氧化物上，晶格氧本身可以被氧化并参与O–O键形成，同时伴随非协同的质子—电子转移，从而使OER活性在RHE标度上表现出pH依赖性。作者进一步主张，金属—氧共价性的增强是触发晶格氧氧化、开启这些新反应路径的关键 [page 1, page 7]。

这一主张由两条相互独立的实验证据线支撑，再辅以DFT计算给出机制解释。

## 同位素标记给出的直接证据

作者用在线电化学质谱（OLEMS）结合¹⁸O标记，直接追踪了产物氧气的来源。实验设计是：先在H₂¹⁸O的0.1 M KOH中于1.6 V（vs. Au）下恒电位保持10分钟，将氧化物标记上¹⁸O；随后用¹⁶O水冲洗，再在H₂¹⁶O的0.1 M KOH中进行循环伏安并原位检测质谱信号。m/z = 32对应¹⁶O¹⁶O，m/z = 34对应¹⁶O¹⁸O，m/z = 36对应¹⁸O¹⁸O [page 2]。

结果呈现出清晰的分化（Fig. 2a, b）[page 3]：

- **LaCoO₃**：归一化的m/z = 34信号未超过¹⁸O天然丰度（约0.2%），m/z = 36也未检出。这意味着LaCoO₃的产物氧气中没有来自晶格氧的贡献。
- **La₀.₅Sr₀.₅CoO₃₋δ和Pr₀.₅Ba₀.₅CoO₃₋δ**：m/z = 34略高于天然丰度，m/z = 36在1.6 V vs. RHE及以上出现小信号，说明有晶格氧参与。
- **SrCoO₃₋δ**：两种信号都最显著，且起始电位更低（1.5 V vs. RHE及以上）。

检出¹⁶O¹⁸O（一个氧来自电解质、一个来自晶格）和¹⁸O¹⁸O（两个氧都来自晶格），要求晶格氧被氧化并形成氧空位 [page 2]。作者还用¹⁸O信号量估算了参与OER的氧化物厚度：LaCoO₃约0.5 nm（表面过程），La₀.₅Sr₀.₅CoO₃₋δ约0.7 nm，Pr₀.₅Ba₀.₅CoO₃₋δ约1.5 nm，SrCoO₃₋δ约14 nm（约37个单层）[page 2, page 3]。SrCoO₃₋δ的14 nm远超传统表面机制的约0.4 nm上限，这是论证的关键量级对比。

这里有一个重要的方法学限定：由于OLEMS检测的m/z = 32信号同时包含OER产生的氧气和环境空气中的氧气，作者明确表示无法定量m/z = 34和m/z = 36相对于m/z = 32的电流比例 [page 2]。因此，上述证据是**定性**的——它证明晶格氧参与了反应，但不能给出精确的参与比例。此外，作者报告在阴极扫描中、无OER活性的电位下仍检出m/z = 34，并坦承"其来源尚不清楚"，仅推测可能与OER触发的化学过程有关，需要进一步研究 [page 3]。

## pH依赖性：非协同质子—电子转移的动力学指纹

第二条证据线是pH依赖性。在RHE标度上，如果OER遵循四个协同质子—电子转移步骤，活性应当与pH无关。作者在pH 12.5至14范围内测量了四种氧化物的OER活性（Fig. 3）[page 4]。

结果与同位素证据高度对应：

- **LaCoO₃**（无晶格氧参与）：CV和恒电流测量的本征OER活性均与pH无关。
- **La₀.₅Sr₀.₅CoO₃₋δ、Pr₀.₅Ba₀.₅CoO₃₋δ、SrCoO₃₋δ**（有晶格氧参与）：pH从12.5升至14，本征OER活性增加约一个数量级。

作者指出，RHE标度上的pH依赖性表明反应中存在非协同的质子—电子转移步骤，其速率决定步骤要么是质子转移步骤，要么 preceded by 酸碱平衡 [page 4]。这一推理的逻辑是：协同转移意味着质子和电子同时转移，其热力学驱动力仅取决于相对于O₂/H₂O平衡的过电位（即RHE标度上的电位），与pH无关；一旦质子和电子转移解耦，质子转移步骤的速率就会依赖于pH（即依赖于OH⁻浓度或表面去质子化程度）。

一个值得注意的方法学细节：作者发现CV测量的比电流系统性地高于恒电流测量，并将此差异归因于氧空位填充（氧嵌入）对CV电流的贡献——CV测量在分钟尺度，氧嵌入不可忽略；恒电流测量在小时尺度，氧嵌入贡献可忽略。作者因此认为恒电流测量更准确地反映OER活性 [page 4]。这一自我修正增强了pH依赖性结论的可靠性。

## 从证据到机制：DFT计算如何桥接

实验证据确立了"晶格氧参与"和"pH依赖性"两个事实，但要从事实到达机制，需要说明：为什么某些氧化物能氧化晶格氧而另一些不能？晶格氧参与如何与pH依赖性联系起来？

作者用DFT计算（VASP，GGA-PW91，Co 3d的Hubbard U校正Ueff = 3.3 eV）构建了桥梁 [page 7]。核心论证如下：

**共价性决定晶格氧能否被氧化。** 从LaCoO₃到SrCoO₃，A位从三价La³⁺替换为二价Sr²⁺，费米能级向O 2p带中心移动，金属3d与O 2p带中心之间的能隙减小（Fig. 1a）[page 2]。当O 2p态位于O₂/H₂O氧化还原能级之上时，晶格氧的氧化在热力学上变得有利（Fig. 1b）[page 2]。费米能级处O 2p特征的增加意味着金属—氧键的共价性增强，反键态具有更多氧特征。

**共价性也决定表面氧位点能否形成O–O键。** DFT计算表明，对于SrCoO₃的(001)表面，从两个表面氧离子形成O–O键并留下氧空位在热力学上有利；而对于LaCoO₃，同样的步骤在能量上不利（Fig. 4f）[page 5, page 6]。这与LaCoO₃不显示晶格氧氧化的实验结果一致。

**机制方案。** 作者提出了两类新机制来解释实验观察（Fig. 4c, e, g, h）[page 5, page 6]：

- 形成³⁴O₂（¹⁶O¹⁸O）的机制（Fig. 4c）：前三个步骤是表面氧位点上的协同质子—电子转移，随后一个化学步骤产生¹⁶O¹⁸O和氧空位，最后一步协同质子—电子转移再生表面。
- 形成³⁶O₂（¹⁸O¹⁸O）的机制（Fig. 4e）：两个化学步骤从两个表面晶格氧离子形成O–O键并产生两个氧空位，其余步骤为协同质子—电子转移以再生表面。

为解释pH依赖性，作者进一步提出，在协同机制中作为速率决定步骤的表面羟基去质子化（O–Mⁿ⁺–OH + OH⁻ → O–M⁽ⁿ⁻¹⁾⁺–O + H₂O）变为非协同，与后续电子转移解耦（Fig. 4g, h）[page 6]。作者强调，解耦也可能发生在其他步骤，最终由表面去质子化的pKa决定哪一步控制pH依赖性动力学 [page 6]。

## 关键推理步骤与独立支持

从"晶格氧参与"和"pH依赖性"到"非协同质子—电子转移机制"的推理，其关键桥接是：pH依赖性要求至少一个质子转移步骤与电子转移解耦，而晶格氧氧化提供的O–O键形成路径恰好可以容纳这种解耦——因为O–O键形成是一个化学步骤（不涉及电子转移），它可以插入到质子转移和电子转移之间，使两者不再严格耦合。

作者还提供了一个独立的动力学支持：褐针镍矿SrCoO₃₋δ在O₂饱和与Ar饱和的1 M KOH中的恒电流氧化行为不同（Fig. 5）[page 6]。在O₂饱和电解液中观察到氧嵌入平台，而在Ar饱和中无清晰平台。作者将此归因于：O₂饱和时表面氧空位优先被O*填充而非OH*填充（DFT计算：Co终止(001)面上O*填充为−0.82 eV per O*，OH*填充为−0.40 eV per OH*），从而绕过慢的去质子化步骤，使氧嵌入动力学更快 [page 6]。这一观察支持"表面去质子化是慢步骤"的推断，但它本身是关于氧嵌入（非OER）的实验，作者将其作为间接支持而非直接证明。

## 结论成立的条件与边界

这篇论文的结论有明确的适用范围，作者在文本中也做了交代：

**材料范围。** 结论建立在四种Co基钙钛矿上（LaCoO₃、La₀.₅Sr₀.₅CoO₃₋δ、Pr₀.₅Ba₀.₅CoO₃₋δ、SrCoO₃₋δ），且这些氧化物在OER过程中体相稳定。作者明确区分了"体相稳定"与"热力学稳定"：前者指OER后无明显非晶化和金属离子流失（如Ba₀.₅Sr₀.₅Co₀.₈Fe₀.₂O₃₋δ在OER中体相非晶化，OLEMS行为截然不同），后者指氧化物在水溶液中形式上不稳定 [page 2]。这一区分意味着结论不能直接推广到在OER中非晶化的催化剂。

**机制方案是"可能的"而非"确定的"。** 作者反复使用"possible""likely""may exist"等措辞描述Fig. 4中的机制方案，并明确指出"其他可能性可能存在"（如Supplementary Fig. 12）[page 5, page 6]。DFT计算给出的是热力学自由能剖面，不包含动力学势垒；速率决定步骤的指认基于热力学下坡步骤的电位比较，而非直接动力学测量。

**pH依赖性的定量关系未被建立。** 作者展示了pH从12.5到14活性增加约一个数量级，但未给出pH依赖性的斜率（如∂log(i)/∂pH）或与特定质子转移步骤的定量关联。作者也承认，解耦可能发生在不同步骤，最终由pKa决定 [page 6]。

**¹⁸O标记的定量解释受限。** 如前所述，m/z = 32信号包含大气贡献，无法定量晶格氧参与的比例 [page 2]。厚度估算基于¹⁸O信号量和Supplementary Table 3，但作者未在正文中给出估算的不确定度范围。

**与电沉积氧化物薄膜的关系。** 作者将本文机制与Co–Pi和(Ni,Fe)OOH薄膜的已有研究相联系，指出后者也涉及氧交换和pH依赖性，但强调"需要进一步研究"来理解非协同质子—电子转移在这些体系中的作用，以及表面参与O–O键形成的氧的性质（末端氧 vs. 桥接氧）[page 7]。这意味着本文机制与电沉积薄膜机制之间的统一性尚待建立。
