# 冷玻色原子在光学晶格中如何实现 Bose-Hubbard 模型并驱动超流–Mott 绝缘体转变

**原文题名**：Cold Bosonic Atoms in Optical Lattices（D. Jaksch, C. Bruder, J. I. Cirac, C. W. Gardiner, P. Zoller），1998，DOI: 10.1103/PhysRevLett.81.3108。登记信息与正文一致。

## 论文要建立的核心对应

这篇 Letter 的主张可以概括为一句话：把超冷稀薄玻色气体装入远失谐光学晶格，其低能动力学由一个 Bose-Hubbard 模型（BHM）描述，而该模型的所有参数——隧穿矩阵元 $J$、在位相互作用 $U$、格点能量偏移 $\epsilon_i$——都能通过激光强度与几何构型连续调节。由此，凝聚态物理中预言已久的超流（SF）到 Mott 绝缘体（MI）量子相变，可以在光学晶格中通过改变势阱深度 $V_0$ 来实现 [page 1]。

论证的起点是式 (1) 的二次量子化哈密顿量：动能项、光学晶格势 $V_0(\mathbf{x})$、外加缓变囚禁势 $V_T(\mathbf{x})$，以及用 $s$-波散射长度 $a_s$ 近似的短程赝势相互作用 [page 1]。作者随后做了一步关键的模型约化：在系统动力学能量远小于到第二能带的激发能这一假设下，把场算符按 Wannier 基展开并只保留最低振动态，$\psi(\mathbf{x}) \simeq \sum_i b_i w(\mathbf{x}-\mathbf{x}_i)$，于是式 (1) 化为式 (2) 的 Bose-Hubbard 哈密顿量

$$H = -J\sum_{\langle i,j\rangle} b_i^\dagger b_j + \sum_i \epsilon_i \hat{n}_i + \tfrac{1}{2}U\sum_i \hat{n}_i(\hat{n}_i-1),$$

其中 $U = 4\pi a_s \hbar^2 \int d^3x\,|w(\mathbf{x})|^4/m$ 是在位排斥，$J = \int d^3x\, w^*(\mathbf{x}-\mathbf{x}_i)[-\tfrac{\hbar^2}{2m}\nabla^2 + V_0(\mathbf{x})]w(\mathbf{x}-\mathbf{x}_j)$ 是相邻格点间的跃迁，$\epsilon_i \simeq V_T(\mathbf{x}_i)$ 是囚禁势造成的格点能移 [page 2]。这一步是整篇论证的枢纽：它把"激光如何控制量子相"的问题，转化为"激光如何控制 $U/J$ 与 $\epsilon_i$"的问题。

## 为什么改变激光强度就能扫过相变

BHM 的相图在均匀情形下由 $J$–$\mu$ 平面上的瓣状结构给出：瓣内（$J$ 相对 $U$ 较小）是 Mott 相，瓣外是超流相 [page 3]。因此，只要能在实验中连续改变 $U/J$，就能跨越相变。作者用图 1b 说明这一点：随着光学势深度 $V_0$ 增大，原子波函数越来越局域，在位相互作用 $U$ 上升，同时隧穿矩阵元 $J$ 下降，两者之比 $U/J$ 单调增大 [page 1, page 2]。这正是从超流向 Mott 相过渡所需的控制旋钮。

定量上，作者引用均匀情形的平均场结果：$n=1$ 的 MI-SF 相变临界值约为 $U/zJ \approx 5.8$，其中 $z=2d$ 是最近邻数 [page 2]。结合图 1b 的数值曲线，这一参数区间可通过把 $V_0$ 调到几十个反冲能量 $E_R = \hbar^2 k^2/2m$ 来实现。作者给出两个具体例子：对钠原子、红失谐 $\lambda = 985$ nm，$E_R/h = 2\pi \times 8.9$ kHz，一维、二维、三维首个 MI 相的临界值分别为 $V_{x0} = 10.8$、$V_{x,y0} = 14.4$、$V_{x,y,z0} = 16.5\,E_R$；对蓝失谐 $\lambda = 514$ nm，$E_R/h = 2\pi \times 32$ kHz，对应值为 $8.4$、$11.9$、$14.1$ [page 2]。这些数字把抽象的相变判据落到了可操作的激光参数上，是"可实现性"论证的核心证据。

## 从均匀相图到真实陷阱：局域化学势与嵌套 Mott 结构

真实实验必然带有缓变囚禁势 $V_T$，系统不再均匀。作者的处理方式是把 $\epsilon_i = V_T(\mathbf{x}_i)$ 吸收进局域化学势 $\mu - \epsilon_i$，从而用均匀相图逐点判断局域相 [page 3]。这一"局域密度近似"式的推理，直接解释了图 2a 的结果：在二维光学晶格加各向同性谐振阱、$U = 35J$、$V_T = J(x^2+y^2)/a^2$、$\mu = 50J$ 的参数下，阱中心出现每格点两个原子的 Mott 相（$\rho = 2$），外围是单原子 Mott 相（$\rho = 1$），两者之间夹着超流环 [page 3]。也就是说，空间上嵌套的 Mott 结构不是额外假设，而是均匀相图加上缓变势的自然推论。

作者进一步展示，用不同角度的干涉激光束可以构造超晶格，使光学势的偏移在大于晶格周期的尺度上周期性调制 [page 3]。图 2b、2c 给出超晶格中 Mott 结构的密度 $\rho(x,y)$ 与标度化密度涨落 $\sigma(x,y)$：随着化学势 $\mu$ 从 $25J$ 增到 $35J$，先在超晶格势底部形成 Mott 结构，随后原子不再局限于单个超晶格阱，而是形成连接各阱的"桥" [page 3]。这部分的论证意义在于：Mott 结构不限于均匀或简单谐振阱，通过设计激光构型可以"定制"特定的 Mott 图案。

## 平均场之外：一维小系统的精确对角化

作者清楚平均场（Gutzwiller 试探波函数 $|\Psi_{\text{MF}}\rangle = \prod_i |\phi_i\rangle$，通过最小化式 (3) 确定系数 $f_n^{(i)}$）在一维和少原子情形下可靠性存疑 [page 2, page 3]。为检验这一点，他们对一维 BHM 做了精确对角化。图 3 给出 $N = 5$ 个原子、七个晶格胞、谐振阱 $V_T = 0.06\,E_R(x/a)^2$ 下密度 $\rho$ 与涨落 $\sigma$ 随 $V_{x0}/E_R$ 的变化：随着 $V_{x0}$ 增大，密度清晰过渡到 $\rho = 1$ 的 MI 相，涨落被压制但保持有限；按均匀平均场预期应在 $V_0 = 7.4\,E_R$ 处发生的相变被"抹平"，只有在更大的 $V_{x0}$ 下涨落才被强烈抑制 [page 3]。

这里有一个值得注意的推理细节：作者说"相变被抹平"，但并未因此否定平均场，而是指出"对于非均匀情形，平均场与精确计算定性上吻合良好，即使对这样小的系统" [page 3]。这是一个有限尺寸效应的诚实交代——小系统的"相变"本质上是渐变的，而非热力学极限下的尖锐转变。作者还把图 3 解读为"随激光强度缓慢变化时的绝热转移进入 MI 相"，这为实验上如何制备 Mott 态提供了操作图像 [page 3]。

## 双组分扩展：独立调节 $J$ 与 $U$

单一光学势深度 $V_0$ 只能提供一个控制参数，$J$ 和 $U$ 被绑在一起变化。作者提出用两个内态 $|g_1\rangle$、$|g_2\rangle$ 并通过非共振拉曼跃迁耦合，且假设两态感受到的光学势相对位移 $\lambda/4$（当极化率符号相反时成立），从而得到式 (4) 的双组分 BHM [page 3, page 4]。此时拉曼诱导的跃迁 $J = \tfrac{1}{2}\int d^3x\, w_a^*(\mathbf{x})V_{\text{eff}}(\mathbf{x})w_b(\mathbf{x}-\lambda/4)$ 可以独立于 $U_{aa}$、$U_{bb}$、$U_{ab}$ 调节，拉曼失谐 $\delta$ 则移动 $b$ 组分的化学势 [page 4]。图 4b 展示了一个具体结果：在 $U_{aa} = U_{bb} = 45J$、$U_{ab} = 0$、$\delta = 225J$、$\mu = 25J$ 的二维均匀情形下，$|g_1\rangle$ 的 MI 相与 $|g_2\rangle$ 的超流分量共存，形成棋盘图案 [page 4]。这一扩展的论证价值在于：它说明光学晶格不只是"实现"已知 BHM，还能构造出参数可独立调控、甚至单组分系统难以实现的模型变体。

## 结论成立的条件与作者承认的边界

整篇论证依赖若干明确的假设，作者在文中逐一交代：

其一，赝势近似与单带近似要求 $a_s \ll a_0 \ll \lambda/2$，且在位相互作用能 $\Delta E_i = \tfrac{1}{2}Un_i(n_i-1) \ll \hbar\nu_j$（到第一激发带的能量间隔）[page 2]。作者称这些不等式"在实践中容易满足"。

其二，次近邻跃迁与最近邻排斥"通常小两个数量级，可以忽略" [page 2]——这是把式 (1) 截断为式 (2) 的定量依据。

其三，碰撞损失与退相干是需要正视的负面因素。作者指出，$n=1$ 的 Mott 相中双粒子和多粒子损失通道不存在；$n=2$ 时存在双粒子损失，按文献 [18] 的量级估计寿命 $\gtrsim 10$ s；$n=3$ 时三原子损失使寿命约为 $1/10$ s [page 2]。这些估计把"Mott 相可观测"的结论限定在特定填充数和时间尺度内。

其四，平均场在低维、少原子情形下不可靠，作者用精确对角化处理一维，并明确说"在 1D 和每个超晶格阱中原子数很少时，我们预期涨落很重要，MFT 的应用成问题" [page 3]。

其五，作者在结尾提到，加入非公度光学势可实现（赝）随机势，导向无序玻色系统和 Bose glass 相的研究；与有限温度粒子库耦合导致的 MI 相生长与涨落将另文发表 [page 4]。这些是作者主动划出的、本文未处理的边界。

## 论证的整体力度

这篇 Letter 的推理链条是：从第一性原理哈密顿量出发，经 Wannier 展开严格约化到 BHM；用数值计算的 $U(V_0)$、$J(V_0)$ 曲线证明 $U/J$ 可通过激光强度扫描；引用已知 BHM 相图定位临界点；用平均场处理非均匀陷阱和超晶格，用精确对角化检验一维小系统；最后用双组分方案展示参数独立调控的可能性。每一步都有具体的公式、数值或图件支撑，且作者对近似条件和损失机制做了明确交代。

需要指出的是，本文是理论方案论文，所有相图与结构均来自数值计算，没有实验数据。因此"可在实验中实现"这一层结论，依赖的是参数估计（如 $V_0$ 几十个 $E_R$、寿命 $\gtrsim 10$ s）与当时已有实验技术（远失谐晶格、BEC 装载）的可行性判断，而非直接观测。作者的语气也相应谨慎：用"can be described""will show""is accessible""we expect"等表述，而非断言已实现。这一分寸与论文作为方案提出者的定位相符。
