# 用路径级权重学习图上的关系检索
*Relational Retrieval Using a Combination of Path-Constrained Random Walks · Lao & Cohen · 2010 · Machine Learning 81, 53–67*

科学文献可以表示为带类型节点和带标签有向边的图：论文连着作者、期刊、关键词、基因或蛋白质，引用关系又把论文彼此连接。给定一组查询节点和目标类型，系统需要把可能答案按相关性排序。普通带重启随机游走（RWR）为每种边标签学习一个权重，但同一种关系在不同上下文里可能意义不同：例如“同年发表的论文”未必就是合适参考文献，而“同年论文所引用的论文”可能更相关。单一边权无法表达这种路径上下文。

作者提出路径排序算法（PRA）：从查询实体出发，沿一条类型正确的关系序列作受约束随机游走，得到各目标实体的到达分布；每条不同关系路径就是一个特征，模型学习这些路径分布的线性权重，再将分数相加排序。于是系统不再只问“引用边重要吗”，还可以区分“由查询词找到的论文再沿引用边到达候选论文”等组合关系。权重使用带 L2 正则化的逻辑回归目标和 L-BFGS 学习；面对大量负例时，作者依据未训练 PRA 的初始排名抽取分层负样本，降低训练开销。

路径级特征带来表达力，也带来组合爆炸。允许的路径长度越长，候选路径数和查询时间大致呈指数增长；论文因此根据开发集结果将 venue 推荐的最大路径长度设为 4，其他任务设为 3。为提升模型，作者加入两类专家：查询无关路径专家以预计算方式编码类似 PageRank 的实体普遍重要性；流行实体专家则对特定目标实体或查询—目标实体组合加入偏置。它们能补充路径上下文信息，但特别是流行实体偏置需要更多训练查询，训练样本不足时更容易过拟合。

实验在两个生物学文献图（Yeast 与 Fly）上评估四种任务：期刊推荐、参考文献推荐、专家发现和基因推荐，共八个任务。每项任务分别留出 2,000 条开发查询和 2,000 条测试查询，以 MAP 衡量排序质量。为避免时间泄漏，每条边带有年份，某篇论文生成查询时，随机游走只能使用该论文发表年份之前的边。基础 PRA 在多数任务上优于训练版 RWR；加入查询无关或流行实体专家后，MAP 通常继续提高；两类扩展合用的模型在八项任务中都取得高于训练版 RWR 的分数，最高报告相对提升为 Yeast 参考文献推荐的 23.8%。不过，表格的配对检验存在未达显著性的例外，不能把所有小幅提升都说成统计显著。

因此，本文的关键贡献是把“哪些关系有用”提升为“哪些关系路径有用”，让模型能从任务数据中学习上下文相关的检索线索；查询无关和实体偏置则补充全局或特定实体的先验。实验支持这一表示在所选生物文献图和四种任务上的有效性，但不等于任意知识图谱都能获得同等收益。图谱覆盖、类型体系、时间戳质量、可用训练查询及路径长度上限都会影响可学到的特征；更长路径虽然可能提高 MAP，也会迅速增加模型规模和查询成本。

## 证据范围

结论来自 Yeast、Fly 两个生物学文献图及 venue、reference、expert、gene 四类任务。每项有 2,000 条开发查询与 2,000 条测试查询，使用 MAP 和配对 t 检验；显著性存在表中标注的例外。构图时通过时间戳屏蔽查询日期之后的边。最大路径长度按任务在开发集上选定，模型复杂度和执行时间对该长度敏感。论文也将多源关系的 AND/超关系建模留作未来方向。
