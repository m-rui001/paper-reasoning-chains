# 控制错误发现率：多重检验的一种实用而有力的方法

**原文题名**：Controlling the False Discovery Rate: A Practical and Powerful Approach to Multiple Testing
**年份**：1995
**DOI**：https://doi.org/10.1111/j.2517-6161.1995.tb02031.x

## 问题的起点：为什么经典多重比较不够用

Benjamini 与 Hochberg 这篇论文要解决的，是多重假设检验中长期存在的一个张力。当研究者同时检验很多个假设时，如果对每个假设都用单次检验的显著性水平，那么至少犯一次假阳性错误的概率会随检验数量迅速膨胀。经典做法是控制**族错误率**（familywise error rate, FWER），即"至少犯一次第一类错误"的概率 P(V ≥ 1)，并且通常要求在强意义下控制——对所有真/假假设的配置都成立 [page 1]。

作者并不否认 FWER 控制在某些场景下的必要性，但他们指出它有三个实际困难 [page 2]：其一，大量 FWER 方法针对的是多元正态（或 t）检验统计量的多处理比较，而实际研究中的检验族往往混合了不同类型的统计量；其二，在常规显著性水平下，强控制 FWER 的方法功效明显低于逐次比较方法；其三，也是最关键的一点——**很多时候根本不需要控制 FWER**。作者举的例子是"多终点问题"：一个治疗组与对照组在多个终点上比较，即便其中某些零假设被错误拒绝，关于"治疗更优"这个总体结论未必就错了。只有当"任何一个错误都会毁掉整体结论"时，FWER 控制才是必需的 [page 2]。

正是这第三点，引出了论文的核心主张。

## 核心主张：把错误率定义在"被拒绝的假设"之中

作者提出，与其控制"是否犯了任何错误"，不如控制**在被拒绝的假设中，错误所占的期望比例**。他们把这个量称为**错误发现率**（false discovery rate, FDR）。

形式化地，用表 1 的记号 [page 3]：m 个假设中 m₀ 个为真，R 是被拒绝的假设数，V 是被错误拒绝的真零假设数。定义随机变量

$$Q = \frac{V}{V+S} = \frac{V}{R},$$

并约定当 R = 0 时 Q = 0（因为此时不可能犯错误拒绝）。FDR 就是 Q 的期望：

$$Q_e = E(Q) = E\{V/(V+S)\} = E(V/R).$$

这个定义带来两个直接而重要的性质 [page 3]：

**(a) 当所有零假设都为真时，FDR 等价于 FWER。** 此时 s = 0、v = r，若 v = 0 则 Q = 0，若 v > 0 则 Q = 1，于是 P(V ≥ 1) = E(Q)。所以控制 FDR 蕴含对 FWER 的**弱控制**。

**(b) 当 m₀ < m 时，FDR 不超过 FWER。** 因为 v > 0 时 v/r ≤ 1，故 P(V ≥ 1) ≤ Q_e。这意味着任何控制 FWER 的程序也自动控制 FDR；反过来，只控制 FDR 的程序可以更宽松，从而**有望获得功效增益**。而且非真零假设越多，S 越大，两种错误率差距越大，功效提升的潜力也越大。

这里的关键推理是：FDR 把"错误的严重性"与"拒绝的数量"挂钩——拒绝得越多，单个错误被稀释得越厉害。这正是作者所说的、整合了 Spjøtvoll 对错误数量的关注与 Soric 对"给定拒绝条件下错误概率"的关注 [page 2]。

作者还讨论了为什么选择 FDR 而非其他替代形式 [page 4–5]。逐次控制随机变量 Q 本身是不可能的（当 m₀ = m 且拒绝了一个假设时，v/r = 1，无法控制）；控制 E(V/R | R > 0) 同样不可行；Soric 的 Q' = E(V)/r 既不是随机变量也不是其期望，混合了期望与实现值；E(V)/E(R) 在所有假设为真时恒等于 1，也无法控制。FDR 之所以可行，是因为它等于 P(R > 0)·E(V/R | R > 0)，这个乘积是可以被控制的。

## 关键一步：一个简单的逐步程序及其证明

论文的核心技术贡献是程序 (1) [page 5]。设 p₍₁₎ ≤ p₍₂₎ ≤ … ≤ p₍ₘ₎ 为排序后的 p 值，H₍ᵢ₎ 为对应假设。令

$$k = \max\left\{i : p_{(i)} \le \frac{i}{m}q^*\right\},$$

然后拒绝所有 H₍ᵢ₎，i = 1, …, k。

**定理 1** 断言：对独立检验统计量，在任意假零假设配置下，该程序将 FDR 控制在 q* 水平 [page 5]。

证明依赖一个引理（附录 A，page 11–12）：对任意 0 ≤ m₀ ≤ m 个真零假设对应的独立 p 值，以及假零假设 p 值可能取的任意值，程序满足

$$E(Q \mid P_{m_0+1} = p_1, \ldots, P_m = p_{m_1}) \le \frac{m_0}{m}q^*. \tag{2}$$

对假零假设的联合分布积分即得 E(Q) ≤ (m₀/m)q* ≤ q*。

引理的证明用对 m 的归纳法 [page 11–12]。其结构值得点出，因为它是整个论证的枢纽：把条件期望按最大真零假设 p 值 p₍ₘ₀₎ = p 分段积分。在 p ≤ p* 的部分（p* 由式 (4) 定义），所有 m₀ + j₀ 个假设都被拒绝，Q 恰为 m₀/(m₀ + j₀)，直接得到式 (6) 的界。在 p > p* 的部分，作者论证：由于 j₀ 和 p* 的定义方式，没有任何假设能因 p、p_{j+1}, …, p_{m₁} 的取值而被拒绝；于是问题归结为对 m' = m₀ + j − 1 ≤ m 个假设、以 {(m₀+j−1)/((m+1)p)}q* 为常数的同类程序，套用归纳假设得到式 (8)，再对 p 积分得到式 (9)。两段相加完成证明。

一个值得注意的细节是作者在定理后的**注记** [page 5]：证明中**不需要**假零假设对应统计量之间的独立性。独立性只对真零假设的 p 值有要求。这放宽了程序的适用条件。

作者还指出程序与既有方法的关系 [page 5–6]。Simes (1986) 曾把这个程序作为探索性扩展提出，但 Hommel (1988) 证明它对个体假设的推断**不**强控制 FWER。Hochberg (1988) 用另一套常数 {1/(m+1−i)}a 实现了强 FWER 控制。两者都是逐步下降程序，两端相似（最大 p 值与 a 比较，最小 p 值与 a/m 比较），但中间的比较常数不同：FDR 程序的线性递减常数 {1 − (i−1)/m}a 始终大于 Hochberg 的双曲递减常数，极端比值在 i = (m+1)/2 处可达 4m/(m+1)²。因此 FDR 程序至少拒绝与 Hochberg 方法一样多的假设，功效也高于 Holm (1979) 等其他 FWER 方法。

## 程序的另一种解读：事后约束最大化

**定理 2** [page 7] 给出程序的一个等价刻画：它是如下约束最大化问题的解——

选择水平 a，使该水平下的拒绝数 r(a) 最大，约束为 am/r(a) ≤ q*。

证明的思路是：对每个 a，若 p₍ᵢ₎ ≤ a < p₍ᵢ₊₁₎ 则 r(a) = i；在 r(a) 恒定的区间上，约束左端随 a 递增，故只需考察 a 等于某个 p₍ᵢ₎ 的情形。取 a = p₍ₖ₎ 时约束变为 p₍ₖ₎/k ≤ q*/m，正是程序 (1) 的条件；从最大的候选 a 开始考察，就得到满足约束的最大 r(a)。

这个解读把程序描述为"在实验后同时最大化拒绝数并尝试控制 FDR"：由于逐次检验时 E(V) ≤ am，观测到结果后可用 am/r(a) 作为 FDR 的上界估计，再据此选 a。作者认为这一"事后最大化"特性正是第 2.2 节那些应用场景所希望的 [page 7]。

## 功效证据：模拟研究

第 4 节用大规模模拟比较了 FDR 程序与两种 FWER 方法（Bonferroni 和 Hochberg）的功效 [page 8–10]。设定是：m 个独立正态变量期望是否为零，用 z 检验，q* = a = 0.05；m 取 4、8、16、32、64，真零假设数为 3m/4、m/2、m/4 和 0；非零期望分四组置于 L/4、L/2、3L/4、L，按递减 (D)、等量 (E)、递增 (I) 三种方式分配；L 取 5 和 10；每次模拟 20000 次重复，功效标准误约 0.0008–0.0016 [page 8]。

图 1 [page 9] 显示的结果可归纳为几点 [page 8–10]：所有方法功效随 m 增大而下降（多重性控制的代价）；FDR 方法功效**一致地**高于其他方法；优势随非零假设数增加而增大；优势随 m 增大而增大，因此在 E 和 I 配置下 FDR 方法因 m 增大而损失的功效相对较小。作者给出具体数字：检验 32 个假设、四簇等量分布、全部非真时，Bonferroni 功效 0.42，FDR 程序提升到 0.65；检验 4 个假设、一半为真时，分别为 0.62 和 0.70 [page 10]。作者特别强调，FDR 相对 FWER 带来的功效增益，**远大于** Hochberg 方法相对 Bonferroni 的增益 [page 10]。

作者还用图 1 的数据回答了审稿人关于 E(V/m₀) 如何被控制的问题 [page 10]。当 m₀ = 0 时该量为 0；否则可近似为个体检验的平均水平 a_ave。由 m·a_ave ≤ R_ave·q* = (m₀a_ave + m·l_ave)q* 推出

$$a_{ave} \le l_{ave}q^*\frac{m_1}{m_1 + m_0(1-q^*)}.$$

因此 E(V/m₀) 比图 1 所示更小，至少小一个 q* 因子。当 m = m₀ 时，该错误率接近 q*/m₀ 而非 q*：对 4、8、16、32、64 个假设分别为 0.0132、0.0063、0.0033、0.0017、0.0009 [page 10]。

## 一个具体例子：rt-PA 与 APSAC 试验

第 3.2 节用 Neuhaus 等 (1992) 的心肌梗死临床试验说明程序的实际使用 [page 6–7]。该研究有四个假设族，其中第四族（心脏及其他事件，15 个假设）适合 FDR 控制——因为研究者不希望在前负荷治疗仅仅"全面等效"时就宣称它更好。原文未处理多重性问题，直接报告个体 p 值。15 个比较的排序 p 值为：

0.0001, 0.0004, 0.0019, 0.0095, 0.0201, 0.0278, 0.0298, 0.0344, 0.0459, 0.3240, 0.4262, 0.5719, 0.6528, 0.7590, 1.000。

在 0.05 水平下，Bonferroni（0.05/15 = 0.0033）和 Hochberg 都只拒绝最小的三个假设，**不包括**死亡率比较（p = 0.0095）。而 FDR 程序从 p₍₁₅₎ 开始比较，第一个满足 p₍ᵢ₎ ≤ 0.05i/15 的是 p₍₄₎ = 0.0095 ≤ 0.05×4/15 = 0.013，于是拒绝四个假设，**把死亡率下降的结论纳入进来** [page 7]。这个例子直观展示了 FDR 控制在"愿意接受少量错误以换取更多发现"时的实际差别。

## 结论成立的条件与边界

把论文的论证边界交代清楚，对理解其主张的适用范围很重要。

**程序控制 FDR 的条件**：定理 1 要求真零假设对应的 p 值相互独立（假零假设的独立性不需要）[page 5]。这是证明的明确前提，超出此条件时定理不保证成立。论文没有讨论统计量相关时程序的表现，因此不能把结论外推到相关情形。

**FDR 与 FWER 的关系是单向的**：控制 FDR 只蕴含 FWER 的**弱**控制（所有零假设为真时），不蕴含强控制 [page 3]。作者在结论中也明确说新方法"由此也控制弱意义下的 FWER" [page 10]。因此，在需要强 FWER 控制的场景（如从多个处理中选一个最优），FDR 程序并不适用——这正是作者在第 1 节区分两类问题时的立场。

**功效比较的设定**：模拟中 FDR 方法与 FWER 方法被设定为在总体零假设下以相同水平弱控制 FWER（取 q* = a）[page 8]。功效优势是在这个可比框架下测得的，且依赖于具体的配置（m、真零假设比例、信号分布形态、信噪比）。作者报告的优势随非零假设数和 m 增大而增大，但这是模拟设定下的规律，不是普适定理。

**作者承认的局限与未来方向**：论文明确说本文只聚焦于提出和论证 FDR 方法、展示其可发展为简单而有力的程序，其他程序（如利用方差分析成对比较等特定问题结构的程序）留待后续；作者还提到已着手发展结合 Hochberg 与 Benjamini (1990) 思想的自适应方法 [page 10]。论文没有给出相关检验统计量下的理论保证，也没有讨论 q* 如何在实际中选取。

**一处需要留意的文本问题**：提取文本中第 3.1 节程序 (1) 的公式排版为 "P U) ~ .i q*; / m"，结合上下文（定理 2 的证明中写作 p₍ₖ₎/k ≤ q*/m，以及第 3.2 节实例中比较 0.05i/15）可判断原式应为 p₍ᵢ₎ ≤ (i/m)q*。这是 OCR 排版造成的符号错乱，不影响论证理解，但引用公式时应以逻辑一致的 (i/m)q* 为准。

## 总体来看

这篇论文的论证链条是清晰的：先论证 FWER 控制在许多场景下过于严格（第 1 节），再提出 FDR 作为更贴切的错误率并证明其与 FWER 的关系（第 2 节），然后给出一个简单的逐步程序并证明其控制 FDR（第 3 节，定理 1），用约束最大化给出直观解读（定理 2），最后用模拟（第 4 节）和实例（第 3.2 节）展示功效增益。关键推理的转折点在于：把错误率从"是否犯错"改为"犯错的比例"，使得错误率随拒绝数增加而被稀释，从而在保持合理错误控制的同时释放功效。这一转折的代价是放弃了强 FWER 控制，因此其适用性严格依赖于"少量错误不破坏整体结论"这一实质判断——这正是作者反复强调、也是使用者必须自行评估的前提。
