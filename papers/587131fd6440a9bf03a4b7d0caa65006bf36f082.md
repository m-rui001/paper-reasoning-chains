# 移动机器人导航路径规划策略综述：从经典方法到反应式智能的论证分析

**原文题名**：A review: On path planning strategies for navigation of mobile robot（2019，DOI: 10.1016/j.dt.2019.04.011）

## 一篇综述要证明什么

这不是一篇提出新算法的研究论文，而是一篇试图用文献计量式证据支撑一个判断的综述：在移动机器人路径规划领域，反应式（reactive）方法已经全面取代经典（classical）方法，成为主流且更优的选择。作者的核心结论在摘要中就已给出——反应式方法"更鲁棒、在所有地形表现更好"，并且被用来改进经典方法形成混合算法，因此"更受欢迎、被广泛使用" [page 2]。

这个结论看似直白，但它需要三类证据支撑：一是对各类方法原理与代表工作的梳理，说明反应式方法为何在机制上更适合不确定环境；二是对文献的统计分类（表1、表2及图24–29），用发表频次和覆盖维度证明反应式方法确实占据主导；三是对比两类方法在静态/动态、单/多机器人、仿真/实时、2D/3D等条件下的表现差异。论证的关键一步，是把"反应式方法处理不确定性能力更强"这一机制性判断，与"文献中反应式方法占比从0%升到95%"这一计量性观察对接起来，让机制解释与趋势数据互相印证。

## 经典方法：机制清晰但边界明确

作者把经典方法限定为三类：单元分解（CD）、路线图法（RA）和人工势场法（APF）。它们的共同前提是**需要环境的先验信息**，因此被归为全局导航，适用于"完全已知的环境" [page 3]。

CD 把区域划分为不重叠网格，用连通图在"纯单元"（无障碍）间寻路，含障碍的"损坏单元"再细分 [page 5]。作者进一步区分精确、近似和自适应三种分解：精确分解的单元形状由障碍几何决定（图3）；近似分解用规则网格，实现简单但边界不与障碍对齐（图4）；自适应分解（如四叉树）在单元被部分占据时一分为四，直到为空（图5）[page 6]。这里作者点出一个关键局限：自适应分解"无法在获得新数据（障碍新位置）时更新程序，因此在动态环境中失效" [page 6]。

RA 用一维曲线网络表示自由空间连通性，具体实现为可见图（图6）和 Voronoi 图（图7）[page 7]。作者承认这类方法能求最短路径，但指出混合可见图、Voronoi 与势场法的尝试"未能获得最优路径且执行过程复杂" [page 7]。

APF 由 Khatib 于1986年提出，把目标和障碍视为带电表面，合力吸引机器人趋向目标、排斥其远离障碍（图8）[page 8]。作者对 APF 的着墨明显多于前两者，因为它被反复用于动态环境和多机器人系统，并可与 BFO、GA、PSO、FL 等杂交 [page 8]。但 APF 的固有问题是局部极小值，作者列举了多种应对：谐波函数、速度控制机制、改进的斥力势函数等 [page 8]。

经典方法的总体短板，作者在讨论部分集中概括：计算量大、易陷局部极小、无法处理最大不确定性、需要精确环境信息和精确传感，因此"采用经典方法时，总存在疑问——究竟能得到解，还是只能认定解不存在" [page 24]。这一表述把经典方法的可靠性问题上升为方法论层面的缺陷。

## 反应式方法：以不确定性处理能力为核心卖点

反应式方法覆盖 GA、FL、NN、FA、PSO、ACO、BFO、ABC、CS、SFLA 及若干杂项算法。作者对每一种都给出原理、代表工作和应用场景，但真正支撑核心结论的，是反复出现的三个论点。

**其一，反应式方法能处理高不确定性，适合未知环境。** 例如 GA 被描述为"在未知环境中只需极少环境信息即可高效搜索" [page 9]；FL 用于"高不确定性、复杂性和非线性"场景 [page 11]；NN 的泛化能力、并行性、学习能力和容错性使其适用于导航 [page 12]。这些机制性描述共同指向一个判断：反应式方法不依赖精确先验模型，因而更适合真实世界的未知与动态条件。

**其二，反应式方法可作实时控制，且能相互杂交。** 作者列举了大量混合案例：GA-FL、GA-NN、GA-PSO [page 10]；FL 与 NN、GA、APF、ACO 结合 [page 11]；NN 与 APF、FL 结合 [page 12]；PSO 与 IGSA、FL 结合 [page 16]；ACO 与 FL、RA 结合 [page 17] 等。杂交被作者视为反应式方法"改进经典方法性能"的具体途径，也是其流行的重要原因。

**其三，反应式方法已扩展到3D、多机器人和国防应用。** 表2显示，几乎所有反应式方法都用于空中导航，多数也用于水下导航；而经典方法中 CD 和 RA 仅用于空中、不用于水下 [page 28]。作者据此判断反应式方法"在最大不确定性下探索3D环境"的能力更强 [page 24]。

不过，作者并未把反应式方法写成没有代价。讨论部分明确指出其缺点：计算时间更长、设计复杂、需要学习阶段、需要大内存、不适合低成本机器人 [page 24]。这一限定很重要——它说明作者的结论是"相对更优"，而非"全面更优"。

## 计量证据：趋势图与分类表如何支撑结论

核心结论最直接的证据来自表1、表2和图24–29。

表1 按参考文献逐条标注每种方法是否用于静态障碍、动态障碍、动态目标、是否作混合、是否用于多机器人、是否有实时结果、是否有仿真结果、是否含运动学分析 [page 25–27]。作者从这张表中读出若干结构性事实：反应式方法的论文数量明显多于经典方法；经典方法中 APF 应用最广，CD 更多用于混合系统；动态障碍与动态目标、多机器人、实时应用方面，经典方法论文"非常少" [page 24]。

图29 给出最具冲击力的趋势判断：从1970年到2018年，反应式方法占比从0%升至95%，经典方法从95%降至5%；21世纪反应式算法增长迅速，"目前超过95%的工作仅使用反应式算法" [page 24]。图24、25 分别比较经典与反应式方法基于发表论文的数量 [page 29]。图26–28 则按静态/动态、实时/仿真、混合/多机器人/运动学等维度分解 [page 29–30]。

这些图表支撑结论的推理链条是：如果反应式方法在机制上更适合不确定环境，那么文献趋势应显示其占比上升、覆盖维度更广；而图表数据确实如此。机制解释与计量趋势在此形成互证。需要指出的是，作者并未给出图表的原始计数或统计方法，因此"95%"等数值应视为作者基于其文献集合的概括，而非可独立复核的精确统计——这是分析者基于文本的判断，非作者明说。

## 结论成立的条件与边界

作者的结论有明确的适用条件，这些条件部分由作者点明，部分需从文本推断。

**条件一：环境的不确定性程度。** 经典方法适用于"完全已知环境"，反应式方法适用于"未知和部分已知环境" [page 3]。因此"反应式更优"的结论，严格说是在不确定或动态环境下成立；在完全已知的静态环境中，经典方法（尤其 CD、RA）仍能给出完备解，作者也承认经典方法"要么得到解，要么确认解不存在"这一确定性优势 [page 5]。

**条件二：任务对实时性和成本的要求。** 反应式方法适合实时导航，但计算时间长、需大内存、不适合低成本机器人 [page 24]。这意味着在资源受限或对响应时间极敏感的场景，反应式方法的优势可能被其开销抵消。

**条件三：算法成熟度。** 作者多次指出新算法（SFLA、CS、IWO、BA、HS、DE、BFO、ABC、FA）在未知复杂环境中的应用"有很大空间"，暗示其当前证据基础尚不充分 [page 31]。CS 被明确称为"新近发展、用于移动机器人路径规划的论文有限" [page 20]。因此对这些算法的优越性判断，应比 FL、GA、NN 等成熟方法更谨慎。

**边界与负面结果。** 作者承认的局限包括：动态环境论文远少于静态环境；移动目标论文远少于移动障碍；仿真论文远多于实时；多机器人论文远少于单机器人；混合算法论文远少于独立算法 [page 30–31]。这些"少"本身构成对结论强度的限制——反应式方法在动态、多机器人、实时条件下的优势，其证据基础其实相对薄弱。此外，表1中部分方法（如 CD、RA、SFLA、BFO、OMA）被标注为不能处理多机器人问题，SFLA、RA、CD、OMA 不能良好处理混合问题 [page 24]，说明反应式方法内部也存在能力分化，不能一概而论。

## 论证的薄弱环节

从论证结构看，有两处需要读者留意。

第一，**"更鲁棒、表现更好"缺乏统一的性能指标。** 作者用"路径长度、平滑度、安全性"等描述各算法的目标 [page 13, 21]，但未给出跨算法的标准化比较。表1是二值（Y/N）分类，无法反映性能差异的程度。因此"反应式更优"更多是覆盖广度和趋势上的判断，而非在受控条件下测得的性能优势。

第二，**趋势数据与因果解释之间存在跳跃。** 图29显示反应式方法占比升至95%，作者将其解释为反应式方法能力更强的结果。但占比上升也可能源于研究热点转移、计算资源普及、发表偏好等未讨论因素。作者未排除这些替代解释，因此"因为更强所以更流行"的因果方向，应视为作者的论证主张而非已证事实。

## 总体判断

这篇综述的价值在于把分散的导航算法组织成一个"经典 vs 反应式"的对照框架，并用分类表和趋势图把这一对照量化。其核心论证——反应式方法因处理不确定性的能力更强而成为主流——在机制描述和文献趋势两个层面都得到支撑，但支撑力度受限于缺乏统一性能基准、动态/多机器人/实时证据相对不足，以及趋势数据的因果解释未充分排除替代因素。读者可以接受"反应式方法在不确定环境下更受青睐且覆盖更广"这一较弱结论，但对"反应式方法在所有方面都优于经典方法"这一较强读法，应保持保留。
