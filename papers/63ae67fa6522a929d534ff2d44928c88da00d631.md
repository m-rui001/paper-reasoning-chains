# 类别不平衡并非学习困难的唯一根源：Batista 等人对十种平衡方法的实验分析

**原文题名**：A Study of the Behavior of Several Methods for Balancing Machine Learning Training Data（2004，DOI: 10.1145/1007730.1007735）

## 论文要回答的问题

机器学习文献中流行一个假设：训练集中类别分布严重偏斜，是分类器在少数类上表现不佳的主要原因。Batista、Prati 和 Monard 的这篇论文正是要检验这一假设，并在此基础上比较十种平衡方法（其中三种由作者提出）在十三个 UCI 数据集上的实际效果。论文的核心结论有两层：第一，类别不平衡本身并不系统性地损害学习性能，真正的问题更可能与少数类样本过少、类别重叠等复杂因素交织在一起 [page 1]；第二，在 AUC 这一指标下，过采样方法总体上优于欠采样方法，这一结果与当时部分已发表文献相矛盾 [page 1]。

## 从"不平衡即困难"到"不平衡加重叠才困难"

论文第 2 节用一张示意图（Figure 1）直观地说明了问题的结构。图 1(a) 展示的是多数类（−）远多于少数类（+）且两类存在重叠的情形；图 1(b) 则是类别均衡、簇边界清晰的情形。作者指出，在图 1(a) 那种情形下，1-NN 分类器很容易把少数类样本误判，因为它们的最近邻往往属于多数类；当不平衡程度极高时，少数类样本的最近邻属于多数类的概率很高，少数类错误率会趋于不可接受的水平 [page 2]。决策树也面临类似困境：在类别重叠时，决策树需要大量测试才能区分少数类，而剪枝未必能缓解问题——剪枝去掉过于专门的枝后，叶节点往往被标记为占主导的多数类 [page 2]。

这里的关键推理是：不平衡本身并不直接导致错误，而是通过"少数类样本太少 + 类别重叠"这一组合条件起作用。作者在引言中已经提到，Sick 数据集即便高度不平衡，标准算法仍能诱导出好的分类器 [page 1]，这暗示不平衡不是唯一原因。第 5 节进一步用 Figure 3 和 Figure 4 来支撑这一判断。

Figure 3 绘制了负正样本比例与平均 AUC 的关系。如果类别不平衡系统性地损害性能，那么高度不平衡的数据集应当对应较低的 AUC。但图中 Letter-a 和 Nursery 尽管不平衡程度很高，AUC 却接近 100% [page 5]。Figure 4 则展示了正例训练样本数与 AUC 的关系，趋势表明：在小规模不平衡数据集上，少数类因样本过少而表示不足，尤其当类别重叠严重且少数类内部还分成子簇时，学习会受影响；数据规模增大后，这些复杂因素的影响似乎减弱 [page 5]。作者将这一趋势与 Japkowicz 在人工数据集上的结论相呼应——不平衡问题是一个相对问题，取决于概念复杂度和训练集总体规模 [page 5]。

需要指出的是，Figure 3 和 Figure 4 呈现的是散点趋势，作者并未报告正式的统计检验来量化"不平衡程度"与"AUC"之间的相关性。因此，这里的证据更应被理解为"与假设不一致的模式"，而非严格的因果证明。作者自己的措辞也是"seem to be compatible"和"suggested" [page 5]，保留了谨慎语气。

## 为什么用 AUC 而不是准确率

论文第 3 节专门论证了评估指标的选择。作者指出，准确率和错误率在类别先验概率差异很大时会产生误导：在一个多数类占 99% 的域中，只要把所有样本都预测为多数类，就能得到 99% 的准确率 [page 2]。此外，准确率把所有分类错误视为同等重要，而不平衡问题通常伴随高度非均匀的错误代价，少数类往往才是主要关注对象——把病人误诊为健康可能是致命错误，而把健康人误诊为病人则严重性低得多 [page 2]。第三个问题是类别分布本身会变化，任何同时使用混淆矩阵两行的指标都会对类别偏斜敏感 [page 2]。

因此作者选择 AUC（ROC 曲线下面积）作为主要评估指标。AUC 的优势在于它分别衡量正类和负类上的表现，不依赖于类别代价和先验概率，且对类别偏斜稳健 [page 3]。对于决策树，作者采用 [9] 提出的方法，用 Laplace 校正后的叶节点准确率来生成 ROC 曲线 [page 3]。这一指标选择直接影响了后续所有比较的结论方向——如果改用准确率，过采样方法因增加了训练样本总数而可能产生更大的树，准确率的表现未必与 AUC 一致。

## 十种方法的设计逻辑

论文第 4 节描述了十种方法。两种非启发式方法作为基线：随机过采样（随机复制少数类样本）和随机欠采样（随机删除多数类样本）。作者指出随机过采样的主要风险是过拟合，因为它制造了少数类样本的精确副本；随机欠采样的主要缺陷是可能丢弃对归纳有用的数据 [page 4]。

启发式方法中，Tomek links 定义了一种特殊的异类最近邻对：如果两个异类样本之间不存在第三个样本使它们更近，则这对样本构成 Tomek link，其中至少一个是噪声或两者都在边界上 [page 4]。作为欠采样方法时只删除多数类样本，作为数据清洗方法时两类都删。CNN（Condensed Nearest Neighbor）寻找一致子集，其思路是删除远离决策边界的多数类样本 [page 4]。OSS（One-sided selection）先应用 Tomek links 再应用 CNN [page 4]。NCL（Neighborhood Cleaning Rule）用 ENN 删除多数类样本，但对少数类被误分类的情况会删除其多数类近邻 [page 4]。Smote 通过在少数类样本之间插值来合成新样本，避免精确复制导致的过拟合 [page 4]。

作者提出的三种方法中，CNN + Tomek links 是 OSS 的变体，先找一致子集再做 Tomek links，动机是 Tomek links 计算量大，在缩减后的数据集上执行更经济 [page 4]。Smote + Tomek links 和 Smote + ENN 则针对一个更具体的问题：过采样虽然平衡了类别分布，但类别簇的边界可能仍然不清晰——多数类样本可能侵入少数类空间，插值产生的少数类样本也可能深入多数类空间，导致过拟合。因此这两种方法在 Smote 过采样之后，分别用 Tomek links 和 ENN 作为数据清洗手段，删除两类中位于错误一侧的噪声样本，以产生边界更清晰的类别簇 [page 4–5]。Figure 2 用四步示意图展示了 Smote + Tomek links 的流程：原始数据 (a) → Smote 过采样 (b) → 识别 Tomek links (c) → 删除边界和噪声样本 (d) [page 5]。

## 实验设计与主要结果

实验使用 C4.5 release 8 诱导决策树，在十三个 UCI 数据集上进行 10 折交叉验证 [page 5]。数据集的不平衡比例从 Pima 的 65.23% 到 Nursery 的 97.45% 不等（Table 3）[page 6]。对于多类数据集，作者选择样本最少的类作为正类，其余合并为负类 [page 5]。Smote、随机过采样、随机欠采样和 CNN 的内部参数被设置为达到平衡分布，这一决定基于 [23] 的结果——当使用 AUC 时，最佳类别分布倾向于接近平衡 [page 6]。

Table 4 和 Table 5 分别报告了原始/过采样和欠采样数据集的 AUC 结果，加粗表示每个数据集在剪枝和未剪枝条件下各自的最佳值 [page 7–8]。作者指出所有最佳结果都由过采样方法获得 [page 6]。Table 6 和 Table 7 将结果转化为方法排名，过采样方法用浅灰色标出，原始数据集用深灰色标出，星号表示在 Hsu 的 MCB 检验（95% 置信水平）下显著劣于排名第一的方法 [page 7–8]。

从排名中可以读出几个关键模式。过采样方法总体上排名优于欠采样方法 [page 7]。随机过采样虽然简单，但在多个数据集上排名靠前，甚至在某些数据集上超过更复杂的方法 [page 7]。作者提出的 Smote + Tomek 和 Smote + ENN 在正例样本数较少的数据集上表现突出：在正例少于 100 的 6 个数据集（Flag、Glass、Post-operative、New-thyroid、E.Coli、Haberman）中，至少有一种提出的方法在剪枝树上对全部 6 个数据集提供了有意义的结果，在未剪枝树上对 5 个数据集如此 [page 7]。

这一结果与当时部分文献相矛盾。Drummond 和 Holte 报告过采样在使用 C4.5 默认设置时效果不佳，且过采样剪枝更少、泛化更差 [page 7]。Domingos 报告 C4.5 Rules 使用欠采样产生更低代价的分类器 [page 7]。Ling 和 Li 报告欠采样产生更好的 lift index [page 7]。但 Japkowicz 和 Stephen 在人工数据集上比较后结论是过采样在降低错误率上更有效 [page 7]。作者对此的解释是：性能损失似乎直接与少数类样本不足及其他复杂因素相关，而过采样正是最直接地针对少数类样本不足这一问题的方
