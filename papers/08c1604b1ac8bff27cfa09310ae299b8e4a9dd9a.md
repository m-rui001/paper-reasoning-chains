# Ti₃C₂Tz MXene 的 XPS 谱图该怎么拟合：一篇批判性综述的论证分析

**原文题名：** A critical analysis of the X-ray photoelectron spectra of Ti₃C₂Tz MXenes
**年份：** 2021　**DOI：** 10.1016/j.matt.2021.01.015

## 问题的起点：四种拟合模型彼此矛盾

这篇综述的核心主张并不复杂：截至写作时，文献中针对 Ti₃C₂Tz 的 X 射线光电子能谱（XPS）拟合模型"往好里说是不完整的，往坏里说是自相矛盾的"（摘要，[page 1]）。作者 Natu、Barsoum 等人系统比较了四套已发表的拟合方案（Fit-I 至 Fit-IV），指出它们在峰位归属、峰数、甚至校准方法上都存在实质分歧，然后提出自己的第五套方案（Fit-V）。

要理解这场争论，先要抓住一个技术前提：Ti 2p 谱因自旋-轨道耦合分裂为 Ti 2p₃/₂ 和 Ti 2p₁/₂ 两个包络峰，二者间距记为 ΔTi2p。作者强调，任何拟合到 2p₃/₂ 的分量都必须在 2p₁/₂ 处有对应分量，理论面积比应为 2:1，但实际因背景扣除不完美、卫星峰重叠和 Coster-Kronig 效应会略有偏离 [page 11]。这是后文评判各模型是否自洽的基本标尺。

四套模型的差异可以这样概括：

- **Fit-I（Halim 等，2016）** 按 Ti 的**氧化态**归属，把 455.0、455.8、457.2 eV 分别指认为 Ti⁺¹、Ti⁺²、Ti⁺³，另有 458.6 eV 的 TiO₂ 和 460.2 eV 的 TiO₂₋ₓF₂ₓ [page 2–3, Table 1]。
- **Fit-II（Persson 等）** 改按**晶体位点**归属，区分 C–Ti–O\O\O、C–Ti–(O,F)、C–Ti–F\F\F，峰位在 455.1、455.9、456.9 eV [page 4–5, Table 2]。
- **Fit-III（Schultz 等）** 区分中心 Ti（Ti–C）与近表面 Ti，把 455.2 eV 归为 Ti–C，456.2 eV 归为 Ti–O，457.3 eV 归为 Ti–F [page 6–7, Table 3]。
- **Fit-IV（Benchakar 等）** 大体沿用 Fit-I 的氧化态思路，但把约 460.0 eV 的峰改归为过量刻蚀形成的 TiFₓ 盐 [page 7, Table 4]。

作者指出，最刺眼的分歧在 C–Ti–F 峰：Fit-I 与 Fit-II 之间相差 3.3 eV，Fit-I 与 Fit-III 之间相差 2.9 eV，而 Fit-IV 干脆认为该峰与 C–Ti–O/OH 重叠、无法分辨 [page 9]。这种量级的差异不是细节之争，而是会直接改变对表面化学的定量结论。

## 论证的关键转折：从"氧化态"转向"局部配位环境"

作者真正的论证转折，是主张放弃按氧化态拟合，改按**每个 Ti 原子周围八面体顶点的终止基团种类**来拟合。这一转向不是凭直觉，而是由几条相互独立的证据链支撑的。

**第一条证据链来自 Ti₂CTz 与 Ti₃C₂Tz 的谱图对比。** Fit-III 假设中心 Ti（被 6 个 C 包围）与近表面 Ti（被 3 个 C 包围）可以区分，并把 455.2 eV 归给前者。但作者指出，Ti₂CTz 中根本不存在被 6 个 C 包围的中心 Ti 层，若 Fit-III 成立，Ti₂CTz 的 Ti 2p 谱在低结合能端就应缺少这一分量。然而把两种 MXene 的 Ti 2p 谱叠加后，低结合能一侧（虚线右侧）几乎完全重合（Figure 7E，[page 12]）。这说明中心 Ti 与近表面 Ti 在常规 XPS 下**无法区分**，因此把 455.2 eV 归给 C–Ti–C 很可能是错的。作者给出的物理解释是：Ti₃C₂Tz 中 C 的电荷约为 −2，使得两种 Ti 位点的电子环境趋同 [page 12]。

**第二条证据链来自 Ti 氧化物中结合能间距的规律。** 作者把 Ti 金属（Ti⁰）到 TiO（Ti⁺²）、Ti₂O₃（Ti⁺³）、TiO₂（Ti⁺⁴）的 Ti 2p 结合能对氧化态作图（Figure 8，[page 13]），发现相邻氧化态之间的结合能差 ΔBE 大致恒定为约 1.6 eV。若 Fit-I 和 Fit-IV 的氧化态归属正确，C–Ti⁺¹–Tz 与 C–Ti⁺²–Tz 之间应约 0.8 eV、C–Ti⁺²–Tz 与 C–Ti⁺³–Tz 之间应约 1.4–2 eV，即三个分量应大致等间距。但实际拟合给出的间距并不均匀，与这一规律不符。

**第三条证据链是氧化态的量级检验。** 作者引用 Lukatskaya 等的 XANES 结果，Ti₃C₂Tz 中 Ti 的平均氧化态约为 +2.4 [page 13]。若按 Fit-I 前三个分量的比例重新归一化，得到约 0.31、0.33、0.35，代入计算平均电荷为 0.31×1 + 0.33×2 + 0.35×3 = 2.02（Equation 1，[page 13]），与 XANES 的 +2.4 相差 0.4。作者进一步引用 Sun 等的 EPR 结果，Ti⁺³ 浓度仅 7.08×10¹⁸ atoms/g，对应不到 1% 的 Ti⁺³ [page 14]。这两点共同说明 Fit-I 和 Fit-IV 显著高估了低氧化态（尤其 Ti⁺³）的峰面积，而 Ti⁺¹ 在 MXene 中本就不稳定。

**第四条证据链来自 Ti–X 化合物结合能与电负性的线性关系。** 作者把 Ti 处于 +3 或 +4 态的多种 TiX 化合物（X = S、O、F、Cl）的 Ti 2p 结合能对归一化电负性作图（Figure 10，[page 16]），发现结合能随 X 电负性近似线性上升，且同一氧化态下 Ti–F 与 Ti–O 的结合能差恒定在约 2.8–2.9 eV。据此推断，C–Ti–O\O\O 与 C–Ti–F\F\F 之间也应相差约 2.9 eV。若把第一个峰定在 455.0 eV，则 C–Ti–F\F\F 应在约 458 eV，而 C–Ti–O\O\F 和 C–Ti–O\F\F 应分别落在约 456 和 457 eV。作者还用这一关系反推 TiOF₂ 的结合能为 459.6 eV，与实验值 459.5 eV 吻合；反推 TiOCl 为 457.8 eV，与文献 457.9 eV 吻合（Figure 10 中的蓝星与绿星，[page 16]）。这两次"预测—验证"是支撑该插值可靠性的关键。

综合以上，作者提出 **Fit-V**：455.1 eV 归 C–Ti–O\O\O，456.0、457.0、457.9 eV 分别归 C–Ti–O\O\F、C–Ti–O\F\F、C–Ti–F\F\F，459.6 eV 归 TiO₂₋ₓF₂ₓ（Table 7，[page 17]）。同时施加若干约束：MXene 相关峰的 ΔTi2p 固定为 6.1 eV，氧化物峰为 5.6 eV；MXene 峰用非对称线型，氧化物用对称高斯线型；统一采用 Tougaard 背景；同一包络下各分量 FWHM 相等 [page 15]。

## 校准问题：一个容易被忽视却影响全局的前提

作者用相当篇幅讨论能量校准，因为峰位归属的可靠性完全依赖于能量标尺是否准确。他们推荐把费米边对齐到 0 eV，而非用外来碳的 C–C 峰（约 284.8 eV）校准——后者因文献取值在 284.5–285.0 eV 之间浮动，0.5 eV 的不确定性足以破坏精确校准 [page 9]。

这里有一个对全文结论至关重要的观察：Ti₃C₂Tz 中 C 1s 的 Ti–C–Ti 峰在 282.0 ± 0.06 eV 极为稳定（Table 5，[page 10]），跨越七项研究、不同刻蚀方法、不同 M:X 比甚至含 N 体系都成立。作者因此建议，当费米边不够清晰时，可用 282.0 eV 作为校准锚点。但作者也明确划出边界：这一锚点**仅适用于含 F 酸刻蚀的 MXene**；熔盐法合成的 MXene 中该峰可能偏离 282.0 eV [page 10, page 17]。

这一边界在熔盐 MXene 的再拟合中得到了具体体现。作者用 Fit-V 重新拟合 Li 等和 Kamysbayev 等的数据时，因原始数据未扫描费米边，只能强行把 Ti–C–Ti 设为 282.0 eV，结果得到 Ti₃C₂Cl₂ 和 Ti₃C₂Br₂ 的 C–Ti–Cl\Cl\Cl / C–Ti–Br\Br\Br 结合能为 454.8 eV（Table 8，[page 18]）。作者指出这在物理上不合理：Cl、Br 电负性高，应使结合能**升高**而非降低，且 454.8 eV 恰与母相 MAX 相近。由此推断，熔盐 MXene 的 Ti–C–Ti 峰已不能假定在 282.0 eV [page 17]。这是一个作者主动承认的、尚未解决的异常，而非被掩盖的矛盾。

## O 1s 与 F 1s：作者承认最薄弱的两环

作者对 O 1s 的拟合评价最为谨慎，直言"最模糊"，需要更多工作 [page 20, page 25]。争议焦点是 532.0 eV 峰的归属：Fit-I 和 Fit-IV 归为 C–Ti–OH，Fit-II 则否认表面存在 –OH，认为该峰是占据桥位的 –O，理由是退火时该峰强度下降但 O 1s 总面积不变 [page 19]。作者对此提出一个**假设性**反驳：Seredych 等的 TGA-MS 显示 F 以 HF 形式脱附，若 –OH 通过失 H 生成 HF 而转为 –O，则总 O 量确实可以不变 [page 20]。作者明确标注这只是"一个可能解释这一现象的假设"，并指出需要把退火样品重新暴露于空气/水后再扫描才能验证。同时，作者引用 NMR 和中子散射研究证明 –OH 确实存在 [page 20]。最终 Fit-V 把 532.0 eV 处理为 C–Ti–OH 与 C–Ti–(O,F) 的**卷积**，并承认无法排除后者贡献 [page 22]。

氧化物峰位也有一处直接对撞：Fit-I 把 529.9 eV 归为 TiO₂/TiO₂₋ₓF₂ₓ，Fit-IV 则把该峰放在 530.6 eV，"二者不可能都对" [page 20]。作者用 Benchakar 等的时效实验裁决：新鲜样品与老化 1、6 个月的 O 1s 谱叠加后，6 个月时在约 530.8 eV 出现明显新峰（Figure 13，[page 20]），支持 Fit-IV 的归属，Fit-V 采纳 530.8 eV。

F 1s 则被作者认为**本质上难以定量**：F 是最电负性元素，化学位移小，且 TiO₂₋ₓF₂ₓ 的 F 1s 峰也在约 685.0 eV，与 C–Ti–F 无法解卷积 [page 21–22]。因此 Fit-V 只用单一非对称峰拟合 F 1s，并建议尽量避免对非 MXene 的 F 贡献做定量。

## 定量结论及其成立条件

作者用 Fit-V 对 10% HF 刻蚀样品重新拟合（Figure 14, Table 10），得到化学式并检验两条结构约束：Ti:C ≈ 3:2，以及 z ≈ 2 [page 22–23]。后者被作者视为极好的判据——若每个终止原子与三个 Ti 成键、填满密排位点，z 就应接近 2；DFT 显示 z > 2 时体系能量迅速上升，而 z > 2.5 往往意味着 O 取代了 Ti₃C₂ 层中的 C [page 23]。反过来，z << 2 意味着存在裸露 Ti 键，而 Ti 表面即使在超高真空也会迅速被氧覆盖，因此作者把 z << 2 视为"分析严重有问题的红旗" [page 24]。

在 Table 11 中，作者比较了不同刻蚀条件得到的化学式与 Tz 总电荷。48% HF 刻蚀样品的 F 含量约为温和刻蚀样品的两倍，且 Tz 电荷略低（约 −2.5 至 −2.8，而温和刻蚀为 −2.9 至 −3.2）[page 24]。作者还做了两种极端假设下的 C 氧化态估算：若把 532.0 eV 全归为 C–Ti–(O,F)，得 C 约 −1.9；若全归为 C–Ti–OH，得约 −2.15。两种情形下 C 的平均氧化态都接近 −2，这恰好解释了为何中心 Ti 与 O\O\O 终止的近表面 Ti 在 Ti 2p 中难以区分 [page 24]。

## 结论的边界与作者承认的局限

这篇综述的结论有明确的适用范围，作者自己也反复划界：

其一，**全文只针对 Ti₃C₂Tz**。作者在结论中明确提醒，即便这是研究最充分的 MXene，其 XPS 拟合仍未完全理解，把 Ti₃C₂Tz 的结论直接套用到其他 MXene 组分需极其谨慎 [page 25]。

其二，**XPS 定量本身受样品形貌限制**。MXene 片层仅约 1 nm 厚，而 XPS 分析深度约 5–10 nm，在 200 μm 束斑下实际是平均了约 10⁶ 个片层，信号同时来自表面终止、片层内部、层间插层物种和杂质 [page 24]。因此作者承认只能得到"粗略估计"，而非精确化学式。

其三，**若干关键归属仍是假设**。TiO₂₋ₓF₂ₓ 中 x 的取值（作者假设 x = 1/2，即 TiO₁.₅F）是基于 XPS 与 XRD 的差异所做的推断，作者明确说需要更多（最好原位）氧化研究来确认 [page 22–23]。非对称线型虽借自 Ti 金属拟合，但作者承认 MXene 中电子散射行为不同，线型需专门优化，这涉及片层间与片层内电子输运、层间物种和杂质的作用 [page 25]。

其四，**不同表征技术之间尚未收敛**。Table 9 显示，同样 48% HF 刻蚀的样品，XPS、NMR、中子 PDF 给出的化学式差异很大，O:OH 比从 0.07 到 8，O:F 比从 0.3 到 11 [page 21]。作者没有断言哪种技术正确，而是指出这种分歧本身说明"要么某些技术不能用于定量终止化学，要么需要更深入研究" [page 21]。


谱峰归属与能量校准也需要分开看待。作者认为 O 1s 是最难拟合的一段：529.8 eV 可归于 C–Ti–O，530.8 eV 归于 TiO₂₋ₓF₂ₓ，533.4 eV 归于吸附水；但 532.0 eV 可能同时包含 C–Ti–OH 与 C–Ti–O/F，现有数据无法把两者可靠拆开。F 1s 中非 MXene 来源的氟也难以区分，因此作者提醒不要把这部分峰面积当作精确的终止基定量。能量标尺方面，282 eV 的八面体碳峰可用于不少酸刻蚀样品，但熔盐刻蚀材料出现的异常尚未解决；Fit-V 因而主要是在酸刻蚀、尤其含氟酸刻蚀的 Ti₃C₂Tz 上相对可靠，不能据此假定各种制备路线都可直接套用 [page 22–25]。
## 总体判断

这篇综述的论证力量，不在于提出了一套完美方案，而在于用几条可独立检验的证据（Ti₂CTz/Ti₃C₂Tz 谱图重合、Ti 氧化物结合能间距规律、XANES/EPR 的氧化态量级、Ti–X 电负性线性关系及其对 TiOF₂/TiOCl 的预测验证）系统性地削弱了既有模型，尤其是按氧化态归属的做法。Fit-V 的合理性建立在这些证据的交叉支撑上，而非单一拟合优度。与此同时，作者对 O 1s 归属、熔盐 MXene 的校准异常、线型优化等问题保持了明确的保留态度，把结论限定在"含 F 酸刻蚀的 Ti₃C₂Tz、且能量标尺可靠"这一范围内。读者若要把这套方案用于其他体系，最需要警惕的正是作者自己标出的那几处边界：校准锚点 282.0 eV 的适用性、z ≈ 2 这一结构约束的检验价值，以及 O 1s 与 F 1s 归属中尚未解决的重叠问题。
