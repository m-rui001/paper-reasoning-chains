# 单层二硫化钼的谷选择性圆二色性：从对称性论证到50%圆偏振发光

**原文题名**：Valley-selective circular dichroism of monolayer molybdenum disulphide
**年份**：2012
**DOI**：10.1038/ncomms1882

## 论文要解决的问题

二维蜂窝晶格（如石墨烯）在动量空间的布里渊区顶点 K± 处存在一对不等价的“谷”，这一自由度可类比自旋，被寄望用于“谷电子学”（valleytronics）。实现谷极化的核心手段是圆偏振光激发：如果两个谷对左旋和右旋光子的吸收不同（即圆二色性，circular dichroism, CD），就能选择性地只激发其中一个谷的载流子。作者指出，蜂窝晶格中谷选择性 CD 的必要条件是**反演对称性破缺** [page 2]。石墨烯本身中心对称，需要借助衬底相互作用来打破反演对称并打开带隙，但作者认为这一策略在实验上相当困难，且即便实现，衬底与石墨烯之间只是大范德华间距下的弱共价耦合，对石墨烯只是“温和的微扰” [page 2]。

作者的替代方案是单层 MoS₂。其自由悬挂的稳定结构本身就是反演对称性破缺的蜂窝晶格（图 1b），且单层极限下材料从体相的间接带隙转变为位于布里渊区顶角的直接带隙，带隙约 1.8 eV [page 2]。论文的核心主张是：**单层 MoS₂ 具有近乎完美的谷选择性圆二色性，这一性质根植于其体对称性，可用于实现谷电子学所需的光学谷极化** [page 2]。作者用第一性原理计算给出理论预言，并用圆偏振光致发光（PL）实验提供证据，测得最高约 50% 的偏振度 [page 1]。

## 理论论证：从对称性到近乎完美的谷选择性

作者评估的关键量是 k 分辨的光学偏振度 η(k)，定义为左旋与右旋光吸收之差除以总吸收，在价带顶与导带底之间取值，见公式 (1) [page 2]。计算采用密度泛函微扰理论、局域密度近似，在 VASP 中实现，平面波截断能 600 eV，包含 80 个能带，k 点网格 15129 个点，且**未包含自旋轨道耦合** [page 2–3]。

计算结果（图 2a）显示，在 K± 处手性吸收选择性是精确的，η = ±1 [page 3]。也就是说，整个 K+ 谷几乎只吸收左旋光子，整个 K− 谷几乎只吸收右旋光子，选择性在整个谷内近乎完美，仅在跨越谷边界时迅速变号 [page 3]。

这一结论的推理关键在于**布洛赫态在旋转对称性下的相位绕转**。作者指出，与能谷相关的能带态来自局域原子轨道，携带不同的轨道磁量子数 l。在 K+ 处，Mo 上的 d 态杂化为 $\frac{1}{\sqrt{2}}(d_{x^2-y^2} + i d_{xy})$（l = +2），与 S 上的 $\frac{1}{\sqrt{2}}(p_x + i p_y)$（l = +1）相互作用；在 K− 处则取相应的负号组合（l = −2 与 l = −1）。导带底主要由 Mo 上的 $d_{z^2}$（l = 0）构成，S 的 p 轨道只有少量贡献 [page 3]。

在此基础上，作者给出微观手性选择定则。在三维旋转 $\hat{C}_3$ 下，价带与导带极值满足公式 (2) 和 (3)：价带态在旋转下只获得平凡相位，而导带态获得 $e^{\mp 2\pi i/3}$ 的相位 [page 3]。作者强调相位绕转有两个不同来源（图 2b）：一是从一个格点到下一个格点的布洛赫相位移动（与 gapped graphene 情形类似），二是局域原子坐标旋转时方位角相位（与磁量子数 l 相关）的“失同步” [page 3]。由此，导带底在 K± 处整体方位量子数 m± = ±1，价带顶 m± = 0，光学跃迁的角动量选择定则为 Δm± = ±1，分别对应左旋和右旋光子的吸收 [page 3]。作者据此指出，密度泛函微扰理论在谷附近的结果实际上由材料对称性所保证 [page 3]。

这里有一个值得注意的论证转折：作者明确区分了 MoS₂ 与 gapped graphene 的微观机制。在 gapped graphene 中，手性选择定则来自依赖子晶格的布洛赫相位绕转；而在 MoS₂ 中，它直接来自原子轨道的局域相对方位角相位 [page 3]。作者还指出，MoS₂ 中跨越带隙的电子态成键更为复杂，因局域原子态对称性而呈现更丰富的变化可能 [page 3]。这一区别也预示了后文关于贝里曲率的判断：MoS₂ 的物理不能由极简两带模型完全刻画。

## 实验证据：50% 的圆偏振发光

为验证理论预言，作者对单层 MoS₂ 进行了圆偏振 PL 测量。样品通过微机械剥离天然 MoS₂ 晶体到 Si/90 nm SiO₂ 衬底上获得，层数由光学对比度和 PL 谱识别 [page 4]。单层样品在 300 K 下显示 1.82 eV 的单 PL 峰，多层样品则出现额外的低能峰（图 3c）[page 4]。

在 83 K 低温、633 nm 的 σ+ 激发下，作者测量了 σ+ 和 σ− 偏振的发光强度（图 3d）。结果与理论预言一致：PL 峰处表现出显著的圆偏振，η ~ 50% [page 4]。作者同时指出，这一实验值**大于** GaAs 等材料中与自旋相关的偏振，但**小于**从头计算预期的值（对入射光能量，η ≥ 0.98）[page 4]。

## 从理论到实验的落差：速率方程与限制条件

作者没有把 50% 与理论值之间的差距当作异常，而是用速率方程加以解释。谷光学过程涉及两个时间尺度：谷寿命 τv 和复合时间 $\tau^{-1} = \tau_r^{-1} + \tau_{nr}^{-1}$（下标 r、nr 分别指辐射和非辐射复合，例如通过衬底）[page 4]。稳态过程的 PL 偏振度由公式 (5) 给出：

$$\eta_{PL} = (1-\delta)\frac{\eta}{1+\tau/\tau_v}$$

其中 1−δ 是初始激发的选择性（包含可能的谷间产生），η 是理论圆偏振度 [page 4]。作者进一步在最低阶动力学描述中取 δ = δimp + δph，以计入杂质/缺陷/衬底辅助以及声子辅助的激发与复合过程，这些过程中谷被散射体的动量分量耦合 [page 4]。

由此，实验 PL 中不完美的圆偏振被归因于不可避免的谷间过程，或谷寿命与复合时间之比较大的比值 τ/τv [page 4]。作者提出，在高质量、清洁样品上于极低温（最小化 δ）测量 PL 圆偏振，将允许提取 τ/τv；并指出评估非辐射弛豫（可由衬底和缺陷诱导）的作用也很有意义 [page 4]。

这里需要明确结论的成立条件。理论预言的 η ≥ 0.98 是在**未包含自旋轨道耦合**的计算框架下、针对入射光能量给出的 [page 2, 4]。实验的 50% 是在 83 K、633 nm 激发、特定样品与衬底条件下测得的 [page 4]。公式 (5) 把实验值与理论值联系起来，但其中 δ 和 τ/τv 并未在本工作中独立测定，因此 50% 这一数值本身不能直接反推谷寿命或散射强度——作者只是把它作为谷间过程存在的证据，并把它列为未来实验的目标。

## 贝里曲率与后续实验的含义

作者进一步考察了贝里曲率 $\Omega_{n,z}(k)$，它通过反常速度（垂直于外加电场，~ E × Ωn(k)）进入半经典波包动力学 [page 4]。由于体系具有时间反演对称性而无反演对称性，Ωn,z(k) 是 k 的奇函数且一般非零 [page 4]。沿 K−–Γ–K+ 路径的贝里曲率（图 4）显示，两个谷中载流子的反常速度符号相反，对横向电流的贡献恰好相互抵消；因此**平衡态下自由悬挂的单层 MoS₂ 不会表现谷霍尔效应** [page 4]。

作者还指出，在 K± 处贝里曲率不具有粒子-空穴对称性，这清楚表明 MoS₂ 的物理不能由极简两带模型完全捕捉，与 gapped graphene 情形不同 [page 4]。这一判断是作者从计算结果中读出的模型适用性边界，而非实验结论。

在此基础上，作者提出若干后续实验方向：当谷极化被诱导后，理想情况下（假设无谷间散射）只有一个谷有非零载流子布居，这可以导致**无外加磁场下的霍尔效应和磁化** [page 4]。在带边附近，导带和价带都显示符号相反的显著贝里曲率，因此圆偏振辐照产生的电子和空穴都对霍尔电导或磁化有内禀的同时贡献 [page 4]。此外，时间分辨 PL 测量将有助于揭示谷寿命，类比于自旋电子学中的自旋寿命 [page 4]。

作者在结尾把 MoS₂ 放入更广的材料家族：MX₂（M = Mo, W；X = S, Se）具有相同晶体结构和相似的电子性质，一旦以单层形式获得，将提供化学上丰富的半导体原子膜家族用于探索谷物理 [page 4]。作者同时承认，这些体系中存在相当大的自旋轨道耦合，且 K 点附近的谷与自旋相关物理已在近期理论工作中讨论；在更高层次理论上评估光学选择性和贝里曲率以处理激发态的多体性质，也是重要的未来方向 [page 4]。

## 论证结构与边界

整篇论文的论证链条可以概括为：反演对称性破缺是谷选择性 CD 的必要条件（引言）→ 单层 MoS₂ 天然满足这一条件且具有直接带隙（结构事实）→ 第一性原理计算给出 K± 处 η = ±1（图 2a）→ 对称性分析表明这一结果由原子轨道的局域方位角相位和 $\hat{C}_3$ 旋转下的相位绕转所保证（公式 2–4）→ 圆偏振 PL 实验测得 ~50% 偏振（图 3d）→ 速率方程把实验值与理论值的差距归因于谷间过程和 τ/τv（公式 5）→ 贝里曲率分析指出平衡态无谷霍尔效应，但光激发载流子可贡献霍尔电导与磁化（图 4）。

需要留意的边界条件包括：理论计算未包含自旋轨道耦合 [page 2]；实验在 83 K 下进行，室温下的偏振行为未在本文报告；50% 的数值依赖于具体样品、衬底和激发条件，作者未在本工作中独立提取 δ 或 τ/τv；贝里曲率的计算基于 Kohn-Sham 单粒子态，作者承认它不是严格的基态性质，但对 Kohn-Sham 态可以相当准确地评估 [page 4]。此外，作者关于“无外加磁场下的霍尔效应和磁化”的预期是建立在“理想情况下假设无谷间散射”之上的 [page 4]，属于对后续实验的展望而非已证实的结论。

总体而言，这篇论文的贡献在于把谷选择性 CD 从石墨烯的“需要衬底工程”转变为单层 MoS₂ 的“内禀对称性保证”，并用计算与实验两条证据链支撑这一主张。其推理中最关键的一步是：把 K± 处近乎完美的 η = ±1 归因于局域原子轨道的方位角相位在 $\hat{C}_3$ 旋转下的失同步，而非 gapped graphene 中的子晶格布洛赫相位绕转 [page 3]。这一机制解释既说明了为什么选择性可以近乎完美，也解释了为什么 MoS₂ 的物理需要超越极简两带模型。
