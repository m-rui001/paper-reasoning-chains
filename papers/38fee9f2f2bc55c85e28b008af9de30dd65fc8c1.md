# 把 C 1s 当作能量标尺：一篇关于 XPS 结合能参考的批判性论证

**原文题名**：X-ray photoelectron spectroscopy: Towards reliable binding energy referencing（2019，DOI: 10.1016/j.pmatsci.2019.100591）

## 一个被广泛使用却从未被真正验证的前提

XPS 之所以能判断化学键，靠的是"化学位移"——同一元素在不同化学环境中的核心能级结合能（binding energy, BE）会有差异。但要让这个差异有意义，必须先有一个可信的 BE 零点。对于金属样品，这个零点由费米能级（Fermi level, FL）自然给出；对于绝缘体或接触不良的样品，费米能级对齐无法保证，于是几十年来最流行的做法是：把表面那层无处不在的"污染碳"（adventitious carbon, AdC）的 C 1s 峰固定到某个值（通常 284.6–285.0 eV），然后把整条谱线平移过去 [page 6][page 41]。

Greczynski 和 Hultman 这篇综述的核心主张是：**这个做法在物理上站不住脚，因为 AdC 的 C 1s 峰位置并不是一个常数，而是被样品功函数"牵着走"的**。作者不是简单重复前人质疑，而是用近百个样品的系统实验，给出了一个可检验的替代关系：C 1s 峰相对费米能级的结合能 $E_F^B$ 与样品功函数 $\phi_{SA}$ 之和近似恒定，即 $E_F^B + \phi_{SA} = 289.58 \pm 0.14$ eV [page 75]。换句话说，AdC 的能级是对齐到真空能级（vacuum level, VL）而非费米能级的。

## 论证的起点：文献中的混乱本身就是证据

作者的第一层论证是"现状诊断"。他们调查了 2010–2017 年磁控溅射薄膜领域的高被引论文，发现绝大多数用 AdC 的 C 1s 峰做参考，而且**不管样品是否导电都这么做**，完全忽略了样品与仪器之间费米能级是否对齐这个前提 [page 6][page 7]。

更关键的是，他们把 C 1s 峰被设定的值统计出来：范围从 284.0 到 285.6 eV [page 7][page 53]。这本身就自相矛盾——一个"参考值"如果可以在 1.6 eV 范围内任意选取，它就不再是参考。作者还引用了 NIST 数据库的统计（Fig. 2）：同一化学态的元素，不同实验室报道的 BE 差异常常超过 1 eV，某些氟化物甚至达到 8.5 eV，而典型化学位移往往只有 1 eV 量级 [page 7][page 8]。这意味着**参考误差可能直接淹没要测量的化学信息**。

这里作者做了一个重要的概念区分：**"校准"（calibration）和"参考"（referencing）不是一回事**。前者是用标准样品（溅射清洁的 Au、Ag、Cu 箔）确认谱仪工作正常，是仪器层面的；后者是对未知样品施加一个刚性平移来补偿荷电，是样品层面的 [page 35][page 52][page 53]。作者指出，早期 XPS 文献把两者混为一谈，这个混淆一直延续至今，是混乱的根源之一。

## 关键实验：C 1s 峰到底由什么决定

诊断之后，作者转向自己的实验。他们用同一台 Axis Ultra DLD 谱仪、相同条件，测量了金属、氮化物、碳化物、氧化物、硼化物、氧氮化物等近一百个样品，空气暴露时间从几分钟到几年不等 [page 54][page 74]。

**第一个发现是 AdC 的化学本质并不固定。** 通过对比空气、高真空、超高真空三种暴露环境（Fig. 25），以及不同基底（Au、Ti、Mn、Mo、Y、Zr，Fig. 27），作者发现 C 1s 谱中 C-C/C-H、C-O、O-C=O、CO₃ 各组分的相对强度随基底和环境剧烈变化。例如 Mo 表面只有 C-C/C-H 和 C-O，Y 表面完全没有 C-O 却有 CO₃，Zr 表面则被 O-C=O 主导 [page 60][page 61]。暴露时间也影响组成：CO₃ 最先形成，O-C=O 需要更长时间 [page 62]。作者由此得出结论：**不存在一种定义明确的"AdC 化合物"**，它的性质取决于基底、环境和时间 [page 63]。

**第二个、也是全文最核心的发现，是 C 1s 峰位置本身随基底大幅变化。** Fig. 32 显示，C-C/C-H 峰的 $E_F^B$ 从 MoN 上的 284.08 eV 到 Y 上的 286.74 eV，跨度达 2.66 eV [page 64][page 75]。这个跨度比大多数化学位移还大。

作者预见到一个自然的反驳：**这会不会是荷电效应？** 他们用四条独立证据排除了这个解释 [page 65][page 66][page 67]：

1. 所有金属样品的价带谱在费米能级处都有清晰的截断，且截断正好落在 BE 标尺的"0 eV"（Fig. 34），证明样品与谱仪费米能级对齐、接触良好，基底没有荷电。
2. 位移在极短暴露时间（亚单层覆盖）就出现，此时光致导电足以补偿电子损失。
3. 位移在数月暴露期内持续存在，不随 AdC 厚度增加而增大——如果是 AdC 层荷电，应该随厚度增加而加剧。
4. 施加基底偏压时，C 1s 峰与基底核心能级同步移动，斜率 0.993–0.997（Fig. 35、Fig. 36），没有电压降的迹象。

**第三个发现建立了机制。** 作者用 UPS 测量样品功函数 $\phi_{SA}$，与 C 1s 的 $E_F^B$ 作图（Fig. 40），发现两者高度线性相关，斜率 −0.994，即 $E_F^B + \phi_{SA}$ 近似恒定 [page 69]。这个恒定值对应的是 C 1s 相对真空能级的结合能 $E_V^B \approx 289.58$ eV，与气相烷烃的 C 1s 值（经分子间弛豫修正后）吻合 [page 69]。作者的解释是：AdC 与基底是弱相互作用（物理吸附），不形成共享费米能级，其能级像气相分子一样对齐到真空能级 [page 69][page 75]。

## 从证据到结论的关键一步

整篇论证的转折点在这里：**如果 C 1s 峰位置由样品功函数决定，那么把它固定到任意值再平移整条谱线，就会引入一个等于功函数差异的系统误差**。

作者用两个具体例子展示后果。Fig. 37 比较了两种参考方法对金属核心能级的影响：用费米能级截断参考，与手册值偏差不超过 0.2 eV；用 C 1s 设在 284.5 eV 参考，Zr 3d、Y 3d、Al 2p 的偏差超过 1.5 eV [page 67]。Fig. 38 更直观：对过渡金属氮化物，用 C 1s 参考后，某些样品（TiN、VN）在费米能级处出现"无态密度"，另一些（HfN、ZrN、TaN）则出现费米能级以上的非零态密度——这在物理上是不可能的 [page 68]。作者强调，这种荒谬在核心能级谱中不易察觉，但会**悄无声息地扭曲化学键的指认**。

## 结论成立的条件与边界

作者对结论的适用范围有明确限定，这些限定本身是论证的一部分：

**替代方案只适用于导电样品。** 作者提出的补救办法是：对不易荷电的样品，补测功函数 $\phi_{SA}$，把 C-C/C-H 峰设在 $289.58 - \phi_{SA}$ eV，再平移其他谱线 [page 72][page 75]。但这要求 XPS 和 UPS 测量之间不破真空，且样品在两种测量中表面电位一致——对绝缘体，这个条件不成立，因为 XPS 和 UPS 会导致不同的表面荷电状态 [page 72]。

**对绝缘体，作者明确表示没有可靠方法。** 他们写道："no reliable referencing method involving AdC for non-conducting samples"，但同时强调"no method is, however, better than an incorrect method"（没有方法好过错误的方法）[page 76]。这是一个重要的态度：与其用一个已知不可靠的参考，不如承认无法参考。

**$E_F^B + \phi_{SA} = 289.58$ eV 这个数值本身有边界。** 它是在特定谱仪、特定泵系统（涡轮泵+离子泵，主要残余气体为 H₂O 46%、CO₂ 30%、CO/N₂ 24%）、特定 AdC 状态下测得的 [page 54]。作者也指出，功函数本身随 AdC 暴露时间变化约 1 eV（Fig. 42），所以不能简单套用文献值，必须对具体样品状态实测 [page 70][page 71]。

**作者承认的局限还包括**：他们无法直接验证绝缘体是否也遵循真空能级对齐，只能"没有理由怀疑"它成立 [page 72]；Auger 参数法虽然物理基础更扎实，但数据库有限、谱线宽、对非均匀样品不适用，使用率持续下降（Fig. 20）[page 39][page 40]。

## 这篇综述真正在论证什么

表面上看，这是一篇关于"如何正确参考 XPS 结合能"的技术综述。但它的论证结构实际上是一个**证伪**：它没有提出一个完美的新方法，而是系统性地证明了一个被广泛接受的前提（C 1s 峰位置恒定）是错的，并给出了错误的机制和量级。

作者反复强调的一点是：**问题不在于 AdC 这个方法"不够好"，而在于它被用在了它根本不适用的情况上**——尤其是导电样品，它们本来有费米能级截断这个可靠的内部参考，却仍然被习惯性地用 C 1s 参考 [page 76]。作者在结论第 15 条写道：只有当没有内部参考（如费米能级截断）可用时，才应该考虑 AdC 参考 [page 76]。

从论证力度看，最扎实的部分是荷电效应的排除（四条独立证据）和功函数相关性的建立（近百样品、斜率 −0.994）。相对较弱的是对绝缘体的推断——作者自己标注为"没有理由怀疑"而非"已证实"。这个诚实的边界标注，反而增强了整篇论证的可信度。

作者最后把矛头指向了社区实践：ASTM 和 ISO 的参考指南需要修订，期刊编辑应该要求作者报告 C 1s 谱和样品历史，数据库应该剔除参考方法描述不足的数据 [page 78][page 79]。他们甚至提供了一个实验报告模板（Sec. 6.1），要求明确记录合成方法、储存时间、环境、转移过程等 [page 77]。这些建议的潜台词是：**如果参考方法本身不可靠，那么至少要让读者知道你是怎么做的，以便判断结果的可信度**。
