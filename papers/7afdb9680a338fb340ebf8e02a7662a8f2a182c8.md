# 捷径学习：当深度网络“答对了，但答错了”

原文题名：*Shortcut Learning in Deep Neural Networks*（2020，Nature Machine Intelligence，DOI: 10.1038/s42256-020-00257-z）

## 一个统一诊断：把分散的失败看成同一种病

这篇 perspective 的核心主张并不复杂，但野心很大：深度神经网络（DNN）在各类任务中暴露出的许多看似无关的失败——图像分类被背景或纹理带偏、语言模型靠关键词而非理解作答、强化学习智能体钻奖励函数的空子、招聘算法放大性别偏见——可以被归为同一个底层问题的不同症状，即**捷径学习（shortcut learning）**。作者给捷径下的定义是：在标准基准（i.i.d. 测试）上表现良好，却无法迁移到更严苛测试条件（如真实场景）的决策规则 [page 1]。

这个定义的关键在于它把“表现好”和“学到了正确的东西”拆开了。作者反复强调，捷径学习最危险的地方不是模型失败，而是模型在错误的理由上成功——它看起来解决了问题，实际上只是抓住了数据中某个与标签偶然相关的特征。因此论文的真正目标不是列举失败案例，而是提供一个统一的诊断框架，并据此提出评估和改进的规范。

## 从直觉到形式：决策规则的分类学

论文的论证骨架建立在一个四层嵌套的分类学上（Figure 3, [page 6]）。作者从最宽泛的“所有可能决策规则”出发，逐层加约束，直到逼近“意图解”：

1. **所有可能规则**，包括那些连训练数据都解决不了的无效规则（用无信息特征，如“检测到白色像素就判为星星”）。
2. **训练解**，包括过拟合解——在训练集上正确，但在 i.i.d. 测试集上失败（用了过拟合特征）。
3. **i.i.d. 测试解**，包括捷径——在训练集和 i.i.d. 测试集上都好，但在分布外（o.o.d.）测试上失败。
4. **意图解**——使用“意图特征”，在 i.i.d. 和 o.o.d. 测试上都能按预期工作。

这个分类学的论证力量在于：它说明**仅靠 i.i.d. 测试无法区分捷径解和意图解**。在玩具实验（Figure 2, [page 5]）中，星星和月亮的位置在训练和 i.i.d. 测试中始终与类别相关，一个三层全连接网络因此学会了“按位置分类”。只要测试数据保持同样的位置-类别相关，这个策略就完美工作；一旦位置被随机化（o.o.d. 测试），性能立刻跌到随机水平。作者特别指出，卷积网络因架构先验而不会走这条捷径 [page 6, 脚注3]——这为后文“归纳偏置决定哪些解容易被学到”埋下伏笔。

这里有一个作者明说但容易被忽略的要点：**哪个解是“意图解”本身带有观察者视角**。在玩具例子里，人类直觉是按形状分类，但“意图”并非数据中客观存在的标签，而是任务设计者的期望。作者承认“意图解在旁观者眼中” [page 6]，这为后文“意图解对复杂问题往往无法形式化”的讨论做了铺垫。

## 捷径从何而来：数据机会与判别式学习的合谋

论文把捷径的来源拆成两个必须同时考虑的因素：数据中的**捷径机会**，以及模型如何**组合特征**形成决策规则 [page 7]。

**数据侧**：捷径机会往往来自自然存在的系统性关联。牛通常出现在草地上，于是“检测草地”成为识别牛的可行策略；一旦牛出现在海滩，模型就失败 [page 7]。作者强调，这类数据集偏差不会因为把数据量扩大几个数量级就消失——“大数据”中依然存在系统性偏差，数据本身很少能充分约束模型，数据不能替代假设 [page 7]。这里引出的“归纳偏置”概念（模型所有假设的总和）是后文 Box II 的核心。

**模型侧**：判别式学习与生成式建模不同，它只挑“足以在给定数据集上可靠区分”的特征，而不管这些特征如何与其他定义对象的属性组合 [page 8]。这解释了为什么 DNN 会强烈依赖纹理而忽略全局形状 [page 8]，甚至有些决策规则只依赖单个预测像素 [page 8]。作者用“猫的图片被加上大象纹理后，标准 DNN 判为大象”这个例子说明：模型用了纹理这个重要属性，却把它等同于对象的定义，漏掉了形状等其他属性。

这里有一个值得注意的推理转折：**忽略某些证据本身可以是好事**。对象识别中我们希望模型对物体平移不变；但“不想要的不变性”（excessive invariance）则有害，现代模型可以对人类依赖的几乎所有特征都不变 [page 8]。这个区分很重要，因为它说明捷径不是“用了太少的特征”这么简单，而是“用了错误组合的特征”。

## 泛化失败不是不会泛化，而是泛化错了方向

论文对泛化的讨论有一个反直觉的论点：DNN 并不缺乏 o.o.d. 泛化能力（Figure 4, [page 9]）。它们能把只含抽象图案的图片高置信度判为“吉他”，能把白噪声、飞机、猫判成同一类。问题不是泛化能力弱，而是**泛化的方向与人类意图不符**。作者由此提出一个精炼的表述：泛化失败既不是学习失败，也不是完全无法泛化，而是“未能朝意图方向泛化”；泛化与鲁棒性可以看作捷径学习的另一面 [page 9]。

这个论点的论证价值在于它重新定位了问题的性质。如果 DNN 只是泛化能力差，那增加数据、增强正则化可能就够了；但既然它们泛化能力很强、只是方向错了，那么问题的根源在于**特征选择**——用一组特征就意味着对其他特征不敏感，只有当所选特征在分布偏移后仍然存在，模型才能 o.o.d. 泛化 [page 9]。

## 跨领域的同一模式

论文用一节（Section 5）展示这个模式在四个领域的表现，论证策略是“同一机制，不同外衣”：

- **计算机视觉**：微小平移、旋转、噪声、背景或纹理变化都能彻底改变预测 [page 10]。对抗样本被解释为捷径学习的后果之一——那些人类不可见的扰动，修改的正是 DNN 用来分类的高预测性模式 [page 10]。
- **自然语言处理**：BERT 学会了“检测到‘not’就能在论证数据集上超过随机水平”，无需理解句子内容 [page 10]。作者指出，BERT、GPT-2 这类无监督预训练并未解决捷径问题 [page 10]。
- **智能体/强化学习**：算法学会“暂停游戏”来避免失败，而非学会玩俄罗斯方块 [page 10]；奖励函数中的漏洞导致 reward hacking；仿真到现实的“现实鸿沟”可视为对仿真细节的窄化捷径学习 [page 10-11]。
- **公平性与算法决策**：亚马逊招聘工具偏好男性，即使去掉姓名，模型仍从“女子学院名称”推断性别 [page 11]。作者谨慎地限定：**只有部分**公平性问题与捷径学习相关，而非全部 [page 11]。

这一节的论证功能是归纳性的：如果同一机制能在如此不同的领域反复出现，那么把它当作一个统一问题来研究就是合理的。但作者也明确承认，这个清单不是穷尽的，选择偏向计算机视觉是因为那里例子最容易可视化 [page 3]。

## 诊断三步：从“摩根法则”到 o.o.d. 测试

论文的实践建议部分（Section 6）是全文论证最具体的落点，可以理解为三个递进的诊断动作。

**第一步是谨慎解释结果**。作者提出两个工具。其一是区分数据集与底层能力：ImageNet 本意测量“对象识别”，但 DNN 似乎主要靠“数纹理块” [page 11]；一个数据集只有在它是所关心能力的良好代理时才有用。其二是借用比较心理学的**摩根法则**，作者将其改写为机器学习版本：“绝不要将可以用捷径学习充分解释的现象，归因于高级能力” [page 12]。这个法则的论证力量在于它把举证责任转移了：声称模型具备高级能力的人，需要排除捷径解释。配套的做法是测试“令人惊讶的强基线”——比如只用局部特征做对象识别、只靠单个线索词做推理、不给模型看视频就回答关于视频的问题 [page 12]。

**第二步是把 o.o.d. 泛化测试变成标准实践**。作者用教育学的类比来论证：多项选择题奖励表面学习（Bob 靠死记硬背拿高分），论文题则鼓励深层学习（Alice 靠理解）[page 13]。i.i.d. 测试就像多项选择题，无法区分意图解和捷径解。作者提出好的 o.o.d. 测试应满足三个条件：存在明确的分布偏移；有明确定义的意图解（白噪声测试虽技术上是 o.o.d.，但没有解）；当前多数模型在此失败 [page 13]。Box I 列出了一批有希望的基准，包括对抗攻击、去除捷径的 ARCT、线索冲突刺激、ImageNet-A/C、ObjectNet、PACS 以及 Shift-MNIST 等受控玩具数据集 [page 14]。

**第三步是理解为什么捷径容易被学到**。作者借用语言学的“省力原则” [page 14]，并把它落到机器学习的四个组件上（Box II, [page 15]）：架构（结构）、训练数据（经验）、损失函数（目标）、优化（学习）。这四个组件共同决定模型的归纳偏置，即哪些解容易被学到。作者给出几个具体机制：交叉熵损失鼓励模型一旦找到简单预测器就停止学习，修改后可以迫使网络使用所有可用信息 [page 15]；随机梯度下降及其变体偏向学习简单函数 [page 15]；大学习率导致学习跨样本共享的简单模式，小学习率促进复杂模式学习和记忆 [page 15]。作者也坦承，训练方法与架构之间的复杂交互目前理解很差，只有在简单情形下才能下强结论 [page 15]。

## 结论的边界与作者承认的局限

论文的结论强度需要仔细界定。作者明确承认：**完全克服捷径学习可能是不可能的** [page 18]。这是一个重要的限定——论文主张的是“任何进展都会让学到的解与意图解更对齐”，而非“捷径学习可以被消除”。

几个具体的边界条件值得注意。第一，意图解对复杂问题往往无法形式化，因此只能从例子中估计，而例子的选择会影响意图解能被逼近到什么程度 [page 6]。第二，o.o.d. 测试本身需要随模型演化而演化——Winograd Schema Challenge 最初为克服图灵测试的捷径而设计，后来被发现含有比预想更多的捷径机会 [page 13]。第三，公平性问题只有部分与捷径学习相关，作者没有声称这个框架能解释所有偏见 [page 11]。第四，关于归纳偏置各组件交互的强主张，作者限定“只在简单情形下”成立 [page 15]。

还有一点是分析者需要指出的：论文的论证主要是**概念统一和案例归纳**，而非定量证明。它没有提供一个可操作的判据来事先判断某个模型是否在走捷径，也没有给出捷径学习的形式化定义（虽然提到了 covariate shift、anti-causal learning 等相关概念 [page 3]）。因此，论文的贡献更适合理解为“提出一个诊断视角和一套评估规范”，而非“解决了一个技术问题”。作者自己也是这样定位的——他们希望“促进跨社区讨论，发起一场推动新泛化范式的运动” [page 18]。

## 论证的关键一步在哪里

如果要在整篇论文中找一步最关键的推理，那就是：**把“在 i.i.d. 测试上表现好”与“学到了意图解”之间的等价关系切断**。这一步之所以关键，是因为当前机器学习实践的大部分评估体系都默认这个等价关系成立。一旦切断，后续所有主张——需要 o.o.d. 测试、需要摩根法则、需要理解归纳偏置——都成为逻辑上的必然。而支撑这一步的证据，正是那些“在标准基准上成功、在稍有不同的条件下失败”的案例集合。论文的力量不在于任何单个案例的新颖性（作者承认许多元素早已被识别 [page 11]），而在于把这些案例组织成一个连贯的论证，说明它们不是孤立的工程 bug，而是同一个结构性问题的表现。
