# 以氧化还原反应实现甲硫氨酸化学选择性生物偶联：ReACT 策略的论证分析

**原文题名**：Redox-based reagents for chemoselective methionine bioconjugation
**年份**：2017　**DOI**：https://doi.org/10.1126/science.aal3316

## 问题的起点：为什么甲硫氨酸难以被选择性标记

论文的核心主张是：通过氧化还原反应而非传统的酸碱亲核反应，可以实现对甲硫氨酸的高选择性、快速、稳健的生物偶联，并将这一方法（ReACT，redox-activated chemical tagging）应用于蛋白质功能化、抗体-药物偶联物（ADC）合成以及全蛋白质组中高反应性甲硫氨酸的鉴定 [page 1]。

作者首先交代了动机。半胱氨酸的偶联方法已经非常成熟，依赖硫醇/硫醇盐侧链的高亲核性，可用马来酰亚胺、卤代烷等亲电试剂实现选择性标记 [page 1]。相比之下，甲硫氨酸的偶联长期不成熟。原因在于其亲核性较弱，在生理 pH 下无法用传统"寻找合适亲电配体"的思路实现选择性——因为半胱氨酸、赖氨酸、酪氨酸、丝氨酸等竞争性氨基酸的亲核性更强 [page 1]。此前的方法多使用强亲电试剂在低 pH 下将甲硫氨酸转化为锍盐，条件苛刻 [page 1]。

作者还给出了一个有利的结构性事实：甲硫氨酸是脊椎动物中最疏水、第二稀有的氨基酸，多数残基埋藏在蛋白质内部，因此表面可及的甲硫氨酸数量有限，反而成为高度选择性修饰的潜在把手 [page 1]。这一"稀有性即优势"的判断，是后续抗体应用论证的关键前提。

## 从模型底物到反应条件：ReACT 的化学基础

作者以 N-乙酰-L-甲硫氨酸甲酯（S1）为模型底物，在 CD3OD/D2O 溶剂中筛选硫亚胺化反应，用 ¹H NMR 监测转化率和选择性，区分目标 N-转移产物（NTP，磺酰亚胺）与副产物 O-转移产物（OTP，亚砜）[page 1]。过渡金属催化的硫亚胺化反应均告失败，要么无转化，要么只生成亚砜 [page 1]。但使用氧氮杂环丙烷（oxaziridine）1（Ox1）时，无需额外催化剂，2.5 分钟内即实现 95% 转化，NTP:OTP = 5:1 [page 1]。

随后作者通过调节氧氮杂环丙烷上的取代基优化选择性：将氨基甲酸酯换成较弱的吸电子脲（Ox2），NTP:OTP 提升至 12:1；在苄位引入 CF3（Ox3）反而使选择性和转化率都下降（NTP:OTP = 2:1，转化率 58%），作者归因于位阻增大 [page 1]。更关键的是溶剂效应：将水比例从 0 提高到 95%，NTP:OTP 从 6:1 改善到 18:1 [page 1]。作者提出的解释是，水通过溶剂化和氢键稳定了通往中间体 A 的过渡态（该过渡态涉及正在形成的烷氧负离子），这与先前假设一致 [page 1]。这一溶剂效应是论证"该反应适用于生物环境"的重要桥梁——因为生物体系正是水相。

反应机理方面，作者提出甲硫氨酸的硫醚进攻氧氮杂环丙烷环的 N 原子或 O 原子，随后 N–O 键断裂分别生成中间体 A 或 B，再经分子内重排生成 NTP 或 OTP，同时释放相应的醛或亚胺 [page 1]。这一机理是理解选择性的基础：N 进攻路径对应目标产物，O 进攻路径对应副产物。

## 选择性的证据链：从单一蛋白到全蛋白质组

ReACT 选择性的核心证据来自多个层次。在氨基酸竞争实验中，作者测试了其他生物相关氨基酸，均未观察到偶联产物；只有甲硫氨酸给出连接产物。半胱氨酸和硒代半胱氨酸被氧化为胱氨酸形式，但未形成 NTP [page 1]。这说明 ReACT 对甲硫氨酸的选择性优于其对硫的同系物。

在 HeLa 细胞裂解液中，用 Ox4 处理、胰酶消化后进行 LC-MS/MS 分析，检测到 235 个甲硫氨酸残基被标记，仅 1 个赖氨酸残基被标记，未检测到半胱氨酸或其他亲核氨基酸的修饰 [page 2]。这一从单蛋白到全蛋白质组的一致性，是"近乎完美选择性"主张的主要支撑。

产物稳定性方面，磺酰亚胺连接对酸、碱条件以及强还原剂 TCEP 均表现合理稳定性；对 80°C 短时（1 小时）稳定，但长时间（18 小时）会显著分解 [page 2]。这一限制在后续应用（如需要长时间高温处理的场景）中需要纳入考量。

## 动力学与蛋白质标记：速度与位点选择性

在 BSA 模型蛋白上，作者采用两步标记：先用带炔基的 Ox4 处理 15 mM BSA，再通过 CuAAC 连接 Cy3-叠氮 [page 2]。ReACT 在 1–2 分钟内即可完成，产率 >95%，加入 Ox4 后前 5 秒内即完成 50% 标记 [page 2]。甲硫氨酸（5–40 倍过量）与 Ox2 在 PBS 中的二级速率常数为 18.0 ± 0.6 M⁻¹ s⁻¹，与 CuAAC 反应相当 [page 2]。这些数据支撑了"快速"这一主张。

在钙调蛋白（CaM）上，作者利用其 9 个氧化还原活性甲硫氨酸验证了 ReACT 对氧化状态的区分能力：过氧化氢预处理导致 Ox4 标记剂量依赖性下降，因为甲硫氨酸被氧化为对 ReACT 不敏感的亚砜 [page 3]。LC-MS/MS 仅检测到甲硫氨酸携带修饰 [page 3]。这为"ReACT 可区分氧化与未氧化甲硫氨酸"提供了直接证据。

在多种含炔基/叠氮的氧氮杂环丙烷探针（1 mM）与 100 mM CaM 的反应中，ReACT 在 10 分钟内对全部 9 个天然甲硫氨酸实现近定量标记，对唯一副产物（8 个磺酰亚胺 + 1 个亚砜）的选择性为 25:1 [page 3]。生物素、荧光团、PEG 等载荷的进一步功能化均顺利进行 [page 3]。

## 抗体偶联：从"无背景"到可控药物-抗体比

抗体应用是论文的重要转折。作者指出，GFP-Fab 的轻链有 1 个、重链有 2 个天然甲硫氨酸，但均不表面可及，即使高探针负载也不被标记 [page 3]。这一"无背景标记"特性反而成为优势：野生型 Fab 无背景，而通过工程化引入表面可及甲硫氨酸即可实现定点功能化。作者用 THIOMab 平台将重链 A114 或轻链 V205 替换为甲硫氨酸，实现了高效标记 [page 3]；在带 C 端甲硫氨酸的 GFP-Fab-CM 上实现了快速、近定量、位点特异的 C 端标记 [page 3]。

功能验证方面，叠氮化 GFP-Fab 对 GFP 配体的结合亲和力与野生型相似 [page 3]；Cy3 标记的 GFP-Fab 在 Dox 诱导细胞表面 GFP 表达的 HEK-293T 细胞中与 GFP 信号共定位，无 Dox 对照无 Cy3 信号 [page 3]；Cy3 信号在 100% 胎牛血清中至少稳定 14 天 [page 3]。

在治疗性 Her-Fab 上，作者在轻链 C 端工程化 1 或 2 个甲硫氨酸，ReACT 分别实现近定量偶联，得到定义明确的药物-抗体比（DAR）[page 3]。作者强调，这是半胱氨酸或赖氨酸偶联难以实现的——后者通常难以控制 DAR [page 3]。将 MMAE 连接到 Her-Fab 得到的 ADC 对 Her2 阳性 BT474 乳腺癌细胞的毒性比野生型 Her-Fab 或 Her-Fab 与游离 MMAE 混合物高 5 倍（EC50 = 0.015 ± 0.007 vs 0.086 ± 0.02 和 0.096 ± 0.04 mg/mL）[page 4]。

需要指出，图 3D 中 Her-Fab2-N3 的质谱数据存在一处可疑：正文写"expected mass 48958 Da, found 47958 Da"，两者相差 1000 Da，疑为 OCR 或排版错误 [page 4]。这一疑点不影响 DAR 可控这一整体结论，但具体数值应以原文为准。

## 化学蛋白质组学：从已知靶点到新功能位点

论文最后将 ReACT 用于 TOP-ABPP，通过低、中、高剂量 Ox4 处理 HeLa 细胞裂解液，鉴定高反应性甲硫氨酸 [page 4]。低、中、高剂量分别鉴定到 116、458、1111 个携带 ReACT 修饰的肽段 [page 4]。低剂量组富集的高反应性甲硫氨酸靶蛋白涵盖酶、伴侣蛋白、核蛋白和结构蛋白等多种类别 [page 4]。即使高剂量探针，一般也只鉴定到表面可及的甲硫氨酸，说明 ReACT 在这些标记条件下不破坏或变性蛋白质 [page 4]。

作为阳性对照，作者在肌动蛋白中鉴定到 3 个高反应性甲硫氨酸，包括此前已知在活细胞中控制肌动蛋白聚合的 Met44 和 Met47 [page 4]。这一验证为方法可靠性提供了独立支撑。

在此基础上，作者鉴定到烯醇化酶（enolase）上的 3 个高反应性甲硫氨酸，其中 Met169 从酵母到哺乳动物高度保守（对应酵母烯醇化酶 1 的 Met171），靠近酶活性位点，且可在氧化剂处理下被氧化 [page 4]。功能验证采用酵母同源物：野生型酵母烯醇化酶 1 经次氯酸盐处理后活性下降，伴随包括 Met171 在内的甲硫氨酸氧化；M371L 突变体同样下降；但 M171L 突变体活性不受氧化剂影响 [page 4]。动力学测量显示，野生型经氧化后 Kcat 和 Km 均受影响，而 M171L 突变体这些值保持不变 [page 4]。在酵母双敲除背景中回补野生型或 M171L 突变体，M171L 菌株对氧化应激诱导的细胞死亡更具抗性 [page 4]。作者据此认为该甲硫氨酸残基在体内发挥功能性氧化还原作用 [page 4]。

## 结论成立的条件与边界

ReACT 的核心主张——化学选择性甲硫氨酸偶联——在论文证据范围内成立，但有几个条件需要明确。

第一，选择性依赖于甲硫氨酸的氧化还原反应性，而非亲核性。这意味着已被氧化的甲硫氨酸（亚砜）不再被标记 [page 3]，这既是区分氧化状态的工具，也意味着 ReACT 无法标记已氧化的残基。

第二，表面可及性是关键限制。多数甲硫氨酸埋藏在蛋白质内部，ReACT 不标记这些残基 [page 3, page 4]。这既是选择性的来源，也意味着天然蛋白质上可标记位点有限，实际应用往往需要工程化引入表面可及甲硫氨酸。

第三，产物稳定性有限。磺酰亚胺连接在长时间高温（80°C，18 小时）下会显著分解 [page 2]。对于需要此类条件的下游应用，这一限制需要考虑。

第四，全蛋白质组选择性数据中仍检测到 1 个赖氨酸标记 [page 2]，说明选择性虽高但并非绝对。作者用"near-perfect"描述，措辞谨慎。

第五，抗体 ADC 的细胞毒性数据来自体外细胞实验 [page 4]，论文未提供体内药效或安全性数据，因此"治疗应用"的推断应限于体外验证层面。

第六，烯醇化酶 Met171 的功能结论基于酵母模型 [page 4]，作者将其与哺乳动物蛋白的保守性和氧化敏感性联系，但哺乳动物体内的功能验证未在本文中完成。作者用"suggesting"描述该残基对氧化还原调控的关键作用 [page 4]，语气与证据强度匹配。

总体而言，论文的论证链条清晰：从模型底物的反应筛选，到溶剂效应和机理推断，到单蛋白和全蛋白质组的选择性验证，再到动力学、抗体偶联和化学蛋白质组学的应用展示。关键推理转折在于用氧化还原反应替代酸碱亲核反应——这一策略转换绕开了甲硫氨酸亲核性弱的根本障碍，同时利用其可被氧化的特性实现选择性。结论的适用范围受限于表面可及性、氧化状态和产物稳定性，作者在文中对这些边界有明确交代。
