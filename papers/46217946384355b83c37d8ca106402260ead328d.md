# 当偏误落在哪一边：PLS 与 CBSEM 的估计哲学之争

**Estimation issues with PLS and CBSEM: Where the bias lies!**（2016，DOI: 10.1016/j.jbusres.2016.06.007）

## 一场争论被放错了焦点

Sarstedt、Hair、Ringle、Thiele 与 Gudergan 这篇文章的出发点，是当时围绕偏最小二乘路径建模（PLS）的一场激烈争论。争论的一方主张研究者应彻底放弃 PLS，甚至宣称“PLS 根本没有任何用处”[page 1]；另一方则为其辩护。作者认为，双方往往都给出了不完整或错误的理由，而混乱的根源在于一个被普遍忽视的区分：**测量模型的设定方式**（反映式还是形成式）与**估计方法所假设的数据模型**（共同因子模型还是复合模型）是两件不同的事 [page 2]。

文章的核心主张可以概括为一句话：**当研究者不知道数据究竟来自共同因子总体还是复合总体时，PLS 是更安全的选择**，因为用 PLS 估计共同因子模型所产生的偏误相对温和，而用 CBSEM（或 PLSc）去估计复合模型数据则会产生严重偏误 [page 2, page 8]。支撑这一主张的，是一套概念澄清加上一项复制并扩展的模拟研究。

## 先把概念拆开：测量与估计是两个层面

作者花了相当篇幅做概念清理，因为这是整个论证的地基。

他们区分了三个层次：概念变量（理论模型中的抽象概念）、构念（统计模型中代表概念变量的实体）、以及代理（proxy）。关键论点是：**任何测量都只是概念变量的近似或代理**，无论它如何被推导出来 [page 3]。构念并非概念变量的完美对应物，它带有数据的特异性，也受制于概念定义本身的模糊性。作者引用 MacCallum 等人的话说，因子分析模型“充其量只是对现实世界现象的近似”[page 3]。

在这个前提下，测量模型的**概念化**有两条路：反映式测量把指标视为构念的、带有误差的表现（式 1：$x = \lambda \cdot Y + e$），指标之间应高度相关且可互换；形成式测量则把指标视为构念的构成成分，指标变化先于构念变化 [page 3]。作者进一步指出，形成式测量内部还要再分：**因果指标**（causal indicators）对应的构念带有误差项 $z$（式 2：$Y = \sum w_i x_i + z$），而**复合指标**（composite indicators）对应的构念没有误差项（式 3：$Y = \sum w_i x_i$）[page 4]。这一区分对应图 1 中的 Y2 与 Y3。

这里有一个作者自己承认的模糊地带：Bollen 认为“误差项缺失”的情形恐怕很少见，而作者则倾向于把潜变量都看作概念变量的代理，这反而模糊了复合指标与因果指标的界限 [page 5]。他们没有强行解决这个分歧，而是把它作为概念现状如实呈现。

## 估计哲学的分野

概念层面之后，作者转向估计层面，这是论证的转折点。

CBSEM 把每个指标的方差拆成共同方差与独特方差，只用共同方差求解，因此遵循**共同因子模型**的估计逻辑，与反映式测量的哲学一致 [page 5]。PLS 则不拆分方差，目标是解释观测指标的总方差，把指标线性组合成复合变量作为潜变量的代理，因此遵循**复合模型**的估计逻辑 [page 6]。

关键的一步在这里：**PLS 的“复合”属性只关乎它如何表示构念，而不限制测量模型怎么设定**。无论测量模型是反映式还是形成式，PLS 在估计参数时总是计算复合变量 [page 6]。作者由此推出三点：其一，PLS 无法显式建模因果指标的构念层误差项，只能近似；其二，当共同因子模型成立时，PLS 会产生“有偏”估计——但这不该叫偏误，因为两种方法估计的本来就是不同的东西；其三，PLS 的 Mode A（相关权重）与 Mode B（回归权重）都产出复合变量，Mode A 是反映式构念的默认，Mode B 是形成式构念的默认 [page 6]。

作者还引用了 Becker 等人的发现：对于形成式构念，当样本量大于 100 且 $R^2$ 中等偏大（$R^2 \geq 0.30$）时，Mode A 的样本外预测更好；在参数精度上，样本量或 $R^2$ 较小时 Mode A 表现最佳 [page 6]。这些细节为后文“PLS 在多种条件下都稳健”的判断提供了铺垫。

## 模拟研究：把偏误逼到台面上

论证的实证核心是两项模拟研究，它们复制并扩展了 Reinartz 等人（2009）的研究。原研究只假设共同因子模型，作者额外生成了复合模型数据，并加入了对 PLSc 的考察 [page 7]。

模拟模型（图 2）沿用 Reinartz 等人的路径结构，路径系数设为低（0.15）、中（0.30）、高（0.50）三档，并新增一个构念 Y5 及两条零路径 p7、p8。所有测量模型都是反映式的 [page 7]。研究 I（共同因子模拟）操纵指标数（2、4、6、8）、载荷（等值 0.50/0.70/0.90 或不等值 0.50/0.90）、数据分布和样本量（100 到 10,000），共 72,000 个数据集；研究 II（复合模拟）操纵指标数、权重（等权或不等权）和样本量，共 36,000 个数据集 [page 7, Table 1]。评价指标是平均绝对误差 MAE（式 4）[page 7]。

结果呈现出鲜明的非对称性。

**在共同因子数据上**（表 2），PLS 的 MAE 在测量模型只有两个指标或载荷较低（0.50）时约为 0.10，随指标数或样本量增加而下降，符合“大样本一致性”。CBSEM 在几乎所有条件下 MAE 都更低，唯独样本量为 100 时例外。PLSc 在小样本（100）下 MAE 高达 0.34，在 250 观测且指标少或载荷低时也表现不佳，但随着指标增多和样本量增大而明显改善。总体平均：PLS 与 PLSc 均为 0.07，CBSEM 为 0.05 [page 8]。作者的评价是：三种方法在共同因子数据上的差异“总体上只是边际性的”。

**在复合模型数据上**（表 3），画面完全反转。PLS 总体 MAE 为 0.04；CBSEM 为 0.76；PLSc 高达 3.70，且在各条件下从 0.64 到 17.89 剧烈波动，某些条件下（4 指标、等权、500 或 10,000 观测）MAE 甚至超过 10 [page 8]。作者为排除 matrixpls 实现问题，用 semPLS 扩展重跑，结果支持 PLSc 偏误的幅度与波动。CBSEM 的偏误在所有条件下都很明显，但水平低得多（0.51 到 1.72）。作者特别指出：**CBSEM 估计复合模型的偏误平均是 PLS 估计共同因子模型偏误的 11 倍** [page 8]。更关键的是，PLS 的 MAE 随样本量增大而下降，而 CBSEM 和 PLSc 没有这种清晰模式——PLSc 在某些条件下甚至先降后升再降。

表 4 汇总了本文结果与既有文献，按数据总体类型（共同因子 vs. 复合）和测量操作化（效应指标、因果指标、复合指标）交叉呈现三种方法的适用性。PLS 在复合总体下（无论效应指标还是复合指标）都获推荐；CBSEM 在共同因子总体下（效应指标）获推荐，但在复合总体下（效应指标）被标为“不推荐”；PLSc 在复合总体下（效应指标）同样被标为“不推荐”[page 10, Table 4]。

## 关键推理与它的边界

从证据到结论，作者走的关键一步是：**既然研究者通常无法确知数据的真实性质，那么应当选择在两种情形下都不会造成灾难性偏误的方法**。PLS 在复合数据上几乎无偏，在共同因子数据上偏误虽存在但绝对值低；CBSEM 和 PLSc 在共同因子数据上表现优异，但在复合数据上偏误严重且不随样本量收敛。因此，在“未知总体”这一社会科学研究的普遍处境下，PLS 是更安全的选择 [page 8, page 11]。

这个推理依赖几个条件。第一，它假设研究者确实无法事先判定数据性质。作者承认，SRMR 等拟合指标可能提供线索（若 SRMR 大于 0.08 提示复合模型），CBSEM 的不当解（improper solution）也可能指向复合总体——他们发现复合模型成立时 CBSEM 在高达 99% 的情况下产生不当解 [page 11]。但作者随即指出，不当解的原因多种多样，不能简单当作复合模型的证据。他们也建议用多方法比较（CBSEM 与 PLS 结果是否一致）作为辅助判断，但明确表示在清晰指南出现之前，PLS 是“更安全的选择”[page 11]。

第二，结论的适用范围限于本文模拟的模型结构：反映式测量模型、特定的路径系数配置、特定的指标数与载荷/权重组合。作者在结论中明确列出未来研究方向：应考察层级构念模型、调节效应、非线性效应，以及 Mode A 与 Mode B 在不同测量设定与总体类型下的交互 [page 11]。他们还指出，未来研究应比较 PLS、PLSc 与 CBSEM 在“两种模型都拟合”的总体上的表现，因为 CBSEM 可能对某些复合测量表现良好而对另一些不佳 [page 11]。

第三，PLSc 的糟糕表现需要谨慎解读。作者报告了 MAE 在某些条件下超过 10 甚至 17.89 的极端值，并做了实现层面的复核，但这些数值的波动模式（先降后升再降）本身提示结果可能对具体条件敏感。作者没有给出 PLSc 偏误的解析解释，只是描述性地呈现。因此，将 PLSc 在复合数据上的表现概括为“严重偏误”是稳妥的，但具体数值不宜当作精确的、可外推的量化结论。

## 这篇文章真正在论证什么

表面上看，这是一篇关于 PLS 与 CBSEM 孰优孰劣的方法学论文。但作者真正想做的，是**把争论从“哪种方法更好”重新框定为“方法假设的数据模型与数据的真实性质是否匹配”**。他们的概念框架（图 3）把理论层、概念层、操作层与估计层分开，指出测量设定（反映式/形成式）与估计哲学（共同因子/复合）是两个独立的维度，混淆二者正是误解的根源 [page 10]。

在这个框架下，“PLS 有偏”这个说法本身就需要限定：PLS 在共同因子数据上确实产生偏离，但那是两种方法估计不同对象的自然结果，而非方法缺陷；真正严重且不对称的偏误，出现在用共同因子方法去估计复合数据的时候。作者用模拟证据把这种不对称性量化出来，并据此给出实践建议。

文章的局限也在于其证据的边界。模拟研究只能覆盖被操纵的因素，而真实研究中模型复杂度、测量质量、样本特征都远超模拟设定。作者对此有清醒认识，在结论中列出了多项未来研究议程。此外，文章对 PLSc 的处理主要是描述性的，缺乏对其偏误来源的深入分析，这使得 PLSc 相关结论的力度弱于 PLS 与 CBSEM 的对比。

总体而言，这篇文章的贡献不在于证明 PLS 在所有情形下优于 CBSEM——作者明确承认 CBSEM 在共同因子数据上表现更好——而在于揭示了一个被争论双方忽视的不对称性：**当数据性质未知时，选错方法的代价在两种方向上并不对等**。这一不对称性，才是“偏误落在哪一边”这个标题的真正所指。
