# 当低秩与稀疏叠加时，凸优化为何能精确分离：对 Candès 等《Robust Principal Component Analysis?》的论证分析

**作者**：Emmanuel J. Candès, Xiaodong Li, Yi Ma, John Wright
**年份**：2009（预印本，2009 年 12 月 17 日）

## 一个反直觉的分离问题

论文要回答的问题可以这样表述：给定一个数据矩阵 $M$，已知它由两部分叠加而成——一个低秩矩阵 $L_0$ 和一个稀疏矩阵 $S_0$，即 $M = L_0 + S_0$。我们不知道 $L_0$ 的秩、列空间或行空间，也不知道 $S_0$ 的非零元位置和数量，更关键的是，$S_0$ 的非零元可以任意大。能否精确、高效地恢复出这两个分量？[page 1]

从信息量上看，这似乎不可能：待求的未知量（$L_0$ 和 $S_0$ 各自的自由度）是观测数 $M$ 的两倍。但论文的核心结论是：在相当弱的假设下，通过求解一个凸优化问题——**主成分追踪（Principal Component Pursuit, PCP）**——可以精确恢复 $L_0$ 和 $S_0$：

$$\text{minimize} \quad \|L\|_* + \lambda\|S\|_1 \quad \text{subject to} \quad L + S = M \tag{1.1}$$

其中 $\|L\|_*$ 是核范数（奇异值之和），$\|S\|_1$ 是 $\ell_1$ 范数（矩阵视为长向量的绝对值之和）。论文进一步证明，当取 $\lambda = 1/\sqrt{n_{(1)}}$（$n_{(1)} = \max(n_1, n_2)$）时，这个选择是"通用的"——不依赖于 $L_0$ 和 $S_0$ 的具体性质 [page 6]。

这一结论之所以令人惊讶，不仅因为它用凸松弛替代了组合优化，更因为它允许 $S_0$ 的非零元比例达到常数级别（而非趋于零），同时允许 $L_0$ 的秩随矩阵维度几乎线性增长。

## 可辨识性的前提：为什么需要"非相干"和"随机支撑"

在陈述主定理之前，论文先交代了问题在什么条件下才有意义。这里有两个根本性的可辨识性障碍 [page 4–5]。

第一个障碍来自低秩与稀疏的重叠。如果 $L_0$ 本身就是一个稀疏矩阵（例如 $M = e_1 e_1^*$，只有一个非零元），那么它既可以被视为低秩，也可以被视为稀疏，分解方式不唯一。为排除这种情况，论文引入了**非相干性（incoherence）**条件，要求 $L_0$ 的奇异向量"足够分散"，不集中在少数坐标上。具体地，对 $L_0 = U\Sigma V^*$，要求：

$$\max_i \|U^* e_i\|_2 \leq \frac{\mu r}{n_1}, \quad \max_i \|V^* e_i\|_2 \leq \frac{\mu r}{n_2} \tag{1.2}$$

$$\|UV^*\|_\infty \leq \sqrt{\frac{\mu r}{n_1 n_2}} \tag{1.3}$$

其中 $\mu$ 是非相干参数，$r$ 是秩。$\mu$ 越小，奇异向量越分散。这一条件借自矩阵补全文献 [8]，其作用是确保低秩分量不会"伪装"成稀疏分量。

第二个障碍来自稀疏分量本身可能具有低秩结构。例如，如果 $S_0$ 的所有非零元都集中在某一列，那么 $M$ 的列空间可能与 $L_0$ 的列空间重合，导致无法区分。论文的处理方式是假设 $S_0$ 的支撑集（非零元位置）在所有大小为 $m$ 的子集中**均匀随机**选取 [page 5]。这是论文中唯一的随机性假设——$L_0$ 本身是确定性的，$S_0$ 的非零元符号和大小也是任意的。

## 主定理及其证据结构

**定理 1.1**（方阵情形）[page 5]：设 $L_0$ 为 $n \times n$，满足 (1.2)–(1.3)，$S_0$ 的支撑集在所有大小为 $m$ 的子集中均匀分布。则存在数值常数 $c$，使得以概率至少 $1 - cn^{-10}$，PCP (1.1) 取 $\lambda = 1/\sqrt{n}$ 时精确恢复，即 $\hat{L} = L_0$、$\hat{S} = S_0$，只要：

$$\text{rank}(L_0) \leq \rho_r n \mu^{-1} (\log n)^{-2}, \quad m \leq \rho_s n^2 \tag{1.4}$$

其中 $\rho_r, \rho_s$ 是正常数。矩形情形的结论类似，$\lambda = 1/\sqrt{n_{(1)}}$，秩的上界涉及 $n_{(2)} = \min(n_1, n_2)$。

这个定理的证明不是通过直接分析优化问题，而是通过构造一个**对偶证书（dual certificate）**——一个满足特定条件的矩阵 $W$，其存在性保证 $(L_0, S_0)$ 是 (1.1) 的唯一最优解。整个证明架构可以概括为：将精确恢复问题转化为对偶证书的存在性问题，再用概率方法构造出这个证书。

## 对偶证书：从最优性条件到可构造对象

论文的证明核心是**引理 2.4** 和 **引理 2.5** [page 12–13]。引理 2.4 给出一个确定性条件：若存在矩阵 $W$ 满足

$$W \in T^\perp, \quad \|W\| < 1, \quad P_\Omega(UV^* + W) = \lambda \,\text{sgn}(S_0), \quad \|P_{\Omega^\perp}(UV^* + W)\|_\infty < \lambda \tag{2.3}$$

则 $(L_0, S_0)$ 是 (1.1) 的唯一解。这里 $T$ 是由 $L_0$ 的奇异向量张成的切空间 (2.1)，$\Omega$ 是 $S_0$ 的支撑集，$P_\Omega$ 是到 $\Omega$ 上矩阵的投影。

引理 2.5 进一步放宽了条件，允许 $P_\Omega(UV^* + W)$ 与 $\lambda\,\text{sgn}(S_0)$ 有小的偏差，只要 $\|P_\Omega D\|_F \leq 1/4$。这个松弛是 Gross 在矩阵补全中引入的"高尔夫方案（golfing scheme）"的关键思想 [22]，论文在此基础上做了两处修改。

**关键推理步骤**：证明定理 1.1 归结为构造一个满足 (2.4) 的 $W$。论文将 $W$ 分解为两部分：$W = W^L + W^S$，其中 $W^L$ 通过高尔夫方案构造，用于控制 $P_\Omega(UV^* + W^L)$ 的 Frobenius 范数；$W^S$ 通过最小二乘法构造，用于精确匹配 $P_\Omega W^S = \lambda\,\text{sgn}(S_0)$ [page 14–15]。

---

## 高尔夫方案与最小二乘：两个构造性引理

$W^L$ 的构造采用迭代方式。将 $\Omega^c$ 分解为 $j_0$ 个独立的 Bernoulli 集 $\Omega_j$ 的并，然后从 $Y_0 = 0$ 出发，迭代

$$Y_j = Y_{j-1} + q^{-1} P_{\Omega_j} P_T (UV^* - Y_{j-1})$$

最终令 $W^L = P_{T^\perp} Y_{j_0}$ (2.5)。这个方案的精髓在于：每一步都利用新鲜的随机集 $\Omega_j$，使得 $Z_j = UV^* - P_T Y_j$ 的 $\ell_\infty$ 范数和 Frobenius 范数都以因子 $\epsilon$ 收缩（引理 3.1 和定理 2.6）[page 17]。经过 $j_0 = 2\lceil \log n \rceil$ 步后，$\epsilon^{j_0} \leq n^{-2}$，从而 $W^L$ 满足所需的范数界。

**引理 2.8** [page 16] 断言：在上述条件下，$W^L$ 满足 $\|W^L\| < 1/4$、$\|P_\Omega(UV^* + W^L)\|_F < \lambda/4$、$\|P_{\Omega^\perp}(UV^* + W^L)\|_\infty < \lambda/4$。证明的关键是三个估计：算子范数由 Lemma 3.2 控制，Frobenius 范数由定理 2.6 控制，$\ell_\infty$ 范数由 Lemma 3.1 控制 [page 17–19]。

$W^S$ 的构造则更为直接：令

$$W^S = \lambda P_{T^\perp} (P_\Omega - P_\Omega P_T P_\Omega)^{-1} \text{sgn}(S_0) \tag{2.6}$$

这个定义保证 $P_\Omega W^S = \lambda\,\text{sgn}(S_0)$，且 $W^S \in T^\perp$。**引理 2.9** [page 16] 证明 $\|W^S\| < 1/4$ 且 $\|P_{\Omega^\perp} W^S\|_\infty < \lambda/4$。证明使用了 Hoeffding 不等式和覆盖论证，关键在于 $\|P_\Omega P_T\|$ 足够小（由推论 2.7 保证）[page 19–21]。

将 $W^L$ 和 $W^S$ 相加，即得满足 (2.8) 的对偶证书，从而完成定理 1.1 的证明。

## 去随机化：从随机符号到固定符号

定理 1.1 的陈述中，$S_0$ 的非零元符号是任意的（固定但未知）。但上述证明中，$W^S$ 的构造和分析依赖于符号是独立对称 Bernoulli 变量的假设。论文通过**定理 2.3**（去随机化）[page 11–12] 弥合这一差距：如果 PCP 在随机符号模型下以高概率精确恢复，那么在固定符号模型下也以至少相同的概率精确恢复。

证明思路是构造一个"消除矩阵" $\Delta$，使得 $S'_0 = \Delta \circ (|S| \circ E)$ 与原始 $S_0$ 同分布，同时 $|S| \circ E$ 服从随机符号模型。然后利用**定理 2.2**（消除定理）[page 10]：如果 PCP 能恢复 $L_0 + S_0$，那么它也能恢复 $L_0 + S'_0$，其中 $S'_0$ 是 $S_0$ 的"修剪版本"（部分非零元置零）。这个去随机化论证是论文的技术创新之一，作者认为它在压缩感知等领域也有应用价值 [page 6]。

## 从完整观测到缺失观测：定理 1.2

论文进一步将结果推广到部分观测且部分损坏的情形。设 $\Omega_{\text{obs}}$ 是观测位置集，$Y = P_{\Omega_{\text{obs}}}(L_0 + S_0)$。论文提出求解

$$\text{minimize} \quad \|L\|_* + \lambda\|S\|_1 \quad \text{subject to} \quad P_{\Omega_{\text{obs}}}(L + S) = Y \tag{1.5}$$

**定理 1.2** [page 8] 断言：若 $L_0$ 满足非相干条件，$\Omega_{\text{obs}}$ 均匀随机选取且 $|\Omega_{\text{obs}}| = 0.1n^2$，每个观测元以概率 $\tau$ 独立损坏，则当 $\lambda = 1/\sqrt{0.1n}$、$\text{rank}(L_0) \leq \rho_r n \mu^{-1}(\log n)^{-2}$、$\tau \leq \tau_s$ 时，PCP (1.5) 以高概率精确恢复 $L_0$。

这个定理的证明（附录 7.3）[page 32–36] 在结构上与定理 1.1 类似，但需要处理三个索引集：$\Omega_{\text{obs}}$（观测位置）、$\Gamma$（观测且干净的位置）、$\Omega$（观测但损坏的位置）。对偶证书的构造需要同时满足 $P_{\Omega_{\text{obs}}}$ 和 $P_\Gamma$ 上的约束，高尔夫方案和最小二乘构造都需要相应修改。

定理 1.2 的意义在于：它统一了矩阵补全（$\tau = 0$ 时退化为纯矩阵补全）和鲁棒 PCA（$\Omega_{\text{obs}}$ 为全集时退化为定理 1.1），并证明矩阵补全对严重损坏是稳定的 [page 8]。

## 数值实验：理论预测与经验行为的对照

论文第 4 节报告了数值实验，旨在验证理论并探索其实际适用范围 [page 21–27]。

**表 1** [page 22] 展示了随机问题的精确恢复结果。对于 $n = 500$ 到 $3000$、秩为 $0.05n$、稀疏度为 $0.05n^2$ 或 $0.10n^2$ 的矩阵，PCP 在所有情形下都正确估计了秩和稀疏度，相对误差小于 $10^{-5}$。值得注意的是，求解所需的偏 SVD 次数几乎恒定（不超过 17 次），且与矩阵维度无关。这表明算法不仅在理论上可行，而且在实际中高效。

**图 1** [page 24] 展示了秩-稀疏度相变图。左图对应随机符号的 $S_0$，中图对应 $S_0 = P_\Omega \text{sgn}(L_0)$（符号与 $L_0$ 相关），右图对应矩阵补全。一个有趣的观察是：中图的精确恢复区域实际上比左图更宽，尽管相关符号的 $S_0$ 按理说更难区分 [page 23]。作者承认这一现象"令人困惑"，但表示已被多个独立模拟实验"确认"。这里需要谨慎：这是经验观察，论文并未给出理论解释。

**图 2 和图 3** [page 25–26] 展示了视频背景建模的应用。将视频帧堆叠为矩阵 $M$，低秩分量对应静态背景，稀疏分量对应移动物体。PCP 在 $\lambda = 1/\sqrt{n_1}$ 下成功分离了两者，且结果优于基于交替最小化的 $m$-估计器方法 [47]。但作者明确指出：视频中的误差支撑并非 Bernoulli 模型（误差倾向于空间连续），因此定理并不保证算法一定成功 [page 24]。这是理论适用条件与实际应用之间的重要边界。

**图 4** [page 27] 展示了人脸图像中阴影和镜面反射的去除。类似地，作者指出误差支撑不服从 Bernoulli 模型，理论不保证成功，但实验结果"视觉上令人印象深刻"。

## 算法实现：为什么选择 ALM

第 5 节讨论了求解 PCP 的算法 [page 28–29]。内点法虽然收敛快，但复杂度 $O(n^6)$ 使其仅适用于 $n < 100$ 的小问题。一阶方法（如迭代阈值、APG）虽然可扩展，但迭代阈值收敛慢（可达 $10^4$ 次迭代），APG 的性能则强烈依赖于连续化策略的设计。

论文选择**增广拉格朗日乘子法（ALM）**，具体是交替方向法：先对 $L$ 最小化增广拉格朗日函数（通过奇异值阈值算子 $D_{\mu^{-1}}$），再对 $S$ 最小化（通过软阈值算子 $S_{\lambda\mu^{-1}}$），然后更新乘子 $Y$。算法 1 [page 29] 给出了完整流程。作者报告 ALM 在实践中比 APG 精度更高、迭代更少，且秩的迭代值通常保持在 $\text{rank}(L_0)$ 以内，使得偏 SVD 计算高效。

## 结论成立的条件与边界

综合全文，定理 1.1 和 1.2 的结论在以下条件下成立：

1. **$L_0$ 非相干**：奇异向量分散，$\mu$ 不太大。这是确定性的、对 $L_0$ 的假设。
2. **$S_0$ 支撑随机**：非零元位置均匀随机。这是唯一的随机性假设。符号和大小任意。
3. **秩和稀疏度有界**：$\text{rank}(L_0) = O(n/\log^2 n)$，$m = O(n^2)$。这是定理的定量结论。
4. **$\lambda$ 取特定值**：$\lambda = 1/\sqrt{n_{(1)}}$。论文证明这个选择是通用的，但证明也表明存在一个正确的 $\lambda$ 范围 [page 6]。

论文明确承认的局限包括：$L_0$ 必须精确低秩，$S_0$ 必须精确稀疏 [page 30]；实际应用中（视频、人脸）误差支撑不服从 Bernoulli 模型，理论不保证成功 [page 24, 27]；定理 1.2 中观测比例固定为 10%，作者预期更精细的分析可以处理更少观测 [page 8–9]。

论文未讨论但可能影响结论的因素（以下为分析推断）：非相干参数 $\mu$ 的实际取值难以先验估计；$S_0$ 的符号虽然理论上任意，但去随机化论证依赖于符号与支撑的独立性；ALM 算法的收敛性虽有文献支持，但论文未给出其收敛速率的理论保证。

## 论证的整体逻辑

这篇论文的论证可以概括为一条清晰的链条：**可辨识性条件（非相干 + 随机支撑）→ 对偶证书存在性 → 凸优化精确恢复**。核心技术创新在于将 Gross 的高尔夫方案适配到"低秩 + 稀疏"分离问题，并引入去随机化论证处理固定符号。定理 1.2 进一步将框架扩展到缺失观测，统一了矩阵补全和鲁棒 PCA。

论文的说服力不仅来自理论证明，也来自数值实验与理论预测的一致性：相变图显示的精确恢复区域与定理 1.1 的预测在量级上吻合，算法的高效性（迭代次数几乎恒定）则表明凸松弛不仅是理论上的优雅工具，也是实际可用的方法。但作者对实际应用中的理论边界保持了诚实的克制：视频和人脸实验的结果虽然视觉上令人满意，但作者反复强调这些场景不满足定理的随机支撑假设，因此理论保证不直接适用。
