# 深度学习的泛化之谜：随机标签实验如何动摇传统解释

**Understanding Deep Learning (Still) Requires Rethinking Generalization**（2021，DOI: 10.1145/3446776）

## 一个反直觉的起点

这篇论文的核心主张可以用一句话概括：**当前最成功的深度神经网络之所以能泛化，传统统计学习理论给出的解释——无论是基于模型复杂度的界，还是显式正则化——都不足以说明问题**。作者并不提出新的泛化理论，而是通过一组设计精巧的实验，逐一检验那些"看似合理"的解释是否真的站得住脚 [page 1]。

论证的起点是一个简单却令人不安的观察：深度网络可以轻松拟合完全随机的标签。这意味着，一个在自然数据上泛化良好的模型，和一个在随机标签上完全无法泛化的模型，在模型规模、优化器、超参数上可以完全一致。那么，任何不依赖于标签与输入之间关系的泛化度量，都无法区分这两种情形——而传统理论中的大多数度量恰恰如此。

## 随机标签实验：论证的核心引擎

作者的方法论借鉴了非参数统计中的随机化检验。具体操作是：保持输入图像不变，将每个标签独立地替换为从有效类别中均匀随机抽取的标签。这样，输入与标签之间的任何真实关系都被彻底破坏，泛化在原则上不可能发生 [page 1]。

如果传统理论是对的——即模型的泛化能力受限于其有效容量或正则化——那么面对随机标签，训练应该变得困难，或者至少表现出明显的异常。但实验结果恰恰相反。

在 CIFAR10 上，Inception、AlexNet 和 MLP 在随机标签下都达到了接近 100% 的训练准确率，而测试准确率降至随机猜测水平（约 10%）[Table 1, page 4]。更令人惊讶的是，训练时间只增加了很小的常数因子，学习率调度无需改变，一旦开始拟合就迅速收敛 [page 3]。在 ImageNet 上，即使有 120 万个随机标签、1000 个类别，Inception 仍达到 95.20% 的 top-1 训练准确率，且未做任何超参数调整 [page 4]。

作者进一步将随机化推向极端：不仅随机化标签，还将真实图像替换为完全随机的像素（高斯噪声），甚至对像素进行随机置换。卷积网络依然能够拟合 [page 2]。这说明，卷积结构带来的归纳偏置并不能阻止网络记忆完全无结构的数据。

在部分标签损坏的实验中，作者观察到一个平滑的过渡：随着噪声比例从 0 增加到 1，训练集始终被完美拟合，但泛化误差稳步上升，最终收敛到随机猜测水平 [Figure 1b, 1c, page 4]。这表明网络能够同时捕捉数据中剩余的真实信号，并用"暴力"拟合噪声部分。

## 这些实验排除了什么

随机标签实验的论证力量在于它构成了一个**对照**：自然数据上泛化良好，随机标签上泛化完全失败，而模型、优化器、超参数全部不变。任何声称能解释泛化的度量，必须能区分这两种情形。作者据此逐一检验了几种主流理论工具。

**Rademacher 复杂度和 VC 维度。** 这些度量衡量的是函数类拟合随机 ±1 标签的能力。但作者指出，当网络足够大时，经验 Rademacher 复杂度会达到其平凡上界，无法给出有意义的泛化界 [page 5]。换句话说，这些度量在随机标签和真实标签上给出相似的数值，因此无法解释两者泛化行为的巨大差异。

**均匀稳定性。** 稳定性衡量的是算法对单个训练样本替换的敏感度。但作者指出，均匀稳定性是算法本身的属性，不依赖于数据的标签分布 [page 5]。因此，同一个算法在真实标签和随机标签上具有相同的稳定性，却表现出截然不同的泛化行为。这一观察也解释了为什么 Hardt 等人的非凸优化分析过于悲观——它只允许极少的数据遍历次数，而实验表明网络可以多次遍历数据仍不具有均匀稳定性 [page 3]。

**显式正则化。** 作者在 CIFAR10 上关闭了数据增强和权重衰减，发现所有模型仍然泛化良好，测试准确率仅下降几个百分点 [Table 1, page 4]。在 ImageNet 上，关闭所有正则化后 top-1 准确率下降约 18%，但仍有 59.80%，远高于随机猜测的 0.1% [page 5]。更值得注意的是，仅保留数据增强就能达到 72.95% 的 top-1 准确率，说明利用已知对称性的数据增强比调权重衰减更有效。作者还测试了批归一化：移除后泛化性能仅下降 3∼4%，但训练稳定性明显变差 [Figure 2b, page 6]。这些结果支持一个谨慎的结论：显式正则化可以改善泛化，但既非必要，也不足以单独控制泛化误差 [page 2]。

## 有限样本表达性：理论补充

实验之外，作者提供了一个理论构造来支持其核心观察。定理 1 表明，一个两层 ReLU 网络，仅需 $p = 2n + d$ 个参数，就能表达 $d$ 维空间中任意 $n$ 个样本的任意标签分配 [page 6]。这与之前 Livni 等人需要 $O(dn)$ 个参数的结果相比，参数数量大幅减少。作者还指出，可以构造深度为 $k$ 的网络，每层仅需 $O(n/k)$ 个参数。

这个结果的意义在于：它说明即使是最简单的深度网络，在参数数量超过样本数量时（这在实践中几乎总是成立），就已经具备了完美记忆训练数据的能力。因此，泛化不能仅仅归因于网络表达能力的某种"适度"限制。

## 隐式正则化：线性模型的启示与局限

既然显式正则化不是答案，作者转向隐式正则化——即优化算法本身对解的偏好。他们回到线性模型这一可分析的场景 [page 6]。

对于线性模型，当数据矩阵 $X$ 满秩时，方程 $Xw = y$ 有无穷多解。作者指出，所有全局最优解的 Hessian 是相同的且退化的，因此曲率无法区分不同的全局最优解 [page 7]。但 SGD 从 $w_0 = 0$ 出发时，解必然落在数据张成的空间中，即 $w = X^T\alpha$。结合完美插值条件 $Xw = y$，得到 $K\alpha = y$，其中 $K = XX^T$ 是 Gram 矩阵。这就是核技巧的推导 [page 7]。

实验上，作者在 MNIST 上直接用高斯核求解 $K\alpha = y$，无预处理时测试误差 1.2%，加 Gabor 小波预处理后降至 0.6%，且添加正则化并未改善性能 [page 7]。在 CIFAR10 上，随机卷积特征加高斯核达到 17% 测试误差，加 $\ell_2$ 正则化后降至 15% [page 7]。

然而，作者谨慎地指出，最小范数解并不总是预测泛化性能。在 MNIST 上，无预处理时最小范数解的 $\ell_2$ 范数约为 220，小波预处理后范数升至 390，但测试误差反而减半 [page 7]。这说明最小范数直觉虽然对算法设计有启发，但只是泛化故事的一小部分。

## 结论的边界与开放问题

这篇论文的论证力度在于其实验设计的简洁性和对照的清晰性。随机标签实验之所以有力，正是因为它构造了一个"泛化不可能"的极端情形，而传统理论工具在这个情形下给出的判断与真实标签情形几乎相同。

但作者明确承认，他们不提供新的泛化理论 [page 1]。他们的结论是**否定性的**：传统解释不够用。这留下了一个开放问题——什么才是正确的解释？

作者在结论中指出，优化容易与泛化好是两个不同的问题。随机标签实验表明，即使模型不泛化，优化仍然容易 [page 7]。因此，驱动泛化的因素不能等同于使优化容易的因素。

在 6.1 节的补充综述中，作者提到后续研究的一些趋势：更紧的泛化界、PAC-Bayes 框架下的新界、对隐式正则化的重新关注，以及"双下降"风险曲线对传统 U 形曲线的扩展 [page 8]。这些工作表明，在过参数化区域，完美插值训练集（包括噪声）不一定与泛化矛盾。但作者也承认，对深度学习的完整数学刻画仍然具有挑战性。

一个值得注意的边界条件是：作者的理论构造（定理 1）针对的是有限样本表达性，而非整个函数空间上的表达性。这与传统的普适逼近定理不同，作者明确区分了这两个层面 [page 6]。此外，线性模型的分析虽然提供了直觉，但作者也指出，这些结果并不能解释为什么某些架构比另一些泛化得更好 [page 2]。

总体而言，这篇论文的贡献不在于给出答案，而在于通过一组难以反驳的实验，迫使理论研究者重新审视那些被广泛接受但可能未经严格检验的假设。随机标签实验作为一个方法论工具，其价值在于它提供了一个清晰的基准：任何泛化理论，如果不能在随机标签和真实标签之间做出区分，就还没有触及问题的核心。
