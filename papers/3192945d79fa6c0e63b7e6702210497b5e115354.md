# 二氧化碳利用与移除的技术和经济前景：一篇论证分析

**原文题名**：The technological and economic prospects for CO2 utilization and removal
**作者**：Cameron Hepburn, Ella Adlen, John Beddington, Emily A. Carter, Sabine Fuss, Niall Mac Dowell, Jan C. Minx, Pete Smith, Charlotte K. Williams
**发表**：*Nature*, Vol 575, 7 November 2019, pp. 87–97
**DOI**：https://doi.org/10.1038/s41586-019-1681-6

---

## 一、作者要论证什么

这篇 Perspective 的核心主张可以概括为一句话：**二氧化碳利用（CO2 utilization）在特定条件下可以降低减排或移除的成本，但"利用"本身并不等于"减排"或"移除"，其气候效益高度依赖反事实基准、碳来源和能源来源；十条路径各自可能扩展到每年 0.5 Gt CO2 以上，但资源约束使它们无法同时部署** [page 1]。

这个主张包含三个层次，需要分开看：

1. **概念层**：作者刻意采用了一个比主流文献更宽的定义，把土地利用类过程（林业、土壤固碳、生物炭、增强风化）也纳入"CO2 利用"，理由是这些过程同样用 CO2 生产有经济价值的产品（木材、增产的作物）[page 1]。这是全文论证的起点，也是后面所有比较得以成立的前提。

2. **规模与成本层**：作者对十条路径逐一评估 2050 年的利用/移除潜力和盈亏平衡成本，结论是每条路径都可能达到 0.5 Gt CO2 yr−1 以上的量级，但成本差异极大，从负成本（已盈利）到每吨数百美元不等 [page 1, Table 2, page 6]。

3. **条件层**：作者反复强调，利用量 ≠ 移除量 ≠ 减排量 ≠ 净气候效益，四者必须区分 [page 2, Box 1, page 5]。这一区分是全文最关键的论证枢纽。

## 二、论证的骨架：从碳循环到成本曲线

### 概念区分是第一步

作者在进入具体路径之前，先做了一个概念清理。CO2 利用（CO2u）、CO2 移除（CO2r）、CO2 储存（CO2s）、减排（CO2ρ）和净气候效益是五个不同的概念，彼此重叠但不重合 [page 2]。Box 1 用一个具体算例说明这一点：假设基准情景下化石电厂排放 1 t CO2、石油使用排放 1.5 t CO2，总计 2.5 t；在 CO2-EOR 情景下，电厂的 CO2 被注入油藏（CO2u = 1 t），总排放变为 1.5 t，减排量 = 1.0 t = CO2u，但由于 CO2 来自化石电厂而非大气，净移除 CO2r = 0 [page 5, Box 1]。

这个算例的推理关键一步是：**减排量可以等于利用量，但移除量取决于碳的来源**。如果 CO2 来自化石源，利用它只是把碳从一种化石用途转移到另一种，不构成从大气中净移除。只有当 CO2 来自大气（如直接空气捕获或光合作用），利用才可能同时构成移除。作者进一步指出，如果 CO2-EOR 产出的油替代了原本由可再生能源驱动的电动车所避免的石油消费，那么 CO2-EOR 反而导致净排放增加 [page 5, Box 1]。

这一步推理是整篇文章的逻辑基石。它意味着：**任何 CO2 利用路径的气候价值，不能从其利用量直接推断，必须追溯碳源、能源来源和反事实基准**。

### 三类路径的区分

作者把十条路径分为"循环型"（cycling）、"封闭型"（closed）和"开放型"（open）三类 [page 1–2, Fig. 1, Table 1, page 3]。这一分类不是描述性的，而是直接对应储存持久性和气候效益的差异：

- **循环型**（化学品、燃料、微藻）：碳在工业系统内循环数天到数月，最终通过使用或分解释放回大气。这类路径不提供净移除，但可以通过工业捕获替代化石燃料来减排 [page 1, Table 1]。
- **封闭型**（混凝土建材、CO2-EOR、BECCS）：碳被封存在岩石圈或矿化产物中，储存时间以世纪或千年计。这类路径可以同时利用和移除 CO2，但前提是碳源和操作方式正确 [page 1–2, Table 1]。
- **开放型**（林业、土壤固碳、生物炭、增强风化）：碳储存在生物圈和土壤中，储存时间以年到几十年计，面临火灾、病虫害和气候变化的释放风险 [page 2, Table 1]。

这一分类的论证功能在于：它把"储存持久性"变成了一个可比较的维度，从而使不同路径之间的权衡变得可见。例如，循环型路径的储存时间以天/月计（Table 1 中标注为 "high" 释放可能性），而封闭型路径以世纪/千年计（标注为 "low"）[page 3, Table 1]。

### 规模与成本的证据结构

作者对十条路径的评估方法不同，这一点值得注意：

- **常规路径**（化学品、燃料、微藻、建材、CO2-EOR）：基于对 5,000 多篇文献的范围综述（scoping review），其中 186 篇提供成本估算；规模估算辅以结构化估计过程和专家意见调查 [page 4]。
- **非常规路径**（BECCS、增强风化、林业、土壤固碳、生物炭）：建立在已有的 CO2 移除估算之上（来自对 6,000 多篇文献的综述，其中 927 篇提供可用估算），再识别已发表的关于移除与利用关系的研究来推算利用规模和成本 [page 4]。

Table 2 汇总了所有路径的移除潜力、利用潜力和盈亏平衡成本 [page 6]。几个关键数值：

- 化学品：利用潜力 300–600 Mt CO2 yr−1，盈亏平衡成本 −$80 到 $320/t CO2
- 燃料：利用潜力 1,000–4,200 Mt CO2 yr−1，成本 $0 到 $670/t CO2
- 微藻：利用潜力 200–900 Mt CO2 yr−1，成本 $230 到 $920/t CO2
- 混凝土建材：移除和利用潜力均为 100–1,400 Mt CO2 yr−1，成本 −$30 到 $70/t CO2
- CO2-EOR：移除和利用潜力均为 100–1,800 Mt CO2 yr−1，成本 −$60 到 −$45/t CO2
- BECCS：移除和利用潜力均为 500–5,000 Mt CO2 yr−1，成本 $60 到 $160/t CO2
- 增强风化：移除潜力 2,000–4,000 Mt CO2 yr−1，利用潜力未确定，成本低于 $200/t CO2
- 林业：移除潜力 500–3,600 Mt CO2 yr−1，利用潜力 70–1,100 Mt CO2 yr−1，成本 −$40 到 $10/t CO2
- 土地管理：移除潜力 2,300–5,300 Mt CO2 yr−1，利用潜力 900–1,900 Mt CO2 yr−1，成本 −$90 到 −$20/t CO2
- 生物炭：移除潜力 300–2,000 Mt CO2 yr−1，利用潜力 170–1,000 Mt CO2 yr−1，成本 −$70 到 −$60/t CO2

这些数值的论证功能是双重的。一方面，它们显示每条路径的潜力都可能达到 0.5 Gt CO2 yr−1 以上（这是作者在摘要中的核心量化主张）[page 1]。另一方面，它们显示成本差异巨大：负成本路径（如土地管理、生物炭、CO2-EOR）在无补贴情况下已可盈利，而高成本路径（如微藻、部分燃料路径）需要每吨数百美元的激励 [page 6, Table 2]。

### 成本曲线的构建与限制

Fig. 3 把 Table 2 的数据画成低情景和高情景两条成本曲线 [page 8]。作者明确警告：这些曲线是"推测性的初步尝试"，不是 nth-of-a-kind 成本，不能与其他封存或减排成本曲线直接比较 [page 8]。更重要的是，**各路径的潜力不能简单相加**：它们可能争夺同一需求（如 CO2 燃料的成功会减少石油需求，从而降低 CO2-EOR 的潜力），土地可用性也意味着选择一种土地利用路径（如 BECCS）可能排除另一种（如生物炭）[page 9]。

这一限制条件直接约束了核心结论的适用范围：**"每条路径可扩展到 0.5 Gt 以上"是一个逐路径的判断，不是总量判断**。作者在低情景下估算，不考虑路径间重叠时，上限超过 1.5 Gt CO2 yr−1，成本远低于 $100/t CO2 [page 9]。但这个数字是上限，不是可实现总量。

## 三、关键推理步骤与桥接

### 从利用到气候效益的桥接

作者论证中最关键的一步，是从"利用量"到"气候效益"的桥接。这一步不是自动的，需要三个条件同时满足：

1. **碳源条件**：CO2 必须来自大气（而非化石源），利用才可能构成净移除 [page 5, Box 1]。
2. **能源条件**：过程所需的能源必须来自脱碳来源，否则生命周期排放可能抵消甚至超过利用带来的减排 [page 5, Box 1]。
3. **反事实条件**：必须与一个合理的基准情景比较，考虑间接效应（如土地利用变化、水床效应/泄漏）[page 2, Box 1]。

作者在 Box 1 中明确指出，一些工业 CO2 利用路径的生命周期分析显示，净减排潜力远大于净移除潜力，后者"非常有限"（very modest）[page 5]。例如，聚碳酸酯多元醇路径每使用 1 吨 CO2 可避免最多 3 吨 CO2 排放，但没有任何 CO2 从大气中移除 [page 5]。这一区分的政策含义是：**如果政策目标是移除，那么大多数循环型路径不合格；如果政策目标是减排，那么循环型路径可能有效，但必须核算生命周期排放**。

### 从成本估算到政策建议的桥接

作者从成本数据推导出的政策建议是：**不应直接补贴利用本身，而应激励可验证的减排和移除** [page 9]。这一推理的关键在于：负成本路径（如土地管理、生物炭）在无补贴时已可盈利，但面临非成本障碍（实施、交易、制度、监测成本）；正成本路径（如 BECCS、建材）则需要移除补贴才能扩展 [page 9]。

作者进一步指出，碳价在 $40–$80/t CO2 范围内并随时间上升，可以惩罚排放并激励可验证的减排和移除 [page 10]。这一建议的逻辑是：如果碳价足够高，负成本路径会自动扩展，正成本路径中气候效益真实的那些也会获得激励。但作者明确不主张直接补贴利用，因为利用本身不保证气候效益 [page 9]。

## 四、结论成立的条件与边界

### 作者明确承认的限制

1. **成本曲线的推测性**：Fig. 3 的曲线基于稀疏数据和近似，不是综合评估，不代表 nth-of-a-kind 成本 [page 8]。
2. **路径间不可加性**：各路径争夺同一需求或土地，不能简单相加 [page 9]。
3. **反事实的困难**：识别反事实"特别具有挑战性"，且影响随空间和时间变化 [page 3]。
4. **非常规路径利用估算的初步性**：基于"初步但稀疏的已发表研究"，是"首次粗略估算" [page 6, Table 2 注释]。
5. **常规路径成本估算的回顾性**：基于回顾性范围综述，不包含当前未发表的创新 [page 8]。
6. **专家意见调查的不确定性**：专家对 2050 年成本方向存在"很大不确定性"，部分路径"共识不足" [page 7, Table 3]。

### 影响结论的关键假设

1. **定义假设**：采用宽定义把土地利用纳入 CO2 利用，这使跨路径比较成为可能，但也意味着"利用"的边界比主流文献更宽 [page 1]。
2. **碳源假设**：对于循环型路径，净移除的前提是碳来自大气（如直接空气捕获），这在当前成本下（$600–$1,000/t CO2 首次工厂，$200/t CO2 nth-of-a-kind）[page 9] 限制了近期可行性。
3. **能源假设**：对于燃料和化学品路径，清洁氢和廉价可再生电力的可用性是关键前提。作者引用美国能源部目标：$2/kg H2 需要无碳电力低于 $0.03/kWh [page 5]。
4. **土地假设**：土地利用路径的规模受土地可用性、粮食安全、生物多样性等约束，作者在 Supplementary Materials 中讨论但正文中仅简要提及 [page 9]。

### 负面结果与风险

作者明确指出了几条路径的负面可能性：

- **CO2-EOR**：可能不产生净气候效益，甚至可能有害；随着脱碳推进，其气候效益会降低，在完全脱碳前某个时点，无直接空气捕获的 EOR 将导致净排放增加 [page 9]。
- **BECCS**：土地利用变化可能导致排放大幅增加 [page 9]。
- **尿素**：所有氮基肥料产生 N2O（100 年尺度上温室效应约为 CO2 的 300 倍），增加尿素生产可能对气候产生负面影响 [page 5]。
- **开放型路径**：储存时间短，面临饱和风险，可能大规模释放 CO2 回大气 [page 9]。
- **建材**：面临监管壁垒，市场渗透可能需要数十年 [page 9]。

## 五、总体判断

这篇论文的论证力度在于它拒绝把"CO2 利用"当作一个同质范畴。通过区分利用、移除、储存、减排和净气候效益，通过区分循环、封闭和开放三类路径，通过逐路径评估规模和成本，作者构建了一个可以比较不同路径的框架。这个框架的核心贡献不是给出一个确定答案（CO2 利用能否解决气候问题），而是给出一个可以提出正确问题的结构：**在什么条件下，哪条路径，以什么成本，提供多少可验证的移除或减排？**

结论的适用范围受限于几个条件：成本数据的时间性（2015 美元，2050 年预测）、路径间不可加性、反事实的困难、以及非常规路径利用估算的初步性。在这些限制下，作者的核心量化主张——每条路径可扩展到 0.5 Gt CO2 yr−1 以上——是一个逐路径的上限判断，不是可实现总量的预测。作者最终的政策建议——不补贴利用本身，而激励可验证的减排和移除——直接来自其概念区分：如果利用不保证气候效益，那么补贴利用就可能补贴无效甚至有害的活动。
