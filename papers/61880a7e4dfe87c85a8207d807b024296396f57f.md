# 奇异值阈值算法：从核范数最小化到大规模矩阵补全

**原文题名**：A Singular Value Thresholding Algorithm for Matrix Completion
**作者**：Jian-Feng Cai, Emmanuel J. Candès, Zuowei Shen
**发表**：SIAM Journal on Optimization, Vol. 20, No. 4, pp. 1956–1982, 2010
**DOI**：10.1137/080738970

---

## 论文要解决的问题与核心主张

矩阵补全问题——从矩阵的一小部分采样条目恢复整个矩阵——本质上是严重欠定的：当采样数远小于未知数时，存在无穷多个满足约束的补全方案。Candès 和 Recht 此前证明，若未知矩阵低秩，则通过求解核范数最小化问题 (1.1) 可以精确恢复，且所需样本量约为 $m \geq Cn^{6/5}r\log n$ [page 2]。然而，这一凸优化问题当时只能用内点法求解，而 SDPT3 等求解器仅能处理 $n \leq 100$ 的矩阵 [page 3]，完全无法应对 Netflix 问题级别的规模。

本文的核心主张是：**可以用一个极其简单的一阶迭代算法——奇异值阈值（SVT）算法——来近似求解核范数最小化问题，且该算法在大规模低秩矩阵补全问题上既高效又实用**。作者从三个层面支撑这一主张：算法构造与解释（第 2–3 节）、收敛性证明（第 4 节）、以及大规模数值实验（第 5 节）。

---

## 算法机制：奇异值收缩与稀疏-低秩结构

SVT 算法的核心构件是**奇异值收缩算子** $D_\tau$。给定矩阵 $X$ 的 SVD $X = U\Sigma V^*$，定义 $D_\tau(X) := U D_\tau(\Sigma) V^*$，其中 $D_\tau(\Sigma) = \mathrm{diag}(\{(\sigma_i - \tau)_+\})$ [page 4, (2.2)]。这相当于对奇异值施加软阈值规则：大于 $\tau$ 的奇异值被缩减 $\tau$，小于等于 $\tau$ 的被置零。

定理 2.1 建立了这一算子的变分刻画：$D_\tau(Y) = \arg\min_X \frac{1}{2}\|X-Y\|_F^2 + \tau\|X\|_*$ [page 5, (2.3)]。证明的关键在于利用核范数的次梯度公式 (2.6)，将 $Y$ 的 SVD 按奇异值与 $\tau$ 的大小关系分块，验证 $Y - D_\tau(Y)$ 属于 $\tau\partial\|D_\tau(Y)\|_*$。这一步是整篇论文的数学基石：它表明奇异值收缩正是核范数的邻近算子（proximity operator），从而将核范数最小化问题与可计算的阈值操作联系起来。

基于此，SVT 迭代格式为 [page 6, (2.7)]：

$$X^k = D_\tau(Y^{k-1}), \quad Y^k = Y^{k-1} + \delta_k P_\Omega(M - X^k)$$

每步只需计算一次 SVD 和若干矩阵加法。算法有两个关键性质使其适合大规模问题 [page 6]：

- **稀疏性**：$Y^k$ 始终在 $\Omega$ 外为零，因为 $Y^0 = 0$ 且每次更新只涉及 $P_\Omega$。更新 $Y^k$ 的计算代价为 $O(m)$。
- **低秩性**：作者观察到 $\{X^k\}$ 的秩经验上非递减，且最终达到真实秩。这使存储和计算成本大幅降低。作者明确标注这是"经验事实"（empirical fact），并承认无法严格证明 [page 6]。

## 从 Uzawa 算法到收敛保证

论文的一个关键论证转折是将 SVT 重新解释为 **Uzawa 算法**（一种 Lagrange 乘子法）[page 8–9]。考虑修正目标 $f_\tau(X) = \tau\|X\|_* + \frac{1}{2}\|X\|_F^2$ 在约束 $P_\Omega(X) = P_\Omega(M)$ 下的最小化问题 (2.8)。其 Lagrangian 为 $L(X,Y) = f_\tau(X) + \langle Y, P_\Omega(M-X)\rangle$。Uzawa 迭代交替进行原始最小化和对偶梯度上升：

$$X^k = \arg\min_X L(X, Y^{k-1}), \quad Y^k = Y^{k-1} + \delta_k P_\Omega(M - X^k)$$

由于 $\arg\min_X f_\tau(X) + \langle Y, P_\Omega(M-X)\rangle = D_\tau(P_\Omega(Y))$ [page 9, (2.14)]，而 $Y^k$ 始终在 $\Omega$ 外为零，Uzawa 迭代恰好还原为 (2.7)。这一等价性的价值在于：它使作者能够调用投影梯度下降算法的已有收敛理论，而不必从零建立分析。

收敛性证明分两步。引理 4.1 建立 $f_\tau$ 的强凸性：对任意 $Z \in \partial f_\tau(X)$，$Z' \in \partial f_\tau(X')$，有 $\langle Z - Z', X - X'\rangle \geq \|X - X'\|_F^2$ [page 13, (4.1)]。证明利用核范数次梯度的性质 $\|Z_0\|_2 \leq 1$ 和 $\langle Z_0, X\rangle = \|X\|_*$。定理 4.2 则直接引用 [25, Theorem 2.1] 给出：当步长满足 $0 < \inf\delta_k \leq \sup\delta_k < 2/\|A\|^2$ 时，$\{X^k\}$ 收敛到 (3.1) 的唯一解；矩阵补全情形下 $\|A\|^2 = 1$，条件简化为 $0 < \delta < 2$ [page 13]。

更一般的收敛定理（定理 4.4）处理凸不等式约束 (3.4)。证明的核心不等式链为 [page 14–15]：

$$\|y^k - y^*\|^2 \leq \|y^{k-1} - y^*\|^2 - 2\delta_k\|X^k - X^*\|_F^2 + \delta_k^2 L^2\|X^k - X^*\|_F^2$$

当 $2\delta_k - \delta_k^2 L^2 \geq \beta > 0$ 时，对偶变量序列单调下降且有下界，从而 $\|X^k - X^*\|_F \to 0$。这里 $L$ 是 $F$ 的 Lipschitz 常数，步长条件为 $0 < \inf\delta_k \leq \sup\delta_k < 2/L^2$。

**关键推理步骤**：整个收敛性论证依赖于将 SVT 识别为对偶问题的投影梯度下降，然后利用 $f_\tau$ 的强凸性（引理 4.1）保证原始变量的收敛。如果 $f_\tau$ 仅是凸而非强凸的，这一论证链条将断裂——$\frac{1}{2}\|X\|_F^2$ 项的加入正是为了提供强凸性。

## 从修正问题到原问题：$\tau \to \infty$ 的桥接

SVT 实际求解的是修正问题 (2.8)，而非原始核范数最小化 (1.1)。定理 3.1 填补了这一缺口：设 $X_\tau^*$ 是 (3.4) 的解，$X^\infty$ 是 (1.6) 的最小 Frobenius 范数解，则 $\lim_{\tau\to\infty}\|X_\tau^* - X^\infty\|_F = 0$ [page 12, (3.15)]。证明通过两个不等式 (3.16) 夹逼，先建立 $\|X_\tau^*\|_F$ 的一致有界性，再证明任何收敛子序列的极限都是 (1.1) 的解且 Frobenius 范数等于 $X^\infty$，由 $X^\infty$ 的唯一性得证。

这意味着：**取足够大的 $\tau$，SVT 的解可以任意接近原始核范数最小化问题的解**。但这里存在一个实际张力：$\tau$ 越大，修正问题越接近原问题，但收敛速度越慢（因为阈值操作"杀死"更多奇异值，有效步长变小）。第 5 节的数值实验（表 5.2）证实了这一点：对每个 $\delta$ 存在最优 $\tau$，过小导致迭代次数增加且秩偏高，过大导致过度收缩和慢收敛 [page 21]。

## 数值证据：规模、精度与噪声

数值实验是论文说服力的重要组成部分。表 5.1 报告了从 $1000\times 1000$ 到 $30000\times 30000$ 的矩阵补全结果 [page 19]。最引人注目的数据点：$30000\times 30000$、秩 10 的矩阵，仅从约 0.4% 的采样条目（$m/n^2 = 0.004$）恢复，耗时约 17 分钟，相对误差 $1.73\times 10^{-4}$。所有实验均在 1.86 GHz 双核 CPU、3 GB 内存的普通台式机上完成。

图 5.1 展示了 $5000\times 5000$ 矩阵在不同秩下 $X^k$ 的秩随迭代步数的变化 [page 20]。三个子图（$r=10, 50, 100$）一致显示：秩在最初几步迅速上升至真实秩，之后保持稳定。这验证了低秩性质的经验观察，也解释了算法的高效性——一旦秩稳定，每步 SVD 的计算量就固定了。

噪声情形（表 5.3）采用早停策略：当 $\|P_\Omega(X^k - B)\|_F^2 \leq (1+\epsilon)m\sigma^2$ 时停止 [page 21, (5.10)]。结果显示相对重建误差与噪声比大致相当（如噪声比 $10^{-2}$ 时误差约 $0.78\times 10^{-2}$ 至 $1.13\times 10^{-2}$），表明算法在噪声下行为合理。作者对此给出了非严格的直觉论证 [page 21–22]：若 $\|P_\Omega(\hat{M}-M)\|_F^2 \asymp p\|\hat{M}-M\|_F^2$ 成立，则 $p\|\hat{M}-M\|_F^2 = O(m\sigma^2)$，相对误差约为噪声比。但作者明确承认"低秩矩阵噪声恢复的理论尚不存在" [page 21]。

## 适用条件、边界与未解决的问题

论文的结论在以下条件下成立：

1. **低秩假设**：算法的高效性依赖于最优解低秩。若解不低秩，$X^k$ 的秩可能很高，每步 SVD 代价剧增。作者在讨论中指出，证明"多数情况下 $X^k$ 低秩"是一个开放问题 [page 24]。

2. **步长选择**：理论保证要求 $\delta < 2$（矩阵补全），但实际使用 $\delta = 1.2n_1n_2/m$ [page 16, (5.1)]，这远超理论界限。作者用非严格的等距性质 (5.2) 启发式地论证：若 $X^* - X^k$ 满足 incoherence 条件，则可取 $\delta \leq 1.6p^{-1}$。但作者明确指出这不是严格论证，因为 $X^* - X^k$ 依赖于 $\Omega$，不能直接应用 (5.2) [page 16–17]。

3. **$\tau$ 的选择**：$\tau = 5n$ 是经验值，基于 $\tau\|M\|_*$ 应约 10 倍于 $\frac{1}{2}\|M\|_F^2$ 的启发式 [page 19]。表 5.2 显示最优 $\tau$ 依赖于 $\delta$ 和问题规模，不存在通用最优值。

4. **不等式约束下的秩增长**：表 5.4 显示，在二次约束 (3.12) 下，迭代的秩随迭代次数增长（tol = 0.05 时秩达 45），与等式约束下的秩稳定行为不同。作者将此列为未来研究方向 [page 22]。

5. **与 PFBS 的对比**：作者区分了 SVT (2.7) 与邻近前向-后向分裂 (PFBS) 方法 (2.10) [page 7–8]。两者形式相似但极限不同：SVT 收敛到约束问题 (2.8) 的解，PFBS 收敛到无约束松弛 (2.9) 的解。作者论证 PFBS 不适合大规模矩阵补全，因为需要小 $\lambda$ 才能拟合数据，但小 $\lambda$ 下 $X^k$ 可能不低秩，导致 SVD 计算代价高。

## 论证的整体评价

这篇论文的论证结构清晰：从邻近算子的变分刻画（定理 2.1）出发，通过 Uzawa 算法框架建立收敛性（定理 4.2、4.4），再用 $\tau\to\infty$ 的极限定理（定理 3.1）桥接到原始问题，最后用大规模数值实验验证实用性。每一步都有明确的数学依据或实验支撑。

最关键的推理步骤是定理 2.1 将奇异值收缩识别为核范数的邻近算子——这不仅赋予了算法直观解释（对奇异值做软阈值），更使 Uzawa 框架得以适用，从而继承已有的收敛理论。如果缺少这一步，算法就只是一个启发式迭代，无法获得收敛保证。

论文的诚实之处在于明确区分了严格结论与经验观察：低秩性是"经验事实"而非定理；步长 $\delta = 1.2p^{-1}$ 的论证是"非严格的"；噪声下的误差分析是"直觉的"且"理论尚不存在"。这些限定语准确反映了论证的边界。
