# 自成像原理如何支撑多模干涉器件：一篇综述的论证结构

**原文题名**：Optical Multi-Mode Interference Devices Based on Self-Imaging: Principles and Applications
**作者**：Lucas B. Soldano, Erik C. M. Pennings
**期刊**：Journal of Lightwave Technology, Vol. 13, No. 4, April 1995, pp. 615–625
**DOI**：10.1109/50.372474（据 IEEE Log Number 9409613 及期刊信息推断）

---

## 一、论文要证明什么

这篇综述的核心主张可以概括为一句话：**基于自成像（self-imaging）原理的多模干涉（MMI）器件，在插入损耗、平衡度、偏振与波长容差、工艺宽容度等方面，整体优于方向耦合器、绝热 X/Y 结、衍射星形耦合器等传统路由与耦合器件，因此值得被广泛集成进光子集成电路（PIC）** [page 1, page 11]。

这个主张不是单一命题，而是由三层支撑结论叠加而成：

1. **物理层**：多模波导中的自成像可以用导模传播分析（MPA）严格描述，成像位置与相位由模式传播常数的近似二次依赖关系决定 [page 2–4]。
2. **机制层**：根据输入激励方式的不同，存在一般干涉、成对干涉、对称干涉三种机制，分别对应不同的成像周期与器件长度 [page 3–6]。
3. **器件层**：这些机制在实验中确实产生了低损耗、低不平衡、相位稳定的耦合器与分束器，并在相干接收机、Mach-Zehnder 结构、环形激光器等系统中得到验证 [page 9–11]。

论文的论证力量主要来自第二、三层之间的衔接：**理论预测的成像长度与相位关系，被多个独立工艺平台上的实测数据所印证**。下面按这条主线展开。

## 二、从波动方程到成像条件：关键推理链

### 1. 传播常数的近似二次依赖是全部成像公式的起点

作者从阶跃折射率多模波导的色散方程出发 [page 2]：

$$k_{yv}^2 + \beta_v^2 = k_0^2 n_r^2, \quad k_{yv} = \frac{(v+1)\pi}{W_{ev}}$$

在 $k_{yv}^2 \ll k_0^2 n_r^2$ 的条件下用二项式展开，得到

$$\beta_v \approx k_0 n_r - \frac{(v+1)^2 \pi \lambda_0}{4 n_r W_{ev}^2}$$

由此定义最低两阶模式的拍长

$$L_\pi = \frac{\pi}{\beta_0 - \beta_1} \approx \frac{4 n_r W_e^2}{3\lambda_0}$$

并得到模式传播常数间距

$$\beta_0 - \beta_v \approx \frac{v(v+2)\pi}{3L_\pi}$$

**这一步是整个论证的枢纽**：正因为 $\beta_0 - \beta_v$ 与 $v(v+2)$ 成正比，模式相位因子 $\exp[j v(v+2)\pi z / (3L_\pi)]$ 才具有可解析的周期性，成像位置才能写成 $L = p(3L_\pi)/N$ 这样的简单形式 [page 3, 公式 (14), (18), (24)]。

需要指出的是，作者明确承认这是**近似**：二次依赖来自二项式展开，实际模式会累积相位偏差，导致成像模糊，类似有限孔径光学系统的像差引起的焦移 [page 7]。作者给出的补救办法是"对成像长度做轻微修正"以平衡相位误差 [page 7]。这是结论成立的一个隐含条件——**成像公式给出的是设计起点，不是精确终点**。

### 2. 一般干涉：不限制激励时的成像规律

在不对激励系数 $c_v$ 施加任何限制的情况下，作者通过分析模式相位因子 $\exp[j v(v+2)\pi L/(3L_\pi)]$ 的取值，得到两个成像条件 [page 3, 公式 (17)]：

- 所有模式相位差为 $2\pi$ 整数倍 → 直接单像，位于 $L = p(3L_\pi)$，$p$ 为偶数；
- 模式相位差交替为 $2\pi$ 与 $\pi$ 的整数倍 → 镜像单像，位于 $p$ 为奇数的位置。

进一步，在 $L = (p/2)(3L_\pi)$（$p$ 为奇数）处，场分解为一对正交、幅度各为 $1/\sqrt{2}$ 的像，即**二重像**，可用于 2×2 3-dB 耦合器 [page 3–4]。

更一般的 $N$ 重像由 Fourier 分析与广义高斯和给出 [page 4, 公式 (24)–(27)]：

$$L = \frac{p}{N}(3L_\pi), \quad \text{像位置 } y_q, \text{ 幅度 } 1/\sqrt{N}, \text{ 相位 } \varphi_q$$

其中 $p$ 与 $N$ 互质。作者特别强调，$N \times N$ 耦合器的输出相位关系（公式 28、29）是**多模波导成像性质内禀的**，不依赖外部设计 [page 4]。这一点对 90° 混合器的应用至关重要。

### 3. 受限干涉：通过选择性激励缩短器件

如果只激励部分模式，模式相位因子的周期可以成倍缩短 [page 5–6]：

- **成对干涉**：当 $v = 2, 5, 8, \ldots$ 不被激励时，$v(v+2)$ 对这些模式取模 3 为零，周期缩短为 $L_\pi$，单像出现在 $L = p L_\pi$。实现方式是让对称输入场在 $y = \pm W_e/6$ 处入射，因为奇对称模式在此处为零 [page 5]。
- **对称干涉**：当所有奇模不被激励时，周期缩短为 $3L_\pi/4$，$N$ 重像出现在 $L = (p/N)(3L_\pi/4)$，像沿横向等间距分布 [page 6, 公式 37]。

作者给出了一个实用的经验规则：**要获得低损耗、良好平衡的 1-to-N 高斯场分束，多模波导至少需支持 $m = N + 1$ 个模式** [page 6]。

## 三、实验证据如何支撑器件层结论

### 1. 一般干涉 2×2 耦合器

InGaAsP 器件（8 μm 宽多模区，支持 4 个导模）实测：过量损耗 0.4–0.7 dB，交叉态消光比 −28 dB（$3L_\pi = 500$ μm），3-dB 态不平衡远低于 0.1 dB，TE/TM 偏振在 $\lambda_0 = 1.52$ μm 下均如此 [page 4]。这组数据直接支撑了"低损耗、低不平衡、偏振不敏感"的主张。

### 2. 4×4 90° 混合器

深蚀刻 III-V 半导体器件（$L_{MMI} \approx 945$ μm，$W_{MMI} \approx 21.6$ μm）实测：过量损耗低于 1 dB，不平衡 0.3–0.9 dB，相位偏差约 5° [page 5]。图 8 的模拟进一步显示，在 $L = 978 \pm 25$ μm 范围内平衡优于 0.3 dB，共模抑制比超过 30 dB，相位保持在正交关系 ±5° 以内 [page 7–8]。**这里的关键推理是**：由于每个像是局部极大值，输出功率对长度变化的敏感度在最佳长度处最小，且所有输出功率同向变化，因此平衡度对长度偏差不敏感——这与方向耦合器在 3-dB 点敏感度最大、且两输出符号相反形成鲜明对比 [page 7]。

### 3. 成对干涉与对称干涉

- 成对干涉 2×2 耦合器（硅基介质脊波导，支持 7–9 模）：插入损耗 < 0.4 dB，不平衡 < 0.2 dB，消光比 −18 dB，偏振敏感损耗代价 0.2 dB [page 5]。计算预测 $v = 2, 5, 8$ 模式的激励系数可低至 −40 dB，0.1 μm 失配下仍低于 −30 dB [page 5]。
- 对称干涉 1×N 分束器（GaAs、InP 脊波导，$N = 2$ 至 20）：不平衡 < 0.4 dB [page 6]。1×2 分束器在硅基中仅 20–30 μm 长，InP 中 50–70 μm，过量损耗约 1 dB，不平衡 < 0.15 dB [page 6]。

### 4. 容差分析

作者用高斯光束散焦模型推导出 0.5 dB 损耗代价对应的长度偏移约等于瑞利长度 [page 8, 公式 39]：

$$\delta L \approx \frac{\pi n_r W_0^2}{\lambda_0}$$

并由此将其他参数的容差与 $\delta L$ 关联 [page 9, 公式 40]。以 2×2 耦合器为例（$W_e \approx 8$ μm，$L = 240$ μm，$n_r = 3.24$，$W_0 \approx 3$ μm，$\lambda_0 = 1.52$ μm）：$\delta L \approx 15$ μm，对应 $\delta W_e \approx 0.25$ μm，$\delta\lambda \approx 95$ nm，$\delta n_r \approx 0.20$ [page 9]。**结论是**：多模区宽度是最关键的工艺参数；长度可在开发阶段以 $\delta L$ 为步长调整补偿 [page 9]。

## 四、结论成立的边界与作者承认的局限

1. **二次近似**：传播常数的二次依赖是近似，实际存在相位误差，成像质量会下降。作者建议通过修正成像长度来部分补偿，但未给出普适的误差上界 [page 7]。

2. **成像分辨率**：最窄可成像宽度约为最高阶模余弦瓣宽 $W_e/m$，更精细的分析给出 0.89 $W_e/m$（平坦模谱）到约 1.50 $W_e/m$（高斯模谱）[page 7]。这意味着**多模波导必须支持足够多的模式**才能分辨输入场，否则损耗和串扰上升。

3. **反射问题**：MMI 器件存在两种反射机制——"内部共振"（多个自成像同时出现导致两端高效互成像）和反向合束时的 180° 反相反射 [page 7–8]。作者明确指出，这在 Mach-Zehnder 调制器关态时可能导致增强的背反射，建议用 2×2 3-dB 耦合器替代合束器，或采用低对比度波导/锥形端面 [page 8]。

4. **成对干涉的长度悖论**：虽然成对干涉理论上可缩短周期，但选择性激励要求增加多模区宽度，从而增加长度，抵消了潜在的长度优势 [page 6]。这是一个**负面结果**，作者如实报告。

5. **表格 III 的谨慎使用**：作者在结论中提醒，器件性能对比表涵盖不同材料与波长，应谨慎使用 [page 11]。

6. **偏振依赖**：偏振无关操作需在中间长度设计，代价是少量损耗增加；实测偏振变化引起的代价损耗低于 0.30 dB [page 9]。

## 五、论证的整体评价

这篇综述的论证力量在于**理论推导与多平台实验的交叉印证**：从色散方程出发的近似二次依赖，导出简洁的成像长度公式；这些公式在 InP、GaAs、硅基、离子交换玻璃等多种材料体系中得到验证；实测的损耗、不平衡、相位偏差与理论预测量级一致。作者没有回避近似带来的相位误差、反射机制、成对干涉的长度悖论等限制，而是将其作为设计时需要权衡的因素明确列出。

**关键推理步骤**是：模式传播常数的二次依赖 → 模式相位因子的周期性 → 成像位置与相位关系 → 器件功能（耦合、分束、混合）→ 系统应用（相干接收、Mach-Zehnder、环形激光器）。每一步都有公式或实验支撑，且作者在关键处标注了近似条件和适用边界。

**结论的适用条件**可以归纳为：多模波导支持足够多的模式以分辨输入场；输入场不激励会破坏目标干涉机制的模式（受限干涉时）；工作波长与设计波长偏差在容差范围内；对反射敏感的应用需采取额外措施。在这些条件下，MMI 器件确实展现出作者所主张的综合优势。
