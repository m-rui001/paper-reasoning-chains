# 用“再入曲率”绕开低表面能极限：超疏油表面的设计论证

**原文题名**：Designing Superoleophobic Surfaces（*Science* 318, 1618, 2007；DOI: 10.1126/science.1148326）

## 一个看似不可能的润湿问题

论文要解决的是一个被既有理论判为“几乎无解”的问题：如何让表面排斥表面张力远低于水的有机液体。水（γ_lv = 72.1 mN/m）的超疏水表面在自然界和实验室中都很常见，但超疏油表面——对癸烷（γ_lv = 23.8 mN/m）、辛烷（γ_lv = 21.6 mN/m）这类液体呈现大于 150° 表观接触角——却极为罕见 [page 2]。

作者先交代了为什么难。经典处理用两个模型描述粗糙度对表观接触角 θ* 的影响：Wenzel 模型 cos θ* = r cos θ（式 1），其中 r 是粗糙度、θ 是光滑表面的本征接触角；Cassie 模型 cos θ* = −1 + f_s(1 + cos θ)（式 2），其中 f_s 是液滴下方固体的面积分数 [page 2]。把两式相等，得到 Wenzel 态向 Cassie 态转变的临界本征接触角：

cos θ_c = (f_s − 1)/(r − f_s)（式 3）

由于 r > 1 > f_s，θ_c 必然大于 90°。这就推出一个关键限制：若想让表面进入 Cassie 态、实现 θ* ≫ 90°，通常需要本征接触角 θ > θ_c > 90°。而对癸烷、辛烷这类低表面张力液体，已知没有任何材料能让 θ 超过 90°——换言之，按这条推理，超疏油表面需要一种表面能低于任何已知材料的固体 [page 2]。这是论文要正面挑战的“不可能”结论。

## 论证的转折点：把局部曲率当作第三个参数

作者的突破口来自对既有反例的重新解释。Herminghaus 曾指出某些植物叶片即使 θ < 90° 也表现超疏水 [page 2]；荷叶表面的蜡本身甚至是弱亲水的（θ ≈ 74°）。这说明 Cassie 态未必是真正的平衡态，而可以是亚稳态——把叶片压入水中一定深度，就能迫使它从亚稳态 Cassie 转入 Wenzel 态。由此作者提出：既然可以设计亚稳态超疏水表面，那么即使受限于 θ < 90° 的材料，也可能设计出亚稳态超疏油表面 [page 2]。

支撑这一想法的机制是**再入曲率（re-entrant curvature）**，即具有凹形形貌的表面。作者用图 3A、3B 的示意图说明：对于纤维和“微石柱（micro-hoodoo）”这类再入结构，无论 0° < θ < 180° 取何值，沿纤维或帽檐长度总存在某一点使 Young 方程在气-液-固界面局部满足 [page 5]。这与垂直柱阵列等常见图案化支撑不同——后者只有在 θ > 90° 时才能形成复合界面。因此再入曲面可以让液滴部分坐在空气上，即使 θ < 90° 也能得到 θ* ≫ 90°。作者同时强调，这个 Cassie 态只是**局部稳定**的：如果液体推进并完全覆盖纤维/石柱，系统总能量会显著下降，界面就转为完全润湿 [page 5]。这一点是理解全文结论边界的关键。

## 从材料到表面：两条证据链

**第一条链：fluoroPOSS–PMMA 电纺纤维。** 作者合成了一类氟化多面体低聚倍半硅氧烷（fluoroPOSS），其刚性硅氧烷笼被全氟烷基包围（图 1A 插图）。纯 fluorodecyl POSS 旋涂膜的推进/后退接触角为 124.5° ± 1.2°，RMS 粗糙度 r_q = 3.5 nm [page 2]。把 fluorodecyl POSS 与 PMMA 共混，可系统调节表面能：随 POSS 质量分数增加，水的 θ_adv 和 θ_rec 单调变化（图 1A），AFM 相图显示 POSS 在溶剂蒸发过程中显著向表面迁移（图 1B）[page 3]。

把这些共混物电纺成纤维毡后，出现了一个用 Wenzel 模型无法解释的现象：纯 PMMA 和 1.9 wt% POSS 的电纺表面，尽管本征 θ_adv < 90°，其 θ*_adv 却大于 90°（图 1C）[page 3]。按式 1，θ < 90° 时粗糙表面应处于 Wenzel 态且 θ*_adv < θ_adv，实际观察相反。图 1D 的润湿图进一步显示，即使 POSS 含量低于 2 wt%，表面已呈现 Cassie 态特征，但接触角滞后很大，且从高处释放的水滴能穿透并润湿纤维毡——说明该 Cassie 态是亚稳态 [page 3]。

对十六烷和癸烷，电纺表面同样表现出 θ* ≫ 90°，而对应的旋涂表面都是亲油的（θ < 90°）（图 2A、2B）[page 4]。把多种烷烃在电纺与旋涂表面的推进角汇总成 θ*_adv–θ_adv 主曲线（图 2C），可以看到在 θ_c ≈ 69° 处发生从 Wenzel 到非润湿 Cassie 态的陡峭转变 [page 3–4]。这个 θ_c 明显小于 90°，正是再入曲率带来的、对经典判据的偏离。

**第二条链：微石柱模型表面。** 为直接验证“局部曲率驱动疏油”这一论点，作者用 SiO₂ 沉积加两步刻蚀（反应离子刻蚀 SiO₂，再用气相 XeF₂ 各向同性刻蚀 Si）在硅片上制备了底切结构，即微石柱（图 3B–3D）[page 5]。这些结构同时具备再入曲率、粗糙度（r > 1）和低润湿面积分数（f_s < 1）。

在未做化学处理的 SiO₂ 微石柱上，仅靠再入曲率，水的 θ*_adv ≈ 143°（θ*_rec ≈ 104°，D* = 2.3），而同一晶片光滑区域的 θ_adv ≈ 10°（图 4A）[page 5]。图 4B 显示该表面对水滴的推进和后退都有抵抗，且水滴未触及石柱底部的 SiO₂ 表面——否则无法将水滴完全撤回。随后用气相 1H,1H,2H,2H-perfluorodecyltrichlorosilane 处理，把低表面能与再入曲率结合。辛烷在硅烷化微石柱上的接触角随润湿面积分数 f_s 减小而单调增大（图 4C），与式 2 大体一致；在 f_s = 0.11、D* = 9、H* = 64 的表面上，θ*_adv ≈ 163°、θ*_rec ≈ 145°，10 μl 辛烷液滴倾斜 15° 即可滚落 [page 5]。作为对照，同样硅烷涂层的光滑 SiO₂ 表面（r_q ≈ 0.5 nm）对辛烷只有 θ_adv ≈ 55°、θ_rec ≈ 50° [page 5]。

## 两个无量纲设计参数与稳健性

作者把再入几何的分析提炼为两个设计参数 [page 5]。对电纺纤维，一是间距比 D* = (R + D)/R（R 为纤维半径），直接影响 f_s 和表观接触角；二是稳健性参数 H* = 2(1 − cos θ)R l_cap / D²，其中 l_cap = (γ_lv/ρg)^(1/2)，衡量亚稳态 Cassie 态相对于流体性质、本征接触角和表面几何的稳健程度。对微石柱，D* = [(W + D)/W]²，H* = 2[(1 − cos θ)R + H] l_cap / D²，其中 W 为间距、H 为高度。

这里有一个重要的权衡：改变 R 和 D 对表观接触角与复合界面稳定性有相反影响，因此并非每个具有再入曲率的表面都能在实际上达到亚稳态 Cassie 态——取决于从 Cassie 不可逆转变为 Wenzel 所需的施加压力 [page 5]。作者给出的设计准则是：要同时最大化 θ* 和 Cassie 态稳定性，应追求稀疏排列、高度再入的表面，即 H* ≫ 1 且 D* ≫ 1。他们据此比较：44.1 wt% POSS 纤维毡对辛烷的 D* = 9、H* = 46，比典型金属丝栅（D* = 1.9–5.8、H* = 0.76–7.6）更稳健，即使孔隙率更高 [page 5]。这一参数框架还被用来解释阳极氧化铝聚集体、等离子处理棉纤维、PTFE 颗粒球阵列等此前观察到的疏油现象，以及荷叶表面“悬垂”结构带来的异常疏水性 [page 5]。

稳健性的直接实验证据是突破压力测量。作者用 h* 表示迫使液体穿过纤维所需的液柱高度（或静压），44 wt% POSS 的纤维毡即使浸在 150 mm 十六烷下也不转变为 Wenzel 态 [page 4]。他们用毛细上升高度 h_cap = 2γ_lv cos θ / (ρgD)（式 4）作标度，绘制归一化突破压力 h*/h_cap = ρgD h* / (2γ_lv cos θ)（式 5），并与理论预测（R = 500 nm、D = 4 μm）比较（图 2D）[page 4]。

## 一个应用推论与结论的边界

论文顺带指出一个实用推论：许多低 POSS 含量的电纺表面同时超疏水又超亲油（θ*_alkane ≈ 0°），因此适合分离烷烃（油）与水的混合物或分散液（图 2E）[page 4]。这是一个由润湿数据直接推出的应用，而非独立验证的结论。

回到论证本身，作者在结尾明确划定了结论的适用条件：再入曲率的存在**不是**获得高非润湿性的充分条件；如果从 Cassie 转变为 Wenzel 所需的施加压力（或能垒）很小，Cassie 态在实际上可能无法达到 [page 6]。换言之，本文展示的超疏油性本质上是**亚稳态**的，其成立依赖于两个条件同时满足：表面具有再入曲率，且几何参数使 H* 和 D* 足够大以提供足够的能量壁垒。作者通过独立调控化学组成与形貌（体现为 D* 和 H* 两个无量纲参数），证明可以设计出极其稳健的非润湿表面 [page 6]。

需要留意的边界还包括：θ_c ≈ 69° 这一数值依赖于所考察表面的具体形貌，作者自己指出它会随表面拓扑变化 [page 3–4]；微石柱实验中 f_s = 0.03（D* = 36、H* = 10）的表面被辛烷完全润湿，说明参数并非单调有利 [page 5]；图 4C 中接触角与 Cassie 预测的偏差被归因于接触线钉扎 [page 5, note 42]。此外，论文对“超疏油”的判定主要基于接触角和滚落/突破实验，未涉及长期稳定性、机械磨损等工程耐久性——这些是文本未讨论的限制，不宜当作作者结论。

总体而言，这篇论文的论证力量在于：它没有去追求一种表面能低于所有已知材料的固体（那被理论判为不可能），而是通过引入再入曲率这一几何自由度，把问题从“材料极限”转化为“亚稳态的能量壁垒设计”，并用两条独立的材料/结构路线（电纺纤维与微石柱）和一套可量化的设计参数（D*、H*）加以支撑。结论的强度应理解为：在再入几何与足够稳健的参数条件下，对低表面张力液体实现亚稳态超疏油是可行的。
