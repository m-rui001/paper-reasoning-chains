# 无限大平坦额外维度中膜上的四维引力：Dvali–Gabadadze–Porrati 的论证分析

**原文题名**：4D Gravity on a Brane in 5D Minkowski Space（2000，arXiv:hep-th/0005016v2）

## 论文要解决的问题与核心主张

论文处理的是一个看似矛盾的问题：如果引力传播在无限大的五维平坦时空中，膜上的观测者能否看到正确的四维牛顿引力？通常的做法是紧致化额外维度，或者像 Randall–Sundrum 场景那样让额外维弯曲但体积有限（$L = 2\int_0^\infty \sqrt{g}\,dy < \infty$）[page 2]。作者要探讨的是额外维既不平坦也不紧致、体积真正无限的情形。

核心主张是：只要在膜的世界体积作用量中加入一个四维 Ricci 标量项 $M_P^2 \int d^4x \sqrt{|g|}\,R$，即使引力在五维平坦无限空间中传播，膜上的源在短距离上仍会感受到正确的 $1/r$ 牛顿势，而在长距离上过渡到五维的 $1/r^2$ 行为 [page 2]。这个四维项与膜上未破缺的对称性相容，可以人为加入，也可能由量子修正产生。

## 从作用量到标量原型

作者从一个五维作用量出发：

$$S = M^3 \int d^5X \sqrt{G}\, R^{(5)} + M_P^2 \int d^4x \sqrt{|g|}\, R \tag{1}$$

其中 $M$ 是五维 Planck 质量，$M_P$ 是四维 Planck 质量，膜位于 $y=0$，诱导度规 $g_{\mu\nu}(x) \equiv G_{\mu\nu}(x, y=0)$ [page 3]。两个极限情形说明了这个作用量的含义：$M \to 0$ 且 $M_P$ 有限时描述纯四维引力；$M_P \to 0$ 且 $M$ 有限时描述纯五维体引力。论文研究的是两者都有限的情形。

关于这个四维项的来源，作者给出两条可能路径。一是膜上局域物质通过圈图修正诱导出四维动能项——图 1 展示了重标量或费米子跑在圈中产生 $\int d^4x\, dy\, \delta(y)\sqrt{|g|}\,R$ 的过程 [page 4]。对应的引力常数由世界体积物质理论的两点关联函数决定，在共形不变模型中为零，共形不变性破缺时非零。作者明确表示不讨论这些模型依赖的细节，而是假设世界体积理论能产生符号和大小都合适的第二项，并忽略诱导的四维宇宙学常数和 $O(R^2)$ 高阶项 [page 4]。二是设想五维引力耦合到一个有 kink 型经典解的标量场 $\phi_{\text{classical}} = v\tanh(vy)$，高阶导数相互作用可能在 $y=0$ 附近产生局域化的四维 Ricci 标量 [page 5]。

为了看清距离依赖关系，作者先研究一个只含标量的原型模型：

$$S = M^3 \int d^4x\, dy\, \partial_A\Phi\,\partial^A\Phi + M_P^2 \int d^4x\, dy\, \delta(y)\,\partial_\mu\Phi(x,0)\,\partial^\mu\Phi(x,0) \tag{6}$$

这里 $\Phi$ 取无量纲归一化，目的是与引力情形做类比 [page 5]。对应的格林函数方程在欧几里得空间中为：

$$\left(M^3(p^2 - \partial_y^2) + M_P^2\, p^2\, \delta(y)\right) \tilde{G}_R(p, y) = \delta(y) \tag{10}$$

其解为：

$$\tilde{G}_R(p, y) = \frac{1}{M_P^2\, p^2 + 2M^3\, p \exp(-p|y|)} \tag{11}$$

由此得到的膜上势能为：

$$V(r) = -\frac{1}{8\pi^2 M_P^2}\cdot\frac{1}{r}\left\{\sin\!\left(\frac{r}{r_0}\right)\text{Ci}\!\left(\frac{r}{r_0}\right) + \frac{1}{2}\cos\!\left(\frac{r}{r_0}\right)\left[\pi - 2\,\text{Si}\!\left(\frac{r}{r_0}\right)\right]\right\} \tag{12}$$

其中交叉尺度为：

$$r_0 \equiv \frac{M_P^2}{2M^3} \tag{13}$$

短距离 $r \ll r_0$ 时，势能展开为：

$$V(r) \simeq -\frac{1}{8\pi^2 M_P^2}\cdot\frac{1}{r}\left\{\frac{\pi}{2} + \left[-1 + \gamma + \ln\!\left(\frac{r}{r_0}\right)\right]\frac{r}{r_0} + O(r^2)\right\} \tag{14}$$

主导项是 $1/r$，即四维牛顿势，修正项是对数排斥。长距离 $r \gg r_0$ 时：

$$V(r) \simeq -\frac{1}{8\pi^2 M_P^2}\cdot\frac{1}{r}\left\{\frac{r_0}{r} + O\!\left(\frac{1}{r^2}\right)\right\} \tag{15}$$

势能按 $1/r^2$ 标度，符合五维理论的规律 [page 6]。

## 引力情形的关键推理：张量结构与额外极化

标量原型给出了距离依赖的直觉，但引力情形有一个标量没有的微妙之处：传播子的张量结构。四维无质量引力子的张量结构为：

$$\frac{1}{2}\eta_{\mu\alpha}\eta_{\nu\beta} + \frac{1}{2}\eta_{\mu\beta}\eta_{\nu\alpha} - \frac{1}{2}\eta_{\mu\nu}\eta_{\alpha\beta} \tag{16}$$

而四维有质量引力子（等价于五维无质量引力子）为：

$$\frac{1}{2}\eta_{\mu\alpha}\eta_{\nu\beta} + \frac{1}{2}\eta_{\mu\beta}\eta_{\nu\alpha} - \frac{1}{3}\eta_{\mu\nu}\eta_{\alpha\beta} \tag{17}$$

最后一项系数 $1/2$ 与 $1/3$ 的差别至关重要。作者引用 Refs. [19, 20] 指出，无论引力子质量多小，由于这个张量结构差异，光线偏折的预言会显著不同，而结构 (17) 与观测矛盾。这是引力子质量趋于零时的不连续性：有质量引力子有 5 个自由度，其中 3 个耦合到守恒的能量-动量张量，等价于四维张量-标量引力，额外的标量极化自由度产生额外吸引力 [page 7]。

作者随后在谐和规范 $\partial_A h_{AB} = \frac{1}{2}\partial_B h^C_{\ C}$ 下计算了模型 (1) 的传播子。他们选取 $h_{\mu 5} = 0$，这与运动方程相容。$(55)$ 分量给出 $\partial_\mu\partial^\mu h^\nu_{\ \nu} = \partial_\mu\partial^\mu h^5_{\ 5}$，结合规范固定条件得到 $\partial_A\partial^A h^\nu_{\ \nu} = \partial_B\partial^B h^5_{\ 5}$ [page 7]。最终 $(\mu\nu)$ 分量的爱因斯坦方程为：

$$\left(M^3\partial_A\partial^A + M_P^2\,\delta(y)\,\partial_\mu\partial^\mu\right) h_{\mu\nu}(x,y) = \left\{T_{\mu\nu} - \frac{1}{3}\eta_{\mu\nu}T^\alpha_{\ \alpha}\right\}\delta(y) + M_P^2\,\delta(y)\,\partial_\mu\partial_\nu h^5_{\ 5} \tag{23}$$

这个结构表明传播子的张量结构如 (17) 所示，即四维有质量引力子或五维无质量引力子的结构。作者进一步将其改写为：

$$\left(M^3\partial_A\partial^A + M_P^2\,\delta(y)\,\partial_\mu\partial^\mu\right) h_{\mu\nu}(x,y) = \left\{T_{\mu\nu} - \frac{1}{2}\eta_{\mu\nu}T^\alpha_{\ \alpha}\right\}\delta(y) - \frac{1}{2}M^3\eta_{\mu\nu}\partial_A\partial^A h^\alpha_{\ \alpha} + M_P^2\,\delta(y)\,\partial_\mu\partial_\nu h^5_{\ 5} \tag{24}$$

右边第一项的括号内是四维无质量引力子的张量结构 (16)，但存在来自迹部分 $h^\mu_{\ \mu}$ 的额外贡献。因此从四维视角看，引力由引力子加一个标量介导 [page 8]。精确的传播子在欧几里得空间中为：

$$\tilde{h}_{\mu\nu}(p, y=0)\,\tilde{T}^{\mu\nu}(p) = \frac{\tilde{T}^{\mu\nu}\tilde{T}_{\mu\nu} - \frac{1}{3}\tilde{T}^\mu_{\ \mu}\tilde{T}^\nu_{\ \nu}}{M_P^2\, p^2 + 2M^3\, p} \tag{25}$$

四维世界体积理论中的张量结构为：

$$D_{\mu\nu\alpha\beta} = \frac{1}{2}\eta_{\mu\alpha}\eta_{\nu\beta} + \frac{1}{2}\eta_{\mu\beta}\eta_{\nu\alpha} - \frac{1}{3}\eta_{\mu\nu}\eta_{\alpha\beta} + O(p) \tag{26}$$

短距离上势能按 $1/r$ 标度，带有 (14) 定义的对数修正；长距离上恢复 (15) 的 $1/r^2$ 行为。传播子的张量结构是四维张量-标量引力 [page 8]。

作者特别指出，在无翘曲因子的情形下，规范变换中不出现正比于 $\eta_{\mu\nu}$ 的项，因此系数 $1/3$ 不会变成 $1/2$——这与有翘曲因子的情形不同 [page 8 脚注 3]。

## 现象学困难与可能的出路

论文最后讨论了模型是否现象学可行，作者承认两个突出问题 [page 9]。

第一个是传播子 (26) 中的额外自由度。额外标量模式产生额外吸引力，作者考虑用新状态来补偿。最直接的是引入鬼场产生排斥力，但作者明确排除这一可能：鬼场可以作为末态在各种过程中产生，会破坏模型的自洽性。另一个可能是引入矢量粒子——给所有物质场附加 $U(1)$ 荷，使规范场产生排斥相互作用，然后调节参数使排斥至少部分抵消额外吸引。作者表示这需要单独的现象学研究来确定一个 $U(1)$ 是否足够，还是需要多个以避免可观测的等效原理破坏 [page 9]。

第二个问题是交叉尺度 $r_0 = M_P^2/2M^3$ 的数值。取 $M_P \simeq 10^{19}$ GeV，假设五维 Planck 质量在 TeV 量级，得到 $r_0 \sim 10^{15}$ cm，恰好是太阳系尺度。但交叉尺度应该远大于太阳系尺度。如果要求 (14) 中的对数修正对水星近日点进动的贡献远小于广义相对论修正，交叉尺度应比太阳系尺度大约 $10^8$ 倍，这意味着 $M$ 应比 TeV 尺度小约 $10^2$–$10^3$ 倍。作者评论说，目前不清楚这样的低能标能否从高维理论中得到 [page 9]。

作者在结论中重申，这类模型的关键特征是额外维既不紧致也不翘曲，其大小真正无限，牛顿定律的修正在长距离上发生。最小 setup 存在现象学微妙之处，他们概述了通过添加额外场来规避的一些可能途径，但需要更详细的研究来确定无限大额外维模型能否获得完整、现象学可行的形式 [page 10]。作者还强调，类似的机制可用于标量和矢量场在平坦高维空间中的局域化，这些情形下引力子面临的现象学微妙之处不存在，因此可以得到理论上和现象学上都自洽的 spin-0 和 spin-1 场局域化模型 [page 10]。

## 论证的关键步骤与成立条件

整篇论文的论证链条可以概括为：四维 Ricci 项在膜上产生一个有效的四维动能项，它与五维体传播竞争，在短距离上主导给出 $1/r$，在长距离上让位于五维的 $1/r^2$。标量原型 (6)–(15) 完整展示了这个竞争如何产生交叉尺度 $r_0$ 和两个极限行为。引力情形的关键推理在于：尽管距离依赖与标量类似，但张量结构 (26) 表明理论从四维视角看是张量-标量引力，额外标量极化产生与观测矛盾的额外吸引力——这是模型的现象学核心困难。

论证成立依赖几个条件。首先，四维 Ricci 项必须存在且符号正确；作者假设世界体积理论能产生它，但承认这依赖具体模型，在共形不变理论中为零 [page 4]。其次，四维宇宙学常数被假设为零，作者承认这需要精细调节，除非体是超对称的 [page 4]。第三，交叉尺度 $r_0$ 必须远大于太阳系尺度才能避免与牛顿引力观测矛盾，但自然估计给出 $r_0 \sim 10^{15}$ cm 恰好是太阳系尺度，需要 $M$ 比 TeV 小两到三个数量级 [page 9]。第四，额外标量自由度的补偿方案（矢量交换或鬼场）都未被作者视为已解决的问题；鬼场被明确排除，矢量方案需要进一步研究 [page 9]。

作者没有讨论的限制包括：膜张力为零的假设（作用量 (1) 中未包含膜张力项）、物质场仅局域在膜上的假设、以及忽略高阶曲率项和诱导宇宙学常数的近似。这些是分析者基于文本的观察，论文本身未将其列为局限。
