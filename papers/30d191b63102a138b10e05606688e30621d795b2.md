# 可学习的融合策略：RFN-Nest 如何用残差融合网络替代手工融合规则

**原文题名**：RFN-Nest: An end-to-end residual fusion network for infrared and visible images（2021，arXiv:2103.04286v2）

## 论文要解决的核心问题

红外与可见光图像融合的常规流程包含三个环节：特征提取、融合策略、重建。作者指出，传统多尺度变换、稀疏表示（SR）、低秩表示（LRR）等方法以及早期深度学习融合方法（如 DenseFuse、NestFuse）的共同弱点是：融合策略始终是手工设计的——无论是加权相加、取最大、l1-norm 还是空间/通道注意力（SCA），都需要人为选择，且难以找到适用于不同融合任务的通用规则 [page 1][page 2]。作者的判断是，即便 NestFuse 在细节保持上表现良好，其融合策略"仍然不可学习"（the fusion strategy is still not learnable）[page 2]。

由此，论文的核心主张是：用一个可学习的残差融合网络（RFN）取代手工融合策略，配合两阶段训练和新的损失函数，可以在红外/可见光融合任务上同时更好地保留可见光细节和红外显著目标，并在主客观评价上超越现有方法 [page 2]。

## 网络结构与"可学习融合"的实现方式

RFN-Nest 由三部分组成：编码器、四个残差融合网络（RFN1−4）、基于 nest connection 的解码器（Fig.1，[page 3]）。编码器通过最大池化在四个尺度上提取多尺度深度特征；每个尺度对应一个结构相同但权重不同的 RFN；解码器利用短连接和跨层连接重建融合图像 [page 4]。

RFN 本身借鉴残差块思想（Fig.2，[page 4]）：Conv1 与 Conv2 的输出拼接后送入 Conv3，Conv6 作为第一个融合层生成初始融合特征。作者对尺度的分工有一个明确的功能假设：浅层特征保留更多细节，深层特征承载语义信息，因此浅层 RFN 与深层 RFN 分别负责细节和显著结构的保持 [page 4]。这一假设是后续损失函数设计（按尺度加权）的直接依据。

解码器采用 nest connection（Fig.3，[page 4]），作者说明这是对 UNet++ 的简化，同一架构也用于 NestFuse [page 4]。消融实验（Table 3，[page 10]）显示，去掉短连接的"No-nest"版本在多项指标上不如完整 RFN-Nest，作者据此认为 nest connection 对解码器的重建能力有实质贡献。

## 两阶段训练：为什么不能一步到位

论文的关键方法论主张是：编码器/解码器的特征提取与重建能力是融合成功的前提，用单一阶段同时训练整个网络"是不充分的"（insufficient）[page 2]。因此作者设计两阶段策略：

**第一阶段**训练自编码器（Fig.4，[page 5]），损失函数为

$$L_{auto} = L_{pixel} + \lambda L_{ssim} \quad (1)$$

其中 $L_{pixel}$ 为 Frobenius 范数下的像素损失（式2），$L_{ssim} = 1 - SSIM(Output, Input)$（式3），$\lambda$ 取 100 以平衡量级 [page 5][page 6]。训练数据为 MS-COCO 的 80000 张灰度图（256×256）[page 6]。

**第二阶段**固定编码器与解码器，仅训练 RFN（Fig.5，[page 5]），损失函数为

$$L_{RFN} = \alpha L_{detail} + L_{feature} \quad (4)$$

$L_{detail} = 1 - SSIM(O, I_{vi})$（式5）约束融合图像保留可见光细节；$L_{feature}$（式6）约束融合特征逼近可见光与红外特征的加权组合，其中 $w_1$ 按尺度取 {1, 10, 100, 1000} 以平衡各尺度损失量级，$w_{vi}$ 与 $w_{ir}$ 控制两种模态特征的相对影响 [page 5]。作者明确说明，由于 $L_{detail}$ 已约束可见光信息，$w_{ir}$ 通常应大于 $w_{vi}$ [page 5]。

这一训练策略的推理链条是：如果编码器不能提取有判别力的多尺度特征、解码器不能忠实重建，那么无论 RFN 如何融合，最终图像质量都会受限；因此必须先让自编码器达到良好的提取/重建能力，再让 RFN 在固定特征空间内学习融合。消融实验（Fig.11，[page 9]）支持这一推理：单阶段训练下融合图像增强了可见光细节，但红外显著目标丢失，"图像融合的前提没有实现"；两阶段训练则同时保留了红外目标和可见光细节。

## 损失函数参数的实证调优

论文用大量篇幅做参数消融，这构成了从"损失函数设计"到"融合性能"之间的关键证据链。

**$L_{detail}$ 是否必要**：当 $\alpha = 0$（仅用 $L_{feature}$）时，作者报告融合网络"无法获得可接受的融合结果"，主客观评价均明显退化 [page 8]。Fig.8 直观显示，$\alpha = 700$ 时融合图像保留更多源图像细节，同时红外特征仍得以维持 [page 8]。

**$w_{vi}$ 与 $w_{ir}$ 的选择**：Table 1（[page 8]）给出不同组合下的六项指标。当 $\alpha = 0$ 时，$w_{ir}$ 过小则融合图像趋近可见光、红外显著特征被抑制；$w_{ir}$ 过大（>3.0）则红外特征保留但可见光细节丢失 [page 7]。当 $\alpha = 700$ 时，作者选择 $w_{ir} = 6.0$、$w_{vi} = 3.0$，理由是这一组合在主观和客观评价上均表现最佳 [page 8]。作者还提到一个负面结果：若 $w_{vi} = 0$，即强制融合特征镜像红外特征，网络因 $L_{detail}$ 与 $L_{feature}$ 的冲突约束而无法收敛 [page 7]。

**$\alpha$ 的选择**：Table 2（[page 9]）显示 $\alpha$ 从 10 增至 700 时多数指标改善，但 $\alpha = 1000$ 时红外显著特征（黄色框中的行人）被抑制，融合图像趋近可见光 [page 8]。最终取 $\alpha = 700$，此时网络在七项指标中四项最优 [page 9]。

这些消融实验的共同逻辑是：$L_{detail}$ 与 $L_{feature}$ 之间存在张力——前者拉向可见光细节，后者拉向红外显著特征——参数调优本质上是在两者之间寻找平衡点。作者通过网格搜索和主客观联合判断确定了一组经验最优值，但并未给出理论上的最优性保证。

## 与手工融合策略的对照

Table 3（[page 10]）和 Fig.13（[page 11]）将 RFN 与五种手工策略（add、max、l1-norm、l*-norm、SCA）对比。作者报告 RFN-Nest 取得五项最优值，并认为这证明可学习融合策略在细节增强（En、SD）和特征保持（MI 等）上均优于手工规则 [page 10]。这一对照是论文"可学习融合优于手工融合"主张的最直接证据。

需要注意的是，Table 3 中"Encoder & Decoder"各行使用的是与 RFN-Nest 相同的编码器和解码器，仅融合策略不同。因此这一对照在控制变量上较为干净：性能差异可较合理地归因于融合策略本身，而非特征提取或重建能力的差异。

## 与现有方法的比较及结论的边界

在 21 对 TNO 图像上（Table 5，[page 13]），RFN-Nest 取得一项最优（SCD）和三项第三（SD、Nabf、MS-SSIM）。作者特别指出 DDcGAN 在 En、SD、MI 上数值更高，但其原因是"向融合图像引入了更多噪声和伪影" [page 13]。这一解释提示：部分客观指标（如熵、标准差）对噪声敏感，数值高不一定代表融合质量好——这是理解 Table 5 时需要注意的指标特性。

在 40 对图像上（Table 6，[page 14]），RFN-Nest 取得一项最优（SCD）、一项第二（Nabf）和两项第三（SD、MS-SSIM），作者认为这"证实了泛化能力" [page 14]。

作者在结论中称 RFN-Nest"在主观和客观评价上均取得最佳融合性能" [page 16]，但 Table 5 和 Table 6 显示这一"最佳"是就综合表现而言，并非在所有指标上均领先。这一措辞与表格数据之间存在一定张力，读者宜以表格为准。

## RGBT 跟踪实验：融合策略的迁移验证

论文第 5 节将 RFN 和损失函数迁移到 RGBT 目标跟踪任务，嵌入 AFAT 跟踪器 [page 14]。由于标注训练数据不足（GTOT、VT821、VT1000 合计仅 17.6k 帧），作者简化了 RFN 架构（Fig.17，[page 14]），并修改 $L_{detail}$ 为 $1 - SSIM(\Phi_f^m, l1(\Phi_{rgb}^m, \Phi_{ir}^m))$（式7），$L_{feature}$ 保持不变 [page 14]。

Table 7 和 Table 8（[page 15]）显示，RFN-based AFAT 在 VOT2019-RGBT 和 VOT2020-RGBT 上均优于仅输入单一模态的 AFAT，且与竞赛中的先进跟踪器具有可比性。作者据此认为 RFN 具有"广泛适用性，超越图像融合" [page 16]。这一推断的强度受限于训练数据不足和架构简化，作者也承认"当更多训练数据可用时，RFN-based 跟踪器将取得更好性能" [page 15]——这是一个明确的未来工作方向，而非当前结论。

## 结论成立的条件与未讨论的限制

综合全文，RFN-Nest 的核心结论——可学习融合策略优于手工策略——在以下条件下得到支持：

1. **编码器/解码器已充分训练**：两阶段策略的有效性依赖于第一阶段自编码器达到良好的特征提取与重建能力。若第一阶段训练不充分，第二阶段的 RFN 融合效果可能受限。论文未讨论第一阶段训练质量对最终融合性能的定量影响。

2. **损失函数参数经过调优**：$\alpha = 700$、$w_{ir} = 6.0$、$w_{vi} = 3.0$ 是在特定数据集（21 对 TNO 图像）上通过网格搜索确定的。这些参数在 40 对图像上仍表现良好，但其对其他数据集或融合任务的普适性未经系统验证。

3. **测试数据规模有限**：主实验基于 21 对和 40 对图像，虽然作者通过两个数据集验证泛化性，但样本量相对较小。Table 5 和 Table 6 中部分指标差距较小，统计显著性未报告。

4. **客观指标的解释需谨慎**：作者自己指出 DDcGAN 在 En、SD、MI 上数值更高源于噪声引入 [page 13]，这说明单一指标的高低不能直接等同于融合质量。论文未系统讨论各指标对噪声、伪影、对比度等不同失真类型的敏感度差异。

论文未讨论的限制包括：RFN 四个尺度共享架构但独立权重，参数量随尺度增加的情况未报告；推理速度未与对比方法比较；对配准误差的鲁棒性未涉及。这些是分析者基于文本的推断，非作者结论。

## 总体判断

RFN-Nest 的核心贡献在于将融合策略从手工设计转变为可学习模块，并通过两阶段训练和双损失函数（$L_{detail}$ + $L_{feature}$）实现了细节保持与显著特征增强的平衡。论文的论证链条较为完整：从问题识别（手工策略的局限）到方案设计（RFN + 两阶段训练 + 新损失），再到消融验证（参数调优、训练策略对比、融合策略对比）和外部比较（与 11 种现有方法对比、RGBT 跟踪迁移）。关键推理步骤——编码器/解码器能力是融合前提、因此需要两阶段训练——得到了消融实验的支持。结论的适用边界主要受限于参数的经验性、测试数据规模和客观指标的解释复杂性。
