# EEGLAB：把单试次脑电动力学与独立成分分析放进一个可用工具箱

**原文题名**：EEGLAB: an open source toolbox for analysis of single-trial EEG dynamics including independent component analysis
**作者**：Arnaud Delorme, Scott Makeig
**发表**：Journal of Neuroscience Methods 134 (2004), 9–21

## 一篇软件论文的论证结构

这不是一篇报告某个实验发现的论文，而是一篇介绍软件工具箱的论文。它的核心主张可以概括为：**EEG 研究不应停留在对事件相关电位（ERP）平均波形的峰值测量上；EEGLAB 这个基于 MATLAB 的开源工具箱，把单试次可视化、独立成分分析（ICA）和事件相关时频分析整合到一个统一、易用的图形界面中，从而使更全面的 EEG 分析方法能够被更广泛的研究者采用** [page 1–2]。

这个主张由两条相互支撑的线索构成。一条是**方法论论证**：为什么平均 ERP 不够、为什么需要 ICA 和时频分析。另一条是**工具论证**：EEGLAB 如何把这些方法变得可用、可复现、可扩展。前者决定了后者要包含哪些功能，后者则决定了前者能否真正落地。理解这篇论文，关键就在于看清这两条线索如何咬合。

## 为什么"只看平均 ERP"是不够的

作者的论证起点是一个对传统做法的质疑。历史上，响应平均法（response averaging）是在 1950–60 年代硬件受限的条件下发展起来的：当时研究者只能用模拟寄存器把多次试次的脑电叠加起来，第一台计算机化的平均仪（CAT，约 1962 年）进一步推广了这一做法 [page 1]。平均法的隐含假设是：与某类事件锁时的单试次 EEG 由两部分组成——一个跨试次波形和极性固定的平均 ERP，加上与实验事件完全无关的自发脑电过程。

作者指出，这个假设有两个漏洞。第一，平均会抹掉那些**不出现在平均波形中、或表现很弱的事件相关动力学**。第二，更关键的是，**正在进行的（ongoing）EEG 过程可能被实验事件部分地时间锁定和相位锁定**，从而对平均 ERP 本身有贡献 [page 1]。换句话说，平均 ERP 的某些峰值未必来自一个固定的诱发响应，而可能来自自发振荡活动被刺激部分"相位重置"（phase-resetting）后的结果。作者引用自己近期的研究（Delorme et al., 2002; Makeig et al., 2002）来支撑这一点 [page 1–2]。

这里有一个重要的推理转折：如果平均 ERP 的峰值可能来自相位重置，那么**只分析平均波形就会系统性地误读数据生成机制**。这就为引入单试次分析和时频分析提供了直接动机——必须能看到试次之间的变化，才能判断某个 ERP 特征到底是"固定诱发"还是"部分同步"。

## 从证据到工具：三个关键功能如何回应上述问题

### ERP-image：把单试次变化变成可看的二维图像

ERP-image 是回应"平均抹掉单试次信息"这一问题的可视化手段。它的构造方式在 Fig. 3(A) 中说明：把每个单试次的电位变化用颜色编码成一条水平线，再把这些线垂直堆叠起来，就得到一张二维图像 [page 3–4]。Fig. 3(B) 展示了按被试反应时排序后的 ERP-image，图像下方是相应的 ERP 平均 [page 4]。

真正体现方法论主张的是 Fig. 3(C)：作者用**给定时间/频率窗口内的 EEG 相位**作为排序变量。对每个试次，在时间 0 附近用 10-Hz 小波测量 3 个周期窗口内的振荡活动，然后按 alpha 频段相位值（−π 到 π）排序。结果显示，刺激后 200–450 ms 之间，alpha 活动的试次间相位分布是非随机的（即被部分相位重置），显著性阈值 p=0.01；而同一时段内 alpha 功率（以 dB 计）没有显著变化 [page 4]。这个对照很关键：**相位重置可以在功率不变的情况下发生**，因此仅看功率或仅看平均波形都可能漏掉这一现象。

作者也诚实地指出了 ERP-image 的局限：用某一频率做相位排序，可能掩盖其他频率的振荡现象；而且几乎所有的头皮电极记录都是多个皮层区域活动的容积传导叠加 [page 4]。正是这个"叠加"问题，把论证引向 ICA。

### ICA：把叠加的信号拆开

ICA 在论证中承担的角色是**分离容积传导造成的空间叠加**。作者的核心假设是：如果各个源的活动在时间上（近似）相互独立，ICA 就能把它们分开 [page 4]。对伪迹源来说，这个独立性假设容易理解——眼动、肌电、线噪之间通常不会可靠地相互锁相。但作者进一步指出，ICA 在实践中也能分离出**生物学上合理的脑源**，这些源的头皮图往往接近单个等效电流偶极子的投影，因而与"一块相连皮层内同步局部场活动"的投影相容 [page 5]。

作者用一段对比来论证为什么用 ICA 而不是主成分分析（PCA）。PCA 的成分在时间和空间上都正交，而实际 EEG 源来自部分同步的皮层区域，其头皮投影几乎总是重叠且非正交的；由于皮层连接偏向局部（<<1 cm），这些同步域应当主要是紧凑的，但通过容积传导，任何一块皮层的同步活动在头皮上都会广泛分布 [page 5]。因此，PCA 的小成分投影常呈"棋盘状"，不可能代表一块相连皮层内的相干活动。ICA 则被作者描述为一种更强的"旋转方法"，能适应 EEG 发生器的实际投影模式 [page 5]。

一个容易被忽略但很重要的论证细节是：**ICA 应该用于未平均的单试次数据，而不是 ERP 平均**。作者给出了两条理由。第一，如果两个或多个源总是以相同潜伏期贡献到一组平均中，在平均数据上训练的 ICA 可能把它们合并成一个成分；而在未平均数据上，ICA 可以利用它们在单试次中的相对变异性把它们分开。第二，平均过程几乎会抵消掉许多 EEG 源的活动，因此用未平均数据还能分离出那些只在短暂时间段内部分相位锁定的持续活动 [page 5–6]。Fig. 4 用样本数据集的 80 个试次展示了 infomax ICA 的结果：IC3 从额极头皮图看像是眼动伪迹，其活动谱平滑下降、ERP-image 中有明显的眼动伪迹，移除它即可在不移除其他感兴趣活动的前提下消除大部分眼动证据 [page 6]。

### 时频分析：量化功率、相位和相干

第三个功能回应的是"事件相关动力学可能不在平均波形中"这一问题。EEGLAB 提供三类主要测量 [page 6–7]：

- **ERSP（事件相关谱扰动）**：测量功率谱的平均事件相关变化，公式为对 n 个试次的谱估计取平均（公式 1）[page 7]。
- **ITC（试次间相干）**：测量特定潜伏期和频率上活动与实验事件的部分或完全同步。其中试次间相位相干（ITPC，公式 2）先归一化每个试次活动向量的长度再取复平均，只考虑相位信息；试次间线性相干（ITLC，公式 3）则不做初始归一化 [page 8]。ITC 取值 0 到 1，0 表示无同步，接近 1 表示近乎完美的相位可复现性。
- **ERCOH（事件相关交叉相干）**：测量两个通道或成分之间的同步，分相位交叉相干（ERPCOH，公式 4）和线性交叉相干（ERLCOH，公式 5）[page 9]。

Fig. 6 给出了一个把三者串起来的例子。IC4 在 500 ms 附近 12 Hz 处出现短暂功率增加，IC9 在 500 ms 后同一范围出现功率下降（Fig. 6A–B）。两者之间的相位交叉相干（Fig. 6C–D）显示，在 400–1000 ms 期间、10 Hz 以上，两成分出现部分同步（相干 ≤ 0.53），相位偏移约 −120 度；在最小相位假设下，这意味着 IC9 的高 alpha 活动比 IC4 领先约 30 ms [page 8]。

这里有一个值得注意的论证张力：ICA 把成分定义为在整个时间范围内最大化独立，但 Fig. 6 却显示这些成分在**特定的事件相关时频窗口内**可以表现出部分但统计显著的同步 [page 9]。作者引用 Delorme et al. (2002) 来处理这个表面矛盾——独立性是全局的，局部同步仍可能发生。这实际上强化了论文的方法论主张：只有同时具备 ICA 分离和时频相干分析，才能看到这种"全局独立、局部同步"的结构。

## 关键推理步骤与作者明说的假设

把上述证据串起来，论文的核心推理链是：

1. 平均 ERP 可能遗漏或误读部分事件相关动力学（因为相位重置可以贡献平均峰值）[page 1–2]。
2. 要看清这些动力学，需要单试次可视化（ERP-image）和时频分析（ERSP/ITC/ERCOH）[page 3–9]。
3. 但头皮记录是多源容积传导的叠加，必须先分离源，ICA 提供了这种分离 [page 4–5]。
4. 因此，一个把 ICA、单试次可视化和时频分析整合在一起的工具箱，能让研究者采用更全面的分析路径 [page 1–2]。

其中**最关键的一步**是第 3 步——ICA 能分离出"生物学上合理的脑源"这一主张。作者对此的支撑是：许多 ICA 识别出的合理源，其头皮图接近单个等效偶极子的投影 [page 5]。但作者也明确承认，**EEG 数据在多大程度上真正符合 ICA 假设是未知的** [page 12]。这是一个诚实的边界声明，意味着第 3 步的强度依赖于数据本身，而非算法保证。

## 结论在哪些条件下成立

作者在 Discussion 中系统列出了限制，这些限制界定了 EEGLAB 方法主张的适用边界：

**ICA 的稳定性**。infomax 算法从随机解混矩阵开始，并在每步训练前随机打乱数据时间点顺序，因此对同一数据重复分解，结果可能略有不同（头皮图、活动时间程、成分顺序都可能变）。作者建议：**在同一数据的不同分解中不稳定的特征，不应被解释**，只能视为 ICA 的"不确定性" [page 11–12]。

**数据量要求**。权重矩阵大小是通道数的平方，因此通常需要**至少数倍于通道数平方的时间点数**才能得到可靠分解。数据点可来自连续数据或多个试次；在空间结构相对平稳的假设下，更多数据只会改善分解 [page 12]。作者还报告了一个经验性观察：使用包含任务相关行为的短基线归零试次，可能比使用更长试次给出更一致的结果，因为短试次约束 ICA 聚焦于任务相关部分 [page 12]。

**线性假设**。如果数据不是底层源投影的线性叠加——主要发生在放大器在高信号水平"饱和"（clipping）或超过 A/D 转换器输入范围导致"回绕"（wrap-around）时——线性 ICA 会给出虚假结果，这类试次必须在运行 ICA 前仔细剔除 [page 12]。

**噪声与源数**。当强空间源数量远多于记录通道数时，额外源必须被混入输出成分。例如头部剧烈运动引入的阵发性噪声，或松脱电极引入的与其他电极信号非线性相关的大噪声，可能使 ICA 专门用一个成分去表示电极噪声，从而不必要地减少可用于分离其他神经和伪迹源的成分数。因此作者建议在**仔细修剪过的"干净"数据试次**上训练 ICA，但可以保留空间上刻板的伪迹活动（眨眼、眼动、重复肌电等）[page 12–13]。

**时频分解的限制**。EEGLAB 的时频分解限于 FFT、多锥（multitaper）分析和一种正弦小波，未实现 Hilbert 方法（尽管作者引用 Le Van Quyen et al., 2001 指出结果差异不大）；频率间的双相干（bi-coherence）也尚不能评估 [page 11]。

**统计与跨条件比较**。被试内显著性用非参数方法（通过打乱潜伏期、试次或两者来构造替代数据分布），多重比较需降低阈值（如 Bonferroni、Holm）。跨条件或被试比较要么用参数检验，要么累积各被试的显著性结果；作者指出 `tftopo()` 采用的方法在统计上是保守的 [page 11]。

**计算与内存**。MATLAB 把所有浮点数转为 64 位双精度，处理大数据集需要大量内存；在 Linux 2GB/进程限制下，长 256 通道数据集可能无法分析。作者把最耗时的 `runica()` 转成 C 版本 `binica()`，但在 MATLAB v6 下加速比似乎远小于 v4 下的约 10 倍 [page 13]。这些是工具层面的现实约束，而非方法本身的缺陷。

## 工具设计如何服务于方法论主张

论文用相当篇幅描述 EEGLAB 的三层结构 [page 9–10]：顶层是图形界面，让不熟悉 MATLAB 的用户通过菜单操作；中层是命令历史，用户可以把 GUI 操作转成批处理脚本；底层是独立信号处理函数，经验用户可以绕过 EEG 数据结构直接调用。Table I 用三个脚本示例说明：从 `pop_erpimage(EEG)` 的纯交互调用，到带参数的 `pop_erpimage(...)`，再到直接调用 `erpimage()` 并传入标准 MATLAB 数组 [page 10]。

这个设计不是无关紧要的细节，而是论文主张的一部分。作者反复强调，过去 ICA/EEG 工具箱（Makeig et al., 1997）虽然被 50 多个国家的 5000 多名研究者下载，但**只有愿意写自定义脚本的熟练用户才能使用** [page 2–3]。EEGLAB 的目标正是降低这个门槛，同时不牺牲高级用户的可扩展性。开源、GNU 公共许可证、约 300 个 MATLAB 函数、5 万行代码、插件机制、夜间测试脚本——这些安排共同支撑"让更全面的分析方法被更广泛采用"这一目标 [page 10–11]。

## 结语

这篇论文的论证力量不在于报告了某个新发现，而在于**把一组方法论主张（平均不够、需要单试次和时频分析、需要 ICA 分离源）与一个具体可用的工具绑定在一起**。它的证据主要是功能演示（Fig. 3–6 用样本数据集展示各功能能揭示什么）和设计论证（为什么这样组织工具、为什么 ICA 优于 PCA、为什么用未平均数据训练）。结论的成立依赖于若干明确声明的条件：数据要足够多、要近似线性、源数不能远超通道数、ICA 结果要跨分解稳定。作者对这些条件的交代相当坦率，尤其是承认"EEG 数据在多大程度上符合 ICA 假设是未知的"以及"不同 ICA 算法结果差异的生理意义尚未被系统检验" [page 12]。因此，EEGLAB 的贡献应当被理解为**提供了一套让研究者能够探索这些问题的基础设施**，而不是宣称这些问题已经被解决。
