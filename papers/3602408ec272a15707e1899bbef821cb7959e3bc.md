# 把原子与光子的腔量子电动力学搬进电路：单光子与库珀对盒的强耦合

**原文题名**：Circuit Quantum Electrodynamics: Coherent Coupling of a Single Photon to a Cooper Pair Box
**作者**：A. Wallraff, D. Schuster, A. Blais, L. Frunzio, R.-S. Huang, J. Majer, S. Kumar, S. M. Girvin, R. J. Schoelkopf（耶鲁大学）
**年份**：2004（发表于 Nature）
**DOI/编号**：arXiv:cond-mat/0407325v1

## 论文要证明什么

这篇论文的核心主张只有一句：在完全固态的电路里，可以让一个超导两能级系统（库珀对盒，Cooper pair box, CPB）与腔中单个微波光子发生**相干强耦合**，即耦合强度 g 同时超过腔的衰减率 κ 和量子比特的退相干率 γ，从而进入腔量子电动力学（CQED）的强耦合区 [page 1]。作者强调这是"首次在固态系统中观测到单个原子与单个光子的强耦合腔 QED" [page 1]。

要支撑这个结论，作者需要同时证明三件事：耦合确实存在且足够强；系统确实处于量子基态（即"单光子"是真空涨落而非热噪声）；以及耦合的相干性没有被耗散淹没。论文的实验设计正是围绕这三点展开的。

## 为什么选这个体系：量级上的先天优势

作者选择 CPB 加共面波导谐振器，不是任意搭配，而是基于一个量级论证。真空 Rabi 频率 νRabi = 2dE₀/h 要超过耗散率，需要大的偶极矩 d 和大的真空电场 E₀ [page 1]。CPB 的有效电偶极矩可以比碱金属原子基态大 10⁴ 倍以上，比典型 Rydberg 原子还大 10 倍；而准一维传输线腔的模体积极小（约 10⁻⁶ 立方波长），使真空态下的均方根电压 Vrms ≈ 1 µV、电场 Erms ≈ 0.2 V/m，比原子微波腔 QED 大约 100 倍 [page 1–2]。两者相乘，正是作者此前理论工作 [15] 预言的强耦合条件。这是全文的物理出发点：不是靠提高测量精度，而是靠体系本身把 g 做大。

## 从哈密顿量到可测信号

论文的推理链条建立在 Jaynes-Cummings 哈密顿量 HJC = Hr + Ha + ħg(a†σ₋ + aσ₊) 上 [page 3]。谐振器是谐振子 Hr = ħωr(a†a + 1/2)，CPB 是可控两能级系统 Ha = −½(Eel σx + EJ σz)，其能级间隔 Ea = ħωa = √(EJ,max²cos²(πΦb) + 16EC²(1−ng)²) [page 2–3]。耦合项 ħg = eVrmsCg/CΣ 就是偶极相互作用能 dE₀ [page 3]。

关键的一步是：作者并不直接测量耦合项，而是通过**色散区**和**共振区**两种可观测行为来间接确认它。

在色散区（|Δ| ≫ g，Δ = ωa − ωr），对角化给出有效哈密顿量，其中谐振器频率被移动为 ωr ± g²/Δ，符号取决于量子比特态 σz = ±1 [page 3]。这意味着量子比特的状态会改变谐振器的透射相位 φ，相位移动量为 tan⁻¹(2g²/κΔ) [page 4]。作者据此把 CPB 当作一个"其有效电容依赖于 σz 的电路元件"来读 [page 3]。这一读出的实验证据是图 3：相位移动随门电荷 ng 以 2e 为周期振荡，且在 EJ/h < νr 时量子比特两次扫过共振，相位在 Δ 变号时改变符号 [page 4–5]。图 3d 中相位对 (ng, Φb) 的密度图显示共振条件 νa = νr 处相位突然变号，作者由此拟合出 EJ,max = 8.0 (±0.1) GHz 和 EC = 5.2 (±0.1) GHz [page 6]。这一步的意义是：色散区的相位行为完全符合 HJC 的预言，说明耦合项真实存在，且量子比特参数可原位控制。

## 共振区的决定性证据：真空 Rabi 劈裂

色散区只证明耦合存在，不直接证明"单光子"层面的相干交换。真正的判据在共振区（Δ = 0）。理论预言：当系统制备在 |0, ↑⟩ 且 ωa = ωr 时，会在 |0, ↑⟩ 与 |1, ↓⟩ 之间以 νRabi = g/π 振荡，本征态劈裂为 E± = ħ(ωr ± g) [page 3]。

实验上，作者先把谐振器冷却到基态（T < 100 mK，热占据 n < 0.06），用远失谐探针测得洛伦兹线宽，定出 κ/2π = 0.8 MHz [page 6]。然后把探针功率降低 5 dB，在共振点测透射谱，观察到两条清晰分开的谱线，间距 νRabi ≈ 11.6 MHz [page 6]，见图 4b。这个数值远大于 κ/2π = 0.8 MHz 和拟合得到的 γ/2π = 0.7 MHz，因此满足强耦合条件 g > [γ, κ] [page 3, 6]。

这里有一个容易被忽略但很关键的对照：图 4b 中，若假设腔内热光子数 n = 0.5，计算出的透射谱（浅蓝线）与数据明显不符；而 n = 0.06（红线）与数据吻合 [page 6]。由于耦合系统的非谐性，热光子会压低透射并产生额外峰 [page 6]。因此，观测到的双峰不仅证明耦合，还同时证明系统确实冷却到接近基态——即参与耦合的是真空涨落意义上的"单光子"，而非热噪声。这是把"单光子"三字坐实的一步。

图 4c 进一步显示，当门电荷偏离 ng = 1 时，两个 Rabi 峰从光子与量子比特等权重的状态演化为以光子为主，峰位与 HJC 精确对角化结果（实线）一致 [page 6]。图 4d 对另一通量偏置重复测量，出现两次反交叉，同样与理论吻合 [page 6]。这些是共振区结论的稳健性检验。

## 结论成立的条件与作者承认的边界

论文的结论有明确的适用条件，作者也点出了若干限制。

其一，强耦合的判据是 g > [γ, κ]，这是一个不等式条件，而非绝对性质 [page 3]。实验值 g/2π ≈ 5.8 MHz（由 νRabi = g/π ≈ 11.6 MHz 推得）对 κ/2π = 0.8 MHz 和 γ/2π = 0.7 MHz 有余量，但并非数量级上的压倒性优势。因此"强耦合"是就本体系参数而言成立，不能外推为任意电路都如此。

其二，退相干来源中，作者明确指出 γ 的贡献来自电磁环境耦合，但"可能由非辐射过程主导"，相关退相干源包括衬底或隧道结势垒中低频电荷涨落，以及超导薄膜中的磁通运动 [page 3]。这些是作者承认但未在本实验中分离的机制。论文在讨论部分提出，可用谐振器把量子比特与电磁环境涨落解耦来研究非辐射退相干 [page 7]——这是未来方向，不是已完成的结论。

其三，作者明确说明，虽然本征态 |±⟩ 是纠缠态，但"其纠缠特性未在当前 CQED 实验中被研究" [page 3]。因此本文证明的是相干耦合与能级劈裂，不是纠缠本身。把结论读成"实现了纠缠"会超出原文。

其四，色散区的 QND 读出、ac-Stark 位移、Lamb 位移等，作者说"除 Lamb 位移外，所有项都在实验结果中被清晰识别" [page 3]。Lamb 位移未被观测，这是一个作者自己标注的缺口。

其五，关于应用前景（量子信息处理、量子通信、单光子产生与探测、量子总线耦合厘米级距离的量子比特等），作者用的是 "may"、"will find application"、"potentially" 等措辞 [page 1, 7]，属于展望而非本实验证明的结论。

## 推理中关键的一步

整篇论文的论证枢纽，是把"耦合强度 g"从一个哈密顿量参数转化为两个独立可测的观测量：色散区的相位移动 g²/Δ 和共振区的劈裂 2g。前者证明耦合存在并给出量子比特参数，后者给出 g 的数值并证明相干交换。两者相互独立又相互印证，且都与 HJC 的定量预言吻合。正是这种"同一参数、两种测量、一致结果"的结构，使"强耦合"的主张不只是拟合出来的，而是被交叉验证的。

需要说明的是，上述"论证枢纽"的表述是本文分析者的重建，论文本身并未以这种方式自我总结；论文的显式主张是"观测到强耦合"以及"特征参数可设计、可原位控制" [page 1, 7]。

## 一处需要留意的文本疑点

在色散区有效哈密顿量中，量子比特能级间隔写作 ΔEa = ħ(ωa + 2a†a g²/Δ + g²/Δ)，其中 2a†a g²/Δ 为 ac-Stark 位移，g²/Δ 为 Lamb 位移 [page 3]。此处符号与系数在提取文本中可能存在排版或 OCR 歧义（例如 a†a 与光子数 n̂ 的对应、各项符号），不宜作为精确定量依据；但作者对"线性于光子数的项为 ac-Stark、常数项为 Lamb"的定性区分是清楚的。这一疑点不影响本文关于强耦合的主要结论，因为主要结论依赖的是共振区劈裂和色散区相位符号变化，而非该式的精确系数。
