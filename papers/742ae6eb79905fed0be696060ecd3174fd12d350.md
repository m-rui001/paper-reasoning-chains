# 毫米波能否撑起5G蜂窝网络：28 GHz与38 GHz城市传播测量的论证分析

**原文题名**：Millimeter Wave Mobile Communications for 5G Cellular: It Will Work!
**作者**：Theodore S. Rappaport 等（NYU WIRELESS）
**年份**：2013
**DOI**：10.1109/ACCESS.2013.2260813

## 一篇以测量数据回应怀疑论的论文

这篇论文的标题本身就是一个论断——“It Will Work!”。作者要反驳的是无线工程界一个流传甚广的成见：毫米波（mm-wave）频段会因雨衰、大气吸收和穿透损耗而无法用于移动蜂窝通信。论文的论证策略不是理论推演，而是用两座城市（纽约曼哈顿/布鲁克林与奥斯汀）在两个频段（28 GHz 与 38 GHz）上的大量实测数据，说明只要配合可转向定向天线和约 200 米的小区半径，毫米波蜂窝通信在密集城市环境中是可行的 [page 1]。

核心结论可以拆成三层：其一，28 GHz 和 38 GHz 在 200 米量级的小区中，雨衰和大气吸收带来的额外损耗可以忽略；其二，实测路径损耗、时延扩展和中断率表明，200 米小区半径在两种城市环境中都能实现稳定覆盖；其三，密集城市环境中的丰富多径和定向天线的角度选择性，反而为波束合并和链路增强提供了可利用的分集资源。下面按论证的实际推进顺序展开。

## 先排除“雨衰与大气吸收”这一常见反对理由

作者没有一上来就展示自己的测量，而是先处理最容易被引用的反对意见。图 1 给出不同降雨率下各频段的雨衰曲线：在 28 GHz、25 mm/hr 的强降雨下衰减为 7 dB/km，若小区半径为 200 米，折算下来只有 1.4 dB [page 4]。图 2 给出大气吸收：28 GHz 在 200 米上仅 0.012 dB，38 GHz 为 0.016 dB [page 4]。作者据此指出，当今天城市小区尺寸已在 200 米量级时，这些损耗相对于链路预算并不构成障碍。

这一步的推理关键在于**把“每公里损耗”换算到“小区尺度损耗”**。雨衰和大气吸收的数值本身并不小（7 dB/km 对毫米波而言是显著量级），但论证成立的前提是小区半径足够小。作者明确把这一前提写进了论证：正是因为蜂窝架构本身在向小小区演进，毫米波才“自然”绕开了这一障碍 [page 4]。换言之，结论依赖于“200 米小区”这一架构假设，而非频段本身的物理特性。

## 穿透与反射：室外与室内的强隔离

第二组证据来自建筑材料层面的测量。表 3 显示，28 GHz 下着色玻璃和砖柱的穿透损耗分别为 40.1 dB 和 28.3 dB，而室内常见的透明玻璃和干墙仅 3.6 dB 和 6.8 dB [page 6]。表 5 的反射系数进一步印证：室外着色玻璃反射系数高达 0.896，混凝土 0.815，而室内透明玻璃和干墙分别为 0.740 和 0.704 [page 6]。作者由此得出一个对系统设计有直接意义的推论：室外信号难以穿透建筑外墙，因此室内网络与室外网络天然隔离，干扰被限制在预期区域内；但代价是室外到室内的覆盖需要额外手段，例如在商业和住宅入口处部署数据“shower”、中继或接入点以完成切换 [page 7][page 13]。

表 4 则把测量从单一材料推进到真实办公环境中的多重遮挡。作者用 8 个接收点、逐层增加遮挡物（墙、门、隔间、电梯井）来测量累积穿透损耗，并区分“信号可捕获”（相对 5 米自由空间损耗小于 64 dB）、“信号可检测”（64–74 dB）和“无信号”（大于 74 dB）三档 [page 6]。一个值得注意的细节是：25.6 米与 11.4 米两个接收点的穿透损耗几乎相同（均为 45.1 dB），尽管前者遮挡更多——作者据此指出穿透损耗主要取决于遮挡物的数量和类型，而非收发距离 [page 7]。唯一的“无信号”点出现在 35.8 米处，原因是金属电梯井无法穿透。这一负面结果被作者如实报告，并用于支持“遮挡物材质比距离更关键”的判断。

## 城市传播：路径损耗指数与 200 米覆盖边界

第三组证据是论文最核心的部分：纽约和奥斯汀的室外传播测量。硬件为 400 Mcps 滑动相关器信道探测器，多径分辨率 2.3 ns，发射功率 +30 dBm，使用 10° 波束宽度 24.5 dBi 和 30° 波束宽度 15 dBi 两种喇叭天线，总动态范围约 178 dB [page 5][page 6]。

图 6 给出 28 GHz 纽约测量的路径损耗指数（PLE）：最佳 LOS 为 n = 1.68，全部 LOS 测量平均为 n = 2.55，全部 NLOS 平均为 n = 5.76；但当把收发天线指向最佳角度组合时，NLOS 的“最佳”PLE 降至 n = 4.58，改善 11.8 dB/decade [page 8]。作者强调，n = 4.58 与今天 700 MHz–2.6 GHz 频段的 NLOS 路径损耗几乎相同 [page 8]。这一步是论证的关键转折：**NLOS 场景下毫米波的劣势并非不可改变，而是高度依赖天线指向**。定向天线的波束对准把“最坏情况”的 n = 5.76 拉回到与现有蜂窝频段相当的水平。

图 7 的中断研究给出覆盖边界：曼哈顿测量中，所有成功捕获信号的位置都在 200 米以内；57% 的位置为中断，且大多数中断发生在 200 米以外 [page 8]。图 8 进一步把覆盖距离与天线增益、PLE 联系起来：在 119 dB 无天线增益动态范围和 10 dB SNR 要求下，PLE = 5.76 的高度遮挡环境配合 49 dBi 收发合并增益，覆盖距离约 200 米，与实测吻合 [page 9]。作者由此推断，可以通过提高天线增益来扩大覆盖，或在 LOS 条件下减少天线增益（或发射功率）。

38 GHz 奥斯汀的测量（图 11）给出更低的 PLE：LOS 为 n = 2.30，NLOS 为 n = 3.86，最佳 NLOS 为 n = 3.2 [page 11]。作者把这一差异归因于奥斯汀相对稀疏的城市环境，而非频段本身 [page 11]。中断研究同样显示 200 米内无中断，200 米外 52.8% 中断 [page 11]。两个城市、两个频段都指向同一个 200 米覆盖半径，这是论文结论最有力的交叉验证。

## 时延扩展与多径：密集环境是负担也是资源

图 9 的极坐标图展示了一个 NLOS 位置的到达角分布：在 36 个接收方位角中有 22 个成功建立链路，且多径分量分布在多个指向角上 [page 10]。作者把这种角度分集解读为可用于波束合并和链路改善的资源 [page 10]。小尺度衰落测量（图 10）显示，在 10 波长（107 mm）线性轨道上以半波长步进移动时，接收功率变化仅约 ±3 dB，说明小尺度移动对到达角和接收功率影响很小 [page 10]。

时延扩展方面，图 13 显示 28 GHz 纽约测量的 RMS 时延扩展在 170 米以内大致持平，超过 170 米后下降——作者解释为路径损耗过大导致多径功率衰减到零 [page 12]。图 15 的 CDF 显示 NLOS 下多数多径分量 RMS 时延扩展低于 200 ns，部分高达 700 ns；而图 16 显示 38 GHz 奥斯汀的 NLOS 平均和最大 RMS 时延扩展仅为 12.2 ns 和 117 ns [page 12]。作者再次把差异归因于城市密度而非频段 [page 12]。图 17 和 18 分别给出两地的时延扩展-路径损耗线性拟合，28 GHz 下时延扩展随路径损耗增加，38 GHz 下在 100–160 dB 范围内平均时延扩展几乎恒为 14 ns [page 12]。

## 结论成立的条件与作者承认的边界

把上述证据串起来，论文的推理链条是：雨衰/大气吸收在 200 米尺度可忽略 → 建筑穿透损耗高但带来室内外隔离 → 定向天线把 NLOS 路径损耗拉回现有频段水平 → 两城市两频段实测均支持 200 米覆盖半径 → 丰富多径和角度分集可被利用。每一步都有对应的图表支撑。

但结论的成立有明确条件，其中一些是作者明说的，一些是文本本身透露的：

**小区半径必须足够小。** 200 米是贯穿全文的核心数字，雨衰换算、覆盖边界、中断率都以此为前提。作者没有论证 200 米小区在部署成本或站址获取上是否可行，这是架构层面的假设而非本文的测量结论。

**定向天线与波束对准是必要条件。** NLOS 的 n = 4.58 是在“最佳角度组合”下取得的，而 n = 5.76 是未对准时的平均值 [page 8]。这意味着系统必须能够找到并维持最佳波束指向，否则性能会显著退化。论文用机械旋转喇叭天线模拟波束扫描，并未验证实际可转向阵列在移动场景下的波束跟踪能力。

**环境依赖性明显。** 纽约与奥斯汀的 PLE 和时延扩展差异被作者归因于城市密度 [page 11][page 12]。这意味着论文的定量结论（如具体 PLE 值）不能直接外推到其他城市，200 米这一数字虽然在两地一致，但其普适性仍需更多环境验证。

**测量本身的限制。** 发射功率 +30 dBm 被描述为“低功率 femtocell 的典型值” [page 5]；接收端使用 AC 电源而非电池 [page 6]；测量在 FCC 实验许可下进行 [page 13]。这些是实验条件，作者未声称已解决实际部署中的功耗、回传和移动性管理问题。此外，论文的“中断”定义基于特定硬件动态范围和 10 dB SNR 阈值 [page 9]，换用不同硬件，中断率数字会变化。

**作者明确承认的局限**包括：测量仅在两个城市、两个频段进行；小尺度衰落测量仅在有限轨道上完成；统计信道模型（SSCM）被提出为后续工作方向而非本文成果 [page 4][page 13]。论文没有讨论毫米波在高速移动、雨雪天气下的实际链路性能，也没有给出端到端系统容量或能效的验证。

## 论证的力度与未竟之处

这篇论文的贡献在于把“毫米波能否用于蜂窝”从一个定性争论转化为可测量的工程问题，并用两城市两频段的交叉数据给出了一致的 200 米覆盖结论。其论证最有力的地方是**把频段特性与架构选择绑定**：雨衰不是被否认，而是被换算到小区尺度后重新评估；NLOS 路径损耗不是被掩盖，而是通过天线指向优化拉回到可比水平。这种“条件化”的论证方式比单纯宣称“毫米波可行”更严谨。

未竟之处同样明显。论文证明了“在特定测量条件下、特定小区半径内、配合定向天线，毫米波链路可以建立”，但从中到“5G 蜂窝将采用毫米波”之间，还隔着波束跟踪、移动性、功耗、成本、标准化等大量工程问题。作者在结论中把这些留给“未来十年的 5G 发展” [page 13]，这是诚实的边界划定。读者若把本文读作“毫米波蜂窝已被证明可行”，就超出了数据本身能支撑的范围；若读作“毫米波蜂窝的物理层障碍已被实测数据大幅削弱”，则与论文的证据强度相符。
