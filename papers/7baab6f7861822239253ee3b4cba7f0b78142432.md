# 二十年目标检测的技术演进：一篇综述如何组织证据与判断

**原文题名**：Object Detection in 20 Years: A Survey（arXiv:1905.05055v3，2023 年 1 月）

这篇综述的目标不是提出一个新检测器，而是把 1990 年代到 2022 年间目标检测的技术变迁整理成一条可读的演化线索。作者的核心主张可以概括为：目标检测经历了从"传统手工特征"到"深度学习"两个历史阶段，其内部由若干可辨识的技术范式（多尺度检测、上下文引导、难负样本挖掘、损失函数、非极大值抑制）逐步演化，而近年来的加速技术与新范式（无锚框、Transformer、端到端）正在把这一领域推向新的方向。下面按论文自身的论证结构，说明这些主张各自依赖什么证据、推理的关键一步在哪里、以及结论在什么条件下成立。

## 一条以"里程碑检测器"为骨架的时间线

论文开篇即给出一个被广泛接受的分期判断：2014 年前为"传统目标检测时期"，2014 年后为"基于深度学习的检测时期"，并以图 2 的路线图呈现 [page 2]。这一分期不是凭印象划分，而是由若干里程碑检测器的出现时间与性能节点支撑的。

传统时期的三个节点是 VJ 检测器（2001）、HOG（2005）和 DPM（2008）。作者对 VJ 的论证方式是：它首次在无约束条件下实现人脸实时检测，在 700MHz Pentium III CPU 上比同期算法快数十甚至数百倍，其速度来自"积分图""特征选择""检测级联"三项技术 [page 2]。这里的关键推理是——滑窗检测本身计算量巨大，VJ 的贡献不在于改变滑窗范式，而在于用三项工程技巧把这一范式的计算代价压下来。HOG 的论证则落在特征设计上：为平衡特征不变性与非线性，HOG 在均匀间隔的 cell 上计算、在 block 上做重叠局部对比度归一化 [page 2]。DPM 被作者称为传统方法的"缩影"，其"分而治之"哲学——把"车"的检测分解为车窗、车身、车轮的检测——以及后续扩展出的混合模型、难负样本挖掘、边界框回归等思想，被明确指出仍深刻影响今天的检测器 [page 2]。这一句是全文一个重要的桥接：作者并非把传统方法当作被淘汰的旧物，而是把它们当作现代检测器若干组件的思想来源。

深度学习时期的证据主要是一组性能数字，集中在图 3 [page 3]。RCNN 把 VOC07 mAP 从 DPM-v5 的 33.7% 提升到 58.5%，但每张图需 14 秒（GPU）[page 3]；SPPNet 通过空间金字塔池化层避免重复计算卷积特征，比 R-CNN 快 20 倍以上而 VOC07 mAP 达 59.2% [page 3]；Fast RCNN 把 VOC07 mAP 提到 70.0%，速度比 R-CNN 快 200 倍以上 [page 3]；Faster RCNN 引入区域提议网络（RPN），成为首个接近实时的深度学习检测器（COCO mAP@.5=42.7%，VOC07 mAP=73.2%，17fps with ZF-Net）[page 3]。这条链条的推理逻辑是清晰的：每一代都在解决上一代暴露的具体瓶颈——RCNN 的瓶颈是重叠提议上的冗余特征计算，SPPNet 的瓶颈是多阶段训练与只微调全连接层，Fast RCNN 的瓶颈是提议检测本身，Faster RCNN 用 RPN 把提议生成也纳入网络。作者由此得出一个判断：从 R-CNN 到 Faster RCNN，提议检测、特征提取、边界框回归等模块"逐渐整合进一个统一的端到端学习框架" [page 3]。这是全文对两阶段检测器演化方向的核心概括。

单阶段检测器的论证则围绕"速度与精度的权衡"展开。YOLO 的快速版达 155fps、VOC07 mAP=52.7%，增强版 45fps、mAP=63.4%，但作者明确指出其定位精度相比两阶段检测器有下降，尤其对小物体 [page 4]。SSD 通过多参考与多分辨率检测显著改善单阶段检测器对小物体的精度（COCO mAP@.5=46.5%，快速版 59fps）[page 4]。RetinaNet 的论证是全文少见的"归因式"论证：作者指出单阶段检测器多年落后于两阶段，T.-Y. Lin 等人探究原因后认为，密集检测器训练中极端的正负样本类别不平衡是"核心原因"，于是提出 focal loss 重塑标准交叉熵损失，使检测器更关注难分样本，从而让单阶段检测器达到与两阶段相当的精度（COCO mAP@.5=59.1%）[page 4]。这里的关键一步是把"性能差距"归因到一个可操作的训练问题（类别不平衡），再用一个损失函数设计去验证这一归因——如果归因正确，改损失就应缩小差距，而实验结果与这一预测一致。

## 多尺度、上下文、难负样本、损失与 NMS：五条技术演化线

论文第 II-C 节把检测系统的若干"基本构件"单独抽出，各自画出一条演化线（图 5–8）。这种组织方式本身传达了一个判断：检测器的进步不只是新架构的堆叠，而是若干可分离的技术维度各自演进、又相互组合。

多尺度检测的演化被分为五个阶段：特征金字塔+滑窗、基于物体提议的检测、深度回归与无锚框检测、多参考检测、多分辨率检测 [page 6]。作者指出，多参考检测（即锚框）与多分辨率检测"如今已成为最先进检测系统的两个基本构件" [page 7]。这一判断的证据是：Faster RCNN、YOLO、SSD、FCOS 等主流检测器都建立在这两项技术之上。

上下文引导的演化被分为局部上下文、全局上下文、上下文交互三类 [page 7]。作者引用早期发现——加入面部边界轮廓等局部上下文区域能显著提升人脸检测，加入少量背景信息能提升行人检测 [page 7]——作为局部上下文有效的证据。全局上下文则从 Gist 统计摘要，发展到用空洞卷积、可变形卷积、池化获得大感受野，再到用注意力机制（non-local、Transformer）获得全图感受野 [page 7]。这一段的推理是：上下文之所以有用，是因为视觉物体通常嵌入在典型环境中，大脑利用物体与环境的关联辅助感知 [page 7]；检测器模仿这一机制的方式随可用工具而变化。

难负样本挖掘的演化被作者明确框定为"不平衡学习问题"：滑窗检测器中背景与物体的比例可达 10⁷:1 [page 8]。Bootstrap 早期用于减少训练计算量，后来成为 DPM 和 HOG 解决数据不平衡的标准技术；深度学习时代初期因算力提升被短暂弃用，检测器改用简单平衡正负窗权重，但作者指出这"不能完全解决"不平衡问题，于是 bootstrap 在 2016 年后被重新引入，另一条路是设计新损失函数（如 focal loss）[page 8]。这里值得注意的是作者对"算力提升导致技术回退、问题重现又导致技术回归"这一循环的呈现——这是一个关于技术演化非线性的观察，而非简单的进步叙事。

损失函数的演化围绕分类损失与定位损失展开，公式 (1) 给出一般形式：L(p, p*, t, t*) = L_cls.(p, p*) + βI(t)L_loc.(t, t*)，其中 I(t) 在 IoU{a, a*} > η 时为 1，否则为 0 [page 8]。作者论证分类损失从 MSE/L2 转向交叉熵，理由是"分类预测是概率，CE 损失比 L2 损失有更大的误分类代价和更低的梯度消失效应" [page 8]。定位损失从 L2 到 Smooth L1（公式 2），再到 IoU loss（公式 3，IoU loss = −log(IoU)），理由是"四个表示边界框的数 (x, y, w, h) 被当作独立变量，但它们之间存在相关性；相同的 Smooth L1 值会有完全不同的 IoU 值" [page 8]。后续 G-IoU、DIoU、CIoU 的改进被简述为逐步纳入重叠面积、中心点距离、长宽比三个几何度量 [page 9]。这一段的推理是：损失函数应当与最终评价指标（IoU）对齐，否则优化目标与评估目标之间存在错位。

NMS 的演化被分为贪心选择、边界框聚合、基于学习的 NMS、无 NMS 检测器四类 [page 9]。作者对贪心选择的批评具体而明确：最高分框未必是最佳拟合、可能抑制邻近物体、不抑制假阳性 [page 9]。无 NMS 检测器（CenterNet、DETR、POTO）被作者评价为"更接近人类视觉感知系统，也是目标检测未来的一种可能路径" [page 9]——这是一个带推测语气的判断，读者应注意其强度。

## 加速技术：三个层次的分解

第 III 节把加速技术分为检测流水线、检测器骨干、数值计算三个层次（图 9）[page 9–10]。这一分类本身是一个分析框架，而非实验结论。其中较有证据支撑的是特征图共享计算（对整图只算一次特征，获得数十甚至数百倍加速）[page 10]、级联检测（粗到细过滤）[page 10]、以及积分图加速 HOG（图 11，在行人检测中实现数十倍加速且不损失精度）[page 11]。深度可分离卷积的计算量从 O(dk²c) 降到 O(ck²)+O(dc)（图 10e）[page 11]，这是一个可验证的复杂度推导。作者对网络剪枝、量化、轻量网络设计、NAS 的讨论多为方法罗列，证据强度弱于前述性能对比，读者宜将其视为领域概览而非因果论证。

## 近年进展与未来方向：从证据到推测的过渡

第 IV 节讨论近期进展，包括超越滑窗检测（关键点、集合预测）、旋转与尺度鲁棒检测、更好的骨干网络、定位改进、分割损失学习、对抗训练、弱监督检测、域适应 [page 11–14]。其中图 13 给出 Faster RCNN、R-FCN、SSD 在不同骨干下的 COCO 精度对比 [page 13]，支撑"检测精度高度依赖特征提取网络"这一判断。作者还提到 COCO 上排名前十的检测方法"全部基于 Transformer"，且 Transformer 与 CNN 的性能差距"逐渐扩大" [page 12]——这是一个基于排行榜的观察，但论文未给出具体数值，读者应注意其证据形式是趋势陈述而非受控比较。

第 V 节的未来方向（轻量检测、端到端检测、小物体检测、3D 检测、视频检测、跨模态检测、开放世界检测）[page 14]属于作者的前瞻判断，不是从实验数据推出的结论。作者用"may include but are not limited to""holds great promise"等措辞，读者应把这些视为研究议程建议，而非已验证的预测。

## 结论成立的条件与边界

这篇综述的核心结论——"目标检测经历了两个历史阶段，并由若干可分离的技术维度演化驱动"——在以下条件下成立：其一，分期以 2014 年 RCNN 为界，这是一个被作者称为"广泛接受"的约定 [page 2]，但分期本身是叙事选择，边界附近的工作（如 2013 年的 DNN Det.、Overfeat）在图 5 中被归入不同阶段，说明分期是渐进而非突变的。其二，性能数字（mAP、fps）来自不同数据集（VOC07、VOC12、COCO）和不同硬件条件，跨检测器的直接比较需谨慎；作者在图 3 中并列展示这些数字，但未统一实验条件。其三，作者对"某技术是某性能提升的原因"的归因，多数是引用原论文的自我解释（如 RetinaNet 对类别不平衡的归因），综述本身未做独立验证。其四，未来方向部分是议程性的，不应被读作经验结论。

论文没有系统讨论的局限包括：不同检测器在相同硬件、相同训练 schedule 下的受控对比；mAP 与 fps 之外的实际部署约束（内存、功耗）；以及综述自身承认的"忽略技术细节、聚焦演化"的定位 [page 1] 所带来的深度取舍。这些是文本未覆盖的边界，读者不宜将其读作作者的否定判断。

总体而言，这篇综述的论证力量主要来自两条线：一条是以里程碑检测器和性能数字为节点的时间线，另一条是把检测系统拆成多尺度、上下文、难负样本、损失、NMS 五个可分离维度的演化线。前者提供"发生了什么"的证据，后者提供"为什么会这样演化"的解释框架。两条线交汇处——即现代检测器的若干组件可追溯到传统方法的思想——是全文最有价值的判断，也是读者理解这一领域"变与不变"的关键。
