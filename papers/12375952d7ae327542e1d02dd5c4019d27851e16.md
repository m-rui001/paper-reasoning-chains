# 当固体在气相中遇见液体：等离子体Ag/Cu/PEG纳米流体的制备、稳定性与界面相互作用

**原文题名**：Plasmonic Ag/Cu/PEG Nanofluids Prepared when Solids Meet Liquid in the Gas Phase
**年份**：2023（Accepted Manuscript，2022年12月在线）
**DOI**：10.1039/D2NA00785A

---

## 一种“反相”纳米流体的制备逻辑

这篇论文的核心主张是：利用两个独立的溅射基气体聚集团簇源（gas aggregation cluster source, GAS），可以在不使用任何溶剂、化学试剂或纯化步骤的条件下，将Ag和Cu纳米颗粒（NPs）直接沉积到真空兼容的聚乙二醇（PEG, 400 g/mol）中，形成仅含金属NPs和宿主液体的二元纳米流体 [page 3]。这一方法的关键特征在于将NPs的气相合成与嵌入液体的过程解耦：金属在独立真空腔中被直流磁控溅射，在冷惰性气体（Ar）中成核生长，再通过气流输运到沉积腔，沉积在PEG表面 [page 3–4]。

作者的目标不仅是展示制备能力，更在于回答几个相互关联的问题：NPs如何穿透真空/液体界面并扩散进入PEG本体？Ag和Cu在PEG中的稳定性差异从何而来？PEG分子如何吸附在NPs表面，这种吸附能否阻止团聚？双金属体系中Ag和Cu是否发生相互作用？

## 扩散的物理图像：Brownian运动足以加载整个聚合物

论证的第一步是排除一个直觉上合理的机制：NPs以数十米/秒的速度从GAS喷出，是否靠动能穿透PEG表面？CFD模拟给出了否定的答案。单个Cu NP（5、20、80 nm）以10¹–10² m/s的初速度进入PEG后，即使最大的80 nm NP以150 m/s入射，速度在约10⁻¹⁰ s内降至零，穿透深度仅3 nm [page 6–7]。作者明确指出，这一计算忽略了表面张力势垒，因此初速度是上限估计 [page 7]。结论是：NPs几乎在到达液面后立即被 immobilize，动能不足以驱动渗透。

那么NPs如何进入PEG本体？作者转向Brownian运动。3D CFD模拟显示，单个20 nm Cu NP在5秒内的位移矢量为42 μm，平均速度约8 μm/s（0.5 mm/min），瞬时速度可达数十cm/s [page 7]。考虑到典型沉积时间为数十分钟，Brownian运动足以在沉积过程中实现NPs与PEG的有效混合。2D集体扩散模拟进一步显示，NPs以约3 μm/s的扩散前沿速度向本体推进，但最高浓度区域以约300 nm/s的速度下移——比单个NP扩散慢一个数量级 [page 7]。作者将这两个时间尺度分别归因于单个NP的扩散和集体扩散，后者虽无相互作用但表现为宏观系综行为 [page 7]。

这里有一个值得注意的对照：作者此前在液体TEM中对200 nm厚纳米流体通道的观测未发现显著的Brownian运动 [page 7]。作者的解释是纳米限域效应——在刚性表面附近，PEG形成吸附层，链段动力学受约束，弛豫时间延长、粘度增加 [page 7]。这一对照暗示，超薄通道中的分析可能不能准确描述本体中的NP动力学。这是一个基于文本的分析重建：作者并未直接证明限域效应是唯一原因，但将其作为最合理的解释提出。

## 颜色、等离子体共振与Cu的氧化

纳米流体的颜色直接关联到局域表面等离子体共振（LSPR）的位置。新鲜制备的Ag/PEG、Cu/PEG和Ag/Cu/PEG均为不透明暗灰色，经超声处理后颜色逐渐显现：Ag/PEG为黄色，Cu/PEG为绿色，Ag/Cu/PEG为蓝色 [page 8]。UV-Vis光谱显示，Ag/PEG在约400和700 nm处有两个透射极小值，Cu/PEG在约700 nm处有单一宽峰，Ag/Cu/PEG则呈现双峰但第二峰与Cu峰重叠 [page 8]。

Mie散射模拟为这些光谱提供了关键解释。30 nm Ag NPs的偶极LSPR位于409 nm，与实验值吻合；但30 nm Cu NPs的模拟LSPR位于575 nm，远低于实验观测的约700 nm [page 9]。作者将这一差异归因于Cu的表面氧化：Cu₂O壳层的形成使LSPR红移至>700 nm，模拟的Cu/Cu₂O核壳结构（核半径等于壳厚度）在部分Cu转化为Cu₂O时，LSPR从575 nm移至680 nm，与实验曲线一致 [page 9]。绿色溶液颜色本身也支持氧化假说——文献中Cu NP溶液的红色因氧化为Cu₂O而变为绿色 [page 9]。

氧化的来源被归因于PEG在空气中吸收的H₂O和O₂。NMR检测到环境空气中储存的PEG含3.5 wt.% H₂O [page 9]。此前的原位环境XPS未检测到CuO，因此氧化限于Cu₂O [page 9]。

## Ag与Cu的稳定性差异：氧化层与静电排斥

Ag和Cu纳米流体的沉降动力学存在显著差异。UV-Vis吸收衰减拟合为双指数衰减，早期 regime中Ag的特征时间t₁ = 2.5 h，Cu为t₁ = 4.5 h [page 10]。作者将早期 regime归因于团聚主导的沉降：Ag更易团聚，形成微米级重团聚体快速下沉；Cu的粘附效率较低 [page 10]。晚期 regime中两者无显著差异，归因于低浓度下Brownian运动扰动的重力沉降 [page 10]。

这一动力学差异的微观起源通过DFT计算得到解释。EG（乙二醇，作为PEG的简化模型）与Ag(111)、Cu(111)和Cu₂O(111)的相互作用能分别为-1.67、-1.73和-3.19 eV [page 12, Table 3]。Cu₂O的相互作用能几乎是Ag和Cu的两倍，总键级和分子电荷也显著更高。DEG（二乙二醇）的计算显示类似趋势，且双齿配位比单齿配位更强 [page 12–13, Table 4]。作者特别指出，在双齿几何中，Cu的键级和电荷甚至略高于Cu₂O，但Cu₂O的相互作用能仍大得多，暗示存在额外的静电相互作用分量 [page 13]。

Zeta电位测量直接支持了这一推断：Ag NPs在PEG中为-35 ± 4 mV，Cu NPs为-44 ± 6 mV [page 13]。作者认为，PEG与金属或金属氧化物表面相互作用时因电子密度重分布而带负电，不必然依赖解离 [page 13]。Cu/Cu₂O上DEG的更大电荷与更负的zeta电位一致，共同支持“Cu₂O与PEG的相互作用强于Ag/PEG和Cu/PEG，因此氧化Cu分散体的胶体稳定性更高”这一结论 [page 13]。

## PEG的吸附构象：蘑菇状、低接枝密度与有限的位阻屏障

PEG分子在NP表面的吸附构象通过De Gennes理论框架进行评估。作者考虑两种极限构象：高密度刷状（链完全伸展，L = 3.2 nm）和低密度蘑菇状（链尺寸由理想链特征尺寸R₀ = an^(1/2)决定）[page 13]。SESSA模拟的XPS C 1s/Cu 2p₃/₂比值与实验值的比较表明，若为完全伸展的刷状（L = 3.2 nm），模拟比值应约为50，而实际纳米流体的比值为10，说明Cu必须更靠近表面 [page 14]。取L = 1.4 nm作为吸附层厚度的粗略上限估计，根据De Gennes关系得到接枝密度σ < 0.20，接枝链平均距离D > 0.8 nm [page 14, Table 5]。每个30 nm Cu NP上附着的PEG链数N < 1800 [page 14]。

这些数值落在De Gennes理论的低密度或中间区域：吸附层厚度接近理想链（无规线团）的特征尺寸R₀ = 1.0 nm，部分链可能重叠但相互作用仍可忽略 [page 14, Table 5]。作者由此得出结论：PEG以蘑菇状构象吸附，提供足够的位阻屏障以延缓但不能完全阻止团聚 [page 14]。吸引性van der Waals力可能未被有效屏蔽，移动链可能被排除，暴露裸NP表面供金属-金属相互作用 [page 14]。作者建议未来研究应致力于将接枝密度提高至σ > 0.33，以实现大分子伸展的起始，从而增强胶体稳定性 [page 14]。

## Ag与Cu在PEG中的有限互混

双金属Ag/Cu/PEG纳米流体的UV-Vis和SAXS数据均表明Ag和Cu NPs之间缺乏有效相互作用。UV-Vis中第二透射极小值的演化精确跟随Cu/PEG的行为，暗示该带主要由Cu/Cu₂O的等离子体效应主导 [page 10]。SAXS显示双金属纳米流体中Ag和Cu的尺寸分布分别保持在42 nm和11 nm，与单金属体系相似 [page 11]。作者引用理论发现，3d和4d金属之间的相互作用因后者的弱相对论效应而无效，4d_Ag与3d_Cu的能级不匹配，显著削弱了键合 [page 11]。

一个引人注目的实验是：将黄色Ag/PEG小心加在绿色Cu/PEG上方而不混合，半小时后两种液体发生交换——黄色Ag/PEG到底部，绿色Cu/PEG到顶部，且至少24小时内保持稳定 [page 11]。考虑到Ag的体密度（10490 kg/m³）高于Cu（8960 kg/m³），这一现象类似于两种不混溶液体的浮力驱动流动（Rayleigh-Taylor不稳定性）[page 11]。但两种纳米流体共享同一宿主液体，理应完全互溶。2D CFD模拟显示，即使250秒后，两个半域仍保持 distinct，无重力交换迹象 [page 11]。作者计算Atwood数为4×10⁻⁷，极低的密度对比可能导致两种可混溶液体以有限扩散剖面进行交换，形成稳定的逆流和尖锐的非互混边界 [page 11]。作者谨慎地指出，Ag/PEG和Cu/PEG纳米流体在静态下交换的驱动力仍不清楚 [page 15]。

## 结论的适用条件与边界

这篇论文的结论建立在若干明确的假设和限制之上。CFD模拟中，NPs被假定为理想球形、无相互作用，Brownian力通过Gaussian随机数和白噪声谱强度系数建模 [page 5]。模拟忽略了表面张力势垒，因此初速度是上限估计 [page 7]。XPS模拟中，样品被建模为半浸没的核壳球体在平坦半无限表面上，NPs规则分布，PEG壳厚度可变 [page 6]。De Gennes分析中，PEG400被简化为EG或DEG分子进行DFT计算，L = 1.4 nm被明确标注为“粗略且上限的估计” [page 14]。

作者承认的局限包括：UV-Vis方法无法区分小NPs和其团聚体，因此沉降特征时间是“更复杂沉降过程的表观值” [page 10]；实际沉降动力学可能至少涵盖三个不同的特征时间尺度 [page 10]；SAXS仪器对小于90 nm的纳米物体敏感，更大团聚体被排除在分析之外 [page 11]；双金属纳米流体中Ag和Cu LSPR在晚期合并为单一宽峰，无法区分各自贡献 [page 10]。

此外，Cu的氧化被归因于PEG在空气中吸收的H₂O和O₂，但作者并未排除其他可能的氧化途径。Ag/Cu/PEG中局部高浓度区域呈现的“迷人而强烈的蓝色”被明确标注为“需要进一步研究” [page 8]。Ag/PEG和Cu/PEG交换的驱动力被列为未解决问题 [page 15]。

总体而言，这篇论文的论证链条是：制备方法可行（实验）→ NPs通过Brownian运动扩散进入PEG本体（CFD）→ Cu的氧化使其LSPR红移并增强与PEG的相互作用（UV-Vis + Mie + DFT + zeta电位）→ PEG以低密度蘑菇状构象吸附，提供有限位阻屏障（De Gennes + SESSA）→ Ag和Cu在PEG中互混有限（UV-Vis + SAXS + CFD）。每个结论都有相应的实验或计算证据支撑，但作者对模拟简化和方法局限保持了明确的谨慎态度。
