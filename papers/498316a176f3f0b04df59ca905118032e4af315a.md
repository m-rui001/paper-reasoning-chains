# 用扩展信号集换取欧氏距离：Ungerboeck 的编码调制论证

**原文**：Gottfried Ungerboeck, "Channel Coding with Multilevel/Phase Signals," *IEEE Transactions on Information Theory*, vol. IT-28, no. 1, January 1982, pp. 55–67. DOI: 10.1109/TIT.1982.1056489

## 问题的重新设定

传统代数编码把调制与编码分开处理：调制器给出一个离散信道，解调器先做硬判决，再交给译码器纠错。Ungerboeck 要打破的正是这个分工。他指出，硬判决在译码前就丢弃了信息，二进制情形下这一损失约相当于 2 dB 信噪比 [page 2]。他的替代方案是把编码与调制视为一个整体，在**相同数据速率、相同带宽**的前提下比较性能。既然速率和带宽都不能动，冗余只能来自一个地方：使用比无编码传输所需更大的信道信号集 [page 2]。

这一设定直接决定了设计目标。接收端假定采用对未量化解调器输出的最大似然（ML）软判决，因此码的设计标准不是最大化汉明距离，而是最大化**自由欧氏距离**（free Euclidean distance）$d_{\text{free}}$。作者特别指出，对 2-AM 和 4-PSK 而言汉明距离与欧氏距离等价，所以问题从未显现；一旦信号集在某一调制维度上超过两个信号，两者就分道扬镳 [page 2]。

## 先算上限：信号集该扩大多少

在动手设计码之前，作者先问了一个定量问题：扩大信号集究竟能带来多少理论收益？他把离散输入、连续输出的调制信道容量写成式 (3)，在 AWGN 下代入高斯条件密度 (4)，并假定各输入信号等概，得到式 (5) [page 2]。随后用蒙特卡洛方法对图 1 所列的一维和二维信号集计算容量 $C^*$，结果画在图 2(a)、2(b) [page 3]。

关键的数字对照是这样的：无编码 4-PSK 传 2 bit/T，在 SNR = 12.9 dB 时符号错误概率为 $10^{-5}$；若改用 8-PSK（信号数翻倍），理论上 5.9 dB 就能无误传输同样的 2 bit/T。而在此之后，即使不限信号数、只约束平均功率，也只能再榨出约 1.2 dB [page 3]。作者由此得出结论：**把信号数翻倍，几乎就能拿到信号集扩展所能提供的全部容量增益**。这个结论为后文所有码都采用 $2^{m+1}$ 个信号传 $m$ bit/T 的做法提供了依据，也解释了为什么作者不主张无限扩大信号集。

## 手工码与"集分割"映射

第三节是全文的直觉核心。作者把编码器看成一个有限状态机，每个状态有 $2^m$ 条转移，任务是把扩展信号集里的信号分配给这些转移，使自由欧氏距离最大 [page 4]。以 8-PSK 传 2 bit/T 为例，无编码 4-PSK 被看作只有单状态、四条并行转移的平凡格，其信号取自 8-PSK 中相互距离最大的四个点（子集 B0 或 B1）[page 4]。

作者随后给出图 7 中四个码：2 状态、4 状态、8 状态、16 状态，自由距离增益分别为 1.1、3.0、3.6、4.1 dB [page 5]。这里有一个值得注意的推理转折：2 状态码无法同时满足"从同一状态出发的信号同属 B0 或 B1"和"汇入同一状态的信号同属 B0 或 B1"这两条规则，因此增益被限制在 1.1 dB；作者据此宣布对 2 状态码不再感兴趣 [page 5]。4 状态码则出现了并行转移带来的权衡——并行转移允许单信号错误发生，把自由距离上限压到并行转移所分配子集的最小距离，但它同时降低了格图的连通性，使多信号错误事件的最小长度得以延长。作者判断在 4 状态下这个权衡仍偏向保留并行转移 [page 5]。

这些手工规则背后是图 4、图 5 的**集分割**（mapping by set partitioning）：把信号集逐层划分成最小距离递增的子集，$A_0 < A_1 < A_2 < \cdots$ [page 4]。对一维 N-AM，$A_{i+1} = 2A_i$（6 dB 步进）；对二维 N-AMPM 和 N-QASK，$A_{i+1} = \sqrt{2}A_i$（3 dB 步进）[page 6]。作者强调，图 4、图 5 中具体的比特到信号映射并不重要，重要的只是这种最小子集距离递增的模式 [page 6]。

## 从手工码到可搜索的代数结构

第四节完成了全文最关键的一步抽象：把手工码重新解释为**码率 $R = m/(m+1)$ 的二进制卷积码**，后接集分割映射。图 9 给出约束长度 $v = 2, 3, 4$ 的无反馈最小编码器实现，其校验矩阵见式 (9) [page 6]。作者进一步给出等价的带反馈系统编码器形式（式 (12)、图 10、图 11），并指出这种形式自动排除了灾难性编码器，且无需预先假定各生成多项式的次数 [page 8]。

真正让搜索成为可能的是式 (14) 与随后的定理。作者定义二进制错误向量 $e_i$ 的欧氏权重 $w(e_i) = \min d[a(z), a(z \oplus e_i)]$，并证明对每个 $e(D)$ 都存在一对码序列使式 (14) 取等号 [page 7]。证明依赖两点：集分割的对称性使 $w(e_i)$ 可由 $[z^1 \cdots z^m]$ 上的最小化达到，而 $R = m/(m+1)$ 的编码允许任意 $[y_i^1 \cdots y_i^m]$ 组合出现 [page 7]。于是自由欧氏距离可以像求自由汉明距离一样计算，只需把 $e_i$ 的汉明权重换成平方欧氏权重 $w^2(e_i)$，见式 (15a)、(15b) [page 7]。

这里有一个作者自己承认的近似：严格的下界应取 $\min \sum w^2(e_i)$，但作者直接令 $d_{\text{free}} = A_{\tilde{m}}$（式 15b），理由是"取 $d_{\text{free}} = A_{\tilde{m}}$ 的风险很小"，因为最小值通常由多个 $e(D)$ 达到，且作者从未找到 $d_{\text{free}} \neq A_{\tilde{m}}$ 的码 [page 7]。这是一个基于经验的简化，不是严格证明，读者应把它当作搜索中采用的实用判据。

## 搜索、码表与仿真

第五节把上述距离度量嵌入一个带拒绝规则的穷举搜索（图 12）。三条规则分别利用时间反转不变性、校验矩阵的对称变换、以及当前最优 $d_{\text{free}}$ 剪枝 [page 8]。表 I–III 给出 2-AM 到 64-QASK 各调制方式在 $v = 2$ 至 11 下的校验多项式（八进制）和归一化自由距离 $d_{\text{free}}^2/A_0^2$ [page 9–10]。8-PSK 的增益从 $v=2$ 的 3.0 dB 升到 $v=8$ 的 5.4 dB；16-QASK 从 4.0 dB 升到 6.0 dB [page 9–10]。作者注意到，当增益已达 6 dB 量级时，增大 $v$ 不再总能提高 $d_{\text{free}}$，并因码复杂度指数增长而满足于已有结果 [page 9]。

第六节的仿真（图 13–15）在中等 SNR 下验证了这些增益，并给出 90% 置信区间 [page 10]。作者特意选择错误事件概率作为指标，因为这样结果不依赖于信息比特到信号序列的具体映射 [page 9]。图 16 显示，对 4 状态 8-PSK 码，错误事件概率与比特错误概率在高 SNR 下趋于一致，原因是该码的自由距离由单信号错误事件实现，且每事件仅错一个比特，同时未使用差分编码和扰码 [page 11]。

## 结论成立的条件与边界

把全文的推理串起来，核心逻辑是：容量计算说明信号数翻倍足够 → 集分割给出把二进制码映射到扩展信号集的方法 → 该映射使欧氏距离可用类似汉明距离的方式下界 → 据此搜索出各约束长度下的最优码 → 仿真验证增益。每一步都依赖若干条件。

**适用条件**：所有比较都在相同数据速率和带宽下进行；接收端采用 ML 软判决；信道为带限 AWGN，无符号间干扰，且假定理想定时与载波相位同步 [page 2]。自由距离增益是**高 SNR 下的渐近量**，式 (7) 的误事件概率下界也明确标注为渐近 [page 4]；仿真部分正是为了检验中等 SNR 下的实际表现。

**作者承认的局限**：只研究了 $R = m/(m+1)$ 的码；作者推测进一步扩大信号集（超过两倍）可能为给定约束长度找到更好的自由距离，但容量增益有限，并将其留作开放问题 [page 12]。作者还指出，未发现一维与二维编码调制在增益上有显著差异，因此怀疑使用二维以上信号集是否有优势 [page 12]。

**需要读者留意的推断性内容**：$d_{\text{free}} = A_{\tilde{m}}$ 的采用是基于经验的简化而非定理 [page 7]；"这些手工码对给定状态数是最优的"是作者经过大量实验后的判断，而非穷举证明 [page 4]；"2 状态码不值得进一步研究"是从规则 2)、3) 无法同时满足推出的，作者称这一限制"并非 8-PSK 独有" [page 5]。

**同步问题**：第七节用 4 状态 8-PSK 码演示了载波相位跟踪，采用基于 Viterbi 译码暂定判决的判决导向环路（图 17），并发现暂定判决延迟 $M_P = 0$ 优于更大延迟 [page 11–12]。图 18 的 S 曲线显示环路在 $|\varphi_n - \hat{\varphi}_n| < \pi/8$ 内正常跟踪，超出则随机游走；曲线以 $\pi$ 为周期，导致 180° 相位模糊，需用最高有效位的差分编解码解决 [page 12]。作者提醒，其他码可能需要不同的模糊解决方法 [page 12]。

总体而言，这篇论文的贡献不在于某个具体码，而在于把"编码+调制"作为一个整体来设计的方法论：用容量计算确定信号集扩展的合理幅度，用集分割把欧氏距离问题转化为可搜索的代数问题，再用搜索程序系统性地寻找好码。其结论的力度受制于渐近分析、经验性简化以及 AWGN 与理想同步的假设，但 3–4 dB（简单码）到 6 dB（约 $2^v$ 状态码）的增益在仿真中得到了支持。
