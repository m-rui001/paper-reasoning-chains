# 能量调节型准相对论赝势的构建与验证：对第13–17族元素的一项原子级基准研究

**原文题名**：Ab initio energy-adjusted pseudopotentials for elements of groups 13–17
**作者**：Andreas Bergner, Michael Dolg, Wolfgang Küchle, Hermann Stoll, Heinzwerner Preuß
**期刊**：Molecular Physics, 1993, 80(6), 1431–1441
**DOI**：10.1080/00268979300103121

---

## 论文要解决的问题

对含重元素的分子做量子化学计算，必须处理相对论效应。一种常见做法是引入准相对论赝势（pseudopotential, PP）：只显式处理价电子，把内层电子的效应用一个有效势来模拟，从而在形式上非相对论的价电子哈密顿量中"吸收"相对论贡献。作者指出，他们此前发表的主族赝势是基于高电荷单价电子离子的经验数据拟合的，而本文改用中性原子或低电荷离子的准相对论全电子计算作为参考数据，为第13–17族（除第六周期外）元素重新构建赝势，并配套给出能量优化的价基组 [page 2]。

核心主张可以概括为两点：其一，这套赝势与基组在原子测试中能复现准相对论全电子结果，误差通常在 0.1 eV 以内；其二，与当时常用的 Hay–Wadt（HW）和 Christiansen–Ermler（CE）赝势相比，本文的赝势在精度上至少不逊于 CE，且明显优于 HW，同时在计算经济性上更紧凑 [page 2, page 9, page 11]。

## 赝势的形式与拟合逻辑

作者采用的价电子哈密顿量（原子单位）为 [page 4]：

$$\hat{H} = \sum_i \left(-\frac{1}{2}\nabla_i^2 - \frac{Q}{r_i}\right) + \sum_{i<j}\frac{1}{r_{ij}} + \sum_i V_{pp}(i) \tag{1}$$

其中半局域赝势写作 [page 4]：

$$V_{pp}(i) = -\frac{Q}{r_i} + \sum_{l=0}^{l_{max}} \sum_k A_{lk}\, r_i^{n_{lk}} \exp(-a_{lk} r_i^2)\, P_l \tag{2}$$

$Q$ 是核心电荷，$P_l$ 是投影到角动量 $l$ 子空间的投影算符 [page 4]。$A_{lk}$ 与 $a_{lk}$ 是可调参数，通过最小化如下最小二乘泛函确定 [page 6]：

$$W = \sum_m \left(E_m^{ae} - E_m^{pp}\right)^2 \tag{5}$$

这里 $E_m^{ae}$ 是第 $m$ 个参考态的数值全电子价能量，$E_m^{pp}$ 是对应的赝势计算能量。**关键的一步在于参考态的选择**：对 $l=0,1,2$，作者使用中性原子或一价阳离子的多个低能组态的 LS 态（多电子拟合，MEFIT）；对 $l=3$（f 分波），则用 $4f^1$、$5f^1$ 单电子参考态（单电子拟合，SEFIT），且 f 分波只对第四、五周期元素构建 [page 5]。作者特别强调，整个赝势构建完全基于有限差分计算，避免了基组展开带来的误差 [page 6]。

这一拟合策略的推理链条是：如果赝势参数能让赝势计算在多个原子参考态上重现全电子价能量，那么它在分子环境中也应能较好地模拟核心–价电子相互作用。这是一个**以原子可观测能量为锚点**的构造思路，作者明确将其与"形状一致"（shape-consistent）赝势区分开，后者依赖单粒子模型的参考数据 [page 2]。

## 原子测试：证据与精度

作者用三类量检验赝势与基组的可靠性：激发能、电离能、电子亲和能。比较对象是准相对论全电子有限差分计算（AE,WB）、赝势有限差分计算（PP,WB）以及用优化基组做的 SCF 计算（PP,SCF）[page 7]。

表 7–10 分别给出第二至第五周期元素的测试结果 [page 8–10]。作者总结：对于占据 s、p 轨道的态，全电子与赝势计算之间的激发能、电离能、电子亲合能差异小于 0.10 eV，例外包括 O⁺(s¹p⁴, ⁴P)、N⁺(s¹p³, ⁵S)、Ga⁺(s¹p¹, ³P)、P⁺(s¹p³, ⁵S) 等高度激发态；对于占据 d 轨道的态，误差可达约 0.15 eV；用小型价基组做的 SCF 计算，与有限差分赝势结果相比误差也小于 0.1 eV [page 9]。

这些数据支撑了"赝势可靠"的结论，但需要注意几点边界。第一，测试全部是**原子**层面的，作者明确说分子测试将在后续论文中给出 [page 3]，因此本文的结论严格来说只覆盖原子性质。第二，误差上限 0.1 eV 的表述有例外，作者自己列出了若干高激发态和含 d 轨道态的更大偏差 [page 9]。第三，电子亲和能的计算对第16、17族使用了扩大的 4s5p 基组 [page 9]，说明阴离子描述需要额外基函数，标准 (4s4p) 基组未必足够。

## 与 HW、CE 赝势的对比

表 11 对第14族元素（C、Si、Ge、Sn）比较了 HW、CE、SEFIT（作者组此前的单电子拟合赝势）和本文 MEFIT 赝势，以及全电子参考值 [page 11]。作者的结论是：在电离能和激发能方面，本文赝势的表现至少与 CE 相当，而 HW 赝势则出现高达零点几电子伏的显著误差 [page 9]。例如 Si 的 ³P→⁵S 激发能，全电子值为 2.53 eV，HW 给出 2.04 eV，CE 为 2.40 eV，MEFIT 为 2.54 eV；Ge 的对应值全电子 3.44 eV，HW 2.93 eV，CE 3.28 eV，MEFIT 3.40 eV [page 11]。这些具体数值支持了作者的精度排序判断。

不过，这一比较有一个方法上的限定：作者将比较限制在有限差分 SCF 结果，目的是排除不同优化基组带来的干扰，使赝势之间的比较"在同等基础上"进行 [page 9]。这意味着表 11 反映的是赝势本身的精度，而非实际分子计算中赝势加基组的综合表现。

## 计算经济性

作者还主张其赝势在计算上更经济：每个角量子数只用一到两个高斯函数，而 CE 和 HW 每个 $l$ 值最多用六项，外加类似数量的局域项 [page 11]。此外，本文赝势的展开式中不含高斯乘以 $r^{-1}$ 或 $r^{-2}$ 的项，因此更容易从半局域形式转换为非局域表示，这对大分子的梯度计算尤其有利 [page 11]。作者引用此前对二茂铈（cerocene）的研究作为佐证：使用其碳和铈赝势时，单电子积分时间仅为双电子积分时间的 47% [page 11]。这是一个具体的量级证据，但它来自另一项研究，并非本文直接测量。

## 结论成立的条件与边界

综合来看，本文结论的适用范围有几个明确的边界。**元素范围**：第13–17族，直到第五周期（原子序数 53，碘），第六周期元素因已有发表参数而未包含在内 [page 2]。**相对论处理层次**：赝势是自旋–轨道平均的单分量形式，不含自旋–轨道耦合 [page 2]，因此对需要精细处理自旋–轨道分裂的问题不适用。**验证层次**：全部测试为原子计算，分子层面的验证留待后续工作 [page 3]。**精度声明**：0.1 eV 的误差范围有明确例外，高激发态和含 d 轨道态可达 0.15 eV [page 9]。**基组**：标准 (4s4p) 基组对中性原子和阳离子足够，但阴离子描述需要额外的 p 函数 [page 9]。

作者在结论中的措辞是谨慎的：赝势和基组"应能成为"（should be a reliable tool）多原子分子量子化学计算的可靠工具，尤其是含一个或多个重原子的情形 [page 12]。这是一个基于原子测试的合理推断，而非已在分子体系中验证的结论。本文的贡献在于提供了一套参数、一套基组，以及一套以原子能量为基准的精度证据；它是否在分子性质（键长、键能、反应能垒等）上同样可靠，取决于后续分子测试的结果。
