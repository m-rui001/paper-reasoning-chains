# 软阈值去噪：从最优恢复到统计估计的论证链

**De-noising by Soft-Thresholding**（David L. Donoho，1995，DOI: 10.1109/18.382009）

## 论文要解决什么

论文处理一个具体的统计问题：从带噪观测

$$d_i = f(t_i) + \sigma z_i,\quad i=0,\dots,n-1,\ t_i=i/n$$

中恢复未知函数 $f$，其中 $z_i$ 是独立同分布标准高斯噪声 [page 1]。作者要证明，对经验小波系数做软阈值处理（soft-thresholding）得到的估计 $\hat f_n^*$ 同时具备两个性质：

- **[Smooth]**：以趋于 1 的概率，$\hat f_n^*$ 至少和 $f$ 一样光滑，且这一结论对一大类光滑度空间同时成立；
- **[Adapt]**：在每个光滑度球上，$\hat f_n^*$ 的均方误差几乎达到极小极大（minimax）下界，只差一个对数因子，而且对所有这些球同时成立 [page 2]。

这两个性质合起来，就是作者对"去噪"（de-noising）给出的形式化解释：不仅要误差小，还要不产生噪声诱发的虚假振荡。作者在引言里明确说，纯均方误差最优的估计会留下"ripples""blips"和振荡，在地球物理和天文场景中可能被误读为真实结构，因此需要附加条件 (3)——"以高概率，$\hat f$ 至少和 $f$ 一样光滑" [page 1]。

## 论证的整体结构

论文的证明不是直接对函数空间做分析，而是走了一条"抽象化—求解—再具体化"的路线。作者把问题拆成两层：

1. **抽象去噪模型**（第 II–IV 节）：在序列空间里研究一个更一般的估计问题，证明软阈值在最优恢复（optimal recovery）模型中有唯一最优性，再把这个结果"迁移"到统计估计模型。
2. **小波基的具体化**（第 V–VI 节）：用经验小波变换把函数估计问题转化为序列估计问题，并证明两个模型之间的误差范数等价。

这条路线之所以可行，关键在于作者发现：**统计估计问题在噪声水平重新标定后，近似等价于一个确定性最优恢复问题**。这个"近似等价"是整个论证的枢纽。

## 抽象模型中的关键一步：最优恢复与软阈值的唯一性

作者先考虑一个确定性模型 [page 3]：

$$y_I = \theta_I + \epsilon u_I,\quad |u_I|\le 1,\ I\in\mathcal{I},$$

其中 $\epsilon>0$ 是已知噪声水平，$u_I$ 是由"聪明对手"选择的干扰项，性能用最坏情况误差衡量。在这个模型里，作者要求估计同时满足**一致收缩条件**：

$$|\hat\theta_I(y)| \le |y_I|,\quad \forall I,$$

即估计值不会比观测值更远离 0。

**定理 3.1** 证明软阈值 $\eta_t(y)=\mathrm{sgn}(y)(|y|-t)_+$（取 $t=\epsilon$）满足一致收缩条件 [page 3]。**定理 3.2** 进一步证明：对任何"实心且正交对称"（solid and orthosymmetric）的参数集 $\Theta$，软阈值估计的误差不超过极小极大误差的 4 倍 [page 4]。**定理 3.3** 则给出唯一性：在满足一致收缩条件的所有规则中，软阈值是唯一最优的 [page 4]。

这里的关键推理是：作者构造了一个特殊的二点问题——假设 $\theta$ 只可能取 $\theta^{(1)}$ 或 $\theta^{(-1)}$ 两个值，且观测恰好是它们的中点。在这个退化问题中，任何满足一致收缩条件的规则都无法区分两者，只能取一个折中值，其误差下界恰好是 $\min(\theta_I^2,\epsilon^2)$。由于原问题至少和这个特殊问题一样难，下界成立 [page 4]。这个论证的巧妙之处在于，它把"软阈值最优"这个结论归结为一个几乎显然的几何事实：中点问题中，任何收缩规则都只能选一个点，而软阈值恰好选在最优位置。

## 从确定性到随机性：噪声水平的重新标定

第 IV 节把上述结果搬到随机模型。作者利用高斯尾概率事实：若 $z_I\sim N(0,1)$，则

$$P\left(\max_I |z_I| \le \sqrt{2\log n}\right) \to 1,$$

因此可以取 $\delta_n = \epsilon\sqrt{2\log n}$，把随机噪声"当作"确定性噪声处理 [page 5]。**定理 4.1** 证明：以概率至少 $r_n$（$r_n\to 1$），软阈值估计满足与确定性模型相同的一致收缩条件 [page 5]。

**定理 4.2** 给出上界：对实心正交对称集 $\Theta$，

$$M_n(\hat\theta^{(n)},\theta) \le (2\log n + 1)(2+2\cdot 2.22\cdot 3.33)\epsilon^2,\quad \theta\in\Theta,$$

即软阈值估计在因子 $4.44\log n$ 以内达到极小极大 [page 5]。这个上界的证明依赖 Donoho 和 Johnstone 的 oracle 不等式 (39) [page 6]，它把软阈值估计的误差与一个"理想"的、由 oracle 选择最优子集的估计器联系起来。

**定理 4.4** 则给出下界方向的近似最优性：在满足概率收缩条件的所有奇单调非线性函数中，存在一个唯一的最优函数 $U_\alpha$，而软阈值与它的差距在 $\alpha\to 0$ 时趋于零 [page 6]。附录给出了这个定理的证明梗概，核心是把问题转化为一个常微分方程的初值问题 [page 13–14]。

## 小波基的具体化：为什么可以"零扩展"

第 V 节的核心是 **定理 5.1** [page 7–8]，它建立了经验小波变换与一个理论小波展开之间的对应关系。这个定理有几个关键断言：

- 经验小波系数恰好是某个特殊展开的前 $n$ 个系数；
- 这个展开的基函数是 $C^R$ 的、紧支撑的"光滑分子"（smooth molecules）；
- 这些基函数在采样测度下近似正交；
- 每个 Besov 空间 $B^s_{p,q}[0,1]$（$1/p<s<\min(R,D)$）的范数等价于系数序列的加权 $\ell^p$ 范数。

这个等价关系是整篇论文能够把抽象序列结果"搬"回函数空间的关键。作者在 (40)–(43) 中观察到：如果系数向量 $\tilde\theta^{(n)}$ 逐元素小于 $\theta^{(n)}$，那么零扩展后的函数 $\tilde f_n$ 的 Besov 范数不超过 $f$ 的 Besov 范数 [page 8]。这个"显然"的不等式之所以成立，正是因为范数等价关系中系数是逐元素加权的。

**定理 1.1** 的证明 [page 9] 就是把这个观察与定理 4.1 结合：在事件 $E_n$（概率至少 $r_n$）上，软阈值后的系数逐元素小于真实系数，因此零扩展后的函数 $\hat f_n^*$ 的每个 Besov 范数都不超过 $f$ 的对应范数。这就是 [Smooth] 的精确含义。

**定理 1.2** 的证明 [page 10] 则结合定理 4.2 的上界和定理 3.2 的下界：上界由 oracle 不等式给出，下界通过构造一个特殊的实心正交对称集 $\Theta_{0,n}$ 并利用 (36) 得到。最终结论是：对每个光滑度球 $\mathcal{F}_C$，存在常数 $C_2$ 使得

$$\sup_{f\in\mathcal{F}_C} E\|\hat f_n^* - f\|_n^2 \le C_2 \cdot \log n \cdot \inf_{\tilde f}\sup_{f\in\mathcal{F}_C} E\|\tilde f - f\|_n^2.$$

## 结论成立的条件与边界

论文的结论有几个明确的适用条件：

**光滑度范围**：$1/p < s < \min(R,D)$，其中 $R$ 是小波的正则性，$D$ 是消失矩个数 [page 2]。这个上界来自小波基的性质，下界 $s>1/p$ 保证空间嵌入到 $C[0,1]$。

**噪声水平已知**：定理 1.1 和 1.2 的证明假设 $\sigma$ 已知。作者在第 IX-A 节讨论了 $\sigma$ 未知的情形，提出用 MAD 估计 $\hat\sigma = \mathrm{MAD}/0.6745$，并指出可以建立平行结果，但论文本身没有给出完整证明 [page 12]。

**高斯噪声**：整个论证依赖高斯尾概率和 Anderson 定理。作者在第 IX-A 节提到，对非高斯误差，阈值行为"精细地依赖于分布的尾部"，并引用 Gao 的博士论文讨论指数尾情形 [page 12]。

**对数因子**：定理 1.2 的结论是"几乎极小极大"，差一个 $\log n$ 因子。第 VII 节的 **定理 7.1** 在额外条件下把这个因子改进为 $\log(n)^\tau$，其中 $\tau = 2s/(2s+1)$ [page 10]。作者指出，这个改进来自对 oracle 不等式的精细分析，而非来自最优恢复的类比。

**软阈值 vs 硬阈值**：作者在第 IX-A 节明确指出，硬阈值也有 oracle 不等式，但与最优恢复的联系更弱，[Smooth] 性质也不明显 [page 12]。这暗示软阈值的优势不仅在于误差，更在于它同时满足两个性质。

## 论证的边界与未竟之处

论文的论证有一个值得注意的"不对称"：[Smooth] 的证明是直接的——软阈值后系数逐元素变小，零扩展后范数不增，逻辑链条清晰。[Adapt] 的证明则依赖 oracle 不等式 (39)，而这个不等式本身来自 [12]，论文没有重新证明。因此，[Adapt] 的结论强度受制于 oracle 不等式的精确形式。

另一个边界是：论文的"最优恢复"类比给出的是**近似**结果，而非精确等价。作者在 (35) 中给出下界 $M_n^*(\Theta) \ge E_n^*(\Theta)$，在 (37) 中给出上界 $M_n(\hat\theta^{(n)},\theta) \le (2\log n + 1)(2+2\cdot 2.22\cdot 3.33)\epsilon^2$，两者之间差一个 $\log n$ 因子。这个差距是否本质，论文没有回答。第 VII 节的改进表明，在特定条件下可以缩小这个差距，但一般情形仍留有余地。

最后，论文的结论是**逐点**的：定理 1.1 说 $\hat f_n^*$ 在每个 Besov 范数下不超过 $f$，定理 1.2 说在每个球上误差不超过极小极大的 $\log n$ 倍。这些结论不涉及估计的渐近分布、置信区间或假设检验，也不涉及 $f$ 的逐点误差。作者在引言中明确说，[Smooth] 是"视觉优越性"的数学表述 [page 2]，但视觉质量本身不是论文的证明对象。

## 总体判断

这篇论文的核心贡献是建立了一条从确定性最优恢复到随机统计估计的论证链，并用小波基的范数等价性把它具体化到函数空间。软阈值之所以特殊，是因为它在最优恢复模型中满足一致收缩条件且唯一最优（定理 3.3），而这个条件在统计模型中近似成立（定理 4.1）。[Smooth] 和 [Adapt] 分别是这个最优性的两个侧面：前者来自系数收缩的逐元素性质，后者来自 oracle 不等式给出的误差上界。

论文的论证力度在于它的**结构性**：不是针对某个特定光滑度类构造一个估计器，而是证明一个简单估计器在一大类空间上同时近似最优。这种"适应性"（adaptivity）是论文标题中"de-noising"一词的实质含义。论文的局限则在于：对数因子未被完全消除，噪声水平已知的假设未被完全放松，非高斯误差的情形未被系统处理。这些局限作者本人都有承认或暗示，读者不应把它们当作论文的隐含结论。
