# 非正交多址接入（NOMA）如何为5G服务：一篇论证分析

**原文题名**：Non-Orthogonal Multiple Access for 5G: Solutions, Challenges, Opportunities, and Future Research Trends（2015，DOI: 10.1109/mcom.2015.7263349）

## 一、作者要论证的核心主张

这篇文章是一篇面向5G的综述性论文，其核心主张可以概括为一句话：**NOMA（非正交多址接入）通过"可控干扰"的非正交资源分配，能够部分满足5G对高频谱效率与海量连接的需求，但它并非要取代OMA（正交多址接入），而是与之共存，并通过软件定义多址接入（SoDeMA）实现自适应配置** [page 1, page 7]。

这个主张包含三个层次，需要分别看它们的证据强度：

1. **NOMA在容量上优于OMA**——这是理论层面的主张，有信息论结果支撑；
2. **NOMA能支持海量连接、低时延**——这是系统层面的主张，证据来自具体方案（如MUSA的过载能力）和机制推理；
3. **OMA与NOMA应共存，由SoDeMA统一调度**——这是作者提出的前瞻性构想，属于设计主张而非已验证结论。

## 二、从证据到结论：关键推理链

### 容量优势：理论证据是全文最硬的一环

作者论证NOMA优越性的起点，是引用多用户容量分析的经典结果 [10]，并用图1（Fig. 1）给出OMA与NOMA在AWGN信道下的容量对比 [page 2]。这里的关键推理是：

- 在**上行**AWGN信道中，NOMA能够达到容量界，而OMA方案除C点外一般次优（Fig. 1a）。但作者随即指出一个重要的限定：在C点这个最优点上，当两用户接收功率差异显著时，用户吞吐公平性很差——弱用户的速率远低于强用户 [page 2]。这是一个作者主动承认的代价，而非被忽略的缺陷。
- 在**下行**中，NOMA的速率对边界一般位于OMA速率区域之外（Fig. 1b）[page 2]。
- 在存在符号间干扰（ISI）的多径衰落信道中，若CSI仅在移动接收机已知，则NOMA最优而OMA严格次优 [page 2]。

**关键推理步骤**：作者从"OMA无法总是达到多用户系统和速率容量"这一信息论事实出发 [page 2]，推出非正交分配在原理上更接近容量界。这一步是理论性的，不依赖具体实现，因此证据力度较强。但要注意，图1的结论建立在**两用户AWGN信道**这一简化模型上，作者明确说这是"不失一般性"的举例 [page 2]——从两用户推广到海量连接场景，是作者未在图中直接证明的桥接，属于推断性延伸。

### 海量连接与低时延：机制推理为主，辅以个别数据

作者给出两条支撑：

- **海量连接**：非正交分配意味着支持的用户数不再严格受限于正交资源总量和调度粒度。这里作者引用了一个具体数据：MUSA在过载300%时仍能取得"相当好"的性能 [page 2, page 4]。这是全文少有的量化证据之一，但"reasonably good performance"是定性表述，原文未给出具体BER或吞吐数值。
- **低时延与低信令开销**：在传统基于授权的OMA中，用户需先发调度请求、基站再下发授权，这一过程在5G海量连接场景下时延和信令开销"变得糟糕甚至不可接受"。而NOMA的某些上行方案不需要动态调度，可实现免授权（grant-free）传输 [page 2]。这是机制层面的因果推理，逻辑清晰，但属于设计预期而非实测结论。

### 方案分类与对比：复杂度是核心权衡

作者将主流NOMA方案分为两大类 [page 1, page 3]：

- **功率域复用**：按信道条件分配不同功率电平，接收端用SIC（串行干扰消除）。作者明确限定"本文中功率域复用仅用于下行NOMA" [page 3]。
- **码域复用**：类似CDMA/MC-CDMA，用户分配不同码字，在相同时频资源上复用。区别在于码域复用以增加信号带宽为代价换取扩频增益和成形增益 [page 3]。

在复杂度对比上，作者给出了明确的量级关系 [page 5]：

- 功率域NOMA的SIC复杂度为 **O(K³)**（K为用户数），远低于最优ML检测的 **O(|X|^K)**（随用户数指数增长）。
- 码域NOMA（LDS-CDMA、LDS-OFDM、SCMA）的MPA接收机复杂度为 **O(|X|^w)**，其中w为每个码片/子载波上叠加的非零信号最大数。由于典型5G海量连接场景中w通常大于3，MPA接收机复杂度一般高于SIC接收机 [page 5]。

**这是全文最重要的权衡论证**：码域方案能获得扩频增益（10log N，N为扩频因子）和SCMA的成形增益（多维星座优化，最大可达1.53 dB）[page 4, page 5]，但代价是接收机复杂度更高。作者没有简单地说哪种方案更好，而是把"性能—复杂度"作为方案选择的核心维度。

## 三、关键假设与适用边界

作者在文中明确或隐含地设定了若干条件，这些条件决定了结论的适用范围：

**第一，功率域NOMA依赖SINR差异。** 作者指出，基本NOMA-SIC利用用户间的SINR差异，这种差异要么来自自然的远近效应，要么来自发射端的非均匀功率分配 [page 3]。这意味着：当用户信道条件接近、远近效应不显著时（如小小区场景），功率域NOMA的优势基础就不存在了。作者在SoDeMA部分明确承认了这一点——"当用户数少且远近效应不显著时，OMA是更好的选择" [page 6]。

**第二，码域NOMA的扩频增益以频谱效率为代价。** 作者明确指出，通过扩频引入冗余会影响系统频谱效率 [page 5]。这是一个内在张力：扩频带来增益，但占用更多带宽。因此码域NOMA的净收益取决于具体场景。

**第三，网络NOMA面临小区间干扰问题。** 当下行NOMA的功率分配偏向远用户时，小区边缘用户会受到邻区更强干扰 [page 3]。作者提出的缓解方案是跨小区联合预编码，但坦承"寻找最优预编码并非易事"，且单小区NOMA的多用户预编码对网络NOMA可能不可行，因为地理上分离的基站天线无法形成可用于波束内NOMA的物理波束 [page 3]。这是一个作者明确承认的开放难题。

**第四，免授权上行存在用户活跃性未知的问题。** 作者指出，在免授权上行传输中，接收机不易获知用户活跃性或瞬时系统负载，这会对性能产生负面影响，并提到压缩感知（CS）是估计资源占用的一种有前景的技术 [page 5]。这属于作者承认的局限。

## 四、SoDeMA：从技术方案到系统构想

文章最后提出的SoDeMA概念 [page 6, page 7] 是全文最具前瞻性的部分，但也是最缺乏验证的部分。其逻辑是：

- 既然OMA和NOMA各有适用场景，且不同NOMA方案在性能与复杂度上各有取舍，那么应当让它们共存，通过软件定义的方式自适应切换。
- 作者给出了具体的配置逻辑：小区中心用户或实时业务（如超高清视频）用OMA；高谱效、海量连接、小包频繁接入场景用NOMA；信道差异大时用功率域NOMA-SIC（低复杂度）；高可靠性要求时用SCMA（成形增益+近最优MPA检测）；用户数极大难以设计码本时用LDS-OFDM或MUSA [page 6, page 7]。
- 技术可行性依据是：多种NOMA方案共享某些信号处理模块（如接收端MPA、发射端扩频操作），可在硬件上共享以降低成本，在软件层面组合以实现不同方案 [page 7]。

**需要明确的是**：SoDeMA是作者提出的概念构想，文中没有给出任何仿真、实验或原型验证。作者用"highly expected"（高度期待）等措辞 [page 7]，表明这是对未来工作的展望而非已证结论。此外，作者指出实现SoDeMA需要足够灵活的帧结构，且不同资源块之间的子载波间干扰需要仔细缓解 [page 7]——这些都是未解决的前提条件。

## 五、证据强度与结论的可靠性评估

综合来看，这篇文章的论证呈现明显的**证据梯度**：

- **最强**：NOMA在容量上优于OMA的理论论证（基于信息论结果和图1），以及SIC与MPA复杂度的量级对比（O(K³) vs O(|X|^w)）[page 2, page 5]。这些有明确的理论或计算依据。
- **中等**：各方案的技术原理描述和优缺点分析，基于具体文献（[2]–[9], [12]–[14]），但多为定性比较，量化数据有限（如MUSA 300%过载、IDMA约1 dB Eb/N0增益、SCMA最大1.53 dB成形增益）[page 2, page 4, page 5]。
- **较弱/前瞻性**：SoDeMA概念、未来研究方向、工程挑战清单 [page 6, page 7]，属于作者基于现有认识的推断和倡议。

**结论成立的条件**：NOMA的优势结论在以下条件下成立——存在用户间SINR差异（功率域）或可设计低互相关码字（码域）；接收机能够承受SIC或MPA的复杂度；系统需要支持的用户数超过正交资源可容纳的数量。当这些条件不满足时（如用户少、信道条件接近、复杂度受限），作者自己承认OMA可能是更优选择 [page 6]。

**一个需要注意的表述问题**：摘要和结论中"can address some of these challenges"、"can partially fulfill"等措辞 [page 1, page 7] 保持了谨慎的限定，但正文在描述具体方案优势时（如"can accommodate significantly more users"）语气更为肯定 [page 2]。读者在引用时应以限定性表述为准，不宜将NOMA的潜力等同于已验证的性能。

总体而言，这篇文章作为2015年的综述，其价值在于清晰地梳理了NOMA的方案谱系、核心权衡（性能vs复杂度）和开放问题，而非提供新的实验证据。它的容量论证有理论根基，方案对比有文献支撑，但SoDeMA构想和多数性能声明仍停留在设计预期层面，需要后续研究验证。
