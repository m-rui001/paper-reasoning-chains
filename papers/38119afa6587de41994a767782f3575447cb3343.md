# 用深度生成模型逆向设计纳米多孔晶态网状材料

**原文题名**：Inverse design of nanoporous crystalline reticular materials with deep generative models
**年份**：2021　**DOI**：https://doi.org/10.1038/s42256-020-00271-1

## 问题设定：把材料发现当作高维空间中的约束优化

网状框架（reticular frameworks，含金属有机框架 MOF 与共价有机框架）由分子构筑单元（节点与连接体）在不同拓扑下自组装而成。构筑单元种类繁多、组装方式多样，使这类材料具有极强的几何与化学可调性，但也带来近乎无限的组合设计空间。作者把寻找新材料明确表述为一个高维空间中的约束全局优化问题 [page 1]。

已有的两条路径各有短板。高通量计算/实验筛选只能覆盖约 $10^3$–$10^5$ 量级的设计空间，覆盖率低且受构筑单元组合方式限制；遗传算法、进化策略等启发式优化能搜索更大空间，但需要预先规定"如何变换框架"的规则，从而对可探索的框架类型施加了前置约束 [page 1]。作者提出的第三条路径是生成模型：不直接预测性质 $y$，而是对数据分布本身建模，并可通过条件化实现"性质→结构"的逆向设计（inverse design）[page 1–2]。

## 核心主张与论证骨架

论文的核心主张是：一个以超分子变分自编码器（supramolecular variational autoencoder, SmVAE）为核心的自动化平台，能够生成结构上可信、性质上显著优于已知基准的 MOF，并用于 CO₂/CH₄ 与 CO₂/N₂ 分离。支撑这一主张需要三块证据：一套可逆、无冗余的框架表示；一个能忠实重建结构、并按性质组织隐空间的生成模型；以及在隐空间中做定向优化后，用独立方法（GCMC 模拟）复核候选结构确实具备所声称的性能。

## 表示层：RFcode 如何把晶体变成可生成的对象

论证的第一块基石是表示。作者指出，若把网状框架直接写成原子图，会得到 $10^2$–$10^4$ 个顶点、每顶点 3–5 条边的图，潜在构型数以十亿计，几乎无法有效优化 [page 2]。因此他们借助 tiling/net/graph 理论的约化思想，用"基元顶点"替代原子顶点、用"多原子分支边"替代键边，构造出 RFcode，即元组 **edges | vertices | topologies**：边是带两个连接点的分子片段，顶点是多连接的金属或有机节点，拓扑定义这些组件如何连接 [page 2]。RFcode 的三个设计目标是效率（无冗余）、唯一性（每个表示对应唯一框架）与可逆性（组件可来回转换）[page 2]。图 1a 以 MOF-117 为例展示了从分解到 `Sym_3_1 | Zn_6_1 | qom` 序列的流程 [page 3]。

这里有一个对后续论证至关重要的建模简化：顶点与拓扑被当作来自已知框架的**类别变量**，因为它们的种类相对有限。作者明确承认，这意味着搜索空间不包含新的顶点和拓扑——"当前顶点与拓扑池代表可信且可实现的网状框架结构"是数据集的一个底层假设 [page 4]。换言之，模型能发明的是新的边（连接体）组合，而非全新的节点化学或全新拓扑。这一限制直接界定了结论的适用边界。

## 数据层：为什么必须做增广，以及性质标签从何而来

CoRE MOF 数据库只有约 14,000 个 MOF，而作者的经验判断是深度生成模型通常需要 $10^6$ 量级数据才开始有用 [page 4]。于是他们从识别出的 372 条边出发，用已知 MOF 中常见的官能团做随机官能化，得到约 300,000 条增广边；再与金属顶点（14 种）、有机顶点（47 种）、拓扑（153 种）组合，得到约两百万个 MOF 的增广数据集 [page 4]。图 1b 用 scaffold tree 展示了 CoRE 数据库连接体的化学多样性来源 [page 3]。

性质标签则无法从实验获得，只能靠计算。作者对约 45,000 个随机抽取的 MOF 做模拟，覆盖四类织构性质（PLD、LCD、密度、AGSA）与两类分离性质（天然气分离：5 bar、300 K、CO₂/CH₄ = 10/90 的 CO₂ 与 CH₄ 吸附量及选择性；烟气分离：1 bar、313 K、CO₂/N₂ = 15/85 的 CO₂ 与 N₂ 吸附量及选择性）[page 4]。织构性质用 Zeo++ 几何计算，气体吸附用 GCMC 模拟，选择性由混合气各相吸附量数值导出 [page 4, page 10]。

**一个必须交代的边界**：模拟采用孔道阻塞（pore blocking）处理，且框架原子在模拟中固定不动。因此半径较大的 CH₄、N₂ 可能吸附量极小甚至为零，导致选择性被算成极大甚至无穷（∞）。作者明确说明，真实选择性不会完美（无穷），因为框架未必完全刚性、大分子未必被完全阻挡；柔性框架的气体吸附模拟仍是未解问题，超出本研究范围。因此这些 ∞ 应被理解为"预测性能突出"的标志，而非真实无穷选择性 [page 4]。这一限定在后面的候选材料讨论中反复出现，是理解表 1 中若干 ∞ 数值的关键。

## 模型层：SmVAE 的结构与"按性质组织隐空间"的证据

SmVAE 是一个多组件 VAE：边的编码/解码用一对循环神经网络（边 SMILES 先转成 SELFIES，再以序列到序列方式处理），框架信息（有机/金属顶点、拓扑）做 one-hot 编码，另有一个性质预测组件 [page 4, page 10]。总损失为

$$L_{total} = L_{edge} + L_{vertex} + L_{topo} + L_{property} + L_{KL} = L_{RFcode\ Recon.} + L_{Semi-super\ Prop.} + L_{VAE\ Constraint} \quad (1)$$

[page 4]。由于有性质标签的样本（约 45,000）远少于结构样本（约两百万），性质组件以半监督方式训练：只有观测到带标签数据时才优化预测网络参数 [page 4]。隐空间维度为 288，训练采用周期 15 epoch 的循环退火调度，共 120 epoch [page 10]。

模型忠实性的证据分几层。其一，隐空间各维核密度估计均为正态分布，说明变分正则化生效 [page 5]。其二，以 MOF-117 为例，在原始隐点能解码回原结构，邻近采样点随距离增大呈现越来越大的结构变化（图 3c）[page 5, page 6]。其三，在两个拓扑不同、几何迥异的已知 MOF（立方 ftw 的 NU-1104 与六方 csq 的 NU-1000）之间做隐空间插值，中间解码结构呈现从立方到六方的清晰几何演化（图 3d）[page 5, page 6]。

更关键的是"按性质组织"这一主张。作者用 PCA 检查联合训练后的隐空间，发现框架分布呈现明显梯度：高性能 MOF 聚集在一侧，低性能在另一侧（图 3a 织构性质、图 3b 气体吸附性质）[page 5, page 6]。作为对照，另训一个不含任何性质、仅用约两百万 MOF 的 SmVAE，其隐表示分布相对性质值没有明显模式（Supplementary Fig. 9）[page 5]。这一对照是"性质条件化确实改变了隐空间结构"的核心证据——没有它，图 3 的梯度可能只是结构相似性的副产品。

## 优化层：从隐空间搜索到候选材料

优化在联合训练后的隐空间中进行。作者训练一个高斯过程（GP）模型来学习隐表示上的性质景观，理由是 GP 局部极小更少、收敛更快，能提供预测不确定性，且便于展示其他优化策略（如进化策略）也可作用于隐向量 [page 5, page 10]。GP 用 5,000 个随机 MOF 的隐向量及性质训练 [page 10]。

作者演示了两条优化路径，目标均为天然气分离中的 CO₂ 吸附量（图 4）[page 7]：

- **等网状（isoreticular）设计**：固定 ftw 拓扑，从 NU-1104（CO₂ 吸附量 0.65 mol kg⁻¹）出发，经一系列中间连接体，优化到 4.33 mol kg⁻¹，且因 CH₄ 吸附量为零而选择性为 ∞* [page 7]。
- **全局优化**：不约束拓扑，从 MOF-5（2.80 mol kg⁻¹）出发，最终发现一个 spn 拓扑 MOF，CO₂ 吸附量达 7.55 mol kg⁻¹，选择性 16.0 [page 7]。

## 候选材料与外部比较：结论在什么条件下成立

作者对全局优化重复运行，按 CO₂ 吸附量排序取前九，再按可合成性（SCScore，越高越难合成）排序，得到表 1 的九个 GMOF [page 8]。所有候选结构经弛豫后稳定，预测性质用 GCMC 重新确认（Supplementary Fig. 11）[page 8]。表 1 显示两类分离机制 [page 8]：

- **尺寸排阻型**（GMOF-1 至 -4）：PLD 为 3.40–3.71 Å，落在 CO₂（3.3 Å）与 CH₄（3.8 Å）或 N₂（3.64 Å）之间，允许 CO₂ 进入而排除 CH₄/N₂，理论上选择性无穷。作者再次提醒，GCMC 中原子固定，真实框架可能有一定柔性，从而允许少量 N₂/CH₄ 吸附，使选择性降为"高但有限" [page 8]。
- **热力学分离型**（GMOF-5 至 -9）：孔径远大于目标分子（LCD 62.61–81.08 Å，PLD 55.99–68.92 Å），AGSA 均 >5,000 m² g⁻¹，提供大量 CO₂ 结合位点，靠 CO₂ 与框架间更强的范德华作用实现选择性 [page 8]。

与文献基准的比较（表 2）需要谨慎解读。作者自己指出，不同测量的条件（温度、压力、气相组成）往往不同，直接比较在实践上很困难 [page 8]。在可比条件下，GMOF-8（7.21 mol kg⁻¹）与 GMOF-9（7.55 mol kg⁻¹）在 5 bar、300 K、CO₂:CH₄ = 1:9 下表现突出，而 Mg-MOF-74 与 zeolite 13X 在 5 bar、313 K、CO₂:CH₄ = 1:1 下容量为 8.0 与 4.4 mol kg⁻¹ [page 9]。对于烟气分离，GMOF-1 在 1 bar、313 K、15/85 CO₂/N₂ 下 CO₂ 吸附量 3.06 mol kg⁻¹、选择性 ∞（零 N₂ 吸附），容量仅低于 Mg-MOF-74 的 4.43 mol kg⁻¹（0.9 bar、313 K、15/75），高于 SIFSIX-2-Cu-i、SIFSIX-3-Zn、UTSA-16 与 13X [page 9]。作者还指出，候选材料仅使用已知稳定的金属节点（Zr₆O₈/Zr₆O₂₀、Cr₃O₄、ZnN₄），可能具有较强化学与湿热稳定性，这对苛刻烟气环境下的碳捕集尤为重要 [page 9]。

## 关键推理步骤与结论的边界

把证据串起来看，从"隐空间按性质组织"到"生成的材料性能优越"，中间依赖一个关键推理：在隐空间中沿性质梯度移动并解码，得到的框架其真实（GCMC 计算）性质也随之提升。作者用两条优化路径的中间结构序列（图 4b、4c）和最终候选的 GCMC 复核（Supplementary Fig. 11）来支撑这一步 [page 7, page 8, page 10]。GP 预测与 GCMC 计算在全部模拟框架（45,000 + 候选）上的 parity plot 吻合良好，是这一推理的直接证据 [page 10]。

但结论的成立有若干明确边界，其中一些是作者承认的，另一些是文本本身可推断的：

1. **搜索空间受限**：不包含新顶点与新拓扑，模型只能重组已知节点/拓扑与增广边 [page 4]。因此"发现新 MOF"应理解为在给定构筑单元池内的新组合，而非全新化学。
2. **∞ 选择性的解释**：源于固定框架与孔道阻塞的模拟设定，作者明确说真实值不会无穷 [page 4, page 8]。表 1 中 3058.0、3157.2、∞ 等数值应视为"预测性能突出"的排序信号，而非可直接引用的物理常数。
3. **合成可行性只是估计**：SCScore 是连接体合成复杂度的计算代理，作者用它排序并建议进一步实验测量，但论文未报告任何实际合成或实验验证 [page 8]。因此"强竞争力"是计算层面的判断。
4. **比较条件不统一**：表 2 中基准材料的数据来自不同条件，作者自己承认直接比较困难 [page 8]。跨条件比较只能作为量级参考。
5. **柔性框架未处理**：气体吸附模拟假设框架刚性，柔性框架的吸附模拟被明确列为超出范围的开放问题 [page 4]。

## 总体判断

这篇论文的论证力量主要来自三点：RFcode 把高维晶体表示压缩为可逆、无冗余的语义元组，使生成建模成为可能；联合训练加对照实验（有/无性质标签的隐空间对比）证明隐空间确实按性质组织，而非仅按结构相似性；以及候选材料用独立的 GCMC 模拟复核，而非仅依赖模型自身预测。其结论的强度则受限于搜索空间不含新节点/拓扑、∞ 选择性来自刚性假设、以及缺乏实验合成验证。作者对后两点的坦白，反而使"这些 MOF 在计算上强竞争力"这一较弱但更可靠的表述站得住脚。
