# 倾向评分方法估计边际风险比的性能：一项模拟研究

**原文题名**：The performance of different propensity score methods for estimating marginal hazard ratios
**年份**：2012　**DOI**：10.1002/sim.5705

## 问题与核心主张

在观察性研究中，处理分配常受受试者特征影响，因此处理组与对照组在基线协变量上存在系统性差异，需要统计方法去除或最小化混杂。倾向评分（propensity score）是"在给定已测基线协变量的条件下接受处理的概率"[page 2]，已有研究证明，在无未测混杂的假设下，对倾向评分进行条件化可以得到线性处理效应（如均值差、比例差）的无偏估计。但生物医学研究中结局常为事件发生时间（time-to-event），此时风险比（hazard ratio）不可折叠（non-collapsible），条件效应与边际效应不再一致，而此前关于不同倾向评分方法估计风险比表现的研究十分匮乏 [page 2]。

作者的核心主张是：在估计边际风险比时，**倾向评分匹配（propensity score matching）与逆概率处理加权（IPTW）能得到偏差极小的估计**；而**倾向评分分层（stratification）与以倾向评分作协变量调整（covariate adjustment）会产生有偏估计**，且它们估计的既不是边际风险比，也不是数据生成过程所设定的那个条件风险比 [page 1, page 6]。在匹配与 IPTW 两者之间，当估计"处理组中的平均处理效应"（ATT）时，IPTW 的均方误差（MSE）更低 [page 1, page 10]。

## 论证的骨架：为什么"不可折叠"是整篇论文的枢纽

要理解作者的推理，必须先抓住"可折叠性"（collapsibility）这一概念。作者指出，均值差和风险差是可折叠的：在没有混杂时，条件效应与边际效应重合。但优势比和风险比不可折叠 [page 2, page 10]。这意味着，一个方法若在估计线性效应时表现良好，并不能保证它在估计风险比时同样无偏——因为"条件化"这一动作本身就会把估计目标从边际效应悄悄换成某个条件效应。

这正是作者对分层和协变量调整给出负面结论的推理核心。作者明确说明：以倾向评分作协变量调整时，模型在给定倾向评分的条件下估计处理效应，因此它估计的是条件效应，这一点"显而易见，甚至不需要模拟来证明"[page 6]。对分层则不那么显然，作者逐一拆解了三种分层实现 [page 3, page 6]：

- **分层（adjusted）**：在 Cox 模型中同时放入处理指示变量和倾向评分分层（五分类变量），这是对分层作条件化的条件模型；
- **分层（stratified）**：Cox 模型按五个倾向评分层分层，允许基线风险函数在各层间变化，但仍在层内条件化；
- **分层（pooled）**：分别拟合五个层内单变量 Cox 模型，再把五个对数风险比合并平均——合并得到的仍是一个"平滑过的"调整效应或条件效应。

作者由此推断：这三种分层方式都不产生边际风险比 [page 6]。同理，在匹配样本中按匹配对分层的 Cox 模型（matched-strata）也是对匹配对条件化的条件模型，因此同样不是边际估计 [page 6]。**这一步是全文最关键、也最容易被读者忽略的桥接**：模拟中观察到的巨大偏差，并非源于数值计算错误，而是因为这些方法在估计一个与目标不同的量。作者用"它们没有估计边际效应，而是给出条件效应度量"来解释图 1、图 2 中分层与协变量调整的大偏差 [page 6]。

## 模拟设计如何支撑结论

作者用蒙特卡洛模拟比较四类方法。数据生成设定为：10 个独立标准正态基线协变量 X1–X10，其中 X1–X7 影响处理选择，X4–X10 影响结局；协变量对处理或结局的效应分为弱、中、强、很强四档，对应回归系数 log(1.25)、log(1.5)、log(1.75)、log(2) [page 4]。处理选择服从 logistic 模型，结局用 Bender 等提出的时间-事件数据生成过程，线性预测子为 LP = β_treat·Z + α_W·x4 + α_M·x5 + α_S·x6 + α_VS·x7 + α_W·x8 + α_M·x9 + α_S·x10，生存时间由 −log(u)/(λ·e^LP)^(1/η) 生成，λ = 0.00002、η = 2 [page 4]。

这里有一个对理解全文至关重要的设计细节：该生成过程本身给出的是**条件**风险比 exp(β_treat)，但作者想要的是**指定边际**风险比的数据。为此，他们用迭代加二分法反解出能诱导出目标边际风险比的 β_treat 值，并分别针对全人群（ATE）和仅处理组人群（ATT）各做一次 [page 4]。作者坦承，把这两个风险比称为"平均处理效应"是对惯例的轻微滥用，因为它们并未显式地对潜在结局之差取期望，其本意只是描述全人群或处理组人群中的平均效应 [page 4]。**这一自我限定很重要**：它说明论文中的"边际风险比"是一个通过潜在结局回归操作化定义的量，而非标准因果推断意义上的 ATE/ATT。

模拟变化的因素为：处理比例（5%、10%、25%）与真实边际风险比（0.8、1、1.10、1.25、1.50、1.75、2），共 21 个情景；每个情景模拟 10,000 个数据集，每个数据集 10,000 名受试者 [page 4]。倾向评分用 logistic 回归对处理状态关于影响结局的七个协变量建模——作者特意选择这一变量选择策略，因为已有研究表明它优于只选影响处理选择的变量 [page 4]。评价指标包括平均处理效应、偏差、相对偏差、MSE、估计标准误与估计量抽样标准差的比值，以及 95% 置信区间的覆盖率和平均长度 [page 4–5]。

## 证据呈现：偏差、方差与覆盖率的分离

**偏差方面**（图 1、图 2）：图 1 画出估计风险比对真实边际风险比，并附单位斜率对角线，偏离对角线即表示有偏 [page 5]。结果显示，协变量调整和三种分层方法的偏差与相对偏差都相当大；匹配的 naïve 与 robust 方法给出相同的相对偏差（因为二者是同一函数形式的边际模型，处理系数估计相同）；而按匹配对分层的匹配方法偏差显著更大；IPTW（两种权重）与 naïve/robust 匹配的偏差都极小 [page 5]。由于使用了 10,000 个数据集，对数风险比估计非常精确，21 个情景下各方法的最大标准误仅为 0.00125 [page 5]。

**条件风险比也未能幸免**（图 3）：既然分层与协变量调整在估计边际风险比时有偏，作者进一步检验它们能否至少无偏地估计数据生成过程所用的条件风险比。答案是也不能——每种方法对条件风险比都有中等程度的偏差 [page 6–7]。作者指出，理论上存在多个条件效应，对每一组被调整的协变量都可能有一个不同的条件效应，因此这些方法究竟在估计哪个条件效应并不清楚，而且它似乎并不等于正确设定结局回归模型、纳入结局预测协变量后所得到的那个条件效应 [page 7, page 10]。**这是对"分层/协变量调整至少能给出某种条件效应"这一直觉的有力反驳**：它们不仅偏离边际目标，连条件目标也对不上。

**方差估计**（图 4）：作者比较了"10,000 个数据集中估计标准误的均值"与"10,000 个估计对数风险比的标准差"，比值等于 1 表示标准误正确反映了抽样变异 [page 5, page 7]。naïve 匹配方法的平均比值为 1.28，robust 匹配方法为 1.09，即忽略匹配样本的配对结构会使标准误平均高估约 28%，而稳健方差估计只高估约 9% [page 7]。IPTW 使用 ATE 权重时比值为 1.0，使用 ATT 权重时为 1.40 [page 7]。**这里出现了一个耐人寻味的张力**：IPTW-ATT 在偏差和 MSE 上表现最好，但其标准误却高估了约 40%。

**覆盖率**（图 5）：95% 置信区间的覆盖率总体欠佳，且随处理比例上升而改善 [page 7]。由于每个情景 10,000 次迭代，覆盖率低于 0.9457 或高于 0.9543 即在统计上显著异于 0.95 [page 7]。作者推测，覆盖率欠佳主要与对数风险比标准误的估计有关，而非与对数风险比本身的偏差有关——因为图 1 显示匹配与 IPTW 的偏差至多极小，而图 4 显示两者都误估了抽样分布的方差 [page 11]。作者明确将"为何如此"列为有待进一步研究的问题，并指出一个值得探索的方向是：倾向评分是被估计出来的，但分析时却当作已知量处理，未来需要能反映"倾向评分已被估计"这一事实的方差估计方法 [page 11]。

**MSE 与精度**（图 7）：由于 naïve 与 robust 匹配给出相同的点估计，二者 MSE 相同。在全部 21 个情景中，IPTW（ATT 权重）的 MSE 都低于匹配估计；21 个情景的平均 MSE，匹配为 0.0023，IPTW(ATT) 为 0.0017，但两者差距随处理比例上升而缩小 [page 10]。作者据此推断，加权分析的估计精度优于匹配分析 [page 12]。需要留意的是，IPTW-ATE 是唯一能估计 ATE 的方法，因此作者没有把它与其他方法直接比较，因为其他方法估计的是处理组人群中的边际效应这一不同量 [page 9–10]。

## 结论成立的条件与作者承认的边界

作者的结论建立在若干明确假设之上。首先是**无未测混杂**——这是倾向评分方法本身的前提，全文的"无偏"都是在这一点下成立的 [page 1]。其次是**倾向评分模型正确设定**：模拟中倾向评分用影响结局的七个协变量估计，这一选择被证明优于只选影响处理选择的变量 [page 4]。第三是**匹配的具体实现**：仅考察了 1:1 贪婪最近邻匹配，卡钳宽度取对数倾向评分标准差的 0.2 倍，因为该宽度在多种设定下表现良好 [page 2, page 3]。

作者主动列出了多项局限 [page 10–11]：

- 结论基于模拟，需要在不同情景、不同基线协变量分布、不同协变量数量及其与处理/结局关系下重复验证；但作者推测结论可推广到其他基线协变量组合 [page 10–11]。
- 只考察 1:1 匹配，未考察 M:1 匹配。作者引用先前研究指出 M = 1 或 2 常为最优；增加每个处理对象匹配的对照数会倾向于匹配到越来越不相似的个体，可能增加偏差，但也会提高精度。作者推测，多对一匹配平均而言会比加权估计有更大偏差 [page 11]。
- 只考察一种匹配算法（贪婪最近邻），未考察最优匹配（optimal matching），后者因计算复杂度更高而被排除；作者认为最优匹配有可能改善匹配方法相对于其他倾向评分方法的表现 [page 11]。

此外，作者与 Gayat 等的结论存在一处分歧：Gayat 等发现分层匹配方法和以倾向评分作协变量调整在估计条件风险比时至多只有中等偏差（相对偏差小于 10%），而本文发现更大的偏差。作者推测原因可能在于：本文协变量从正态分布生成，而 Gayat 等从伯努利分布生成；且本文考察了七个风险比，而对方只考察三个 [page 11]。作者由此得出一个带限定语的判断：倾向评分方法一般会对潜在条件风险比产生有偏估计，但偏差程度会因设定而异 [page 11]。

## 对实践建议的解读

作者最终建议研究者在用观察性或非随机数据分析时间-事件结局时，采用倾向评分匹配和 IPTW 来估计处理的相对效应，因为这两种方法能估计处理的边际效应——即随机对照试验中报告的那个量 [page 12]。IPTW 的一个优势是可通过不同权重同时估计 ATE 和 ATT [page 12]。虽然匹配与 IPTW 都能以极小偏差估计边际风险比，但后者 MSE 更低，提示加权分析精度更高 [page 12]。

需要提醒读者的是，这一实践建议的力度受制于两个未完全解决的问题：其一，覆盖率欠佳意味着基于这些方法构造的置信区间可能不可靠，而作者把原因归于标准误估计而非点估计偏差 [page 11]；其二，IPTW-ATT 的标准误高估约 40% [page 7]，这与它"精度更高"的结论之间存在需要读者自行权衡的张力——MSE 更低说明点估计的抽样波动更小，但区间估计的可靠性是另一回事。作者本人也把"如何为已估计的倾向评分做方差估计"列为未来研究方向 [page 11]，这实际上承认了当前方法在推断层面尚未完全闭合。
