# 涡旋玻璃与高温超导体的相变图景：一篇论证分析

**原文题名**：Thermal fluctuations, quenched disorder, phase transitions, and transport in type-II superconductors
**作者**：Daniel S. Fisher, Matthew P. A. Fisher, David A. Huse
**期刊**：Physical Review B, Vol. 43, No. 1, 1 January 1991
**DOI**：10.1103/PhysRevB.43.130

---

## 一、论文要解决的核心问题

这篇论文处理的是一个原则性问题：在第二类超导体中，当磁场穿透样品之后，热涨落和淬火无序（quenched disorder）是否会破坏超导体的定义性特征——线性电阻严格为零？[page 1]

传统的 Anderson-Kim 磁通蠕变理论给出的答案是否定的：在有限温度下，热激活总是允许磁通线缓慢运动，从而产生非零的线性电阻。作者主张，这一图像在存在淬火无序时可能是错误的。他们提出，无序钉扎可以产生一种新的平衡相——**涡旋玻璃（vortex-glass）相**——它具有自旋玻璃式的非对角长程有序，是真正的超导体，线性电阻严格为零 [page 2, page 4]。

这一主张对常规超导体而言基本是学术性的，但对高温铜氧化物超导体则具有直接的实验意义。高温超导体的高温、短相干长度、大穿透深度和准二维性共同放大了热涨落效应，使得涡旋玻璃物理在可及的实验条件下变得重要 [page 1]。

## 二、论证的起点：平均场相图及其不稳定性

论文从 Ginzburg-Landau 模型的平均场解出发（Fig. 1, [page 2]），建立了两个有序相：Meissner 相和 Abrikosov 涡旋点阵相。涡旋点阵相具有两种自发破缺的对称性：配对场的相位相干（非对角长程有序）和涡旋点阵的平移对称性 [page 2]。

论证的关键转折在于：Larkin 和 Ovchinikov 早已证明，对于空间维度 $D < 4$，任意弱的随机钉扎都会破坏涡旋点阵的晶体长程有序 [page 2]。这意味着真实的二维或三维系统在平衡态下不可能维持长程有序的涡旋点阵。然而，作者指出，现有钉扎理论普遍忽略了一个问题：在点阵关联被破坏的长度尺度之外，配对场的相位相干性是否仍然存在？[page 2]

作者的回答是：可能存在一种涡旋玻璃相，它保留了配对场的非对角长程有序（类似于自旋玻璃中的长程磁有序），但空间结构由无序的具体实现决定，而非周期性点阵 [page 2, page 4]。这一相的核心特征是其输运响应：热激活的涡旋环激发导致非线性耗散，但线性电阻严格为零。

## 三、从证据到结论的关键推理链

### 3.1 Meissner 相中的激活耗散：建立分析范式

论文首先在 Meissner 相中建立了热激活涡旋环产生非线性耗散的图像。半径为 $R$、位于垂直于电流平面的圆形涡旋环的自由能为 [page 7]：

$$F_{\text{loop}} = 2\pi R \epsilon_1 - J \frac{\pi R^2 \phi_0}{c}$$

临界半径 $R_c = c\epsilon_1/(J\phi_0)$ 给出激活能垒 $\sim c\epsilon_1^2/(J\phi_0)$，从而导致电阻率 [page 7]：

$$\rho \sim \exp\left[-\left(\frac{J_T}{J}\right)\right], \quad J_T \sim \frac{c\epsilon_1^2}{\phi_0 T}$$

这里出现了两个特征电流尺度：$J_T$（热激活相滑移）和 $J_F$（非激活的确定性涡旋环产生）。在常规超导体中 $J_T \gg J_F$，因此存在一个看似尖锐的临界电流 [Fig. 3(a), page 3]。但在临界区域附近，$J_T \sim J_F$，I-V 曲线变得圆滑 [Fig. 3(b), page 3]。

**这一步的论证功能**：它为后续涡旋玻璃相的非线性输运分析提供了模板。涡旋玻璃相中的耗散机制在数学结构上与此相同——热激活涡旋环激发——但激活能的标度行为不同。

### 3.2 零场正常-超导转变：建立标度框架

论文在零磁场下分析了从平均场到涨落主导临界行为的交叉。Ginzburg 判据给出交叉温度 [page 8, Eq. (4.1)]：

$$\frac{\alpha \xi^3 \xi_z}{2\beta} = T$$

对于强第二类超导体，系统首先交叉到未带电超流体的 XY 模型临界点，然后极靠近 $T_c$ 时再交叉到带电超流体的临界行为 [page 8]。在中间的 XY 临界区域，作者推导了频率依赖电导率的标度形式 [page 9, Eq. (4.11)]：

$$\sigma(\omega) = \xi^{z+2-D} \Phi_\pm(\omega \xi^z)$$

以及非线性直流电导率的标度形式 [page 10, Eq. (4.18)]：

$$E(J) = J \xi^{D-1} \Theta_\pm(J \xi^{D-1} \phi_0 / cT)$$

**关键推理步骤**：作者论证这些标度形式应该普遍适用于任何连续的正常-超导相变，只需替换相应的关联长度和临界指数。因此，它们也应该适用于涡旋玻璃-涡旋流体转变 [page 11]。这一类比是论文后续实验分析的理论基础。

### 3.3 涡旋点阵熔化：Lindemann 判据与维度交叉

论文用 Lindemann 判据估计了纯净系统中涡旋点阵的熔化温度。在准二维区域（高度层状材料），熔化温度由 2D Kosterlitz-Thouless 熔化温度给出 [page 13, Eq. (5.5)]：

$$T_M = (1\text{--}2) \times 10 \frac{\phi_0^2 d}{16\pi^3 \lambda_{ab}^2}$$

在三维区域，熔化场为 [page 13, Eq. (5.8)]：

$$B_M(T) = \frac{4\phi_0}{\pi^2 \gamma^2 d^2} \left(\frac{T_M}{T}\right)^2$$

作者还指出，在 $H_{c1}$ 附近，涡旋流体相会以"重入"方式侵入 Meissner 相和涡旋点阵相之间 [Fig. 4, page 4]。这一预言的实验意义在于：在低场下，即使温度远低于 $T_c$，也可能存在一个涡旋流体区域。

### 3.4 无序钉扎与涡旋玻璃相

论文的核心论证在于：Larkin-Ovchinikov 机制破坏了涡旋点阵的平移长程有序，但这不意味着相位相干性也被破坏。作者引入涡旋玻璃序参量 [page 18, Eq. (8.1)]：

$$G_{\text{VG}}(r) = \overline{|\langle \psi^*(r')\psi(r'+r)\rangle|^2}$$

在涡旋玻璃相中，$G_{\text{VG}}(r)$ 在 $r \to \infty$ 时趋于非零常数；在涡旋流体相中，它指数衰减 [page 18]。

**从序参量到输运结论的关键一步**：作者论证，涡旋玻璃相中的涡旋环激发具有随面积增长的激活能 [page 18, Eq. (8.3)]：

$$F_L \sim \Upsilon L^a$$

其中 $a = 1 + (1/\zeta)$，$\zeta$ 是涡旋线横向位移的标度指数。对于单根涡旋线，$\zeta \approx 0.6$，因此 $a \approx 2.67$。这导致非线性 I-V 关系 [page 19, Eq. (8.5)]：

$$E(J) \sim \exp\left[-\left(\frac{J_T}{J}\right)^\mu\right]$$

其中 $\mu \leq 1$。由于激活能随面积增长，线性电阻严格为零——这是涡旋玻璃相是真正超导体的核心论证。

### 3.5 涡旋玻璃-涡旋流体转变的标度理论

论文将零场转变的标度框架推广到涡旋玻璃转变。在转变温度 $T_G$ 处，I-V 曲线应呈幂律 [page 22, Eq. (9.2)]：

$$E \sim J^{(z+1)/(D-1)}$$

对于 $D=3$，这给出 $E \sim J^{(z+1)/2}$。作者估计 $z$ 在 4-7 之间，$v$ 在 1-2 之间 [page 22]。

## 四、实验证据的评估

论文将理论预言与 Y-Ba-Cu-O 和 Bi-Sr-Ca-Cu-O 的实验数据进行了对比。

**Y-Ba-Cu-O 的非线性 I-V 数据**：Koch 等人的测量显示，在 $T_G$ 处存在幂律 I-V 曲线，且数据可以用标度形式 (9.1) 拟合，提取的指数 $z=5$，$v=1.8$ [page 26]。作者认为这是涡旋玻璃相存在的初步证据。但作者也承认，这些数据尚未探测到磁涨落变得重要的区域 [page 27]。

**磁弛豫数据**：Yeshurun 等人在 Y-Ba-Cu-O 晶体中观察到对数时间衰减，且 $-\partial J/\partial \ln t$ 在约 20 K 处显示非单调性 [page 26]。这与涡旋玻璃相预言的 (8.7) 式一致，但与 Anderson-Kim 理论的预言不同。

**Bi-Sr-Ca-Cu-O 的 Arrhenius 行为**：与 Y-Ba-Cu-O 不同，Bi-Sr-Ca-Cu-O 在磁场中显示近似 Arrhenius 的电阻行为，激活能随磁场减小 [page 28]。作者将此解释为准二维涡旋玻璃行为：各层中的点涡旋独立钉扎，层间耦合在高温高场下变得不重要 [page 28]。

**μSR 数据的困惑**：μSR 测量暗示 $\lambda_{ab} \sim 5000$ Å，但电阻数据暗示 $\lambda_{ab0} \sim 600$ Å [page 28]。作者承认这是一个未解决的困惑，可能与样品差异或 μ子附近的涡旋畸变有关。

## 五、结论成立的条件与边界

论文的结论依赖于若干关键假设和适用条件：

**第一，维度条件**。涡旋玻璃相在三维中可能在有限温度下稳定存在，但在二维中只存在于 $T=0$ [page 2, page 24]。对于准二维系统，存在一个从 3D 到 2D 行为的交叉，其特征温度依赖于层间耦合强度。

**第二，无序类型**。论文主要讨论微观钉扎（如氧空位），并假设钉扎势的关联长度小于或等于涡旋间距 [page 17]。大尺度无序（如晶界、孪晶界）可能产生定性不同的行为。

**第三，磁涨落的重要性**。作者明确指出，当 $\lambda_{ab} \sim \xi$ 时，磁涨落变得重要，可能改变临界行为甚至破坏涡旋玻璃相 [page 9, page 27]。这一区域尚未被实验探测。

**第四，理论证据的不确定性**。作者坦承，三维涡旋玻璃相的存在性主要基于类比论证，而非严格证明 [page 23]。他们引用了二维涡旋玻璃的数值证据、单根涡旋线在随机势中的玻璃态行为、以及 3D 规范玻璃的数值模拟作为间接支持，但承认"一个更有说服力的理论解决可能需要等待高质量的 Monte Carlo 或高温级数工作" [page 23]。

**第五，标度形式的适用性**。非线性 I-V 的标度形式 (9.1) 假设电流在样品体内均匀流动，而非被屏蔽到表面 [page 22]。在涡旋玻璃相中，电流穿透深度可能变得与关联长度相当，此时均匀性假设失效。

## 六、论证的整体评价

这篇论文的核心贡献在于提出了一个概念上清晰的替代方案：在存在淬火无序的第二类超导体中，涡旋点阵的长程平移有序被破坏，但配对场的相位相干性可以以玻璃式的方式存活，产生一个真正的超导相。这一主张的论证力量来自多个层面的相互支持：

- **理论层面**：Larkin-Ovchinikov 论证确立了涡旋点阵的不稳定性；涡旋环激发的面积标度论证建立了线性电阻为零的机制；标度理论提供了可与实验对比的预言。
- **实验层面**：Y-Ba-Cu-O 的非线性 I-V 数据和磁弛豫数据与涡旋玻璃预言一致；Bi-Sr-Ca-Cu-O 的 Arrhenius 行为可以用准二维涡旋玻璃解释。
- **类比层面**：自旋玻璃、规范玻璃和二维涡旋玻璃的已知行为提供了间接支持。

然而，论证的薄弱环节也很明显。三维涡旋玻璃相的存在性缺乏严格的理论证明；磁涨落区域尚未被实验探测；μSR 数据与电阻数据之间的不一致尚未解决。作者对这些局限的坦诚态度值得肯定——他们明确将这些标记为开放问题，而非确定性结论。

从后续发展的角度看，这篇论文的预言——涡旋玻璃转变的存在及其标度行为——在高温超导体研究中引发了大量后续工作，但涡旋玻璃相是否在三维中真正稳定存在，至今仍是一个活跃的研究问题。
