# 从键长到键价：Brown 与 Altermatt 的无机晶体键价参数系统化提取

**原文题名**：Bond-Valence Parameters Obtained from a Systematic Analysis of the Inorganic Crystal Structure Database（1985，DOI: 10.1107/s0108768185002063）

## 一、论文要解决的核心问题

键价理论的基本假设是：一个化学键的键价 $s$ 与其键长 $r$ 之间存在经验关系，而中心阳离子周围所有键的键价之和应等于该阳离子的氧化态 $V_i$：

$$V_i = \sum_j s_{ij} \tag{3}$$

[page 2]

要使用这一框架，必须知道每种阳离子-阴离子对的具体参数。此前这些参数多由少量结构拟合得到，可靠性参差。本文的目标是：利用无机晶体结构数据库（ICSD）中经 SINDBAD 程序处理过的大量结构，系统性地确定 750 对原子间的键价参数，并给出一个能预测其余上千种组合的算法。

## 二、为什么选择指数形式，以及 $B$ 为何可以固定

描述 $s$-$r$ 关系有两种常用表达式：

$$s = (r/r_0)^{-N} \tag{1}$$
$$s = \exp[(r_0 - r)/B] \tag{2}$$

[page 2]

作者选择式 (2)，理由是一个经验观察：$B$ 在不同原子对之间变化很小，而 $N$ 变化较大。通过精修发现 $B$ 很少能被确定到优于 0.05，且 0.37 与大多数精修值一致 [page 2]。固定 $B = 0.37$ 后，每个阳离子环境中只剩一个待定参数 $r_0$，可由式 (4) 精确求解：

$$V_i = \sum_j s_{ij} = \sum_j \exp\left(\frac{r_0 - r_{ij}}{B}\right) \tag{4}$$

[page 2]

这一步是整个方法的关键简化：把一个二维拟合问题降为一维，使每个环境都能独立解出 $r_0$，再对同一离子对的多个环境取平均。作者指出，通常 10–20 个阳离子环境即可给出可靠值，但用得越多越好 [page 2]。

## 三、数据规模与筛选标准

从 ICSD 中提取了 15 371 个不同的阳离子环境，共确定 750 个 $r_0$ 值 [page 2]。表 1 列出其中最可靠的 141 个，入选标准是 $r_0$ 的标准误差 $\sigma_e \leq 0.01$ Å 且环境数 $n \geq 10$ [page 2]。表中同时给出 $\sigma_e$、$\sigma'$（各环境 $r_0$ 值的标准差）和 $n$。

$\sigma'$ 的含义值得注意：它衡量不同晶体环境中解出的 $r_0$ 是否一致。除碱金属 $\sigma' \approx 0.09$ Å 外，一般落在 0.01–0.05 Å [page 2]。作者明确指出，碱金属的大标准差反映的是阳离子环境的真实物理变化，而非单纯的实验误差 [page 2]。这是一个重要的限定：对这些离子，单一 $r_0$ 值的代表性本身就有限。

作者还尝试了一个额外筛选：在环境数允许时，只保留晶体学 $R$ 因子小于 0.12 的结构，这通常会降低 $\sigma'$，但碱金属除外 [page 2]。表 1 最后一列的 "R" 即标记采用了此限制。

## 四、从个别参数到周期表规律

750 个 $r_0$ 值本身已是有用数据，但作者进一步追问：$r_0$ 是否随离子在周期表中的位置系统变化？他们提出：

$$r_0 = r_c + A \times r_a + P - D - F \tag{5}$$

[page 2]

其中 $r_c$ 和 $r_a$ 分别是阳离子和阴离子的贡献（表 2；氧的 $r_a$ 被任意设为零），$A$ 对含 $d$ 电子的过渡金属离子取 0.8，否则取 1.0。$P$、$D$、$F$ 分别是非键 $p$、$d$、$f$ 电子的修正项，$D$ 值列于表 3，$P$ 和 $F$ 由公式计算：

$$P = 0.0175 \times (\text{阳离子周期} - 2)$$
$$F = 0.016 \times f \text{ 电子数}$$

[page 2]

式 (5) 一般能将确定良好的 $r_0$ 值重现到约 0.013 Å（标准差）或约 $3\sigma_e$ 以内 [page 2]。作者对算法值与其可靠性的判断是审慎的：对表 1 中那 141 个精选值，算法不如实验值；但对剩余 609 个（$\sigma_e > 0.01$ Å 或 $n < 10$），算法值可能不差于甚至优于实验值 [page 2]。此外，该算法还能预测上千种尚未确定参数的阳离子-阴离子组合 [page 2]。

这里有一个推理上的关键转折：作者并非主张算法可以替代实验拟合，而是主张在实验数据不足时，算法提供了一个有物理依据的替代方案。这一判断的成立依赖于式 (5) 所隐含的假设——$r_0$ 可以分解为阳离子和阴离子的独立贡献加上电子结构修正——这一假设在过渡金属和含非键电子体系中得到了表 3 和 $A$ 因子的经验支持，但作者未给出该分解为何成立的更基本论证。

## 五、氢键的特殊处理

氢键被单独处理，原因有二：O–H 键长观测范围从 0.95 到 3.2 Å，跨度太大，任何简单公式都难以全程拟合；且氢原子位置在 X 射线衍射中往往定位不准 [page 2–3]。

图 1 给出 H···X 键价与键长的关系，适用于 O 或 C 为给体的情况，但对 N 为给体时给出的值偏低 [page 3]。作者特别提醒：X 射线衍射定位的是电子密度质心而非原子核位置，氢原子看起来比实际更靠近给体阴离子；因此在使用图 1 前，宜将氢原子移到距给体约 1.0 Å 的位置（O 为 0.95 Å，C 为 1.10 Å 等）[page 3–4]。

即便移动后氢位置仍不确定，作者指出一个不对称性：H···X（受体）键价对键长的小误差不敏感，因此可以较好确定；而 X–H（给体）键价对距离误差极其敏感，因此最好通过从 1.0 中减去受体键价之和来间接确定 [page 4]。这是一个方法论上的重要判断，其依据是式 (2) 中 $s$ 对 $r$ 的导数在不同键长区域的大小不同——短键区域 $s$ 变化更快。

当氢位置完全未知时，对 O–H···O 键，作者提供图 2：H···O 键价与 O···O 距离的关系。该图基于一个假设——氢键弯曲程度遵循 Brown (1976a) 观察到的趋势 [page 4]。作者明确承认这一假设在个别情况下可能不成立，但差异不会很大，对许多用途图 2 可给出足够好的结果 [page 4]。这是论文中少见的作者主动标注的局限。

## 六、结论成立的条件与边界

综合来看，本文结论的适用范围受以下条件约束：

**$B = 0.37$ 的普适性**。这是整个参数体系的基础。作者说 $B$ 很少能被确定到优于 0.05，且 0.37 与大多数精修值一致 [page 2]——注意这是"一致"而非"精确等于"，对 $B$ 敏感的特殊体系（如极短或极长键）可能偏离。

**表 1 中 141 个值的可靠性**以 $\sigma_e \leq 0.01$ Å 和 $n \geq 10$ 为门槛。碱金属的 $\sigma'$ 偏大被归因于真实物理变化，这意味着对这些离子，单一 $r_0$ 的适用性本身有限 [page 2]。

**式 (5) 算法值**的精度约 0.013 Å，作者认为对数据不足的 609 对不差于实验值，但这一判断未经过独立验证，属于作者基于拟合质量的推断 [page 2]。

**氢键部分**：图 1 对 N 给体偏低；图 2 依赖氢键弯曲趋势假设；氢原子位置需先移到理想距离。这些都是作者明说的限制 [page 3–4]。

论文未讨论的参数包括：温度效应、压力效应、以及 $B$ 是否随键长系统性变化。这些在提取文本中均未出现，不应作为作者的结论或局限来陈述。

## 七、整体论证结构的一个观察

本文的论证线索是：从一个已知的物理约束（式 3）出发，选择一个参数较少的函数形式（式 2），利用大规模数据库逐环境求解单参数（式 4），再对结果做两层推广——横向通过周期表规律（式 5）预测未知组合，纵向对氢键这一特殊体系单独建模。每一步推广都伴随明确的适用条件说明。论文的说服力主要来自数据规模（15 371 个环境）和筛选标准的透明性，而非某个单一关键实验的判决性证据。
