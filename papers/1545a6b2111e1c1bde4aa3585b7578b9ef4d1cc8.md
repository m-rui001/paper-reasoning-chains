# 因果推断的七种工具：Pearl 对机器学习的反思

**原文题名：** The Seven Tools of Causal Inference, with Reflections on Machine Learning（2019，DOI: 10.1145/3241036）

## 一、作者要论证什么

Judea Pearl 这篇文章的核心主张是：当前机器学习系统所遭遇的三类根本障碍——适应性/鲁棒性不足、可解释性缺失、以及缺乏对因果关系的理解——都可以借助因果建模工具来克服，尤其是因果图及其配套逻辑。作者进一步断言，因果推理（尤其是反事实推理）是通向人类水平智能的"必要（但非充分）"条件 [page 1]。

这个主张的论证结构不是靠单一实验支撑，而是靠一个理论框架加上七项任务的可行性论证。作者要说服读者的关键一步是：**存在一个严格的三层因果层级，机器学习系统被限制在最底层，而因果建模工具能够系统性地把系统提升到更高层。**

## 二、三层因果层级：论证的地基

作者提出的核心理论装置是三层因果层级（Figure 1, [page 4]）：

1. **关联层（Association）**：以条件概率 $P(y|x)$ 为句法特征，回答"看到 X 会如何改变我对 Y 的信念"。这是当前机器学习的领地。
2. **干预层（Intervention）**：以 $P(y|do(x), z)$ 为句法特征，回答"如果我做 X 会怎样"。这需要随机试验或因果贝叶斯网络才能估计。
3. **反事实层（Counterfactual）**：以 $P(y_x|x', y')$ 为句法特征，回答"如果当初我做了不同的事会怎样"。这需要基于函数关系或结构方程模型才能计算。

层级的关键性质是**方向性**：高层信息可以回答低层问题，反之不行。作者明确指出，"无论数据多大"，干预表达式都不能仅从被动观察中推断出来 [page 3]。这一断言是整个论证的支点——它把"机器学习为什么不够"从经验观察提升为理论限制。

作者还特别加了一个脚注（脚注 b, [page 3]）来堵住一个可能的反驳：即使深度学习通过交叉验证等手段防止过拟合，只要系统优化的仍是观测数据的某种性质、不涉及数据之外的世界，它就仍然停留在第一层。这个脚注很重要，因为它把批评的矛头从"技术不够好"转向"目标函数本身的性质不改变层级归属"。

## 三、SCM 推理引擎：从假设到估计

作者用 Figure 2 [page 4] 展示了一个"推理引擎"的工作方式：输入是假设（图模型）、查询和数据，输出是 Estimand（估计目标，即从假设出发回答查询的数学配方）、Estimate（实际估计值）和拟合指标。

一个具体的例子贯穿了这部分说明 [page 4–5]：查询是 $Q = P(Y|do(X))$，即药物 X 对康复 Y 的因果效应；假设由图 3 编码，其中 Z（性别）同时影响 X 和 Y；数据是从 $P(X,Y,Z)$ 中随机采样的。引擎自动导出的 Estimand 是：

$$ES = \sum_z P(Y|X, Z)P(Z)$$

这个公式的含义是：分别估计男性和女性的条件分布 $P(Y|X,Z)$，按性别概率 $P(Z)$ 加权后取平均。作者指出，这个 Estimand 定义了 $P(X,Y,Z)$ 的一个性质，如果正确估计，就能给出查询的正确答案；而具体的估计值 $\hat{E}S$ 可以用任何能产生一致估计的技术来获得，包括深度学习擅长的稀疏数据估计 [page 5]。

这里有一个值得注意的细节：作者说图 3 的拟合指标是 NULL，因为该图是"完整的"（每对节点之间都有边），因此假设没有可检验的蕴含。这意味着估计的正确性完全依赖于箭头所编码的假设，数据既不能反驳也不能佐证 [page 5]。这是作者自己承认的一个认识论边界：**当模型假设不可检验时，因果结论的可靠性完全落在假设本身的可信度上。**

## 四、七种工具：论证的展开

作者用七种工具来展示 SCM 框架能做什么。这些工具不是并列的清单，而是围绕一个共同主题展开：**如何从不同角度突破关联层的限制。**

**工具 1（编码因果假设）** 和 **工具 2（do-calculus 与控制混杂）** 是基础。工具 1 的核心是透明性和可检验性：图模型让假设以定性形式呈现，d-分离准则则告诉我们数据中应该出现什么样的依赖模式 [page 5]。工具 2 处理的是混杂问题——通过"后门"准则选择控制变量，通过 do-calculus 在无法使用后门时仍能预测干预效果，或者在无法预测时明确失败 [page 5]。

**工具 3（反事实的算法化）** 是作者认为的"当代因果性研究的顶峰成就之一"：每个结构方程模型都决定了每个反事实句子的真值，因此算法可以判断该句子的概率是否可从实验或观察研究中估计 [page 5–6]。这里作者特别提到"果之因"（causes of effects）与"因之果"（effects of causes）的区分，前者如"Joe 的游泳运动是其死亡的充分/必要原因的概率有多大" [page 6]。

**工具 4（中介分析）** 处理的是机制传递问题：X 对 Y 的效应中有多大比例是通过 Z 传递的 [page 6]。**工具 5（适应性、外部效度与样本选择偏差）** 直接回应了文章开头提到的鲁棒性问题：do-calculus 提供了克服环境变化偏差的完整方法论，可用于调整学习策略、控制非代表性样本与目标人群之间的差异，以及在强化学习中评估训练中未出现的新动作 [page 6]。**工具 6（缺失数据恢复）** 指出传统文献局限于"随机缺失"情形，而因果模型可以形式化更一般的可恢复条件 [page 6]。**工具 7（因果发现）** 讨论如何从数据中推断模型结构，包括 Shimizu 等人基于非高斯噪声的函数分解方法，以及 Tian 和 Pearl 的方法 [page 6]。

## 五、关键推理步骤与省略的桥接

从证据到结论的关键推理可以重构为：

1. 因果信息存在严格的层级结构（Figure 1）。
2. 机器学习系统本质上只处理第一层信息（脚注 b 的论证）。
3. SCM 框架提供了在第二、三层进行推理的完整工具集（七种工具）。
4. 因此，机器学习系统可以通过采用 SCM 工具来克服其根本障碍。

作者省略的一个桥接是：**从"工具存在且理论上可行"到"这些工具在实践中能有效提升机器学习系统"之间，文章没有给出大规模实证。** 作者列举的是方法论能力和个别应用方向（如中介分析、域适应），而非系统的实验对比。这不是缺陷——文章是一篇立场性综述而非实证论文——但读者需要意识到，七种工具的"可行性"论证主要是概念性和数学性的，而非工程性的。

另一个隐含假设是：**因果模型中的假设（图结构）是可获得的。** 工具 1 强调透明性和可检验性，但图 3 的例子恰恰说明，当图是完整的时，假设不可检验。在实际应用中，领域知识是否足以构建可信的因果图，是结论成立的重要前提条件。

## 六、结论的边界与局限

作者明确承认的局限包括：因果推断是人类水平智能的"必要但非充分"条件 [page 1]；当查询不可识别时，引擎应"以失败退出" [page 5]；某些模型的假设没有可检验的蕴含，估计的正确性完全依赖假设 [page 5]。

从文本中可以推断（但作者未明说）的边界还有：七种工具的有效性依赖于结构方程模型或图模型的正确设定；do-calculus 的完备性是相对于给定假设而言的，不是绝对的；因果发现方法（工具 7）通常需要"温和假设"（mild assumptions），这些假设在具体领域中的合理性需要逐一评估。

此外，文章对深度学习的定位是"在稀疏数据估计方面表现出色" [page 5]，这意味着作者并不否定机器学习的价值，而是将其定位为因果推理链条中的一个环节（估计技术），而非全部。这个定位本身就是一个值得注意的论证选择：它把"机器学习 vs. 因果推断"的对立转化为"机器学习在因果框架中扮演什么角色"的合作关系。

## 七、整体评价

这篇文章的论证力量在于它把"机器学习缺少什么"从一个模糊的直觉转化为一个精确的理论陈述：三层层级及其方向性限制。七种工具则展示了这个理论陈述的操作性含义。论证的薄弱环节不在于逻辑，而在于从理论可行性到实践有效性的过渡——作者没有（也不可能在一篇通讯文章中）展示这些工具在大规模真实系统中的系统表现。因此，结论的强度应理解为：**因果建模工具在原理上能够克服机器学习的三类障碍，且已有方法论证明其可行性；但这些工具的实际效果取决于具体领域中因果假设的可获得性和可信度。**
