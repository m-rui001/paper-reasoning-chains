# 晶体对称性如何定义新的拓扑相：评 Fu 的“拓扑晶体绝缘体”

**原文题名：** Topological Crystalline Insulators（2011，arXiv:1010.1802v3）

## 一、作者要主张什么

这篇论文的核心主张是：在**没有自旋轨道耦合**的三维绝缘体中，如果同时尊重**时间反演对称性（T）**和**四重（C4）或六重（C6）旋转对称性**，能带结构可以被赋予一种新的 Z2 拓扑分类。属于非平凡类（ν0 = 1）的材料被称为“拓扑晶体绝缘体”（topological crystalline insulator），其**保持旋转对称的 (001) 表面**上存在受对称性保护的、具有**二次能带简并**的无能隙表面态 [page 1]。

作者明确把这一相定位为“拓扑绝缘体在无自旋轨道耦合材料中的对应物”：在普通拓扑绝缘体里，自旋扮演关键角色，表面态是线性色散的 Dirac 锥；而在拓扑晶体绝缘体中，**电子的轨道自由度**（px、py 或 dxz、dyz）扮演了类似自旋的角色，表面态在 ¯M 点形成二次简并 [page 1, page 2]。

一个必须强调的限定是：晶体对称性不同于时间反演对称性，**可以被样品表面破坏**。因此拓扑晶体绝缘体的表面态只在尊重相应旋转对称的特定晶面上受保护；低对称性表面没有稳健表面态 [page 1]。这是理解整篇论文适用范围的关键前提。

## 二、论证的骨架：从模型到不变量再到表面态

论文的论证链条可以概括为三步：

1. **构造一个尊重 C4 对称性的紧束缚模型**，在 (001) 面上数值求解，发现无能隙表面态（Fig.2）[page 2]；
2. **定义一个新的 Z2 拓扑不变量 ν0**，用占据能带的 Bloch 波函数表达，并证明它是规范不变的 Z2 量 [page 3–4]；
3. **建立不变量与表面态的联系**：ν0 = 1 时 (001) 面存在无能隙表面态，ν0 = 0 对应平庸相 [page 4]。

这条链条的关键在于：表面态的存在不是偶然的数值结果，而是由一个可计算、可判定的体拓扑量所保证。下面逐段拆解。

## 三、紧束缚模型：对称性如何决定哈密顿量形式

模型是四方晶格，沿 c 轴每个原胞含两个不等价原子 A、B（Fig.1a），可视为 ab 面内双层正方格子的堆叠 [page 1]。哈密顿量 H 由层内跃迁 HA、HB 和层间跃迁 HAB 组成，见 Eq.(1) [page 2]。

作者特别强调：**H 的形式完全由晶体对称性决定**。层内跃迁是 σ 键型的，依赖 p 轨道与跃迁方向的相对取向 eij；层间跃迁与轨道无关。由于 dxz、dyz 轨道在 C4 下与 px、py 变换方式相同，Eq.(1) 也适用于这些 d 轨道材料，因此作者认为该模型可能对一大类含 t2g 轨道的过渡金属化合物有潜在相关性 [page 2]。这里“potentially relevant”是作者的谨慎措辞，属于可能性陈述，不是已证实的材料预言。

取最近邻和次近邻跃迁后，Fourier 变换得到 Bloch 哈密顿量 Eq.(2) [page 2]。数值参数为 tA1 = −tB1 = 1，tA2 = −tB2 = 0.5，t′1 = 2.5，t′2 = 0.5，t′z = 2。作者声明已检查能隙在整个布里渊区有限（Fig.2a），并指出只要能隙不闭合，系统在有限参数范围内保持同一拓扑类 [page 2]。这是拓扑分类稳定性的标准论证：拓扑不变量在能隙不闭合的连续变形下不变。

## 四、表面态与 k·p 分析：二次简并从何而来

在 slab 几何下求解，作者发现无能隙表面态的存在**关键取决于表面终止方式**。只有保持 C4 对称的高对称 (001) 面存在横跨能隙的表面态，形成二维表面金属（Fig.2b）[page 2]。

关键的结构性事实是：在 ¯M = (π, π) 点，表面态是**双重简并**的，一个来自 px 轨道，一个来自 py 轨道。由于 ¯M 在四重旋转下是固定点，这个双重态构成 C4 对称的二维不可约实表示，这是无自旋轨道耦合（即无自旋费米子）时间反演对称性的结果 [page 2]。

围绕 ¯M 的 k·p 哈密顿量由对称性完全确定，见 Eq.(3) [page 2]：

$$H(k_x,k_y)=\frac{k^2}{2m_0}+\frac{k_x^2-k_y^2}{2m_1}\sigma_z+\frac{k_xk_y}{2m_2}\sigma_x$$

其中赝自旋 σz = ±1 标记双重态的 px、py 轨道，C4 旋转由 eiσyπ/4 表示，时间反演由复共轭表示。作者指出，破坏 C4 的项（M1kxσy + M2σz）或破坏 T 的项（Mσy）都会打开能隙、破坏受保护的表面态 [page 2]。这直接说明保护机制同时依赖 C4 和 T 两个对称性。

## 五、拓扑稳定性的推理：奇偶交叉论证

作者用沿 ¯Γ¯M 的表面能带连通性来论证拓扑保护 [page 3]。在模型内，表面态在 ¯Γ 和 ¯M 必须双重简并。因此沿 ¯Γ¯M 存在两种不同的能带连通方式：在费米能级上**偶数次**或**奇数次**能带交叉。

- 偶数次交叉的表面态是脆弱的，可以通过改变表面势被推出能隙；
- 奇数次交叉的表面态具有包围 ¯Γ 奇数次的费米面，**无法被移除**。

这两类表面态对应两种拓扑不同的相。作者明确说明这一推理“closely follows the previous study of topological insulators”[page 3]，即借用了 Kane 等人处理拓扑绝缘体的思路。这是论证中一个重要的桥接步骤：作者没有在此重新证明奇偶判据，而是援引既有工作。

## 六、Z2 不变量的定义与规范不变性证明

不变量定义在 Eq.(5)–(6) [page 3]：

$$(-1)^{\nu_0}=(-1)^{\nu_{\Gamma M}}(-1)^{\nu_{AZ}}$$

$$(-1)^{\nu_{k_1k_2}}=\exp\left(i\int_{k_1}^{k_2}dk\cdot A_k\right)\frac{\mathrm{Pf}[w(k_2)]}{\mathrm{Pf}[w(k_1)]}$$

其中 Ak 是 U(1) Berry 联络，wmn(ki) = ⟨um(ki)|UT|un(ki)⟩ 是反对称 U(2N) 矩阵，Pf 为 Pfaffian。积分路径：νΓM 沿 kz = 0 面内连接 Γ 和 M 的任意线，νAZ 沿 kz = π 面内连接 A 和 Z 的线（Fig.1b）[page 3]。

论证的关键步骤有三：

**（1）规范不变性。** 在 U(2N) 规范变换 Eq.(7) 下，A 和 w 按 Eq.(8) 变换。利用恒等式 Pf[X^T M X] = det[X] Pf[M]，可验证 νk1k2 规范不变 [page 3]。这是纯代数验证，作者称“straightforward”。

**（2）Z2 性质。** 在 kz = 0 和 kz = π 面上，H(k) 满足 H(k) = ΞH(k)Ξ，其中 Ξ ≡ U²T。这允许选取实规范 Eq.(9)，使 A = 0，于是 Eq.(6) 简化为 Eq.(10)：(−1)^ν = Pf[w(k2)]/Pf[w(k1)] [page 3]。

**（3）Pfaffian 取 ±1。** 由于 |um(ki)⟩ 属于 C4 的二维表示，U²|um(ki)⟩ = −|um(ki)⟩，实规范条件等价于 T|um(ki)⟩ = |um(ki)⟩，即波函数为实。在此实条件下 w(ki) 简化为 ⟨um(ki)|U|un(ki)⟩（Eq.11）。选取特定实基后 w(ki) 化为 N 个 2×2 Levi-Civita 张量的直和 w0，一般实基下 w(ki) = O^T(ki)w0O(ki)，O ∈ O(2N)（Eq.12）。于是 Pf[w(ki)] = det[O(ki)] = ±1（Eq.13）[page 4]。

这一步是整篇论文技术上的核心：它证明 (−1)^νk1k2 是规范不变的 Z2 量，从而 νΓM 和 νAZ 分别刻画 kz = 0 和 kz = π 两个二维动量面上的能带结构，其乘积 ν0 定义三维不变量 [page 4]。

作者还指出，ν0 与 νΓM、νAZ 的关系“analogous to that of strong and weak Z2 index in 3D topological insulators”[page 4]，即类比于三维拓扑绝缘体中的强、弱 Z2 指标。这是类比性陈述，作者并未声称两者数学上等同。

## 七、关键假设与适用边界

论文的结论在若干明确条件下成立，读者需要留意：

**（1）无自旋轨道耦合。** 全文假设自旋轨道耦合可忽略，自旋指标被省略 [page 2]。这是模型和不变量的前提。在有显著自旋轨道耦合的材料中，这套分类是否适用，论文未讨论。

**（2）双重态能带必须与单重态能带可分离。** 作者承认，真实材料的占据能带通常同时含双重简并和单重态分量。只有当双重态在能量上与单重态分离（即无带交叉）时，Z2 不变量才对前者良定义 [page 4]。这是不变量定义的一个实质限制。

**（3）单重态表面态可能破坏表面态。** 补充材料（Supplementary Material）专门分析：若单重态在体内产生一支无保护的非简并表面态，它可以与二次简并表面态杂化。杂化项 H′ 在 k·p 哈密顿量中是**对称性允许的**，当 ϵ3m3 < 0 且 λ ≠ 0 时，原本的带交叉变为避免交叉并打开能隙，表面态可被平滑推入体连续谱 [page 5]。作者由此承认单重态带“in principle”可以破坏无能隙表面态，但强调该情形需要特定条件共存，“seems very non-generic in real materials”，因此对实际用途仍持乐观态度 [page 5]。这是作者明确承认的负面结果与局限，读者不应把它读成表面态绝对稳健。

**（4）表面态只在保持旋转对称的晶面上受保护。** 低对称性表面没有稳健表面态 [page 1]。这是拓扑晶体绝缘体区别于普通拓扑绝缘体的根本特征。

**（5）C6 推广的细节未给出。** 作者称 C6 情形下 (001) 面二次简并点可在 ¯Γ 或两个等价 ¯K，不变量由 ΓK 和 AH 线上的波函数类似定义，具体紧束缚模型“will be reported elsewhere”[page 4]。因此 C6 部分的论证在本文中只是框架性陈述，未完整展开。

## 八、结论的力度与未决问题

综合来看，论文的论证是：**对称性约束哈密顿量形式 → 数值发现无能隙表面态 → 定义并证明 Z2 不变量的规范不变性与 Z2 性质 → 建立不变量与表面态的对应**。其中第 2 步（数值）和第 4 步（对应）之间的桥接，部分依赖对既有拓扑绝缘体论证的类比（奇偶交叉判据），而非本文独立重证。

作者对若干开放问题保持谨慎：真实材料中双重态与单重态共存的影响、相互作用系统的推广、光子晶体中的可能实现，都被列为“would be interesting”或“remains to be developed”[page 4]。这些是作者明说的展望，不是已完成的结论。

一个值得读者注意的分析性推断（非作者原话）：论文的拓扑保护同时依赖 T 和 C4，而 C4 可被表面破坏，这意味着拓扑晶体绝缘体的“拓扑性”在概念上比时间反演保护的拓扑绝缘体更依赖具体晶面选择。这一特征既是其新颖之处，也限制了其在任意表面上的鲁棒性。作者通过强调 (001) 面来规避这一问题，但这也意味着材料应用必须考虑晶面工程。
