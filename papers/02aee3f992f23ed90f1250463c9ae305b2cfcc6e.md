# 用多峰回归估算纳米微晶尺寸：一项 Scherrer 方程修正提案
*Modified Scherrer Equation to Estimate More Accurately Nano-Crystallite Size Using XRD · Ahmad Monshi, Mohammad Reza Foroughi & Mohammad Reza Monshi · 2012 · https://doi.org/10.4236/wjnse.2012.23020*

这篇论文针对 XRD 峰宽逐峰代入 Scherrer 方程后得到的微晶尺寸不一致，提出把多个衍射峰放在一起回归。作者从 `L=Kλ/(β cosθ)` 出发，写成 `lnβ=ln(1/cosθ)+ln(Kλ/L)`，据称以 `lnβ` 对 `ln(1/cosθ)` 作线性拟合，再由截距反算一个共同尺寸。思路是用多峰数据汇总估计，而不是把每个峰当作独立答案；但回归结果能否支持该估计，取决于数据是否符合这条关系及峰宽是否只反映微晶尺寸。

作者用牛骨来源羟基磷灰石作示例：样品在 600、700、900 和 1100°C 热处理后，以 Cu Kα XRD 测量若干峰宽，并报告多峰回归所得尺寸分别为 22.8、35.5、37.3 和 38.1 nm。1100°C 样品出现少量 β-TCP 峰，因此作者为生物材料用途选择 900°C，尽管该温度下报告的微晶尺寸略小。这里的数值是该样品、热处理和分析流程下的结果；XRD 微晶尺寸描述相干衍射域，并不等同于颗粒尺寸。

不过，论文的回归解释存在需要谨慎处理的数学问题。由作者给出的对数关系，理想情况下斜率被固定为 1，截距为 `ln(Kλ/L)`。文中却允许斜率自由拟合，并报告实际拟合斜率偏离 1、甚至为负；作者仍把该拟合截距当作上述理论截距来反算尺寸。斜率与理论关系明显不符时，截距未必还能代表同一个 `Kλ/L`，所以这些反算值不能仅凭“用了最小二乘”就视作更准确。拟合偏离也可能反映峰宽测量误差、峰重叠、晶格应变、仪器展宽、各向异性或峰选择等因素；论文没有通过独立尺寸测量验证所报告精度。

作者以 `2θ=10°` 与 `170°` 的极端角度例子强调高角峰宽理论上会大很多，但这不足以推出 Scherrer 方程本身普遍失效。文中实验的羟基磷灰石峰主要位于约 20°–50° 区间，和极端角度示例并不相同；峰宽差异首先需要结合实际测量区间、仪器响应和其他展宽来源分析。论文也承认若应变贡献不可忽略，须另行分离尺寸与应变展宽，而其回归流程未展示这一分离。

因此，更稳妥的读法是：作者提出了一个多峰汇总估计方案，并在特定羟基磷灰石样品上给出示范值；其“提高准确度”的主张尚需更多验证。复用时应报告峰的选择、仪器展宽校正、尺寸/应变分离方法、拟合斜率及残差，并用显微成像或其他独立方法交叉验证。原文对 1100°C 截距的正文与表格记录也不一致（正文为 −5.6276，表格提取值有疑似排版/OCR冲突），因此该点不宜据单一记录精确复算。
