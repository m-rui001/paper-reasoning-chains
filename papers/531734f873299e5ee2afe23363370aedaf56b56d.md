# 凝固中的不稳定性与图案形成：从 Mullins–Sekerka 失稳到枝晶与胞状界面的选择问题

J. S. Langer, *Instabilities and pattern formation in crystal growth*, Reviews of Modern Physics **52**(1), 1–28 (1980). DOI: 10.1103/RevModPhys.52.1

## 一、这篇综述要回答什么

Langer 开篇就把问题定位得很清楚：晶体生长是生物学之外最漂亮的自组织现象之一，雪花和合金中的枝晶都是"从无结构环境中涌现出图案"的实例 [page 1]。但他反复强调，这类现象在概念上虽然简单，其底层机制却远未被理解。全文的核心主张可以概括为一句话：**凝固界面的形态图案，源于扩散场驱动的不稳定性与毛细力（表面张力）之间的竞争；而"复杂形状如何被选择"这一环节，至今只有自由枝晶给出了一个可能的答案，且这个答案本身还很脆弱。**

作者明确划定了讨论范围：只考虑由单一扩散过程控制的凝固——要么是潜热从移动界面流走，要么是化学成分的重新分配；忽略对流，也忽略绝大多数晶体各向异性效应 [page 1]。这个限定非常重要，因为后面几乎所有结论都建立在这个"各向同性、局域平衡"的简化模型之上。

值得注意的是作者对"普适性理论"的态度。他点名评论了 Thom 的突变论、Prigogine 的耗散结构、Haken 的协同学，认为这些框架在自由度很少的系统中（少模激光、空间均匀化学反应）确有成功，但"无论是广度还是深度，所 conjectured 的普适性原理都尚未确立"，当前需要的不是进一步推广，而是对可实验实现的物理系统做细致分析 [page 3]。这是理解全文取向的关键：Langer 要做的不是套用现成范式，而是展示凝固问题中那些"特定于具体模型、在均匀化学反应的非线性理论中没有对应物"的数学结构。

## 二、三类模型：把物理问题写成方程

作者用第二节建立了三个层次的模型，它们共享同一套数学骨架。

**纯物质凝固**由热流完全控制。温度场满足扩散方程 (2.1)，界面处有热守恒条件 (2.2)，而热力学边界条件是 Gibbs–Thomson 关系 (2.3)：$T(\text{interface}) = T_M[1-(\gamma\mathcal{K}/L)]$，其中 $\gamma$ 是液固表面张力，$\mathcal{K}$ 是曲率 [page 4]。作者特别指出，若省略表面张力项，就退化为数学文献中的经典 Stefan 问题，而**这样的模型根本无法描述自然界看到的图案形成——它缺少设定图案尺度的量纲信息** [page 4]。$\gamma/L$ 具有长度量纲，这正是后来反复出现的毛细长度 $d_0$ 的来源。

**二元合金的等温凝固**把热的角色换成化学扩散。作者用化学势而非浓度来写方程，因为这样界面局域平衡条件就简化为 $\mu$ 连续且取特定值 (2.9) [page 6]。这一节还解释了为什么淬火铸锭会形成不规则图案：即使很稀的合金，化学扩散也可能像纯物质中的热扩散一样控制界面运动，而由于热扩散远快于化学扩散，凝固实际上是等温的，化学效应主导 [page 5]。当液相被"成分过冷"（constitutionally supercooled）时，从壁面推进的平界面就不稳定，会长出溶质贫乏的枝晶森林 [page 6]。

**定向凝固**在化学扩散之外施加一个温度梯度 $T = T_0 + Gz$ (2.10)，从而多了一个控制参数 [page 6]。作者在这里给出了一个重要的方法论点：稳态条件要求液相中的全部溶质被固相吸收，因此界面两侧无穷远处 $C = C_0$；$C = C_0$ 与固相线的交点决定了参考温度 $T_0$ 和界面位置 [page 7]。他还提醒读者不要过度强调"成分过冷"的热力学图像——下一节将表明，界面确实在临界 $v/G$ 处失稳，但这个临界值依赖于固液两相的扩散系数，**底层机制本质上是动力学的** [page 7]。

## 三、Mullins–Sekerka 失稳：全文的物理核心

第三节是整篇综述的支点。作者引入无量纲扩散场 $u$（热模型中是温度，化学模型中是浓度），把两个模型统一起来 (3.1) [page 8]。稳态平界面解 (3.8) 显示：$u$ 在液相中按 $\exp(-2z/l)-1$ 衰减，其中 $l = 2D/v$ 是扩散长度；这个解对任意正速度 $v$ 都存在，但要求无穷远处单位过冷 [page 9]。作者特意点出一个反复出现的事实：**稳态速度 $v$ 并不由过冷度固定**。

线性稳定性分析在准静态近似下进行。对界面施加扰动 $\zeta = \zeta_q\exp(ik\cdot x + \omega_q t)$ (3.9)，解出扩散场 (3.10)，再代入连续性条件，得到放大率 [page 9]：

$$\omega_q = kv\left[1 - (1+p)d_0k^2\right] \quad (3.14)$$

这个公式被作者称为"包含本文将要遇到的大部分物理"。它由两部分组成：**正比于速度的失稳项**和**含表面张力的稳定项**。作者用图 8 直观解释了竞争机制：无毛细力时，界面前凸处（A 点）使前方热梯度变陡，热量快速流走，凸起失稳增长；凹陷处（B 点）则回熔。有表面张力时，曲率使 A 点温度降低、B 点升高，由此产生的从 B 到 A 的热流倾向于恢复平坦 [page 10]。正是这两种效应的竞争决定 $\omega_q$ 的符号。

中性稳定波数给出问题的长度尺度 (3.15)：$\lambda_s = 2\pi/k_s = 2\pi\sqrt{d_0 l}$。作者论证，最快速增长的形变发生在 $k_s/\sqrt{3}$，因此涌现图案的特征尺寸约为 $\lambda_s$ [page 10]。这里有一个关键的尺度分离论证：毛细长度 $d_0$ 是埃量级的微观长度，扩散长度 $l$ 通常是宏观的，所以 $l/\lambda_s = 2vk_s l \gg 1$——这既保证了 (3.14) 近似形式的有效性，也保证了准静态假设成立（失稳增长率 $\omega_{max}\sim k_s v$ 远小于扩散场弛豫率 $\sim Dk^2$）[page 10]。反过来，当 $k_s l$ 很小时，准静态近似失效。

**生长球体**的情形（III.B）给出类似的结论。球对称生长模式在半径超过临界值后失稳，中性稳定半径 (3.28) 对 $j=2$ 模最小，约为 $\sqrt{3}R^*$，其中 $R^*$ 是成核临界半径 [page 11]。作者推断，枝晶形成的不稳定性起源于亚微米量级的晶种，但强调这需要完整的非线性理论加上热涨落分析才能确认 [page 11]。

**定向凝固**（III.C）引入温度梯度后，放大率 (3.36) 多了一个与 $k$ 无关的稳定项，作者定义无量纲参数 $v$（扮演流体力学中 Rayleigh 数或 Reynolds 数的角色）(3.37)，并给出稳定性判据 $v < v_c = 1$ (3.38) [page 12]。在 $D'\ll D$ 的冶金情形下，这个判据形式上与成分过冷判据 (3.39) 相同。但作者再次警告：这个热力学类比可能误导，因为失稳实际上涉及比简单热力学解释更复杂的动力学效应——即使没有毛细修正，固相中可观的扩散率也能在相邻流体有一定过冷时稳定界面 [page 12]。

## 四、枝晶：从针状晶体到边缘稳定性假设

第四节处理自由枝晶，这是全文最深入也最不确定的部分。

**针状晶体模型**（IV.A）先建立零表面张力下的稳态解。在随尖端移动的抛物坐标中，Ivantsov 解 (4.7)–(4.9) 给出 $\Delta = P e^P E_1(P)$，即过冷度只固定 $v$ 与 $p$ 的乘积，不能分别确定两者 [page 13]。引入毛细力后，作者用 Fisher 的球近似 (4.10) 说明 $v$–$p$ 曲线在 $p = 2R^*$ 处有极大值 [page 14]。冶金文献长期猜测这个极大速度对应枝晶的自然工作点，但作者明确指出**这个假设现在看来是错误的**，尽管它作为理论框架刺激了大量研究 [page 14]。

Glicksman 等人在 succinonitrile 上的实验是唯一同时测量 $p$ 和 $v$ 的工作，因而能独立检验稳态理论 [page 15]。实验结果（图 11 中的实心点）落在稳态曲线上，但偏离最大速度预测达 5 倍以上，清楚否定了最大速度假设；同时，自然工作点对应一个几乎等温的针状晶体，形状受毛细力影响很小 [page 15]。于是问题变成：**自然界如何选择这个特定工作点？**

**枝晶不稳定性**（IV.B）给出作者的答案。Langer 与 Müller-Krumbhaar 在 $P\to 0$ 极限下导出界面形变的运动方程 (4.24)，其中只留下两个长度：尖端半径 $p$ 和稳定性长度 $\lambda_s = 2\pi\sqrt{d_0 l}$ (4.28) [page 17]。作者强调这是一个非常普遍的特征：**如果枝晶工作点由稳定性判据决定，该判据必须具有形式 $\sigma = 2d_0 D/(p^2 v) = \sigma^*$ (4.29)，其中 $\sigma^*$ 可能依赖 $P$ 但不依赖 $p$ 或 $v$** [page 17]。这是量纲分析的直接推论。

零表面张力下，Ivantsov 针状晶体明显不稳定，存在无上界的本征值谱，失稳是局域在尖端的"尖端分裂"形变，越尖锐增长越快 (4.33) [page 17]。引入毛细项后，数值计算显示：小 $\sigma$ 时尖端分裂形变仍发生，但产生向下游移动的次级扰动，这些扰动在实验室系中近似静止并增长——这就是**侧枝不稳定性**；较大 $\sigma$ 时尖端稳定，但侧枝行为持续 [page 18]。图 14 展示 $\sigma = 0.025$ 时最活跃的侧枝模式，作者认为这与真实 succinonitrile 枝晶（图 12）"令人鼓舞地相似" [page 18]。

**边缘稳定性假设**（IV.C）是全文最大胆也最脆弱的一步。作者承认线性分析留下了一个连续族的可接受稳态解，因此必须引入非线性论证：侧枝形变达到可观幅度后，向外比向内增长更快，导致有效增厚，使 $p$ 增大、$v$ 减小；而侧枝不稳定性在低速时更强，所以向下波动比向上波动走得更远。净效应是**侧枝活动把枝晶驱向更慢更胖的构型**；但若 $v$ 太小，枝晶又对尖端分裂失稳。因此自然工作点出现在尖端恰好边缘稳定的地方 [page 18]。这就是边缘稳定性假设：即使枝晶生长本质上是非线性过程，$\sigma^*$ 仍可由线性稳定性分析中"本征值实部不再为正的最小 $\sigma$"得到。

作者用球近似给出 $\sigma^*$ 的解析估计 (4.35)：$\sigma^* = 1/[j(j+2)(1+p+j^{-1})]$。对 succinonitrile，$P\approx 1$；若取 $j=2$ 得 $\sigma^* = 0.1$（远大于观测），若假设立方各向异性只允许 $m=4$ 模则 $j=5$ 得 $\sigma^* = 0.026$ [page 19]。Glicksman 最新实验（考虑对流修正后）与 $\sigma^* = 0.0195, j=6$ 吻合极好。图 15 显示 $\sigma^* = 0.025$ 在 succinonitrile 中跨越两个数量级的无量纲速度和一个数量级的过冷度都预测良好 [page 19]。但作者对冰的数据吻合持保留态度：冰的 $P\approx 4$，二重而非四重对称要求 $j=3$，得 $\sigma^* = 0.025$ "似乎完全正确"，但作者认为"鉴于理论的重大不确定性，这种精确吻合很大程度上是偶然的"，并指出当前理论形式不足以描述高度各向异性的系统，必须把各向异性附着动力学纳入稳态计算和稳定性分析 [page 20]。

作者对边缘稳定性理论的局限做了坦率交代：**枝晶的稳定工作点似乎是一个复杂的、动态的、本质非线性的状态，而我们完全不理解这个状态** [page 20]。没有令人满意的模型说明 $\sigma < \sigma^*$ 时的尖端失稳如何把 $\sigma$ 恢复到 $\sigma^*$ 附近而不破坏枝晶结构；可能是极限环，也可能是热涨落驱动的布朗运动。在理解这一点之前，无法判断稳定性判据是精确的、有限适用的近似，还是根本无意义 [page 20]。作者还指出一个耐人寻味的结构：假设的工作点同时对三种独立非平凡形变模边缘失稳——尖端分裂模、沿生长轴的平移模、以及 $p$ 和 $v$ 沿稳态曲线同步移动的模。三种零恢复力模同时出现，产生极其精细的非线性情形，细节行为由相对小的高阶项控制；**这种精细性恰恰可能是理解图案形成过程对生长条件敏感性的关键** [page 20]。

## 五、胞状界面：非线性分析能走多远

第五节转向定向凝固的胞状界面，作者认为平面几何使其成为做完整非线性分析的理想场所。

**单侧模型**（V.A）假设潜热可忽略、两相热导率相同、固相化学扩散为零 [page 21]。Wollkind 和 Segel 的工作是最全面的研究。线性稳定性结果 (5.3) 显示，方括号项作为 $k$ 的函数有极大值；小 $V$ 极限下极大值在 $k_0 l = V^{-1/2}/\sqrt{2}$ (5.5)，临界 $v_0 = 1 + 3(\kappa^2 V/2)^{2/3}$ (5.6) [page 22]。这具体展示了毛细和动力学效应如何使稳定性判据偏离简单的成分过冷规则。

非线性分析的核心是 Landau 常数 $a_2$ 的计算。Wollkind 和 Segel 取 $\kappa = 0.2$，发现 $a_2$ 只在 $V$ 大于约 0.3 时为正，对应 $k_0 l$ 小于约 0.5 [page 22]。但作者指出这个参数区间在理论上很尴尬，因为准静态近似在如此小的 $k_0 l$ 下失效 [page 22]。对可观的溶质浓度，$d_0$ 变得微观小，单侧模型的非线性分析似乎表明界面在失稳时会直接转变为枝晶或非稳态行为，而不经过稳定胞状态 [page 22]。

**对称模型**（V.B）是 Langer 和 Turski 引入的，假设两相化学扩散相同、$\beta = 1$、$\Delta C$ 与温度无关、$\kappa = 1$ [page 22]。这些假设对凝固问题不现实，但保留了定性特征，且可能描述某些液-液或固-固系统中的非平衡界面。作者导出界面运动的非线性积分微分方程 (5.13)，其中记忆效应清晰可见 [page 23]。在准静态近似下得到耦合非线性方程组 (5.14)。

小振幅展开给出 Landau 常数 (5.22)：$a_2 = 4/(k_0 l)^2$，**对小的 $V$ 总是正的** [page 23]。这意味着对称模型在略超临界条件下可以形成重稳定的胞状界面，波数接近 $k_0$，具有静止振幅 (5.23) [page 24]。作者进一步做了完整稳定性分析，把一般界面位移写成 (5.25)，线性化后得到类似周期势中薛定谔方程的本征值问题，可定义 Bloch 波数和能带 [page 24]。稳定性要求所有能带中所有 $\omega$ 都不大于零。对小幅态，最危险的模是与胞状图案侧向平移相关的模。

结果总结在图 17 的 $v$–$k$ 平面：平面界面在实线曲线外稳定；小振幅胞状界面在阴影区（虚线抛物线以上）对纵向形变微分稳定 [page 24]。作者指出这又回到了枝晶问题的类似处境：**数学给出了一整族线性稳定的稳态解，而实验只能固定 $V$ 和 $v$，系统必须自己决定界面构型包括波数 $k_1$** [page 25]。但与枝晶不同，这里实验情况不清楚，不知道自然界是否强烈偏好其中一个态。

**强超临界区**（图 18、19）显示，光滑、静止、重稳定的胞状界面图像在控制参数 $v$ 的相当窄的范围外就崩溃了。在 $v = 1.40$ 时，Landau 常数在 $k_1 = k_c$ 处已变负，小振幅稳态出现在 $k_1 < k_c$ 且不稳定；可能稳定的胞状态都有较大振幅，波数范围延伸到 $k_c$ 以外 [page 25]。图 19 的界面剖面显示出图 7 中胞状结构的症状：前缘相对平坦，沟槽根部尖锐弯曲，图案前移使大部分界面比参考温度 $T_0$ 更热，溶质集中在较冷的窄沟中 [page 26]。数值计算在 $v = 1.50$ 时崩溃，光滑曲线扭曲碎裂，暗示该区域可能不存在真正静止、有限且稳定的胞状结构 [page 26]。

作者还讨论了沟槽深处的问题：在平行于生长方向的界面处没有附近扩散场源，(5.13) 必须退化为 (5.30)，因此若 $\zeta$ 变得大而负，曲率必须变得可观，这与原始图像矛盾 [page 26]。一个出路是让 $v\to\infty$，即先看热梯度消失的极限；这样的无限伸长胞状解可以在数值上找到，出现在 $k_0 l = V^{-1/2}/\sqrt{2}$ 附近的窄波数带内，其间距小于平面失稳的最小波长 [page 26]。

## 六、结论成立的条件与边界

把全文的论证串起来看，Langer 的核心结论——**扩散驱动的不稳定性与毛细力的竞争产生凝固图案，而自由枝晶的工作点可能由边缘稳定性选择**——成立需要一系列明确的条件。

首先是模型层面的假设：单一扩散过程控制、忽略对流、忽略各向异性、界面分子级粗糙（非小面化）、局域平衡的 Gibbs–Thomson 条件 [page 1, page 5]。作者承认这些简化对冶金学家来说"天真地过度简化"，特别是雪花和冰枝晶的六重对称性在模型中完全没有体现 [page 5]。他明确表示，各向异性附着动力学必须纳入稳态计算和稳定性分析，才能描述高度各向异性的系统如冰 [page 20]。

其次是边缘稳定性假设本身的地位。作者反复强调它**没有坚实的理论基础**，是一个单参数理论，$\sigma^*$ 难以从第一性原理准确计算 [page 18, page 20]。原始数值分析假设柱对称形变、忽略固相热流、省略毛细相关的稳态形状修正，这三项缺陷都需要进一步研究 [page 19]。球近似虽然给出与实验吻合的 $\sigma^*$，但作者认为"太粗糙，不能如此当真" [page 19]。

第三是准静态近似的适用边界。它在 $k_s l \gg 1$ 时有效，在 $k_s l$ 小的时候失效 [page 10]。Wollkind–Segel 分析中有意义的参数区间恰好落在准静态近似失效的区域 [page 22]，这是单侧模型非线性分析的一个内在困难。
