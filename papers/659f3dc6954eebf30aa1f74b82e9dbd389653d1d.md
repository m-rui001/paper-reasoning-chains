# 同一批病例上两条 ROC 曲线面积的配对比较：Hanley 与 McNeil（1983）的论证分析

**原文题名**：A Method of Comparing the Areas under Receiver Operating Characteristic Curves Derived from the Same Cases
**年份**：1983　**DOI**：https://doi.org/10.1148/radiology.148.3.6878708

## 问题：为什么不能把两条 ROC 面积当作独立量来比

论文的出发点是一个很具体的统计错误。当两种诊断模态（modality）在**同一批病人**身上各产生一条 ROC 曲线时，研究者常把两条曲线下面积之差的标准误写成

SE(Area₁ − Area₂) = √[SE²(Area₁) + SE²(Area₂)]　（式 1，[page 1]）

作者指出这是不恰当的，因为 Area₁ 与 Area₂ 来自同一批病例，二者很可能正相关：如果随机抽样恰好抽到一批“容易/困难”的病例，两种模态的准确度会**同向**偏高或偏低 [page 1]。因此正确的标准误应包含一个协方差项：

SE(Area₁ − Area₂) = √[SE²(Area₁) + SE²(Area₂) − 2r·SE(Area₁)·SE(Area₂)]　（式 2，[page 2]）

其中 r 是同一批病例在两种模态下诱导出的两条面积之间的相关系数。检验统计量为

z = (A₁ − A₂) / √[SE₁² + SE₂² − 2r·SE₁·SE₂]　（式 3，[page 2]）

**关键推理**：配对设计已经通过“同一批病例”消除了部分抽样波动，若在分母里不把这一部分减掉，分母会偏大、z 偏小，从而低估差异的显著性 [page 2]。这正是本文的核心主张——配对比较应比独立比较更敏感。

## 从“评分相关”到“面积相关”：论文的核心贡献

式 2、式 3 要能用，必须知道 r。但 r 是**两条面积之间**的相关，无法直接观测。作者的策略是分两步走：

1. 先算两种模态在**评分层面**的相关：正常病例组的 r_N 与异常病例组的 r_A，用 Kendall tau 计算（因为 ROC 数据来自有序评分量表）[page 2]。
2. 再通过一张表（TABLE I，[page 3]）把“评分的平均相关”和“平均面积”转换为“面积之间的相关 r”。

TABLE I 是本文自称的“fundamental contribution” [page 2]。它的行是评分平均相关（(r_N + r_A)/2），列是平均面积 ((A₁ + A₂)/2)，表内数值即 r。这一转换依赖**双正态（binormal）假设**：即假设患病与未患病两组评分各自服从高斯分布，且 ROC 曲线可由该假设导出 [page 1]。作者还借助“ROC 面积与 Wilcoxon 统计量的对应关系”来推导面积的标准误与相关结构 [page 1]。

需要说明的是，TABLE I 的推导细节并未在正文给出，作者注明“Mathematical derivation available upon request” [page 2]。因此，读者能核验的是表的**使用方式**，而非其推导过程。

## 实例：CT 体模数据如何走完整个流程

作者用 112 个 CT 体模（58 个“正常”、54 个“异常”）比较两种图像重建算法，单一读者按 6 点量表评分 [page 2]。结果如下（[page 2–3]，附录 [page 5]）：

- 两条 ROC 面积：A₁ = 89.45%（SE 3.0%），A₂ = 93.82%（SE 2.6%）。
- 评分相关：r_N = 0.39（正常体模），r_A = 0.60（异常体模），平均 0.50。
- 平均面积 (89.45 + 93.82)/2 = 91.64，配合平均相关 0.50，查 TABLE I 得面积相关 r ≈ 0.40。
- 代入式 3：z = 0.0437 / 0.0309 = 1.41。

若**忽略配对**（即令 r = 0），z 只有 1.10，单尾 p = 0.136（约 1/7）；考虑配对后 z = 1.41，单尾 p = 0.079（约 1/13）[page 3]。作者谨慎地表述为“the observed difference may not be random” [page 3]，并未宣称差异已确立。这一对照直观展示了配对校正带来的敏感性提升。

作者还给出一个等价算法：用平均面积 0.9164 反推共同标准误 0.0281，再代入 √[2(1 − 0.4)]·0.0281 = 0.0308，得 z = 1.42，与 1.41 几乎一致 [page 3]。这说明当两条面积接近时，用共同标准误是合理简化。

## 模拟验证：z 统计量的表现

为检验 z 的分布是否可靠，作者做了模拟 [page 3]：

- **特异性**：12 种“面积 × 相关”组合各模拟 400 次，共 4800 次。z 的分布“实际上与高斯分布无法区分”，标准差接近 1。z 超出 ±2.0 的平均比例为 5.1%（特异性 94.9%），而理想高斯下应为 4.6%（95.4%）。
- **敏感性（power）**：在四种相关与基线准确度组合下，配对检验可把非配对分析预期的 50% 敏感性提升到 60–75%。

这些模拟支持 z 统计量在零假设下的校准性，以及配对设计在备择假设下的增益。但需注意，模拟的具体参数组合、样本量等细节在正文中未完整列出，读者难以独立复现。

## 结论成立的条件与边界

**依赖的假设**：

- **双正态假设**：TABLE I 的转换以患病/未患病评分服从高斯分布为前提 [page 1]。若真实分布偏离高斯，r 的查表值可能不准。作者在标准误计算中另提供了一种“指数分布”近似，并称其相对高斯假设是保守的 [page 2]，但 TABLE I 本身仍基于双正态。
- **面积作为准确度指标**：整套方法以“ROC 曲线下面积”为比较对象。若改用其他准确度指标（如特定工作点处的敏感度），式 2、式 3 的形式不直接适用。
- **单一读者、单一评分**：正文的 z 检验回答的是“若这一位读者读无限多图像，两种模态的准确度是否相当” [page 4]。它不直接回答“多种模态在多位读者上的总体比较”。

**作者承认的局限**：

- 当评分类别很少（如 ≤4）时，Kendall tau 可手工计算，但 TABLE I 的精度受限于表格粒度 [page 2–3]。
- 在多位读者情形下，Swets 与 Pickett 的公式需要 r_c（病例相关）和 S_c（病例难度方差）等分量，而若每张图像只读一次（m = 1），S_c 与 S_r 不可分离，且 r_c 无法估计，只能假设 r_c = 0，从而放弃配对带来的收益 [page 4]。本文的方法正好补上这一缺口：用 ROC 面积作指标时，r 可通过 TABLE I 从评分相关和面积获得，不必假设 r_c = 0 [page 4]。

**作者未讨论、但影响结论适用性的边界**（以下为分析推断，非原文结论）：

- 论文未给出 TABLE I 的推导细节，也未报告该表在偏离双正态假设时的稳健性。
- 模拟中“z 分布接近高斯”的结论基于特定参数组合，外推到极端面积（接近 0 或 1）或极端相关时需谨慎。
- 论文未讨论 r 的估计误差如何传播到 z 的分布；当样本量小、评分类别少时，r_N、r_A 的估计不确定性可能不可忽略。

## 配对设计的经济性

作者从式 1 与式 2 的比较推出一个简洁关系：若两条面积的标准误相等，则配对与非配对设计达到相同 z 值所需样本量满足

n_p = (1 − r)·n_u　（[page 4]）

例如 r ≈ 0.3 时，非配对需每模态 100 例，配对只需 70 例；总读片数从 200 降到 140，而所需**病人数**从 200 降到 70 [page 4]。作者提醒，若采用非配对设计，必须通过病例匹配或随机分配确保两种模态没有内置优势 [page 4]。

## 小结

本文的论证链条是：配对数据使两条 ROC 面积正相关 → 忽略相关会高估差的标准误、低估显著性 → 用评分层面的相关经 TABLE I 转换为面积相关 r → 代入含协方差项的 z 统计量 → 实例与模拟验证其校准性与敏感性增益。其结论的力度取决于双正态假设、面积作为准确度指标、以及 r 的可估计性；在多位读者、每图只读一次等场景中，本文方法恰好提供了此前只能假设 r_c = 0 的那个相关量。
