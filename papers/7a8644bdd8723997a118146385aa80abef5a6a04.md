# 用光学干涉直接做复数运算：一篇复数神经网络的芯片级论证

**原文题名**：An optical neural chip for implementing complex-valued neural network（2021，DOI: 10.1038/s41467-020-20719-7）

## 论文想解决的那个“错配”

这篇论文的出发点是一个看似技术性、实则概念性的错配：复数神经网络在表达力、收敛速度和泛化能力上被认为优于实数网络，但绝大多数实现复数网络的硬件——数字电子计算机——恰恰不擅长复数运算。复数要被拆成两个实数来表示，一次复数乘法因此膨胀为多次实数乘加（MAC），而 MAC 正是神经网络里最昂贵的操作 [page 2]。作者由此提出一个反问：既然光本身就用振幅和相位两个自由度携带信息，而干涉天然就是复数加法，那么为什么还要把复数网络“翻译”成实数算法，再交给不擅长复数的硬件去跑？

论文的核心主张是：可以在单块硅光芯片上实现**真正的**复数神经网络，让复数乘法由光干涉被动完成，并在多个任务上系统性地优于同构的实数实现。这里的“真正”是关键限定词——作者反复强调，此前多数光学神经网络虽然用光做干涉，但算法仍是实数框架，只用了光强的幅度信息而丢弃了相位 [page 2]。这篇论文要证明的，正是保留相位、让网络在复数域里运行所带来的实际收益。

## 芯片如何把“复数”变成物理事实

论证的物理基础在 Fig. 1b 和 Eq. (1) [page 3]。芯片本质上是一个多端口干涉仪，由马赫–曾德尔干涉仪（MZI）阵列构成，每个 MZI 含两个分束器（BS）–移相器（PS）对，BS 透射率固定 50:50，PS 由热调制调相位。一个 N 模网络通过调整这些 PS，实现任意 N×N 酉矩阵乘法 $S_{out}=U(N)S_{in}$，其中 $U(N)=\prod_{p=2}^{N}\prod_{q=1}^{p-1}T_{pq}D$，每个 $T_{pq}$ 由内部相位 θ 和外部相位 ϕ 参数化（Eq. 1）。换句话说，**权重矩阵不是被“计算”出来的，而是被“配置”进光路的几何结构里**，加权求和通过光干涉被动完成。

这里有一个值得点出的推理桥接：作者说复数乘法“由光干涉被动完成”，但严格说，芯片实现的是酉矩阵乘法，而一般复数权重矩阵并非酉矩阵。论文的处理方式是把权重矩阵分解为多个旋转矩阵与一个对角矩阵的乘积（Fig. 1b 及 Supplementary Notes 4–6），从而用可调 PS 网络逼近任意矩阵。这一步是论证成立的技术前提，但正文把它放进了补充材料，读者若只读正文，会低估“任意复数矩阵可片上实现”这一环节的工程难度。

输入准备、权重乘法、相干探测全部集成在单芯片上（Fig. 1b, 1c）[page 3]。相干探测的作用是同时拿到幅度和相位：通过平衡探测得到 $I_I \propto 2A_sA_l\cos\phi_s$，再对参考光加 π/2 相移得到 $I_Q \propto 2A_sA_l\sin\phi_s$，由二者比值确定相位 $\phi_s$，同时抵消光学器件的物理噪声 [page 3]。探测方式与激活函数绑定：强度探测对应 $M(z)=\|z\|$，相干探测对应 $\mathrm{ModReLU}(z)=\mathrm{ReLU}(\|z\|+b)e^{i\theta_z}$ [page 3]。这个绑定关系是理解后文消融实验的钥匙。

## 从单神经元到网络：四组基准的递进逻辑

论文用四个任务构成一条从“最小能力单元”到“完整网络”的证据链，每一组都配一个同构的实数对照。

**逻辑门**（Fig. 3）[page 4–5] 检验的是单个复数神经元的能力边界。输入是实数（相位限制为 0 或 π），偏置用一个常数输入 1 加可训练复数权重实现，激活函数取恒等，于是 Eq. (2) 简化为 $y=x\cdot W$。权重按 $W\leftarrow W+\Delta W$、$\Delta W=\eta(\hat{y}-y)x^T$ 更新。判定规则是：奇数象限映射为逻辑 0，偶数象限映射为逻辑 1。NAND 和 XOR 的训练过程（Fig. 3b, c）显示，四种输入组合都从随机起点经连续的幅度调制和相位旋转收敛到目标象限，10 次迭代内完成。XOR 的意义在于：它是实数域线性不可分的经典例子，单个实数神经元做不到，通常需要三层实数网络，而单个复数神经元可以 [page 5]。作者谨慎地补充，这些任务是为了揭示复数与实数神经元在**学习能力上的定性差异**，而非真的要去做逻辑门器件 [page 5]——这个限定很重要，避免读者把演示误读为应用。

**Iris 分类**（Fig. 4）[page 5–6] 把测试从单神经元推到单层。150 个样本按 0.75:0.25 划分，实数输入用光强幅度编码、相位保持一致，输出为复数、由相干探测获取。作者比较了三种训练目标：仅相位、仅幅度、以及二者组合。盲测准确率分别为 92.1%、89.5% 和 97.4%。这里的论证重点不是绝对精度，而是**层数与误差累积的权衡**：单复数层仿真精度 99.3%、片上 97.4%；而常用的三层实数网络虽然仿真精度相当（97.3%），但在物理实现时会因多层累积误差大幅下降 [page 6]。作者据此主张，复数模型用更少的层和神经元就能在物理实现中保持高精度，从而规避累积误差。需要注意，这个对比中“三层实数网络物理实现会下降”是作者基于补充材料的推断，正文没有给出该实数网络的实际片上数据，因此这一条的证据强度弱于复数层自身的片上结果。

**非线性数据集 Circle 和 Spiral**（Fig. 5）[page 6–7] 是全文论证最漂亮的一环，因为它把“复数网络能构造非线性决策边界”从直觉变成了可推导的数学事实。作者对单层双神经元模型做了解析：实数模型的决策边界由 $\|y_1\|=\|y_2\|$ 给出，解出的是两条直线（Eq. 4）；而把权重和偏置换成复数 $w_{jk}=p_{jk}+iq_{jk}$、$b_j=m_j+in_j$ 后，同一条件展开为 Eq. (5)，可化简为二元二次方程 $Ax_1^2+Bx_2^2+Cx_1x_2+Dx_1+Ex_2+F=0$（Eq. 6），随参数不同可形成抛物线、圆、椭圆、双曲线 [page 6]。这就从代数上解释了为什么 Fig. 5b, c 中实数边界是直线、复数边界是能贴合纠缠数据形状的曲线。仿真精度上，复数模型在 Circle 和 Spiral 上均达 100%，实数模型仅 55% 和 89%；片上扫描 441 个输入点（x₁, x₂ 从 −1 到 1，步长 0.1），复数模型片上精度为 Circle 98%、Spiral 95% [page 7]。作者也诚实指出，理论边界是光滑的，实验可视化分辨率受输入间隔限制 [page 7]。

**手写数字识别**（Fig. 6）[page 7–8] 把单层扩展为多层感知机（MLP）。网络结构为输入层 784×4、隐藏层 4×4、输出层 4×10，隐藏层在 ONC 上实现，输入输出层电学执行。训练用 TensorFlow 的 RMSPropOptimizer，学习率 0.005，100 次迭代，批大小 100；实数模型用 ReLU，复数模型用 ModReLU。复数模型训练精度 93.1%、测试 90.5%，实数模型 84.3% 和 82.0%，且复数模型收敛更快 [page 8]。

## 消融实验：把“复数优势”拆开来看

手写识别部分真正的论证转折在消融实验（Fig. 6e, Table 1）[page 8]。作者意识到一个可能的质疑：复数模型精度高，也许只是因为它从上一层接收了更多信息（幅度+相位），而不是复数权重矩阵本身有优势。于是设计了五种配置：(a) 完全复数；(b) 实数编码、复数探测；(c) 复数编码、实数探测；(d) 实数编码+实数探测；(e) 完全实数。前四种的隐藏权重矩阵都参数化为复数。

结果（Table 1，N=4）显示：完全复数测试 90.5%，实数编码 87.0%，实数探测 88.5%，实数编码+实数探测 86.5%，完全实数 82.0%。关键结论有两条。第一，**即使编码和探测都退化为实数，复数权重模型仍以 86.5% 对 82.0% 胜过实数模型**——这直接回应了“优势只来自更多信息”的质疑，说明复数权重矩阵本身有独立贡献。第二，复数编码（87.0%）比复数探测（88.5%）带来的增益更小，作者据此推断“扩大输入信息”比“改进探测方式”贡献更大，而探测方式的妥协影响相对边缘 [page 8]。这个推断方向合理，但要注意 87.0% 与 88.5% 的差距不大，且只基于 N=4 一组数据，作者用“relatively marginal”这样的谨慎措辞是恰当的。

容量对比进一步支撑“小芯片办大事”的主张：4×4 复数模型（有效实数参数容量 32）以 93.1% 训练精度胜过 8×8 实数模型（容量 64）的 92.3%；要达到可比性能，复数模型只需 4 模芯片上的 12 个 PS，而实数模型需要 8 模芯片上的 56 个 PS [page 8]。作者由此论证，复数实现能在不增加硬件复杂度的前提下提升学习能力，从而缓解当前大规模光学芯片制造受限的问题 [page 9]。

## 结论在什么条件下成立

论文的结论有明确的适用边界，其中一部分是作者自己承认的，一部分是文本分析可以补足的。

作者明确承认的限制包括：当前光学电路难以达到实用神经网络的规模，尽管工业代工的发展可能使其可行 [page 9]；多层扩展需要级联光路，虽然作者主张其方案满足可级联光子神经网络的全部判据（同构性、物理可级联性、增益可级联性、噪声可级联性），但噪声级联性仍是薄弱环节——神经元变量由光波表示，噪声不可避免地受相位不精确、光电探测噪声、耦合漂移和热串扰影响，作者建议在训练中考虑噪声并用已验证策略补偿 [page 9]。此外，手写识别任务中只有隐藏层在片上实现，输入输出层是电学的，作者称理论上可通过矩阵分解在 ONC 上实现，但出于实际工作量只做了隐藏层的原理验证 [page 8]。

从文本可以补足的边界还有几处。其一，所有基准的规模都很小（最多 8 模、56 个 PS），复数优势是否在更大规模上保持，论文没有验证。其二，Iris 任务中“三层实数网络物理实现会因累积误差下降”这一对比，正文未给出该实数网络的片上实测数据，属于基于补充材料的推断，证据强度有限。其三，逻辑门任务中作者自己声明其目的是揭示定性差异而非器件实现 [page 5]，因此不应被解读为复数神经元在逻辑运算上的实用优势。其四，消融实验中“复数编码贡献小于复数探测”的结论基于 N=4 单组数据，且两者差距不大，宜视为趋势性观察而非确定结论。

## 论证的整体形状

把四组任务和消融实验连起来看，论文的论证结构是：先用逻辑门证明单个复数神经元能解决实数神经元原理上做不到的问题（XOR），再用 Iris 证明单层复数网络在物理实现中比多层实数网络更抗误差累积，然后用 Circle/Spiral 从代数上证明复数网络的决策边界是二次曲线、从而能贴合非线性数据，最后用 MNIST 的消融实验把“复数优势”分解为权重矩阵本身的贡献与编码/探测方式的贡献。这条链条的每一环都配了实数对照，且对照是同构的（相同层数、相同神经元数），这是论证可信度的主要来源。

最关键的推理一步，是 Eq. (5)–(6) 把复数网络的非线性决策边界从“实验观察”提升为“代数必然”：实数模型的 $\|y_1\|=\|y_2\|$ 是直线，复数模型展开后是二次曲线。这一步让“复数网络更适合非线性任务”不再只是经验断言，而有了可推导的根据。相对地，论文对“复数优势在规模上是否持续”“噪声级联是否真的可行”这两个决定实用前景的问题，只给出了方向性论述而非实验证据，这是读者在采纳其结论时需要保留的余地。
