# 用 Sigmoid 加权线性单元做强化学习中的神经网络函数逼近：一篇论证分析

**原文题名**：Sigmoid-weighted linear units for neural network function approximation in reinforcement learning（2018，DOI: 10.1016/j.neunet.2017.12.012）

## 一、论文想证明的两件事

这篇论文的主张可以拆成两条彼此独立、但共享同一套实验平台的结论。

第一条是**激活函数层面**的：作者提出两种新的隐藏单元激活函数——Sigmoid 加权线性单元（SiLU，定义为输入乘以它的 sigmoid）及其导数形式 dSiLU，并主张它们在强化学习的函数逼近中优于 ReLU、sigmoid 等常用单元 [page 6]。SiLU 的动机来自作者此前研究的受限玻尔兹曼机（EE-RBM）：EE-RBM 对状态价值的估计恰好可以写成一个隐藏层前馈网络，其隐藏单元激活就是 $z_k\sigma(z_k)$，输出权重恒为 1（式 6–9）[page 5–6]。也就是说，SiLU 不是凭空设计的，而是把 EE-RBM 中已被验证有效的隐藏节点贡献"提取"出来当作通用激活函数。dSiLU 则是这个激活的导数（式 10），作者称它"像 sigmoid 的更陡、会过冲的版本" [page 7]。

第二条是**算法范式层面**的：作者主张，用带资格迹的 on-policy 学习（TD(λ)/Sarsa(λ)）配合 softmax 动作选择，可以不用经验回放、也不用独立的目标网络，就与 DQN 竞争 [page 3–4]。这条主张带有明确的"复古"色彩——它回到 Tesauro 的 TD-Gammon 路线，而非 DQN 的 off-policy + replay 路线。

两条主张的验证路径不同：第一条靠激活函数之间的受控对比，第二条靠与 DQN 系列在 Atari 上的横向比较。下面分别看证据如何支撑它们。

## 二、激活函数主张的证据链

**浅层网络对比（SZ-Tetris）**。作者在随机 SZ-Tetris 上用 TD(λ) 训练了四种隐藏单元（SiLU、ReLU、dSiLU、sigmoid）的浅层网络，各跑 10 次，每次 20 万 episode [page 9–10]。结果（表 1）显示四者最终平均分差异显著（$p<0.0001$）：dSiLU 263 分 > sigmoid 232 > SiLU 214 > ReLU 191 [page 11]。这里的关键推理是：**有界单元（dSiLU、sigmoid）整体优于无界单元（SiLU、ReLU）**，而在同类内部 dSiLU 又胜过 sigmoid、SiLU 胜过 ReLU。作者把 dSiLU 的优势部分归因于它的"软地板"性质——SiLU 在 $z_k\approx-1.28$ 处有约 $-0.28$ 的全局最小值，这个导数为零的点像隐式正则项，抑制权重变得过大 [page 6–7]。这是从函数形状到学习稳定性的桥接，属于作者明说的机制解释，但论文并未单独做消融来隔离"软地板"的贡献，所以这一因果链是**合理但未被直接证明**的。

**深层网络对比（SZ-Tetris）**。作者进一步用原始棋盘作为状态，比较 SiLU-SiLU、ReLU-ReLU、SiLU-dSiLU 三种深层结构 [page 10]。SiLU-dSiLU 显著优于另两者（$p<0.0001$），最终平均 229 分，超过此前最优的 220 分；而 SiLU-SiLU 与 ReLU-ReLU 之间无显著差异（$p=0.32$）[page 11]。这个"无差异"结果值得注意：它说明在卷积层里 SiLU 相对 ReLU 的优势并不稳定，dSiLU 的增益主要来自最后的全连接层。作者据此在 Atari 实验中固定采用 SiLU-dSiLU 结构 [page 13–14]。

**跨任务外推（10×10 Tetris）**。dSiLU 浅层网络在 10×10 标准 Tetris 上取得平均 4900 分、最佳单次 5300 分，均刷新纪录（此前 CBMPI 为 4200/5000）[page 12–13]。作者特别强调，这一成绩只用 Bertsekas 类特征就达成，而 CBMPI、DPI、CE 等方法仅用同类特征时只能到约 500 分 [page 13]。这一步的作用是**把激活函数的优势从简化任务外推到更接近标准 Tetris 的设定**，增强结论的普适性。

## 三、算法范式主张的证据链

**Atari 上的横向比较**。作者用 Sarsa(λ) + SiLU-dSiLU 深度网络，在 12 个以 A、B 开头的 Atari 游戏上训练 20 万 episode，各跑 2 次 [page 14]。选游戏的方式是"按字母顺序"而非挑好成绩的游戏，这是作者刻意避免选择偏差的设计 [page 14]。结果（表 2）显示，DQN 归一化后的平均 Best 分从 double DQN 的 127% 提升到 332%，中位数从 105% 提升到 125% [page 17–18]。作者据此声称超越了 DQN 和 double DQN。

但这里有一个**必须交代的边界**：Final 分（用最终 mScore 计算）的 DQN 归一化中位数只有 78%，低于 DQN 的 100% [page 17]。也就是说，按"最终稳定表现"衡量，该方法在多数游戏上并不占优，优势主要体现在"最佳表现"上。作者用 Best 分是为了与 DQN 系列的报告口径对齐（DQN 报单次、Gorila 报 5 次平均、double DQN 报单次，且 mScore 窗口长度不一）[page 15–17]。这种口径对齐是必要的，但也意味着 332% 这个数字对"取最佳"这一操作敏感。此外，Breakout 一局学习完全没起来（Final 25、Best 55），作者也承认这是明显失败 [page 18]。

**为什么 on-policy 能行：价值估计分析**。作者用一节专门论证 TD(λ)/Sarsa(λ) 不会像 Q-learning 那样因 max 算子而高估动作值 [page 18]。在 SZ-Tetris 中，dSiLU 网络对折扣回报的估计在平均长度 episode 上仅有 -0.43 的轻微低估（图 7）[page 18–19]；在 Asterix 和 Asteroids 中，学习到的动作值与折扣回报沿整局高度吻合（图 8）[page 19–20]。这是**支撑"on-policy 可行"这一主张的机制性证据**：它说明不用 double DQN 那类去偏技巧，价值估计本身就不会系统性高估。不过要注意，作者展示的是"表现好的 agent 在训练末期的估计质量"，这不能排除训练早期或表现差的 agent 存在高估。

**为什么 softmax 重要：动作选择分析**。作者比较了 softmax（不同退火温度）与 ε-greedy（不同 ε）在 SZ-Tetris、Asterix、Asteroids 上的表现（表 3）[page 21]。结论很鲜明：ε=0.05（DQN 评估常用值）下得分只有 softmax 的 4%–10%；即便 ε 低到 0.001，Asteroids 和 SZ-Tetris 的得分仍比 ε=0 下降 26% 和 22%；而 softmax 把非贪心动作数增加约一个数量级，得分只降 7%–10% [page 21–22]。作者的推理是：在这些游戏里，最差动作的后果极坏（Tetris 里多数动作会造洞、Asterix 里随机动作会送命、Asteroids 里一个动作会把飞船传送到随机位置），ε-greedy 对所有动作等概率探索，因此代价高昂 [page 20]。这是**从任务结构到探索策略选择**的桥接，逻辑清晰，且被数据支持。

## 四、关键推理步骤与成立条件

把两条主张的推理骨架抽出来看：

激活函数主张的关键一步是**"EE-RBM 的隐藏节点贡献可独立作为激活函数"**。这一步是设计动机，不是被证明的定理；它的合理性由后续实验（SiLU 胜过 ReLU、dSiLU 胜过 sigmoid）间接支持。结论成立的条件是：任务具有 Tetris/Atari 这类"错误动作代价高、需要稳定价值估计"的结构。论文没有在纯监督任务上验证（虽然引用了 Ramachandran 等人在 CIFAR/ImageNet 上的独立发现 [page 3]），所以"SiLU 普遍更优"不是本文的结论，本文只主张它在**强化学习函数逼近**中更优。

算法范式主张的关键一步是**"on-policy + 资格迹 + softmax 足以替代 replay + 目标网络"**。这一步的证据是 Atari 上的横向比较加上价值估计与动作选择两组分析。它成立的条件相当具体：需要 softmax 退火调度得当（温度退火式 13）、需要任务对随机探索敏感、需要价值估计不因 max 算子而失真。作者也明确承认，这并不意味着该方法已到顶——他们指出还有空间引入目标网络、dueling 架构、异步并行学习等 DQN 系改进 [page 22]。换言之，论文主张的是"传统路线有竞争力"，而非"传统路线优于一切"。

## 五、作者承认与未讨论的局限

作者明确承认的局限有两处：一是无法把方法用到标准 20 行高的 Tetris，因为学习时间过长 [page 12]；二是 Atari 上用了比 DQN 更小的网络（两层卷积、滤波器数减半）和更少的训练量（20 万 episode、2 次运行），这是出于计算考虑 [page 14]。Breakout 的失败也被如实报告 [page 18]。

需要读者自己留意的、论文未充分讨论的边界：Atari 只跑了 2 次运行，Best 分的方差未被报告；12 个游戏按字母选取虽避免了挑选偏差，但样本量小，且未覆盖 DQN 论文的全部 49 个游戏；SZ-Tetris 与 10×10 Tetris 的对比中，激活函数优势与任务难度、特征集、网络规模纠缠在一起，难以完全分离。这些不是作者的结论，而是基于文本的分析推断，用于界定结论的适用范围。

总体而言，这篇论文的论证是"设计动机 + 受控对比 + 跨任务外推 + 机制分析"的组合：激活函数部分证据较扎实（多任务、多结构、显著性检验），算法范式部分证据方向明确但受口径和样本量限制。两条主张都成立，但都带有明确的适用条件——前者限于强化学习函数逼近，后者限于对随机探索敏感、价值估计不易高估的任务。
