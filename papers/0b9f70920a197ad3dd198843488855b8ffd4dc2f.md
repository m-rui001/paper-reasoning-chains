# 用不同激发能量下的拉曼光谱定量石墨烯中的缺陷

**原文题名**：Quantifying Defects in Graphene via Raman Spectroscopy at Different Excitation Energies（2011，DOI: 10.1021/nl201432g）

## 一、论文要解决的问题与核心主张

这篇论文处理的是一个看似简单、实则容易混淆的定量问题：如何用拉曼光谱测出石墨烯中**点缺陷**的密度，并且让这个测量不依赖于所用的激光能量。

作者首先区分了两类"无序"的几何含义。在纳米微晶石墨中，无序程度由晶粒尺寸 $L_a$ 描述，本质上是"边界（一维缺陷）相对于晶粒面积"的比例；而在含零维点缺陷的石墨烯中，无序程度应由**缺陷间距** $L_D$ 描述 [page 1]。这两者的拉曼响应规律并不相同，因此不能把测 $L_a$ 的老公式直接搬来测 $L_D$。此前 Lucchese 等人 [ref 28] 已经在单一激光线（$E_L = 2.41$ eV）下建立了 $I_D/I_G$ 与 $L_D$ 的关系，本文的任务是把这个协议推广到**任意可见光激发能量**。

核心结论有三条：

1. 对给定的缺陷密度，$I_D/I_G$ 强烈依赖激光激发能量 $E_L$；这一依赖几乎全部来自拟合参数 $C_A$ 的变化，而拉曼相干长度 $r_A$ 与 $E_L$ 无关 [page 4]。
2. 作者据此给出了一组经验公式（式 3–6），可在 $L_D \geq 10$ nm、可见光范围内用任意激光线定量点缺陷密度 [page 4]。
3. 对**所有**激发能量，$I_D/I_G$ 都在 $L_D \sim 3$ nm 处达到最大值；因此单凭一个 $I_D/I_G$ 值无法区分"缺陷少"和"缺陷多"两种情形，必须结合 G 峰宽度 $\Gamma_G$ 才能消除这一歧义 [page 1, page 5]。

## 二、实验设计与证据链

**样品与缺陷引入方式。** 作者用机械剥离制备单层石墨烯（SLG），再用 Ar⁺ 离子轰击引入缺陷。离子动能 90 eV，入射角相对样品表面法线 45°，在超高真空中进行（基础压强 $5 \times 10^{-11}$ mbar）[page 2]。据理论计算，此条件下主要产生单空位和双空位 [ref 37, 38]。轰击剂量从 $10^{11}$ Ar⁺/cm²（约每 $4\times10^4$ 个碳原子一个缺陷）到 $10^{15}$ Ar⁺/cm²（约每四个碳原子一个缺陷），由此得到 $L_D = 24, 14, 13, 7, 5, 2$ nm 的系列样品 [page 2]。$L_D$ 是独立测定的（沿用 ref 28 的程序），不是从拉曼谱反推的——这一点对论证很关键，因为它保证了 $I_D/I_G$ 与 $L_D$ 的关系是"用独立标尺校准的"。

**拉曼测量。** 三条激发线：Ti–Sapph 1.58 eV（785 nm）、He–Ne 1.96 eV（632.8 nm）、Ar⁺ 2.41 eV（514.5 nm）。光斑约 1 μm，功率约 1.0 mW 以避免加热 [page 2]。

**图 1** 给出 $E_L = 2.41$ eV 下五个不同剂量样品的谱，标注了 G、D、D′、2D、2D′、D+D′ 等峰。作者指出 $L_D = 2$ nm 的样品已失去尖锐的二阶峰，说明该样品进入了第二阶段的起点 [page 2–3]。**图 2a–c** 是三条激发线下的一阶谱，**图 2d** 专门对比 $L_D = 7$ nm 样品在三种能量下的谱，直观显示 $I_D/I_G$ 随 $E_L$ 明显变化 [page 3]。

## 三、从证据到结论的关键推理

### 1. 为什么 $I_D/I_G$ 会随 $L_D$ 先升后降

这是全文的物理骨架，作者用"缺陷贡献是否独立叠加"来解释 [page 3]。

在**第一阶段**（缺陷稀疏），每个缺陷独立贡献 D 峰散射，$I_D$ 正比于激光光斑内探测到的缺陷总数。若光斑尺寸 $L_L$、平均缺陷间距 $L_D$，则光斑面积内有约 $(L_L/L_D)^2$ 个缺陷，故 $I_D \propto (L_L/L_D)^2$；而 $I_G$ 正比于总探测面积 $I_G \propto L_L^2$。两者相除得

$$I_D/I_G \propto 1/L_D^2$$

但是，当两个缺陷的距离小于电子–空穴对在散射声子前走过的平均距离时，它们的贡献不再独立叠加。这个距离可估计为 $v_F/\omega_D \sim 3$ nm（$v_F \sim 10^6$ m/s 为 K、K′ 点附近的费米速度）[page 3]。这解释了为什么 $I_D/I_G$ 在 $L_D \sim 3$ nm 处达到峰值。

在**第二阶段**（$L_D < 3$ nm），sp² 畴变小、六元环减少并畸变。由于 G 峰只与 sp² 碳的相对运动有关，可近似认为 $I_G$ 大致不随无序变化；而随着 sp² 环的丧失，$I_D$ 相对 $I_G$ 下降，于是 $I_D/I_G \propto 1/L_D^2$ 不再成立，转为 $I_D/I_G \propto M$（$M$ 为有序六元环数），进而 $I_D/I_G \propto L_D^2$ [page 3]。作者特别强调：在第二阶段，D 峰的出现反而意味着"有序化"，与第一阶段正好相反。

### 2. 拟合公式与参数

**图 3** 的实线是按下式拟合的 [page 3–4]：

$$\frac{I_D}{I_G} = \frac{C_A}{(r_A^2 - r_S^2)}\left(r_A^2 - 2r_S^2\right)\left[e^{-\pi r_S^2/L_D^2} - e^{-\pi(r_A^2 - r_S^2)/L_D^2}\right] \quad (1)$$

其中 $r_S$ 是离子撞击造成的结构无序区半径，$r_A$ 是缺陷周围"sp² 六角结构仍完好、但 D 带散射仍发生"的区域半径；$r_A - r_S$ 即 D 带散射的拉曼弛豫长度，与经历光学声子非弹性散射的电子的相干长度相关 [page 4]。拟合取 $r_S = 1$ nm（结构参数，与 $E_L$ 无关），所有数据可用同一个 $r_A = 3.1$ nm 拟合，与 refs 28、29、35 一致 [page 4]。作者选择 $C_S = 0$，理由有二：$C_S$ 应依赖缺陷结构，理想情况下（缺陷即 C–C 键断裂）应为零；且本文不聚焦 $L_D < r_S$ 的大缺陷密度区 [page 4]。

$C_A$ 对应理想情况下（D 带在整个样品被激活、无六角环破坏）可能观测到的最大 $I_D/I_G$ [page 4]。**图 3 插图**显示 $C_A$ 随 $E_L$ 下降，用 $C_A = A E_L^{-B}$ 拟合，固定 $B = 4$（与 refs 9、10 一致），得 $A = (160 \pm 48)$ eV⁴ [page 4]。这就是"$I_D/I_G$ 随 $E_L$ 变化"的来源：$r_A$ 与 $E_L$ 无关，变化全在 $C_A$。

### 3. 低缺陷密度区的实用公式

在 $L_D \geq 10$ nm（即 $L_D > 2r_A$）区间，式 1 可近似为 [page 4]：

$$\frac{I_D}{I_G} = C_A \frac{\pi(r_A^2 - r_S^2)}{L_D^2} \quad (2)$$

代入 $r_A = 3.1$ nm、$r_S = 1$ nm、$C_A = (160 \pm 48)E_L^{-4}$，得到：

$$L_D^2 (\text{nm}^2) = (4.3 \pm 1.3)\times 10^3 \, E_L^4 \left(\frac{I_D}{I_G}\right)^{-1} \quad (3)$$

以波长表示：

$$L_D^2 (\text{nm}^2) = (1.8 \pm 0.5)\times 10^{-9} \lambda_L^4 \left(\frac{I_D}{I_G}\right)^{-1} \quad (4)$$

以缺陷密度 $n_D (\text{cm}^{-2}) = 10^{14}/(\pi L_D^2)$ 表示：

$$n_D (\text{cm}^{-2}) = (7.3 \pm 2.2)\times 10^9 \, E_L^4 \left(\frac{I_D}{I_G}\right) \quad (5)$$

$$n_D (\text{cm}^{-2}) = (1.8 \pm 0.5)\times 10^{22} \, \lambda_L^{-4} \left(\frac{I_D}{I_G}\right) \quad (6)$$

**图 4** 是这一推理的关键验证：把 $E_L^4 (I_D/I_G)$ 对 $L_D$ 作图，$L_D > 10$ nm 的、用不同激光能量测得的数据**塌缩到同一条曲线上** [page 4]。阴影区为 ±30% 实验误差给出的上下限。这一"数据塌缩"是式 3–6 成立的最直接证据——它表明 $E_L^4$ 的标度确实能把不同激发能量的测量归一化。

## 四、关键的一步与歧义的消除

整篇论文最关键的一步，是把"$I_D/I_G$ 随 $E_L$ 变化"这一现象**归因到单一参数 $C_A$**，并发现 $C_A \propto E_L^{-4}$。这一步之所以关键，是因为它把原本需要逐条激光线单独标定的问题，转化为一个可解析的标度关系：只要知道 $E_L$，就能把任意激光线下测得的 $I_D/I_G$ 换算成 $L_D$ 或 $n_D$。作者也坦承，$C_A$ 的物理来源尚未完全清楚——它此前被联系到 K 与 Γ 之间光学声子散射效率之比，而本文的数据提示它可能还涉及电子/空穴散射过程求和时的干涉效应 [page 4]。这是一个**作者明说的开放性**，不是已解决的结论。

另一个关键点是**歧义的消除**。由于 $I_D/I_G$ 在 $L_D \sim 3$ nm 处有极大值，同一个 $I_D/I_G$ 值对应两个可能的 $L_D$（一个在峰左侧、一个在峰右侧）[page 1]。作者用 G 峰宽度 $\Gamma_G$ 来区分：**图 5c** 显示 $\Gamma_G$ 在第二阶段开始前大致恒定在约 14 cm⁻¹（典型剥离石墨烯值），进入第二阶段后显著增大 [page 5]。因此，第一阶段和第二阶段可以有相同的 $I_D/I_G$，但 $\Gamma_G$ 不同——第二阶段大得多 [page 5]。**图 5b** 补充了另一条判据：G 峰色散 $\Delta\omega_G/\Delta E_L$ 在第二阶段开始前为零，之后变为约 6 cm⁻¹/eV [page 5]。**图 5a** 则显示 $\Gamma_D$ 和 $\Gamma_{2D}$ 在第一阶段内看不出对激发能量的依赖，而 D 和 2D 峰位置始终随激发能量色散，$\Delta\omega_D/\Delta E_L \sim 52$ cm⁻¹/eV，$\Delta\omega_{2D}/\Delta E_L = 2\Delta\omega_D/\Delta E_L$ [page 5]。

## 五、适用条件、边界与作者承认的局限

论文对结论的适用范围有明确限定，这些限定本身就是论证的一部分：

- **只适用于能激活 D 峰的缺陷。** 作者反复强调，按定义，该分析只对能在拉曼过程中激活 D 峰的缺陷有效 [page 2, page 5]。完美的锯齿型（zigzag）边缘不产生 D 峰 [ref 32, 33]，因此一组只有理想锯齿边缘的样品，其 D 峰会保持恒定（由其他缺陷决定）[page 2]。带电杂质、插层物、单轴/双轴应变同样不产生 D 峰 [page 4]。对这些"沉默"缺陷，需借助其他拉曼特征：完美锯齿边缘改变 G 峰形状，应变、插层物和带电杂质强烈影响 G 和 2D 峰 [page 4–5]。
- **$L_D \geq 10$ nm 且可见光范围。** 式 3–6 的适用条件是点缺陷间距 $L_D \geq 10$ nm、激发线在可见光范围 [page 4]。作者指出，$r_A$ 的不确定性不影响低缺陷密度区（$L_D > 10$ nm）的结果 [page 4]。
- **缺陷类型的推广是有限度的。** 作者认为，尽管公式基于离子轰击样品，但在大 $L_D$ 极限下，缺陷性质对 $I_D/I_G$ 影响应不强，因此可能适用于其他点缺陷（如共振散射体、替位原子）[page 4]。但这是**推测性推广**（"should be valid"），且作者同时指出，$A_D$ 一般不仅依赖缺陷浓度，还依赖缺陷类型——只有能在 K 与 K′ 两谷间散射电子的缺陷才能贡献 [page 3]。不同缺陷还可能产生不同的频率和偏振依赖 [page 3]。
- **$C_S = 0$ 的简化。** 这一选择意味着分析不聚焦 $L_D < r_S$ 的大缺陷密度区 [page 4]，即式 1 的完整形式在极端无序区并未被本文数据充分检验。
- **$C_A$ 的物理机制未定。** 如前所述，$C_A$ 与 $E_L^{-4}$ 的关系是经验拟合，其微观来源（散射效率比、干涉效应）仍是开放问题 [page 4]。

## 六、结论的成立条件

综合来看，论文的核心定量结论——式 3–6 可用于由 $I_D/I_G$ 反推 $L_D$ 或 $n_D$——在以下条件同时满足时成立：

1. 样品是石墨烯（单层），缺陷是**点状**且能激活 D 峰；
2. 缺陷间距 $L_D \geq 10$ nm（低缺陷密度区，式 2 的近似成立）；
3. 激发线在可见光范围，且 $C_A = (160 \pm 48)E_L^{-4}$ 的标度关系适用；
4. 测量在避免加热的功率下进行，且 $I_D/I_G$ 与峰宽被解耦处理（作者明确选择解耦 $I_D/I_G$ 与峰宽趋势，而非用面积比，因为大无序下解耦更有信息量）[page 2]。

在这些条件之外——尤其是当 $I_D/I_G$ 接近峰值、无法判断样品处于第一阶段还是第二阶段时——必须结合 $\Gamma_G$（以及 G 峰色散）才能给出无歧义的缺陷密度。这正是论文标题中"不同激发能量"的意义所在：激发能量的变化不仅被用来建立普适标度，也被用来提供区分两个无序阶段的额外维度。
