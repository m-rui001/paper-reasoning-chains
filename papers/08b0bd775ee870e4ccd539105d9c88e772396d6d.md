# 混合态纠缠与量子纠错：从纠缠提纯到量子信道的容量刻画

**原文题名**：Mixed State Entanglement and Quantum Error Correction（1996）
**作者**：Charles H. Bennett, David P. DiVincenzo, John A. Smolin, William K. Wootters
**DOI/编号**：arXiv:quant-ph/9604024v2

## 一、论文要解决的核心问题

这篇论文处理的是量子信息论中一个基础而困难的问题：当 Alice 和 Bob 共享的不是纯纠缠态，而是经过噪声污染后的**混合态**时，他们还能从中提取多少纯纠缠？这种提取能力与通过含噪量子信道可靠传输未知量子态的能力之间，又是什么关系？

论文的核心主张可以概括为三条相互支撑的结论：

1. **纠缠提纯协议（EPP）与量子纠错码（QECC）在单向通信情形下等价**：一个作用于混合态 $\hat{M}(\chi)$（由通过信道 $\chi$ 共享 EPR 对的一半得到）的单向 EPP，其产率 $D$ 恰好对应信道 $\chi$ 上一个速率 $Q = D$ 的 QECC，反之亦然 [page 1, page 8-10]。
2. **单向与双向通信能力有本质差别**：存在某些混合态（如 50% 去极化信道产生的 Werner 态 $W_{5/8}$），双向协议可以提纯出纠缠，而任何单向协议都提纯不出，即 $D_1(W_{5/8}) = 0 < D_2(W_{5/8})$ [page 10-11, page 41-43]。
3. **混合态纠缠需要多个不等价的度量**：作者引入 $D_1(M) \le D_2(M) \le E(M)$，其中 $E(M)$ 是"形成纠缠"（entanglement of formation），并给出 Bell 对角态下 $E(M)$ 的精确表达式 [page 7, page 15-21]。

下面我按论证的逻辑链条展开，说明作者如何从证据走到这些结论，以及这些结论在什么条件下成立。

## 二、形成纠缠 $E(M)$：定义、上界性质与精确解

### 2.1 为什么 $E(M)$ 是"形成"纠缠

作者把混合态 $M$ 的**形成纠缠** $E(M)$ 定义为：在所有能实现 $M$ 的纯态系综 $\{p_i, \Upsilon_i\}$ 中，纯态纠缠 $E(\Upsilon_i) = S(\mathrm{Tr}_A|\Upsilon_i\rangle\langle\Upsilon_i|)$ 的系综平均 $\sum_i p_i E(\Upsilon_i)$ 的最小值 [page 12]。

这个定义要配得上"形成"二字，必须证明两件事：Alice 和 Bob 若想通过局域操作制备 $M$，至少需要这么多纯单态；而若已有这么多，就足以制备 $M$。第二点由纯态纠缠的渐近可逆性直接给出；第一点则需要证明 $E(M)$ 在局域操作和经典通信下**不增**。

作者用两个引理加一个定理完成这一证明 [page 12-15]：

- **引理 1**（测量不增期望纠缠）：Alice 对纯态 $\Upsilon$ 做测量，得到结果 $k$ 的概率为 $p_k$，残余纯态为 $\Upsilon_k$，则 $\sum_k p_k E(\Upsilon_k) \le E(\Upsilon)$（式 6）。证明的关键是：局域测量不改变 Bob 端的约化密度矩阵 $\rho$，而冯·诺依曼熵的凸性给出 $S(\rho) \ge \sum_k p_k S(\rho_k)$（式 7）。
- **引理 2**（丢弃子系统不增纠缠）：若三体纯态 $\Upsilon$ 分属 A、B、C，Alice 持有 AC，Bob 持有 B，令 $M = \mathrm{Tr}_C|\Upsilon\rangle\langle\Upsilon|$，则 $E(M) \le E(\Upsilon)$。
- **定理**（式 8）：对混合态 $M$ 做 Alice 的局域操作，得到结果 $k$ 的残余混合态 $M_k$，则 $\sum_k p_k E(M_k) \le E(M)$。证明把引理应用到最小纠缠系综的每个纯态上，再用 Bayes 定理（式 14）和 $E(M_k) \le \sum_j p_{j|k} E(M_{jk})$ 完成。

由于任何有限步的局域操作加经典通信都可分解为这类操作的序列，定理意味着 $E(M)$ 在局域操作和经典通信下不增。作者特别指出：**纠缠本身可以在局域操作下增加，但其期望值不能**——Alice 和 Bob 可以"赌"纠缠，冒损失一部分的风险去博取更多 [page 15]。

### 2.2 Bell 对角态的精确解与一般下界

对一般的混合态，找到最小纠缠系综是困难的。作者对**在 Bell 基下对角的混合态**给出了精确解，并对任意两量子比特态给出下界 [page 15-21]。

关键量是**完全纠缠分数** $f(M) = \max\langle e|M|e\rangle$，其中最大值取遍所有完全纠缠态 $|e\rangle$（式 19）。作者证明：

$$E(M) \ge h[f(M)], \quad h(f) = \begin{cases} H\left(\frac{1}{2} + \sqrt{f(1-f)}\right) & f \ge \frac{1}{2} \\ 0 & f < \frac{1}{2} \end{cases} \tag{20, 28}$$

推导路径是：先把任意纯态 $|\varphi\rangle = \sum_j \alpha_j|e_j\rangle$ 的纠缠写成 $E = H[\frac{1}{2}(1 + \sqrt{1-C^2})]$，其中 $C = |\sum_j \alpha_j^2|$（式 23）；由此得到 $E(|\varphi\rangle) \ge h(|\alpha_1|^2)$（式 24），再推广到任意完全纠缠态 $|e\rangle$ 上的分量 $w = |\langle e|\varphi\rangle|^2$（式 25）；最后对系综取平均，利用 $h$ 的凸性得到式 28。

对 Bell 对角态 $W = \sum_{j=1}^4 p_j|e_j\rangle\langle e_j|$，作者证明下界**取等**：若某个 $p_j \ge 1/2$，则用八个等概率纯态（式 30）实现 $W$，每个纯态纠缠都是 $h(p_1)$，故 $E(W) = h[f(W)]$；若所有 $p_j < 1/2$，则存在相位 $\theta_i$ 使 $\sum_j p_j e^{i\theta_j} = 0$，此时 $W$ 可写成八个零纠缠纯态的等权混合（式 32），故 $E(W) = 0$ [page 19-20]。

**一个重要的负面结果**：作者明确证明 $E(M) = h[f(M)]$ 对一般混合态**不成立**。反例是 $M = \frac{1}{2}|{\uparrow\uparrow}\rangle\langle{\uparrow\uparrow}| + \frac{1}{2}|\Psi^+\rangle\langle\Psi^+|$（式 33），其 $f = 1/2$ 故 $h(f) = 0$，但作者通过分析式 37 的约束条件证明它无法由无纠缠纯态混合而成，故 $E(M) > 0$ [page 20-21]。这一反例说明下界只是下界，不是精确公式。

## 三、提纯协议：从 Werner 态到一般混合态

### 3.1 预处理与基本工具

所有提纯协议都建立在几个简化步骤上 [page 22-26]：

- **Twirl（旋转平均）**：对每对粒子施加相同的随机 SU(2) 旋转，可把任意两量子比特混合态 $M$ 变成 Werner 态 $W_F$（式 17）或 Bell 对角态 $W$。附录 A 证明只需从 12 个离散双边旋转中均匀随机选取即可（式 100），甚至对已是 Bell 对角的态只需 3 个元素（式 103）[page 72-75]。
- **Bell 态映射**：单边 $\pi$ 旋转（$\sigma_{x,y,z}$）、双边 $\pi/2$ 旋转（$B_{x,y,z}$）和双边 XOR（BXOR）可以把 Bell 态互相映射（Table 1, page 24）。
- **两位标记**：$\Phi^+ = 00$，$\Psi^+ = 01$，$\Phi^- = 10$，$\Psi^- = 11$（式 40），其中低位是"振幅"位（$\Phi/\Psi$），高位是"相位"位（$+/-$）。局域测量一次只能区分其中一个属性，另一个被随机化。

### 3.2 递推法（recurrence method）

这是双向协议 [page 28-33]。从 Bell 对角系综中取两对，分别作 source 和 target 做 BXOR，然后测量 target 并保留 source 中 target 通过测试的那些。Table 2（page 27）列出所有初始构型和 BXOR 后的结果。通过测试的子集的 a posteriori 概率由式 42-43 给出。对 Werner 态，通过子集的 $p'_{00} > p_{00}$（当 $p_{00} > 0.5$），失败子集变成完全混合态（$p_{00} = p_{01} = p_{10} = p_{11} = 1/4$），纠缠为零，直接丢弃。迭代可把保真度推向 1（Fig. 7, page 30）。

**关键限制**：递推法在每次迭代至少损失一半粒子，趋近零产率。作者指出，当保真度足够高时切换到 hashing 法，可得到正产率。组合的 recurrence-hashing 方法对所有 $F > 1/2$ 的 Werner 态给出正产率（Fig. 8, page 31）。

### 3.3 单向 hashing 法

这是论文的核心协议之一 [page 34-38]。给定 $n$ 个来自已知 Bell 对角系综 $W$ 的混合对，hashing 法可提纯出约 $m \approx n(1 - S(W))$ 个近完美 $\Phi^+$ 态，其中 $S(W)$ 是混合对的冯·诺依曼熵。

协议的逻辑是：把 $n$ 个 Bell 态编码为 $2n$ 比特串 $x_0$。由于独立同分布，几乎所有概率集中在约 $2^{nS(W)}$ 个"可能"串上。每轮 Alice 随机选一个子集 $s_k$，双方通过局域操作和测量一对，把子集奇偶 $s_k \cdot x_k$ 收集到某一对的振幅位上，同时把未测量对的状态更新为 $x_{k+1} = f_{s_k}(x_k)$。关键事实是：对任意两个不同串 $x \ne y$，随机子集给出相同奇偶的概率恰为 $1/2$（由分配律 $(s\cdot x) \oplus (s\cdot y) = s\cdot(x\oplus y)$ 保证）。因此经过 $n - m$ 轮后，可能候选从 $2^{n(S(W)+\delta)}$ 降到 1 的概率趋于 1，失败概率上界为 $2^{n(S(W)+\delta) - (n-m)} + O(\exp(-\delta^2 n))$。取 $n - m = n(S(M) + 2\delta)$，$\delta \approx n^{-1/4}$，即得产率 $m/n \to 1 - S(M)$。

对 Werner 态，$S(W_F) = -F\log_2 F - (1-F)\log_2((1-F)/3)$（式 47），故 $F > 0.8107$ 时产率为正。Fig. 8 和 Fig. 9（page 31-32）把 $D_H$ 与 $E$、递推法产率、Calderbank-Shor-Steane 码速率以及 $D_1$ 上界对比。

### 3.4 非 Bell 对角态的直接提纯

作者给出一个简单例子说明 twirl 并非必需 [page 33]。对 $M = (1-p)|{\uparrow\uparrow}\rangle\langle{\uparrow\uparrow}| + p|\Psi^+\rangle\langle\Psi^+|$（式 45），用 BXOR 加双边测量，若 target 结果为"down-down"则 source 留在 $\Psi^+$，产率 $D_2 = p^2/4$。作者引用 Horodecki 等人的结果：对任意两量子比特态，只要 $E(M) \ne 0$，就有 $D_2(M) \ne 0$ [page 34]。

## 四、单向与双向的本质差别：no-cloning 论证

这是论文最精彩的论证之一 [page 41-43]。作者构造一个对称场景（Fig. 12, page 41）：Alice 有 $n$ 个单态，一半与 Bob 共享，一半与 Charlie 共享，但她不知道哪些是哪些。Bob 和 Charlie 各自还有足够的"垃圾"粒子使每人也有 $n$ 个粒子。从 Alice 和 Bob 的角度看，每个态的密度矩阵都是 $W_{5/8}$。

论证的关键一步：Alice 在未收到 Bob 或 Charlie 任何信息前，她看到的每个粒子都是完全混合态。由对称性，任何能让她确认某粒子是与 Bob 共享的好 EPR 对一半的操作，也会让她确认同一粒子是与 Charlie 共享的好 EPR 对一半。但这样的"三边 EPR 对"不存在——若她用其向 Bob 传送量子比特，也会同时传给 Charlie，违反**不可克隆定理**。因此她无法从任意多 $W_{5/8}$ 中提纯出哪怕一个 EPR 对。

结合双向协议的正下界，得到：

$$D_1(W_{5/8}) = 0 < 0.00457 \le D_2(W_{5/8}) \tag{48}$$

作者进一步指出，任何 Werner 系综都可通过与完全混合态组合降低保真度，故 $D_1(W_F) = 0$ 对所有 $F < 5/8$。Knill 和 Laflamme 证明 $D_1(W_F) = 0$ 对所有 $F < 3/4$ [page 42]。作者用信道可加性（Sec. 5.2）把这一结果扩展为线性上界 $D_1 < 4f - 3$（式 49）。

**这一结论的物理含义**：50% 去极化信道（经典容量为正）在单向使用下，即使借助量子纠错码，量子容量也为零；但双向使用或借助双向经典通信，则有正容量 [page 10-11, page 43]。

## 五、信道与混合态的对应：$Q = D_1$ 的证明

### 5.1 两个映射

作者建立信道 $\chi$ 与混合态 $M$ 之间的双向映射 [page 44-46]：

- $\hat{M}(\chi)$：制备标准最大纠缠态 $\Upsilon = N^{-1/2}\sum_i |e_j\rangle \otimes |e_j\rangle$（式 51），把 Bob 的一半通过 $\chi$ 传输。
- $\hat{\chi}(M)$：用混合态 $M$ 代替标准最大纠缠态做量子隐形传态。

对 Bell 对角混合态，两个映射互逆，对应信道称为"广义去极化信道"。对一般信道和混合态，映射不互逆（例如 $M = |{\uparrow\uparrow}\rangle\langle{\uparrow\uparrow}|$ 对应 $p=1$ 去极化信道，但反向映射给出 $G$）。

### 5.2 两个不等式与等式

作者证明两个一般不等式 [page 45-51]：

$$\forall M \quad D_1(M) \ge Q(\hat{\chi}(M)) \tag{52}$$
$$\forall \chi \quad D_1(\hat{M}(\chi)) \le Q(\chi) \tag{53}$$

式 52 的证明（Fig. 14, page 49）：用混合态 $M$ 做隐形传态定义信道 $\hat{\chi}(M)$；若 QECC $\{U_e, U_d\}$ 能纠正该信道的错误，则整个流程就是一个 1-EPP，从 $n$ 个 $M$ 制备 $m$ 个好 EPR 对，故 $D_1(M) \ge Q(\hat{\chi}(M))$。

式 53 的证明（Fig. 15, page 50）：给定信道 $\chi$，Alice 通过 $\chi$ 传输 $\Phi^+$ 的一半得到 $\hat{M}(\chi)$；双方执行 1-EPP 得到好 EPR 对，再用其隐形传态 $|\xi\rangle$。这构成一个带单向经典边信道的 QECC，容量为 $D_1(\hat{M}(\chi))$。但 Sec. 5.1 已证明单向经典边信道不增加量子容量（$Q_1 = Q$，式 50），故 $Q(\chi) \ge D_1(\hat{M}(\chi))$。

当映射可逆时，两个不等式同时成立，给出等式 $D_1(M) = Q(\chi)$（式 54）。双向情形类似：$D_2(M) = Q_2(\chi)$（式 57）。

### 5.3 单向经典边信道不增加量子容量

$Q_1 = Q$（式 50）的证明 [page 46-47] 是构造性的：任何带单向经典边信道的协议（Fig. 13, page 44）都可转化为无经典通信的协议。设解码在 $r=0$ 时成功，则 $U_d^{-1}(r=0)(|\xi\rangle \otimes |0\rangle) = |\eta_{0i}\rangle \otimes |0\rangle$（式 59），存在 $U_s$ 把 $|\eta_{0i}\rangle$ 转回无噪声编码向量 $|\zeta_0\rangle$（式 60），故 $U_s U_d^{-1}(r=0)$ 就是好编码器，无需发送 $r$。作者还证明：若 $i=0$（无错误）被高保真解码，则编码器可取为解码器的逆，$U_e = U_d^{-1}$ [page 47]。

### 5.4 信道容量的可加性

作者证明完美信道与不完美信道的容量可加 [page 48]：若容量 $Q$ 的信道用 $n$ 次、容量 1 的完美信道用 $m$ 次，总传输量 $T$ 不能超过 $Qn + m$。否则用不完美信道模拟完美信道，会得到 $Q' > Q$ 的矛盾（式 61-62）。

## 六、有限块量子纠错码：5 比特码

### 6.1 从 1-EPP 到 QECC 的简化推导

作者给出另一种推导 [page 52-55]：对单边噪声（或可化为单边），利用测量与制备的对称性。关键观察是式 65-66：对 A 粒子施加的酉变换 $U_1$ 等价于对 B 粒子施加 $U_1^T$。因此 Alice 的任务可简化为：对 $n-m$ 个 A 粒子做单粒子测量、对 $m$ 个粒子做 Bell 测量、对 B 粒子施加 $U_1^T$。进一步，单粒子测量可被消除（用 $\Phi^+$ 的关联性质），Bell 测量也可被消除（预先约定结果为 00），最终得到 Fig. 16（page 55）的 in-place QECC。

### 6.2 有限块提纯的数学形式

对有限块，噪声被建模为"承诺"：错误数不超过 $t$。可能的错误 syndrome 数为 $S = \sum_{p=0}^t 3^p \binom{n}{p}$（式 67），其中"3"对应相位错误、振幅错误、两者兼有 [page 56]。

提纯问题被转化为纯经典问题：找线性可逆布尔函数 $L_u$（式 68-69），使得对任意两个不同 syndrome $i \ne j$，若 $w'^{(i)} \ne w'^{(j)}$ 则 $v^{(i)} \ne v^{(j)}$（式 74）。这比"学习所有错误"的更强条件（式 75）更弱，后者导致块大小限制 $S \le 2^{n-m}$（式 76）。

### 6.3 Monte Carlo 搜索与 5 比特码

作者对 $t=1, m=1$ 做 Monte Carlo 搜索 [page 60-64]。$n=2$ 不可能；$n=3,4$ 未找到解；$n=5$ 找到多个解。Table 3（page 62）列出所有 16 个初始 Bell 态和最终态，Fig. 18（page 63）给出量子门阵列，式 77-78 给出对应的线性变换矩阵 $M_u$ 和向量 $b$。这个码不仅满足式 74，还满足更强的式 75。

### 6.4 纠错条件的直接表述

作者用 QECC 语言重新表述纠错条件 [page 64-67]。设编码为 $|\xi\rangle = \alpha|v_0\rangle + \beta|v_1\rangle$（式 79），噪声为 $|\xi\rangle \to \{R_i|\xi\rangle\}$（式 82）。成功纠错的充要条件是（式 89-90）：

$$\langle v_0|R_i^\dagger R_j|v_0\rangle = \langle v_1|R_i^\dagger R_j|v_1\rangle, \quad \langle v_1|R_i^\dagger R_j|v_0\rangle = 0$$

对 5 比特码，$|v_0\rangle$ 是所有偶宇称 ket 的特定符号叠加（式 91），$|v_1\rangle$ 是 0/1 互换的对应向量（式 92）。

### 6.5 纠错条件对信道容量的限制

Knill 和 Laflamme 用式 89-90 证明 $F = 0.75$ 时 $D_1 = 0$ [page 67-69]。证明思路：把编码基写成 $|v_i\rangle = \sum_{y:z} \alpha^i_{y:z}|y:z\rangle$（式 93），定义约化密度矩阵 $\rho^i_{n-2t}$ 和 $\rho^i_{2t}$（式 94-95），证明 $\rho^0_{n-2t}\rho^1_{n-2t} = 0$（式 96）和 $\rho^0_{2t} = \rho^1_{2t}$（式 97）。当 $2t = n - 2t$（即 $F = 0.75$）时两式矛盾。结合信道可加性，得到线性上界 $Q = D_1 \le 4F - 3$（式 98）。

## 七、结论的适用条件与边界

论文的结论在以下条件下成立，作者也明确承认了若干局限：

**成立条件**：
- 纠缠提纯和 QECC 的等价性（$Q = D_1$）对 Bell 对角混合态及其对应的广义去极化信道严格成立（映射可逆时）[page 45-46]。
- $D_1(W_{5/8}) = 0$ 的 no-cloning 论证依赖于 Alice 在收到任何经典信息前无法区分粒子归属的对称性 [page 41-42]。
- 5 比特码的 Monte Carlo 搜索是启发式的，作者承认"没有证明式 74 能导致比式 75 更强的纠错方案"，但 Shor 和 Smolin 已展示渐近超越式 76 的协议族 [page 60]。

**作者承认的局限**：
- 对一般混合态，$E(M)$ 的精确值未知，$h[f(M)]$ 只是下界（式 33 的反例）[page 20-21]。
- $D_1$ 和 $D_2$ 对一般混合态没有显式值，只有上下界 [page 7]。
- 没有提纯协议被证明最优 [page 28]。
- 对双向协议，作者"没有洞察如何把上界降到 $E$ 以下" [page 71]。
- 对抗性噪声模型（量子密码场景）下能否成功提纯尚不清楚 [page 70]。
- 两个平行量子信道的经典容量能否通过纠缠输入增加，仍是开放问题 [page 71]。

**分析者补充的推断**（非原文结论）：论文的 $Q = D_1$ 等式依赖于信道-混合态映射的可逆性，对非 Bell 对角的一般信道，式 52-53 只给出不等式，等式是否成立需要额外条件。此外，no-cloning 论证虽然有力，但它针对的是 $W_{5/8}$ 这一特定态；对 $5/8 < F < 3/4$ 的 Werner 态，$D_1 = 0$ 由 Knill-Laflamme 的更强结果覆盖，但论文本身只对 $F < 5/8$ 给出直接论证。

## 八、论证的整体逻辑

这篇论文的论证结构可以概括为一条主线加两条支线：

**主线**：定义 $E(M)$ 为形成纠缠 → 证明 $E(M)$ 在局域操作下不增（Sec. 2.1）→ 对 Bell 对角态求精确解（Sec. 2.2）→ 建立 EPP 与 QECC 的等价（Sec. 5-6）→ 用 no-cloning 论证证明 $D_1 \ne D_2$（Sec. 4）→ 得到 $Q = D_1$ 和 $Q_2 = D_2$（Sec. 5）。

**支线一**：hashing 协议给出 $D_H = 1 - S(W)$ 的显式下界（Sec. 3.2.3），并与递推法组合得到对所有 $F > 1/2$ 的正产率。

**支线二**：5 比特码作为有限块纠错的具体构造（Sec. 6.2-6.4），以及 Knill-Laflamme 的 $F = 0.75$ 上界（Sec. 6.5）。

论文最重要的概念贡献是：**混合态纠缠不能用单一参数刻画**。纯态下 $E$ 既是形成纠缠又是可提纯纠缠，但混合态下 $D_1 \le D_2 \le E$，且 $D_1$ 和 $D_2$ 可以严格不等。这一发现把量子信息论从纯态的理想世界推向混合态的现实世界，也为量子纠错码的容量分析提供了统一框架。
