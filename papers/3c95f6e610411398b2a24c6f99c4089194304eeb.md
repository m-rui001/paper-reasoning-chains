# 用E值量化观察性研究对未测混杂的稳健性：一篇方法学论证的解读

原文题名：Sensitivity Analysis in Observational Research: Introducing the E-Value（2017，DOI: 10.7326/M16-2607）。作者 Tyler J. VanderWeele 与 Peng Ding 提出的核心主张是：在旨在推断因果的观察性研究中，应当常规报告一个名为“E值”（E-value）的敏感性分析指标，用以刻画一个未测混杂因素需要多强，才能把已观测到的处理—结局关联完全解释掉。本文围绕这一主张，梳理其证据、关键推理步骤与成立条件。

## 问题设定与E值的定义

论证的起点是一个老问题：观察性数据中的关联不等于因果，核心威胁是未测或未控制的混杂——某个同时与处理和结局相关的第三因素可能制造出虚假关联 [page 1]。敏感性分析的思路是反过来问：未测混杂要多强，才能“解释掉”这个关联？作者指出，传统敏感性分析常被批评为主观（研究者可挑选让结果显得稳健的参数），且往往预设未测混杂是二值的、只有一个、或与处理无交互等简化假设 [page 2]。本文所依托的技术（引文37）声称不需要对未测混杂的底层结构作这类假设，只要求两个参数。

这两个参数是：`RRUD`，即在处理组内、调整已测协变量后，未测混杂任意两类之间结局风险比的最大值，刻画混杂对结局的重要性；`RREU`，即调整已测协变量后，比较有无处理时未测混杂某一水平上的风险比最大值，刻画处理组在混杂上的失衡程度 [page 2]。图1给出这一结构：未测混杂同时指向处理与结局，已测协变量可影响未测混杂，反之亦然 [page 3]。给定这两个参数，观测风险比可能被改变的最大倍数（偏倚因子）为

`B = RRUD × RREU / (RRUD + RREU − 1)`。

把观测风险比（及其置信限）除以 `B`，就得到混杂能把估计推向无效的方向上的极限；当观测风险比小于1时改为乘以 `B` [page 2]。

E值则是对这一框架的进一步简化：它不再让研究者自选 `RRUD` 和 `RREU`，而是令两者相等，求出能把关联恰好解释掉所需的最小共同强度。对风险比 `RR`（大于1）有

`E-value = RR + sqrt{RR × (RR − 1)}`。

其几何含义见图2：E值对应曲线上 `RRUD = RREU` 的那一点 [page 3]。作者强调，E值是一个连续指标，最低为1（无需任何未测混杂即可解释掉关联），越高说明需要越强的混杂关联才能解释掉效应 [page 4]。

## 证据如何支撑结论：从公式到实例

论证的经验支撑主要来自把公式套用到若干真实关联上，并比较其E值大小。

呼吸系统死亡例子中，Victora 等报告配方奶喂养婴儿死于呼吸道感染的风险是纯母乳喂养的 `RR = 3.9`（95% CI, 1.8–8.7），已调整年龄、出生体重、社会地位、母亲教育、家庭收入，但未调整吸烟 [page 1]。作者先演示参数化敏感性分析：设 `RRUD = 4`、`RREU = 2`，则 `B = 4×2/(4+2−1) = 1.6`，把估计和CI除以1.6得 `RR = 2.43`（CI, 1.1–5.4），即这一强度的混杂不足以解释掉效应 [page 3]。随后计算E值：`E = 3.9 + sqrt{3.9×2.9} = 7.26`，对应结论是“观测到的3.9可被一个与处理和结局各关联约7.2倍的未测混杂解释掉，更弱的混杂则不能” [page 3–4]。对CI下限1.8，E值为3.0，即需要各约3.0倍的混杂才能把置信区间推到包含无效值 [page 4]。

对照例子强化了E值的判别力。儿童白血病：`RR = 0.80`（CI, 0.71–0.91），P < 0.001，但取倒数后E值仅1.8，CI对应E值1.4，作者判断“各1.4倍的混杂关联并不显得不可信”，故因果证据较弱 [page 5]。卵巢癌：哺乳6–12个月者患病比值 `OR = 0.5`（CI, 0.3–0.8），E值3.4，CI对应1.8，属中等稳健 [page 5]。作者特别指出一个反直觉对照：儿童白血病的P值更极端，但其E值反而小于卵巢癌；这说明P值与E值衡量的是不同概念，且P值更依赖样本量，二者可以背离，理应同时报告 [page 5–6]。

## 关键推理步骤

从证据到“应常规报告E值”的结论，关键一步是把“未测混杂需多强才能解释掉关联”重新表述为一个可计算、且不依赖研究者主观选参的量。这一步的桥接在于：既然 `RRUD` 与 `RREU` 中一个变小、另一个就必须变大（图2），那么令二者相等所得到的E值，就是任何能解释掉关联的混杂组合的下界——它给出的是“最小必要强度”，而非某个被选定的情景 [page 4]。正因如此，E值把原本主观的“选参数”问题转化为一个客观报告值，读者再自行判断这种强度的混杂是否可信。作者据此把E值与 Bradford Hill 的“关联强度”准则联系起来：敏感性分析从数量上说明了为何关联强度对因果推断重要 [page 4]。

## 成立条件、边界与作者承认的局限

E值的解释高度依赖语境，尤其是已调整的协变量集合。作者举例：两项研究E值同为2.5，但一项控制了教育、收入、职业、房产、财富等多个社会经济指标，另一项只控制了一个大学教育的二值变量，则前者更稳健，因为其未测混杂必须“绕过”更多已测路径 [page 5]。这是E值相对性的直接体现。

作者明确列出若干限制。其一，E值只说明“存在能解释掉效应的情景是可能的”，并不保证某个特定强度的混杂一定解释得掉；罕见混杂的偏倚更小 [page 5]。其二，E值不涉及测量误差、选择偏倚、缺失数据或选择性报告，这些也是观察性研究的偏倚来源 [page 5–6]。其三，E值不能用来确证“无关联”：小E值只意味着支持效应的证据弱，而“无证据”不等于“无效应” [page 6]。其四，作者明确不设E值阈值，认为0.05的P值截断已造成足够危害，发表决策不应仅凭P值或E值的大小 [page 6]。其五，大样本可得到极小的P值，但若效应量小，E值仍会很小；E值不能靠增大样本量任意抬高，CI对应的E值虽依赖样本量，但受关联强度上界约束（即“设计灵敏度”）[page 5]。

在方法适用性上，表1给出风险比的E值计算规则（含RR<1时先取倒数、CI含1时E值为1等）[page 4]；表2把公式推广到其他效应量，但都带近似或附加假设：罕见结局（如<15%）的OR或HR可直接套用风险比公式；常见结局的OR用 `RR ≈ sqrt(OR)`；常见结局的HR用 `RR ≈ (1 − 0.5sqrt(HR))/(1 − 0.5sqrt(1/HR))`；连续结局用标准化效应量 `d` 与 `RR ≈ exp(0.91 × d)`；风险差则用 `p1/p0` 替代风险比，其CI计算更复杂并需软件 [page 4]。作者提示这些推广“依赖额外假设与近似”，且不一定都有对应的E值 [page 4]。需要说明的是，表2中部分公式在提取文本里以近似符号和排版形式出现，个别符号（如HR近似式）的精确形式应以原文为准，此处仅作对照。

## 结论的适用范围

综合来看，E值主张的成立条件可归纳为：研究以风险比（或可合理近似为风险比的效应量）为尺度、目标是因果推断而非纯描述或预测、且已对一组已测协变量作了调整。在这些条件下，E值给出未测混杂解释掉关联所需的最小共同强度，其数值越大，因果证据相对越稳健。作者的建议是报告估计值与最接近无效值的置信限两个E值，并把它作为P值的补充而非替代 [page 6]。超出这些条件——例如存在严重测量误差、选择偏倚，或结局过于常见而近似失效——E值的解释力就相应减弱，这属于作者已承认或由文本可合理推出的边界，而非其结论的延伸。
