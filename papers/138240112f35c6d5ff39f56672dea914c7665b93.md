# 非参数判别的一致性：Fix 与 Hodges 的论证结构

**原文题名**：Discriminatory Analysis. Nonparametric Discrimination: Consistency Properties
**作者**：Evelyn Fix、J. L. Hodges, Jr.（1951 年报告，1989 年由 Silverman 与 Jones 整理重刊）
**DOI/来源**：*International Statistical Review*, Vol. 57, No. 3 (1989), pp. 238–247

---

## 一、问题设定与核心主张

论文处理的是两总体判别问题：观测值 $Z$（取值 $z$，位于 $p$ 维空间）来自分布 $F$ 或 $G$ 之一，需要据此判断它属于哪一个。作者按对 $F$、$G$ 已知程度把问题分为三类：完全已知、已知到参数、完全未知 [page 3]。前两类已有成熟处理——第一类由 Neyman–Pearson 引理给出最优的似然比程序 $L(c)$，第二类则先估计参数再套用似然比（Fisher 线性判别函数即其典型）。作者真正要攻的是第三类：**在完全不知道分布参数形式的前提下，能否构造出合理的判别程序？**

核心主张是：可以。作者提出一类非参数程序，并证明当两个样本量 $m,n$ 同时趋于无穷时，这些程序与已知密度下的最优程序 $L(c)$ 在分类结果上趋于一致。这就是标题中的"一致性"（consistency）——注意它并非参数估计意义上的相合性，而是**判别程序之间的一致性**。

## 二、把"好结果"精确化：三种一致性定义

作者没有直接说"程序好用"，而是先给出可证明的判据。关键一步是把"非参数程序不劣于最优程序"这一直觉固定下来：当 $f,g$ 已知时，$Z$ 关于 $(Z;X_1,\dots,X_m;Y_1,\dots,Y_n)$ 是充分的，因此任何基于样本的程序都无法在错误概率上优于似然比程序 [page 5]。这为"一致性"提供了比较基准——非参数程序的目标不是超越 $L(c)$，而是在极限下追平它。

作者区分了两种一致性 [page 5]：

- **定义 1（性能特征一致）**：两列决策函数的各类决策概率在极限下接近；
- **定义 2（决策函数一致）**：两列决策函数在极限下以高概率给出相同决策。

定义 2 强于定义 1（作者给出证明：$P(A'=A'')$ 不小于各 $P(A'=\delta_i)-P(A''=\delta_i)$），但二者不等价——作者用"两列都靠抛硬币决策"的例子说明：决策完全一致，但决策概率可以完全不同。作者选择采用更强的定义 2，因为本文所有证明都能达到这一强度 [page 5]。

随后是**定义 3**：序列 $\{A_{m,n}\}$ 与 $L(c)$ 一致，指对任意 $F,G$、任意 $Z$ 的来源、任意 $\varepsilon>0$，只要 $m,n$ 足够大，就有 $P\{A_{m,n}\text{ 与 }L(c)\text{ 对 }Z\text{ 分类相同}\}>1-\varepsilon$ [page 6]。若这个界可以对所有 $F,G$ 用同一组 $m,n$ 保证，则称**一致一致**（uniformly consistent）。

一个技术性但重要的约定：作者假设 $m/n$ 与 $n/m$ 都有界远离 0，即两样本以相同速度增长 [page 6]。这把双重极限化为单一极限，也是后文 §5 避免困难的前提。

## 三、参数情形作为铺垫：定理 1

在进入非参数之前，作者先证明参数情形下"估计参数再套用似然比"是合理的（定理 1，[page 6]）。条件是：(a) 估计量 $\{\hat\theta_{m,n}\}$ 相合；(b) 对每个 $\theta$，$f_\theta(z)$、$g_\theta(z)$ 作为 $\theta$ 的函数在 $z\notin Z_\theta$ 处连续，其中 $P_i(Z_\theta)=0$。

证明思路是典型的"夹逼"：$\hat\theta$ 大概率接近真值 $\theta$，由连续性 $f_{\hat\theta}$ 接近 $f_\theta$、$cg_{\hat\theta}$ 接近 $cg_\theta$，因此比较 $(f_\theta,cg_\theta)$ 与比较 $(f_{\hat\theta},cg_{\hat\theta})$ 大概率给出相同结论 [page 6–7]。作者特别在 Remark 1 指出，允许不连续集 $Z_\theta$ 依赖于 $\theta$ 是重要的，若要求固定不连续集会排除许多本可包含的情形 [page 7]。

这一步的作用是**建立类比**：非参数情形可以照搬同一逻辑，只是把"估计参数"换成"直接估计密度值"。

## 四、非参数程序与定理 2

非参数情形下没有 $\theta$ 可估，但 $L(c)$ 实际只需要两个数 $f(z)$ 和 $g(z)$ [page 7]。于是作者直接估计这两个密度值，记所得程序为 $L^*(c,\hat f,\hat g)$。

**定理 2**（[page 7]）：若 $\hat f_{m,n}(z)$、$\hat g_{m,n}(z)$ 是 $f(z)$、$g(z)$ 的相合估计（除零测集 $Z_{f,g}$ 外），则 $\{L^*_{m,n}(c,\hat f,\hat g)\}$ 与 $L(c)$ 一致。证明与定理 1 同路，从略。

问题于是归结为：**如何构造密度的相合估计？**

## 五、关键构造：引理 3

作者的估计思想很直观 [page 7–8]：取 $z$ 的一个小邻域 $A_m$，用落入其中的样本比例估计该邻域的概率，再除以邻域测度，得到 $f$ 在 $z$ 附近的平均值；若 $f$ 在 $z$ 连续，且邻域随 $m\to\infty$ 收缩到 $z$，这个平均值就趋于 $f(z)$。但邻域不能收缩太快，否则落入的样本数期望不足，比例不再是概率的相合估计。

**引理 3**（[page 8]）：若 $f$ 在 $z$ 连续，$\{A_m\}$ 满足 $\limsup_{m\to\infty}\sup_{d\in A_m}|z-d|=0$ 且 $\lim_{m\to\infty}m\mu(A_m)=\infty$（$\mu$ 为 Lebesgue 测度），$M$ 为落入 $A_m$ 的 $X$ 个数，则 $M/\{m\mu(A_m)\}$ 是 $f(z)$ 的相合估计。

证明分两种情形：$f(z)>0$ 时，$mP(A_m)\to\infty$，由大数律 $M/\{mP(A_m)\}\to 1$（依概率），结合 $P(A_m)/\mu(A_m)\to f(z)$ 得结论；$f(z)=0$ 时用 Markov 不等式 [page 8]。两个条件缺一不可：邻域收缩保证平均逼近点值，测度与样本量之积发散保证比例稳定。

结合定理 2，这就给出了非参数判别的一致性：**只要 $F,G$ 的密度连续（至多除零测集外），程序 $L^*(c, M/\{m\mu(A_m)\}, N/\{n\mu(A_m)\})$ 就与 $L(c)$ 一致** [page 8]。

## 六、从理论到实践：§5 的动机与定理 4

作者明确承认，引理 3 的估计"在证明一致性时自然，但在实践中未必可取" [page 8]。实际困难在于邻域 $\{A_m\}$ 的选择：太小则落入样本太少、比例不准；太大则概率不能近似 $f(z)\mu(A_m)$——"处于双重危险之间，须走中间路线" [page 9]。

作者提出一个更实用的替代方案：不预先固定邻域，而是**固定近邻点数 $k$**，取包含两样本合计 $k$ 个最近点的区域，设其中 $M$ 个来自 $X$、$N=k-M$ 个来自 $Y$，用 $M/m$ 和 $N/n$ 代替 $f(z)$、$g(z)$ [page 9, 11]。但这改变了概率结构：$M+N=k$ 使两个估计不再独立，邻域变成随机的。作者追问：这样得到的估计还相合吗？

为回答这个问题，作者先做一步**降维变换** [page 9]：取非负函数 $\rho(x,y)$，满足 $x_n\to x$ 时 $\rho(x_n,x)\to 0$，且对几乎每个 $z$，$\rho(X,z)$、$\rho(Y,z)$ 有连续密度 $f_z$、$g_z$ 且在 0 处不全为 0（例如 $\rho(x,y)=|x-y|^p$ 即满足）。于是问题化为：判断 $f_z(0)$ 与 $cg_z(0)$ 谁大，样本变为 $\rho(X_i,z)$、$\rho(Y_j,z)$。这样可"不失一般性"假设 $f,g$ 是非负一元随机变量的密度，且 $z=0$。

**定理 4**（[page 9–11]）：设 $X,Y$ 非负，$f,g$ 在 0 处正且连续。$k(m,n)$ 为正整数函数，满足 $k\to\infty$、$m^{-1}k\to 0$、$n^{-1}k\to 0$（在 $m/n$ 有界远离 0 和 $\infty$ 的约束下）。定义 $U$ 为合并样本的第 $k$ 小值，$M$ 为小于 $U$ 的 $X$ 个数，$N$ 为小于 $U$ 的 $Y$ 个数。则 $M/(mU)$ 是 $f(0)$ 的相合估计，$N/(nU)$ 是 $g(0)$ 的相合估计。

证明的核心是构造两个辅助阈值 $v(m,n)$、$w(m,n)$，分别对应 $k_1,k_2$ 个期望落入的样本，其中 $k_1+k_2=k$ 且 $k_1/k_2=mf(0)/\{ng(0)\}$ [page 9]。利用 $f,g$ 在 0 处的连续性，把 $v,w$ 取得足够小使密度在 $[0,\eta]$ 内相对偏差小于 $\delta$，从而把 $E(M_v)$、$E(M_w)$ 等夹在 $k_1/(1\pm\delta)$ 之间 [page 10]。由于这些是二项随机变量、期望趋于无穷但慢于试验数，可用大数律控制。关键事件是 $U>v$ 蕴含 $M_v\le M$，$U<w$ 蕴含 $M_w\ge M$，从而把 $M/(mU)$ 夹在 $f(0)v(1-\delta)^2/(mU)$ 与 $f(0)w(1+\delta)^2/(mU)$ 之间；而 $v/w=(1-\delta)^2/(1+\delta)^2$，夹逼即得依概率收敛 [page 11]。$N/(nU)$ 同理。

定理 4 的实践含义是：**取一个大的但远小于样本量的 $k$，在合并样本中找离 $z$ 最近的 $k$ 个点，数出其中 $M$ 个 $X$、$N$ 个 $Y$，当 $M/m>cN/n$ 时判 $Z$ 属于 $F$** [page 11]。这正是后来所谓 $k$ 近邻判别规则的雏形。

## 七、结论成立的条件与边界

把整条论证链串起来，结论依赖以下条件：

1. **密度连续**：引理 3 要求 $f$ 在 $z$ 连续；定理 4 要求 $f,g$ 在 0 处正且连续。作者在 §4 开头说明，可接受的密度类包括一致连续、连续、或至多可数点不连续的密度 [page 7]。若不作任何连续性假设，作者明确指出无法估计 $f(z)$——因为可以任意改变 $f(z)$ 而不改变样本分布 [page 8]。

2. **样本量同速增长**：$m/n$ 与 $n/m$ 有界远离 0 [page 6]。这是双重极限化为单一极限的技术前提，也是定理 4 中 $k_1/k_2$ 配比有意义的基础。

3. **$k$ 的增长速率**：$k\to\infty$ 但 $k/m\to 0$、$k/n\to 0$ [page 9]。$k$ 太小则近邻区域概率估计不稳，太大则密度在区域内不再近似常数。

4. **临界值 $c$ 固定**：作者明确不讨论 $c$ 的选择，把它当作问题的给定数据 [page 3]。

5. **边界情形**：作者假设 $P\{f(Z)=cg(Z)\}=0$ 以简化处理，但指出这一限制不难推广 [page 3]。定理 4 末尾也提到某一密度在 0 处为 0 的情形可用"相应但更简单"的论证处理，从略 [page 11]。

作者承认的局限主要是**渐近性**：§5 开头即指出，$L^*$ 程序在 $m,n$ 不大时是否适用仍是未决问题，并说"任何渐近定理都可受此批评" [page 8]。作者在 §1 末尾预告正在进行的抽样实验，目的正是考察中等样本量下的表现 [page 4]。因此，本文的结论严格说来只保证极限行为，不保证有限样本性能——这是读者需要保留的边界。

## 八、论证的关键转折

整篇论文的推理枢纽有两处。第一处是**把判别问题化归为密度值比较**：既然 $L(c)$ 只需要 $f(z)$ 和 $g(z)$，非参数情形就不必估计整个分布，只需估计这两个数 [page 7]。这一步把"非参数判别"这个看似困难的问题，转化为"非参数密度点估计"这个相对成熟的问题。

第二处是**用近邻比例估计密度值**，并证明在邻域收缩与样本量增长的恰当平衡下估计相合（引理 3、定理 4）。定理 4 尤其关键，因为它处理的是固定近邻点数这一更实用但概率结构更复杂的方案，证明中通过构造 $v,w$ 两个阈值和利用 $U$ 的次序统计量性质，绕开了 $M,N$ 不独立带来的困难。

从证据到结论的桥接可以这样概括：定理 1 建立"估计量相合 + 密度连续 ⟹ 判别程序一致"的一般框架；定理 2 把这一框架搬到非参数情形，条件是密度估计相合；引理 3 和定理 4 分别提供两种相合密度估计；于是非参数判别程序与 $L(c)$ 一致。作者省略的桥接（定理 2 的证明）与定理 1 同构，读者可自行补足。

## 九、一点分析性推断

需要说明的是，本文的"一致性"是程序间的一致性，而非错误率的最优性。作者并未声称非参数程序在有限样本下达到最小错误率，只声称极限下与最优程序给出相同分类。这一区分对理解论文的贡献很重要：它把非参数判别的合理性建立在"追平已知密度下的最优"这一可证明的基准上，而不是建立在有限样本的优越性上。此外，定理 4 的证明虽然只处理一元非负情形，但通过 §5 开头的降维变换，结论可回到原始 $p$ 维空间——这一变换的合法性依赖于 $\rho(X,z)$、$\rho(Y,z)$ 在 0 处有连续且不全为 0 的密度，这是读者应用时需要注意的技术条件。
