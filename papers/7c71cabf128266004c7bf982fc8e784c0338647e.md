# 分布式发电并网控制与同步：从系统任务到控制取舍

**原文**：Frede Blaabjerg、Remus Teodorescu、Marco Liserre、Adrian V. Timbus，*Overview of Control and Grid Synchronization for Distributed Power Generation Systems*，IEEE Transactions on Industrial Electronics 53(5), 1398–1409 (2006)，DOI: 10.1109/TIE.2006.881997。

这是一篇综述，不是提出并验证单一新控制器的实验论文。作者要解释的是：随着风能、光伏和燃料电池等分布式电源大量接入电网，控制系统必须同时处理能量转换、电流质量、并网同步和电网故障穿越；其中一项设计选择往往会把代价转移到另一项性能上。全文因而从系统硬件和控制任务出发，比较不同参考坐标系、控制器、故障运行目标及同步方法，而非以某组新实验数据证明一个普适方案。

系统层面的划分先给出后续讨论的逻辑起点：输入侧控制器负责尽可能提取能源并保护变换器，电网侧控制器则要调节有功和无功、维持直流母线电压、保证注入电流质量并完成同步 [pp. 1399–1400]。光伏和燃料电池通常需要直流变换与逆变环节；风电拓扑则取决于发电机及其是否通过全功率或部分功率变换器接网。硬件并非背景细节：它决定哪些变量可控、控制环如何配置，也决定故障时扰动如何传递。

这一组任务解释了为何论文把参考坐标系与电流控制器放在一起比较。同步旋转的 dq 坐标把基波交流量变成近似直流量，因此 PI 控制器可以有效调节；代价是需要准确的电网相角，而且通常还要用电压前馈和交叉耦合补偿。静止坐标系中的电流仍是正弦量，普通 PI 难以消除稳态误差，因此常配比例谐振（PR）控制器；它可以在基波及选定谐波频率提供高增益，且对相角信息的依赖较弱。直接在 abc 自然坐标中实现时，滞环控制反应快，却需处理开关频率固定、变压器接线等实现问题；死拍控制可快速跟踪，但数字实现有采样延迟，作者讨论用观测器修正参考来补偿 [pp. 1401–1403]。因此这里没有脱离条件的“最佳坐标系”：同步角的可用性、计算和调制复杂度、动态响应与谐波要求共同决定选择。

电能质量讨论进一步把这种取舍具体化。论文指出当时并网标准对注入电流总谐波畸变率提出 5% 的限制，并比较在 dq 坐标下用多个滤波/补偿环节处理正、负序谐波，与在静止坐标系下通过并联谐振环节选择性补偿的实现差异。前者在不平衡时需要区分序分量，结构会迅速变复杂；后者较容易针对多个谐波扩展，且一个谐振补偿环节可同时作用于该次谐波的正、负序。滞环和死拍响应快，但仍会留下开关或采样频率附近的谐波，并要求足够快的硬件采样 [pp. 1403–1405]。这些比较说明，控制器“响应快”并不能替代对电流频谱和实现条件的检查。

故障运行部分把目标冲突摆到台面上。非对称电压跌落会引入负序分量，造成二倍频功率波动，并可能在直流母线电压、PLL 相角和电流参考中留下纹波；若同步环节没有抑制负序，扰动会沿“电网电压 → 相角估计 → 电流参考”这条链传到变换器控制 [pp. 1405–1406]。作者据此归纳了四类控制目标：维持单位功率因数、跟随正序电压、保持有功功率恒定、保持无功功率恒定。它们分别偏向不同的并网要求，不能同时消除所有波动。例如单位功率因数方案不向电网送无功，但故障下电流波形可能出现谐波；正序控制可保持电流平衡和正弦，却会让有功、无功出现二倍频振荡；恒有功方案可压低有功波动，但需注入负序电流，电流因而不平衡且无功会振荡；恒无功控制则提供无功调节自由度。具体采用哪种策略，取决于电网规范和运营方要求，而非论文给出一个对所有故障占优的方案 [pp. 1405–1407]。

同步方法的比较把上面的关系闭合起来。过零检测实现简单，却容易受谐波和缺口干扰；滤波电压后用反正切取相角，性能有所改善，但滤波延迟和故障期间相角估计困难仍是问题；dq 坐标 PLL 在当时是主流方案，对谐波、缺口和一般扰动的抑制较好，但不平衡电压的负序会引入二倍频并污染估计相角，需要额外滤波或序分量处理。反过来，若电流控制本身采用静止坐标系，作者指出可直接把滤波后的 αβ 电压作为参考电流模板，不一定要显式计算电网相角 [pp. 1407–1408]。所以同步算法并非可独立挑选的外围模块：其延迟、负序抑制和角度误差会直接影响电流闭环和故障运行策略。

论文的证据主要来自对既有拓扑、控制框图、方程和文献结果的比较；文中没有新建统一测试平台，也没有在同一条件下对所有方法作系统实验排名。作者得出的更稳妥结论是，分布式发电并网需要协同设计输入/电网侧结构、电流控制、电能质量补偿和同步环节，故障控制还必须按电网代码所要求的功率目标选择。文中引用的 5% 谐波限值与并网标准属于 2006 年的讨论背景，不能直接当成当前所有地区的现行规范；具体性能描述也依赖所引文献的系统和实现条件。整篇综述的价值在于整理了各设计决策之间的因果联系和代价，而不是证明某一种方法在所有设备、网况或标准下都最好。

**术语简释**：DPGS 指分布式发电系统；PLL 为锁相环；dq 为与电网同步旋转的坐标系，αβ 为静止坐标系；正序/负序用于描述三相电压或电流的对称分量。
