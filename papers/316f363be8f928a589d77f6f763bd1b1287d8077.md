# 从原子坐标计算生物大分子X射线溶液散射：CRYSOL的论证结构

**原文题名**：CRYSOL – a Program to Evaluate X-ray Solution Scattering of Biological Macromolecules from Atomic Coordinates
**年份**：1995
**DOI**：https://doi.org/10.1107/s0021889895007047

## 问题与主张

这篇论文的核心主张有两层。第一层是方法性的：作者提出一套算法，能够从已知的原子坐标（如PDB文件）快速计算生物大分子的溶液小角X射线散射（SAXS）曲线，并且只需两个自由参数——每个原子基团的平均排代溶剂体积，以及水化层的衬度——就能拟合实验曲线 [page 1]。第二层是物理性的：作者主张，在计算中显式引入水化壳层（hydration shell）对于正确再现散射曲线是必要的，忽略它会在小角区域引入系统性误差，甚至导致对结果的误读 [page 1]。

这两层主张是相互支撑的。方法层面，作者用多极展开（multipole expansion）实现球面平均的快速计算，并用水化壳层模型补上了此前方法缺失的一块；物理层面，正是通过把"有水化壳"与"无水化壳"的拟合结果并置对照，作者才论证了水化壳的贡献不可忽略。

## 从散射强度公式到可计算量

论证的起点是稀溶液中单颗粒的散射强度表达式（公式1）[page 1]：

$$I(s) = \langle |A_a(s) - \rho_0 A_c(s) + \delta\rho A_b(s)|^2 \rangle_{\Omega}$$

这里 $A_a(s)$ 是真空中的颗粒散射振幅，$A_c(s)$ 是排代体积（单位密度）的散射振幅，$A_b(s)$ 是边界层（单位密度）的散射振幅，$\rho_0$ 是溶剂平均散射密度，$\delta\rho = \rho_b - \rho_0$ 是水化层衬度。这个式子的物理含义是：溶液散射 = 真空颗粒散射 − 被排代溶剂的散射 + 水化层的额外散射。前两项是此前方法已有的，第三项是CRYSOL新增的。

关键的技术一步是把球面平均变得可算。作者利用球谐函数展开（公式3–4），把三个振幅都写成多极分量 $A_{lm}(s)$、$C_{lm}(s)$、$B_{lm}(s)$ 的形式 [page 2]。由于球谐函数的正交性，交叉项在取向平均中全部消去，散射强度简化为各多极分量模方之和（公式11）[page 2]：

$$I(s) = \sum_{l=0}^{L} \sum_{m=-l}^{l} |A_{lm}(s) - \rho_0 C_{lm}(s) + \delta\rho B_{lm}(s)|^2$$

这一步是整篇论文的推理枢纽。它把"对每个散射矢量做球面平均"这个计算上昂贵的操作，转化为"对有限个多极分量求和"，截断值 $L$ 控制着表示的精度。作者在示例中使用 $L=12$、$N_g=2585$ 个角方向 [page 4]。

## 三个振幅各自怎么算

**真空振幅 $A_a(s)$**：对非氢原子求和（公式2、5），氢原子被并入其所键合的原子基团，按表1替换为对应的基团形式因子 [page 2–3]。表1列出了H、C、CH、CH₂、CH₃、N、NH、NH₂、NH₃、O、OH、S、SH以及Mg、P、Ca、Mn、Fe、Cu、Zn等离子的排代溶剂体积和半径。基团形式因子用五个高斯函数拟合，在 $0 < s < 10$ nm⁻¹ 范围内制表 [page 2]。

**排代体积振幅 $C_{lm}(s)$**：用虚拟原子（dummy atoms）表示排代体积，其形式因子为（公式12）[page 2]：

$$g_j(s) = G(s) V_j \exp(-g s^2 V_j^2 / 3)$$

其中 $V_j$ 是第 $j$ 个原子或基团排代的溶剂体积，$G(s)$ 是整体膨胀因子（公式13），依赖于有效原子半径 $r_0$ 与实际平均半径 $r_m$ 之比。$r_0$ 正是两个自由参数之一，作者发现它不应偏离 $r_m$ 太多，经验范围是 $0.96 r_m < r_0 < 1.04 r_m$ [page 3]。

**边界层振幅 $B_{lm}(s)$**：水化壳被建模为厚度 $\Delta$、密度 $p_b$ 的均匀边界层，由二维角函数 $F(\omega)$ 描述（公式7）[page 2]。$F(\omega)$ 的构造方式是：把颗粒移到几何中心，用Fibonacci数生成准均匀角网格，每个非氢原子沿方向 $\omega_i$ 更新包络函数，条件是原子到该方向的最小距离小于原子半径加水面半径（$r_w = 0.15$ nm），更新规则为公式14 [page 3]。$B_{lm}(s)$ 通过数值积分公式10得到 [page 2]。

## 两个自由参数与拟合

作者论证，由于 $F(\omega) \gg \Delta$ 通常成立，边界层的贡献主要取决于乘积 $\delta\rho \Delta$，因此可以固定其中一个。CRYSOL取 $\Delta = 0.3$ nm 来模拟最有序的第一水化层 [page 3]。这样，拟合实验曲线时只剩两个可调参数：有效原子半径 $r_0$（控制排代体积）和水化层衬度 $\delta\rho$。拟合通过网格搜索最小化 $\chi^2$（公式15–16），搜索范围是 $0.96 r_m \le r_0 \le 1.04 r_m$ 和 $0 \le \delta\rho \le 60$ e nm⁻³ [page 4]。$\delta\rho$ 的上限 $(r\rho)_{\max} \approx 70$ e nm⁻³ 对应自由水与结合水的电子密度差 [page 3]。

## 两个实例如何支撑结论

**溶菌酶（14 KDa）**：实验曲线在EMBL Hamburg的X33相机上记录，坐标取自PDB文件pdb61yz.ent [page 4]。最佳拟合给出 $\chi = 0.477$，$r_0 = 0.161$ nm（总排代体积17.4 nm³），$\delta\rho = 25$ e nm⁻³，对应水化比0.4 g g⁻¹ [page 4]。实验回转半径 $R_g = 1.52(2)$ nm，理论值 $R_g^t = 1.48$ nm。关键对照是：当固定 $\delta\rho = 0$（即不考虑水化壳）时，拟合明显变差（$\chi = 0.765$，$R_g^t = 1.43$ nm）[page 4]。图3直观展示了这一点——虚线（$\delta\rho = 0$）与实线（最佳拟合）的差异 [page 4]。

**ATCase（303 KDa，十二聚体）**：坐标由PDB文件pdb6atl.ent经对称操作生成，实验曲线来自LURE [page 5]。最佳拟合 $\chi = 1.16$，$R_g^t = 4.64$ nm，$r_0 = 0.168$ nm，$\delta\rho = 58$ e nm⁻³，水化比0.21 g g⁻¹。不考虑水化壳时拟合很差（$\chi = 4.89$，$R_g^t = 4.43$ nm），且子极大值出现显著位移 [page 5]。这个例子比溶菌酶更有说服力，因为大分子形状更复杂，水化壳的贡献更突出。

## 与已有方法的比较

作者把CRYSOL与Pavlov & Fedorov（1983）的改进立方体方法做了对比 [page 4–5]。对于溶菌酶，两种方法给出的排代体积一致（16.8 vs 17.4 nm³），$I_a(s)$ 和 $I_c(s)$ 在 $s \lesssim 4$ nm⁻¹ 范围内吻合良好；但在更高角度，由于排代体积填充不均匀，CRYSOL的形状散射出现偏差 [page 5]。Pavlov程序不考虑水化壳，在小角区域有系统性偏差（$\chi = 0.687$，$R_g^t = 1.47$ nm）；即使人为把溶剂密度调到 $\rho_0 = 310$ e nm⁻³，也只能把 $\chi$ 降到0.581 [page 5]。计算时间上，CRYSOL在IBM AT/486 DX50上需310秒，Pavlov程序需660秒 [page 5]。

作者还尝试与Lattman（1989）的程序比较，但"由于运行该程序时遇到软件限制"而失败 [page 5]。这是一个负面结果，作者如实报告，没有掩饰。

## 结论成立的条件与边界

作者明确承认了几个限制。第一，边界层模型是简化的：对于形状复杂的大分子，包络函数 $F(\omega)$ 可能不是单值的，用 $F(\omega)$ 会填充内部空腔；虽然 $F(\omega)$ 不适合评估形状散射本身，但用于描述外部水化壳仍然合理 [page 5]。第二，CRYSOL被证明在 $s < 4$ nm⁻¹（约1.5 nm分辨率）范围内能充分评估SAXS曲线，更高角度下立方体方法预期更准确 [page 5]。第三，水化比在大多数研究的蛋白质中为0.2–0.3 g g⁻¹，溶菌酶的0.4 g g⁻¹是异常高的值 [page 5]。第四，PDB中通常只有不到50%的结合水，且这些水"很难用于表示溶液中的水化壳"；实际上，用Pavlov程序把这些水纳入溶菌酶计算反而使结果变差 [page 5]。

这些限制界定了结论的适用范围：CRYSOL的强项在于中低角度的溶液散射计算，其水化壳模型抓住了第一水化层的主导贡献，但对内部空腔和更高角度的处理不是它的目标。作者没有声称这套方法适用于所有大分子或所有角度范围。

## 推理链的要点

整篇论文的论证可以概括为：溶液散射 = 真空散射 − 排代溶剂散射 + 水化层散射（公式1）→ 用多极展开把球面平均化为可计算的求和（公式11）→ 三个振幅分别用原子形式因子、虚拟原子和包络函数计算 → 固定水化层厚度，留两个自由参数拟合实验 → 溶菌酶和ATCase的实例表明，引入水化壳显著改善拟合，忽略它则产生系统性偏差。关键推理步骤是公式11的推导，它使得从原子坐标到散射曲线的计算在普通计算机上变得可行；关键物理判断是水化壳的贡献不可忽略，这一点由两个实例中"有水化壳"与"无水化壳"的对照所支撑。
