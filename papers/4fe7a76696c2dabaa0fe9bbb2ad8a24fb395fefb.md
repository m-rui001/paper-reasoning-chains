# 多光子纠缠与干涉测量：从基础检验到量子信息处理

**原文题名**：Multiphoton entanglement and interferometry
**年份**：2012
**DOI**：https://doi.org/10.1103/RevModPhys.84.777

这是一篇发表在 *Reviews of Modern Physics* 上的综述，作者包括潘建伟、陈增兵、陆朝阳、Weinfurter、Zeilinger 和 Żukowski。文章系统梳理了多光子干涉与纠缠在理论与实验两方面的进展，并强调这些现象既服务于量子力学基础检验，也构成光量子信息处理的核心资源。以下分析围绕作者的核心主张、支撑证据、关键推理步骤以及结论的适用边界展开。

## 核心主张与论证主线

文章的核心主张可以概括为：**多光子干涉揭示了严格非经典的现象，而对这些现象的操控（尤其是通过线性光学手段构造和投影多光子纠缠态）既能够检验量子力学与局域实在论的冲突，又能够支撑量子通信与量子计算的关键协议。** 这一主张贯穿全文，其论证结构大致分为三条相互支撑的线索：

1. **概念与工具层面**：作者先建立量子干涉与经典干涉的本质区别，说明多粒子干涉为何不能被经典波或经典粒子图像解释，并引入线性光学元件、Hong-Ou-Mandel 干涉、Bell 态分析器等工具 [page 4–14]。
2. **实验实现层面**：作者说明如何利用自发参量下转换（SPDC）产生各种形式的纠缠，并通过"纠缠交换"从两光子纠缠构造三光子、四光子乃至更多光子的纠缠 [page 15–24]。
3. **基础检验与应用层面**：作者用这些多光子态检验 Bell 不等式、GHZ 定理、Leggett 型非局域实在论以及非语境隐变量理论，并展示它们在量子隐形传态、纠缠纯化、量子中继器和线性光学量子计算中的应用 [page 25–32]。

这三条线索并非并列罗列，而是层层递进：工具决定了能构造什么态，能构造什么态决定了能检验哪些理论、实现哪些协议。

## 从量子干涉到多粒子干涉：关键的概念转折

作者首先区分经典干涉与量子干涉。经典情形下，两束波的强度叠加给出式 (2) 的干涉项，可见度最大为 1；而对于相位随机涨落的两个场，强度关联函数 $G^{(2)}$ 的可见度最多只有 50% [page 5, Eq. (4)]。这一 50% 上限是经典场的硬性限制。

量子情形则不同。单粒子干涉在形式上与经典类似，概率密度由振幅叠加给出，式 (9) 显示可见度可达 100% [page 5]。真正的转折出现在两粒子情形：式 (12) 表明，当两个粒子的路径振幅相干叠加时，联合探测概率可以出现 100% 可见度的干涉，而单粒子边缘分布却是常数 [page 6, Eq. (14)]。作者强调，这种"无界可见度"只是两粒子干涉区别于经典干涉的特征之一，更深刻的区别在于纠缠态所定义的联合性质——单粒子约化密度矩阵是完全随机的，全部信息只存在于联合测量中 [page 6]。

这一概念转折是理解全文后续论证的基础：**多光子干涉的非经典性不在于单个光子行为的怪异，而在于联合探测概率中出现的、经典关联无法复制的干涉项。**

## 线性光学工具箱：从 Hong-Ou-Mandel 到 Bell 态分析

作者用相当篇幅介绍线性光学元件和由它们构成的分析工具，因为这些工具决定了后续所有实验的可能性边界。

最基础的是 50:50 分束器（BS），其变换由式 (28) 给出，反射时引入相位 $i$ [page 11]。由此产生的 Hong-Ou-Mandel 干涉是全文反复使用的核心机制：两个全同光子从不同输入端口进入 BS 时，式 (30) 显示"各走一个输出端口"的两项相消，导致符合计数消失 [page 11–12]。作者明确指出，这一相消依赖于光子在所有其他自由度上的不可区分性；若光子部分可区分，符合概率为 $(1/2)|\epsilon|^2$，其中 $\epsilon$ 刻画可区分程度 [page 12]。

这一机制的直接应用是 Bell 态分析。Weinfurter 以及 Braunstein 和 Mann 提出的方案利用 $|\psi^-\rangle$ 的反对称性，使其在 BS 后产生符合计数，从而可以区分四个 Bell 态中的两个 [page 14, Fig. 7(a)]。Pan 和 Zeilinger 的改进方案则利用偏振分束器（PBS）和半波片，可以区分 $|\phi^\pm\rangle$，并可直接推广到 N 粒子 GHZ 态分析 [page 14, Fig. 7(b)–(c)]。作者指出，完整的 Bell 态分析需要借助超纠缠才能实现 [page 14]。

这里的关键推理是：**线性光学本身无法实现确定性 CNOT 门，因此无法确定性地区分四个 Bell 态；但借助玻色子不可区分性带来的干涉效应，可以概率性地实现部分区分，而这已足够支撑隐形传态、纠缠交换等协议。** 这一"概率性但可行"的定位，是全文对线性光学量子信息处理的基本判断。

## 多光子纠缠的构造：纠缠交换作为核心方法

作者明确指出，SPDC 只能直接产生两光子纠缠，而三光子及以上的纠缠必须通过"纠缠交换"来构造 [page 3, page 20]。其原理是：两个独立源各发射一对纠缠光子，将每个源的一个光子送到共同的 BS 或 PBS 上进行联合测量；当联合测量成功时，剩余两个从未相互作用过的光子被投影到纠缠态 [page 20, Fig. 14]。

作者详细分析了这一过程对实验条件的要求。关键条件是**源不可区分性**：必须使得无法从探测时间或频率判断某个光子来自哪个源。为此，作者给出式 (47) 的可见度公式

$$V^{(4)} = \left[\frac{\sigma_p^2}{\sigma_p^2 + \sigma_F^2 \sigma_f^2/(\sigma_p^2 + \sigma_F^2 + \sigma_f^2)}\right]^{1/2},$$

其中 $\sigma_p$ 是泵浦脉冲谱宽，$\sigma_f$ 是 a、b 路径滤波器的谱宽，$\sigma_F$ 是 c、d 路径滤波器的谱宽 [page 21]。这一公式的物理含义是：只有在观测到来自两个源的光子的路径上使用足够窄的滤波器，才能抹去源的信息，从而恢复干涉。

作者还指出一个重要的限制：**光子统计会降低可见度**。式 (48) 给出 SPDC 的态为 $|\psi\rangle = N^{-1}\sum_{m=0}^\infty z^m |m,s\rangle|m,i\rangle$，当 $|z|^2 > (\sqrt{17}-3)/8 \approx 0.140$ 时，可见度降到 50% 以下 [page 21]。这意味着，要构造更多光子的纠缠，需要更强的泵浦，但强泵浦又会引入多对发射，降低干涉可见度。作者明确将这一矛盾列为多光子纠缠方法的固有限制 [page 21]。

这一分析是全文论证的一个关键节点：**多光子纠缠的构造能力受到"需要更多初始纠缠对"与"强泵浦降低可见度"之间的张力所约束。** 作者并未声称这一限制不可突破，而是指出它是当时方法的内在困难，并介绍了通过调控相位匹配条件产生频率不可关联光子对等新方法来缓解这一问题 [page 21–22]。

## 基础检验：从 Bell 不等式到 GHZ 定理

作者用大量篇幅讨论多光子纠缠在基础检验中的应用，其论证逻辑是：**多粒子纠缠使得局域实在论与量子力学的冲突更加尖锐，且所需的实验条件在某些方面反而更宽松。**

对于两粒子情形，作者给出 CHSH 不等式 $S_{\text{Bell}} \leq 2$ [page 25, Eq. (54)]，并指出量子力学对单态的最大违反值为 $2\sqrt{2}$（Cirel'son 界）[page 26]。作者详细讨论了实验检验中的两个漏洞：定域性漏洞和效率漏洞。定域性漏洞要求测量设置的选择必须随机且足够快，使得信息无法在测量完成前从一个观察者传到另一个；效率漏洞则要求探测效率足够高，否则需要额外的公平采样假设 [page 26]。Weihs 等人的实验通过 400 m 空间分离和量子随机数发生器实现了对定域性漏洞的关闭，观测到 $S_{\text{Bell}} = 2.73 \pm 0.02$，违反局域实在论阈值 30 个标准差 [page 26, Fig. 17]。但作者明确指出，该实验的探测效率仍远低于关闭效率漏洞所需的阈值 [page 26]。

对于三粒子情形，GHZ 定理的论证更为有力。作者给出式 (56)–(60) 的推导：从三个完美关联关系出发，局域实在论要求 $A_n(\pi/2)B_n(\pi/2)C_n(\pi/2) = 1$，而量子力学预言该值为 $-1$，导致 $1 = -1$ 的矛盾 [page 27–28]。这一"无不等式的 Bell 定理"直接摧毁了从局域性和完美关联推导实在论的可能性。Pan 等人的实验用三光子 GHZ 态检验了这一矛盾，测得平均可见度 $(71 \pm 4)\%$，超过 50% 的阈值 [page 28, Fig. 18]。

作者还讨论了 GHZ 推理向两观察者情形的推广，以及 Hardy 悖论作为另一种"无不等式"检验方案 [page 29–30]。这些讨论的共同指向是：**多粒子纠缠使得局域实在论与量子力学的冲突不再依赖于统计不等式，而是表现为确定性的逻辑矛盾，从而在概念上更为尖锐。**

## 非局域实在论与非语境隐变量：更精细的排除

作者进一步讨论了 Leggett 型非局域实在论和非语境隐变量理论。Leggett 的模型假设 (L1) 实在论、(L2) 物理态是具有确定偏振的子系综的统计混合、(L3) 每个子系综的局域期望值服从 Malus 定律，但不假设定域性 [page 30]。作者给出 Leggett 型不等式 (68)：

$$S_{\text{NLHV}} \leq 4 - 4\left|\sin\frac{\phi}{2}\right|,$$

并指出量子力学对单态的预言在 $\phi_{\max} = 18.8^\circ$ 时给出最大违反：不等式界为 3.792，量子值为 3.893 [page 31]。Gröblacher 等人的实验测得 $S_{\text{NLHV}} = 3.8521 \pm 0.0227$，以 3.2 个标准差违反该不等式 [page 31, Fig. 19]。

对于非语境隐变量理论，作者引用 Cabello 的不等式 (69)：

$$S = \langle ABC\rangle + \langle abc\rangle + \langle \gamma\beta\chi\rangle + \langle Aa\alpha\rangle + \langle Bb\beta\rangle - \langle Cc\gamma\rangle \leq 4,$$

并指出量子力学对四维系统预言 $S = 6$，Amselem 等人的实验违反了该不等式 [page 32]。

这些讨论的论证意义在于：**即使放弃定域性假设，只要保留某种形式的实在论（如 Leggett 型模型）或非语境性假设，量子力学仍然与这些理论冲突。** 这扩展了 Bell 定理的排除范围，使得"量子力学与经典世界观的冲突"不再仅仅依赖于定域性这一条假设。

## 量子信息应用：从隐形传态到量子中继器

作者将多光子纠缠的应用分为量子通信和量子计算两大块。在量子通信方面，核心协议包括量子密集编码、量子隐形传态、纠缠交换、纠缠纯化和量子中继器 [page 24–32]。

量子隐形传态的理论方案由 Bennett 等人提出，需要 EPR 通道和两个经典比特的传输 [page 24]。实验实现的关键步骤是 Bell 态测量，而这正是前文讨论的线性光学 Bell 态分析器的应用场景。Bouwmeester 等人的首次实验利用 SPDC 产生的纠缠光子对和 Hong-Ou-Mandel 干涉实现了隐形传态 [page 24]。作者还讨论了隐形传态到自由飞行光子、以及各种物理系统的推广 [page 24]。

纠缠纯化是克服噪声环境的关键工具。作者指出，纠缠交换和纯化是量子中继器的两个核心组件 [page 24]。量子中继器协议由 Briegel 等人提出，旨在实现长距离高保真度的纠缠分发 [page 24]。作者列举了已经实现的组件：纠缠交换、纯化、量子存储等 [page 24]。

在量子计算方面，作者重点讨论了 KLM 方案和单向量子计算。KLM 方案表明，利用线性光学、单光子源和探测器，原则上可以实现可扩展的量子计算 [page 4]。单向量子计算则从簇态出发，通过单量子比特测量来执行算法 [page 4]。作者指出，基于单向量子模型的光学方案比 KLM 方案减少了三个数量级的计算资源开销 [page 4]。实验中已经实现了多达六光子的簇态，并演示了基本量子门和算法 [page 4]。

这一部分的论证逻辑是：**多光子纠缠不仅是基础检验的工具，也是量子信息处理的核心资源；而线性光学方法虽然概率性，但已经足以实现一系列关键协议，并展现出向可扩展方向发展的潜力。**

## 结论的适用条件与边界

作者在引言中明确限定了综述范围：**只讨论涉及离散可观测量的"少光子"现象，不涉及连续变量实验** [page 4]。这一限定意味着，文中关于多光子纠缠能力的结论不直接适用于连续变量领域。

在具体论证中，作者反复强调了几类限制条件：

**第一，多光子纠缠的构造受光子统计限制。** 如前所述，强泵浦引入多对发射，降低干涉可见度，这限制了可纠缠的光子数 [page 21]。作者指出，这一限制是当时方法的内在困难，虽然新方法（如频率不可关联光子对）可能缓解，但尚未完全解决。

**第二，Bell 检验存在漏洞。** 定域性漏洞和效率漏洞在多数实验中并未同时关闭。作者明确指出，Weihs 等人的实验关闭了定域性漏洞，但效率漏洞仍然存在；离子阱实验关闭了效率漏洞，但定域性漏洞仍然存在 [page 26]。同时关闭两个漏洞仍是未来目标。

**第三，线性光学 Bell 态分析是概率性的。** 作者明确指出，线性光学无法实现确定性 CNOT 门，因此无法确定性地区分四个 Bell 态 [page 14]。这意味着基于线性光学的量子信息协议在效率上存在固有损失。

**第四，多光子纠缠的可见度随光子数增加而下降。** 作者在讨论 GHZ 实验时指出，三光子 GHZ 实验的可见度为 $(71 \pm 4)\%$，而更高光子数的实验面临更大的对齐和相干性挑战 [page 28]。虽然 GHZ 不等式的噪声容限随粒子数指数增长，但实验上实现高可见度的多光子态仍然困难 [page 28]。

**第五，部分理论检验依赖于辅助假设。** 例如，Leggett 型不等式的推导依赖于 (L1)–(L3) 三个假设，而非语境隐变量理论的检验则依赖于非语境性假设 [page 30–32]。作者明确指出，这些假设的合理性本身是可以讨论的，因此这些检验排除的是特定类别的理论，而非所有可能的非局域或实在论模型。

## 总体评估

这篇综述的论证力量在于，它将概念分析、实验实现和理论检验紧密编织在一起，展示了一个从基础到应用的完整链条。作者的核心贡献不在于提出新的理论或实验，而在于系统性地论证：**多光子纠缠与干涉测量已经从一个纯粹的哲学兴趣领域，发展为量子信息科学的核心实验平台。**

其论证的关键转折点有三：一是从单粒子干涉到多粒子干涉的概念跃迁，揭示了联合探测概率中经典关联无法复制的干涉项；二是从两光子纠缠到多光子纠缠的实验跃迁，通过纠缠交换突破了 SPDC 只能直接产生两光子纠缠的限制；三是从基础检验到信息应用的实用跃迁，展示了多光子纠缠在隐形传态、纯化和量子计算中的核心作用。

结论的边界同样清晰：多光子纠缠的构造能力受光子统计限制，Bell 检验存在未关闭的漏洞，线性光学方法本质上是概率性的，而部分理论检验依赖于可讨论的辅助假设。这些限制并不削弱文章的核心主张，但明确界定了该主张成立的实验和理论条件。
