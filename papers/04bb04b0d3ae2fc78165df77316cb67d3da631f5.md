# 类别不平衡何时真正伤害分类器？
*The class imbalance problem: A systematic study · Nathalie Japkowicz & Shaju Stephen · 2002 · Intelligent Data Analysis 6(5)*

少数类样本少，并不自动意味着分类器一定会失效。Japkowicz 和 Stephen 试图把问题拆开：类别比例、概念复杂度、训练集规模和分类器类型，究竟哪些因素决定错误？他们先用 C5.0 决策树在人工生成的概念上系统改变这些因素，再比较重采样与代价修正，并把观察扩展到 MLP、SVM 和若干真实数据集。

人工实验把输入简化为一维区间：两类交替出现，区间数控制概念复杂度，训练样本总量和两类比例则分别变化。这个构造使变量容易控制，但也意味着小类的每个子区间具有规则、相同的结构。结果显示，线性可分的简单概念对不平衡并不敏感；概念越复杂，训练集越小，不平衡越严重，C5.0 越容易错分。错误主要落在多数类一侧的假阳性上，假阴性在这些人工实验中始终低于 5%。

研究者进一步排除了两种混淆解释。首先，不平衡越强时总训练样本也会减少；他们重新构造数据，在同一规模条件下比较，C5.0 的总体趋势仍在。其次，他们固定少数类每个子区间都有 50 个训练样本，再改变两类比例和概念复杂度，错误降到 1%以内，原有的不平衡效应不再明显。由此他们提出：在这类概念学习任务中，真正危险的不是比例悬殊本身，而是复杂概念被切分成许多区域后，少数类某些子区域样本稀少到不足以学准。比例、复杂度和样本总量会共同影响这种稀疏状况。

这个解释也说明补救方法为何不能脱离场景排序。对人工域中的 C5.0，随机过采样比随机欠采样更有效；聚焦过采样通常还能改善表现，而聚焦欠采样并未稳定胜过随机欠采样；代价修正在多数设置中表现较好，但并非每个复杂度/样本规模组合都最佳。真实数据集提供了方向一致但较弱的检验：Sick、Allbp 等较大数据即使偏斜也能较准确分类，成本调整没有明显帮助；Hayes–Roth 等很小的数据对复杂度和不平衡更敏感；Monks 数据即使概念较复杂，在平衡时仍可准确分类。真实域测试多为一次训练/测试划分，特征结构也远比人工的一维域复杂，作者没有把它们当作与人工扫描同等强度的证据。

分类器比较进一步削弱了“类别不平衡必然伤害任意模型”的说法。MLP 在同一人工域中也受到影响，但错误变化较平滑，与 C5.0 有些设置下突然从近乎全对转为明显误差的模式不同；SVM 在所测设置中相对不敏感，过采样没有明显收益，欠采样甚至可能损害表现。因此，C5.0 上有效的补救方法不能自动推广到 SVM，重采样也不应在不检查模型和数据的情况下当作标准前处理。

论文的结论有明确范围：人工实验主要是单特征、两类、类间不平衡的概念学习问题，少数类的子簇在构造上较规则；作者没有研究多数类内部的大量无关样本、特征维度与相关性、子簇大小不均等复杂因素，也指出重采样至完全平衡未必是现实数据的最优比例。因而更稳妥的读法是：不平衡是否有害，取决于它是否让模型难以覆盖少数类的局部结构，以及模型对这种稀疏是否敏感；在真实应用中，应检查局部样本覆盖、错误类型和分类器行为，再选择采样或代价策略。

## 研究边界

本文主要以 C5.0 在受控人工概念上的系统扫描支撑机制解释；MLP、SVM 仅覆盖其中一部分人工域。真实数据集数量有限，且比较基于单次划分，不能建立人工生成分布与复杂现实分布的一一对应。讨论集中于两类之间的类间不平衡，不包含同一类别内部的小子簇不平衡；过采样/欠采样目标设为两类样本平衡，是为比较方便而采用的设定，不等于普遍最优策略。
