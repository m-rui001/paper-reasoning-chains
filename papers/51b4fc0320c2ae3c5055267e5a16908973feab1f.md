# 从自然键轨道供体-受体视角看分子间相互作用：一篇论证分析

**原文题名**：Intermolecular Interactions from a Natural Bond Orbital, Donor-Acceptor Viewpoint
**作者**：Alan E. Reed, Larry A. Curtiss, Frank Weinhold
**年份**：1988　**DOI**：10.1021/cr00088a005

## 一、作者要论证什么

这篇综述的核心主张可以概括为一句话：**氢键及其他强范德华复合物的结合，本质上是一种"化学"的、轨道重叠型的供体-受体相互作用，而非经典静电作用主导的"物理"结合**。作者用自然键轨道（NBO）分析这一工具，把从头算波函数重新翻译成化学家熟悉的"孤对电子→反键轨道"（n → σ*）语言，并主张：在氢键这类复合物的实际平衡距离上，电荷转移（charge transfer, CT）项才是把两个单体拉进范德华接触距离以内的关键力量 [page 1, page 3]。

这个主张是**有争议的**，作者对此非常清楚。1980年代主流的 Kitaura-Morokuma（KM）能量分解和静电模型都得出"静电主导、电荷转移次要"的结论。因此本文不只是报告结果，更是一场方法论辩护：作者要论证，那些支持静电主导的结论，问题出在**分析方法的假设**上，而不是波函数本身 [page 22, page 24]。

## 二、NBO 方法为什么能支撑这个主张

论证的根基在第二节。NBO 分析把输入基组经过一系列正交变换，得到自然原子轨道（NAO）、自然杂化轨道（NHO）、自然键轨道（NBO）和自然定域分子轨道（NLMO）[page 4, 式(6)]。关键在于，这套变换把密度矩阵分成两块：一块是形式 Lewis 结构中"占据"的轨道（键、孤对），另一块是"未占据"的反键轨道 σ*。总能量因此可分解为

E = E_Lewis + E_non-Lewis　[page 2, 式(2)]

作者用表 I 和表 II 说明，对大量第一、二周期氢化物和简单有机物，Lewis 结构部分占总电子密度的 99% 以上，非共价修正通常不到 1% [page 3, Table I; page 5, Table II]。这为"把小的非共价项当作微扰处理"提供了合法性。于是非共价能量降低可以用二阶微扰表达：

ΔE_σ* ≈ −2 ⟨σ|F|σ*⟩² / (E_σ* − E_σ)　[page 3, 式(3)]

**这是全文最关键的一步推理桥梁**：作者把"反键轨道的微小占据"等同于"从供体到受体的电荷转移"，并把它与一个可计算的能量降低联系起来。作者特别强调，这里的 σ* 不是 SCF 理论中严格空置、对波函数无贡献的虚轨道，而是有非零占据、能带来确定能量降低的轨道 [page 3]。这一步区分很重要，因为它是 NBO 与 HOMO-LUMO 图像、与 Mulliken 电荷转移复合物图像划清界限的地方。

作者还反复强调**正交性**是微扰分析物理自洽的前提：非正交原子轨道会导致非厄米的哈密顿量、概率不守恒等病态 [page 4]。这一铺垫直接服务于第四节对 KM 方法的批评——KM 对价层空间做了不对称的正交化处理。

## 三、从证据到结论：水二聚体作为范例

论证的经验核心是水二聚体（第三节 A.1）。这是最早做 NBO 分析的氢键体系，作者用一系列基组检验了结论的稳定性 [page 9, Table III]。在最大的基组 TZP++(2d) 下，复合能为 −4.1 kcal/mol，分解为

ΔE = ΔE_NCT + ΔE_CT = +2.4 + (−6.5) kcal/mol　[page 9, 式(17)]

也就是说，**电荷转移项（−6.5）在数值上超过了净结合能**，而排斥-静电项（NCT）本身是正的（排斥的）。二阶微扰分析显示，唯一大于 0.25 kcal/mol 的分子间稳定化作用就是那个 n → σ* 相互作用，其 Fock 矩阵元为 0.0864 au，能量分母 1.42 au，二阶估计 −6.6 kcal/mol，与 ΔE_CT 的 −6.5 吻合 [page 9]。占据数也自洽：近端 σ* 占据增加 0.0083 e，近端孤对减少 0.0081 e，净转移电荷 0.0081 e。

这里有一个容易被误读的地方，作者专门澄清：**ΔE_CT 大于净结合能，并不意味着"电荷转移就是全部"**。因为 CT 与排斥都随距离指数变化，CT 的作用是让两个单体克服排斥、靠得更近，从而**放大**静电作用。作者做了一个判决性检验：把 CT 稳定化删掉后重新优化氢键距离，键长拉长了 0.56 Å，NCT 结构的最优结合能只有 −2.44 kcal/mol，且 O···H 距离恰好等于范德华半径之和 [page 10]。这直接说明：**没有 CT，剩下的静电作用根本不足以让单体靠得那么近**。作者由此提出一个重要的方法论警告：在平衡几何下算一个静电作用能、发现它和总结合能相当，就断言"本质是静电的"，这是误导性的 [page 11]。

图 5 进一步展示了伴随 CT 的分子内电子结构重排：给体水的 O–H 键更偏向氧极化、氧杂化轨道 s 成分增加，氢键上的 σ_OH 键极性和 s 成分大幅增加，使反键更偏向 H、成为更好的受体 [page 10]。这些变化与 Bent 规则一致，也解释了氢键质子上电子密度降低的现象。

## 四、把结论推广到更广的体系

作者用同一套逻辑覆盖了多个体系，论证策略是**展示 n → σ* 图像的普适性和可预测性**：

- **OC···HF 与 CO···HF**：CT 稳定化在 OC···HF 中比 CO···HF 大 6 kcal/mol 以上，解释了为何实验观察到的是碳键合异构体 [page 11, Table IV]。作者用二阶表达式把偏好归因于碳孤对是更好的供体（能量更高、更弥散，矩阵元 0.109 vs 0.069 au）[page 11]。
- **NO···HF**：开壳层的 NO 因多一个 π* 电子，可以用"不同自旋不同 Lewis 结构"描述，从而在很宽的接近角度上都能形成氢键，解释了 NO 对 HF 振动弛豫的高效性 [page 12]。
- **大系列氢键复合物**：图 6、图 7 显示 ΔE_CT 在所有氢键复合物中都显著超过净 ΔE，且随 Lewis 酸碱强度平滑变化 [page 12]。作者提出一个经验规则：转移电荷 q 与能量稳定化（原子单位）大致成比例，0.001 e 对应约 0.6 kcal/mol [page 6, page 13]。
- **非氢键复合物**：图 9 与图 6、7 形成鲜明对照——非氢键复合物中 ΔE_CT 通常小于 ΔE，且同核双原子（N₂、F₂、O₂）的 n → π* 重叠为零，q 可忽略 [page 16]。作者强调，这种氢键/非氢键的清晰区分是 NBO 分析独有的，KM 分析则"看不出区别" [page 16]。
- **离子-分子复合物**：阴离子-水复合物中 CT 与总结合能同量级，但不再占主导（静电因离子-偶极作用增强）；阳离子-水复合物中 CT 只占 5–40% [page 17, Table VI; page 18]。
- **双氟离子 FHF⁻**：CT 高达 0.20 e、约 160 kcal/mol，是强氢键的极限案例，等价于 Pimentel 的三中心四电子模型 [page 18]。
- **疏水相互作用**：CH₄···OH₂ 中相关效应"戏剧性"地重要（MP2 下 C–H···O 键强 −1.6 kcal/mol，约 160% 的相关修正），但 n → σ* 仍是主导贡献；作者指出协同效应（非加和性）本质上游离于静电图像之外 [page 15]。

## 五、与静电模型的对峙：论证的真正转折

第四节是全文论证张力的顶点。作者要解释：**为什么同样的波函数，NBO 和 KM 会得出相反的结论？**

答案在于**价层空间的正交化方式** [page 22]。NBO 用加权的对称正交化处理所有价层 NAO；而 KM 实际上把每个单体的虚轨道对另一单体的占据轨道做 Schmidt 正交化。由于反键轨道占据很低，几乎全部落在虚空间里，Schmidt 正交化就把近端 n → σ* 重叠的绝大部分"判给"了占据轨道，于是这部分能量被计入"静电"项，只有与占据轨道正交的残余部分才被算作"电荷转移"。作者用一个具体数字说明这种不对称：水二聚体 12 个价层原子轨道中，KM 只对 8 个做对称正交化，其余 1/3 做 Schmidt 正交化 [page 22]。

作者的结论是：**NBO 与 KM 之间没有量子力学层面的对错之分**——分子哈密顿量只含库仑项，本就"纯粹是静电的"；分歧取决于如何定义"静电""电荷转移""离域"这些词 [page 23]。但作者主张 NBO 有概念上的优势：它能与强重叠区域的共价、配位共价概念平滑衔接，而静电模型在单体深入范德华接触以内 0.5 Å 以上时越来越不合理 [page 23]。

作者还指出静电模型的具体缺陷：无法描述缺乏多极矩的非极性物种（如 CH₄）、本质上是成对加和的因而无法描述协同效应、依赖介电参数选择 [page 24]。同时作者也**坦承一个劣势**：当时还没有基于供体-受体方法的经验模型势函数，而静电方法有 [page 24]。

## 六、结论成立的条件与边界

作者自己划定了供体-受体图像的适用边界，这是论证诚实性的体现：

1. **最弱的范德华分子**（如 He···OH₂）中 CT 不重要，因为没有可用的低价空价层轨道，平衡距离在范德华接触之外，长程理论适用 [page 24]。
2. 作者提出两个判据：范德华穿透距离 d_p = R_vdW − R_eq 明显为正（约 ≥ 0.1 Å），或净结合能约 ≥ 1 kcal/mol [page 24, 式(24)]。
3. 作者引入无量纲"共价比" x = d_p / (R_vdW − R_cov)，氢键物种 x ≈ 0.3，双氟离子可达 0.9；供体-受体模型的边界在 x ≈ 0–0.1 的弱非氢键复合物附近 [page 24, 式(25)(26)]。

需要提醒读者注意的**不确定性**：文中若干数值在 OCR 提取中可疑，例如表 III 中 6-31++G** 的 ΔE_CT 与 ΔE_NCT 之和与 ΔE 不完全自洽，图 5 中部分数字（如 "+0.0081"、括号内百分比）在提取文本中模糊 [page 9, page 10]。这些疑点不影响定性结论，但引用具体数值时应核对原文。此外，作者反复使用 may、suggest、likely 等谨慎语气（如疏水效应的生物物理意义、协同效应的作用），这些应保留为可能性而非确定结论。

## 七、总体判断

这篇综述的论证力量不在于提出新数据，而在于**重新解释已有波函数**，并把解释分歧追溯到分析方法对价层空间的处理方式。其关键推理链是：NBO 分解 → 反键轨道有非零占据 → 对应可计算的二阶能量降低 → 该能量在氢键平衡距离上超过净结合能 → 删除它则单体无法靠近 → 因此 CT 是氢键的特征性主导力量。这条链的每一环都有具体数据支撑，且作者主动检验了基组依赖性和相关效应。

结论的**力度**应严格限定为：在氢键及强范德华复合物（x ≳ 0.1）中，n → σ* 型供体-受体相互作用是主导的、特征性的结合因素；在弱复合物中 CT 退居次要。作者也承认，供体-受体与静电两种描述在量子力学上并非互斥，分歧部分是定义问题——这一让步使全文的立场更接近"概念框架之争"而非"事实之争"，也解释了为何作者说这一观点在当时仍是"少数派" [page 25]。
