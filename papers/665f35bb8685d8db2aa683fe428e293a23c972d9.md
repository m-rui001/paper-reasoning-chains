# 把 AIC 差值翻译成模型概率：Akaike 权重的论证逻辑

**原文题名**：AIC model selection using Akaike weights（2004，DOI: 10.3758/bf03206482）

## 论文要解决的一个解释难题

这篇短文的核心主张并不复杂：在认知心理学中，研究者习惯只报告"原始"AIC 值并据此接受单一模型，但这种做法难以把 AIC 之间的差异解释为连续的概率度量；作者主张把 AIC 值转换成所谓的 Akaike 权重（Akaike weights），后者可以直接解释为每个模型的条件概率 [page 1]。

要理解这个主张为什么值得提出，需要先看 AIC 本身在做什么。AIC 的目标是估计：当用候选模型的概率分布 g 去近似真实（生成）模型的分布 f 时，会产生多少信息损失；衡量这种差异的是 Kullback–Leibler 信息量 I(f, g) [page 2]。Akaike 证明，选择期望信息损失最小的模型，渐近等价于选择 AIC 值最低的模型，而 AIC 定义为

$$\text{AIC}_i = -2\log L_i + 2V_i \quad (1)$$

其中 $L_i$ 是候选模型 i 的最大似然，$V_i$ 是自由参数个数 [page 2]。式 (1) 的结构本身就体现了模型选择的核心张力：第一项奖励描述精度（似然越大，AIC 越小），第二项惩罚参数过多。作者也明确交代，式 (1) 基于渐近近似，只对足够大的数据集有效；当 $n/V < 40$ 时一般推荐使用有限样本校正 $\text{AIC}_c$ [page 2]。这是结论适用条件的第一道边界。

## 从 AIC 差值到权重：关键的一步

作者的论证转折在于：原始 AIC 值本身无法回答"证据有多强"这个问题。他们用表 1 的假设数据说明这一点。表 1 对五个模型（A1、A2、B1、B2、C）给出自由参数数、对数似然、AIC 值等；其中 A2 的 AIC 为 202，是最低值，A1 为 204，仅差 2 [page 2, Table 1]。作者指出，从原始 AIC 值可以判断 A2 是首选模型，但很难直觉地知道 A2 与 A1 之间这个差值在统计上意味着什么；当 AIC 差异很小时，接受单一模型可能带来虚假的确定感。此外，原始 AIC 值也无法说明数据在多大程度上支持模型 A 相对于模型 B [page 2]。

转换分三步。第一步，计算每个模型相对最佳模型的 AIC 差值：

$$\Delta_i(\text{AIC}) = \text{AIC}_i - \min \text{AIC} \quad (2)$$

这一步把关注点从绝对 AIC 值转向模型的相对表现 [page 2]。第二步，由 AIC 差值估计模型 i 的相对似然：

$$L(M_i \mid \text{data}) \propto \exp\left\{-\frac{1}{2}\Delta_i(\text{AIC})\right\} \quad (3)$$

第三步，把这些相对似然归一化，得到 Akaike 权重：

$$w_i(\text{AIC}) = \frac{\exp\left\{-\frac{1}{2}\Delta_i(\text{AIC})\right\}}{\sum_{k=1}^{K}\exp\left\{-\frac{1}{2}\Delta_k(\text{AIC})\right\}} \quad (4)$$

使得 $\sum w_i(\text{AIC}) = 1$ [page 3]。表 1 第 5 列给出了这组权重：A2 为 .6094，A1 为 .2242，B1 和 B2 各为 .0824，C 为 .0015 [page 2, Table 1]。

这里的关键推理是：AIC 差值经过指数变换和归一化后，不再只是一个排序指标，而成为一个可解释为"在给定数据和候选模型集合下，$M_i$ 是最佳模型（即在 AIC 意义上最小化 Kullback–Leibler 距离）的概率"的量 [page 3]。作者明确说明，这一解释来自 Burnham 和 Anderson (2001)，并且权重本身受抽样波动影响，不同样本很可能产生不同的权重集合 [page 3]。这一点很重要：权重是条件于当前数据和候选模型集合的，不是模型的固有属性。

## 权重如何让比较变得可读

有了权重，模型间的证据强度可以用权重之比来表达。作者给出两个例子。A2 相对 A1 的证据比是

$$\frac{w_{\text{A2}}(\text{AIC})}{w_{\text{A1}}(\text{AIC})} = \frac{.6094}{.2242} \approx 2.7$$

即 A2 在 Kullback–Leibler 意义上成为最佳模型的可能性约为 A1 的 2.7 倍；作者还把它表达为归一化概率 $2.7/(2.7+1) \approx .73$ [page 3]。类似地，模型 A（A1 与 A2 合计）相对模型 B 的证据比约为 5.1，归一化概率 .83；含注意参数的模型（A2 与 B2）相对不含该参数的模型（A1 与 B1）的证据比约为 2.3，归一化概率 .69 [page 3]。这些数字说明，权重不仅复现了"选 A2"的结论，还额外给出了证据的连续强度。

作者还指出，权重之比可以直接由 AIC 值计算，不必先算权重：

$$\frac{w_i(\text{AIC})}{w_j(\text{AIC})} = \exp\left\{-\frac{1}{2}\left[\text{AIC}_i - \text{AIC}_j\right]\right\}$$

[page 3]。这一步在数学上等价于式 (3) 与式 (4) 的结合，但让读者看到：证据比只依赖 AIC 差值，与最佳模型的绝对 AIC 值无关。

## AIC 与 BIC 的对照：不同问题，不同偏好

论文后半部分把 AIC 权重与 BIC（Bayesian information criterion）权重并置。BIC 定义为

$$\text{BIC}_i = -2\log L_i + V_i \log n \quad (5)$$

其中 n 是进入似然计算的观测数 [page 3]。作者指出，当 $n > e^2$ 时，BIC 的惩罚项大于 AIC 的惩罚项 [page 3]。表 1 最后两列给出 BIC 值和 Schwarz 权重：BIC 偏好更简单的模型，在 A1 与 A2 之间选择 A1（A1 的 BIC 为 211.0，A2 为 212.4），而 AIC 偏好 A2 [page 2, Table 1; page 4]。不过两种权重都偏好模型 A 而非模型 B；按 Schwarz 权重，模型 A 比模型 B 更可能的归一化概率为 .95 [page 4]。

作者对两者差异的解释是框架性的，而非单纯数值的：BIC 假设真实生成模型就在候选集合中，衡量的是"某模型是真实数据生成模型"的信念程度；AIC 不假设任何候选模型必然为真，而是为每个模型计算 Kullback–Leibler 距离，即模型生成的密度与现实之间的距离 [page 4]。因此，作者强调 AIC 与 BIC 回答的是不同问题，形式上的性能比较非常困难：多数显示 BIC 优于 AIC 的模拟假设真实模型在候选集合中且维度较低；多数支持 AIC 的模拟则假设现实是无限维的，真实模型不在候选集合中 [page 4]。这段讨论实际上为 Akaike 权重的解释划定了边界——权重的"概率"含义是 AIC 意义上的，不是"模型为真的概率"。

## 结论成立的条件与作者承认的局限

把上述线索收拢，Akaike 权重的解释力依赖几个条件。第一，AIC 本身基于渐近近似，只适用于足够大的数据集；小样本下应使用 $\text{AIC}_c$ [page 2]。第二，权重是条件于候选模型集合的：如果候选集合本身不包含合理模型，权重再精确也只能在错误选项间分配概率。第三，权重受抽样波动影响，不同样本会产生不同权重 [page 3]。第四，作者明确把权重的概率解释限定为"AIC 意义上最佳模型"的概率，而非"模型为真"的概率；后者更接近 BIC 的框架 [page 3–4]。此外，作者提到 AIC 被批评为过于宽松、倾向于选择过复杂模型，且不是一致估计量——当 n 趋于无穷时，AIC 恢复真实低维模型的概率并不趋于 1 [page 3]。这些是作者转述的批评，不是他们自己的新结论，但构成了使用 Akaike 权重时应当意识到的背景。

论文的最终建议是温和的：鉴于 Akaike 权重易于从原始 AIC 值计算，且能提供对竞争模型相对优缺点的更深入理解、量化基于 AIC 分析的结论的统计置信度，作者认为在许多情况下用 Akaike 权重补充标准 AIC 比较结果是很有用的 [page 4]。他们没有主张权重可以替代 AIC 分析本身，也没有主张权重能解决模型集合设定是否正确的问题。
