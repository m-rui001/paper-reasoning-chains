# 掺杂驱动绝缘体—金属转变与庞磁电阻：La₁₋ₓSrₓMnO₃ 单晶的电子相图与磁电阻标度

**原文题名**：Insulator-metal transition and giant magnetoresistance in La₁₋ₓSrₓMnO₃
**作者**：A. Urushibara, Y. Moritomo, T. Arima, A. Asamitsu, G. Kido, Y. Tokura
**期刊**：Physical Review B, Vol. 51, No. 20, 15 May 1995-II, pp. 14103–14109
**DOI**：10.1103/PhysRevB.51.14103

---

## 一、论文要解决什么问题

这篇工作研究的是钙钛矿锰氧化物 La₁₋ₓSrₓMnO₃（0 ≤ x ≤ 0.6）中，由空穴掺杂驱动的绝缘体—金属转变，以及伴随铁磁相变出现的庞磁电阻（giant magnetoresistance, MR）效应。作者的核心关切不是单纯报告某个组分的 MR 数值，而是要建立一条从**载流子填充（名义空穴浓度 x）** 到**磁结构**再到**输运性质**的完整关联链条，并解释为什么 MR 的大小会随 x 发生系统性变化 [page 1]。

作者选择单晶而非陶瓷样品，理由在引言中交代得很清楚：陶瓷样品的晶界散射会掩盖本征的金属—非金属行为，而且磁输运性质对 x 极为敏感，需要精细、系统控量的样品 [page 2]。因此，本文的实验基础是用浮区法（floating-zone, FZ）生长的一系列组分受控的单晶。

## 二、从晶体生长到电子相图

### 样品与表征

晶体通过 FZ 法生长，生长气氛随组分调整：x = 0、0.05 用氩气，x = 0.1–0.25 用空气，x = 0.3–0.6 用氧氩混合气 [page 2]。表 I 汇总了生长条件以及各组分的关键参数——奈尔温度 T_N、居里温度 T_C 和饱和磁化强度 M_s [page 3]。化学分析（EPMA、氧化还原滴定、热重）表明，0 ≤ x ≤ 0.4 的晶体实际组分与名义值几乎一致 [page 2]。室温晶体结构在 x ≈ 0.175 处从正交（Pbnm）变为菱面体（R3c），晶格参数随 x 的变化见 Fig. 1 [page 2]。

这里有一个对后续论证很重要的方法学细节：作者用磁转变温度 T_C 和结构转变温度 T_s 的清晰可辨来证明样品组分在宏观尺度上是均匀的 [page 3]。换句话说，如果样品内部存在明显的组分梯度，这些转变就会被抹平。这是作者为"单晶数据可靠"这一前提提供的实验支撑。

### 相图的建立

Fig. 2 给出 0 ≤ x ≤ 0.4 各组分电阻率随温度的变化 [page 3]。几个关键观察：

- x ≤ 0.05 没有铁磁相变；
- 在 T_C 附近电阻率出现显著变化（箭头标出）；
- x ≥ 0.175 时，低温铁磁相中呈现金属性导电；
- x = 0.1 和 0.15 的样品在 T_C 以下电阻率先降后升，说明存在某种局域化效应；
- 高温顺磁相中，x < 0.2 时 dp/dT < 0（非金属行为），x > 0.3 时变为金属性。

Fig. 3 进一步展示了 x = 0.15、0.175、0.2、0.3 四个样品的电阻率与磁矩的对应关系（均在 0.5 T 偏置场下测量）[page 3]。电阻率的陡降与铁磁磁化的出现同步发生。作者据此提出，电阻率的温度依赖可以用**热自旋涨落对载流子的散射**以及**空穴有效质量的减小**来解释 [page 4]。其微观图像是双交换机制：相邻格点间的电子跃迁积分依赖于局域自旋的相对夹角，t_ij = t₀cos(Δθ_ij/2)，铁磁排列降低了跃迁的随机性 [page 4]。

低温区（Fig. 4）的数据显示，x = 0.2–0.4 样品的电阻率满足 ρ(T) = ρ(0) + AT²（T < 200 K）[page 4]。作者指出，铁磁相中的自旋波散射预期贡献 T² 项，但系数 A 随 x 减小这一事实（见 Fig. 4 插图）暗示电子—电子散射过程扮演了重要角色，反映了该体系中强的电子关联 [page 4]。

综合以上，Fig. 5 给出 La₁₋ₓSrₓMnO₃ 的电子相图 [page 4]。低温下按自旋构型和导电性分为五个区域：自旋倾斜反铁磁绝缘体（CNI，x < 0.1）、铁磁绝缘体（FI，0.1 < x < 0.15）、铁磁金属（FM，x > 0.15）；高温下则分为顺磁绝缘体（PI）和顺磁金属（PM），非金属—金属转变大致在 x ≈ 0.3 附近 [page 4]。

作者特别讨论了 FI 相的存在意义：简单的双交换理论只预言低温下存在金属性铁磁相，FI 相的出现说明传导电子受到了随机杂质势（替代的 Sr 离子）或电子—晶格相互作用的局域化影响 [page 4]。作者提到，施加约 1 GPa 的静水压可以使 x ≈ 0.17 附近的体系在直至零温都保持金属性，这进一步支持了"局域化而非本征绝缘"的判断 [page 4]。即使载流子被局域化、无法贡献宏观电荷输运，它们仍可以通过键渗流的方式媒介相邻局域自旋之间的铁磁相互作用 [page 4]。

## 三、磁电阻的核心论证

### 现象描述

Fig. 6 展示了 x = 0.15、0.175、0.20 三个样品在不同磁场下的电阻率—温度曲线，以及 15 T 下负磁电阻值 −[ρ(H) − ρ(0)]/ρ(0) [page 5]。x = 0.15 样品在 240 K 附近的 MR 值高达 0.95 [page 5]。作者将 T_C 以上观察到的 MR 现象解释为**场诱导的非金属—金属转变**，并指出磁场将 T_C 向低温方向移动 [page 5]。

### 关键推理：MR 与磁化的标度关系

这是全文论证的核心转折。Fig. 7 展示 x = 0.15 和 0.175 样品中电阻率变化与磁化强度变化的对应关系 [page 5]。一个关键观察是：MR 在 T_C 附近很大，但在远低于 T_C 时很小——例如 x = 0.175 在 78 K 时 MR 几乎为零 [page 6]。作者解释，低温下磁化曲线的快速上升来自软铁磁体的磁畴运动，而畴壁位移并不代表各个 Mn 位上场诱导矩的大小，因此不影响载流子散射 [page 6]。

Fig. 8 将 x = 0.175 样品的电阻率变化对归一化磁化强度 M/M_s 作图（M_s 取经典值 4μ_B）[page 6]。来自不同温度的场依赖数据点落在一条近似普适的曲线上，而由 0.5 T 下 ρ-T 和 M-T 曲线得到的 ρ-M 关系也遵循类似轨迹 [page 6]。作者认为这一重合表明 ρ-T 曲线和 MR 受同一散射过程支配 [page 6]。

在低磁化区域（M < 0.3M_s），数据点偏离普适曲线，呈水平线（虚线），这被归因于磁畴壁位移主导的初始磁化过程 [page 6]。

### 标度关系的定量形式与 x 依赖

Fig. 9 将 x = 0.175、0.3、0.4 三个样品在 T_C 略上方（1.01T_C 和 1.05T_C）的负磁电阻对 (M/M_s)² 作图 [page 6]。数据可以用一个标度函数很好地描述：

$$-\Delta\rho/\rho(0) = C(M/M_s)^2$$

其中系数 C 强烈依赖于 x：在金属—绝缘体相边界附近（x_c ≈ 0.17，Fig. 9 插图中用箭头标出），C 约为 4；随 x 增大，C 急剧减小，到 x = 0.4 时降为 1 [page 6]。

### 理论对照与物理解释

作者将这一结果与 Furukawa 基于 Kondo 点阵模型（铁磁耦合 J > 0）在经典自旋（S = ∞）和无穷维（D = ∞）极限下的 Kubo 公式计算进行对比 [page 7]。该计算表明，C 可以超过 1——在强耦合（J ≫ W，W 为单电子带宽）情形下约为 4，但在弱耦合极限下趋于 1 [page 7]。实验观察到的 C 从约 4 降到 1，被解释为空穴掺杂驱动体系从强耦合向弱耦合区域的**渡越（crossover）** [page 7]。

这里需要点明推理的关键一步：作者并不是说 C 的数值精确等于理论预言，而是说 C 随 x 的变化趋势——从相边界附近的大值降到高掺杂区的小值——与理论中耦合强度从强到弱的趋势定性一致。这个"定性一致"是连接实验标度关系与双交换物理图像的桥梁。

## 四、结论成立的条件与作者承认的局限

**适用条件**：

- 标度关系 −Δρ/ρ(0) = C(M/M_s)² 在 M < 0.3M_s 的低磁化区域成立 [page 7]；
- 在高温区（T_C 以上）数据重合较好，但在高磁化区域，温度变化和磁场变化得到的两条曲线之间存在小的系统性偏差 [page 6]；
- 作者将这一偏差归因于温度依赖的散射过程（电子—电子散射、电子—声子散射），并指出局域自旋的量子涨落可能也因极强的相互耦合而对载流子散射有贡献 [page 6]。

**作者明确承认的局限**：

- 高磁化区域的定量理解需要考虑局域自旋的量子涨落效应 [page 7]；
- x = 0.15 样品在 78 K 下 MR 效应持续存在，作者推测与完全自旋极化的 e_g 载流子的 Anderson 局域化有关，但同时指出 MR 在纵向和横向构型下几乎各向同性这一现象"有待澄清" [page 6]；
- 作者在总结中指出，平均场型理论能解释 C 为何可以如此之大（C ≈ 4），但高磁化区域 MR 现象以及低温输运性质的定量理解，仍需考虑局域自旋的量子涨落 [page 7]。

**分析者补充的边界说明**（非原文结论）：本文的标度关系是在 T_C 附近及以上的温区建立的，将其外推到远低于 T_C 的温度需要谨慎，因为低温下磁畴运动主导初始磁化、且电子—电子散射的贡献变得显著。此外，C 的 x 依赖是在 x = 0.175、0.3、0.4 三个组分上确定的，中间组分的插值行为并未被直接验证。

## 五、论证的整体逻辑

回顾全文，作者的论证链条是：

1. **材料基础**：用 FZ 法生长组分均匀的单晶，通过磁转变和结构转变的清晰性验证均匀性 [page 3]；
2. **相图建立**：通过系统的电阻率和磁化测量，建立 T—x 平面上的电子相图，识别出 CNI、FI、FM、PI、PM 五个区域 [page 4]；
3. **现象关联**：发现电阻率变化与铁磁磁化同步，提出双交换框架下的自旋散射图像 [page 4]；
4. **标度关系**：发现 MR 与 (M/M_s)² 成正比，且标度系数 C 强烈依赖 x [page 6]；
5. **理论解释**：将 C 的 x 依赖与 Kondo 点阵模型的理论计算对比，解释为空穴掺杂驱动强耦合→弱耦合的渡越 [page 7]。

这条链条中最具启发性的转折在于第四步到第五步之间：作者没有停留在"MR 很大"这一现象描述上，而是找到了一个**可标度的定量关系**，并利用标度系数的系统变化来揭示体系电子结构随掺杂的演化。这使得 MR 从一个应用导向的效应变成了探测强关联电子态的有力工具。
