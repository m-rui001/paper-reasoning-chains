# 量子计算机上的多项式时间因子分解与离散对数：Shor 算法的论证结构

**原文题名**：Polynomial-Time Algorithms for Prime Factorization and Discrete Logarithms on a Quantum Computer
**作者**：Peter W. Shor，1996（arXiv:quant-ph/9508027v2；初版发表于 FOCS 1994）

## 论文要证明的核心命题

Shor 这篇论文要确立的结论相当明确：在量子计算机上，整数因子分解和离散对数这两个被广泛认为经典计算困难、并支撑了 RSA 等密码体制的问题，存在多项式时间的随机算法，且错误概率很小 [page 1, page 4]。这里的"多项式"是相对于输入规模而言的——对因子分解，输入规模是待分解整数的位数 log n；对离散对数，是素数 p 的位数。

这个结论本身并不直接证明量子计算机比经典计算机更强，因为论文的算法运行在"假想的量子计算机"上，而这样的机器当时（乃至现在）尚未建成 [page 4]。因此论文的论证实际上分两层：第一层是构造性的——给出算法并证明其在量子门阵列模型下确实以多项式步数运行；第二层是概念性的——论证量子力学可能赋予计算超越经典图灵机的自然能力，从而挑战"强 Church 论题"。

## 从强 Church 论题到量子计算的位置

论文开篇没有直接进入算法，而是先搭建一个概念框架。经典计算理论用"多项式 vs 超多项式"来区分高效与低效计算，这个分类要成立，必须保证它与具体计算设备无关。这正是作者引用的"定量 Church 论题"（Vergis 等称之为"强 Church 论题"）：任何物理计算设备都能被图灵机以多项式步数模拟 [page 2]。作者指出这个论题有两个"逃生口"——"物理的"和"资源"两个词含义不完全明确 [page 2]。量子计算恰好从这两个口子切入：量子态操控的精度（precision）是一种新的资源，如果精度可以随输入规模多项式增长，就可能获得比经典计算机更强的计算能力 [page 3]。

这里有一个关键的论证转折：作者承认，如果精度是常数（不随输入规模增长），那么目前不知道量子计算机能在多项式时间内计算任何经典随机计算机不能计算的东西 [page 3]。换言之，量子优势的成立依赖于"精度作为可增长资源"这一假设。作者进一步指出，精度由材料和架构决定，而非基本物理定律，因此把它当作可变资源来研究是合理的——就像不把经典计算机当作有限自动机来研究一样 [page 3]。这是论文概念论证的核心一步，也是其结论的边界条件之一。

## 量子门阵列模型与可逆性约束

论文采用量子门阵列（quantum gate array）作为计算模型，并说明它与量子图灵机在允许小错误概率时能计算相同的多项式时间函数 [page 5]。这个模型选择本身是论证的一部分：它表明所构造的算法不依赖于某种特定量子架构，从而增强了结论的稳健性。

模型的两个基本约束直接塑造了后续算法。第一，量子态的演化必须是酉变换（unitary），且只允许作用在固定数量比特上的局部变换；通用门集可以取所有单比特门加上一个受控 NOT [page 6]。第二，量子计算本质上是可逆的，因为叠加态必须全程保持，不能像经典计算机那样通过耗散能量来擦除信息 [page 8]。可逆性约束意味着任何确定性计算必须先用可逆方式实现，这给经典子程序（如模幂运算）带来额外成本。

论文用 Toffoli 门和 Fredkin 门作为可逆经典计算的通用门，并引用 Bennett 的方法把不可逆计算改造成可逆计算 [page 8-9]。这里有一个对理解整个算法至关重要的技术点：Bennett 方法通过保留输入和记录中间结果来实现可逆，但代价是空间与时间同量级 [page 10]。作者随后说明，对模幂运算这一特定子程序，可以复用重复平方阶段的空间，把空间降到 O(l log l log log l)（用 Schönhage–Strassen 乘法）或 O(l)（用长乘法）[page 10]。这个"特定算法可特殊处理"的观察，是算法整体多项式资源占用的关键支撑。

## 量子傅里叶变换：算法的数学心脏

论文的算法核心是量子傅里叶变换 A_q，它把 |a⟩ 映射为 (1/q^{1/2}) Σ_c |c⟩ exp(2πiac/q) [page 13, 公式 4.1]。作者需要证明这个变换能在多项式时间内用量子门实现，否则整个算法不成立。

论文给出的构造针对 q = 2^l 的情形，只使用两类门：R_j（作用在第 j 位的 Hadamard 型门，公式 4.2）和 S_{j,k}（作用在第 j、k 位、添加相位 e^{iθ_{k-j}} 的门，公式 4.3），按公式 4.4 的顺序施加，共需 l(l−1)/2 个门 [page 13-14]。证明的关键在于追踪从 |a⟩ 到 |b⟩ 的相位累积：R_j 在 a_j = b_j = 1 时加 π，S_{j,k} 在 a_j = b_k = 1 时加 π/2^{k−j}，总相位为公式 4.5，经变量替换和重新索引后化为 2πac/q（公式 4.6–4.9）[page 14-15]。这个推导是纯代数的，不依赖物理假设，因此是论文中最稳固的一环。

一个值得注意的细节：当 k−j 很大时，S_{j,k} 的相位因子极小，物理上难以精确实现。作者引用 Coppersmith 的结果说明可以忽略这些小相位因子，构造一个近似傅里叶变换，仍足以用于因子分解，且大幅减少门数 [page 15]。这个近似步骤是算法实用性的重要支撑，但也引入了一个隐含条件：近似精度必须足够高，而论文在此处依赖引用而非自行证明。

## 因子分解：从求阶到分解的归约

论文不直接分解 n，而是求 x 模 n 的阶 r（最小正整数使 x^r ≡ 1 mod n），再利用经典数论把求阶归约为分解 [page 15]。归约的逻辑是：随机选 x，求其阶 r，计算 gcd(x^{r/2}−1, n)。由于 (x^{r/2}−1)(x^{r/2}+1) = x^r−1 ≡ 0 mod n，这个 gcd 在 r 为奇数或 x^{r/2} ≡ −1 mod n 时可能失败 [page 15-16]。作者给出失败概率上界 1−1/2^{k−1}（k 为 n 的不同奇素因子个数），证明思路是用中国剩余定理把随机选 x 化为在每个素幂因子下独立随机选 x_i，而每个奇素幂的乘法群是循环群，其阶的最大 2 幂因子与前面一致的概率至多 1/2 [page 16]。这个归约是经典结果（Miller 1976），论文只是引用并简述，因此其正确性不构成本文的新贡献，但它是整个算法能输出因子的必要环节。

量子求阶算法本身分四步：制备均匀叠加态 (1/q^{1/2}) Σ_a |a⟩|0⟩（公式 5.1）；计算 x^a mod n 存入第二寄存器（公式 5.2）；对第一寄存器做傅里叶变换（公式 5.3–5.4）；测量 [page 16-17]。测量得到状态 |c, x^k mod n⟩ 的概率为公式 5.5，经变量替换 a = br+k 化为公式 5.6，再忽略相位、替换 rc 为 {rc}_q 后得到公式 5.7 [page 17]。

这里是整个算法论证最关键的一步：作者要证明当 |{rc}_q| ≤ r/2 时，公式 5.7 中的求和项相位接近同向，从而使概率足够大。作者把求和近似为积分（公式 5.8），证明误差项为 O(1/q)，再替换变量得到公式 5.9–5.10，最终证明该积分的绝对值最小为 2/(πr)，其平方给出概率下界 4/(π²r²)，对足够大的 n 至少为 1/(3r²) [page 17-18]。这个下界直接支撑了后续的采样复杂度分析。

由 |{rc}_q| ≤ r/2 可推出存在整数 d 使 |c/q − d/r| ≤ 1/(2q)（公式 5.11–5.13）[page 18]。由于 q > n²，满足此不等式的分母小于 n 的分数 d/r 至多一个，因此可以用连分数展开从 c/q 恢复 d/r [page 18-19]。当 d 与 r 互素时即得 r。作者计算能恢复 r 的状态数为 rφ(r)（φ 为欧拉函数），每个状态概率至少 1/(3r²)，故单次成功概率至少 φ(r)/(3r)，利用 φ(r)/r > δ/log log r 得成功概率至少 δ/log log r，重复 O(log log r) 次即可高概率成功 [page 19]。

图 5.1 给出了 r = 10、q = 256 时观测到各 c 值的概率分布，显示概率集中在 q/r = 25.6 的整数倍附近 [page 18]。这个图是对上述解析下界的直观佐证，但注意作者特意把 q 取得比 n² 小以便区分 c 值，说明图的参数选择是为了可视化而非算法实际运行条件。

## 离散对数：更复杂的相位分析

离散对数算法使用三个寄存器，制备 (1/(p−1)) Σ_{a,b} |a, b, g^a x^{−b} mod p⟩（公式 6.1），对前两个寄存器做傅里叶变换（公式 6.2–6.3），测量后概率为公式 6.4 [page 20]。与因子分解的关键区别在于这里有两个模数 p−1 和 q 需要同时处理，使得相位分析更复杂。

作者把输出分为"好"和"坏"两类，定义"好"输出满足条件 (6.10) 和 (6.11) [page 21]。条件 (6.10) 保证第一个指数项的相位在 b 变化时最多覆盖半个单位圆，条件 (6.11) 保证第二个指数项的相位偏离 1 不超过 π/6。在两者都满足时，作者通过把求和近似为积分（公式 6.15–6.16），证明每个好输出的概率至少为 1/(20q²)（公式 6.17）[page 21-22]。好状态的数量约为 pq/12，因此观测到某个好状态的概率至少为 1/480 [page 22]。

从好输出恢复 r 的过程比因子分解更曲折。由条件 (6.10) 可得公式 (6.18)，其中 r 的系数是分母为 p−1 的分数，因此可以把 d/q 舍入到 1/(p−1) 的最近倍数，再除以整数 c'（公式 6.19）得到候选 r [page 22]。但问题在于 c' 可能与 p−1 不互素，无法直接求逆。作者的解决办法是：只对大于 18 的素幂证明能恢复 r 的余数，小于 18 的素幂用常数因子枚举所有可能 [page 23]。对于大于 18 的素幂 p_i^{α_i}，随机好 c' 被其整除的概率至多 12/p_i^{α_i}，若有 t 个好 c'，则存在大于 18 的素幂整除所有 c' 的概率由公式 (6.20) 界定，该和对 t = 2 收敛，每增加 t 减半，故存在常数 t 使其小于 1/2 [page 23]。由于每个好 c' 以至少 1/(40q) 的概率获得，且好 c' 有 q/12 个，经 480t 次实验后可获得 t 个好 c'，从而对所有大于 18 的素幂确定 r 的余数，再用中国剩余定理恢复 r [page 23]。

这个离散对数算法的论证比因子分解更依赖"好输出"的常数概率下界和素幂整除的概率估计，其中公式 (6.20) 的收敛性论证是关键的桥接步骤。作者也承认，如果实际编程，效率可以大幅提高，因为好 c' 的估计可能偏低，且坏 c' 的分布不太可能与小于 18 的素数有关 [page 23]。这些是作者明确标注的乐观推断，而非已证明的结论。

## 结论成立的条件与边界

论文的结论有若干明确的适用条件和边界，需要与核心主张区分开。

首先，算法运行在假想的量子计算机上，其物理实现面临退相干和精度两大障碍 [page 4-5, page 24]。作者引用 Bennett 等的结果说明，量子门只需精度 O(1/t) 即可高概率完成 t 步计算，退相干只需多项式小即可 [page 24]。但这些是"允许"条件，不是"已实现"条件。作者明确指出，构建足够精度和低退相干的量子计算机可能给实验物理学家带来巨大困难 [page 24]。

其次，因子分解算法要求 n 为奇数且非素数幂；素数幂的因子可用经典方法高效找到 [page 16]。离散对数算法要求乘法群是循环的，且已知生成元的阶，能在多项式时间内做乘法和求逆 [page 23-24]。作者指出算法不依赖 Z_p 的许多性质，可推广到其他有限域，Boneh 和 Lipton 进一步推广到阿贝尔非循环群 [page 24]。

第三，算法的多项式时间界依赖于具体的乘法算法选择。用 Schönhage–Strassen 乘法，模幂需 O(l² log l log log l) 时间；用长乘法需 O(l³) 时间 [page 10]。作者指出哪种乘法算法对哪种规模最优并不清楚，且经典计算机的数据可能误导，因为经典计算机不必可逆，且硬件内置了 32/64 位乘法 [page 12-13]。这是一个诚实的限制说明：算法的实际效率取决于底层算术的量子实现，而这在论文写作时尚未研究。

第四，论文对量子计算能否解决 NP 完全问题持谨慎态度。作者指出，若量子计算机只能解决因子分解和离散对数，它可能只是 thwart 公钥密码系统的专用技术；量子计算机要广泛有用，可能需要能解决 NP 完全问题，但存在弱迹象表明量子计算机不够强大，不过作者不认为这种可能性已被排除 [page 24-25]。这是对结论重要性的自觉限定，而非对算法正确性的怀疑。

## 论证的整体评价

Shor 这篇论文的论证力量在于其构造的完整性和数学证明的严密性。从量子门阵列模型到可逆模幂运算，从量子傅里叶变换的显式门构造到求阶算法的概率下界，再到离散对数的好输出分析，每一层都有明确的数学支撑。论文的结论——量子计算机上因子分解和离散对数是多项式时间的——在论文设定的模型和假设下是成立的。

论证中最关键的推理步骤有两处。一是量子傅里叶变换的相位累积计算（公式 4.5–4.9），它把门序列的物理作用转化为纯代数的相位求和，是整个算法数学正确性的基础。二是求阶算法中概率下界的推导（公式 5.7–5.10），它把量子测量的概率分布与数论中的分数逼近联系起来，是算法能输出正确结果的关键。这两处都是原文明说的证明，而非分析者的重建。

论文的结论在以下条件下成立：量子计算机能按门阵列模型运行；精度和退相干满足 Bennett 等给出的多项式界；底层算术（特别是模乘）能在量子计算机上高效实现。这些条件在论文写作时都未在实验上验证，因此论文的结论是条件性的——它证明的是"如果量子计算机能建成，则这些问题是多项式时间可解的"，而非"量子计算机已经能解决这些问题"。

论文对自身局限的承认是坦率的：量子计算机尚未建成，退相干和精度是主要障碍，算法实际效率取决于未研究的量子算术实现，量子计算能否解决 NP 完全问题未知。这些承认不削弱论文的核心数学贡献，但确实划定了结论的适用范围。作者对量子计算前景的讨论——特别是"若只能解决因子分解和离散对数，可能只是专用技术"的判断——显示其对结论重要性的评估是审慎的，而非夸大的。
