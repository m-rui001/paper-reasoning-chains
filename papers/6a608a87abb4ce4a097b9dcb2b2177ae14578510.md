# 把“拟合得好”变成可检验的假设：MacCallum、Browne 与 Sugawara 的 RMSEA 功效分析框架

**原文题名**：Power Analysis and Determination of Sample Size for Covariance Structure Modeling（1996，*Psychological Methods*, 1(2), 130–149，DOI: 10.1037/1082-989x.1.2.130）

## 一个被“精确拟合”卡住的检验逻辑

协方差结构模型（covariance structure modeling, CSM）的实证研究几乎总要回答一个问题：这个模型拟合得够不够好？作者指出，传统做法有两条路——用似然比（LR）检验检验“模型在总体中精确成立”这一零假设，或者用各种描述性拟合指标看样本拟合优度 [page 1]。这篇文章要处理的，正是第一条路里一个长期被默认接受、但逻辑上很别扭的问题。

问题的核心在于：常规的精确拟合检验，零假设是 $H_0: \Sigma(\gamma) = \Sigma(\gamma_0)$，即模型在总体中**完全正确**，样本中的任何偏离都只来自抽样误差 [page 3]。作者直言，这个零假设对任何过度识别模型来说“在实践中总是某种程度上为假”，研究者真正能期望的只是模型**近似**现实。更麻烦的是，当 $N$ 足够大（而 CSM 恰恰需要大样本以获得精确参数估计和满足渐近分布近似），即使是一个好模型，精确拟合检验也会把它拒绝掉 [page 3]。于是研究者陷入一个尴尬位置：想支持模型，却把“模型好”设成了零假设，而拒绝零假设才是否定模型——这与“研究假设应放在备择假设”的常规统计逻辑正好相反 [page 6]。

作者的应对不是修补精确拟合检验，而是换一套假设框架，并在此基础上建立功效分析和最小样本量确定方法。全文三个目标：定义关于模型拟合的合适假设及检验方法；给出这些检验的功效分析程序；给出达到指定功效所需最小样本量的确定方法 [page 2]。

## 从 $F_0$ 到 RMSEA：把“拟合差多少”变成一个可估计的量

论证的起点是差异函数。设 $\Sigma(\gamma)$ 为总体协方差矩阵的模型表达，$S$ 为样本协方差矩阵，$F(S, \Sigma)$ 度量二者差异，最小化后得到样本差异函数值 $F$ [page 2–3]。在精确拟合下，$(N-1)F$ 渐近服从自由度 $d = p(p+1)/2 - q$ 的中心 $\chi^2$ 分布 [page 3]。

关键转折在于承认模型在总体中不精确成立。此时定义 $F_0$ 为模型拟合总体协方差矩阵时的差异函数值，$(N-1)F$ 渐近服从非中心 $\chi^2_{d,\lambda}$，非中心参数 $\lambda = (N-1)F_0$ [page 4]。作者明确交代这一近似的适用条件：分布假设充分满足、样本量不太小、$F_0$ 不太大；并引用 Steiger、Shapiro 和 Browne（1985）以及 Browne 和 Cudeck（1993）作为理论基础，同时承认尚无大规模蒙特卡洛研究检验该近似在假设违反下的表现，只有 Satorra、Saris 和 de Pijper（1991）的有限研究显示在小样本、误设不严重时表现尚可 [page 4]。这是全文所有后续推导的共同前提，也是结论边界的第一道门槛。

由于 $E(F) = F_0 + d/(N-1)$，$F$ 是 $F_0$ 的有偏估计，作者用 $\hat{F}_0 = F - d/(N-1)$（负值取 0）作较少的偏估计 [page 4，式 4–5]。在此基础上定义总体 RMS 差异 $\varepsilon = \sqrt{F_0/d}$，其估计 $\hat{\varepsilon} = \sqrt{\hat{F}_0/d}$，即 RMSEA [page 5，式 6–7]。这个指标“每自由度”度量差异，因此对模型参数数量敏感：两个总体拟合相同（$F_0$ 相等）但自由度不同的模型，自由度更大（参数更少）的模型会得到更小（更好）的 $\varepsilon$ [page 5]。

作者引用 Steiger（1989）、Browne 和 Mels（1990）独立得出的经验准则：$\varepsilon < 0.05$ 视为接近拟合，0.05–0.08 为尚可，$>0.10$ 为差，0.08–0.10 为中等 [page 5]。作者强调这些是连续尺度上的解释辅助，不是绝对阈值。

## 反转零假设：从“检验精确拟合”到“检验不接近拟合”

有了 $\varepsilon$ 的分布性质，假设检验可以重新表述。精确拟合检验等价于 $H_0: \varepsilon = 0$，此时 $\lambda = 0$，用中心 $\chi^2$ 评估 [page 6]。Browne 和 Cudeck（1993）建议的接近拟合检验是 $H_0: \varepsilon \le 0.05$，此时 $\lambda = (N-1)d(0.05)^2$，用非中心 $\chi^2$ 评估；由于非中心分布的临界值右移（图 1，[page 7]），一个拒绝精确拟合的 $(N-1)F$ 值可能并不拒绝接近拟合 [page 6]。

但作者指出，接近拟合检验仍未解决零假设角色的问题：不拒绝 $H_0: \varepsilon \le 0.05$ 只意味着“没有足够证据反对接近拟合”，而非“支持接近拟合” [page 6]。于是他们提出**反转零假设**：定义 $H_0: \varepsilon \ge 0.05$（总体拟合**不**接近），拒绝它才支持“拟合接近”这一研究假设。这就是“不接近拟合检验”（test of not-close fit），用非中心 $\chi^2$ 的**下尾**做单尾检验，$(N-1)F$ 足够小则拒绝 $H_0$ [page 6–7，图 2]。

置信区间与这两类检验有直接对应关系（表 1，[page 8]）：若 $\varepsilon$ 的整个置信区间低于 0.05，则接近拟合检验不拒绝、不接近拟合检验拒绝；若区间跨越 0.05，两者都不拒绝；若整个区间高于 0.05，则接近拟合检验拒绝、不接近拟合检验不拒绝。作者反复强调置信区间比假设检验提供更多信息——它显示估计的精度 [page 2, 6]。

两个实证例子说明这一框架的区分力。McGaw 和 Joreskog（1971）的 21 个能力测验、$N = 11{,}743$ 数据中，四因子模型 $\varepsilon$ 的 90% 置信区间为 [0.046, 0.048]：精确拟合被拒绝（$\chi^2 = 3{,}548$，$d = 132$），接近拟合不被拒绝，而由于区间上界低于 0.05，不接近拟合被拒绝，从而为接近拟合提供了强支持 [page 8]。对比 Naglieri 和 Jensen（1987）的 24 个智力测验、$N = 86$ 数据，五因子模型 $\varepsilon$ 的 90% 置信区间为 [0.034, 0.081]：精确拟合被拒绝（$\chi^2 = 215.74$，$d = 166$），但区间跨越 0.05，接近拟合与不接近拟合都不被拒绝——此时若因未拒绝接近拟合就推断接近拟合，是错误的；宽区间说明两种可能都合理 [page 9]。

## 功效分析：效应量是一对 $\varepsilon$ 值，不是一个数

功效分析的核心是定义效应量。作者明确拒绝用 $\varepsilon_0 - \varepsilon_a$ 的算术差作为效应量指标，因为功效不是这个差的简单函数：相同的差、不同的 $\varepsilon_0$ 和 $\varepsilon_a$ 组合，功效不同 [page 9]。他们把效应量定义为一对值 $(\varepsilon_0, \varepsilon_a)$，其中 $\varepsilon_0$ 是零假设下的值，$\varepsilon_a$ 是真实值 [page 9]。

具体做法是构造两个非中心 $\chi^2$ 分布：零假设下 $\lambda_0 = (N-1)d\varepsilon_0^2$，真实值下 $\lambda_a = (N-1)d\varepsilon_a^2$ [page 10，式 8]。给定 $\alpha$，从零假设分布确定临界值 $\chi_c^2$；功效就是真实分布超出临界值（方向依检验类型而定）的面积，即式 9（$\varepsilon_0 < \varepsilon_a$，如接近拟合检验）或式 10（$\varepsilon_0 > \varepsilon_a$，如不接近拟合检验）[page 10，图 3–4]。

作者为三类检验选了具体值：接近拟合检验 $H_0: \varepsilon \le 0.05$ 对 $\varepsilon_a = 0.08$（真实拟合中等）；不接近拟合检验 $H_0: \varepsilon \ge 0.05$ 对 $\varepsilon_a = 0.01$（真实拟合极好）；精确拟合检验 $H_0: \varepsilon = 0$ 对 $\varepsilon_a = 0.05$（真实拟合接近）[page 9–10]。他们承认这些选择有任意性，但认为不比其他统计惯例（如 $\alpha = .05$）更任意，且方法本身不绑定于任何特定值 [page 9]。

表 2（[page 13]）给出 $\alpha = .05$ 下不同 $d$ 和 $N$ 的功效估计。几个值得注意的模式：

- 功效随 $d$ 或 $N$ 增大而增大。原因是两个非中心分布的分离程度取决于 $\lambda_0$ 与 $\lambda_a$ 之差，而该差是 $d$、$N$、$\varepsilon_0$、$\varepsilon_a$ 的函数 [page 12]。
- 当 $d$ 小，即使 $N$ 较大，功效也持续偏低。例如 $d = 40$、$N = 200$ 时，接近拟合检验对 $\varepsilon_a = 0.08$ 的功效约 0.69；$d = 100$、$N \ge 200$ 时功效远超 0.90 [page 10]。
- 不接近拟合检验的功效在 $d$ 和 $N$ 不大时略低于接近拟合检验，尽管其算术差（0.05 − 0.01 = 0.04）大于接近拟合检验的差（0.08 − 0.05 = 0.03）。作者解释这是“有效效应量”的差异：在较高 $d$ 下接近拟合检验的效应量实际更大，在较低 $d$ 下则更小 [page 10–11]。
- 精确拟合检验在真实拟合接近时（$\varepsilon_a = 0.05$）的功效也随 $d$ 和 $N$ 增大而升高，这正是“好模型被大样本拒绝”问题的量化体现。作者提醒，不能因此认为低 $d$、低 $N$ 就好——那样所有检验的功效都低，置信区间也宽，信息不精确 [page 11–12]。

功效还可以用置信区间解释：给定 $\alpha$、$d$、$N$、$\varepsilon_0$、$\varepsilon_a$，功效就是当 $\varepsilon = \varepsilon_a$ 时，置信区间不包含 $\varepsilon_0$ 的概率 [page 12]。

## 最小样本量：$d$ 小是真正的瓶颈

确定最小样本量 $N_{\min}$ 没有直接公式，作者用区间二分法系统搜索，附录给出 SAS 程序 [page 13–14]。表 4（[page 15]）给出 $\alpha = .05$、目标功效 0.80 下，接近拟合检验（$\varepsilon_0 = 0.05$，$\varepsilon_a = 0.08$）和不接近拟合检验（$\varepsilon_0 = 0.05$，$\varepsilon_a = 0.01$）所需的最小 $N$。

最突出的现象是 $d$ 与 $N_{\min}$ 的强关联。$d = 2$ 时接近拟合检验需要 $N = 3{,}488$；$d = 40$ 时需要 252；$d = 100$ 时只需 132 [page 15]。作者据此提出一条实践建议：**不鼓励在 $d$ 低时评估模型，除非 $N$ 极大**；同时不鼓励为改善拟合而引入大量参数，因为这会降低 $d$，而降低 $d$ 会大幅降低模型检验的功效 [page 14–15]。

另一个现象是两条 $N_{\min}$ 曲线在 $d \approx 14$ 处交叉：低 $d$ 时接近拟合检验需要更大 $N$，高 $d$ 时反过来。作者归因于效应量与 $d$ 的交互作用 [page 15]。

作者还给出一个看似诱人但需谨慎的推论：$d$ 很大时，中等 $N$ 就能获得足够功效。例如 $p = 30$、检验“测量变量不相关”的零模型，$d = 435$，接近拟合检验对 $\varepsilon_a = 0.08$ 只需 $N_{\min} = 53$ [page 15]。但作者立即列出两条限制：第一，ML 估计要求 $N > p$；第二，更重要的是，整个功效分析框架基于渐近分布理论，$N$ 太小时非中心 $\chi^2$ 近似可能不成立，因此 $N_{\min}$ 很小的结果应谨慎对待 [page 15]。作者还提醒，$N$ 只针对模型检验这一目的，参数估计精度等其他目的可能需要不同的 $N$ [page 15]。

表 5（[page 16]）给出精确拟合检验在 $\varepsilon_a = 0.05$ 时达到功效 0.80 和 0.50 所需的最小 $N$。例如 $d = 50$ 时，$N \ge 243$ 就有至少 0.80 的概率拒绝精确拟合，即使真实拟合接近；$N \ge 148$ 时概率超过 0.50。作者认为这为“不建议使用精确拟合检验”提供了明确依据 [page 16]。

表 3（[page 14]）把上述方法应用于五组已发表数据。McGaw 和 Joreskog（1971）数据 $d$ 和 $N$ 都极大，两种检验功效几乎为 1.0；Naglieri 和 Jensen（1987）与 Fredricks 和 Dossett（1983）功效中等；Meyer 和 Gellatly（1988）与 Vance 和 Colella（1990）$d$ 和 $N$ 都低，功效极低（接近拟合检验约 0.11–0.12，不接近拟合检验约 0.07–0.08），所需 $N_{\min}$ 高达 954–1,463。作者评论：在这种条件下，对模型的支持声明“必须被视为高度可疑” [page 14]。

## 与 Satorra–Saris 方法的差异，以及框架的边界

作者用一节比较了 Satorra 和 Saris（1983, 1985；Saris & Satorra, 1993）的方法。两者基于相同的分布近似，功效计算本身也相同（都用式 9），差别在效应量的建立方式：Satorra–Saris 需要指定一个包含额外参数的替代模型作为总体真模型，效应量是原模型与真模型之差；本文方法只用一对 $(\varepsilon_0, \varepsilon_a)$ 值，不要求说明模型如何误设，只说明总体中拟合差多少 [page 16–17]。作者列出三个优势：不依赖具体模型（唯一相关的模型特征是 $d$）；可用于精确拟合之外的检验；最小样本量确定简单 [page 17]。

作者也指出两个可能的推广方向：用其他拟合指标（如 GFI，因其可表示为 $F$ 的函数）替代 RMSEA 作为假设基础；把框架用于 CSM 之外的其他产生渐近 $\chi^2$ 拟合检验的语境（如对数线性模型）[page 17]。这些被明确标为“留给进一步研究”。

## 结论成立的条件

把全文的推理链串起来：非中心 $\chi^2$ 近似是全部推导的基石，它要求分布假设充分满足、$N$ 不太小、$F_0$ 不太大 [page 4]。在这个近似下，$\varepsilon$ 的置信区间、接近/不接近拟合检验、功效公式（式 9–10）和 $N_{\min}$ 搜索才成立。作者承认该近似在假设违反下的表现缺乏大规模蒙特卡洛证据，只有有限研究支持 [page 4]。

第二个条件是效应量值的选择。$\varepsilon_0 = 0.05$、$\varepsilon_a = 0.08$ 或 0.01 这些具体数字有任意性，虽然作者引用独立经验准则支持 0.05 作为接近拟合的界限 [page 5, 9]。方法本身不绑定这些值，但功效和 $N_{\min}$ 的具体数值依赖于它们。

第三个条件是 $N_{\min}$ 的解释边界。当计算出的 $N_{\min}$ 很小时，渐近理论可能不成立，结果不可靠 [page 15]。此外，$N$ 只针对模型检验，不保证参数估计精度 [page 15]。

最后，作者反复强调置信区间应优先于假设检验使用，因为区间估计直接显示精度，而假设检验的结果可以由区间推断（表 1）[page 2, 6, 8]。这一建议本身不依赖特定 $\varepsilon_0$ 值，但区间的宽度受 $N$ 和 $d$ 共同影响：$d$ 小则区间宽，需要极大 $N$ 才能收窄 [page 5]。这正是全文最核心的实践信息——**在 CSM 中，自由度 $d$ 而非仅仅是样本量，才是决定拟合评估精度的关键杠杆**。
