# 混合模拟与数字波束成形的毫米波大规模天线系统：一篇面向5G的论证分析

**原文题名**：Large-Scale Antenna Systems with Hybrid Analog and Digital Beamforming for Millimeter Wave 5G
**年份**：2015
**DOI**：https://doi.org/10.1109/mcom.2015.7010533

## 论文要解决的问题与核心主张

这篇论文的出发点是一个工程上的两难：大规模天线系统（LSAS）在理论上能通过全数字波束成形（BF）显著提升能量效率（EE）和频谱效率（SE），但在毫米波频段，为每根天线配备独立收发机在实时信号处理、功耗和成本上都不可行，尤其是毫米波混合信号器件的高成本与高功耗 [page 1]。因此作者主张：采用收发机数量远小于天线数量的**混合模拟与数字波束成形结构**，是毫米波大规模天线部署的务实替代方案。

论文聚焦于两种混合结构（Fig. 1 [page 2]）：结构1中每个收发机连接全部天线，结构2（即 N × M 结构）中每个收发机只连接 M 根天线。作者的核心论证围绕结构2展开，因为它的复杂度远低于结构1，而在实际 N 值下容量损失并不显著 [page 3]。论文要回答三个具体问题：与数字BF相比性能差距多大；更大的收发机数 N 是否总带来更好的 EE，以及 EE-SE 最优设计是什么；如何设计高效的参考信号（RS）[page 2]。

## 从容量分析到结构选择

论证的第一步是建立两种结构的容量关系。作者设定 N 个单天线用户、下行信道 H（N × NM）、模拟BF矩阵 A、数字BF矩阵 D，接收信号为 y = HADs + n [page 2]。关键推理是：当 M 足够大时，若把 A 取为 H 的归一化共轭转置，则有效信道 HA 变成对角矩阵且对角元相等，此时可达到 N 用户容量上界，且最优 D 是单位矩阵——也就是说，跨收发机的数字BF其实不再必要 [page 3]。

这一步是全文论证的枢纽。它同时给出了两个结论：结构1能达到与全数字BF相同的容量；结构2也能达到容量上界，但其对角元（即BF增益）只有结构1的 1/N，因此带来大约 N·log₂N b/s/Hz 的容量损失 [page 3]。作者据此判断，在实用 N 下这一损失不显著，从而为后续把分析集中到结构2提供了依据。需要指出的是，这一"不显著"是作者的判断，论文并未给出定量阈值；它依赖于 M 足够大以及用户空间分离良好这两个前提。

## EE-SE 关系的推导与"绿点"概念

论文的第二个论证环节转向能量效率。作者采用一个简化的功率模型：P_total = NP + P_static，其中 P_static = NP₀ + P_common + NM·P_rf_circuit，分别对应随 N 缩放的静态功耗、与收发机数无关的公共功耗、以及随总天线数 NM 缩放的射频电路功耗 [page 3]。基于此，EE-SE 关系写成式(1)：

η_EE = C / P_total = W·η_SE / [N·(2^(η_SE·N/(W·η_PA)) − 1)·... ]（原文公式在抽取文本中排版错乱，此处不逐项复原）

作者强调，引入电路功耗后，EE-SE 曲线上会出现一个"绿点"（green point），即 EE 最大的工作点 η*_EE [page 3]。这是与经典香农理论单调关系的关键区别：纯香农关系下 SE 越高 EE 越低，而考虑电路功耗后存在唯一最优点。

作者进一步推导出绿点处的关系：lg(η*_EE) = −η*_SE·lg2/N + lg(M·η_PA/(N₀·ln2))，即 lg(η*_EE) 随 η*_SE 线性变化，斜率为 −lg2/N [page 3]。一个值得注意的推论是：这一关系与 P₀、P_common、P_rf_circuit、W 无关，尽管 η*_SE 和 η*_EE 本身由这些参数决定 [page 3-4]。作者将此与 [14] 中 MIMO 系统的类似趋势相印证。

## N 如何影响 EE：两个场景的对照

论文最有实践意义的分析是关于收发机数 N 的优化，分两种场景：总天线数固定（NM = L）和 N、M 独立可变 [page 3]。

在固定 NM 场景下，作者证明对任意给定 SE，存在唯一最优 N 使 EE 最大 [page 4]。仿真（Fig. 3 子图1，NM = 500）显示：SE = 20 b/s/Hz 时最优 N = 4，SE = 8 b/s/Hz 时最优 N = 1 [page 4]。在 N、M 独立场景下（Fig. 3 子图2，M = 50），同样存在唯一最优 N，例如 SE = 40 b/s/Hz 时最优 N = 6，但 EE 对 N 更敏感，因为总天线数随 N 增长 [page 4]。

这里有一个重要的实践推论：由于 SE 需求随业务负载变化，系统应按可能 SE 范围设计最大最优 N，再通过收发机开关（transceiver on/off）按需选择最佳 N [page 5]。这是从"存在最优 N"到"如何动态使用"的桥接，属于作者明说的设计建议。

关于绿点 EE 与 N 的关系，作者给出一个反直觉的结果：当 N、M 独立时，更大的 N 总带来更高的 η*_EE；但当 NM = L 固定时，η*_EE(N) 先增后减 [page 5]。Fig. 4 子图1（NM = 800）显示 N 从 1 增到 8 时 η*_EE 上升，从 8 增到 16 时下降，最优 N = 8 [page 5]。这一对照说明"更多收发机总是更好"并不成立，取决于总天线数是否受限。

## 参考信号设计：从模拟BF到混合BF

论文最后一部分处理信道状态信息获取问题。作者指出，TDD 上行探测在 LSAS 中因互易性校准复杂而困难，下行 RS 又因每收发机连接的天线构成一个"逻辑天线"而设计不明 [page 5]。因此论文采用部分信道信息（AoA/AoD）可用的假设 [page 6]。

模拟BF的 RS 设计中，每个收发机通过 M 根天线发一个预定义波束，共 N 个波束，用户反馈最强波束索引。其 AoD 估计精度受限于 N，给定 N 后难以提升 [page 6]。

混合BF的 RS 设计（Fig. 5）则利用 OFDM：所有收发机使用相同模拟BF（主波束方向 φ₀,s），数字BF矩阵 D_k 为对角阵，第 i 个对角元为 exp(ja_i)，通过选择各收发机相移使全部 NM 根天线的和阵列因子在 φ₀ 附近某方向最大化，其最大值是单收发机模拟BF的 N 倍 [page 6]。RS 占据 2K+1 个连续子载波，第 k 个子载波对应 AoD 为 φ₀,s + (K−k)Δ [page 6]。

关键推理在于：在相干带宽内各子载波信道响应相同，因此接收功率差异只来自数字BF权重不同，用户反馈最强子载波索引即可确定 AoD [page 6-7]。由此，混合BF的 AoD 估计精度为 Δ，而模拟BF覆盖同样区域（约 2KΔ）时精度为 2KΔ/N [page 7]。由于 LOS 环境下 2K 可以很大，混合BF的估计精度远优于模拟BF。作者引用 38 GHz 测量结果 [5] 说明 NLOS 环境下相干带宽也可能很大（80% 的 NLOS 链路 RMS 时延扩展低于 20 ns，90% 低于 40 ns），因此大的 2K/N 在 NLOS 下也可能实现 [page 7]。

Fig. 6 的仿真（32 元线阵，N = 4，M = 8）验证了混合BF的阵列增益是单元模拟BF的 4 倍，且主波束方向可通过数字BF在 84°–96° 范围内控制 [page 7]。作者同时指出一个限制：混合BF主波束方向偏离模拟BF主波束方向越远，增益越小，因此波束覆盖范围有限 [page 7]。

## 结论成立的条件与边界

综合来看，论文的核心结论——混合BF结构能在显著降低收发机数量的同时接近最优容量，并存在可优化的 EE-SE 工作点——依赖若干明确或隐含的条件：

**M 足够大**是容量上界可达的前提。作者在结构1和结构2的分析中都明确写出"当 M 足够大时" [page 3]。当 M 不够大时，HA 无法成为理想对角阵，容量上界不再可达。

**用户空间分离良好**是零用户间干扰假设的基础。作者承认这需要"足够大的 M 或适当的用户调度"，并给出 50 元半波长线阵波束宽度可小至 2°、调度 N = 10 用户不难的例子 [page 3]。但作者也指出当 M 很小时（如 N > 10 对应 M 很小）用户调度困难，因此 Fig. 3 未展示 N > 10 的情况 [page 4]。

**功率模型的简化**是 EE 分析的主要局限。作者明确承认基站类型多样、厂商实现各异，精确功率模型不易获得，因此采用简化模型 [page 3]。这意味着绿点位置和最优 N 的具体数值依赖于该模型，实际部署中需要重新标定。

**信道增益假设为 1**（后文仿真中设为 −100 dB）以及**完美模拟BF**的假设 [page 3]，都是理想化处理。作者在结论中承认未来工作需要研究 W、P₀、P_rf_circuit、P_common、天线间距等参数对最优 N、M 的影响 [page 8]。

**结构2的联合最优 D 和 A 设计仍是开放问题** [page 3]，论文给出的是 M 足够大时的渐近最优解，而非任意 M 下的最优解。

此外，论文的 RS 设计分析假设了 LOS 或相干带宽足够大的环境，虽然作者用测量数据论证 NLOS 下也可能成立，但这一推广仍属推断而非确证 [page 7]。

## 论证的整体逻辑与遗留问题

这篇论文的论证链条可以概括为：毫米波频段使 LSAS 物理尺寸可行，但全数字BF的收发机成本不可接受 → 混合BF结构以少量收发机换取接近最优的容量 → 在简化功率模型下，EE-SE 曲线存在唯一绿点，且对给定 SE 存在唯一最优 N → 因此系统应按业务负载动态开关收发机以逼近绿点 → 混合BF的 RS 设计通过数字BF在子载波上的相位控制，实现比模拟BF更精细的 AoD 估计。

其中最关键的一步是从"HA 可对角化"到"结构2容量损失为 N·log₂N"的推导 [page 3]，它决定了结构2是否值得采用。而最具实践约束力的一步是从"存在最优 N"到"通过收发机开关动态选择 N"的建议 [page 5]，它把静态优化转化为可操作的系统策略。

论文遗留的主要问题包括：任意 M 下结构2的联合最优设计、更精确的功率模型、以及 RS 反馈机制和帧结构等协议层面的设计 [page 8]。这些都被作者列为未来工作，说明本文的结论是面向设计方向的论证，而非可直接落地的完整方案。
