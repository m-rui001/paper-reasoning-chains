# 硫键相互作用的本质：分子天平如何把“σ-空穴”争论推向轨道离域

**The Origin of Chalcogen-Bonding Interactions**（2017，DOI: 10.1021/jacs.7b08511）

## 一个被晶体学反复看到、却说不清来源的接触

硫、硒这类第16族元素本身富电子，按直觉不该彼此亲近；但晶体结构中硫–硫、硫–氧接触出现得如此频繁，以至于它们被命名为“硫键”（chalcogen bond），并被归入“σ-空穴相互作用”这一大家族——后者最著名的成员是卤键 [page 1]。问题在于，这类相互作用在溶液中的能量意义和物理来源一直有争议：一种观点把它归因于σ-空穴带来的静电势，另一种则强调色散或轨道离域。作者在引言里明确把这场争论摆出来，并指出定量实验证据稀缺，原因之一是弱相互作用在溶液中难以测量，且溶剂效应本身可能主导实验行为 [page 1]。

这篇论文的策略不是继续做计算或晶体学统计，而是用合成分子天平（molecular balance）把硫键“装进”一个可测的构象平衡里，再用一系列对照把静电、疏溶剂、色散逐一排除，最后把剩余的实验趋势与计算出的轨道能量对上。核心结论是：这些硫键相互作用主要由（硫）酰胺孤对电子向噻吩/硒吩的 σ* 反键轨道的 n → σ* 离域所主导，而且这种稳定化出人意料地不依赖溶剂 [page 1, page 6–7]。

## 分子天平：把弱相互作用变成可积分的构象比例

分子天平的工作原理是：一个分子存在开式和闭式两种构象，闭式构象中额外形成一个待研究的分子内接触，构象平衡的位置就反映了这个接触的净能量，同时叠加溶剂竞争效应 [page 2]。本文的天平基于此前研究氢键和溶剂效应的骨架改造而来，闭式构象容纳硫键，开式构象则没有 [page 2]。由于（硫）甲酰胺的旋转在室温下对 NMR 时间尺度是慢的，两种构象的 ^19F NMR 信号可以分别积分，直接给出平衡常数 K，进而得到构象自由能差 ΔG_EXP = −RT ln K [page 2]。

作者合成了涵盖 O···S、O···Se、S···S 以及作为对照的 O···HC、S···HC 接触的一系列化合物，并在 **13 种不同溶剂**中测量了 **超过 160 个实验构象自由能** [page 1, page 2]。1a-Cl 的 X 射线晶体结构和 DFT 计算确认 α-取代的 1a、2a 系列在闭式构象中确实容纳硫–硫接触；而 β-取代的噻吩（1b 系列、2b）在闭式中无法形成直接的硫–硫接触，被设计为对照 [page 2]。构象归属通过 HMBC/NOESY NMR 以及实验与计算构象比例的比较完成 [page 2]。

这里有一个值得注意的对照设计：α-噻吩能形成直接 O···S 接触，β-噻吩不能，但两者仍可能通过 C=O···H−C 接触稳定闭式构象。这个对照后来成为论文最关键的论证转折之一。

## 实验趋势：强度可比氢键，却几乎不随溶剂变化

1a 和 1c 系列的所有化合物都偏好闭式构象，即形成 O···S 或 O···Se 接触，ΔG_EXP 在约 −7.4 到 −1 kJ mol⁻¹ 之间 [page 2]。作者指出，这一偏好程度与结构相关的分子天平中测得的 OH···O=C 氢键相当 [page 2]。噻吩取代基对 O···S 偏好的影响遵循 Me < H < Cl < COOMe < COMe < CHO 的趋势 [page 2, Figure 2]。值得注意的是，1c 中的 O···Se 接触比 1a-CHO 中的 O···S 接触略更有利，尽管硒吩环上空间位阻更大且没有吸电子基团 [page 2]。

对照结果符合预期：不能形成 O···S 接触的 β-噻吩 1b-H 和 1b-CHO，其闭式偏好弱于对应的 α-噻吩 1a-H 和 1a-CHO [page 2]。硫代甲酰胺 2a-Me、2a-H、2a-Cl 的闭式偏好比同等取代的 1a 系列低约 1.5 kJ mol⁻¹ [page 2]。计算显示，1a 和 1c 系列的最小化结构含有平面的 O···S 或 O···Se 接触，而类似的平面 S···S 接触只在 2a-Cl 中出现；β-噻吩 1b 系列计算为平面结构，容纳 C=O···HC 接触，而对应的 β-硫代甲酰胺 2b 则采取螺旋桨式构象 [page 2]。

真正让作者意外的是溶剂依赖性。Figure 2 显示，偏好闭式构象的天平在甲醇-d4、二甲基亚砜-d6 这类强氢键溶剂中，与二硫化碳、苯-d6 这类极弱极性溶剂中测得的构象自由能几乎相同 [page 2]。唯一显著的变化出现在全氟叔丁醇中：它作为强氢键给体，能与甲酰基羰基竞争氢键，使构象自由能向开式移动约 2 kJ mol⁻¹ [page 2, Figure 2 底部]。作者强调，这与结构类似的甲酰胺分子天平中氢键和芳香相互作用强烈依赖溶剂氢键给受能力的情况形成鲜明对比 [page 2]。由此他们推断，本文的硫键相互作用没有实质性的疏溶剂、静电或偶极来源 [page 2]。作者也承认这些天平不溶于水，但鉴于溶剂无关性似乎具有普遍性，他们推测水溶液中可能有类似的构象偏好——这是一个明确标注为推测的推断 [page 2–3]。

## 排除色散：溶剂极化和色散校正计算的双重检验

排除了静电和疏溶剂之后，作者转向范德华色散力。逻辑是：低体相极化率的溶剂应该有利于闭式构象，因为这样可以把可极化的 S、Se 原子埋起来，减少与溶剂的色散竞争；高极化率溶剂则应有利于开式构象 [page 3]。但 Figure 2 显示，高极化率溶剂二硫化碳与低极化率溶剂甲醇-d4 中测得的构象自由能差异可以忽略 [page 3]。而体相极化率最低的全氟叔丁醇，如果色散力显著，本应有利于闭式构象，实际却把平衡推向开式——作者解释为甲酰基氧被氢键溶剂化在能量上比残余色散差异更重要 [page 3]。

第二条证据来自计算。作者把实验构象自由能与气相 DFT 计算的构象能 ΔE_CALC 做相关：不含色散校正的 B3LYP 给出最佳相关（R² = 0.94，Figure 3A），而含色散校正的 M06-2X 和 ωB97X-D 相关明显更差（R² = 0.88 和 0.84，Figure 3B,C）[page 3–4]。使用 SM8 隐式溶剂模型模拟氯仿也没有改善相关系数 [page 3, Figure 3 图注]。作者据此判断，色散力差异对控制构象自由能的硫键相互作用贡献可以忽略 [page 4]。

这里需要留意推理的边界：R² 的差异是相关性证据，不是直接的因果分解。作者把“不含色散校正反而相关更好”与“溶剂极化率无关”两条独立证据合起来支持色散贡献可忽略，这一论证是合理的，但它依赖于所选用泛函和计算方案的代表性。作者在 SI 中提供了替代方法的对照，正文只报告了主结果。

## 关键一步：从轨道能量到实验自由能的定量对应

排除三类主要竞争解释后，作者转向轨道离域。他们先做几何优化，比较开式和闭式构象中特定轨道的能量，假设稳定闭式构象的轨道相互作用会表现为闭式中某些轨道能量更低 [page 4]。为避免芳香电子正则共振形式造成的轨道分裂干扰，他们把氟苯基替换为质子，在保留完整天平几何的单点计算中分析片段 [page 5]。

Figure 4A 中，绝大多数轨道落在灰色背景线附近，表示开闭式能量差异很小；低于背景线的数据分两组：橙色对应酰胺孤对电子向共平面芳香体系的共振离域，只出现在平面闭式构象中（Figure 4B）；青色对应酰胺另一个正交孤对电子向相邻噻吩（或硒吩）S–C（或 Se–C）σ 键的离域，即 n → σ* 轨道相互作用（Figure 4C,D 和 Figure 5C,D）[page 5]。

作者进一步把天平片段分解为（硫）甲酰胺和噻吩（或硒吩）组分，确认这些离域轨道确实来自一个高能占据孤对轨道（Figure 5A）与一个能量更高的未占据反键分子轨道（Figure 5B）的杂化 [page 5]。分解分析还显示，无论 α/β 连接方式或噻吩环取向如何，都是同一组分子轨道在稳定甲酰胺孤对电子（Figure 5C,D）[page 5]。NBO 分析也揭示了直接硫–硫接触处存在 n → σ*_{S−C} 和 n → σ*_{Se−C} 离域的潜力，而 β-连接噻吩中则存在较弱的 n → σ*_{C−S}、n → σ*_{H−C} 和 n → σ*_{C−C} [page 5]。

几何上，闭式构象中与（硫）酰胺接触对齐的键确实发生伸长（Figure 6 蓝色键），但伸长程度与实验构象自由能不相关，因为电子密度变化也受相邻 X、Y 取代基调制，吸电子取代基处也出现键伸长（Figure 6 紫色键）[page 5]。这说明键长变化本身不能作为定量证据。

真正的定量关系出现在 Figure 7A：含有 n → σ* 离域的分子轨道能量与实验构象自由能之间相关极强，R² = 0.99 [page 6]。更关键的是，直接硫–硫接触和硫···H−C 接触的数据点落在同一条相关线上（青色和黑边点）[page 6]。作者认为这支持同一个 σ* 受体轨道参与了两类接触，无论噻吩环的取向或连接方式如何 [page 6]。与先前建议相反，β-连接噻吩是比同等取代的 α-连接变体更弱的孤对电子受体 [page 6]。作者谨慎地补充，这种相对受体能力可能不具普遍性，可能受分子内体系几何约束影响 [page 6]。硒吩天平 1c 是离群点，表明该相互作用比 O···S 和 S···S 更有利 [page 6]。相比之下，共振离域轨道能量（Figure 7B）和其他分子轨道与实验数据不形成良好相关 [page 6]。

作者也报告了一个负面结果：NBO 计算输出的 n → σ* 离域能量与实验构象自由能不相关（Figure S22 和 Table S45）[page 6]。他们解释 NBO 的局限在于难以赋予其直观物理意义，因此转而比较物理相关的分子轨道能量 [page 6]。这个转折值得注意：它说明作者并非简单地把“轨道离域”当作口号，而是明确区分了哪种轨道描述能与实验定量对应。

## 结论成立的条件与边界

论文的核心主张是：在这些分子天平体系中，硫键相互作用主要由 n → σ* 轨道离域主导，而非静电、疏溶剂或色散 [page 6–7]。这一结论的力度来自多重排除加一条强定量相关，但它的适用范围有明确边界。

首先，结论建立在特定分子内体系上。作者自己指出，β-连接噻吩的相对受体能力可能受几何约束影响，不一定普遍 [page 6]。其次，所有实验都在非水溶剂中进行，作者对水溶液的推测是明确标注的推断 [page 2–3]。第三，Figure 7A 的 R² = 0.99 是轨道能量与实验自由能之间的相关，作者将其解释为 n → σ* 离域主导的证据，但相关本身不排除其他因素与轨道能量共变；作者的论证力量来自此前对静电、疏溶剂、色散的独立排除，而非单一相关系数。第四，NBO 离域能量与实验不相关这一负面结果，提示“轨道离域”的定量表述方式会影响结论，作者选择分子轨道能量作为与实验对应的量，这一选择本身是论证的一部分。

作者在结论脚注中明确限定：这些发现排除了纯静电模型，但至少定性上可能与“静电加极化”模型兼容 [page 7, 脚注 81]。这是一个重要的自我限定——论文反对的是把硫键简单归因于静电，而不是否认静电在更完整模型中可能仍有位置。

最后，论文的标题和登记信息一致，未发现题名疑点。整体而言，这篇工作把硫键争论从“哪种力更重要”的定性讨论，推进到一个可测量、可对照、可计算对应的实验框架中；其最有启发的转折或许不是“轨道离域赢了”，而是作者展示了如何用溶剂无关性、色散校正的负相关和同一受体轨道的跨接触对应，把多个竞争解释逐一压缩到剩余的那个。
