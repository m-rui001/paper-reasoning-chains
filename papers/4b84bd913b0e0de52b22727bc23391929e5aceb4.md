# 用双功能分子调控钙钛矿表面终止：从缺陷钝化到 23.37% 反式电池效率

**原文题名**：Regulating Surface Termination for Efficient Inverted Perovskite Solar Cells with Greater Than 23% Efficiency
**年份**：2020（J. Am. Chem. Soc.，DOI: 10.1021/jacs.0c09845）

## 论文要解决的问题与核心主张

这篇工作针对的是有机—无机卤化物钙钛矿（OIHPs）表面缺陷导致的非辐射复合损失。作者的基本判断是：钙钛矿表面的晶格干扰和原子周期性扰动比体相更严重，会产生大量非辐射复合中心，其中欠配位的 Pb²⁺ 和卤素位点是主要陷阱来源 [page 1]。现有钝化分子大多只能钝化正电荷或负电荷缺陷中的一种，能同时钝化 Pb²⁺ 和卤素陷阱的分子很少 [page 2]。

作者的核心主张是：设计一种在同一六元环上同时含有中性 R₂NH 和 R₂NH₂⁺ 的双功能分子——哌嗪碘盐（piperazinium iodide, PI），让它同时充当电子给体和电子受体，分别与钙钛矿表面不同的终止基团反应，从而同时钝化两类缺陷，释放表面残余应力，抑制非辐射复合，最终把反式（p-i-n）电池效率推到 23.37%（认证 22.75%），并将开路电压损失降至 0.33 V [page 1, page 2]。

## 从单晶模型到表面化学：PI 如何与 Pb²⁺ 结合

论证的第一步是证明 PI 中的中性 R₂NH 确实能与 Pb²⁺ 发生强相互作用。作者没有直接在器件上验证，而是先长出单晶模型化合物 (PI)₂PbI₂·2DMSO 和 (PDI)₂PbI₂（PDI 为哌嗪二碘盐，含两个 R₂NH₂⁺，作为对照）[page 2]。在 (PI)₂PbI₂·2DMSO 中，R₂NH 的孤对电子取代一个卤素与 Pb 成键，形成键长 2.80 Å 的 Pb−N 键，说明中性 R₂NH 与 Pb²⁺ 之间有强化学作用（Figure 1c）[page 2]。而 (PDI)₂PbI₂ 则形成 0D 结构，PbI₆⁴⁻ 被完全隔离，与 MAPbI₃/FAPbI₃ 的 3D 结构截然不同（Figure 1d）[page 2]。

¹H NMR 提供了独立佐证：PI 与 PbI₂ 混合后，R₂NH 与 Pb²⁺ 的强相互作用压过了质子交换，给出更明确的信号；而 PDI 加 PbI₂ 后谱图变化很小（Figure 1e,f）[page 2, page 3]。这一步的关键推理是：单晶和 NMR 共同证明 PI 的中性 R₂NH 具有 PDI 所没有的 Pb²⁺ 配位能力，为后续"双功能"主张提供了分子层面的基础。

## 表面处理后的化学与结构证据

XPS 用于验证 PI 在钙钛矿薄膜表面的实际作用。N 1s 谱中，FA⁺/MA⁺ 的 C−N（400.7 eV）和 C−NH₂⁺（402.4 eV）在 PI 处理后分别移至 400.5 和 402.2 eV，作者归因于 FA⁺/MA⁺ 与 PI 的 R₂NH 之间形成 N−H···N 氢键；PDI 处理后则无位移（Figure 2b）[page 3]。Pb 4f 谱中，PI 处理后峰位向高结合能移动超过 400 meV（143.8 和 138.9 eV），与 R₂NH 成键一致；同时 Pb⁰ 峰面积在 PI 和 PDI 处理后都显著下降（Figure 2c）[page 3, page 4]。这里需要注意：Pb⁰ 减少被解释为碘和阳离子空位被抑制，但 XPS 只能说明表面化学环境变化，不能直接给出缺陷密度的定量值。

GIWAXS 和 GIXRD 进一步显示，PI 和 PDI 处理后 (101) 环强度更高，结晶性更好；而 |q| = 0.88−0.94 Å⁻¹ 处的过量 PbI₂ 信号仅在 PI 处理后消失（Figure 3a−d）[page 4]。作者将此与单晶和 XPS 结果串联，认为 PI 与 PbI₂ 的强相互作用消耗了表面残余 PbI₂。这一推理链条是自洽的，但 PbI₂ 消失也可能与溶剂冲洗或表面溶解有关，论文未做区分。

## 应力释放：一个可量化的中间结论

作者用 GIXRD 的 2θ−sin²φ 方法定量分析表面残余应力，选取 (012) 晶面（31.6°）作为目标 [page 4]。拟合结果显示，参考膜的残余拉伸应力为 61.57 ± 6.92 MPa，PI 处理后降至 27.54 ± 2.16 MPa，PDI 处理后为 40.15 ± 3.89 MPa（Figure 3h）[page 4]。作者的解释是：R₂NH₂⁺ 插入 A 位空位、R₂NH 与欠配位 Pb²⁺ 反应，共同调控表面终止并释放应力 [page 4]。

这一步是论证的关键转折之一：应力释放本身是一个独立于器件效率的可测量量，它把"分子与表面反应"和"器件性能提升"之间的因果链补上了一环。但需要指出，应力降低与缺陷钝化之间的因果方向在文中并未严格区分——两者可能互为因果，也可能共同由表面化学变化导致。

## 复合抑制与载流子寿命

PL 和 TRPL 提供了复合抑制的直接证据。PI 和 PDI 处理后 PL 强度分别约为参考膜的 5 倍和 3 倍（Figure 4a）[page 4]。TRPL 双指数拟合给出的平均寿命 τavg 分别为：参考膜 305 ns、PI 处理 1948 ns、PDI 处理 1461 ns（Figure 4b）[page 4]。SCLC 测得参考膜陷阱密度约 2.54 × 10¹⁶ cm⁻³，PI 和 PDI 处理后分别降至 8.4 × 10¹⁵ 和 1.64 × 10¹⁶ cm⁻³ [page 5]。共聚焦 PL  mapping 显示 PI 处理后整体 PL 强度显著提升且分布更均匀，PL 峰位分布变窄，说明表面相分离被抑制（Figure 4c−e）[page 5]。

这些数据共同支持"PI 比 PDI 更有效地抑制非辐射复合"这一结论。但要注意，PL 强度和寿命的提升是复合减少的间接指标，不能直接等同于缺陷密度下降；SCLC 的陷阱密度测量基于单载流子器件，其数值受器件结构、注入条件和拟合模型影响，论文未给出误差范围。

## 能带调控与 n 型特征

UPS 显示 PI 处理后价带顶向真空能级移动 180 meV，费米能级向导带底移动 350 meV（Figure S11）[page 5]。作者将此解释为 PI 处理后薄膜呈现更强的 n 型特征，可能源于表面终止的改变；PI 的偶极取向背离表面，暴露电正性的铵端基，在钙钛矿与电子传输层之间形成能带弯曲，有利于电荷转移 [page 5]。这一部分论证相对薄弱：UPS 只给出能级位置，n 型特征的判断依赖费米能级相对位置，而表面偶极取向的直接证据（如开尔文探针或表面电位测量）在正文中未呈现。

## 器件性能与电压损失分解

器件结构为 ITO/PTAA/perovskite/C60/BCP/Ag（Figure 5a）[page 5]。参考器件 PCE 20.76%（平均 19.67%），VOC 1.06 V，JSC 24.93 mA cm⁻²，FF 78.57%；PDI 处理后 PCE 21.98%（平均 21.31%），VOC 1.13 V，但 JSC 下降，作者推测可能形成低维钙钛矿阻碍电荷传输；PI 处理后 PCE 23.37%（平均 22.26%），VOC 1.17 V，FF 80.17%，JSC 24.92 mA cm⁻²，迟滞可忽略（Figure 5b−d）[page 5]。独立认证效率 22.75%，JSC 24.68 mA cm⁻²，VOC 1.16 V，FF 79.16%（Figure S13）[page 5]。EQE 积分电流 24.18 mA cm⁻²，与 J−V 曲线吻合（Figure 5e）[page 5]。最大功率点稳定输出 22.88%（Figure 5f）[page 5]。

电压损失用细致平衡理论分解为三部分 [page 6]：

- ΔV₁（Eg 以上辐射复合）：参考、PI、PDI 分别为 265.15、264.61、265.11 mV，基本不变。
- ΔV₂（亚带隙黑体辐射）：参考 27.37 mV，PI 2.73 mV，PDI 12.46 mV，由高灵敏 EQE 计算（Figure 6a）。
- ΔV₃（非辐射复合）：由 ΔV₃ = (kBT/q) ln(EQEEL) 计算，参考器件 EQEEL 0.55% 对应 134.35 mV，PI 处理器件 EQEEL 9.77% 对应 60.13 mV（Figure 6b）。

总 VOC 损失降至 0.33 V（Figure 6c, Table S5）[page 6]。这一分解的论证力度在于：ΔV₃ 直接由电致发光量子效率导出，是 nonradiative 复合的独立测量，不依赖 PL 或 TRPL 的间接推断。ΔV₂ 的降低（27.37 → 2.73 mV）幅度较大，作者将其归因于亚带隙吸收的减少，但高灵敏 EQE 在低信号区的测量精度和拟合方法在正文中未详述，这一数值的可靠性需要谨慎对待。

## 稳定性与结论的边界

稳定性方面，封装器件在潮湿空气（RH 55 ± 5%，25 °C）中保持初始效率的 93%，参考器件降至 40%；连续光照 200 h 后 PI 处理器件保持 98% 以上，参考器件降至 87% [page 6]。这些数据支持 PI 处理同时提升稳定性，但测试条件（封装方式、光照强度、温度控制）在正文中描述较简，无法判断是否满足标准稳定性测试协议。

作者在结论中重申：PI 的双功能设计同时提升效率和稳定性，VOC 损失 0.33 V 为目前已报道的最低值之一 [page 6]。这一结论的成立依赖于几个条件：单晶模型确实能代表真实钙钛矿表面；XPS、GIWAXS、PL、TRPL、SCLC、UPS 和电压损失分析共同指向同一机制；器件制备和认证过程可重复。论文未讨论的限制包括：PI 处理对大面积器件均匀性的影响、长期光照下分子本身的稳定性、以及 R₂NH 与 Pb²⁺ 配位是否在器件工作条件下保持。此外，PDI 处理后 JSC 下降的原因（低维钙钛矿形成）仅为推测，未提供结构证据。

总体而言，这篇论文的论证链条从分子设计出发，经单晶模型、表面化学、应力释放、复合抑制、能带调控到器件性能和电压损失分解，逐步推进，关键推理环节有独立实验支撑。最有力的证据是单晶中 Pb−N 键的直接观测和 ΔV₃ 由 EQEEL 导出的定量结果；相对薄弱的是 UPS 对 n 型特征的推断和 ΔV₂ 的测量精度。结论在作者所测试的特定钙钛矿组分（Cs₀.₀₅(FA₀.₉₅MA₀.₀₅)₀.₉₅Pb(I₀.₉₅Br₀.₀₅)₃）和器件结构下成立，向其他组分或更大面积器件的推广需要额外验证。
