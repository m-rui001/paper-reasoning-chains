# 相位退火如何提升大结构直接法的求解概率：对 SHELX-90 论证的解析

**原文题名**：Phase Annealing in SHELX-90: Direct Methods for Larger Structures
**作者**：George M. Sheldrick，*Acta Cryst.* (1990). A46, 467–473
**DOI**：https://doi.org/10.1107/s0108767390000277

## 一、作者要解决什么问题

这篇论文的目标很具体：把晶体学相位问题中的多重解方法（multisolution approach）扩展到更大的"小分子"结构上。作者开篇即指出，MULTAN 式的数值多重解方法已参与至少 70% 的小分子结构测定 [page 1]，但当结构变大时，每找到一个正确解所需的计算机时间急剧上升，问题被比作"大海捞针" [page 3]。

作者把遗留的困难归为三类 [page 2–3]：赝对称问题（多个非等价解具有相近的品质因子）、分辨率问题（经验规则：在 1.1–1.2 Å 范围内可测反射中若"观测到"的不足一半，直接法几乎无望），以及大结构问题。本文的贡献集中在第三类。

核心主张是：一种借鉴模拟退火（simulated annealing）思想的"相位退火"（phase annealing）方法，可以在原子分辨率下把求解大结构的机会提升最多一个数量级 [page 1]。这一主张最终由七个测试结构的统计实验支撑（Tables 2、3）。

## 二、论证的起点：SHELXS-86 已有的机制

要理解相位退火为何必要，先要理解作者此前程序的做法。SHELXS-86 采用随机起始相位，并在修正的切公式（tangent formula）中同时纳入三相位关系（TPR）和负四重关系（NQR）[page 1]。修正公式写作

new φ_h = phase of [α⁻¹η]

其中 α 与 η 都是复数，N 为每个（初基）晶胞中的原子数（此处假定相等）[page 1]。NQR 的特征是四个主项 E 值大、三个交叉项 k−h、l−b、k+l 的 E 值小 [page 1]。作者强调，只应使用三个交叉项都被测量且确为弱的四重关系，并把 NQR 总数限制在最可靠的前 1000 至 8000 个（视结构大小与空间群类型而定）[page 1]。

这里有一个关键的诊断工具。作者不用常见的 NQEST，而用 α 与 η 的相关性

NQUAL = Σ|α·η| / Σ|η|

并报告 NQUAL 对大结构比 NQEST 更负、更敏感，因为对给定 h，参与求和的 NQR 数目更多，可在相当程度上补偿概率表达式中的 1/N 项 [page 2]。品质因子最终由 R_α 与 NQUAL 组合成 CFOM：当 Q > NQUAL 时 CFOM = R_α，否则 CFOM = R_α + (NQUAL − Q)²，其中 Q 通常取比预期 NQUAL 再负约 0.1 的值 [page 2]。

作者还引入一个针对非中心对称结构的技巧：保留单位权重，但把 α 投影到其期望值 ⟨α²⟩¹ᐟ² 上，对纯切公式相位 φ 施加一个 δφ 修正，δφ 的符号由使结果与 NQR 求和最一致来决定（若无 NQR 贡献则随机取号）[page 2]。作者明确说这一技术"只能用于非中心对称结构"，但非常有效地把解驱向小的 R_α 和负的 NQUAL [page 2]。

## 三、为什么需要退火：从"过滤"失败说起

SHELXS-86 曾用两阶段策略节省时间：第一阶段用约一半反射，按品质因子只把最好的（比如）10% 相位集送入第二阶段 [page 3]。对简单测试结构这确实降低了平均求解时间，但对大结构，它常常反复得到同一个错误解 [page 3]。

作者给出两种解释，这是全文推理的关键转折。其一，正确解在第一阶段结束时的品质因子可能根本排不进前 10%。其二——也是更本质的——若把相位修正视为某个目标函数的极小化，则"假极小通常比真极小更宽但更浅"，因为偶然解的各相位关系不太可能让各自的极小如此紧密同相 [page 3]。由此推出一个反直觉的结论：如果极小化过程无法逃出极小，那么随机起始相位落入"宽而浅"极小吸引域的概率，反而大于落入"窄而深"极小的概率 [page 3]。这正是需要引入"动能"来帮助系统逃离宽浅极小的理由。

## 四、相位退火的构造

作者借用 Kirkpatrick 等人的模拟退火框架 [page 3]，并把它落到直接法上。对中心对称结构，Cochran–Woolfson 公式给出

P₊ = ½ + ½ tanh(α/2)

其中 P₊ 是 E_h 取 α 符号的概率。对正的 α，P₊ 度量较低能态的概率，P₋ = 1 − P₊ 是较高能态的概率，于是 Boltzmann 比为

P₋/P₊ = exp(−α)

因此只需把 α 乘以 β，即一个与温度成反比的控制变量 [page 4]。作者采用 Metropolis 算法的一个变体：只有当 (P₋/2P₊)（必小于 ½）大于 0–1 之间的随机数 R 时，才取较高能态，否则取修正切公式给出的较低能态相位 [page 4]。

对非中心对称结构的一般相位，作者在修正切公式（或当 α > ⟨α²⟩¹ᐟ² 时用投影法）得到的相位上加上 Δφ，其中

cos(Δφ) = [4/3α + ln(R)] / [4/3α − ln(R)]

Δφ 的符号随机指定，R 为 0 到 1 之间的随机数 [page 4]。作者明确声明这个公式"纯粹是经验性的"，数值因子 4 是为了让一般相位与限制相位在相位测定开始（随机相位）时具有相近的平均绝对相移 [page 4]。

两个极限情形界定了方法的边界：β 无穷大（T = 0）时，相位退火精确对应于上述修正切公式的相位修正；β 为零（T 无穷）时，相位保持随机（无约束最大熵）[page 4]。作者由此给出直观图像：缓慢降温时，α 大的明确相位波动小于 α 小的相位，因此由强相位关系联系的相位会更早确立，其余相位仍可自由探索相位空间 [page 4]。

## 五、证据：CFOM 分布与求解率

**Table 1** 给出 loganin 测试结构在恒定"温度"下 50 与 250 个退火循环后的 CFOM 分布 [page 4–5]。B = 0（对应 T = 0）时正确解与其余解清晰分离，但正确解数目在 50 到 250 循环之间只略有增加——作者据此指出，把切公式修正视为纯粹极小化是过度简化 [page 4–5]。随 B 增大，所有 CFOM 值升高，正确解比例随循环数增长；当 B = 0.3 或更高时，由于所有 CFOM 值都高（高动能），已无法区分正确解 [page 5]。此外，分布逐循环的涨落随 B 明显增大 [page 5]。

**Table 2** 列出七个测试结构的参数与最终品质因子 [page 5]。结构从 54 到 340 个原子/晶胞，涵盖 P2₁2₁2₁、P1、Pc、R3(hex) 等空间群。表中区分了相位退火阶段与完整阶段的反射数 n(E)、TPR 数、NQR 数，以及最终 R_α、NQUAL 和每个相位集的时间。作者说明 n(E) 由基于晶胞体积和空间群的经验算法自动选取，所有可用 TPR 都被使用，但 n(NQR) 在某些情形被限制 [page 5]。

**Table 3** 是核心的定量证据：在 25 个循环、每循环温度乘以 0.95、随后 3–4 个相位修正循环的冷却计划下，每 10000 次尝试中正确解的数目随初始 Boltzmann 因子 B 变化 [page 5]。结果可归纳为：

- B = 0 时，各结构正确解数从 PEP1 的 1 到 MBH2 的 469 不等；
- B 在 0.2–0.4 区间总体表现最好，且"B 的精确值并不十分关键" [page 6]；
- 对最大结构 PEP1，相位退火把找到正确解的机会提升超过一个数量级 [page 6]；
- 对 P1 结构 MBH2，相位退火带来的解数增加仅够补偿额外计算时间 [page 6]；
- 其余六个结构都获得显著收益 [page 6]。

作者还报告了一项负面/边界结果：对 P2₁2₁2₁ 的三个结构，在相位退火阶段去掉 NQR 后结果总是不如 Table 3，但对 PEP1 差异不显著 [page 6]。作者预期 NQR 随结构增大而相对更不可靠，因为概率表达式中 NQR 含 1/N 项而 TPR 含 1/N¹ᐟ² 项；但 NQR 对对称型（symmorphic）空间群是必需的 [page 6]。

## 六、关键推理步骤与省略的桥接

从证据到结论，最关键的一步是把"假极小更宽更浅"这一关于目标函数地形的假设，与"随机起始相位更易落入宽浅极小"这一概率论证连接起来，从而说明为什么需要引入受控噪声（动能）而非单纯极小化。这一步是作者明说的 [page 3]，但它依赖一个未在文中严格证明的前提：相位修正确实对应某个可快速计算的目标函数的极小化。作者自己对此保持谨慎，用"if we assume that phase refinement corresponds to the minimization of some target function" [page 3] 引出该论证，并在讨论 T = 0 时指出"正确解不一定对应任何可快速计算的函数的全局极小" [page 4]。因此，退火有效的理由更多是启发式类比而非严格定理。

另一处需要读者补足的桥接是：Table 3 的"正确解数/10000 次"如何转化为"求解机会提升一个数量级"。作者用 PEP1 的对比直接给出这一量级判断 [page 6]，但该判断依赖"正确解可被品质因子清晰识别"这一前提——作者在定义"正确解"时明确要求 (a) CFOM 清晰分离、(b) 傅里叶循环后所有原子峰高于任何杂峰 [page 6]。对 PEP1，判据 (b) 被放宽，因为一个苯环和溶剂分子热运动显著：典型最终图中 80 个预期非溶剂原子有 78 个落在前 80 个峰内，约一半溶剂也出现在峰表中 [page 6]。这意味着 PEP1 的"正确解"计数带有一定宽松度，读者在解读"一个数量级"时应保留这一限定。

## 七、结论成立的条件与边界

综合全文，相位退火结论的适用条件可归纳如下（均为原文明说或直接蕴含）：

1. **分辨率前提**：方法建立在"原子已分辨"的假设上；若 1.1–1.2 Å 范围内观测反射不足一半，直接法很可能失败，此时分子置换可能是替代途径 [page 2–3]。
2. **空间群依赖**：NQR 对对称型空间群是必需的；在极性空间群中，较小的初始 B 略优，且退火循环数可减少 [page 6]。
3. **结构规模的双刃性**：NQR 随结构增大相对更不可靠（1/N 对 1/N¹ᐟ²），但相位退火对最大结构收益最大 [page 6]。
4. **B 的鲁棒区间**：初始 B 在 0.2–0.4 是良好通用策略，精确值不关键；B 过高（≥0.3 在恒温实验中）会使 CFOM 无法区分正确解 [page 5–6]。
5. **多重起始集仍不可少**：由于正确解不一定对应任何可快速计算函数的全局极小，多相位起始集仍是"必要条件"（sine qua non）[page 4]。
6. **计算实现**：方法适合向量化，作者以 M = 128 个相位集并行处理；在 IBM-3090 300E 上向量化版本对关键循环快约 3.7 倍、对完整求解快约 3.0 倍 [page 5]。

作者承认的局限还包括：冷却计划本可针对每个结构调优，但那需要预先知道结构 [page 6]；对 P1 结构 MBH2，收益仅够抵消额外时间 [page 6]。此外，作者报告相位退火已成功求解八个此前用包括 SHELXS-86 在内的多种程序均失败的大结构，最多达不对称单元 180 个原子 [page 6]——这是支持性但非受控的案例证据。

## 八、小结

这篇论文的论证结构是：先确立 SHELXS-86 的 NQR 修正切公式与品质因子体系，再通过两阶段"过滤"策略在大结构上的失败，引出"假极小更宽更浅"的地形论证，进而把模拟退火的 Metropolis 机制映射为对 α 乘以温度控制变量 β 的操作，最后用七个结构的 CFOM 分布（Table 1）和求解率统计（Tables 3）证明相位退火在 B ≈ 0.2–0.4 时显著提升大结构的求解概率。其结论的力度受限于若干经验性构造（非中心对称的 Δφ 公式被作者自称为"纯粹经验性"）、"正确解"判据的宽松度（尤其 PEP1），以及退火有效性的启发式而非严格基础。方法在原子分辨率、NQR 可用、且愿意以多重起始集换取探索能力的前提下成立；对 P1 等赝对称严重的情形，收益可能仅够抵消成本。
