# 用醋酸盐阴离子改写钙钛矿结晶动力学：从“旁观离子”到形貌调控者

**原文题名**：Ultrasmooth organic–inorganic perovskite thin-film formation and crystallization for efficient planar heterojunction solar cells（2015，DOI: 10.1038/ncomms7142）

## 一个被忽视的变量：铅源阴离子

这篇论文要回答的问题很具体：在有机–无机三卤化物钙钛矿（ABX₃，A为有机阳离子、B为二价金属、X为卤素）的溶液法制备中，铅源所带的阴离子究竟扮演什么角色？作者指出，此前大量工作把注意力放在改变阴离子比例来调带隙、改变阳离子或二价金属上，但溶液组成如何影响晶体生长与薄膜形成、进而影响器件性能，仍不清楚 [page 2]。更麻烦的是，用 PbI₂ 或 PbCl₂ 与 CH₃NH₃I 一步溶液涂布时，在致密 TiO₂（c-TiO₂）覆盖的 FTO 上很难得到平滑连续的膜，针孔会形成分流通道，限制电池性能 [page 2]。

作者的策略是引入一个“非卤素”铅源——醋酸铅（PbAc₂），与 PbCl₂、PbI₂ 对照，三者都配成 CH₃NH₃I:PbX₂ = 3:1（摩尔比）的 N,N-二甲基甲酰胺溶液，即刻意使用过量有机组分 [page 2]。这个 3:1 而非 1:1 的选择本身是论证设计的一部分：作者要考察的正是过量有机组分存在时阴离子的作用，而不是化学计量比下的行为 [page 2]。

## 核心主张与证据链

论文的核心结论可以概括为一条因果链：**铅源阴离子决定副产物 CH₃NH₃X 的挥发性 → 决定过量有机组分被驱除的难易 → 决定结晶动力学与成核密度 → 决定薄膜形貌（平滑度、覆盖度）→ 决定器件性能**。下面逐环看证据。

**第一环：三种路线最终都生成同一种钙钛矿相。** X 射线衍射（图1）显示，无论铅源是 PbCl₂、PbI₂ 还是 PbAc₂，薄膜的晶体结构一致，对应 CH₃NH₃PbI₃ 钙钛矿，晶格参数 a = b = 8.85 Å、c = 12.64 Å [page 2–3]。这排除了“不同铅源生成不同物相”这一替代解释，把差异锁定在形貌与动力学上。

**第二环：结晶动力学顺序。** 原位广角 X 射线散射（WAXS，图2）追踪“前驱体”衍射峰的消失时间 t_end。PbAc₂ 与 PbCl₂ 薄膜同在 100 °C 退火，可直接比较：t_end 分别为 2.5 min 与 43.8 min；PbI₂ 薄膜在 150 °C 退火，t_end = 17.8 min [page 3]。作者还引用此前 130 °C 下 PbCl₂ 的 t_end ≈ 8–10 min（补充图1），据此外推结晶速率顺序为 PbAc₂ ≫ PbCl₂ > PbI₂ [page 3]。这里需要留意：PbI₂ 是在更高温度下测得的，跨温度比较本身不是严格同条件对照，作者用外推来弥补，这一推理的强度弱于 PbAc₂ 与 PbCl₂ 的直接对比。

**第三环：为什么 PbAc₂ 更快？** 作者把原因归于副产物 CH₃NH₃X 的热稳定性差异。热重分析（TGA，图3）给出初始分解温度（95% 重量处）为：CH₃NH₃Ac 97.4 °C、CH₃NH₃Cl 226.7 °C、CH₃NH₃I 245.0 °C，导数曲线峰值 T_d 也呈 T_d(CH₃NH₃Ac) ≪ T_d(CH₃NH₃Cl) < T_d(CH₃NH₃I) [page 3]。在 100 °C 退火条件下，醋酸甲铵极易挥发去除，而 CH₃NH₃Cl 和 CH₃NH₃I 需要更长时间。作者由此推断：副产物越易去除，成核密度越高，短时间内形成大量较小晶体并完全覆盖衬底；反之成核密度低、晶体大，且薄膜常不连续 [page 3]。这是全文最关键的一步桥接——把“副产物挥发性”与“成核密度/形貌”联系起来。需要说明，这一步在原文中主要是机理性解释，TGA 数据支持“挥发性差异”，但成核密度本身并未被直接独立测量，属于作者的合理推断。

**第四环：形貌证据。** 扫描电镜（SEM，图4）显示 PbCl₂ 与 PbI₂ 路线薄膜不连续、有针孔：PbCl₂ 的晶片在数十微米尺度、间隙大；PbI₂ 的孔洞在数百纳米尺度，且无明显晶界，符合同一路线给出多孔晶体膜而非晶粒间微孔 [page 5]。PbAc₂ 路线则几乎完全覆盖、无针孔，晶粒从数百纳米到一微米 [page 5]。原子力显微镜（AFM，图5）给出均方根粗糙度：PbCl₂ 62.4 nm、PbI₂ 52.2 nm、PbAc₂ 12.3 nm（15 μm × 15 μm 区域）[page 5]。作者特别强调，PbAc₂ 一步溶液涂布的平滑度甚至优于双源气相沉积的薄膜（PbCl₂ 基 16.2 nm、PbI₂ 基 23.2 nm）[page 5]。这是论文一个颇具冲击力的对照：简单溶液法在平滑度上超过了此前被认为更平滑的气相法。

**第五环：光学性质佐证“无残留阴离子”。** 吸收与光致发光（PL）谱（图6a）显示三种薄膜吸收边相近、PL 峰均在约 775 nm，与结构中检测不到 Cl 或 Ac 一致 [page 5]。PbI₂ 与 PbAc₂ 的 PL 相对 PbCl₂ 略有蓝移，作者将其与晶体尺寸反相关，并谨慎指出这不太可能是量子限域效应（晶体都较大），可能源于晶界处的晶格应变 [page 5]。光热偏转谱（PDS，图6b）给出 Urbach 能量：PbCl₂ 14.0 meV、PbI₂ 15.8 meV、PbAc₂ 14.4 meV，作者据此认为 PbI₂ 路线电子无序度更高 [page 5–6]。这些数值差异较小，作者也以“在测量误差内”措辞，读者不宜过度解读。

## 氯到底去哪了：一个高灵敏度检测的结论

论文对“混合卤化物”CH₃NH₃PbI₃₋ₓClₓ 中 Cl 的去向给出了一个强主张。作者采用氧瓶燃烧–电位滴定法检测 Cl⁻，分辨率达 30 p.p.m.，远高于此前方法 [page 3]。对 PbCl₂ 路线薄膜，滴定未显示对应 Cl⁻ 的电位变化，即 Cl⁻ 浓度上限为 30 p.p.m.（质量比）；即便把误差放宽 10 倍，也低于 300 p.p.m. [page 3–4]。作者据此认为，所谓“混合卤化物”路线的主导相其实是 CH₃NH₃PbI₃，与纯碘路线类似 [page 4]。他们进一步论证：若醋酸盐大量进入晶格，因醋酸根离子半径（0.162 nm）< Cl⁻（0.184 nm）< I⁻（0.220 nm），应观察到晶格参数减小，而 XRD 显示晶体与 CH₃NH₃PbI₃ 一致 [page 4]。

这里作者明确划定了边界：该结论基于**平面衬底**上的薄膜，而非介观结构（TiO₂ 或 Al₂O₃）；Cl 是否残留在介观结构界面仍需进一步研究 [page 4]。作者也不排除 Cl 在晶界或表面存在、或具有直接电子学作用的可能，但认为本研究结果与“Cl 的主要作用是影响结晶”这一解释一致 [page 8]。这是全文对“Cl 角色”最谨慎也最重要的限定。

## 器件性能：从形貌到效率

器件结果（图7、表1）把形貌差异转化为性能差异。优化退火时间后，PbCl₂、PbI₂、PbAc₂ 路线的平均 PCE 分别为 12.0%、9.3%、14.0% [page 6]。平均开路电压顺序为 PbI₂（0.85 V）< PbCl₂（0.88 V）< PbAc₂（0.99 V）[page 6]。作者把 PbI₂ 与 PbCl₂ 较低电压归因于不连续薄膜导致 spiro-OMeTAD 与 c-TiO₂ 接触形成分流通道，并用电化学阻抗谱（EIS，补充图7）佐证 PbAc₂ 路线复合被强烈抑制 [page 6]。PbI₂ 路线填充因子偏低，作者归因于该路线材料电子/空穴扩散长度更短、寿命更短导致体复合更快，可能与薄膜缺陷更多（与 PDS 一致）或退火后残留 PbI₂ 杂质（XRD 中亦观察到）有关 [page 6]。

最佳 PbAc₂ 器件在 AM 1.5G、100 mW cm⁻² 下，正向偏压到短路（FB-SC）扫描给出 J_SC = 21.7 mA cm⁻²、V_OC = 0.97 V、FF = 0.72、PCE = 15.2%；反向（SC-FB）扫描为 12.3% [page 7]。作者没有回避迟滞问题，而是指出比较有迟滞的电池应看最大功率点附近的稳定功率输出：同一电池稳定 PCE 约 13.4%，为最高 FB-SC 效率的 88%；作为对照，PbCl₂ 路线为 74%、PbI₂ 路线为 64% [page 7]。作者据此认为 PbAc₂ 路线迟滞影响更小。这一处理方式值得肯定：它没有用最高扫描值掩盖迟滞，而是用稳定输出作为更保守的性能指标。

## 结晶过程的四步模型与作者承认的不确定性

在讨论部分，作者把上述证据整合为过量有机组分存在下钙钛矿结晶的四步描述 [page 7–8]：

1. 溶液涂布初期溶剂蒸发，过量有机组分主要被截留在膜内，强烈延缓完全结晶，正是它促成了均匀薄膜；此阶段可能形成“前驱体”材料。
2. 只有当过量有机组分在升温下被驱除，向 ABX₃ 的结晶才进行；该过程的温度与时间强烈依赖副产物 CH₃NH₃X（X = Cl、I 或 Ac）。
3. 若过量有机组分挥发性不足，就需过多热量、过长时间将其驱除，薄膜形貌粗化。作者明确表示尚不清楚过度加热对晶体化学计量比的影响，但推测可能导致 CH₃NH₃ 与卤素缺陷，这或许是 PbI₂ 路线能量无序增加的来源 [page 8]。
4. 选择挥发性远高于 CH₃NH₃Cl 和 CH₃NH₃I 的副产物盐，可降低热输入、加快结晶，得到更平滑、针孔更少更小的薄膜。

作者在图8中给出 CH₃NH₃PbI₃₋ₓClₓ 薄膜制备阶段的示意 [page 8]。同时，作者坦承若干未知：无法排除部分过量有机组分残留在膜内或截留在 c-TiO₂/钙钛矿界面；对溶剂蒸发的确切时间、以及截留溶剂是与过量有机组分同时被驱除还是先后进行，均无精确知识，因此溶剂与有机组分相互作用的相对重要性仍不确定 [page 8]。

## 结论成立的条件与边界

综合来看，这篇论文的结论在以下条件下成立，超出这些条件则需谨慎：

- **工艺条件**：结论针对 3:1 过量 CH₃NH₃I、约 40 wt% DMF 溶液、一步旋涂、100–150 °C 退火的平面异质结体系 [page 2, 8]。作者明确指出不使用 1:1 化学计量比，因为研究焦点是过量有机组分下阴离子的作用 [page 2]。
- **衬底类型**：Cl 残留的结论限于平面衬底，介观结构（TiO₂、Al₂O₃）未纳入 [page 4]。
- **动力学比较的严格性**：PbAc₂ 与 PbCl₂ 是同温直接对比，证据较强；PbI₂ 在更高温度下测量，其“最慢”的排序依赖外推，强度较弱 [page 3]。
- **机理解释的性质**：副产物挥发性 → 成核密度 → 形貌这条链，TGA 直接支持挥发性差异，但成核密度未被独立测量，属作者基于形貌与动力学的推断 [page 3]。
- **性能数值**：15.2% 是 FB-SC 扫描的最高值，稳定输出约 13.4%；平均 PCE 为 14.0% ± 0.7% [page 6–7]。引用时应区分最高值与平均值、扫描值与稳定值。

论文的启发性在于一个简洁的化学杠杆：不改变钙钛矿的最终物相，只改变铅源阴离子，就通过副产物挥发性重写了结晶动力学，从而同时改善平滑度、覆盖度、退火时间和器件效率。作者也把这一思路推广为“通过简单化学管理调控晶体生长动力学”，并指出可探索其他非卤素铅源以在更低温度下制备均匀钙钛矿薄膜 [page 8]。这一推广是作者提出的方向，而非本论文已证实的结论。
