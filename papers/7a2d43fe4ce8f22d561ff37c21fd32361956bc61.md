# 混合态的可分性：从正映射到部分转置判据

**原文题名**：Separability of mixed states: necessary and sufficient conditions
**作者**：Michał Horodecki, Paweł Horodecki, Ryszard Horodecki
**年份**：1996（arXiv:quant-ph/9605038v2）

---

## 论文要解决的核心问题

量子纠缠在纯态情形下已有清晰定义，但实验室中因环境相互作用，实际面对的是混合态。混合态何时仍可写成乘积态的凸组合（即可分），何时不可分，是一个远比纯态复杂的问题。此前只有若干必要性条件，Peres 提出了一个很强的必要条件——可分态经部分转置后仍保持正定——并猜测它也是充分的 [page 3]。本文的目标是给出可分性的充要条件，并判定 Peres 猜想在什么范围内成立。

## 主论证的骨架：可分态与正映射

论文的核心思路建立在一个直观事实上：乘积态在"正映射 ⊗ 恒等映射"作用下仍为正算子，可分态作为乘积态的凸组合自然保持这一性质。作者由此反推：如果一个态不可分，是否总能找到某个正映射 Λ，使得 (Λ ⊗ I)ρ 不再正定？如果能，那么可分性就等价于"对所有正映射都保持正定"。

这一反推的关键技术步骤是 **Lemma 1** [page 4–5]：对任意不可分态 ρ̃，存在 Hermitian 算子 Ã，使得 Tr(Ãρ̃) < 0，而对所有可分态 σ 有 Tr(Ãσ) ≥ 0。证明借助 Hahn-Banach 定理的推论——可分态集合是凸闭集，可用连续泛函的等式/不等式完全刻画。这一步把"不可分"翻译成了"存在一个线性泛函把该态与可分态锥分离"。

由此得到 **Theorem 1** [page 5–6]：ρ 可分当且仅当对所有满足 Tr(A P⊗Q) ≥ 0（P、Q 为任意投影）的 Hermitian 算子 A，都有 Tr(Aρ) ≥ 0。这里 A 的条件正是"在乘积投影上非负"，而这类算子与正映射之间存在同构（式 (10)）[page 6]。经过一系列等价变形（式 (11)–(15)），最终得到本文的主定理：

**Theorem 2** [page 7]：ρ 可分当且仅当对任意正映射 Λ: A₂ → A₁，算子 I ⊗ Λρ 是正定的。

这是全文论证的枢纽。它把可分性问题从"态本身的几何性质"转化为"态在全体正映射作用下的行为"，从而把一个看似无从下手的凸集刻画问题，变成了一个关于正映射结构的代数问题。

## 2×2 与 2×3 系统：Peres 猜想成立

有了 Theorem 2，剩下的问题是：哪些正映射真正"有用"？完全正映射对不可分性不敏感（它们把任何态都映为正算子），所以关键在于那些**非完全正**的正映射。作者引用 Strømer 和 Woronowicz 的结果 [page 8]：在 2×2 和 2×3（或 3×2）系统中，任何正映射都可写成

$$\Lambda = \Lambda_1^{CP} + \Lambda_2^{CP} T \quad (17)$$

其中 Λᵢ^{CP} 是完全正映射，T 是转置。这意味着在这两个低维情形下，转置是唯一"额外"需要的正映射。代入 Theorem 2 即得 **Theorem 3** [page 8]：作用在 C²⊗C² 或 C²⊗C³ 上的态 ρ 可分，当且仅当其部分转置 ρ^{T₂} = I ⊗ T ρ 是正算子。

这一步的推理链条是：若 ρ^{T₂} ≥ 0，则对任意形如 (17) 的 Λ，I ⊗ Λρ = I ⊗ Λ₁^{CP}ρ + I ⊗ Λ₂^{CP}ρ^{T₂} 是两项正算子之和，故正定；由 Theorem 2 得 ρ 可分。反过来，可分态的部分转置正定是 Peres 已证的 [page 8 脚注 4]。因此 Peres 猜想在 2×2 和 2×3 系统中成立。

## 例子：判据的效力与边界

论文用两个例子展示判据的实际使用。

**例一**（式 (22)–(24)）[page 9–10]：ρ = p|ψ₁⟩⟨ψ₁| + (1−p)|ψ₂⟩⟨ψ₂|，其中 |ψ₁⟩ = a e₁⊗e₁ + b e₂⊗e₂，|ψ₂⟩ = a e₁⊗e₂ + b e₂⊗e₁。计算部分转置后的两个 2×2 子行列式得 W₁ = a²b²(2p−1)，W₂ = −W₁。只要 ab ≠ 0 且 p ≠ 1/2，就有一个行列式为负，故态不可分。p = 1/2 时 ρ^{T₂} = ρ 正定，由 Theorem 3 得可分。a = b 时两个纯态都退化为乘积态，ρ 自然可分。这个例子还显示，对该族态，2-熵不等式与部分转置正定条件是等价的 [page 10]。

**例二**（式 (25)–(26)）[page 10–11]：ρ = p|Ψ⁻⟩⟨Ψ⁻| + (1−p)|↑↑⟩⟨↑↑|。这里部分转置后的第二个行列式 W₂ = −p²/4 < 0 对任意 p ≠ 0 成立，故态仅在 p = 0（纯乘积态 |↑↑⟩⟨↑↑|）时可分。然而 2-熵不等式在 p ≤ 1/3 时仍被满足。这说明部分转置判据严格强于 2-熵不等式——存在满足熵不等式却不可分的态。

## 高维反例：Peres 猜想一般不成立

论文附录 [page 11] 给出 Peres 猜想在高维失效的论证。定义两个锥：S_T = {A ≥ 0, A^{T₂} ≥ 0} 和可分态锥 S。若二者相等，则它们的对偶锥也相等。可分态锥的对偶 W 同构于全体正映射锥；而 S_T 的对偶 W_{T₂} 同构于形如 (17) 的正映射锥。但 (17) 只对 2×2、2×3、3×2 成立 [page 11]，高维存在不能写成此形式的正映射。因此 W ≠ W_{T₂}，S_T ≠ S，即存在部分转置正定但不可分的态。这从结构上证明了 Peres 条件在高维只是必要而非充分。

## 结论成立的条件与论证的边界

Theorem 3 的充分性**严格依赖** Strømer–Woronowicz 的分类结果，即低维正映射的分解式 (17)。一旦维数升高，这一分解不再普遍，判据随即失效——这正是附录反例的根源。因此"部分转置正定 ⟺ 可分"是一个**低维现象**，不能外推。

Theorem 2 本身是普遍成立的充要条件，但它是"对所有正映射"的量化陈述，在实践上难以直接检验，除非能像低维那样把正映射锥约化为有限个基本映射。论文没有给出高维可操作判据，也没有讨论无限维情形下 Theorem 3 是否成立（Remark 2 只说明 Theorem 1 可推广到无限维 [page 6]）。

另外，论文对"可分"采用 Werner 的定义：可用乘积态在迹范数下逼近 [page 3 脚注 1]。在有限维下这与凸组合定义等价，但这一等价性论文未展开证明，属于读者需自行补足的桥接。

## 论证的整体评价

本文的贡献不在于发现某个具体判据，而在于建立了一个**概念框架**：可分性等价于"在全体正映射下保持正定"，而正映射锥的结构决定了判据的复杂度。低维时正映射锥由完全正映射和转置生成，判据简化为部分转置；高维时正映射锥更丰富，判据随之复杂化。这一框架把纠缠判定的问题从"猜条件"提升为"研究正映射锥的几何"，为后续纠缠理论的发展提供了基本语言。
