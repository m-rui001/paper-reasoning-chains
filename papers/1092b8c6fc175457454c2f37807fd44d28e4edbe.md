# 石墨双层中的朗道能级简并与量子霍尔效应：一篇论证分析

**原文题名**：Landau level degeneracy and quantum Hall effect in a graphite bilayer
**作者**：Edward McCann, Vladimir I. Fal'ko（Lancaster University）
**年份**：2006（arXiv:cond-mat/0510237v2, 3 Mar 2006）

---

## 一、作者要证明什么

这篇 Letter 的核心主张可以拆成三层，层层递进：

1. **双层石墨的低能准粒子是 J=2 的手性粒子**，具有抛物线型色散和 2π 的 Berry 相位，与单层石墨中 J=1、Berry 相位 π 的狄拉克粒子形成对照 [page 1]。
2. **这种手性导致一个特殊的朗道能级（LL）谱**：有限能量处是近乎等间距的四重简并态，而在零能处存在一个八重简并态 [page 1, page 3]。
3. **该谱结构直接决定量子霍尔电导 σxy(N) 的台阶序列**：双层在 4e²/h 的整数倍处出现平台，并在零密度两侧呈现一个"双倍"的 8e²/h 台阶，而单层则是 (4n+2)e²/h 的序列 [page 1, page 4]。

第三层是全文的落点：它把抽象的哈密顿量结构转化为一个可被实验直接检验的输运预言。

## 二、从晶格到有效哈密顿量：论证的起点

作者的建模从 Bernal (˜A-B) 堆叠的双层六角晶格出发（Fig. 1, [page 1]）。关键的结构事实是：层间耦合 γ1 把 ˜A-B 轨道配成"二聚体"（dimer），从而把高能带推到一边，留下低能物理由 A 和 ˜B 两个子晶格主导。这一物理图像是后续所有推导的支点。

作者没有直接从紧束缚模型硬推，而是先写出 4×4 的紧束缚哈密顿量 H（以 A, ˜B, ˜A, B 为基），再用 Green 函数方法把高能二聚体带"积分掉"：将 H 分块，对 G22 在 γ1⁻¹ 中展开并保留到 p 的二次项，最终得到 2×2 的有效哈密顿量 Ĥ2（Eq. 1, [page 1]）。这一步是全文的技术核心——它把四带问题约化为两带问题，代价是引入了适用能量范围 |ε| < ¼γ1。

Ĥ2 的第一项给出抛物线色散 |ε| = p²/2m，有效质量 m = γ1/2v²；Ĥw 项（含 v3）引入三角翘曲；Ĥa 项描述层间不对称（打开 mini-gap u）。作者明确指出，Ĥ1 和 Ĥ2 属于同一族手性哈密顿量 ĤJ，手性度 J 在单层为 1、双层为 2，而沿闭合轨道绝热传播获得的 Berry 相位为 Jπ [page 2]。**这是从"抛物线色散"到"2π Berry 相位"的关键推理步骤**：手性不是额外假设，而是哈密顿量本征结构的直接后果。

## 三、色散、交叉与量级：证据如何支撑"抛物线主导"

作者并未止步于形式推导，而是给出可检验的量级估计。由 Eq. (2) 的插值公式，色散在低动量时线性（ε ≈ vp），在高动量时二次（ε ≈ p²/2m），交叉发生在 p ≈ γ1/2v，对应载流子密度 N* ≈ γ1²/(4πℏ²v²) [page 2]。用块体石墨参数代入，N* ≈ 4.36×10¹² cm⁻²，二聚体带被占据需 N⁽²⁾ ≈ 8N* ≈ 3.49×10¹³ cm⁻²，有效质量 m ≈ 0.054 me [page 2]。

这些数字的作用是划定"抛物线主导"的窗口：在 ½γ1(v3/v)² < |ε| < ¼γ1 的能量区间内，Ĥw 的线性项可忽略，抛物线项主导。**换句话说，作者主张的"双层是抛物线手性粒子"并非无条件成立，而是在中等密度/中等磁场下才成立**——极低密度下线性项重新变得重要。

三角翘曲（Ĥw）进一步把等能线在最低能量处劈裂成一个"中心"口袋和三个"腿"口袋（Fig. 2, [page 2]），劈裂发生在 N < Nc = 2(v3/v)²N* ≈ 1×10¹¹ cm⁻²，对应 B < Bc ≈ 1 T [page 3]。这是作者主动交代的一个边界条件：在极低密度和极弱磁场下，费米面不再是单一闭合曲线，LL 谱会退化为"四重简并组 + 两个非简并能级"的复杂结构。

## 四、朗道能级谱：数值计算与解析结果

作者用朗道规范 A = (0, Bx) 把 π、π† 映射为升降算符，数值求解 Eq. (1) 的 LL 谱，结果画在 Fig. 3 [page 3]。Fig. 3(a)（B = 0.1 T）显示随 v3 增大，谱从等间距阶梯演化为口袋相关的简并组；Fig. 3(b)（B = 1 T）则在很宽的 v3 范围内保持不变。**这一对照是作者论证"可以忽略 v3"的关键证据**：在 ℏλB⁻¹ > v3m 的场范围内，v3 不影响谱结构，因此可以用 Ĥ2 的第一项近似描述。

在这个近似下，解析结果干净利落：

- 高能级：ε±n = ±ℏωc√(n(n−1)) − ½ξδ，n ≥ 2（Eq. 3, [page 3]），其中 ωc = eB/m，δ = uℏωc/γ1。这些态在谷和自旋简并下是四重简并的。
- 零能级：ε0 = ½ξu（Φ0 = (φ0, 0)）和 ε1 = ½ξu − ξδ（Φ1 = (φ1, 0)）（Eq. 4, [page 3]）。在对称双层（u = 0）中，这两个能级在 K 和 ˜K 谷都简并，加上自旋，形成**八重简并的零能 LL**。

这里有一个值得点出的物理细节：n = 0 和 n = 1 态在 K 谷主要位于底层 A 位，在 ˜K 谷主要位于顶层 ˜B 位，层间不对称 u 会把两个谷的零能级劈开 [page 3]。作者强调，即使在高场下需要用完整两带哈密顿量 H，零能 LL 的八重简并仍然保持不变 [page 3]——这是一个稳健的结论，不依赖于近似。

## 五、从 LL 谱到量子霍尔台阶：关键的一步

Fig. 4 [page 4] 是全文论证的收束点。左栏是双层的 LL 谱，右栏是单层的 LL 谱，中间是预言的电导 σxy(N)。作者把 LL 简并度直接翻译成霍尔平台序列：

- 双层：平台在 4e²/h 的整数倍，零密度两侧有一个"双倍"的 8e²/h 台阶，伴随 σxx 的极大值。
- 单层：平台在 (4n+2)e²/h，零能 LL 导致 σxy = 0 平台缺失。

**这一步推理的桥接是**：每个 LL 贡献的霍尔电导量子数等于其简并度；零能 LL 的八重简并意味着在 N = 0 附近有 8 个态同时穿越费米面，因此出现 8e²/h 的"双倍"台阶。作者明确说明 Fig. 4 的草图假设温度和 LL 展宽掩盖了谷/自旋劈裂以及 n = 0, 1 能级间的劈裂，使得这些能级的渗透态无法分辨 [page 4]。**这是一个重要的适用条件**：如果实验分辨率足够高，能分辨这些微小劈裂，那么"双倍台阶"的简单图像会被修正。

作者还指出，单层的 σxy(N) 序列 (4n+2)e²/h 与早期文献 [3] 的讨论一致，而两个平行等效单层会给出 2σ⁽¹⁾xy(N)，从而"错过"每隔一个的平台 [page 5, 注 20]——这个对照进一步凸显双层 σ⁽²⁾xy(N) 的独特性。

## 六、结论的边界与作者承认的局限

作者在几个地方主动限定了结论的适用范围：

1. **能量范围**：Ĥ2 仅在 |ε| < ¼γ1 内适用 [page 1]；高场下需用完整 H [page 3]。
2. **v3 的处理**：Ĥw 在极低密度/极弱磁场下不可忽略，此时费米面劈裂为四个口袋，LL 谱退化为"四重简并组 + 两个非简并能级" [page 2–3]。
3. **u 的作用**：层间不对称会劈开零能 LL，破坏八重简并；Fig. 4 的简单台阶图像假设这种劈裂被展宽掩盖 [page 4]。
4. **自旋**：作者用 g = 2 和 m ≈ 0.054 me 估计 Zeeman 能与 LL 间距之比 εZ/ℏωc ~ 0.05，因此自旋劈裂很小 [page 4, 注 19]——这是"自旋简并"假设的定量依据。

作者还提到一个开放性的推断：零能 LL 的八重简并"暗示"电子-电子相互作用可能在双层中产生多种强关联 QHE 态，在 N ~ 10¹² cm⁻²、B ~ 10 T 时可能实现 [page 4]。**这是作者明确标为"interesting to note"和"may give rise to"的推测，不是已证结论**，读者应保留其谨慎语气。

## 七、论证的整体评价

这篇 Letter 的论证链条是：晶格对称性 → 4×4 紧束缚模型 → Green 函数约化 → 2×2 手性哈密顿量 → 抛物线色散 + 2π Berry 相位 → LL 谱（数值 + 解析）→ 霍尔台阶序列。每一环都有明确的数学或数值支撑，且作者在关键处给出了量级估计（N*, Nc, Bc, m, εZ/ℏωc）来界定适用窗口。

最值得注意的推理转折有两个：一是**从手性 J=2 到零能 LL 八重简并**——这不是简单的计数，而是因为 n = 0 和 n = 1 两个轨道态在对称双层中恰好简并；二是**从 LL 简并度到霍尔台阶**——这一步依赖"展宽掩盖微小劈裂"的实验条件，是结论成立的关键假设。作者对这两点都有交代，没有把条件性结论写成无条件结论。

一个文本上的小疑点：Fig. 3 的纵轴标注为 ε/ℏωc，但图注中给出 ℏωc = 0.216 meV（B = 0.1 T）和 2.16 meV（B = 1 T），数值与 γ1 = 0.39 eV、v = 8.0×10⁵ m/s 自洽；不过 Eq. (3) 中 δ = uℏωc/γ1 的定义与 Eq. (4) 中 ε1 = ½ξu − ξδ 的符号约定，读者需对照原文仔细核对，OCR 提取的符号方向在此处不宜作为独立推理前提。
