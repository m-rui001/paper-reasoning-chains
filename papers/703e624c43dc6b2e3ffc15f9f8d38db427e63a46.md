# 三维拓扑绝缘体：从四个 Z₂ 不变量到强弱分类与表面态

**原文题名：** Topological Insulators in Three Dimensions
**作者：** Liang Fu, C. L. Kane, E. J. Mele（宾夕法尼亚大学）
**年份：** 2007（arXiv:cond-mat/0607699v2）

## 论文要解决的问题

二维量子自旋霍尔（QSH）效应由一个 Z₂ 拓扑不变量刻画，把 QSH 相与普通能带绝缘体区分开来。本文把这一框架推广到三维，追问：三维时间反演不变能带系统有哪些拓扑类别？这些类别在物理上意味着什么？它们能否用具体模型实现，并与真实材料对应？[page 1]

作者建立在 Moore 和 Balents（以及 Roy）已有结果之上——三维时间反演不变能带由四个 Z₂ 不变量刻画，共 16 类"拓扑绝缘体"——但本文的贡献不止于复述这一计数，而是给出这些不变量的物理含义、区分"弱"与"强"两类相，并刻画它们的表面态。[page 1]

## 从二维 Laughlin 论证到三维不变量

论证的起点是作者在先前工作（Ref. 12）中建立的二维 Z₂ 不变量与自旋过滤边缘态之间的联系，本文用一种便于推广到三维的方式重述了它。[page 1]

核心构造是 Laughlin 型论证：在柱面上穿入磁通 Φ = 0 或 π（以 $\bar{h}/e$ 为单位）。当柱面在周向只含一个原胞时，磁通扮演能带理论中晶体动量 $k_x$ 的角色，柱面端态的谱随磁通的变化就反映了边缘态谱随动量的变化。时间反演极化（TRP）随磁通从 0 变到 π 的改变，决定了边缘处 Kramers 简并态在时间反演不变动量（TRIM）$k_x = \Lambda_1 = 0$ 与 $k_x = \Lambda_2 = \pi$ 之间如何连接。在 QSH 相中，Kramers 对"交换伙伴"（Fig. 1a），而在常规绝缘体中不交换（Fig. 1b）。由此推出：QSH 相的边缘态穿越体能隙，在 $\Lambda_a$ 与 $\Lambda_b$ 之间穿过费米能级奇数次；绝缘相则穿过偶数次（或零次），且不受拓扑保护。[page 1]

TRP 的变化与体能带结构相关，由式 (1) 给出：

$$\delta_i = \sqrt{\text{Det}[w(\Gamma_i)]}/\text{Pf}[w(\Gamma_i)] = \pm 1 \quad (1)$$

其中 $w_{ij}(k) = \langle u_i(-k)|\Theta|u_j(k)\rangle$。在 $\Gamma_i$ 处 $w_{ij} = -w_{ji}$，故 Pfaffian 有定义。$\pi_a = \delta_{i=a1}\delta_{i=a2}$ 本身不是规范不变量——依赖规范变换可以改变任意一对 $\delta_i$ 的符号，这反映了端部 Kramers 简并依赖晶体如何终止，类似于电荷极化的不确定性。但乘积 $\pi_1\pi_2 = \delta_1\delta_2\delta_3\delta_4$ 是规范不变量，定义了二维的单个 Z₂ 不变量。[page 1–2]

## 三维的四个不变量与强弱分类

三维有 8 个不同的 TRIM，可视为立方体的顶点（Fig. 2）。规范变换可以改变同一平面内任意四个 $\Gamma_i$ 对应的 $\delta_i$ 的符号。模去这些规范变换后，有 16 种不变的 $\delta_i$ 构型，由四个 Z₂ 指标 $\nu_0; (\nu_1\nu_2\nu_3)$ 区分，定义如式 (2)(3)：

$$(-1)^{\nu_0} = \prod_{n_j=0,1} \delta_{n_1n_2n_3} \quad (2)$$
$$(-1)^{\nu_i=1,2,3} = \prod_{n_j\neq i=0,1; n_i=1} \delta_{n_1n_2n_3} \quad (3)$$

$\nu_0$ 与 $b_k$ 的选取无关；$(\nu_1\nu_2\nu_3)$ 则不然，但可等同于 $G_\nu \equiv \sum_i \nu_i b_i$，属于模 2 倒格矢的 8 元素集合（相差 $2G$ 的矢量视为等同），可解释为 $G_\nu$ 的 Miller 指标。[page 2]

这里的关键推理转折在于：$\nu_0$ 的奇偶性把 16 类分成两大物理类别。

**弱拓扑绝缘体（WTI，$\nu_0 = 0$）**：每个面要么有 0(4) 个、要么有 2 个被包围的 Dirac 点。对于面 $G = \sum_i m_i b_i$，当 $m_i = \nu_i \bmod 2$ 时有 0(4) 个 Dirac 点，否则有 2 个。这些相可解释为沿 $G_\nu$ 方向堆叠的二维 QSH 层，类似于三维量子霍尔相（由一组 Chern 整数指标化）。由于 $G_\nu$ 定义在模 $2G$ 意义下，沿 $G_\nu$ 和 $G_\nu + 2G$ 堆叠的层状 QSH 相是等价的。[page 2]

WTI 的拓扑区分"脆弱"：它依赖晶格的平移对称性。若把原胞加倍，两个 Dirac 点会折叠到一起，一个弱的周期势就能打开能隙。因此无序很可能消除这些相与简单绝缘体之间的拓扑区分，表面态一般会局域化。作者据此称之为"弱"拓扑绝缘体，但强调弱不变量对干净表面仍有重要含义。[page 3]

**强拓扑绝缘体（STI，$\nu_0 = 1$）**：更稳健。此时所有面上的表面费米弧都包围 1(3) 个 Dirac 点。若费米能级恰在 Dirac 点，这提供了 2+1 维宇称反常（parity anomaly）的一个时间反演不变实现，且无费米子倍增——之所以可能，是因为 Dirac 点的伙伴位于相对的表面上。对于体能隙内的任意费米能级，表面费米弧包围单个 Dirac 点，定义了一个二维"拓扑金属"：电子绕费米弧一周获得量子化的 π Berry 相位，这一相位使表面在有无序时处于辛普莱克（symplectic）普适类，不被弱无序局域化。[page 3]

## 紧束缚模型：把相图算出来

为显式实现这些相，作者考虑金刚石晶格上 s 态的四带紧束缚模型，含自旋轨道相互作用，推广了二维蜂窝晶格模型（式 4）：

$$H = t\sum_{\langle ij\rangle} c_i^\dagger c_j + i(8\lambda_{SO}/a^2)\sum_{\langle\langle ij\rangle\rangle} c_i^\dagger \mathbf{s}\cdot(\mathbf{d}^1_{ij}\times\mathbf{d}^2_{ij})c_j \quad (4)$$

第一项是连接金刚石晶格两个 fcc 子晶格的最邻近跃迁；第二项是自旋依赖的第二近邻跃迁，$\mathbf{d}^{1,2}_{ij}$ 是路径上经过的两个最邻近键矢，$a$ 是立方原胞尺寸。[page 3]

能带结构（Fig. 3a）显示：由于反演对称性，每条能带二重简并；导带与价带在三个不等价 X 点 $X_r = 2\pi\hat{r}/a$（$r = x,y,z$）处形成三维 Dirac 点。通过对称性降低的最近邻键调制 $t \to t + \delta t_p$（$p = 1,\dots,4$）可解除简并。在 $X_z$ 附近，低能有效质量模型取 3+1 维 Dirac 方程形式（式 5）：

$$H^z_{\text{eff}} = ta\sigma_y q_z + 4\lambda_{SO}a\sigma_z(s_x q_x - s_y q_y) + m_z\sigma_x \quad (5)$$

其中 $q = k - X_z$，$m_z = \sum_p \delta t_p \,\text{sgn}[\mathbf{d}_p\cdot\hat{z}]$，$\sigma_i$ 对应子晶格自由度，$s_i$ 描述自旋。$H^{x,y}_{\text{eff}}$ 形式相同，只是 $q_i$ 和 $s_i$ 中 $x,y,z$ 轮换，而 $\sigma_i$ 不轮换。当任一 $X_r$ 处的质量为零时发生相变，$\delta t_p = 0$ 是分隔 8 个时间反演不变相的多临界点。[page 3]

作者利用本问题中本征矢可解析求出的便利，得到式 (6)：

$$\delta_i = \text{sgn}\left[\sum_p (t + \delta t_p)\cos\Gamma_i\cdot(\mathbf{d}_p - \mathbf{d}_1)\right] \quad (6)$$

由此读出相图（Fig. 3b）：当四个键中一个比其他的弱（如 $\delta t_p < 0$，其余 $\delta t_{p'\neq p} = 0$），系统处于 WTI 相，可解释为沿 $\mathbf{d}_p$ 方向层叠的 QSH 态，共 4 个这样的态。当一个键比其他的强，系统处于四个 STI 相之一。能带绝缘体 $0;(000)$ 不能从该临界点微扰到达，但在紧束缚模型中当某个键调到 $\delta t_1 > 2t$ 时出现；交错子晶格势也能导致能带绝缘体，但强度须超过由 $\lambda_{SO}$ 设定的有限值。[page 3–4]

## 表面态的直接验证

作者在板几何中求解式 (4)，得到 Fig. 4：沿 111 面、经过四个 TRIM 的二维能带结构。体能隙上方的体态清晰可见，此外有穿越能隙的表面态。在 WTI 相 $0;(111)$ 和 $0;(1\bar{1}\bar{1})$ 中，上下表面各有 0 和 2 个二维 Dirac 点；在 STI 相 $1;(111)$ 和 $1;(\bar{1}11)$ 中，每个表面有 1(3) 个 Dirac 点——与前述一般论证的预期一致。每个情形中，Dirac 点附近的非简并表面态都是自旋过滤的，满足 $\langle\vec{s}(-k)\rangle = -\langle\vec{s}(k)\rangle$，因此自旋密度与电荷流耦合。[page 4]

这一步是论证的关键闭环：一般性拓扑论证预言了表面 Dirac 点的奇偶性，而具体模型的数值解直接展示了这一奇偶性，两者相互印证。

## 与真实材料的联系及其边界

作者明确指出，四带金刚石模型虽然简单，但"probably not directly relevant to any specific material"，其价值在于为真实晶体提供洞见。[page 4]

他们考虑从金刚石出发、沿 (111) 方向连续位移 fcc 子晶格得到的晶体结构序列：金刚石 → 石墨(ABC) → 立方。从金刚石开始，111 最近邻键被拉伸，导致 $0;(111)$ WTI 相；继续位移，两个子晶格最终共面，结构类似 ABC 堆叠石墨；再位移，晶格最终变为立方，此时能隙闭合，系统为金属。s 态模型在到达立方点之前一直处于 WTI 相。[page 4]

关于铋：铋具有菱方 A7 结构，可视为"向金刚石畸变"的立方晶格加上 fcc 布拉菲格子的三角畸变。Murakami 已证明铋双层（结构类似石墨烯单层）处于 QSH 相。这暗示在双层间弱耦合时，铋处于 $0;(111)$ WTI 相。作者指出这与上述简单模型一致，但强调"a realistic description of bismuth requires a theory which incorporates bismuth's five valence bands"——这是一个明确的局限声明。[page 4]

作者在"Note added"中补充：后续工作已预言若干具体材料是 STI，包括半导体合金 Bi₁₋ₓSbₓ 以及单轴应变下的 α-Sn 和 HgTe。[page 4]

## 结论成立的条件与推理边界

本文的核心结论——三维有 16 类拓扑绝缘体、由四个 Z₂ 不变量区分、$\nu_0$ 的奇偶性区分强弱相、STI 表面有奇数个 Dirac 点且受拓扑保护——建立在若干条件之上。

首先，整个框架适用于时间反演不变系统，且要求体能隙存在。其次，WTI 的拓扑区分依赖平移对称性，无序会破坏它——这是作者明确承认的，也是"弱"这一命名的由来。第三，STI 的稳健性论证依赖表面费米弧包围单个 Dirac 点时电子获得 π Berry 相位，进而落入辛普莱克普适类；这一推理链的每一步在文中都有交代，但"不被弱无序局域化"的结论是建立在普适类论证之上，而非本文的直接数值验证。

关于材料对应，作者对铋的判断是"暗示"（suggests）而非确证，并明确指出现实描述需要包含铋的五个价带。金刚石模型到真实材料的映射是启发性的类比，不是定量预测。这些限定语在原文中都有保留，分析时不应升级为确定结论。

值得注意的一处细节：Fig. 2 中 $0;(001)$ 相的 100 面有两个 Dirac 点，而 801 面有 0(4) 个——原文此处"801"疑为"001"或"100"的 OCR 讹误，因为上下文讨论的是同一相不同面的 Dirac 点数目，且 801 面在立方晶系中并非常规记法。这一疑点不影响主要论证，但引用该具体数值时应谨慎。[page 3]
