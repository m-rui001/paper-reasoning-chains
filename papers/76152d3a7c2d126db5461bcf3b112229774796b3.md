# 拓扑绝缘体表面上的超导近邻效应与马约拉纳费米子

**原文题名：** Superconducting Proximity Effect and Majorana Fermions at the Surface of a Topological Insulator（Liang Fu, C. L. Kane, *Phys. Rev. Lett.* **100**, 096407 (2008), DOI: 10.1103/PhysRevLett.100.096407）

## 一个不破缺时间反演的“无自旋 pₓ+ip_y”态

论文的出发点是一个类比：无自旋的 pₓ+ip_y 超导体在涡旋中心承载零能马约拉纳束缚态（MBS），而这类态是非阿贝尔统计与拓扑量子计算的最简载体 [page 1]。作者要论证的是，不需要去寻找本征的 p 波超导体，只要把普通 s 波超导体放到强拓扑绝缘体（TI）表面，近邻效应就能在表面态中诱导出一个“类 pₓ+ip_y”的二维态，并且它同样在涡旋处支持 MBS。

关键的第一步是把表面态写下来。强 TI 表面最简单的单支费米弧由时间反演不变哈密顿量 H₀ = ψ†(−iv σ̃·∇ − μ)ψ 描述，其中 σ̃ 是自旋泡利矩阵，ψ = (ψ↑, ψ↓)ᵀ [page 1, Eq. (1)]。作者强调这一项只能存在于表面，因为它违反费米子倍增定理——表面态本质上相当于普通二维电子气的一半。

当 s 波超导体沉积在表面时，库珀对通过近邻效应隧穿进表面态，可用配对项 V = Δ ψ↑†ψ↓† + H.c. 描述，其中 Δ = Δ₀e^{iφ} 依赖超导相位与界面性质 [page 1]。在 Nambu 表象 Ψ = (ψ↑, ψ↓, ψ↓†, −ψ↑†)ᵀ 下，BdG 哈密顿量为

H = −iv τ_z σ̃·∇ − μ τ_z + Δ₀(τ_x cosφ − τ_y sinφ)  [page 1, Eq. (2)]

其中 τ̃ 混合粒子与空穴块。作者指出该 H 满足时间反演不变性（ΘHΘ⁻¹ = 0，Θ = iσ_y K）和粒子—空穴对称性（Ξ = σ_y τ_y K，{Ξ, H} = 0）[page 1]。

均匀 Δ 时激发谱为 E_k = ±√((v|k| − μ)² + Δ₀²)。当 μ ≫ Δ₀ 时，低能谱与无自旋 pₓ+ip_y 超导体相似。作者把这个类比“做实”：定义 c_k = (ψ↑_k + e^{iθ_k}ψ↓_k)/√2（k = k₀(cosθ_k, sinθ_k)，vk₀ = μ），投影后的哈密顿量形式上就是无自旋 pₓ+ip_y 超导体 [page 1]。**但作者立刻点出关键差别：H 尊重时间反演对称性，而 pₓ+ip_y 超导体不尊重。** 这个差别不是修辞，它决定了后面所有“手性”相关结论都要被重新审视。

## 涡旋零模与“手性”的缺失

既然低能有效理论与 pₓ+ip_y 超导体等价，作者推断涡旋应承载 MBS。他们直接求解极坐标下的 BdG 方程，取 Δ(r,θ) = Δ₀(r)e^{−iθ}，发现对任意 μ 都存在零能解；μ = 0 时形式最简：

Ψ₀(r,θ) = e^{−∫₀^r dr′ Δ₀(r′)/v} · (u, v)ᵀ  [page 2, Eq. (3)]

其中 u = (0, i; 1, 0)ᵀ，v = (1, 0; 0, −i)ᵀ。这是论文第一个核心结论：**s 波超导体/TI 表面界面上的 h/2e 涡旋承载 MBS** [page 1–2]。

但作者随即处理一个容易被忽略的边界问题。pₓ+ip_y 超导体还有手性边缘态，而本系统有时间反演对称性，手性边缘态被禁止——理由很直接：表面本身已是三维晶体的边界，不能再有边界 [page 2]。要得到手性马约拉纳边缘态，必须破坏时间反演：加入塞曼场 Mσ_z 作为质量项，在表面态谱中打开绝缘能隙。求解 (2) 后，作者发现这种绝缘态与超导态之间的界面存在手性马约拉纳边缘态，可通过在表面沉积超导与磁性绝缘材料实现 [page 2]。作者还顺带指出，类似效应也可出现在二维 TI 边缘，那里超导能隙区与绝缘能隙区的边界处会出现 MBS，与 Kitaev 链端点态类似 [page 2]。

## 线结：一条非手性马约拉纳量子线

论文的主体转向 STIS 线结：宽度 W、长度 L→∞ 的结，两侧超导体相位分别为 0 和 φ，中间是 TI 表面态 [page 2, Fig. 1(a)]。作者求解 Δ(x,y) 在 y > W/2 为 Δ₀e^{iφ}、y < −W/2 为 Δ₀、中间为 0 的 BdG 方程。计算思路与 Titov、Ossipov、Beenakker 对石墨烯 SNS 结的分析相似，但有一个重要区别：石墨烯有四个独立狄拉克点，这里只有一个 [page 2]。

W ≫ v/Δ₀ 时存在两支束缚态，沿 x 方向以动量 q 色散。W = μ = 0 时

E_±(q) = ±√(v²q² + Δ₀²cos²(φ/2))  [page 2, Eq. (4)]

φ = π 时谱无能隙 [page 2, Fig. 1(b)]。为处理有限 W 和 μ，作者构造低能有效理论：先解 q = 0、φ = π 时的两个零能模 a₁,₂(y)，选择满足 Ξa = a 的基，然后计算 ⟨a|q∂_xτ_z|b⟩ 和 ⟨a|Δ₀Θ(y−W)τ_y|b⟩，得到“k·p”哈密顿量

H̃ = −iṽ τ_x ∂_x − m τ_y  [page 2, Eq. (6)]

其中 ṽ = v[cos μW − (Δ₀/μ)sin μW]Δ₀²/(μ² − Δ₀²)，m = Δ₀cos(φ/2)，τ_x,y 作用在 a、b 两个分量上 [page 2]。作者指出 H̃ 形似 Su-Schrieffer-Heeger（SSH）模型，但有一个本质区别：E_±(q) 态不独立，对应的 Bogoliubov 准粒子算符满足 γ(q) = γ†(−q)。**因此系统是常规一维费米气的一半，即一条非手性“马约拉纳量子线”** [page 2]。

这里有一个对后续电路分析至关重要的技术细节：当线结弯折成角度 θ 时，基矢 (5) 按 a → e^{iτ_zθ/2}a 变换，但 H̃ 在 θ(x) 变化时保持不变。在圆环上，θ 增加 2π 时 a 变号，因此 H̃ 的本征态必须满足反周期边界条件 ψ(0) = −ψ(2π) [page 2]。这个反周期条件在后面推导编织规则时会再次出现，并解释了一个关键的负号。

## 三叉结与相图：MBS 何时存在

作者接着考虑三叉结——三个超导体被线结分隔并在一点相遇 [page 2, Fig. 1(c)]。一般 BdG 方程无法解析求解，但作者通过两个可解极限推断相图：φ_k = 0 时无束缚态；三个 W = 0 线结呈 120° 取向、φ_k = π − 2πk/3 时（C₃ 对称的涡旋离散类比，Fig. 1(d) 中圆圈），μ = 0 时存在与 (3) 相同的 MBS，只是指数中的 Δ₀ 被 Δ₀ n̂·r/v 替换，n̂ 是每个超导体中平分相邻结夹角的单位矢量 [page 2]。由于 MBS 不能在 φ_k 连续变化时消失，除非能隙关闭，相边界由线结解给出：**当相邻超导体相位差为 π 时，MBS 存在** [page 2–3, Fig. 1(d)]。

作者还给出一个直观的极限：当三叉结中两条线接近无能隙时（φ₁ = π − ε₁，φ₂ = π − ε₂），Fig. 1(d) 预言 ε₁ε₂ < 0 时存在 MBS。这可以用 Eq. (6) 理解：下方两条线结的 masses 为 m₁,₂ = Δ₀ε₁,₂/2，当 m₁m₂ < 0 时 m 变号，产生 SSH 模型著名的 midgap 态，在此语境下就是 MBS [page 3]。

## 从线结到电路：产生、输运与融合

论文最后一部分展示如何用 STIS 结搭建电路来操控 MBS。核心工具是两端被三叉结终止的线结。作者假设线结两侧超导相位为 0 和 π − ε，两端超导相位 φ_L(R) 不接近 0 或 π，用硬壁边界条件 m → ∞ 建模，符号 s_{L,R} = sgn sin φ_{L,R} [page 3]。

**s_L = s_R = 1 时**，谱为 E_n(δ) = √(δ² − ṽ²k_n²)，k_n 满足 tan k_n L = −ṽk_n/δ，δ = Δ₀ε/2。δ < 0 时存在 midgap 态。L → ∞ 时一对零能态 Ψ₁,₂(x,y) 局域在两端：

Ψ₁ = a₁(y)e^{−|δ|x/ṽ}，Ψ₂ = a₂(y)e^{−|δ|(L−x)/ṽ}  [page 3, Eq. (7)]

有限 L 时本征态为 ψ_± = Ψ₁ ± iΨ₂，能量 E_±⁰(δ) ≈ ∓2|δ|e^{−|δ|L/ṽ}。这些定义 Bogoliubov 准粒子算符 γ = (ψ_+ + ψ_−)†Ψ，由于 ψ_− = ψ_+†，可得 γ† = γ†，即 γ = (η₁ + iη₂)/2，其中 η_a = (Ψ_a)†Ψ 是马约拉纳算符。**一对 MBS 因此定义一个二态希尔伯特空间，由 n₁₂ = γ†γ 标记，MBS 之间的相互作用由劈裂描述：**

H = E_+⁰(δ)(γ†γ − 1/2) = iE_+⁰(δ)η₂η₁/2  [page 3, Eq. (8)]

s_L = s_R = −1 情形类似，Eq. (8) 同样适用，只需把 η₂ 关联到 π 涡旋 [page 3]。这提供了产生和融合 MBS 对的方法：从 δ > 0 无 MBS 的基态出发，绝热减小 δ 穿过 0，MBS 出现在态 |0₁₂⟩ 中；若初始 δ < 0 且有一对 MBS 处于态 |n₁₂⟩，绝热增大 δ 穿过 0 时系统保持 |n₁₂⟩，最终演化为基态或带一个额外费米子的态。两者可通过测量跨线结的电流区分：I = ±ΔI/2，其中 ΔI = (e/ℏ)dE_+⁰/dφ ≈ eΔ₀/2ℏ，Δ₀ ~ 0.1 meV 时 ΔI ~ 10 nA [page 3]。

**s_L = −s_R = 1 时**，存在平面波解 E_n = √(δ² + (nπṽ/L)²)（n = 1, 2, …）以及一个 E₀ = 0 态：

Ψ(x,y) ∝ a₁(y)e^{−δx/ṽ}  [page 3, Eq. (9)]

δ 的符号决定 MBS 指数局域在左端还是右端；δ 变号时 MBS 平滑地从一端切换到另一端。**这提供了将 MBS 从一个节点输运到另一个节点的方法** [page 3]。

## 编织与融合：反周期边界条件带来的负号

作者用两个简单电路展示 MBS 的编织与融合。Fig. 3(a) 中，中心岛相位从 0 绝热推进到 2π：φ = 0 时无 MBS；φ = 2π/3 时上下线结产生两对 MBS；φ = 4π/3 时 MBS 在左右线结融合。若系统从 φ = 0 的基态出发，φ → 2π 时

|0₁₂0₃₄⟩ → (|0₁₄0₃₂⟩ + |1₁₄1₃₂⟩)/√2  [page 3, Eq. (10)]

左右段因此处于纠缠态，跨左右结的电流测量将以 50% 概率给出 ±ΔI/2，且完全关联 [page 3]。

作者给出两种理解方式。第一种：该循环等效于产生两对 MBS、交换一对（如 2 和 4）、再让两对重新靠近，对应 Ivanov 的编织算符 P₂₄ = (1 + η₂η₄)/√2，直接给出 (10) [page 3]。第二种：从 (6) 和 (8) 推导。φ ≳ 2π/3 时 H₁ ∝ i(η₁η₂ + η₃η₄)；φ ≳ 4π/3 时 H₂ ∝ i(η₁η₄ − η₃η₂)。**这里负号的出现正是因为闭合一维电路必须满足反周期边界条件，因此某个线结上必须有一个波函数变号的割缝。** 作者选择割缝在 2 和 3 之间的结上，然后直接用 H₁ 的基态在 H₂ 本征态下展开，即得 (10) [page 3–4]。

Fig. 3(b) 给出不融合而交换 MBS 的几何：φ = 0 时 MBS 按图示位置分布；φ 推进 2π 时 MBS 逆时针跳跃三次并交换。Ivanov 规则预言 η₂ → η₁，η₁ → −η₂，负号同样来自反周期边界条件的割缝 [page 4]。作者指出可以想象更大的阵列，用此过程执行基本编织操作 [page 4]。

## 结论成立的条件与实验边界

论文最后一段集中讨论实验实现的条件与限制，这些条件直接决定上述结论在什么范围内成立。

**材料与界面。** 首先需要具有稳健能隙的强 TI。Bi₁₋ₓSbₓ 和应变 HgTe 的能隙可达 30 meV 量级 [page 4]。其次需要与合适的超导体接口。Δ₀ 取决于界面质量、肖特基势垒和费米波长失配；若这些能优化，Δ₀ 可与体超导能隙相当 [page 4]。

**最简单的实验几何。** 单个线结，W ≪ ℏv/Δ₀。Δ₀ ~ 0.1 meV、ℏv ~ 1 eV·Å 时，W ≪ 1 μm 即可满足，应与石墨烯 SNS 结类似 [page 4]。马约拉纳特征的信号可通过测量通道热导探测：φ = π 时无能隙马约拉纳模的中心荷 c = 1/2，导致量子化 Landauer 热导 κ = (cπ²/3)(k_B²/h)T [page 4]。构造 Fig. 2 那样的三叉结对可以控制 MBS 的存在，进而可做 MBS 非局域性测试 [page 4]。

**操控与融合的能隙要求。** 结应足够短以满足 ΔE = ṽ/L > k_BT，又应足够长以使 MBS 良好局域化。作者指出好消息是 ΔE 随 L 幂律变化，而 MBS 重叠指数衰减，低温下两个条件可同时满足 [page 4]。

**非绝热与准粒子激发。** 若操控 MBS 的过程非绝热或 ΔE < k_BT，可能激发额外准粒子。若这些准粒子逃逸并与其他 MBS 相互作用，MBS 态会被扰动。但若 δ ≪ Δ₀，激发准粒子被限制在产生它们的段内；若把 δ 调高使 k_BT ≪ δ ≪ Δ₀ 并让系统弛豫回基态，MBS 态保持完好。**因此只要 k_BT 与 Δ₀ 之间有足够动态范围，系统可容忍这些激发** [page 4]。

## 论证结构与关键推理步骤

整篇论文的论证链条可以概括为：**表面态 H₀（Eq. 1）→ 近邻配对后 H（Eq. 2）→ 低能有效理论等价于无自旋 pₓ+ip_y 超导体（但时间反演不变）→ 涡旋零模（Eq. 3）→ 线结束缚态（Eq. 4）与有效 SSH 型 H̃（Eq. 6）→ 三叉结相图（Fig. 1(d)）→ 两端终止线结的 MBS 对与劈裂（Eq. 7–8）→ 电路中的融合（Eq. 10）与编织（Fig. 3(b)）**。

其中最关键的一步是 Eq. (6) 的推导：它把二维表面态在超导结中的低能物理约化为一个一维 Dirac/SSH 型哈密顿量，从而把 MBS 问题转化为一维拓扑缺陷问题。这一步的可靠性依赖于 W ≫ v/Δ₀ 和 q ≪ Δ₀/v 的近似，以及单狄拉克点的假设——后者正是与石墨烯 SNS 结分析的本质区别 [page 2]。

另一个容易被忽略但贯穿全文的推理节点是**反周期边界条件**。它来自线结弯折时基矢 a → e^{iτ_zθ/2}a 的变换，在圆环上 θ 增加 2π 时 a 变号 [page 2]。这个条件在 Eq. (10) 的推导和 Fig. 3(b) 的编织规则中都产生了一个负号，而这个负号正是非阿贝尔编织统计的体现。作者明确把这一点与 Ivanov 的编织算符对应起来 [page 3–4]。

## 适用条件与未讨论的限制

论文的结论在以下条件下成立：强 TI 具有稳健能隙；s 波超导体与 TI 表面形成高质量界面使 Δ₀ 足够大；线结宽度 W ≪ ℏv/Δ₀；温度满足 k_BT ≪ ΔE = ṽ/L 且 k_BT ≪ Δ₀；操控过程绝热或系统有足够动态范围弛豫 [page 4]。作者也承认实验实现“需要在多个方面取得进展”，包括寻找强 TI、优化界面、控制 Δ₀ [page 4]。

论文没有讨论的限制包括：具体材料参数下 Δ₀ 的实际可达值（作者只说“若可优化，可与体超导能隙相当”，未给出定量预测）；无序和杂质对表面态和 MBS 的影响；有限温度下热激发的定量估计；以及多体相互作用（超出 BdG 平均场）的效应。这些是分析者基于文本的推断，不是作者明确讨论的内容。

一个值得注意的边界是：论文的核心结论——涡旋处存在 MBS——是在 BdG 平均场层面证明的，作者通过求解 Eq. (2) 的零能解（Eq. 3）和构造有效理论（Eq. 6）来论证。MBS 的拓扑保护性来自能隙不关闭，这一点作者在讨论三叉结相图时明确使用（“MBS 不能在 φ_k 连续变化时消失，除非能隙关闭” [page 2]），但论文没有给出严格的拓扑不变量计算。这是分析者指出的一个论证强度边界：结论的稳健性依赖于能隙不关闭这一物理假设，而非显式的拓扑分类证明。
