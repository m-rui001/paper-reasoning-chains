# 碳氢化合物经验势的构建与验证：Brenner 金刚石 CVD 模拟势函数分析

**原文题名**：Empirical potential for hydrocarbons for use in simulating the chemical vapor deposition of diamond films
**作者**：Donald W. Brenner（美国海军研究实验室理论化学部）
**发表**：*Physical Review B*, Vol. 42, No. 15, 1990, pp. 9458–9471
**DOI**：10.1103/PhysRevB.42.9458

---

## 一、论文要解决的问题与核心主张

这篇论文的目标不是解释金刚石 CVD 的化学机理，而是为分子动力学（MD）模拟提供一个**可用的经验势函数**。作者在引言中明确指出，当时已有的量子化学方法（如 MNDO、LDF）虽然能计算反应路径和吸附能，但计算代价高，难以处理大体系或大量反应机制，也无法直接模拟基底温度的影响 [page 1]。而已有的经典势函数（如 Allinger 的分子力学力场）不能描述键的断裂与形成，因此无法用于模拟分子在金刚石表面的化学吸附 [page 2]。

作者的核心主张是：**一个经过高度参数化的 Tersoff 型键级（bond-order）势函数，经过针对自由基过结合（overbinding）和非局域共轭效应的修正后，能够同时描述金刚石、石墨以及大量碳氢分子的分子内成键，并可用于金刚石 CVD 相关表面结构的能量学计算** [page 1, page 2]。

这个主张包含两个层次：第一层是势函数的**可迁移性**——它能否在拟合数据之外的结构上给出合理结果；第二层是势函数对**金刚石表面重构和吸附**的预测是否与实验和第一性原理计算一致。论文的论证结构基本围绕这两层展开。

## 二、从 Abell-Tersoff 形式到碳氢势：关键修正及其理由

### 2.1 原始 Tersoff 形式为何不够

论文的势函数建立在 Abell-Tersoff 键级形式之上。Abell 提出的结合能表达式将总能量写为原子位点求和，每个位点的能量由近邻对相互作用乘以一个反映局域环境的键级因子 $B_{ij}$ 调制 [page 2, Eq. (1)–(3)]。Tersoff 随后将 $B_{ij}$ 参数化为局域配位数的函数，并成功描述了硅的多种固态结构 [page 2]。

但作者指出，这一形式在碳体系中存在两个根本问题 [page 2–3]：

**问题一：自由基过结合。** 当碳原子配位数不同时，式 (1)–(3) 会在单键和双键之间插值。例如，一个三配位碳与一个四配位碳成键时，势函数会给出介于单键和双键之间的键级。但物理上，四配位碳没有可用的 2p 轨道参与 $\pi$ 重叠，该键应被描述为单键加一个自由基轨道。这种过结合使得在拟合石墨的同时拟合金刚石空位形成能变得"困难甚至不可能" [page 3]。

**问题二：共轭与非共轭双键无法区分。** 在石墨中，每个碳原子局域配位数为 3，Tersoff 型势函数被拟合为给出适合石墨的键强度。但简单 Kekulé 结构分析表明，由于共轭效应，石墨中每个键约具有 1/3 双键和 2/3 单键特征。而在分子 (CH₃)₂C=C(CH₃)₂ 中，中心双键连接的两个碳原子具有与石墨相同的局域环境，但由于不共轭，该键几乎完全是双键特征。除非引入非局域效应，否则势函数无法同时描述这两种情况 [page 3]。

### 2.2 修正方案

作者将式 (1)–(3) 改写为**对键求和**的形式 [page 3, Eq. (4)–(5)]：

$$E_b = \sum_i \sum_{j(>i)} [V_R(r_{ij}) - B_{ij} V_A(r_{ij})]$$

其中 $B_{ij} = (B_{ij} + B_{ji})/2$。这一改写本身不改变物理内容，但为引入修正项提供了自然框架。

**自由基过结合的修正**通过函数 $F_i(N_i^{(H)}, N_i^{(C)}, N_i^{(t)})$ 实现，仅用于碳-碳键 [page 3, Eq. (6)–(11)]。该函数依赖于原子 $i$ 的氢邻居数、碳邻居数和总邻居数，通过多维三次样条插值在离散邻居数之间连续过渡 [page 4]。

**共轭效应的近似处理**通过定义 $N_{ij}^{\text{conj}}$ 实现 [page 4, Eq. (15)–(17)]。如果碳-碳键的任一端原子的邻居中有配位数小于 4 的碳原子，该键被定义为共轭体系的一部分。函数 $F(x_{ik})$ 在 $x_{ik} \leq 2$ 时为 1，在 $2 < x_{ik} < 3$ 时通过 $[1+\cos[\pi(x_{ik}-2)]]/2$ 连续过渡，在 $x_{ik} \geq 3$ 时为 0。当 $N_{ij}^{\text{conj}} = 1$ 时使用非共轭参数，$N_{ij}^{\text{conj}} \geq 2$ 时使用共轭参数。

这里的关键推理是：**共轭效应本质上是非局域的**（涉及多个原子的轨道重叠），但作者用一个仅依赖近邻配位数的解析函数来近似它。作者明确承认这是一种"近似"和"一阶近似"，不会给出共轭环体系中键级的细微差别，但好处是不需要对角化矩阵或超越近邻相互作用，从而大幅降低计算量 [page 9]。

## 三、参数化策略与两套势函数的取舍

### 3.1 拟合数据的选取

参数化分两步：先拟合纯碳和纯氢体系，再选择混合碳氢体系的参数以重现加和键能 [page 4]。

碳-碳键能来自分子原子化能的分解。作者使用乙炔、乙烯、乙烷、苯和环己烷的 0 K 生成热（分别为 2.356、0.629、−0.717、1.041 和 −0.868 eV），结合石墨的结合能 7.3768 eV 和分子氢的结合能 2.375 eV，得到这些分子的总原子化能分别为 17.149、23.626、29.723、57.472 和 73.634 eV。假设碳-氢键和碳-碳单键能量恒定，推导出碳-氢键能 4.362 eV，以及碳-碳三键、双键、共轭双键（苯中）和单键的能量分别为 8.424、6.175、5.216 和 3.547 eV [page 4]。

氢-氢对势项拟合到气相双原子分子性质，并重现 H + H₂ → H₂ + H 反应的 0.425 eV 势垒（在 H-H 距离 0.93 Å 处）[page 4–5]。

### 3.2 两套参数的权衡

作者给出了两套参数（势 I 和势 II），它们体现了**键长与力常数之间的权衡**：

- **势 I**（Table I, [page 5–6]）：碳-碳键长与实验值吻合很好，最大偏差仅 0.02 Å（单键），但拉伸力常数与实验值偏差高达 60% [page 4, Table II]。
- **势 II**（Table III, [page 7–8]）：力常数更接近实验值（单键、双键、三键的偏差分别降至 11%、8% 和 26%），但双键和三键的键长分别比实验值大 3.7% 和 7.5% [page 4, Table II]。

作者明确指出，**无法找到一组对势项参数同时拟合碳-碳拉伸力常数和键长**，尽管其他函数形式可能做到 [page 4]。这是一个诚实的负面结果，也解释了为何需要提供两套参数。

## 四、可迁移性验证：从分子到表面

### 4.1 分子原子化能

Table IV [page 10] 列出了势函数对烷烃、烯烃、炔烃、芳香烃和自由基的原子化能预测值与实验值的对比。作者报告，对于 81% 的测试分子，能量重现精度在 1% 以内 [page 9]。最差的拟合出现在 CH₃CH=C=CH₂ 和 H₂C=C=CH₂ 上，因为势函数将两个双键视为共轭体系的一部分，导致键能降低——这正是共轭近似失效的例子 [page 9]。

作者也承认，这种精度"可能有些偶然"，因为实验值的估算本身包含近似（未校正零点能和其他有限温度效应）[page 9]。

### 4.2 金刚石 (111) 表面重构

Table V [page 11] 给出了金刚石 (111) 表面几种重构方式的能量，并与 Vanderbilt 和 Louie 的 LDF 计算对比。势函数预测 **π 键链重构（π-bonded chain）是最稳定的**，与 LDF 结果和实验一致 [page 9]。作者特别指出，如果自由基能量学描述不正确，Tersoff 型势函数会错误地预测弛豫的体终止表面最稳定——这反过来说明自由基修正项的必要性 [page 9]。

氢吸附的计算表明，势函数正确预测氢吸附在能量上稳定，且**体终止表面上的吸附优于重构表面上的吸附** [page 9]。势 I 给出体终止表面氢吸附能为 −1.00 eV/(表面原子)，π 键链重构为 −0.61 eV/(表面原子)；势 II 给出 −1.13 和 −0.63 eV/(表面原子) [page 9]。

### 4.3 金刚石 (001) 表面二聚体重构

势 I 预测二聚体重构相对于体终止表面的稳定化能为 −5.49 eV/二聚体，表面二聚体键长 1.38 Å；势 II 给出 −5.20 eV/二聚体和 1.43 Å [page 9]。二聚体键长从乙烯中的双键距离被拉伸，键能相应减弱，作者将此归因于晶格应变 [page 9]。单氢化物相的碳-碳表面二聚体键长为 1.63 Å（势 I）和 1.60 Å（势 II），均从气相单键长度被拉伸 [page 11]。

## 五、CVD 相关能量学：从静态结构到趋势推断

### 5.1 氢抽取反应

作者用势函数检验了气相反应 CH₄ + H → CH₃ + H₂ 的势能面 [page 11, Eq. (20)]。势 I 给出 0.52 eV 的势垒，与实验阈值 0.52 eV 一致，也接近 Walch 从头计算估计的 0.58 eV。势 II 给出 0.72 eV，偏高 [page 11]。因此作者认为势 I 对氢抽取反应的描述更好。

从金刚石 (111) 表面移除一个氢原子是吸热的，势 I 为 4.13 eV，势 II 为 4.15 eV [page 11]。结合气相 H₂ 键能 4.75 eV，净放热约 0.6 eV。由于该表面的键合拓扑，移除第二个相邻氢原子所需能量与第一个基本相同，因此自由基位点应随机分布 [page 11–12]。

从二聚体重构 (001) 表面的单氢化物相移除一个氢原子是吸热的，势 I 为 4.44 eV，势 II 为 4.49 eV，因此被气相氢原子抽取是放热的约 0.3 eV。但移除同一二聚体对中另一个碳上的第二个氢原子仅需 2.9 eV（势 I）或 3.1 eV（势 II），这种吸热性的降低与表面两个碳原子之间形成部分双键一致 [page 12]。

### 5.2 单分子和单层吸附

Table VI [page 12] 给出了单个分子在氢终止 (111) 表面台阶位吸附的能量和分子内碳-碳键长。Table VII [page 13] 给出了单层覆盖的结果。

关键发现包括：
- 乙炔和乙烯吸附时，每个分子与表面形成两个单键，分子内碳-碳键级降低 1。化学吸附的乙炔中碳-碳键长等于气相双键长度，说明与 (001) 表面二聚体重构不同，晶格约束不抑制双键形成 [page 12]。
- 乙炔和乙烯化学吸附能的差值与它们的氢化热一致 [page 12]。
- 从单分子到单层，氢原子、乙炔基自由基和乙炔分子的吸附能降低（即结合更强），而甲基自由基和乙烯分子的吸附能升高，原因是非键合氢原子之间的相互作用 [page 13]。

### 5.3 对 CVD 趋势的推断

作者明确表示，**不能从这些能量中唯一地推断出具体的 CVD 生长模式**，但它们提示了一些可能的趋势 [page 13]：

1. 从 (111) 表面抽取单个氢原子应优于从二聚体重构 (001) 表面抽取。但抽取第二个氢原子在重构 (001) 表面上应强烈 favored，因为表面重构的键合拓扑允许形成双键。
2. 乙炔基或甲基自由基从氢终止 (111) 表面置换氢原子在能量上不强烈 favored。但乙烯，尤其是乙炔，可以在气相氢分子形成（而非两个 H 原子）的条件下从台阶位置换氢。
3. 单层甲基自由基在 (111) 表面上的吸附相对于氢吸附在能量上不利。但作者指出，这一预测"最多是不确定的"，因为势函数未包含氢原子之间的非键合空间相互作用，更好的估计可能需要使用 Allinger 分子力学等其他势函数 [page 13]。

## 六、结论成立的条件与边界

### 6.1 作者明确承认的局限

论文在第二节末尾和第五节系统列出了势函数的已知限制 [page 9, page 13]：

- **孤对电子未显式处理**：导致某些实验上弯曲的结构（如亚甲基）被预测为线性。
- **共轭定义仅为近似**：不会给出共轭环体系中键级的细微差别，CH₃CH=C=CH₂ 和 H₂C=C=CH₂ 的拟合误差即为例证。
- **碳-碳单键能小于金刚石中的值**：作者将此归因于氢导致的键弱化和空间排斥，并指出更精细的最小二乘拟合也显示类似差异。
- **未包含碳-碳键旋转势垒**（尤其是双键）和范德华力等非键合相互作用。
- **共振效应和 Woodward-Hoffmann 规则不一定被遵守**：作者明确警告，在解释经验势建议的反应机制时应谨慎，并尽可能用其他非经验方法重新检验 [page 9]。

### 6.2 分析性推断的边界

以下判断是分析者基于论文内容的推断，而非作者原话：

- 势函数对金刚石表面重构的预测与 LDF 一致，这支持了其可迁移性，但 LDF 本身也有近似，两者一致并不等于实验验证。
- 氢抽取反应势垒的吻合（势 I 的 0.52 eV vs 实验 0.52 eV）可能部分反映了参数化过程中对反应 (19) 的拟合，而非纯粹的预测能力。
- 单层甲基吸附能的不确定性（作者自己标注为"最多是不确定的"）意味着基于此的任何 CVD 机制推断都应视为暂定的。

### 6.3 适用条件

势函数的适用性建立在以下条件之上：

- **近邻相互作用假设**：只考虑最近邻原子间的相互作用，共轭效应通过局域配位数的解析函数近似。
- **短程性**：势函数是短程的，可快速求值，适合大规模 MD 模拟 [page 1, page 13]。
- **参数化范围**：拟合数据包括金刚石、石墨、简单立方和面心立方结构的结合能和晶格常数，以及金刚石和石墨的空位形成能 [page 4]。对超出此范围的结构，可迁移性是外推而非内插。
- **两套参数的取舍**：势 I 适合需要准确键长的场景，势 II 适合需要准确力常数的场景；氢抽取反应势 I 更优 [page 11]。

## 七、总结

Brenner 这篇论文的核心贡献是**一个计算高效、可描述键断裂与形成的碳氢经验势**，其论证逻辑是：从 Abell-Tersoff 形式出发，识别出自由基过结合和共轭/非共轭双键无法区分两个根本问题，通过引入键求和形式、自由基修正函数和共轭近似函数来解决，然后用大量分子的原子化能、金刚石表面重构能与 LDF 和实验的对比来验证可迁移性，最后用氢抽取和分子吸附能量学来展示其在 CVD 相关结构上的应用潜力。

论证中最关键的一步是**自由基过结合的修正**：没有这一修正，Tersoff 型势函数会错误地预测体终止表面最稳定，而修正后正确预测 π 键链重构最稳定 [page 9]。这一修正的必要性由金刚石空位形成能的拟合困难所驱动，其效果由表面重构能的正确预测所验证。

结论的边界在于：势函数对共轭效应的处理是近似的，对非键合相互作用和旋转势垒的缺失限制了其在某些场景下的定量可靠性，作者本人也警告不要过度解释经验势建议的反应机制。在这些限制之内，势函数为金刚石 CVD 的大规模 MD 模拟提供了一个可用的起点。
