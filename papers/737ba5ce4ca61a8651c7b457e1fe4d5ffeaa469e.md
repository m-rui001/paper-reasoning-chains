# 单簇翻转的集体更新：Wolff 算法如何绕开连续自旋模型的临界慢化

**原文**：Ulli Wolff, *Collective Monte Carlo Updating for Spin Systems*, Physical Review Letters **62**(4), 361–364 (1989). DOI: 10.1103/PhysRevLett.62.361

## 问题与主张

1987 年 Swendsen 与 Wang 提出的团簇算法（SW）在 Potts 模型上大幅改善了临界慢化，但推广到连续自旋模型（如 x-y 模型）时效果基本是负面的 [page 1]。Wolff 这篇短文要解决的就是这个落差：给出一个受渗流思想启发、能同时更新大团簇的 Monte Carlo 算法，并证明它在二维 O(n) 非线性 σ 模型上——包括 n=1（Ising）、n=2（x-y）以及 n=3（Heisenberg）——都能显著抑制临界慢化 [page 1]。

核心主张可以拆成两层。第一层是算法层面的：对任意 n≥2 的 O(n) 模型，可以用"随机反射 + 单簇生长"的方式构造一个满足细致平衡的更新步骤。第二层是数值层面的：在临界温度附近，长程可观测量的自关联时间 τ 折算成"每自旋扫描"后只有 1–2 步，且在 L 从 32 到 128 的范围内看不到随 L 增长的迹象 [page 1, page 2]。

## 从 Ising 翻转到连续自旋的反射

算法的关键概念是把 Ising 的 spin-flip 操作 σ_x → −σ_x 推广为对超平面的反射。对 n≥2 和任意单位向量 r ∈ S_{n−1}，定义

R(r)σ_x = σ_x − 2(σ_x·r)r  (2)

这是关于垂直于 r 的超平面的反射，显然幂等（R(r)²=1），且全局 R 变换保持作用量不变，因为 [R(r)σ_x]·[R(r)σ_y] = σ_x·σ_y (3)(4) [page 1]。

一次基本团簇更新包含四步：(a) 随机选反射向量 r 和起始格点 x；(b) 翻转 σ_x → R(r)σ_x 并标记 x；(c) 访问 x 到最近邻 y 的所有键，以概率

P(σ_x, σ_y) = 1 − exp(min[0, βσ_x·[1−R(r)]σ_y]) = 1 − exp[min[0, 2β(r·σ_x)(r·σ_y)]]  (5)

激活键；若激活则翻转 σ_y、标记 y 并并入团簇 c；(d) 对新加入格点的未标记邻居迭代，直到过程停止 [page 1]。

这里有一个值得注意的直觉：对连续自旋使用"离散"反射，初看似乎奇怪，但作者给出了物理解释——如果 r 与局部自旋方向近乎正交，反射 (2) 实际上是小形变，键概率 (5) 通常只长出小团簇；如果 r 与局部自旋（反）平行，团簇会一直生长到能量上可接受的表面为止 [page 2]。这个"要么小、要么长到边界"的行为，正是后面数值结果中团簇尺寸分布出现明显截断的来源。

## 细致平衡的证明与 SW 的联系

细致平衡的论证是全文推理最紧的一步。考虑两个仅相差团簇 c 上反射 R(r) 的构型 {σ_x} 和 {σ'_x}。转移概率之比为

W({σ_x}→{σ'_x}) / W({σ'_x}→{σ_x}) = ∏_{(xy)∈∂c} [1−P(R(r)σ_x, σ_y)] / [1−P(R(r)σ'_x, σ_y)] = exp[β Σ_{(xy)∈∂c} (σ'_x·σ_y − σ_x·σ_y)]  (6)

其中 ∂c 是 c 的表面，即所有 x∈c、y∉c 的键 [page 1]。推导中两个要点：一是 c 内部所有键的激活概率从 {σ_x} 或 {σ'_x} 出发都相同，这由 (3)(4) 保证；二是要长出特定的团簇 c，其表面键必须不被激活，这些概率正好提供 (6) 中不抵消的因子。注意 P(·,·) 左自变量出现 R(r)，是因为探测表面键 (xy) 时 σ_x 已经被翻转了 [page 2]。最终指数中出现的正是作用量能量差，与 Metropolis 算法类似 [page 2]。

作者还指出一个等价但效率较低的实现方式：先按相应概率激活格点所有键、分解成 SW 团簇，然后随机选一个格点、翻转它所在的 SW 团簇、忽略其余团簇。由于翻转的团簇可从其任一格点到达，选中某个特定 SW 团簇的概率正比于它占据的格点比例 |c_SW|/|Λ|。由此得到平均翻转团簇尺寸

⟨|c|⟩ = ⟨|c_SW|²⟩ / ⟨|c_SW|⟩  (7)

对 n=1，这正是磁化率 χ 的改进估计量，因此预期（并确实发现）χ = ⟨|c|⟩ [page 2]。作者进一步论证：临界 Ising 模型中 SW 团簇的平均尺寸是常数（因为团簇数正比于 L²），所以这个变体把相对更多的 CPU 时间投入到大的团簇上，理应带来更好的去关联行为 [page 2]。这一步是分析性推断，不是数值结论，但它解释了为什么新算法在 n=1 时可能优于 SW。

## 数值证据：自关联时间与团簇尺寸分布

Table I 列出了三种 O(n) 模型在 L³ 格点上的结果 [page 2]。Ising 模型取精确临界值 β_c = log(1+√2)/2；x-y 模型取 β=1.12（预期非常接近 Kosterlitz-Thouless 点，或可能略处于临界自旋波相），另外模拟了 β=1.04 和 1.07 以检查有限尺寸移动是否导致自关联时间上升；n=3 取 β=1.5、1.6，预期（并确认）空间关联长度约 10 和 20 [page 2]。

诊断量是磁化率 χ 和它表现出的自关联时间 τ_χ。测量之间间隔固定数目的 m 次团簇更新步（n=1,2 取 m=1，n=3 取 m=10）。τ_χ 由自关联函数的指数衰减确定，所有表项都基于在至少从 τ_χ 到 3τ_χ 的窗口内看到稳定对数比 [page 3]。误差估计采用两种方法：从稳定性窗口的涨落主观估计，以及把数据分成 1000 次测量的块；两种结果总在 10% 以内一致 [page 3]。有效自关联时间定义为

τ_eff = (ε_block/ε_naive)²  (9)

即块误差与朴素误差之比的平方，恰好指数自关联会产生相同误差 [page 3]。

关键的换算关系是

τ_χ = τ_eff · m · ⟨|c|⟩ / L³  (8)

作者称这是与局部算法中常见的"扫描"可比的量：τ_χ=1 意味着平均每个自旋被"触碰"（这里是反射）一次就能把关联压低 1/e [page 3]。Table I 中 n=1 的 τ_χ 在 1.9–3.6 之间，n=2 在 1.1–1.5 之间，n=3 在 0.25–0.50 之间 [page 2]。作者明确说这些值"signal an enormously enhanced efficiency" [page 3]。

Fig. 1 给出 L=128 时三种模型的团簇尺寸分布 [page 3]。两个临界模型（n=1,2）看起来相似，而 O(3) 中有限的物理关联长度表现为明显的截断 [page 3]。这直接对应前面"要么小、要么长到边界"的直觉：临界时团簇可以长到整个格点尺度，非临界时被关联长度截断。

## 结论成立的条件与作者承认的边界

作者对结论的限定相当克制。首先，他明确说"To quote values for dynamical exponents is beyond the scope of the present paper"，即本文不给出动力学指数 z 的数值，只报告 τ_χ 的量级 [page 2]。其次，τ_χ 的误差是"subjectively"估计的，来自稳定性窗口的涨落和重复实验 [page 3]——这意味着 Table I 中的误差棒不是严格的统计误差。

第三，作者报告了一个负面结果：对极短程量（如最近邻关联）和 n=2,3，看到稍长的关联时间，最高到 τ=4，但在 L 中是平坦的 [page 3]。他随即指出这些可观测量的物理意义较小，且如果短波模式演化太慢，总可以穿插局部更新步 [page 3]。这是一个诚实的边界说明：算法对长程量高效，对短程量未必。

第四，关于 x-y 模型的临界点，作者说 β=1.12 "is expected to be very close to the Kosterlitz-Thouless point or possibly somewhat beyond in the critical spin-wave phase" [page 2]——即临界点的精确位置本身有不确定性，这影响 τ_χ 是否在真正的临界点上测量。他用 β=1.04 和 1.07 的模拟来检查有限尺寸移动是否导致自关联时间上升，但没有报告发现上升。

第五，作者提到 Z(16)=O(2) 的对照运行（反射适当限制）产生与 O(2) 不可区分的结果，且速度差异很小，因此"there is consequently no need for the discrete spin approximation" [page 3]。这支持了算法对连续自旋的适用性，但 Z(16) 毕竟不是连续群，这个对照的说服力有限。

最后，作者在结论中把算法的推广方向列为"should also be useful"和"seems straightforward"——对四维 O(4) 模型、自旋玻璃、神经网络、格点规范理论的推广都是预期而非已验证 [page 3]。这些是作者明确标记为未来工作的部分，不应读作本文的结论。

## 推理链的要点

整篇论文的推理可以概括为：SW 算法在 Potts 模型上成功，但推广到连续自旋时效果负面 [page 1]；Wolff 的变体用"随机反射 + 单簇生长"替代 SW 的"全格点键激活 + 多簇翻转"，其细致平衡由 (6) 保证 [page 1]；对 n=1，新算法的平均团簇尺寸等于磁化率，且比 SW 更偏向大团簇 [page 2]；数值上，τ_χ 折算成每自旋扫描后只有 1–2 步，且在 L=32 到 128 范围内看不到临界慢化 [page 1, page 2]。关键的一步是 (6) 的推导——它把团簇表面键的不激活概率与作用量能量差联系起来，使得反射操作满足细致平衡。没有这一步，整个算法就只是启发式的团簇生长，无法保证正确的平衡分布。

一个值得注意的对照是作者在参考文献 8 中提到的 Niedermayer 的工作：Niedermayer 用"实际上相同的算法"得到负面结果——要么整个格点变成一个团簇，要么大非平凡团簇因表面能而很少移动。Wolff 说这个挫折"led to the present algorithm, where a cluster, once created, is always flipped" [page 3]。这个细节说明：新算法的关键改进不是团簇生长本身，而是"一旦创建就总是翻转"——即单簇翻转而非 SW 的多簇同时翻转。这个选择避免了 Niedermayer 遇到的表面能障碍，因为单簇翻转不需要同时满足多个团簇的表面条件。

## 总体判断

这是一篇方法论文，其价值主要在于算法构造和初步数值验证，而非物理结论。作者对结论的限定（不给出 z、误差主观、短程量有例外、临界点位置不确定）与主张的强度是匹配的。数值证据支持"在二维 O(n) 模型临界点附近，该算法的长程量自关联时间折算后为 O(1) 每自旋扫描"这一结论，但支持范围限于 L≤128、n≤3、二维。对更高维、更大 L、其他模型（自旋玻璃、规范理论）的推广是作者的预期，不是本文已验证的结果。
