# 线性混合效应模型中的显著性评估：模拟证据与推荐方法

**原文题名**：Evaluating significance in linear mixed-effects models in R（2016）
**DOI**：https://doi.org/10.3758/s13428-016-0809-y

## 问题与主张

这篇论文处理的是一个在应用统计中相当具体、却困扰大量研究者的难题：在 R 的 lme4 包中拟合线性混合效应模型时，输出只给出固定效应的 t 值，而不给出 p 值。作者 Luke 指出，lme4 之所以默认省略 p 值，是因为在混合模型中分母自由度并不明确——尤其当设计是交叉的（crossed）或数据不平衡时，究竟该用观测数（level 1）、被试/项目数（level 2）、分组因子数，还是它们的某种组合来定义自由度，并没有显然的答案 [page 1]。但许多期刊和写作规范仍要求报告 p 值，因此研究者实际中必须选择某种方法来评估显著性。

论文的核心主张可以概括为：**在常用的两类方法（似然比检验 LRT 与 t-as-z）都偏于反保守（anti-conservative，即实际 Type 1 错误率高于名义 0.05）的背景下，若用 REML 拟合模型、再用 Kenward-Roger 或 Satterthwaite 自由度近似来推导 p 值，Type 1 错误率最接近 0.05，且对样本量最不敏感** [page 1, page 7]。这一结论由一系列模拟支撑，而非理论证明。

## 从证据到结论：模拟如何展开

作者的论证方式是模拟实验。所有模拟都用 SIMGEN 包生成数据，设定一个连续反应变量和一个被试内、项目内的两水平预测变量，并把固定效应大小设为 0，这样任何"显著"结果都代表 Type 1 错误 [page 2]。这一设计选择是理解全文的关键：它把问题从"能否检出真实效应"暂时转化为"在零效应下会不会误报"。

**第一组模拟**比较 LRT 与 t-as-z。对 5 种被试数（12、24、36、48、60）与 5 种项目数（12、24、36、48、60）的 25 种组合，各生成 100,000 个数据集，分别用 ML 和 REML 拟合最大模型 [page 2–3]。结果见 Fig. 1 [page 4]：所有方法的 Type 1 错误率都偏高，最高达 0.08，且 0.05 从未落入任何模拟的 95% 置信区间 [page 3]。在 ML 拟合下，t-as-z 的错误率始终高于 LRT，差距在样本较小时最大。一个值得注意的发现是：REML 拟合下 t-as-z 的错误率低于 ML 拟合，且这一优势在小样本时更明显 [page 3]。

这里有一个对理解结论边界很重要的细节。作者指出，Type 1 错误率取决于第二层分组的数量，而不只是数据点总数。例如 24 被试 × 24 项目与 12 被试 × 48 项目的数据点总数相同（576），但前者的错误率更低 [page 3]。这意味着"用大量项目弥补被试不足"（或反之）在控制错误率上行不通——这一点在总讨论中被再次强调 [page 6]。

**第二组模拟**引入新方法：Kenward-Roger 与 Satterthwaite 自由度近似（用 lmerTest 包的 anova 函数实现），以及参数自助法（parametric bootstrapping，用 afex 包实现）。由于这些方法计算量大，样本组合缩减为 7 种（被试 12、24、36，项目 12、36、60），lmerTest 模拟用 10,000 个数据集，afex 模拟仅用 1,000 个 [page 4–5]。

结果见 Fig. 2 与 Fig. 3 [page 5–6]。Satterthwaite 近似用于 ML 模型时仍略偏反保守；但用于 REML 模型时，与 Kenward-Roger（本身只用于 REML）产生的错误率高度接近，且不再明显反保守——0.05 稳定落在置信区间内，并且在小样本下也保持稳定 [page 4, page 6]。参数自助法优于 LRT 和 t-as-z，平均错误率比 LRT 低 0.0076，但仍对样本量敏感，小样本时可能反保守 [page 5]。

## 关键推理与桥接

从证据到"推荐 Kenward-Roger/Satterthwaite + REML"这一结论，中间有一步推理需要点明。作者并未证明这两种近似在理论上给出了"正确"的自由度；相反，他明确写道，这些模拟**不应被解读为确立了线性混合模型真正合适的自由度是多少**，这些方法"至多只是权宜之计（at best ad hoc solutions）" [page 8]。因此，推荐的基础是经验性的：在模拟覆盖的样本范围内，这两种方法产生的 Type 1 错误率最接近名义水平，且最不随样本量波动。换言之，结论的力度是"在这些模拟条件下表现最好"，而非"理论上正确"。

作者还处理了一个可能的反驳：更保守的方法是否以损失统计效力（power）为代价？他用 100 个数据集、固定效应设为 0.8 的小型模拟计算了 power，并用 Barr 等（2013）的方法计算了校正后 power（power'），即在控制 Type 1 错误率后的效力 [page 7–8]。Table 1 [page 7] 显示，Kenward-Roger 与 Satterthwaite（REML）的未校正 power 略低，但校正后各方法高度接近，说明效力差异可归因于错误率差异，采用这两种方法不应造成明显的效力损失。作者同时提醒这些效力模拟规模很小，解释需谨慎 [page 8]。

## 结论成立的条件与边界

论文自己承认的限制值得逐条交代，因为它们直接界定了推荐方法的适用范围。

其一，**数据与模型被理想化**。模拟使用的是相对理想的数据和简单的单因子模型，因此观察到的 Type 1 错误率未必适用于协方差结构更复杂的模型。作者引用 Schaalje 等（2002）指出，Kenward-Roger 近似虽然总体稳健，但在复杂协方差结构叠加小样本时可能导致错误率膨胀 [page 7]。

其二，**"小样本"仍有下限**。作者特别提醒，模拟中的"小"样本至少包含 144 个数据点 [page 7]。因此"小样本下仍稳健"这一说法不能被外推到数据点极少的场景。

其三，**方法选择受实现限制**。Kenward-Roger 只适用于 REML 模型，参数自助法则不提供 ML/REML 的选择；只有在方法允许选择时，REML 才应被优先 [page 7]。此外，MCMC 抽样因无法处理随机相关参数、且已从当前 lme4 中移除，不在可行选项之列 [page 1–2]。

其四，**结论是经验性的、非理论性的**，如前所述 [page 8]。

## 一个附带的实践判断

论文还顺带评估了一个常见做法：把 t > 2 当作显著（t-is-2）。作者用第一组模拟数据发现，该方法的错误率与 LRT 相近，小样本时略高、大样本时略低，因此比 t-as-z 可取，可作为经验法则，但仍对样本量敏感 [page 6]。这属于对主论证的补充，而非核心结论。

## 总体判断

这篇论文的论证结构清晰：先确立问题（lme4 不给 p 值，而研究者需要），再通过零效应模拟量化常用方法的错误率，最后在多种备选方法中按"最接近 0.05 且最不依赖样本量"的标准选出推荐方案。其说服力来自模拟规模（第一组每组 100,000 个数据集）和跨样本量、跨 ML/REML 的系统比较；其谨慎之处在于作者反复强调这些方法是权宜之计，并最终建议研究者不要盲目依赖任何 p 值，而应结合参数估计与标准误做判断 [page 8]。因此，最稳妥的读法是：在论文模拟所覆盖的、结构相对简单的模型与中等以上样本条件下，REML + Kenward-Roger/Satterthwaite 是当前可得方法中错误率控制最好的选择；超出这一范围时，结论的确定性随之下降。
