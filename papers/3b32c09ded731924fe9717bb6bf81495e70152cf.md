# 毫米波MIMO中的空间稀疏预编码：从硬件约束到稀疏重构的论证链

**原文题名**：Spatially Sparse Precoding in Millimeter Wave MIMO Systems（2013，arXiv:1305.2460v1 [cs.IT]）

## 问题起点：硬件约束如何把预编码变成另一类问题

这篇论文要解决的是一个由硬件现实逼出来的设计难题。毫米波频段比微波频段高约十倍，自由空间路损随之增加数个量级，因此必须依靠大规模天线阵列提供的波束成形增益来补偿 [page 2]。但传统MIMO的数字基带预编码要求每根天线配备独立的基带与射频链路，而毫米波混合信号器件的高成本与高功耗使这种架构在当下不可行，系统被迫依赖模拟或射频处理 [page 2]。模拟预编码通常用移相器实现，这给射频预编码矩阵的每个元素加上了恒模约束 [page 2]。

于是作者面对的系统是：发射端有 $N_t$ 根天线但只有 $N_t^{\mathrm{RF}}$ 条发射链路（$N_s \le N_t^{\mathrm{RF}} \le N_t$），先施加一个 $N_t^{\mathrm{RF}} \times N_s$ 的基带预编码器 $\mathbf{F}_{\mathrm{BB}}$，再经过一个由移相器实现的 $N_t \times N_t^{\mathrm{RF}}$ 射频预编码器 $\mathbf{F}_{\mathrm{RF}}$，其元素满足 $(\mathbf{F}_{\mathrm{RF}}^{(i)}\mathbf{F}_{\mathrm{RF}}^{(i)*})_{\ell,\ell} = N_t^{-1}$，即等模约束 [page 4–5]。接收端对称地有 $\mathbf{W}_{\mathrm{RF}}\mathbf{W}_{\mathrm{BB}}$ [page 5]。信道采用扩展Saleh-Valenzuela的簇模型（式(4)），由 $N_{\mathrm{cl}}$ 个散射簇、每簇 $N_{\mathrm{ray}}$ 条路径叠加而成，阵列响应向量 $\mathbf{a}_t(\varphi_{i\ell}^t,\theta_{i\ell}^t)$ 是恒模相位向量 [page 6–7]。

核心结论是：**利用毫米波信道的稀疏散射结构，可以把混合预编码/合并的设计转化为稀疏重构问题，用正交匹配追踪（OMP）求解，从而在低成本射频硬件下逼近无约束最优预编码的频谱效率** [page 1, page 3–4]。

## 关键推理的第一步：把"最大化互信息"换成"逼近最优预编码器"

直接最大化式(3)的频谱效率需要对 $\mathbf{F}_{\mathrm{RF}}, \mathbf{F}_{\mathrm{BB}}, \mathbf{W}_{\mathrm{RF}}, \mathbf{W}_{\mathrm{BB}}$ 四个矩阵联合优化，而 $\mathbf{F}_{\mathrm{RF}}$ 和 $\mathbf{W}_{\mathrm{RF}}$ 上的非凸恒模约束使全局最优几乎不可求 [page 8]。作者先解耦收发两端，只设计 $\mathbf{F}_{\mathrm{RF}}\mathbf{F}_{\mathrm{BB}}$ 以最大化高斯信号下的互信息式(8) [page 8]。

真正的转折在于：作者不直接优化互信息，而是证明互信息可以被"混合预编码器与信道最优无约束预编码器之间的距离"所控制。设信道SVD为 $\mathbf{H}=\mathbf{U}\boldsymbol{\Sigma}\mathbf{V}^*$，最优无约束预编码器为 $\mathbf{F}_{\mathrm{opt}}=\mathbf{V}_1$（$\mathbf{V}_1$ 取前 $N_s$ 个右奇异向量）[page 9]。在**近似1**下——即假设系统参数使 $\mathbf{V}_1^*\mathbf{F}_{\mathrm{RF}}\mathbf{F}_{\mathrm{BB}} \approx \mathbf{I}_{N_s}$ 且 $\mathbf{V}_2^*\mathbf{F}_{\mathrm{RF}}\mathbf{F}_{\mathrm{BB}} \approx \mathbf{0}$ [page 10]——作者通过Schur补恒等式和高有效SNR近似，把互信息化简为式(14)：

$$I(\mathbf{F}_{\mathrm{RF}},\mathbf{F}_{\mathrm{BB}}) \approx \log_2\left|\mathbf{I}_{N_s}+\frac{\rho}{N_s\sigma_n^2}\boldsymbol{\Sigma}_1^2\right| - \left(N_s - \|\mathbf{V}_1^*\mathbf{F}_{\mathrm{RF}}\mathbf{F}_{\mathrm{BB}}\|_F^2\right)$$

第一项正是最优预编码器 $\mathbf{F}_{\mathrm{opt}}$ 的互信息，第二项刻画混合预编码器与它的偏离 [page 11]。由此，最大化互信息近似等价于最小化 $\|\mathbf{F}_{\mathrm{opt}}-\mathbf{F}_{\mathrm{RF}}\mathbf{F}_{\mathrm{BB}}\|_F$，即把 $\mathbf{F}_{\mathrm{opt}}$ 投影到可行混合预编码器集合上（式(15)）[page 12]。

这里有一个值得读者注意的桥接：作者明确说明，式(14)的推导依赖的"高SNR"不是标称SNR高（这在毫米波中是不合理的假设），而只是信道主导 $N_s$ 个子空间中的**有效SNR**足够高——这些有效SNR包含了毫米波波束成形带来的大阵列增益 [page 11, 脚注2]。这是整个近似链条中最容易被误读的一步。

## 关键推理的第二步：为什么可以用阵列响应向量做基

式(15)的投影问题本身仍因 $\mathcal{F}_{\mathrm{RF}}$ 的非凸性而难以求解 [page 12]。作者的突破口来自对毫米波信道结构的观察 [page 12–13]：

1. 最优预编码器 $\mathbf{F}_{\mathrm{opt}}=\mathbf{V}_1$ 的列张成信道的行空间；
2. 簇信道模型式(4)中的阵列响应向量 $\mathbf{a}_t(\varphi_{i\ell}^t,\theta_{i\ell}^t)$ 也张成同一行空间——当 $N_{\mathrm{cl}}N_{\mathrm{ray}} \le N_t$ 时它们以概率一线性独立，构成另一组基（对ULA，这些向量构成Vandermonde矩阵，角度互异时满秩；对UPA可写成两个ULA响应向量的Kronecker积）[page 12–13]；
3. 因此 $\mathbf{F}_{\mathrm{opt}}$ 的列可写成这些阵列响应向量的线性组合；
4. 而这些向量恰是恒模相位向量，可以直接用移相器在射频端实现 [page 13]。

于是把 $\mathbf{F}_{\mathrm{RF}}$ 的列限制为阵列响应向量，问题变为式(16)，再引入辅助变量 $\mathbf{A}_t$（所有阵列响应向量组成的矩阵）和 $\tilde{\mathbf{F}}_{\mathrm{BB}}$，得到式(17)：

$$\tilde{\mathbf{F}}_{\mathrm{BB}}^{\mathrm{opt}} = \arg\min_{\tilde{\mathbf{F}}_{\mathrm{BB}}} \|\mathbf{F}_{\mathrm{opt}}-\mathbf{A}_t\tilde{\mathbf{F}}_{\mathrm{BB}}\|_F, \quad \text{s.t.} \quad \|\mathrm{diag}(\tilde{\mathbf{F}}_{\mathrm{BB}}\tilde{\mathbf{F}}_{\mathrm{BB}}^*)\|_0 = N_t^{\mathrm{RF}}, \quad \|\mathbf{A}_t\tilde{\mathbf{F}}_{\mathrm{BB}}\|_F^2 = N_s$$

稀疏约束 $\|\mathrm{diag}(\tilde{\mathbf{F}}_{\mathrm{BB}}\tilde{\mathbf{F}}_{\mathrm{BB}}^*)\|_0 = N_t^{\mathrm{RF}}$ 意味着 $\tilde{\mathbf{F}}_{\mathrm{BB}}$ 至多有 $N_t^{\mathrm{RF}}$ 个非零行，等价于从 $\mathbf{A}_t$ 中"选出" $N_t^{\mathrm{RF}}$ 列 [page 13–14]。这正是稀疏信号恢复中多测量向量的同时稀疏逼近问题，可用OMP求解（算法1）[page 14–15]。

## 接收端：同一框架的平移

第三节暂时假设接收端能做最优解码，但实际毫米波接收机必须在模拟域先合并信号，无法访问 $N_r$ 维接收信号 [page 8, page 17]。第四节因此设计混合合并器 $\mathbf{W}_{\mathrm{RF}}\mathbf{W}_{\mathrm{BB}}$ 以最小化MSE（式(19)）[page 17]。无约束MMSE合并器 $\mathbf{W}_{\mathrm{MMSE}}$ 由式(20)给出，但同样无法分解为满足恒模约束的射频/基带乘积 [page 18]。

作者通过展开MSE并添加与优化变量无关的常数项，把问题等价地改写为式(23)：最小化 $\|\mathbb{E}[\mathbf{y}\mathbf{y}^*]^{1/2}(\mathbf{W}_{\mathrm{MMSE}}-\mathbf{W}_{\mathrm{RF}}\mathbf{W}_{\mathrm{BB}})\|_F$ [page 18–19]。与预编码侧的区别在于，这里的投影是 $\mathbb{E}[\mathbf{y}\mathbf{y}^*]$-加权的Frobenius范数，而非标准范数 [page 19]。同样的稀疏结构论证把 $\mathbf{W}_{\mathrm{RF}}$ 的列限制为接收阵列响应向量 $\mathbf{a}_r(\varphi,\theta)$，得到式(24)，再用OMP求解（算法2）[page 19]。

作者承认收发设计仍是解耦的：设计 $\mathbf{F}_{\mathrm{RF}}\mathbf{F}_{\mathrm{BB}}$ 时假设接收最优，设计 $\mathbf{W}_{\mathrm{RF}}\mathbf{W}_{\mathrm{BB}}$ 时假设预编码固定 [page 20]。为缓解这一局限，作者提出式(25)的规则：从约束更强的一侧先设计，再据此更新有效信道设计另一侧 [page 20]。作者明确指出，更直接的联合优化是未来工作 [page 21]。

## 仿真证据如何支撑结论

仿真采用 $N_{\mathrm{cl}}=8$、$N_{\mathrm{ray}}=10$、Laplacian角度分布、发射端60°方位/20°俯仰扇区天线、接收端全向天线、半波长间距 [page 22]。

**图3**（64×16系统，4条射频链路）显示：$N_s=1$ 时稀疏预编码与合并的频谱效率与最优无约束预编码"基本相等"，$N_s=2$ 时与最优有"小差距"；相比传统波束 steering 有"不可忽略的改进" [page 23–24]。**图4**（256×64系统，6条射频链路）显示 $N_s=1$ 和 $N_s=2$ 时都"几乎完美"，且比波束 steering 好约5 dB [page 24]。**图5**（256×64，4条射频链路，注水功率分配）显示稀疏方案能逼近信道容量，且大幅优于波束 steering；作者指出由于复用增益受 $N_s \le \min\{N_t^{\mathrm{RF}},N_r^{\mathrm{RF}}\}$ 限制，极高SNR下无法逼近容量，但在0 dB时仍与容量差距很小 [page 25]。

**图6**考察角度扩展的影响：角度扩展低时性能接近无约束预编码；随角度扩展增大性能缓慢下降，但在两个 $N_s=1$ 的配置中，即使角度扩展达15°，速率差距仍低于10%，在约5°的合理角度扩展下差距可忽略；$N_s>1$ 且阵列较小时性能下降更快，可通过增加射频链路数缓解 [page 26]。**图7**考察有限反馈：每个角度3比特通常足够，64×16系统 $N_s=1$ 时甚至2比特就接近完美；作者给出经验法则——阵列宽度（或高度）每翻倍，方位（或俯仰）角度量化加1比特 [page 27]。作者据此估算量化一个64×1预编码器不超过20比特，64×2约22比特，相比传统MIMO的4–6比特反馈，空间稀疏性帮助大幅压缩了反馈开销 [page 28]。

## 结论成立的条件与边界

这篇论文的结论有明确的适用边界，作者在文中多处主动交代：

**近似1是整个推导的枢纽假设**。它要求混合预编码器能足够"接近"最优酉预编码器，作者认为在以下系统中该近似会较紧：(i) 天线数 $N_t$ 相当大，(ii) 发射链路数满足 $N_s < N_t^{\mathrm{RF}} \le N_t$，(iii) 信道矩阵相关 [page 10]。换言之，如果天线数不够大、射频链路数太少或信道散射过于丰富，这一近似可能失效，后续的"最小化距离等价于最大化互信息"的推理链也随之松动。

**稀疏性假设**。整个方法依赖毫米波信道散射有限，使阵列响应向量构成有效的稀疏基。图6直接显示：角度扩展增大（散射变丰富）时性能下降，$N_s>1$ 且阵列小时下降更快 [page 26]。作者在Remark 4中指出，在大阵列极限（$N_t,N_r\to\infty$）且散射极弱（$N_{\mathrm{cl}}N_{\mathrm{ray}}=o(\min(N_t,N_r))$）时，简单射频波束 steering 反而最优；但对实际尺寸阵列，更复杂的预编码仍有显著增益 [page 17]。

**信道知识假设**。第三节假设发射端和接收端都完美、即时地知道 $\mathbf{H}$ [page 5]。第五节用有限反馈放松了这一假设，但作者明确将有限反馈性能的严格分析留作未来工作 [page 4, page 21]。此外，作者在结论中列出未来工作需放松的假设：接收端完美CSI、已知天线阵列结构、窄带信道 [page 28]。

**解耦设计的局限**。预编码与合并器是分别设计的，作者承认更直接的联合优化值得研究 [page 21]。Remark 5举了一个具体场景说明解耦可能有害：接收端只有单条射频链路时，发射端向多个方向辐射功率可能导致实际接收功率损失 [page 20]。

**推导与仿真的一个不一致**。作者在讨论图5时主动指出，式(14)的推导并未考虑流间不等功率分配，但图5表明算法1对这类预编码器仍是合理方法 [page 25]。这是一个作者自己标注的、推导覆盖范围与仿真验证范围之间的缝隙。

## 总体判断

这篇论文的论证力量在于一条清晰的归约链：硬件约束使直接优化不可行 → 用近似1把互信息最大化归约为到最优预编码器的距离最小化 → 用毫米波信道的稀疏结构把距离最小化归约为稀疏重构 → 用OMP求解。每一步归约都附带了明确的成立条件，而仿真结果在多个系统配置和角度扩展下检验了最终性能。最关键的推理转折是近似1——它既是把互信息表达式化简为式(14)的前提，也是把"预编码设计"重新解释为"投影到可行集"的合法性来源。读者若要判断这篇论文的结论在何种新场景下仍成立，最应审视的正是这一近似在目标场景中是否足够紧。
