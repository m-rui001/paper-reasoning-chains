# 纯有机电致发光材料实现电能到光能的100%转换

**原文题名**：Purely organic electroluminescent material realizing 100% conversion from electricity to light
**年份**：2015　**DOI**：10.1038/ncomms9476

## 论文要解决的问题与核心主张

有机发光二极管（OLED）的效率瓶颈在于激子的自旋统计：电激发下单重态与三重态激子按1:3生成，而普通荧光材料只能利用单重态发光，因此内量子效率（IQE）的理论上限仅为25% [page 2]。突破这一限制的既有方案是重金属（Pt、Ir）配合物的磷光路线，借助重原子效应让三重态也发光，但这类金属稀缺且昂贵 [page 2]。另一条思路是反向系间窜越（RISC）：让三重态激子（T₁）回到单重态（S₁）再辐射发光，即热活化延迟荧光（TADF）。TADF 的困难在于，RISC 需要 S₁ 与 T₁ 的能隙 ΔE_ST 足够小，而缩小 ΔE_ST 的常规手段——分离 HOMO 与 LUMO 的空间分布——会同时削弱 S₁→S₀ 的振子强度 f，降低发光量子产率。作者把这一矛盾称为“有效发光与三重态-单重态上转换之间的典型权衡（trade-off）” [page 2]。

论文的核心主张是：通过精细调控 HOMO/LUMO 分布，可以同时实现近乎为零的 ΔE_ST 和足够大的 f，从而在纯有机材料 DACT-II 上同时获得约100%的光致发光量子产率（PLQY）和约100%的三重态到单重态上转换，使 OLED 的 IQE 达到约100%，即“电能到光能的100%转换” [page 1, page 2]。器件层面，无外耦合处理时最大外量子效率（EQE）为29.6%，加外耦合片后为41.5%，在3,000 cd m⁻² 高亮度下仍达30.7% [page 1]。

## 材料设计：如何绕开权衡

DACT-II 的分子设计是论证的起点。它由给电子的二苯氨基咔唑与受电子的三苯基三嗪通过一个扭转角 α 连接（Fig. 1b）[page 2]。作者用 PBE0/6-31G(d) 水平的计算显示，HOMO 与 LUMO 在空间上分离（Fig. 1c）[page 2]，这正是获得小 ΔE_ST 的结构基础。但分离本身会降低 f，因此关键在于扭转角 α 的精确控制：TD-DFT 计算表明 f 随 α 增大而减小，α=0° 为平面构型、90° 为垂直构型（Supplementary Fig. 1）[page 6]。DACT-II 的 f 计算值为 0.2400，高于对照材料 4CzIPN 的 0.0708 [page 6]。S₀、T₁、S₁ 的能量极小分别位于 α=48°、85°、89°，由 S₁ 与 T₁ 能量极小之差得到计算 ΔE_ST 为 5.2 meV，小于同水平下 4CzIPN 的 11.3 meV [page 6]。

这里的关键推理是：作者并非简单地“分离 HOMO/LUMO 以减小 ΔE_ST”，而是主张通过控制扭转角，在保持 HOMO/LUMO 分离（小 ΔE_ST）的同时维持足够的轨道重叠（大 f）。这是全文论证的枢纽——如果这一点不成立，后续所有效率数据都无从解释。需要说明的是，计算给出的 5.2 meV 与实验拟合的 9.0 meV 并不完全一致，作者也未将二者等同，而是分别作为计算与实验证据使用。

## 从光物理证据到“上转换约100%”

作者用多条独立证据链支撑“三重态被有效上转换”这一结论。

**PLQY 的氧气敏感性**。DACT-II 在甲苯中的 PLQY 为46.0%，通 O₂ 后降至26.6%，通 Ar 除氧后升至63.7% [page 3]。作者的解释是：部分激子经 ISC 转移到 T₁ 后被溶解氧淬灭；除氧后 T₁ 激子得以经 RISC 回到 S₁，因而 PLQY 升高 [page 3]。这一解释依赖“延迟发光来自 RISC 而非磷光”的前提，作者随后专门排除了磷光。

**延迟发光的温度依赖性**。瞬态 PL 衰减显示 prompt 与 delayed 两个组分（Fig. 3a, 3b）[page 4]。区分延迟荧光与磷光的判据是温度依赖方向：延迟荧光随温度升高而增强，磷光则相反。实验观察到延迟组分在10 K 时缺失、随温度升高逐渐增强（Supplementary Fig. 8），说明该延迟发光是热活化的，即 TADF [page 4]。此外，prompt 与 delayed 组分的 PL 谱在实验误差内不可区分（Supplementary Fig. 9），进一步支持延迟组分来自 TADF 而非磷光 [page 6]。

**排除 TTA 机制**。延迟荧光也可能来自三重态-三重态湮灭（TTA），但 TTA 机制下 β 理论上限为62.5% [page 4]。作者指出本研究 IQE 达到100%，因此延迟荧光只能来自 RISC [page 4]。这是一个以效率上限反推机制的论证：如果 β 真能超过62.5%，TTA 解释就不成立。

**ΔE_ST 的实验测定**。由 k_RISC 的 Arrhenius 图（Fig. 3c）拟合得到 ΔE_ST = 9.0 meV [page 4]。这一数值小于室温热能 25.9 meV [page 5]。作者进一步用 Boltzmann 因子 exp(−ΔE_ST/k_BT) 作对比：DACT-II 在300 K 时为0.71，远大于 4CzIPN 的0.041（Fig. 3d），说明 DACT-II 中 RISC 更易发生 [page 5]。Table 2 显示，6 wt% 掺杂薄膜的总 PLQY 在200–300 K 范围内维持在约98–100%，即上转换在较宽温度区间都有效 [page 5]。

综合这些证据，作者得出“约100%的三重态到单重态上转换”与“约100%辐射发射”的结论。需要留意的是，PLQY 数值带有 ±4% 的误差（如101.1±4%、100.3±4%）[page 3, page 4]，因此“100%”应理解为在测量误差范围内接近100%，而非精确等于100%。

## 从光物理到器件效率：IQE≈100% 的论证

器件结构为 ITO/HTL(100 nm)/EML(40 nm)/ETL(30 nm)/Liq/Al（Fig. 1d），发光层为 CBP 主体掺杂 x wt% DACT-II，另有纯 DACT-II 层的 DACT-II-100 器件 [page 3]。EL 谱显示1–23 wt% 器件均发绿光，λ_max 从516到537 nm，随浓度增加小幅红移（Fig. 2a）[page 3]。除 DACT-II-1 外，未观察到来自其他层的明显发射，说明激子被限制在发光层内 [page 3]。

效率方面，DACT-II-9 器件在5 cd m⁻² 处取得最大 EQE 29.6%（Fig. 2c, Table 1）[page 3]。作为参照，作者制备了 Alq₃ 荧光器件（最大 EQE 1.3%）和 Ir(ppy)₃ 磷光器件（最大 EQE 13.0%），所有 DACT-II 器件（除 DACT-II-1）的最大 EQE 都超过这两个参照 [page 3]。

把 EQE 换算为 IQE 是论证的关键一步。EQE = IQE × η_out，而 IQE = β × γ × Φ_PL [page 2]。作者用光学与电学模拟来闭合这一推理：电学模拟显示注入的电子和空穴在 EML 内靠近 HTL 界面处有效复合；光学模拟在假设 IQE=100%、取向序参数 S=−0.29 的条件下，对 DACT-II-9 器件给出最大 EQE 29.0±0.9%，与实验值29.6%吻合（Fig. 4c, 4d）[page 6, page 7]。作者据此认为，模拟与实验的一致“清楚确认了 IQE≈100%，即 β·γ·Φ_PL≈100%” [page 7]。

这一推理的逻辑是：如果 IQE 不是100%，模拟在固定 IQE=100% 时算出的 EQE 就应系统性高于实验值；二者吻合，反推出 IQE 确实接近100%。由此作者进一步得到 η_out = EQE/(γ·β·Φ_PL) = 29.6/(1.0×1.0×1.0) = 29.6% [page 7]。这里 γ=1.0、β=1.0、Φ_PL=1.0 是作为前提代入的，而非独立测得，因此“IQE≈100%”的结论强度依赖于模拟模型与取向参数的正确性。

## 取向、外耦合与滚降

**分子取向**。发射分子跃迁偶极矩的取向显著影响外耦合效率。作者用变角光谱椭偏（VASE）和角度依赖 PL 两种方法测量，分别得到序参数 S = −0.32±0.01 和 S = −0.29±0.05（Fig. 4a, 4b），二者吻合，表明 DACT-II 倾向于平行于基底排列 [page 6]。这一取向有利于外耦合，是器件效率较高的一个辅助因素。

**外耦合提升**。作者强调此前未刻意优化外耦合，当前 η_out 已达29.6% [page 7]。加装含微透镜阵列与散射粒子的外耦合片后，最大 EQE 提升至41.5%，在500和3,000 cd m⁻² 下分别为37.6%和30.7%（Fig. 2c, Table 1）[page 7]。

**效率滚降**。作者主张 DACT-II 克服了随亮度增加 EQE 显著下降的滚降问题。其机制解释是：由于 f 大且 ΔE_ST 小，S₁ 与 T₁ 激子被快速转化为光子，从而抑制了作为滚降来源的 TTA 和单重态-三重态湮灭 [page 2]。数据上，提高 DACT-II 浓度可缓解滚降：DACT-II-19 器件在500和3,000 cd m⁻² 下 EQE 分别为26.9%和21.8%（Table 1）[page 3]。使用 BmPyPhB 作 ETL 并加外耦合片的器件在3,000 cd m⁻² 下达到30.7% [page 7]。不过，即便最优器件在高亮度下 EQE 仍明显低于其峰值，因此“克服滚降”应理解为显著缓解而非完全消除。

## 结论成立的条件与边界

论文的结论建立在若干明确或隐含的条件之上，作者本人也承认了部分局限。

其一，**“100%”是误差范围内的近似**。PLQY 测量带 ±4% 误差，ΔE_ST 的实验值9.0 meV 与计算值5.2 meV 存在差异，因此“100%转换”是理想化表述，而非精确数值。

其二，**IQE≈100% 依赖模拟反推**。γ=1.0、β=1.0、Φ_PL=1.0 是代入模拟的前提，而非各自独立测定；结论的可靠性取决于光学/电学模型和取向参数 S 的准确性。作者用模拟与实验 EQE 的吻合来支持这一前提，属于间接论证。

其三，**非辐射与淬灭通道被假定可忽略**。作者在讨论 TTA 时以“IQE 达到100%”反推延迟荧光来自 RISC，这一推理本身预设了 IQE 确为100%，存在一定循环性；其独立性来自 PLQY、温度依赖和光谱一致性等多条证据的相互支持。

其四，**器件性能受结构与材料限制**。作者明确指出，通过进一步优化器件结构和周边材料，DACT-II 器件有望获得更高性能，如更高亮度下的 EQE 和更低功耗；提升外耦合效率也将进一步提高 EQE [page 7]。这说明当前29.6%/41.5%并非该材料的效率上限。

其五，**实际能级存在分布**。作者承认，在实际 OLED 中 S₁ 和 T₁ 能级可能存在分布，ΔE_ST 会因非晶态下分子构象与环境的差异而波动 [page 6]。这意味着“ΔE_ST 小于室温热能”是就平均值或典型情形而言，个别分子的 ΔE_ST 可能偏离该值。

其六，**热稳定性数据存在方法依赖**。块体样品的 T_g 为151–159 °C，而真空蒸镀薄膜在超快升温速率下测得192–197 °C，作者指出薄膜 T_g 较高可能反映其热稳定性优于块体样品，但也承认外推到低升温速率时 T_g 会下降（Supplementary Note 3）[page 3]。因此 T_g 数值应结合测量条件理解。

总体而言，这篇论文的论证力量在于多条独立证据链的汇聚：分子设计计算预测小 ΔE_ST 与大 f，光物理实验分别验证上转换、排除磷光与 TTA，器件效率与光学模拟相互印证，取向测量与外耦合分析补全效率图像。其结论的边界则在于“100%”的误差范围、IQE 的模拟反推性质，以及器件性能对结构与外耦合条件的依赖。
