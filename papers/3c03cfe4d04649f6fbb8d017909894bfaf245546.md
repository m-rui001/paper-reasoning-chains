# 攀爬密度泛函阶梯：为分子与固体设计的非经验 meta-GGA

**原文题名**：Climbing the Density Functional Ladder: Non-Empirical Meta-Generalized Gradient Approximation Designed for Molecules and Solids
**作者**：Jianmin Tao, John P. Perdew, Viktor N. Staroverov, Gustavo E. Scuseria
**年份**：2003（arXiv:cond-mat/0306203v2）
**DOI**：10.1103/PhysRevLett.91.146401（原文发表信息，供参考）

## 一、论文要解决的核心问题

Kohn-Sham 密度泛函理论把多电子基态问题化为自洽的非相互作用电子问题，原则上对密度和能量是精确的，但实践中必须近似交换关联能泛函 $E_{xc}[n_\uparrow, n_\downarrow]$ [page 1]。作者沿 Perdew 提出的"雅各布阶梯"框架组织论证：第一级是局域自旋密度近似（LSD），第二级是广义梯度近似（GGA），第三级是 meta-GGA。meta-GGA 的局域原料是电子密度 $n$、其梯度 $\nabla n$，以及 Kohn-Sham 轨道动能密度

$$\tau_\sigma(\mathbf{r}) = \sum_i^{\text{occup}} \tfrac{1}{2}|\nabla\psi_{i\sigma}(\mathbf{r})|^2 \tag{2}$$

[page 1]。作者的目标是构造一个**不含经验参数**的 meta-GGA，同时高精度描述分子和固体，从而"完成雅各布阶梯的第三级" [page 1]。

这里的关键动机是：半经验泛函可能在其拟合集之外失效，只拟合分子的泛函可能不适合固体 [page 1]。因此作者选择另一条路线——让泛函满足精确约束，再用真实或计算机实验数据来验证（而非拟合）。这一"非经验"立场贯穿全文，也是理解其论证结构的钥匙。

## 二、论证的起点：PKZB 的成功与失败

作者明确以 Perdew-Kurth-Zupan-Blaha（PKZB）meta-GGA 为出发点 [page 1]。PKZB 在设计上对缓慢变化密度给出到 $\nabla$ 二阶正确的交换关联能，并对任意单电子密度给出正确的关联能。但它有一个经验参数（拟合原子化能），且表现出"意外的成功与失败"：强相互作用极限下自旋非极化非均匀密度的关联能准确、表面能和原子化能准确，但**平衡键长很差**，氢键复合物描述也很差 [page 1]。

作者诊断：PKZB 关联部分只需技术性小改进，而**PKZB 交换部分是键长误差的根源**，需要同时考虑两种范式密度 [page 1]。这就把问题聚焦到交换泛函的构造上。

## 三、关键推理：从"精确约束"到交换增强因子

### 3.1 为什么选择"核处势有限"作为关键约束

作者指出，在 meta-GGA 形式内不可能对任意一或两电子密度实现精确交换能（即完全非局域的 Hartree 自相互作用修正）。于是退而求其次：**要求 meta-GGA 交换势在基态一、两电子密度的原子核处有限**。这是 LSD 满足但 GGA 丢失的精确约束 [page 1]。作者明说："This is the key idea of our construction."（这是本文构造的关键思想）[page 1]。

这是全文推理的枢纽。它把"精确交换"这一不可达目标替换为一个可操作的、局域的约束，并由此推导出对增强因子导数的具体条件。

### 3.2 交换泛函的形式与约束

利用自旋标度关系和均匀密度标度约束，meta-GGA 交换能写成

$$E_x^{\text{MGGA}}[n] = \int d^3r\, n\,\epsilon_x^{\text{unif}}(n)\, F_x(p, z) \tag{3}$$

其中 $\epsilon_x^{\text{unif}}(n) = -\tfrac{3}{4\pi}(3\pi^2 n)^{1/3}$，增强因子 $F_x$ 依赖两个无量纲非均匀性参数

$$p = |\nabla n|^2/[4(3\pi^2)^{2/3}n^{8/3}] = s^2 \tag{4}$$

和 $z = \tau^W/\tau \le 1$，其中 $\tau = \sum_\sigma \tau_\sigma$，$\tau^W = \tfrac{1}{8}|\nabla n|^2/n$ [page 2]。

为满足 Lieb-Oxford 界，作者取

$$F_x = 1 + \kappa - \kappa/(1 + x/\kappa) \tag{5}$$

其中 $\kappa = 0.804$（更紧的界会给出 $\kappa = 0.758$）[page 2]。

对缓慢变化密度，$F_x$ 应恢复 Svendsen 和 von Barth 的四阶梯度展开

$$F_x = 1 + \tfrac{10}{81}p + \tfrac{146}{2025}q^2 - \tfrac{73}{405}qp + Dp^2 + O(\nabla^6) \tag{6}$$

其中 $q = \nabla^2 n/[4(3\pi^2)^{2/3}n^{5/3}]$ 是约化拉普拉斯量。PKZB 中 $D$ 是经验参数 0.113，而 TPSS 取 $D = 0$，即该系数的最佳数值估计 [page 2]。这是 TPSS 去除经验性的一个具体步骤。

### 3.3 关键约束如何转化为方程

对两电子基态密度，$z = 1$（$\alpha = 0$），meta-GGA 退化为 GGA 形式，增强因子 $\tilde{F}_x(s) = F_x(p = s^2, z = 1)$。对应的交换势含 $\nabla^2 n$ 项，除非其系数（正比于 $d\tilde{F}_x/ds$）在核处为零，否则会在核处发散 [page 2]。对两电子指数密度，核处 $s = 0.376$，因此作者要求

$$d\tilde{F}_x/ds\big|_{s=0.376} = 0 \tag{9}$$

[page 2]。这就是 3.1 节"关键思想"的数学落地。

作者进一步说明，TPSS 相对 PBE GGA 新增的所有精确约束都涉及**小无量纲密度导数**；对大 $p$ 行为，作者没有理由修改 PBE 的 $F_x \sim 1 + \kappa - \kappa^2/(\mu p)$（$p \to \infty$），其中 $\mu = 0.21951$，保留这一大 $p$ 极限以描述弱结合 [page 2]。

### 3.4 满足约束的具体形式

为满足上述所有条件，作者选择 $x$ 为式 (10) [page 2]：

$$x = \left\{ \tfrac{10}{81} + c\tfrac{z^2}{(1+z^2)^2} \right\}p + \tfrac{146}{2025}\tilde{q}_b^2 - \tfrac{73}{405}\tilde{q}_b\sqrt{\tfrac{1}{2}(\tfrac{3}{5}z)^2 + \tfrac{1}{2}p^2} + \tfrac{1}{\kappa}(\tfrac{10}{81})^2 p^2 + \tfrac{2\sqrt{e}}{}\tfrac{10}{81}(\tfrac{3}{5}z)^2 + e\mu p^3 \Big\} \cdot \tfrac{(1+\sqrt{e}p)^2}{}$$

（原文式 (10) 排版在提取文本中略有错乱，此处按结构转写，具体系数以原文为准。）其中常数 $c = 1.59096$ 和 $e = 1.537$ 被选来强制满足式 (9)，并给出氢原子精确基态密度的正确交换能（$-0.3125$ hartree）[page 2]。作者坦承式 (10) 的形式"不是唯一被约束决定的"，选择它是为了使 $F_x$ 在 $0 \le \alpha \le 1$ 时对 $s$ 光滑单调 [page 2]。参数 $b = 0.40$ 取为使 $F_x$ 即使对固定 $\alpha \gg 1$ 也保持对 $s$ 单调递增的最小值，出于"审美"理由，因为 $b = 0$ 在分子测试中给出几乎相同的结果 [page 2]。

**这里需要读者注意**：$c$ 和 $e$ 虽被称为"常数"，但它们是通过拟合两个精确条件（式 (9) 和氢原子交换能）确定的。作者将其归入"非经验"，理由是拟合对象是精确约束和精确密度下的精确能量，而非真实系统的实验数据。这是"非经验"定义的关键边界，也是读者评估其主张时需要把握的。

## 四、关联部分的改进

关联部分对 PKZB 做"次要技术改进"（独立于 TPSS 交换）[page 2]：

$$E_c^{\text{MGGA}}[n_\uparrow, n_\downarrow] = \int d^3r\, n\,\epsilon_c^{\text{revPKZB}}[1 + d\,\epsilon_c^{\text{revPKZB}}(\tau^W/\tau)^3] \tag{11}$$

$$\epsilon_c^{\text{revPKZB}} = \epsilon_c^{\text{PBE}}(n_\uparrow, n_\downarrow, \nabla n_\uparrow, \nabla n_\downarrow)[1 + C(\zeta, \xi)(\tau^W/\tau)^2] - [1 + C(\zeta, \xi)](\tau^W/\tau)^2 \sum_\sigma \tfrac{n_\sigma}{n}\tilde{\epsilon}_c \tag{12}$$

[page 3]。基本成分 $\epsilon_c^{\text{PBE}}$ 已具备正确的二阶梯度展开、在均匀密度标度下正确趋于高/低密度极限、非正、且当 $p \to \infty$ 时趋于零 [page 3]。为保证对所有可能密度 $E_c \le 0$，取 $\tilde{\epsilon}_c = \max[\epsilon_c^{\text{PBE}}(n_\sigma, 0, \nabla n_\sigma, 0), \epsilon_c^{\text{PBE}}(n_\uparrow, n_\downarrow, \nabla n_\uparrow, \nabla n_\downarrow)]$ [page 3]。

对任意 $C(\zeta, \xi)$，式 (11) 对单电子密度正确趋于零（此时 $\tau = \tau^W$，$\zeta = \pm 1$）[page 3]。作者设 $C(0,0) = 0.53$（同 PKZB）和 $d = 2.8$ hartree$^{-1}$，这一选择使 jellium 表面关联能在价电子体密度范围内与 PBE GGA 值保持不变 [page 3]。

为在强相互作用极限下对 $0 \le |\zeta| \le 0.7$ 实现 $E_{xc}$ 对自旋极化的独立性，作者要求

$$C(\zeta, 0) = 0.53 + 0.87\zeta^2 + 0.50\zeta^4 + 2.26\zeta^6 \tag{13}$$

[page 3]。为在 Li 这类单价原子中把价区关联能密度清零而不在芯-价重叠区产生额外关联能密度（PKZB 的一个错误），作者取

$$C(\zeta, \xi) = \frac{C(\zeta, 0)}{\{1 + \xi^2[(1+\zeta)^{-4/3} + (1-\zeta)^{-4/3}]/2\}^4} \tag{14}$$

其中 $\xi = |\nabla\zeta|/2(3\pi^2 n)^{1/3}$ 在重叠区很大 [page 3]。对自旋非极化密度，令式 (11) 中 $d = 0$ 即恢复 PKZB [page 3]。

## 五、数值验证：证据如何支撑结论

作者对原子、分子、固体和 jellium 表面做了广泛数值测试，结果汇总于 Table I [page 3–4]。除 jellium 表面外，所有计算都是自洽的，使用 Gaussian 程序的开发版本，分子计算用 6-311++G(3df,3pd) 基组 [page 3]。分子结合性质用 G2 测试集的 148 个分子（由 $Z \le 17$ 的原子构成）的原子化能评估；氢键复合物用 Ref. [14] 的 10 个复合物，误差相对 MP2 预测；固体用 17 种正常晶体结构 [page 3]。

## 六、论证的关键一步与推理链

把全文推理串起来：

1. **问题**：需要一个同时适用于分子和固体的非经验 meta-GGA。
2. **诊断**：PKZB 的键长误差源于交换部分，需同时考虑一/两电子密度和缓慢变化密度两种范式 [page 1]。
3. **关键思想**：在 meta-GGA 形式内无法实现精确交换，退而要求交换势在核处有限 [page 1]。
4. **数学落地**：对两电子密度，核处 $s = 0.376$，要求 $d\tilde{F}_x/ds|_{s=0.376} = 0$（式 9）[page 2]。
5. **构造**：选择式 (10) 的 $x$，用 $c$、$e$ 两个常数强制满足式 (9) 和氢原子交换能 [page 2]。
6. **验证**：Table I 显示 TPSS 修正了 PKZB 的键长误差，并在多项性质上表现优秀 [page 3–4]。
7. **归因**：作者把好表现归因于满足额外精确约束，尤其是式 (9) [page 3]。

**关键推理的桥接**（作者明说与读者需补足的部分）：作者明说式 (9) 是关键约束，也明说 TPSS 修正了键长误差。但"式 (9) 的满足**导致**键长误差修正"这一因果链，作者是通过"归因"（attribute）表述的，而非通过对照实验直接证明。读者应把它理解为作者提出的**合理解释**，而非已证实的因果机制。作者没有报告"去掉式 (9) 约束后键长如何变化"的对照计算，因此这一归因的强度是"likely/suggest"级别，而非确定。

## 七、结论成立的条件与边界

**适用条件**：
- TPSS 是 meta-GGA，依赖 $\tau_\sigma$，因此需要能处理 $\tau$ 依赖泛函的自洽计算（作者用 Ref. [21] 的方法）[page 3]。
- 分子测试用 6-311++G(3df,3pd) 基组，固体用多种基组 [page 3]。
- 氢键复合物误差相对 MP2 预测（MP2 在可得处与实验一致）[page 3]。

**作者承认的局限**：
- 式 (10) 的形式"不是唯一被约束决定的"，选择它是为了光滑单调 [page 2]。
- $b = 0.40$ 的选择出于"审美"理由，$b = 0$ 给出几乎相同结果 [page 2]。
- 作者说"细节和与其他泛函的比较将在后续发表中给出" [page 3]，本文只给统计汇总。
- 作者把 TPSS 定位为"更像缓慢变化极限与一/两电子极限之间的受控插值"，而非从缓慢变化极限的受控外推 [page 4]。

**读者应留意的边界**：
- "非经验"的定义是：不拟合真实或计算机实验数据，但**拟合精确约束和精确密度下的精确能量**（如氢原子交换能）。这是作者的定义，读者可自行判断其强度。
- Table I 中 PBE0 在多项性质上与 TPSS 相当，作者用"实用优势"（固体不易算杂化）来论证 TPSS 的价值，而非精度优势 [page 3]。
- 作者把 TPSS 的好表现归因于式 (9)，但未提供直接对照证据；这是**分析重建**层面的因果主张，原文用"attribute"表述 [page 3]。

## 八、总体评价

这篇论文的论证结构清晰：从"需要非经验 meta-GGA"出发，诊断 PKZB 的失败，提出"核处势有限"这一关键约束，将其数学化为式 (9)，构造满足该约束的交换泛函，再用广泛数值测试验证。其最有说服力的部分是 Table I 的系统性对比——TPSS 在键长、氢键长度、晶格常数等 PKZB 失败的项目上显著改善，同时在原子化能、电离能、电子亲和能等多项性质上与 PBE0 相当或更好。

其论证的薄弱环节在于：式 (9) 与键长改善之间的因果链是归因而非证明；"非经验"的标签依赖于对"经验"的特定定义；式 (10) 的形式非唯一，$b$ 的选择被作者自己称为"审美"。这些都不否定结论，但限定了结论的强度：TPSS 是一个在广泛测试中表现优秀的非经验 meta-GGA，其成功与特定精确约束的满足**相关联**，作者**建议**这一关联是因果性的，但直接的对照证据留待后续工作。
