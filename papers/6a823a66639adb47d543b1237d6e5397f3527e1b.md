# 水溶液中水合电子、氢原子与羟基自由基反应速率常数的批判性汇编：一部“数据如何被判定为可信”的论证

**原文题名**：Critical Review of Rate Constants for Reactions of Hydrated Electrons, Hydrogen Atoms and Hydroxyl Radicals (·OH/·O⁻) in Aqueous Solution
**年份**：1988　**DOI**：https://doi.org/10.1063/1.555805

## 这篇综述真正要论证的是什么

表面上看，这是一部数据汇编：作者汇总了超过 3,500 个反应速率常数，覆盖 eaq⁻、H·、·OH 和 ·O⁻ 四类瞬态物种 [page 1]。但把它当作“数据表”来读会错过它的核心论证。真正的主张是：**在辐射化学这样一个测量对象寿命极短、产物常不可直接观测的领域里，一个速率常数的可信度并不取决于它被报告了多少次，而取决于它是否来自能够直接、时间分辨地观测瞬态本身的方法，以及它能否被纳入一个相互自洽的相对测量网络。** 整部综述的方法论——从方法分类、参考值选取、数据拟合到平均值的取舍规则——都是为这一主张服务的。

因此，本文的论证结构不是“先给结论再列证据”，而是“先建立一套判定证据等级的框架，再用这套框架筛选、归一化并重算数据”。理解这一点，才能理解为什么作者反复强调直接法与竞争法的区别、为什么坚持固定参考值、为什么在数值相差两倍以上时拒绝给出平均值。

## 为什么“直接观测”被赋予最高证据地位

作者对四类物种的物理性质做了系统交代（Table 1，[page 3]；吸收光谱见 Fig. 1，[page 4]），这些性质直接决定了测量方法的可靠性排序。

eaq⁻ 在可见区有强吸收（720 nm 处 ε = 19000 L mol⁻¹ cm⁻¹），因此它的衰减可以被直接、灵敏地跟踪，绝大多数 eaq⁻ 速率常数来自脉冲辐解下的衰减动力学（d.k.）[page 8]。相比之下，H· 只在 200 nm 以下弱吸收，·OH 和 ·O⁻ 的光谱同样不适合监测其自身衰减，所以对它们通常只能监测产物的生成（p.b.k.）[page 8, page 10]。这一物理事实构成了整部综述证据分级的起点：**能直接看瞬态衰减的测量，天然比只能看产物生成的测量更少依赖机理假设。**

作者据此把方法分为直接法、竞争动力学和稳态法三类，并逐一列出误差来源 [page 6–7]。竞争法的关键风险是参考物选择不当：当产物不是一步生成时（如 ·OH 与 X⁻ 反应先生成 HOX·⁻ 再转化为 ·X₂⁻，Eq. 11、24、25，[page 7]），中间体可能与竞争底物反应，导致 k₂ 被错误评估。作者明确指出这一情形在用 SCN⁻ 作参考物时已被识别，并建议用多个竞争物测同一常数 [page 7]。稳态法的根本弱点则是时间尺度长、剂量率低，使相对不活泼的次级物种得以干扰，而它们在脉冲实验的时间尺度上基本惰性 [page 7–8]。

## 从证据到结论的关键一步：把相对测量锚定到固定参考值

这是全文推理中最关键、也最容易被忽略的一步。

大量速率常数并非绝对测量，而是相对于某个参考物测得的比值。如果每个实验室用不同的参考值，这些数据就无法直接比较。作者的做法是：先选定一组“参考速率常数”（Table 3a、3b、3c，[page 9–11]），把它们**固定在拟合过程之外**，然后把所有相对测量按报告或隐含的比值重新归一化到这些选定值上 [page 12–13]。

以 ·OH 为例，作者选择 Fe(CN)₆⁴⁻ 的氧化（Eq. 42）作为一级标准，理由是它可通过稳定产物 Fe(CN)₆³⁻ 的直接生成来测量，且几乎肯定是扩散控制的 [page 11]。二级标准则通过“同一化合物用八个不同竞争物得到相同值”这一自洽性来建立——如果八个竞争物给出同一个 k，那么这八个化合物的速率常数就必然相互正确 [page 11]。这是一个漂亮的推理：**自洽性不是被假设的，而是被用作筛选正确值的判据。**

对 ·O⁻ 采用同样程序，以 3-hexene-1,6-dioate 离子（Eq. 44）为一级标准 [page 11]。这种“锚定—归一化—自洽”的链条，正是把分散的、方法各异的测量转化为一个可比数据集的机制。

## 数据拟合的角色：不是求平均，而是暴露矛盾

作者明确说明所用方法**不是**传统最小二乘，而是一种受限拟合：被广泛接受或经特别谨慎测定的值不参与随机调整 [page 13]。拟合的首要用途不是产生“最佳值”，而是**标记需要进一步评估的问题**——当全局拟合给出的值与公认值不符，或测量值彼此相差甚远时，就提示需要复核 [page 13]。

拟合还给出了各方法测量偏差的统计分布：约 95% 的测量落在拟合值 ±50% 以内，具体为 eaq⁻ 51%、H· 直接法 46%、H· 相对法 62%、·OH 直接法 63%、·OH 相对法 47% [page 13]。作者据此得出一个重要判断：**不同实验室报告的速率常数之间的差异，超过了各自声称的误差范围。** 这正是“测量值相差两倍以上就不给平均值”这一规则的依据 [page 13, page 16–17]。

## 结论在什么条件下成立

这部综述的结论有明确的适用边界，作者对此交代得相当清楚。

**介质与温度**：Tables 6–9 只收录室温、水相均相、适用常规扩散理论的速率数据；重水溶液中的反应（ed⁻、D·、·OD）被排除，但含氘化物的数据被保留 [page 16]。这意味着所有结论默认在常温水相条件下成立。

**离子强度**：eaq⁻ 带负电，其反应性依赖溶液离子强度 I，遵循 Brønsted–Bjerrum 方程（Eq. 40，[page 9]）。作者明确表示**自己不做离子强度校正**，因为离子实际电荷、浓度等存在不确定性；只在作者本人报告了校正值时引用，并标注“k cor. for I”[page 9]。因此表中数值的适用离子强度需逐条查看注释。

**pH 与 ·OH/·O⁻ 平衡**：·OH 与其共轭碱 ·O⁻ 的平衡（Eq. 14，pKa = 11.9）在碱性溶液中快速建立，因此测 ·O⁻ 时必须校正 ·OH 的贡献 [page 4, page 11]。作者用 ·OH/·O⁻ 与 H₂O₂/HO₂⁻ 体系（Eq. 50–54，Fig. 3，[page 12]）具体演示了这一点：在 1 mol L⁻¹ OH⁻ 中实际仍有约 1% 的 ·OH，若观测速率比 ·OH 已知值低 100 倍，只能说明 ·O⁻ 反应更慢甚至不反应。一批 ·O⁻ 速率常数正是因为校正后贡献可忽略而被从 Table 9 中剔除 [page 12]。

**异相与高分子体系**：对囊泡、胶束中的底物，速率决定步骤常是 eaq⁻ 或 ·OH 扩散到表面，因此把测得常数归为自由基与底物的反应通常不成立；对聚合物，基于单体浓度的 kobs 依赖浓度、聚合度和分子形状，缺乏浓度细节时无法比较 [page 16]。这些数据被单独放入 Table 10。

**作者承认的局限**：金属离子因水解可存在多种形式，信息不足时仅以氧化数标注，实际物种可能包含 M(OH)ₓⁿ±、MOₙ± 及多核离子 [page 16]；引用的 pKa 未经作者评估，仅用于指示可能的离子形式 [page 16]；未发表或未经评审的数据、以及仅有的估计值或上下限，只在无更确定数据时才收录 [page 16]。

## 需要留意的文本疑点

提取文本存在明显的 OCR 损伤，若干数值和符号可疑，不宜作为确定证据：Table 1 中 eaq⁻ 的 dhv/dT 出现“-2.9 3”这类残缺标注，H· 与 ·OH 的多个热力学量带有上标字母但对应关系混乱 [page 3]；Table 5 中部分速率常数写作“5.0 X 101)”“6.2 x 10°”等，指数明显失真 [page 20]；Table 6 中大量条目（如“1.9 X 1010”“3.6 X 1010”）的指数格式不统一，个别如“2 X 104-”“<2 X 101”难以判读 [page 35]。这些疑值若被当作推理前提，会削弱相应结论的强度。正文中引用的关键数值（如 k₁₄ = 1.2 × 10¹⁰ L mol⁻¹ s⁻¹、pKa(·OH) = 11.9、扩散控制反应活化能 10–18 kJ mol⁻¹）在上下文中相对清晰，可信度较高。

## 这部综述的论证性格

把它读成“数据手册”会低估它。它实际上示范了一种在测量条件高度异质、绝对标准稀缺的领域里建立可信知识的方法：**用物理性质决定方法等级，用固定参考值把相对测量串成网络，用自洽性而非重复次数来判定正确性，用统计分布来暴露超出声称误差的系统差异，并明确划出结论不适用的边界。** 作者对“不给平均值”的坚持、对离子强度校正的克制、对 ·O⁻ 数据的大量剔除，都是这一方法论性格的体现——宁可留下空白，也不让不可比的数据混入自洽网络。
