# 通过压力与层间耦合调控扭转双层石墨烯中的超导与关联绝缘态

**原文题名**：Tuning superconductivity in twisted bilayer graphene
**年份**：2018
**DOI/预印本**：arXiv:1808.07865v2 [cond-mat.mes-hall]

## 一、作者要论证什么

这篇论文的核心主张可以概括为一句话：扭转双层石墨烯（twisted bilayer graphene, tBLG）中的关联绝缘态与超导态，不仅由扭转角决定，还可以通过层间耦合强度来精确调控；而层间耦合既可以用横向位移场（displacement field, D）改变，也可以用静水压改变层间距来实现 [page 1]。

围绕这一主张，作者提出若干支撑性结论：

1. 在接近魔角（约 1.1°）的器件中，除已知的空穴型超导外，还观察到电子型超导，以及半填充附近的关联绝缘态 [page 1, page 3]。
2. 位移场 D 对超导转变温度影响很小，却强烈改变半填充绝缘态，且电子带与空穴带对 D 的响应方向相反 [page 3]。
3. 在偏离魔角的 1.27° 器件中，原本几乎不存在关联态；施加静水压后，关联绝缘态和超导态同时被"恢复"，且 Tc 在约 1.33 GPa 达到最高（约 3 K）[page 2, page 5]。
4. 高质量器件中的量子振荡揭示了半填充附近出现新的小费米面，其退化度降低，且超导出现的密度区间与这些低退化度量子振荡重合 [page 6, page 8]。
5. 平行磁场下不同填充态的行为差异，暗示自旋—谷（isospin）自由度在关联绝缘态中扮演角色，但单纯的 isospin 序不足以解释半填充绝缘态 [page 8]。

## 二、从证据到结论的关键推理

### 1. 魔角附近的相图：D 场作为"外来的"调控旋钮

作者首先用器件 D1（θ ≈ 1.14°）建立基线。图 1B 显示，在约 10 mK 下，电阻在电子和空穴掺杂两侧、密度接近 ±ns/2 处都降到零，即出现超导 [page 2]。图 1C 给出转变温度：空穴型约 0.4 K，电子型约 0.25 K，后者是首次在 tBLG 中观察到 [page 3]。

关键的一步在图 1D：当扫描位移场 D 时，超导区域对 D 几乎不敏感，但 −ns/2 处的绝缘态在正 D 下电阻超过 10 kΩ，在负 D 下却"消失"（电阻降到零）[page 3]。作者据此推断，绝缘态被抑制的条件是载流子被极化到同一层（顶层）。这里有一个重要的推理桥接：作者明确指出，自由悬浮的 tBLG 在层交换下是对称的，因此这种对 D 的响应"很可能是外来的（extrinsic）"，而非本征 [page 3]。也就是说，D 场本身不应破坏层对称性，观察到的效应更可能来自两层石墨烯各自不同的无序程度。

为支持"无序导致渗流超导网络"的猜想，作者给出图 1E–G 的 Fraunhofer 型量子干涉图样。临界电流 Ic 随磁场周期性振荡，周期 ΔB 为 2–4 mT，对应有效结面积 S ≈ 0.5–1 µm²（用 S = Φ₀/ΔB 计算，Φ₀ = h/2e），可达器件面积的约 40% [page 3]。图 1G 在 −ns/2 和负 D 下还显示 Ic 在 B = 0 处取极小值，即 π 结 [page 3]。作者给出两种可能解释：铁磁弱链接，或符号变化的配对序参量（如 d 波）[page 4]。这里作者没有下定论，而是明确说"两种情形都可能适用于我们的数据"。

### 2. 压力调控：偏离魔角也能"造出"魔角物理

器件 D2（θ ≈ 1.27°）在常压下几乎没有关联态：图 2A 灰线只显示 ±ns 处的绝缘态，±ns/2 和 ±3ns/4 处仅有微弱的电导极小，且无超导 [page 4–5]。施加 2.21 GPa 静水压后（蓝线），±ns/2 和 +3ns/4 处出现明显绝缘态，+ns/4 和 −3ns/4 处也较弱地出现 [page 5]。

这里的物理逻辑是：平带的宽度由动量空间失配（由扭转角决定）与层间杂化强度（由层间距决定）共同决定。压力减小层间距，增强杂化，从而在更大扭转角下也能达到平带条件 [page 4]。作者引用理论计算指出，对 1.27° 的 tBLG，最小带宽预计出现在 1.3–1.5 GPa [page 5]，而实验观察到 Tc 最大值在 1.33 GPa，两者"吻合得非常好"。

图 2D 和 2E 显示，绝缘能隙和 Tc 都随压力非单调变化，均在 1.33 GPa 达到最高测量值 [page 5]。作者还观察到电子型超导的迹象（+ns/2 稍高掺杂处磁阻在 B = 0 附近急剧下降），但其 Tc 远低于空穴型，受限于 300 mK 的基底温度无法详细研究 [page 5]。

### 3. 更干净的相图：金属相与能量尺度比较

器件 D2 在压力下表现出比 D1 更高的均匀性。图 3A 和 3B 显示，−ns/2 处是强绝缘态，稍高空穴掺杂处是超导口袋，稍低掺杂处是金属行为 [page 6]。这与 D1 和此前文献 [6] 不同：D1 中 −ns/2 处电阻随降温趋于零，而这里电阻快速上升；D1 中 −ns/2 两侧都有超导，这里只在 n < −ns/2 一侧 [page 6]。

图 3C 是一个关键的定量比较：在 2.21 GPa 下，绝缘态（红）和超导态（蓝）的电阻都在约 5 K 处偏离高温金属行为 [page 6]。作者还指出，在器件 D1 中，两个相的临界电流相近 [page 6, page 14]。这些观察"表明绝缘相和超导相共享相似的能量尺度，从而约束了那些认为超导是绝缘体子态的模型" [page 6]。这是一个有条件的推理：如果超导是绝缘体的"女儿态"，人们可能预期两者能量尺度有层级关系；观察到相近的 onset 温度，至少对这种简单图像构成挑战。

### 4. 量子振荡：新费米面与超导的密度重合

图 4A 展示器件 D2 在 1.33 GPa 下的 Landau fan。从电荷中性点（CNP）出发的主序列为 ν = ±4, ±8, ±12, ...，即四重退化 [page 6]。在 +ns/4、±ns/2、±3ns/4 处，霍尔效应提取的载流子密度趋近于零，表明形成了新的小费米面 [page 6]。

这些新费米面的量子振荡退化度各不相同：±ns/2 处为二重退化（自旋和谷退化部分解除），±3ns/4 处无额外退化（所有退化均解除），+ns/4 处为二重退化但奇数主导（ν = +1, +3, +5, ...）[page 6]。作者指出，+ns/4 附近的 1, 3, 5... 和 10, 14, 18... 序列与单个无质量 Dirac 锥（π Berry 相位）的量子振荡一致，分别对应二重和四重退化 [page 7]。但作者也提出替代解释：当回旋质量 m* 与裸电子质量 me 可比时，不同轨道中 Zeeman 分裂的 Landau 能级可能重合，也会产生相位移动 [page 7]。

一个重要的负面结果是：单粒子模型无法预测从公度填充处的能隙态中涌现出新量子振荡序列，也无法解释这些振荡只向一个方向色散并在下一个公度填充处突然终止 [page 7]。作者据此提出"相互作用修饰的能带结构"这一问题，但没有给出确定答案。

### 5. 平行磁场与 isospin 序

图 5A 显示器件 D3（θ ≈ 1.10°）在不同平行磁场 B∥ 下的电导。±ns/2 处的电导极小随 B∥ 增大而减弱，±ns/4 处则相反，±3ns/4 处基本不变 [page 8]。定性上，这暗示 ±ns/2 绝缘态是自旋未极化的，而 ±ns/4 和 ±3ns/4 是自旋极化的 [page 8]。

但定量分析给出了意外结果：+ns/2 态的热激活能隙随 B∥ 非线性关闭，近似抛物线下降，这与完全自旋极化或谷极化的线性预期都不一致，也与反铁磁排列（能隙应随 B∥ 增大）不一致 [page 8]。作者据此得出结论："仅靠 isospin 序，而不引入额外打破 Dirac 点接触退化的对称性破缺，可能不足以理解半填充绝缘态的本质" [page 8]。这是一个明确的限制性结论，但作者用"可能"（may be）保留了余地。

## 三、关键推理步骤与桥接

整篇论文最关键的一步推理，是把"压力改变层间距"与"压力改变平带宽度"联系起来，进而把"在 1.27° 下压力诱导关联态"解释为"压力把系统推到了平带条件"。这个推理依赖两个前提：

- 理论计算预测 1.27° tBLG 的最小带宽在 1.3–1.5 GPa [page 5]；
- 实验观察到 Tc 和能隙都在 1.33 GPa 达到最大 [page 5]。

两者吻合，支持了"压力即带宽调控"的图像。但作者也承认，Tc 的增大"可能"来自更大扭转角下更小的 moiré 波长导致的库仑能标增大，"也可能"与样品无序差异有关 [page 6]。这里作者没有把话说死。

另一个关键桥接是：量子振荡显示 ±ns/2 处出现二重退化的小费米面，而超导恰好出现在这个密度附近，作者据此推断"在 ±ns/2 处成核的费米面性质可能对附近超导的出现至关重要" [page 8]。但作者紧接着说，这究竟是通过纯电子机制、声子介导机制中态密度的增强，还是尚未提出的机制，"尚不清楚" [page 8]。这是一个明确的开放性结论。

## 四、结论成立的条件与边界

**适用条件**：

- 压力调控的结论建立在"压力不改变扭转角，只改变层间耦合"这一前提上。作者通过量子振荡在各压力下投影到几乎相同的载流子密度来支持这一点 [page 14]。
- 器件 D2 在压力下表现出的高均匀性，被作者解释为"可能代表更接近无无序的相图"，但作者也承认"由于样品数量有限，不能排除样品间的随机差异" [page 6]。
- 位移场对超导影响很小的结论，在器件 D1 和 D2 中都成立，但 D1 中 −ns/2 绝缘态对 D 的强烈响应被归因于无序，而非本征效应 [page 3]。

**作者承认的局限**：

- 压力实验的基底温度限制在 300 mK，无法详细研究电子型超导 [page 5]。
- 器件 D1 存在明显的结构无序迹象（不同触点对之间 full-filling 密度有偏移），作者选择"几乎不可区分"的四个相邻触点进行测量，但无法探测小于触点间距的应变 [page 11]。
- π 结的两种解释（铁磁弱链接 vs. 符号变化配对）都无法排除 [page 4]。
- 量子振荡中 +ns/4 附近的相位移动有两种可能解释，需要回旋质量测量来区分 [page 7]。
- 平行磁场下 +ns/2 能隙的非线性关闭，无法用现有 isospin 序图像解释 [page 8]。

**分析者推断**（非原文结论）：论文中"超导与绝缘态共享相似能量尺度"的论证，依赖于两个相在相近温度偏离金属行为的观察 [page 6]。这一观察本身是可靠的，但"共享能量尺度"到"约束超导非绝缘体子态"之间的推理，隐含了一个假设：如果超导是绝缘体的子态，两者的 onset 温度应有明显层级。这个假设在文中没有被独立论证，属于分析者补足的桥接。

## 五、术语说明

- **tBLG**：twisted bilayer graphene，扭转双层石墨烯。
- **魔角**：约 1.1°，此时平带形成，关联效应显著。
- **ns**：对应每个 moiré 原胞填充 ±4 个电子的密度，即平带边界。
- **位移场 D**：通过双栅极施加的横向电场，使两层石墨烯之间产生电势差。
- **isospin**：自旋与谷自由度的统称。
- **π 结**：基态相位差为 π 的 Josephson 结，临界电流在零磁场处取极小值。

## 六、总结

这篇论文的核心贡献，是把 tBLG 的关联物理从"只能靠精确控制扭转角"扩展为"扭转角与层间耦合共同决定"。压力实验表明，偏离魔角的器件可以通过压缩层间距恢复平带条件，且 Tc 可提升至约 3 K，比魔角器件高近一个数量级 [page 5–6]。高质量器件中的量子振荡进一步揭示了半填充附近新费米面的退化度降低，以及超导与这些低退化度费米面的密度重合 [page 6, page 8]。但论文也留下若干未解问题：半填充绝缘态的 isospin 序本质、量子振荡中相互作用修饰能带的具体结构、以及超导配对机制是否 unconventional，都仍待进一步实验和理论工作。
