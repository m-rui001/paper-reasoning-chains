# 从配对势到多体势：Finnis–Sinclair 过渡金属经验势的论证结构

**原文题名**：A simple empirical N-body potential for transition metals
**作者**：M. W. Finnis, J. E. Sinclair
**年份**：1984
**DOI**：10.1080/01418618408244210

## 问题的起点：配对势为何不够用

这篇论文要解决的是一个很具体的建模困境。在1980年代初，用原子尺度模拟过渡金属中的位错、晶界和裂纹时，几乎只能依赖中心配对势。配对势没有理论基础，但至少能给出定性信息。问题在于，它在两个地方系统性地失败。

第一是弹性常数。立方晶体中，中心配对势在平衡态下必然给出 Cauchy 关系 $C_{12}=C_{44}$，而真实金属很少满足。惯常的补救办法是在总能量里加一个依赖宏观体积的项，人为提供"外部压力"来平衡 Cauchy 压力 $\frac{1}{2}(C_{12}-C_{44})$。但作者指出，这引入了一个悖论：用长波方法（恒定体积）算出的体模量与用均匀形变算出的值不一致，除非体积依赖项对体积是线性的 [page 2]。更麻烦的是，当模拟晶体内部的空洞或裂纹时，这种体积依赖项只在晶体表面移动时才起作用，内部畸变不涉及它，于是"施加特殊表面力"在原理上就令人不满 [page 2]。

第二是空位形成能。如果放弃表面力、接受 $C_{12}=C_{44}$，配对势给出的空位形成能总是约等于内聚能。而实验值（table 2）只有内聚能（table 1）的约三分之一 [page 2]。作者判断，这种对内聚性质的严重误represent，可能连裂纹尖端张开或空位团簇的定性特征都无法模拟。

作者提出的解决思路是引入金属内聚的能带特征。最简单的表达是紧束缚模型的二阶矩近似：每原子内聚能正比于 $\sqrt{z}$，$z$ 是原子配位数，可以从1（双原子分子）变到约12（f.c.c. 晶体）。正是这个 $\sqrt{z}$ 依赖，而非配对势的线性依赖，解释了空位形成能为何偏低 [page 3]。

## 模型构造：一个平方根项加一个排斥配对项

总能量写成两项之和：

$$U_{tot} = U_N + U_P \tag{1}$$

$U_N$ 是多体项，$U_P$ 是常规的中心配对势求和。多体项写成对每个原子的"内聚函数"求和：

$$U_N = -A \sum_i f(\rho_i) \tag{2}$$

其中位点密度

$$\rho_i = \sum_{j \neq i} \phi(R_{ij}) \tag{3}$$

$A$ 是预期为正的常数。作者选择 $f(\rho) = \sqrt{\rho}$，以模仿紧束缚理论中 $\phi(R)$ 可解释为重叠积分平方和的结果 [page 5]。配对项写成

$$U_P = \frac{1}{2}\sum_{ij} V(R_{ij}) \tag{4}$$

作者给出三种可能的物理解释：紧束缚图像下 $U_N$ 是能带能（成键），$U_P$ 是排斥的核-核相互作用；Daw 和 Baskes 的图像下 $\rho_i$ 是刚性叠加原子电荷密度构造的局域电子密度；或者 $\rho_i$ 是局域原子位点密度的度量 [page 5]。作者明确表示，模型的推导和拟合不依赖哪种解释 [page 5]。

## 关键推理：平方根形式如何产生 Cauchy 压力

论文最核心的论证在 §2.1 和 §2.2。作者限制到 b.c.c. 结构，且 $\phi$ 和 $V$ 只延伸到第二近邻。第一近邻距离 $\sqrt{3}a/2$，第二近邻距离 $a$。记 $\phi_1 = \phi(\sqrt{3}a/2)$，$\phi_2 = \phi(a)$，$V_1 = V(\sqrt{3}a/2)$，$V_2 = V(a)$，则

$$\rho = 8\phi_1 + 6\phi_2 \tag{8}$$
$$u_P = 4V_1 + 3V_2 \tag{9}$$

对能量取应变导数得到压力和各弹性模量。体模量分解为 $B = B_N + B_P$，其中 $B_N$ 含有一个正比于 $f''$ 的项 [page 6, eqn. (12)]。菱形剪切模量 $C_{44} = C_{44}^N + C_{44}^P$，四方剪切模量 $C' = C'^N + C'^P$ [page 6–7]。

作者发现一个有意思的结果：这些表达式在形式上与从一个有效中心配对势

$$V_{eff}(R) = V(R) - 2Af'\phi(R) \tag{18}$$

得到的结果相同，**除了**体模量 $B$ 中多出一个含 $f''$ 的项 [page 7]。也就是说，如果忽略 $f$ 的二阶及以上导数，整个模型等价于一个有效配对势。

那么 Cauchy 压力呢？定义 $P_c = \frac{1}{2}(C_{12} - C_{44})$。对中心配对势，平衡态下 $P_c = 0$。对本模型，作者得到

$$P_c = -\frac{4A}{9a}(2\sqrt{3}\phi'_1 + 3\phi'_2)^2 f'' \tag{20}$$

应用平衡条件 $P=0$ 后，$P_c$ 恰好只由 $f''$ 项贡献 [page 7]。由于 $A$ 是正的内聚能，平方根形式保证 $P_c$ 为正，这与所有 b.c.c. 过渡金属的实验观测一致（table 1）[page 8]。

这就是关键推理链：平方根形式 → $f'' \neq 0$ → 体模量中有额外项 → Cauchy 压力非零 → 不需要人为体积依赖项就能拟合弹性常数。作者还论证，忽略 $f''$ 对空位形成能影响很小：配位数从12变到11时，精确变化 $12 - 12(11/12)^{1/2}$ 与线性化近似 $1/2$ 只差 2.2% [page 7]。但 $f''$ 对体模量的贡献显著，正是它解释了 Cauchy 差异。

## 参数化与拟合

作者采用抛物线形式的 $\phi$：

$$\phi(r) = (r-d)^2, \quad r < d; \quad = 0, \quad r > d \tag{27}$$

$d$ 是可调参数，假设在第二和第三近邻之间：$a < d < \sqrt{2}a$。$V$ 采用四次多项式：

$$V(r) = (r-c)^2(c_0 + c_1 r + c_2 r^2), \quad r < c; \quad = 0, \quad r > c \tag{28}$$

$c$ 同样在第二和第三近邻之间。$c_0, c_1, c_2$ 和 $A$ 是自由参数。拟合策略是：先选 $c$ 和 $d$ 的可行组合，然后用线性方程组拟合 $u_{tot}$、$P=0$、$B$ 和 $P_c$ 来确定 $c_0, c_1, c_2, A$，再通过迭代 $d$ 拟合 $C_{44}$ [page 10]。额外约束是未弛豫空位形成能 $E_v^f$ 应在 $0.3u_{tot} \lesssim E_v^f \lesssim 0.5u_{tot}$ 范围内 [page 10]。

铬和铁的处理略有不同。由于它们的 $P_c$ 异常低，上述参数化无法拟合所有弹性常数。作者修改 $\phi$ 为

$$\phi(r) = (r-d)^2 + \beta(r-d)^3/d \tag{29}$$

$\beta$ 的选取使 $\phi$ 在第一近邻距离内出现极大值。对 Cr 和 Fe 取 $\beta = 1.8$，作者称这是"任意值"，但给出了两个元素都合理的结果 [page 10–11]。

拟合结果在 table 2 中给出。计算的内聚能、晶格常数、弹性常数与实验值吻合。未弛豫空位形成能与实验比较"非常合理"，作者指出弛豫会降低 $E_v^f$ 约 20%，从而抵消计算值偏高的趋势 [page 11]。表面能 $\gamma_{100}$ 的计算值与高温实验估计"相当一致"，但作者承认 Miedema 半经验模型预测的零温值更高，暗示他们的值系统性偏低；不过 Miedema 模型假设 $\gamma$ 和 $u_{tot}$ 都正比于 Wigner-Seitz 球边界的电子密度，因此"受到与其他配对加和键模型相同的批评" [page 11]。计算值与 Desjonquères 和 Cyrot-Lackmann 的紧束缚计算也吻合较好 [page 11]。

## 结论成立的条件与边界

作者在讨论中明确了几点限制。首先，模型参数是从完美晶体的实验数据拟合的，因此"如果势在第一和第二近邻位置之外被修改，拟合不会改变" [page 12]。这意味着模型对短程行为的预测没有约束，用于损伤或冲击研究时可能需要修改短程部分。

其次，作者承认"模型是否给出不同晶体结构之间定性正确的能量差，从而预测稳定的 b.c.c. 结构，仍有待观察" [page 12]。势的程太短，无法区分 f.c.c. 和 h.c.p. 结构，要做到这一点需要扩展到这些结构中的第三近邻距离。

第三，作者明确表示"不从拟合参数的数值中读出任何定量的物理意义" [page 12]。图1和图2中钼的排斥势有一个弱吸引尾部，但作者认为这很可能依赖于拟合 $V$ 所假设的函数形式，因为关于 $V$ 的信息只在近邻位置获得 [page 12]。

第四，空位形成能的计算是未弛豫的。作者根据简单配对势的经验估计弛豫可降低 $E_v^f$ 约 20%，但未实际计算 [page 11]。

第五，表面能的实验数据本身"受到很大不确定性" [page 11]，因此计算值与实验的比较只能说是"fair"。

## 论证的整体评价

这篇论文的论证力量在于一个清晰的逻辑转折：配对势的失败（Cauchy 关系、空位能）源于其线性加和性质，而紧束缚二阶矩近似给出的 $\sqrt{\rho}$ 形式恰好引入了一个非零的 $f''$，这个 $f''$ 在体模量中产生额外项，从而产生非零 Cauchy 压力，同时不显著影响空位能。作者通过解析推导（eqn. 20）证明了 Cauchy 压力完全来自 $f''$，并通过数值拟合展示了模型能同时拟合内聚能、晶格常数、三个弹性模量和合理的空位形成能。

论证的薄弱之处在于参数化的非唯一性。作者承认"结果仍不唯一，除了 $A$" [page 10]，并说可以通过精确拟合包含弛豫的实验 $E_v^f$ 来使其唯一，但"考虑到模型的粗糙性，我们不觉得这种 refinement 是必要的" [page 10]。这意味着模型的预测能力在拟合量之外是有限的。此外，Cr 和 Fe 需要引入额外的 $\beta$ 参数，且 $\beta = 1.8$ 是"任意值" [page 11]，这削弱了模型对这些元素的预测基础。

从今天的视角看，Finnis–Sinclair 势成为了原子尺度模拟中广泛使用的工具之一，但这篇原始论文的结论强度是适度的：它展示了一个能克服配对势两个具体缺陷的简单模型，同时明确承认了模型在结构预测、短程行为和参数唯一性方面的局限。作者没有声称这是一个普适的过渡金属势，而是将其定位为"扩展了原子尺度模拟可处理的情境范围" [page 12]。
