# 大数据中伪相关的洪流：Calude 与 Longo 如何用数学反驳“相关即一切”

**原文题名**：The Deluge of Spurious Correlations in Big Data
**作者**：Cristian S. Calude、Giuseppe Longo
**年份**：2016　**DOI**：https://doi.org/10.1007/s10699-016-9489-4

## 一篇针对“数据哲学”的数学反驳

这篇论文的靶子不是数据科学本身，而是一种被作者称为“哲学”的立场。2008 年，时任《连线》主编 Chris Anderson 发表《理论的终结：数据洪流让科学方法过时》，主张“有了足够的数据，数字自己会说话”，“相关取代因果，科学可以在没有连贯模型、统一理论的情况下前进” [page 2]。作者把这一立场概括为“科学的终结”：只要算法足够强、数据库足够大，就能从中挖出相关与规律，无需理解其“意义”或“内容”，机器直接给出预测和行动规则 [page 2–3]。

作者要证明的是：这个立场在数学上是错的。他们的核心结论有两层。第一，足够大的数据库**必然**包含任意指定的相关，这种相关只源于数据规模，而非数据性质 [page 1]。第二，由于这种大数据库可以被“随机”生成，而随机生成排除了任何可支撑未来行动的结构或规则，因此**大多数相关是伪相关**，且伪相关的比例随数据库增大而趋于 1 [page 1, page 8]。用作者的话说：“信息太多，往往表现得像信息太少” [page 1]。

值得注意的是，作者明确划定了自己的目标边界：他们不批评数据科学、数据挖掘或数据分析本身，而是警告“让大数据中的相关搜索吞并并取代科学方法”的危险 [page 6]。这一自我限定很重要，它决定了后文所有“负面结果”的解读方式——不是否定工具，而是否定工具的越界。

## 论证的两条腿：遍历论与 Ramsey 理论

作者的数学论证由两条互补的路径构成，分别对应“预测为何不可靠”和“相关为何必然出现”。

**第一条腿：遍历论说明“按过去类比未来”不可靠。** 数据科学的一个隐含假设是：一系列相关会沿参数（如时间）继续迭代下去，即“递归”（recurrence）。这一直觉有数学支撑——Poincaré 递归定理指出，在保测变换下，几乎每个点都会无穷多次回到原集合 [page 7]。这似乎支持了“跟随规律即可预测未来”的做法。

但作者引入 Kac 引理来翻转这个结论：回到子集 A 的平均递归时间是 A 概率的倒数 [page 8]。这意味着 A 越小（即要找的规律越具体），递归时间越长。更关键的是，Cecconi 等（2012）的结果表明，在确定性系统中，这些概率还随相空间维度（可观测量与参数的数量）指数下降，递归时间指数上升；若方程非线性、存在吸引子，概率还随吸引子维度指数下降 [page 8]。作者由此得出结论：在真实问题中，相空间和吸引子维度都很大，因此轨道（规律、模式）再次迭代“非常不可能”，或需要极长的递归时间 [page 8]。他们引用的原文结论是：“当 underlying 动力过程的有效自由度数量即使只是中等偏大，仅基于观测数据的预测很快就变得有问题，天气预报就是例子” [page 8]。

这里有一个容易被忽略的推理细节：数据库分析者可能只选择少数几个可观测量做相关（例如图 1 中的 n=2），但作者指出，不能排除这些可观测量依赖更多参数——恰恰在因果依赖远非唯一的情形下就是如此 [page 8]。因此，即便表面上只关联两个变量，其背后的有效维度可能仍然很大，递归概率仍然极低。

**第二条腿：Ramsey 理论说明“相关必然出现”。** 这条路径不依赖确定性假设，只依赖基数（数据库元素数量）[page 12]。作者用了两个 Ramsey 型结果。

第一个是有限 Van der Waerden 定理：对任意正整数 k 和 c，存在正整数 c，使得任何由 c 个数字或颜色组成、长度超过 c 的字符串，都包含长度为 k 的单色等差数列 [page 9]。作者用二进制串举例：长度 9 的所有 512 个二进制串都含有长度为 3 的单色等差数列；01100110 没有，但加一位变成 011001100 或 011001101 就有了 [page 9]。这个定理的意义在于：任何足够长的字符串都会显示一种最简单的相关——同一数值在等距位置上的序列 [page 9]。而且，由于字符串是任意的，其值可以“随机”选取（掷骰子或测量量子可观测量），相关仍然必然出现 [page 12]。

第二个是有限 Ramsey 定理，处理更一般的 n 元关系。作者用“派对问题”引入：六个人的派对中，必然存在至少三个彼此陌生或至少三个彼此相识的人 [page 10]。这等价于完全图的边用红蓝两色染色，必然出现红色或蓝色三角形 [page 10–11]。定理的一般形式是：对任意正整数 b、n、c，存在正整数 c，使得任何元素多于 c 的有限集 A，对 ［A］ⁿ 的任意 c 色划分，都存在 A 的 b 元素子集 B，其 n 元子集全部同色 [page 11]。

作者把数据库中的相关重新表述为：一个相关就是大小为 b 的集合 B，其 n 元子集构成相关（即同色）[page 12]。选择标准——相关函数——在这里“没有相关性，它是任意的”；唯一重要的是，出于某种可能是伪的原因，b 元素集合的所有 n 元子集同色 [page 12]。于是 Ramsey 定理保证：给定任意相关函数和任意 b、n、c，总存在足够大的 c，使得任何大于 c 的集合 A 都包含一个大小为 b 的集合 B，其 n 元子集全部相关 [page 12]。

两条腿的互补关系值得点明：遍历论那条腿说明，即使世界是确定性的、有规律的，按过去类比未来的预测也不可靠，因为递归概率极低、递归时间极长；Ramsey 那条腿则说明，即使完全放弃确定性假设，只靠数据规模，相关也必然出现。作者说这两条论证“相互加强”，因为寻找规律（按前一条腿的结果）需要非常大的数据库，而大数据库（按后一条腿的结果）又必然充满伪相关 [page 12]。

## 关键一步：把“伪相关”定义为“随机数据库中的相关”

论证到这里还缺一个环节：Ramsey 定理只证明了相关必然出现，但“必然出现”不等于“大多数是伪的”。要回答“伪相关占多大比例”，必须先定义“伪相关”。作者指出，字典定义（“假的、伪造的、基于错误观念的”）是语义的，依赖于某个假定理论：一个相关在一种理论下是伪的，在另一种理论下可能是有意义的 [page 13]。为了得到不依赖任何理论的答案，作者采用了一个“非常严格”的定义：**一个相关是伪的，如果它出现在“随机”生成的数据库中** [page 13]。

这个定义的关键在于“随机”的数学化。作者使用算法信息论中的算法随机性，把随机定义为“相对于预期理论不可预测”，而理论通过计算来预测，因此算法随机性提供了一个适用于任何理论的随机性概念 [page 13]。算法随机性用“不可压缩性”来刻画：一个字符串 x 是 m-可压缩的，如果 K(x) ≤ |x| − m，即存在长度不超过 |x| − m 的输入 y 使 U(y) = x [page 14]。不可压缩的字符串具有大多数与随机相关的性质，因此被称为算法随机的 [page 14]。

作者随后给出一个量级结果：固定 a ∈ (0,1)，长度为 n 的字符串中能被 an 比特压缩的，数量小于 2^((1−a)n) − 1，因此概率小于 2^(−an)，当 n → ∞ 时指数收敛到零 [page 15]。换句话说，对大的 n，极少数字符串可压缩，或者说大多数字符串是算法随机的 [page 15]。作者还给了具体数字：据 Hoffman（2015），最佳平均压缩率约 86.4%；一个长度 2048 的二进制串被压缩 13.6% 的概率小于 2^(−(136/1000)×2048) < 10^(−82)，而 10^82 大约是 observable universe 中氢原子的数量 [page 15]。

这一步的推理是：既然大多数大字符串是算法随机的，而 Ramsey 定理保证任何足够大的字符串都含相关，那么这些相关中的大多数就出现在算法随机的数据库中，按作者的严格定义就是伪相关。作者由此得出结论：伪相关构成多数，而且是“可量化的多数” [page 13]。他们进一步说，即使采用这个限制性定义，大多数相关是伪的；如果放宽定义，这个结论只会更强（a fortiori）[page 13]。

这里有一个作者明确承认的微妙之处：算法随机字符串“不能拥有所有与随机相关的性质”，因为 Ramsey 定理保证它们总含规律 [page 14, 脚注 19]。也就是说，算法随机性并不排斥所有规律，它排斥的是可压缩的规律。作者用布尔矩阵的例子说明：除有限集外，算法随机的 n×n 布尔矩阵（在 F₂ 上）的秩大于 n/2，否则可以选出 n/2 列使其他列是线性组合，从而把矩阵压缩到 (3/4)n² + O(n log n) 比特，而非算法随机性要求的 n² [page 14]。这个例子说明算法随机对象仍有“有趣”的结构，但这些结构不足以支撑可靠预测。

## 结论成立的条件与作者承认的边界

作者的结论有明确的适用条件。首先，所有 Ramsey 型结果都是**存在性**的：它们保证相关存在，但不告诉我们具体是哪种相关、什么颜色 [page 12]。作者明确说：“我们事先不知道单色集将是什么颜色，就像数据挖掘者事先不知道哪个相关会从数据中冒出来一样” [page 12]。不过，由于定理的有限性，在每个具体实例中，我们可以算法性地找到所有单色元素及其着色 [page 11–12]。这一点很重要：它意味着伪相关不是不可发现的，而是可发现但无预测价值的。

其次，结论的强度依赖于“伪相关”的定义。作者的定义是限制性的（随机数据库中的相关），他们承认“还有其他原因使相关成为伪的，即使在‘非随机’数据库中” [page 13]。因此，他们的结论是：即使按最严格的定义，大多数相关也是伪的；按更宽的定义，这个比例只会更高。这是一个精心设计的论证策略——用最弱的假设得出最强的结论。

第三，作者对“随机”的处理有一个技术细节：他们用算法随机性来定义随机数据库，但算法随机性本身是不可计算的（K 是不可计算的，脚注 16）[page 14]。这意味着“这个数据库是算法随机的”这一判断本身不可算法判定。作者没有回避这一点，但他们也没有展开讨论这对实际数据挖掘的影响。这是一个可以推断的限制：在实践中，数据挖掘者无法先验地知道自己的数据库是否算法随机，因此也无法先验地知道挖出的相关是否属于他们定义的伪相关。不过，作者的论证并不需要这个可判定性——他们只需要证明大多数大数据库是算法随机的，从而大多数相关是伪的。

第四，作者在结论中明确区分了三种相关：局部相关（一个事件影响另一个，或共同局部原因）和非局部相关（如量子纠缠），然后加上他们论证的“Ramsey 型相关”，后者“除了规模之外，不能归因于任何其他东西” [page 15–16]。他们承认，这三种相关在算法上无法区分 [page 16]。这是一个重要的边界：伪相关不是通过某种算法标记出来的，而是通过其生成机制（随机数据库）来定义的。在实际分析中，分析者无法仅凭相关本身判断它属于哪一类。

## 论证的力度与未竟之处

这篇论文的论证力度在于它把一种哲学立场转化为可检验的数学命题，然后用经典结果予以反驳。作者没有停留在“相关不等于因果”的老生常谈上，而是进一步证明：在大数据条件下，相关不仅不等于因果，而且大多数相关连预测价值都没有，因为它们的出现只源于规模。这个结论比“相关不等于因果”强得多，也更有针对性——它直接反驳了“数据足够大，数字自己会说话”的核心主张。

论证的一个关键转折是 Kac 引理与 Cecconi 等（2012）结果的结合。Poincaré 递归定理表面上支持“规律会重复”，但 Kac 引理和维度依赖把这种重复推到了极远的未来，使得基于递归的预测在实践中不可行。这个转折的力度取决于 Cecconi 等（2012）结果的适用性：作者说“在真实生活问题中，相空间和吸引子的维度都很大” [page 8]，这是一个经验断言，不是数学定理。如果某个具体问题的有效维度确实很小，那么递归概率可能不低，预测可能可行。作者没有讨论这种可能性，但他们的论证结构允许这种例外——他们反对的是“相关取代科学方法”的普遍主张，而不是反对在特定低维问题中使用相关。

另一个值得注意的推理是作者对“随机数据库”的处理。他们用算法随机性来定义随机，但算法随机性是一个渐近概念（对大的 n），而实际数据库是有限的。作者给出的量级结果（2^(−an) 收敛到零）是渐近的，对有限 n 只给出概率上界。在 n = 2048 的例子中，概率小于 10^(−82)，这在实际意义上足够小，但严格来说，有限数据库的“大多数”是一个程度问题，不是非黑即白的。作者没有过度声称这一点，他们说的是“对大的 n，极少数字符串可压缩” [page 15]，这是一个渐近陈述。

最后，作者在结论中把他们的“负面结果”定位为“不摧毁数据科学，而是为更多反思开辟道路” [page 16]。他们主张的是：大数据分析不能取代科学，对称地，也没有任何理论好到可以取代数据和检验的需要；隐式的、或更好是显式的、可修正的理论化，应该伴随有意义的证据测量、数学建模和可靠的数据库分析 [page 16]。这个结论比论文开头的强硬反驳温和得多，也更符合他们实际证明的东西：他们证明的是“相关取代因果”这一主张在数学上站不住脚，而不是数据科学没有价值。
