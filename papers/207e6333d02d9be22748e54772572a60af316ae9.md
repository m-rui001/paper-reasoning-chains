# 分裂 Bregman 方法：如何把一类 L1 正则化问题拆成可快速求解的子问题

**原文题名**：The Split Bregman Method for L1-Regularized Problems（2009，DOI: 10.1137/080725891）

## 一、作者要解决的核心问题

论文处理的是形如

$$\min_u |\Phi(u)| + H(u) \tag{1.1}$$

的一类 L1 正则化优化问题 [page 1]。这类问题涵盖图像处理中的 ROF 全变差去噪（1.2）和压缩感知/基追踪（1.3）。作者指出，尽管这类问题近年来因压缩感知而备受关注，但许多具体实例仍然难以求解，或者需要高度问题特定的技巧 [page 1]。

作者的核心主张是：**Bregman 迭代可以被用来求解一大类约束优化问题，而在此基础上提出的"分裂 Bregman"方法能够高效求解非常广泛的 L1 正则化问题** [page 1]。这一主张的支撑来自两个层面：一是关于 Bregman 迭代求解约束问题的理论论证（第 2 节），二是将 L1 与 L2 部分"解耦"后得到的可快速交替求解的算法结构（第 3 节），以及 TV 去噪和 MRI 压缩感知上的数值验证（第 4–5 节）。

## 二、从约束问题到 Bregman 迭代：论证的起点

论证的出发点是一个一般约束问题

$$\min_u E(u) \quad \text{s.t.} \quad Au = b. \tag{1.7}$$

作者先交代了传统罚函数/延拓方法的困难：为了逼近约束，罚权重 $\lambda_k$ 必须趋于极大，而这会使 Hessian 的条件数趋于无穷，导致共轭梯度、Gauss–Seidel 等快速迭代方法失效，且 $\lambda_k$ 往往需要以很小的步长递增 [page 4]。这是理解 Bregman 迭代为何有吸引力的关键对照。

Bregman 迭代的做法是：不把 $\lambda$ 推向无穷，而是固定 $\lambda$，通过迭代地最小化 Bregman 距离加上罚项来逐步满足约束。对问题 (2.4)，迭代形式为 (2.6)–(2.8)，并可简化为"把约束误差加回右端项"的形式：

$$u^{k+1} = \min_u E(u) + \frac{\lambda}{2}\|Au - b^k\|_2^2, \tag{2.9}$$
$$b^{k+1} = b^k + b - Au^k. \tag{2.10}$$

作者指出，当 $A$ 线性时，这个看似复杂的迭代等价于上述简化形式，这正是 ROF 去噪中"把噪声加回去"的类比 [page 6]。

**关键推理的一步**在于 Theorem 2.2 [page 6]：如果某个迭代 $u^*$ 满足 $Au^* = b$，那么 $u^*$ 就是原约束问题 (2.4) 的解。证明思路是：设 $\hat u$ 为真解，则 $Au^* = b = A\hat u$，故 $\|Au^* - b^*\|_2^2 = \|A\hat u - b^*\|_2^2$；又因 $u^*$ 最小化 (2.12)，有 $E(u^*) \le E(\hat u)$，结合 $\hat u$ 的最优性即得 $u^*$ 也是解。这个定理把"迭代收敛到满足约束"与"收敛到原问题最优解"连接起来，是整篇论文理论论证的枢纽。作者还特别指出，证明并未真正用到 $A$ 的线性性，因此该条件其实不必要 [page 6]——这是一个值得注意的、作者主动放宽的边界。

## 三、分裂 Bregman：把 L1 与 L2 解耦

第 3 节是方法的核心创新。作者不直接处理 (1.1)，而是引入辅助变量 $d$，考虑等价问题

$$\min_{u,d} |d| + H(u) \quad \text{s.t.} \quad d = \Phi(u). \tag{3.1}$$

将其代入 Bregman 框架并应用 (2.9)–(2.10) 的简化，得到"分裂 Bregman 迭代"：

$$(u^{k+1}, d^{k+1}) = \min_{u,d} |d| + H(u) + \frac{\lambda}{2}\|d - \Phi(u) - b^k\|_2^2, \tag{3.7}$$
$$b^{k+1} = b^k + (\Phi(u^{k+1}) - d^{k+1}). \tag{3.8}$$

**为什么这个"分裂"是关键**：因为 L1 部分和 L2 部分被分开了，所以 (3.9) 可以交替地对 $u$ 和 $d$ 分别最小化 [page 8]：

- **对 $u$ 的子问题**：由于 $u$ 已与 L1 项解耦，该子问题可微，可用 Gauss–Seidel、Fourier 方法或少量共轭梯度步求解。
- **对 $d$ 的子问题**：$d$ 的各分量之间无耦合，可用显式的收缩算子求解：$d_j^{k+1} = \text{shrink}(\Phi(u)_j + b_j^k, 1/\lambda)$，其中 $\text{shrink}(x,\gamma) = \frac{x}{|x|}\max(|x|-\gamma, 0)$ [page 8]。

作者还给出一个重要的实践观察：**不必把第一个子问题解到完全收敛**。直觉是，若子问题误差已小于 $\|b^k - b^*\|_2$，则额外精度会在 Bregman 参数更新时被"浪费"；经验上最优效率往往只需内循环一次（$N=1$）[page 9]。作者进一步用 Theorem 2.2 论证：即使子问题用不精确迭代求解，分裂 Bregman 的任何不动点仍是原约束问题 (3.1) 的极小点——因为不动点满足 $b^* = b^* + \Phi u^* - d^*$，即 $d^* = \Phi u^*$，从而满足 Theorem 2.2 的条件 [page 9]。这一步把"允许不精确求解"从经验观察提升为有理论依据的性质。

## 四、两个应用：TV 去噪与压缩感知 MRI

**TV 去噪**（4.1 节）。作者分别处理各向异性与各向同性两种 TV。各向异性情形下，$d_x, d_y$ 完全解耦，$u$ 子问题的最优性条件为 $(\mu I - \lambda\Delta)u^{k+1} = \mu f + \lambda\nabla_x^T(d_x^k - b_x^k) + \lambda\nabla_y^T(d_y^k - b_y^k)$ (4.2)，作者用 Gauss–Seidel 求解，并给出分量形式的更新式 $G^k_{i,j}$ [page 10]。各向同性情形下 $d_x, d_y$ 不再解耦，但作者引用 [27] 的广义收缩公式 (4.4)–(4.6) 仍可显式求解 [page 11]。作者强调，各向同性 TV 是"图割方法无法求解的更好模型" [page 9]，这是分裂 Bregman 相对既有最快方法的一个结构性优势。

**压缩感知 MRI**（4.2 节）。问题写作 $\min_u J(u)$ s.t. $\|RFu - f\|_2^2 < \sigma^2$ (4.7)，其中 $F$ 为 Fourier 变换、$R$ 为行选择矩阵、$f$ 为 k 空间数据 [page 12]。作者选择混合正则项 $J(u) = \|u\|_{BV} + \|u\|_{B_{1,1}} = |\nabla u| + |Wu|$，$W$ 为 Haar 小波变换，理由是多个正则项有助于平滑图像的准确重建，且对收敛速度影响很小 [page 12]。由于 $u$ 可取复值，作者对 L1 范数作了精确的 Hermitian 定义 [page 12]。$u$ 子问题的最优性条件利用 $\nabla^T\nabla = -\Delta$、$W^TW = I$、$F^T = F^{-1}$ 化为 $(\mu F^T R^T R F - \lambda\Delta + \gamma I)u^{k+1} = \text{rhs}^k$，系统是循环的，可用两次 Fourier 变换求解 [page 13]。外层再套 Bregman 更新 $f^{k+1} = f^k + f - RFu^{k+1}$ 以处理约束 (4.7) [page 14]。

## 五、数值证据与结论的支撑力度

**TV 去噪**：Table 1 [page 14] 报告，256×256 合成图与 512×512 Lena 上，分裂 Bregman 用时分别为 0.0732 s 和 0.2412 s，均快于图割的 4 点（0.214 / 0.709 s）和 16 点（0.468 / 1.51 s）模板。Figure 1 [page 15] 显示，与基于对偶问题的梯度下降 [8] 相比，两者前期都收敛快，但接近精确解时的"停滞"在分裂 Bregman 中明显更轻。作者还报告一个实用性质：中间结果平滑，前 10 次迭代已消除大部分噪声，后续迭代主要"压平阶梯"，因此 10 次与 50 次迭代的结果在视觉上难以区分（Figure 2、Figure 3）[page 15–16]。作者明确指出，这种速度依赖于用 Bregman 迭代而非延拓来施加约束；若让 $\lambda\to\infty$，(4.2) 会病态，Gauss–Seidel 会停滞 [page 15]。

**压缩感知**：Table 2 [page 17] 给出达到收敛所需的迭代次数。线性化 Bregman 在 $\sigma=10^{-3}$ 时需 367 次，而分裂 Bregman（Besov）仅 10 次；含噪情形下分裂 Bregman 与线性化 Bregman 相当或更快。作者解释，分裂 Bregman 对 (4.8) 中较大的 $\mu$ 容忍度高，因此外层 while 循环很少（phantom 测试中不超过 8 次），内层 for 循环每次外层仅需 5 次 [page 18]。Figure 4 显示混合 TV+Besov 正则的重建优于仅用 Besov [page 17]；Figure 5 展示 MR phantom 用 30% k 空间数据的重建过程 [page 19]。

**结论**：作者总结分裂 Bregman 高效、易并行（大量使用 Gauss–Seidel 与 Fourier 方法）、内存占用小（无需显式 Hessian）、易于编码 [page 18]。

## 六、结论成立的条件与边界

论文的论证有几个需要读者留意的限定：

1. **收敛性依赖 Theorem 2.1 的假设**。作者明确假设 $E$、$H$ 凸、$H$ 可微、子问题 (2.2) 的解存在 [page 5]。分裂 Bregman 的推导进一步假设 $H$ 与 $|\Phi(\cdot)|$ 凸、$\Phi$ 可微 [page 7]。这些是结论成立的前提。

2. **"不精确求解仍收敛"的论证是局部性的**。作者用不动点论证说明任何不动点都是原问题的解 [page 9]，但这依赖迭代确实到达不动点；论文并未给出分裂 Bregman 本身的完整全局收敛率证明，而是借助 Theorem 2.1 的 $H(u^k)\to 0$ 结果。

3. **数值比较的公平性有作者自陈的限制**。作者指出，线性化 Bregman 与分裂 Bregman 每次迭代都需两次 Fourier 变换，单次迭代耗时相近，因此用迭代次数比较是合理的 [page 17]。但 Table 2 中"线性化 Besov"在无噪几何图上需 367 次，作者归因于该方法接近收敛时显著变慢、且需选择极端参数 [page 18]——这是对比较条件的一个诚实交代。

4. **MRI 采样方式不实际**。作者明确承认，均匀随机采样虽对 CS 理想，但对多数 MRI 应用不实际，因为多数脉冲序列按螺旋等几何模式采集 k 空间；选择均匀随机采样是为简化，且论文焦点在数值而非采集细节 [page 18]。这是作者主动划出的适用边界。

5. **附录的快速收敛解释是"非正式但直观"的**。作者在附录开头即声明这是 informal but intuitive 的说明 [page 18]，其推导基于对 L1 范数的光滑化 $|u|_\epsilon = \sum_i\sqrt{u_j^2+\epsilon}$，并用到中值定理得到 (A.2)。因此这一部分应视为直觉性论证，而非严格收敛率定理。

6. **一处需注意的文本疑点**：第 10 页 Gauss–Seidel 分量式 $G^k_{i,j}$ 中出现了 $d^k_{x,i-1,j} - d^k_{x,i-1,j}$ 与 $b^k_{x,i-1,j} - b^k_{x,i-1,j}$ 这类同项相减的写法，从上下文看很可能是 OCR 或排版导致的符号错误（应为相邻不同下标项之差）。由于该式是算法实现细节而非核心结论依据，此处仅作提示，不影响对方法论证的理解。

总体而言，论文的核心论证链条是清晰的：Bregman 迭代把约束问题化为固定 $\lambda$ 的短序列无约束问题（Theorem 2.2 保证解的正确性）→ 分裂变量使 L1 与 L2 解耦 → 两个子问题分别可用收缩算子和快速线性求解器高效处理 → 数值实验显示在 TV 去噪和 CS-MRI 上兼具速度与通用性。其结论的强度受限于凸性、可微性假设，以及数值比较所依赖的具体参数选择与测试图像；作者对这些边界大多有明确交代。
