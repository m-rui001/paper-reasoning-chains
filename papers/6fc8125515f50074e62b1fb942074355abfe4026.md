# 让混杂变量留在模型中：目的性选择算法在logistic回归中的论证

**原文题名**：Purposeful selection of variables in logistic regression
**作者**：Zoran Bursac, C Heath Gauss, David Keith Williams, David W Hosmer
**发表**：Source Code for Biology and Medicine, 2008, 3:17；DOI: 10.1186/1751-0473-3-17

## 论文要解决的是一个"选变量"之外的问题

在流行病学和临床研究中，logistic回归建模的常见做法是从一批候选协变量中挑出统计显著的变量，构造一个尽量精简的模型。但Bursac等人关注的不是"预测得准不准"，而是"风险因素建模"这一特定目的：当研究者想知道某个暴露对结局的作用时，那些本身不显著、却会改变其他变量系数估计的混杂变量（confounder）必须留在模型里，否则暴露效应的估计就是有偏的。论文的核心主张正是围绕这一点展开——Hosmer和Lemeshow提出的目的性选择（purposeful selection, PS）流程，经过自动化后，在保留混杂变量方面优于SAS PROC LOGISTIC中现成的FORWARD、BACKWARD、STEPWISE三种机械选择方法 [page 1]。

这个主张有两个层次。较弱的一层是：PS在模拟中识别并保留混杂变量的比例更高。较强的一层是：这种优势在混杂变量本身处于显著性边缘（p值介于0.1和0.15之间）时尤其明显，因为此时其他算法会因不显著而将其剔除，PS却因混杂判据而保留 [page 5]。论文的论证结构就是围绕这两层展开的。

## PS算法与三种机械方法的逻辑差异

理解论证的关键，是先看清PS与三种机械方法在"什么条件下保留一个变量"上的分歧。

FORWARD、BACKWARD、STEPWISE的共同点是：保留与否几乎完全由统计显著性决定。FORWARD按score卡方统计量逐个纳入，一旦进入就不再移除；BACKWARD按Wald检验逐个剔除，一旦剔除就不再回来；STEPWISE在两者之间交替，但同样以显著性为唯一门槛 [page 2]。它们没有"混杂"这个概念。

PS则不同。它先做单变量筛选，以0.25为候选门槛（作者明确说0.05这样的传统水平可能漏掉已知重要的变量 [page 2]），然后在多变量迭代中同时评估两件事：变量是否显著（0.1水平），以及剔除它之后其他变量的系数估计是否变化超过某个百分比（15%或20%）。只要满足后者，即使不显著也作为混杂变量保留。迭代结束后，还会把最初未入选的变量逐个加回，以0.1或0.15的水平检验它们是否在联合模型中变得重要 [page 2]。

这个差异是整篇论文论证的支点：PS的保留规则比"显著性"多了一条"混杂"通道，而模拟和实例就是用来检验这条通道是否真的带来了可观测的差异。

## 模拟证据：优势出现在哪里，不出现哪里

论文做了两组模拟，各1000次运行。

第一组模拟没有混杂变量：6个协变量中3个显著（系数均为0.122）、3个为零，样本量从60到600。结果（Table 1, [page 3]）显示，PS、STEPWISE、BACKWARD的保留正确模型比例几乎相同，且随样本量增加而上升（从60时的约5%升到480时的约71%）；FORWARD在样本量较大时明显更差（480时仅44.2%）。这一组的作用是建立一个基线：在没有混杂的情况下，PS并不比STEPWISE或BACKWARD更好。这实际上是对PS主张的一个限定——它的优势不是普遍性的。

第二组模拟引入了混杂结构：X1为Bernoulli(0.5)，X2的分布依赖于X1（X1=1时X2~U(-6,3)，X1=0时X2~U(-3,6)），X3显著，X4–X6为零。真实logit为 -0.6 + 1.2X1 + 0.1X2 + 0.122X3 [page 3]。这里X2的系数0.1相对较小，意味着它在很多模拟中可能不显著，但它通过分布依赖X1而成为混杂变量。模拟变化了样本量、混杂判据（15%和20%）和非候选纳入水平（0.1和0.15），共24种条件。

结果（Table 2, [page 4]）的模式是：在混杂判据为15%、非候选纳入为0.15的条件下，PS在所有六个样本量上都保留了比其他三种方法更高比例的正确答案。在其他条件下，PS的优势较小，主要体现在样本量240–360区间。作者还额外调整了X2的系数：当E2=0.13时（X2更容易显著），PS、BACKWARD和较大样本下的STEPWISE表现接近，因为X2此时靠显著性就能被保留，混杂通道不再是唯一途径；当E2=0.07时（X2更难显著），PS在所有样本量上都优于其他方法，但所有方法的正确保留率都下降了 [page 3–4, Table 3]。

这组结果对论证的支持是分层的。它表明PS的优势确实来自混杂通道，而不是某种普遍的优越性：当混杂变量本身显著时，优势消失；当它不显著时，优势显现。这正是论文想要证明的机制。

## WHAS实例：一个具体的模型差异

论文用Worcester Heart Attack Study（WHAS）数据的307个观测、11个协变量做实例分析 [page 4]。单变量分析在0.25水平上选出9个候选变量（AGE, SEX, HR, BMI, CVD, AFB, SHO, CHF, MIORD）。多变量迭代中，SEX、CVD、AFB、CHF因不显著且不改变其他系数超过20%而被剔除；BMI虽不显著，但剔除后MIORD的系数变化超过20%，因此作为混杂变量保留。最终，最初未入选的MITYPE在加回检验中显著（0.1水平），且它的加入使MIORD的p值从0.0324变为0.1087，说明MITYPE对MIORD关系有混杂作用 [page 5]。

三种SAS机械方法得到完全相同的模型（Table 5, [page 5]）：AGE、SHO、HR、MITYPE、AV3。PS在（20%, 0.1）设置下得到AGE、SHO、HR、MITYPE、MIORD、BMI；在（15%, 0.15）设置下得到AGE、SHO、HR、MITYPE、AV3、MIORD、BMI。差异集中在：PS保留了BMI（混杂变量）和MIORD，而机械方法保留了AV3。当混杂判据放宽到15%、非候选纳入放宽到0.15时，AV3也进入PS模型（其显著性为0.1173），此时PS模型等于机械方法模型加上BMI和MIORD [page 5]。

这个实例的作用不是提供统计推断，而是展示PS在真实数据上确实会产生与机械方法不同的模型，且差异恰好落在混杂变量和边缘显著变量上。它与模拟结果形成呼应：PS多保留的，正是那些"不显著但重要"的变量。

## 结论成立的条件与作者承认的边界

论文的结论有明确的适用条件。首先，PS的优势只在"风险因素建模"而非"纯预测"的目的下才构成优势 [page 1, page 5]。如果研究者的目标只是预测，多保留一个不显著的混杂变量可能反而增加方差、降低泛化性。其次，优势在样本量240–600范围内最明显，作者明确说这是流行病学和行为研究中常见的样本量 [page 5]；当样本量达到1000时，所有方法（除FORWARD外）趋于收敛，因为边缘显著的混杂变量在大样本下也会变得显著，混杂通道与显著性通道的差异被压缩。第三，优势在混杂变量本身处于显著性边缘（p约0.1–0.15）时最大；如果混杂变量本身显著，所有方法都能保留它 [page 5]。

作者在Limitations部分列出了四条限制 [page 5–6]。第一，最初未入选的变量是在最后逐个加回检验的，如果两个这样的变量只有在联合放入时才显著，PS会漏掉它们；作者补充说，联合显著可能意味着多重共线性，此时分析者可能本就不该同时放入。第二，如果两个不显著的协变量互相混杂，PS会把它们都作为混杂变量保留，作者建议分析者此时应检查它们是否在0.25水平上与结局有关联，否则应视为无意义的混杂而剔除。第三，算法不强制把一组哑变量作为一个整体处理，如果其中一个显著，分析者需要手动加入其余。第四，多分类问题未被探索，因此结果不支持PS在更广泛的模型选择问题上的稳健性。

这些限制中，第一条和第二条实际上是对PS"过度保留"倾向的自我约束：混杂判据本身不区分"有意义的混杂"和"无意义的相互混杂"，需要分析者介入判断。这与论文Discussion中"人类建模过程仍然有效"的立场一致 [page 5]。

## 论证的力度与未竟之处

从证据到结论的推理链条是清晰的：PS的保留规则多了一条混杂通道 → 模拟显示在混杂变量不显著时PS保留率更高 → 实例显示PS确实多保留了混杂变量。但这条链条的强度受限于几个因素。

模拟中混杂变量的构造方式是让X2的分布依赖于X1，这是一种特定的混杂机制。论文没有探索其他混杂结构（例如通过中间变量、或非线性关系产生的混杂），因此"PS在混杂变量保留上更优"这一结论的普适性未被充分检验。作者在Limitations中承认多分类问题未探索，但未提及其他混杂机制的局限——这是分析者可以指出的推断性边界，而非作者原话。

另外，模拟的总结指标是"正确保留X1、X2、X3的比例"，这是一个全或无的指标。它没有区分"多保留了不显著的X4–X6"和"漏掉了混杂的X2"这两种错误。PS的混杂通道在保留X2的同时，是否也更容易错误保留X4–X6？论文没有报告这一点。从Table 2看，PS在多数条件下的正确保留率高于其他方法，这间接说明它的错误保留没有严重到抵消优势，但论文没有直接量化假阳性率。这是一个论证上的空白。

最后，论文推荐将混杂水平设为15%、非候选纳入设为0.15 [page 6]，但这一推荐主要基于模拟中这两个设置下PS表现较好，而非基于理论推导或外部验证。作者也明确说这个宏是"帮助决策的工具，而非确定答案"，分析者应仔细检查模型并判断每个变量为何被保留 [page 6]。这一自我限定是恰当的，也提示读者：PS的优势是相对于机械方法而言的，它本身仍是一个需要分析者判断的半自动化流程。
