# 用熵挑选“最佳基”：Coifman 与 Wickerhauser 的论证结构

**原文题名**：Entropy-Based Algorithms for Best Basis Selection
**作者**：Ronald R. Coifman, Mladen Victor Wickerhauser
**出处**：IEEE Transactions on Information Theory, Vol. 38, No. 2, March 1992, pp. 713–718
**DOI**：10.1109/18.119732

---

## 一、作者要解决什么问题

这篇论文的目标很具体：给定一个信号（或一族信号），如何在一个预先构造好的“正交基库”里，自动挑出一个让信号表示最“紧凑”的基，并且这个挑选过程要足够快、足够稳定，能用于声音和图像的压缩 [page 1]。

作者的核心主张可以概括为三点：

1. 存在若干结构良好的正交基库（局部三角基、小波包基），它们共享两个关键性质：库内所有基都保持能量（正交性），且库本身具有二叉树结构。
2. 在这类库上，可以用一个“可加信息代价函数”（additive information cost function）来度量某个基对信号的表示效率，并定义“最佳基”为该代价最小者。
3. 由于树结构和代价函数的可加性，最佳基可以在 O(N) 次比较内找到，而计算所有系数只需 O(N log N)（小波包）或 O(N[log N]²)（局部三角基）[page 5]。

换句话说，论文不是提出一个新的变换，而是提出一个**在已有正交基集合中做选择**的算法框架，并论证这个框架在计算上是可行的、在噪声下是稳健的。

---

## 二、论证的起点：为什么“库”这个概念能成立

作者先构造两类波形库，目的是说明“库”不是空想，而是有具体数学对象的。

**局部三角基**（local trigonometric basis，也叫 local sine basis）：作者从一列严格递增的节点 {aᵢ} 出发，构造一组支撑在区间 [aᵢ₋₁, aᵢ₊₁] 上的“bump”函数 pᵢ，满足 Σpᵢ² = 1，并由此定义出局部化的正弦函数 Sᵢ,ₖ，它们构成 L²(R) 的正交基 [page 1–2]。这些基对应 R 的不同划分，划分之间有“细化”偏序，可以组织成树。

**小波包基**（wavelet packet library）：作者引用 [4] 的框架，从正交镜像滤波器 h(n) 出发，定义算子 F₀、F₁ 和函数序列 {Wₙ}，满足正交关系 (2) 式 F₀F₀* + F₁F₁* = I [page 2]。库中的基由形如 Wₙ(2ˡx − k) 的函数组成，参数 l、k、n 分别对应尺度、位置和振荡次数。作者给出一个命题：只要指标 (l, n, k) 使得区间 [2ˡn, 2ˡ(n+1)) 构成 [0, ∞) 的不相交覆盖，对应的函数族就是 L²(R) 的正交基 [page 3]。

这一步的论证作用是：**库不是任意集合，而是有明确正交性和树结构的集合**。正交性保证能量守恒，因此不同基下的展开可以直接比较代价；树结构保证搜索可以自底向上进行。

---

## 三、关键一步：代价函数必须“可加”

论文的推理枢纽在第三节。作者要找一个函数 𝒜，把系数序列映射为实数，用来衡量“集中程度”：系数越集中（少数大、多数小），𝒜 越小；系数越平均，𝒜 越大 [page 3]。

作者明确要求 𝒜 是**可加的**（additive）：

> 𝒜({xᵢ}) = Σᵢ 𝒜(xᵢ)，且 𝒜(0) = 0 [page 3]

这个条件看似技术性，实则是整个算法可行性的关键。因为最佳基搜索是在树上做“父节点 vs. 两个子节点”的比较：如果父区间上的代价等于两个子区间代价之和，那么局部最优选择就能保证全局最优。作者随后用归纳法证明：按 (5) 式自底向上选择，得到的确实是整个库中的最佳基 [page 5]。

作者选的具体代价函数是 **Shannon 熵**。对单位向量 u 在正交分解 H = ⊕Hᵢ 下的分量 uᵢ，定义

> e²(u; {Hᵢ}) = −Σ ‖uᵢ‖² log ‖uᵢ‖² [page 3]

并给出 Shannon 方程：

> e²(u; {Hᵢ, Hⱼ}) = e²(u; {H₊, H₋}) + ‖P_{H₊}u‖² e²(u₊; {Hᵢ}) + ‖P_{H₋}u‖² e²(u₋; {Hⱼ}) [page 3–4]

这个方程是 Pythagoras 定理的熵版本，也是“可加性”在具体代价函数上的体现。作者还引入“理论维数” d = exp(−Σpₙ log pₙ)，其中 pₙ = |xₙ|²/‖x‖²，用来刻画信号的有效自由度 [page 4]。

**这里的关键推理是**：正交性保证所有基下能量相同，因此不需要归一化就能比较代价；可加性保证树搜索的局部比较等价于全局最优；熵的凸性保证“平均化”会增加代价，符合“集中即好”的直觉。三者合起来，才使“最佳基”既有意义又可计算。

## 四、算法与复杂度

作者描述的算法很简洁：从最细划分开始，对每个相邻对计算“合并后的代价”与“分开的代价之和”，取较小者，逐层向上 [page 4–5]。对于二叉树库，复杂度正比于节点数，即 O(N)；加上计算所有系数的开销，小波包库为 O(N log N)，局部三角基库为 O(N[log N]²) [page 5]。

作者还给出基的数量的递归估计：A_{L+1} = 1 + A_L²，由此 A_{L+1} ≳ 2^{2L}，即 N = 2^L 个点的信号可在约 2^N 个正交基中选择，而搜索只需额外 O(N) 次操作 [page 5–6]。这个量级对比是论文说服力的重要来源：**可选空间极大，但搜索代价极低**。

## 五、结论成立的条件与边界

论文的结论不是无条件的，作者也明确或隐含地划定了适用范围：

1. **库必须是树结构**。作者给出“二叉树库”的定义：基向量对应区间 I_{n,k} = [2ᵏn, 2ᵏ(n+1))，每个基对应一个不相交覆盖，且 V_{n,k+1} = V_{2n,k} ⊕ V_{2n+1,k} [page 4]。只有满足这个结构，自底向上的归纳搜索才成立。作者也提到多维情形需要推广为更一般的树（每个节点有 b > 1 个子节点）[page 5]。

2. **代价函数必须可加**。这是算法正确性证明的前提。作者在第三节开头就限定 𝒜 为 additive information cost function [page 3]。如果代价函数不可加，树搜索的局部比较就不能保证全局最优。

3. **正交性保证噪声稳健**。作者指出，虽然“在自身最佳基中表示信号”是非线性变换，但一旦基选定，变换是正交的，因此变换域中的噪声能量不会超过原信号中的噪声能量 [page 1]。这是一个定性论断，论文没有给出定量噪声分析。

4. **作者承认的局限**：论文提到，全局最小熵正交基（Karhunen-Loève 基）对单个向量会“平凡化”，而限制在库内可以保持“快速”展开 [page 4]。这实际上是在说：最佳基不是全局最优，而是在快速可计算库内的最优。作者没有声称该方法在所有情况下优于其他方法，只声称它在特定库和特定代价下可行且高效。

5. **实验证据的性质**：论文提到对声音和图像“导致显著压缩算法”，并引用 [7]、[8]；还提到用于人脸识别的联合最佳基 [6]。但这些是引用，不是本文的详细实验。本文的主要证据是数学构造和复杂度分析，而非大规模数值对比。因此，关于“压缩效果多好”的结论，本文只提供方向性支持，具体效果需看引用文献。

---

## 六、总体判断

这篇论文的论证力量来自一个清晰的三段式结构：**构造具有正交性和树结构的基库 → 定义可加的信息代价 → 证明树搜索给出库内最优基并给出复杂度**。每一步都有明确的数学对象和证明支撑，关键推理（可加性 + 树结构 ⇒ 局部比较即全局最优）在 page 5 的归纳证明中完成。

结论的适用边界也很清楚：它适用于满足树结构定义的正交基库，适用于可加代价函数，适用于作者构造的两类具体库。超出这些条件，论文不声称结论成立。论文没有讨论非可加代价、非树结构库、或噪声下的定量性能，这些是读者需要自行判断的空白。

从今天的视角看，这篇论文的价值不在于某个具体数值结果，而在于它把“在大量正交基中选一个最适合当前信号的基”这件事，从一个组合爆炸问题转化为一个 O(N) 的树搜索问题，并给出了使这个转化成立的代数条件。这个思路后来在信号处理和小波分析中被广泛引用和发展。
