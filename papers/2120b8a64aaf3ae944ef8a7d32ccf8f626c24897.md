# 单光束高灵敏度 n₂ 测量：Z 扫描如何把相位畸变变成可读的透过率曲线

**原文题名**：High-sensitivity, single-beam n₂ measurements（1989，Optics Letters 14(17): 955–957；DOI 未在提取文本中给出）

## 一、作者要解决什么

测量材料的非线性折射率 n₂，此前常用非线性干涉、简并四波混频、近简并三波混频、椭圆旋转以及光束畸变测量等方法。作者在开篇即指出，前几类方法虽然灵敏，但装置复杂；光束畸变类方法又需要精确的光束扫描和繁琐的波传播分析 [page 1]。本文提出的 Z 扫描（Z scan）试图用单光束、简单装置同时给出 n₂ 的**符号**和**大小**，并声称对非线性相移的探测灵敏度优于 λ/100 [page 1]。

## 二、核心思想：相位畸变在传播中转化为振幅畸变

Z 扫描的物理直觉在文中用一段定性描述给出 [page 1]。装置如图 1：高斯光束紧聚焦，样品沿 z 轴（相对焦平面）移动，远场放置一个有限孔径，记录透过率 D₂/D₁ 随样品位置 z 的变化 [page 1]。

以 n₂ < 0 的薄样品为例：样品远在焦点之前（−z）时，随样品移向焦点，辐照度增大，负透镜效应倾向于准直光束，孔径透过率上升；样品移到焦点之后（+z），负透镜效应反而加剧衍射，透过率下降；在 z = 0 附近近似为零变化，类似于把薄透镜正好放在焦点处，远场图样几乎不变；再往 +z 远处，辐照度下降，透过率回到线性值，并被归一化为 1 [page 1]。正非线性则给出相反趋势：−z 处透过率降低，+z 处升高 [page 1]。因此，Z 扫描曲线的峰谷方向直接指示 n₂ 的符号。

## 三、从曲线到 n₂：薄介质近似与关键公式

作者把问题简化为“薄介质”：样品长度足够短，以致样品内因衍射或非线性折射引起的光束直径变化可以忽略 [page 1–2]。在此近似下，折射率写为

n = n₀ + n₂|E|² = n₀ + Δn，(1)

高斯光束振幅由式 (2) 描述，其中 w²(z) = w₀²(1 + z²/z₀²)，z₀ = kw₀²/2 为衍射长度，k = 2π/λ [page 1]。样品内振幅与非线性相位变化满足

dΔφ/dz = 2π/λ · Δn，d|E|/dz = −(α/2)|E|，(3)

其中 α 为线性吸收系数 [page 2]。解得样品出射面的相位移 Δφ：

Δφ(r, z, t) = Δφ₀(t) exp[−2r²/w²(z)]，(4a)

Δφ₀(t) = (2π/λ) Δn₀(t) (1 − e^{−αL})/α，(4b)

L 为样品长度，Δn₀(t) 为焦点处（z = 0）瞬时轴上折射率变化 [page 2]。出射场由式 (5) 给出，含非线性相位畸变；远场孔径处的场 Eₐ 通过 Huygens 原理或 Weaire 等人的高斯分解法求得 [page 2]。归一化瞬时 Z 扫描功率透过率为式 (6)，对时间积分后得到 Z 扫描注量透过率 T(z) [page 2]。

**关键推理的一步**在于：作者发现，峰谷透过率差 ΔT_{p−v} = T_p − T_v 与轴上相位畸变 Δφ₀ 近似线性相关。对多种孔径尺寸计算后，在 ±3% 精度内成立

ΔT_{p−v} ≈ p|Δφ₀|，当 |Δφ₀| < π，(7a)

p = 0.405(1 − S)^{0.25}；对轴上透过（S ≈ 0）则

ΔT_{p−v} ≈ 0.405|Δφ₀|，当 |Δφ₀| < π。(7b)

正是这条线性关系，使实验上只需测一个峰谷差，就能反推相位畸变，再经式 (4b) 得到 n₂ [page 2]。作者还指出，这种线性使时间与瞬态效应可以通过对瞬时相位畸变 Δφ₀(t) 按脉冲形状取平均来处理：高斯脉冲加快速立方非线性，平均因子为 1/√2；衰减时间远长于脉宽的累积非线性（如热），注量平均因子为 0.5，与脉冲形状无关 [page 2]。

## 四、灵敏度与几何条件

式 (7) 直接给出灵敏度标度：若装置能分辨 ΔT_{p−v} ≈ 1%，则可探测约 λ/250 的波前畸变 [page 2]。孔径大小 S 是重要参数：孔径越大，T(z) 变化越小，灵敏度越低；这种减弱在峰值处更明显，峰值透过率不能超过 (1 − S)；当 S = 1（大孔径或无孔径）时，效应消失，T(z) = 1（假设无非线性吸收）[page 2]。对小的 |Δφ₀|，峰谷相对焦点对称，对立方非线性其间距约为 1.7z₀ [page 2]。

## 五、两个实验验证

**CS₂ 的热自散焦（图 2）**：1 mm 厚 CS₂ 池，300 ns 单纵模 TEA CO₂ 激光脉冲，λ = 10.6 μm，能量 0.85 mJ [page 2]。Z 扫描呈峰谷构型，指示负（自散焦）非线性；实线为 Δφ₀ = −0.6 的计算结果，对应 Δn₀ = −1 × 10⁻³ [page 3]。作者将其归因于 CS₂ 在 10.6 μm 的线性吸收（α ≈ 0.22 cm⁻¹）导致的热非线性 [page 3]。热透镜上升时间由声渡越时间 τ = w₀/v_s 决定，CS₂ 中 v_s ≈ 1.5 × 10⁵ cm/s、w₀ ≈ 60 μm，得 τ ≈ 40 ns，比脉冲宽度小近一个数量级；热扩散弛豫约 100 ms [page 3]。因此 300 ns 脉冲引起的非均匀加热被视为准稳态，轴上平均非线性折射率变化由式 (8) 给出：

Δn = (dn/dT) · 0.5 F₀α/(ρC_v)，(8)

其中 F₀ 为注量，ρ 为密度，C_v 为比热，0.5 为注量平均因子 [page 3]。用 CS₂ 的 ρC_v ≈ 1.3 J/K·cm³，算得 dn/dT ≈ −(8.3 ± 1.0) × 10⁻⁴ °C⁻¹，与文献报道的 −8 × 10⁻⁴ °C⁻¹ 吻合 [page 3]。

**BaF₂ 的电子 Kerr 自聚焦（图 3）**：2.5 mm 厚 BaF₂ 晶体，27 ps（FWHM）、2.0 μJ 的倍频 Nd:YAG 激光，λ = 0.532 μm，聚焦光斑 w₀ = 18 μm [page 3]。Z 扫描指示正（自聚焦）非线性；按高斯脉冲拟合得 Δφ₀ = 0.085，由此算得 n₂ = (0.8 ± 0.15) × 10⁻¹³ esu [page 3]。该值与近简并三波混频测得的约 0.7 × 10⁻¹³ esu 和时间分辨干涉测得的约 1.0 × 10⁻¹³ esu 一致 [page 3]。作者特意把输入能量降到 2.0 μJ，以展示对小相位变化的灵敏度；图 3 的峰值波前畸变对应 λ/75 [page 3]。

## 六、结论成立的条件与边界

作者的结论建立在若干明确假设之上。**薄介质近似**要求样品长度远小于光束焦深，且样品内光束直径变化可忽略 [page 1–2]；式 (7) 的线性关系仅在 |Δφ₀| < π 时成立，精度 ±3% [page 2]。**无非线性吸收**是 S = 1 时 T(z) = 1 的前提 [page 2]；文中也提到此前在半导体中观察到的非线性吸收情形 [page 1]，但本文实验未涉及。**远场条件**要求孔径平面满足远场近似，此时 T(z) 的形状与幅度不依赖波长或几何 [page 2]。**脉冲平均因子**依赖非线性类型：快速立方非线性用 1/√2，长衰减累积非线性用 0.5 [page 2]；若实际非线性机制介于两者之间，该因子需相应调整，这是推断而非原文结论。

作者承认的局限主要体现在方法定位上：Z 扫描被描述为一种“筛选测试”，用于给出新非线性光学材料的符号、大小和响应阶数 [page 3]。文中未讨论非线性吸收与折射同时存在时如何分离二者，也未给出对更高阶非线性或饱和效应的处理；这些是文本未涉及的限制，不应冒充作者结论。

## 七、论证的力度

整体上，作者的论证是“理论推导 + 数值计算 + 两个独立实验验证”的组合。式 (7) 的线性关系来自数值计算而非解析证明，作者以 ±3% 精度加以限定 [page 2]；两个实验分别覆盖热非线性和电子 Kerr 非线性、红外和可见、纳秒和皮秒，且算得的 n₂ 或 dn/dT 与独立文献值吻合 [page 3]。这些一致性支持 Z 扫描作为定量方法的可靠性，但样本量小、材料种类有限，作者也未做系统的误差分析；因此“高灵敏度、单光束、可同时定符号和大小”这一核心主张在文中所给条件下成立，其普适性仍需更多材料与机制来检验。
