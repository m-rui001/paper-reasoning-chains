# 用SDSS星系功率谱打破WMAP的参数简并：Tegmark等人（2004）的联合约束论证

**原文题名**：Cosmological parameters from SDSS and WMAP
**作者**：Max Tegmark et al.
**年份**：2004（submitted 2003年10月，revised 2004年1月）
**DOI/arXiv**：astro-ph/0310723v2

## 论文要解决的核心问题

WMAP对宇宙微波背景（CMB）的精确测量开启了精密宇宙学的新阶段，但CMB数据本身无法同时约束所有宇宙学参数——参数空间中存在多种简并。Tegmark等人在这篇论文中，利用Sloan Digital Sky Survey（SDSS）对超过20万个星系的三维功率谱$P(k)$测量，与WMAP及其他数据联合，来打破这些简并，从而大幅收紧宇宙学参数的限制 [page 1]。

论文的核心主张是：在"vanilla"平坦绝热$\Lambda$CDM模型（无倾斜、无张量模、无大质量中微子）框架下，SDSS信息将WMAP单独给出的部分参数误差条缩小了一半以上——Hubble参数从$h \approx 0.74^{+0.18}_{-0.07}$收紧到$h \approx 0.70^{+0.04}_{-0.03}$，物质密度从$\Omega_m \approx 0.25 \pm 0.10$收紧到$\Omega_m \approx 0.30 \pm 0.04$（1$\sigma$），中微子质量上限从$< 11$ eV收紧到$< 0.6$ eV（95%）[page 1]。

## 论证的起点：WMAP的"香蕉"简并

论文论证的出发点是一个物理上可理解的简并结构。作者在13参数空间（式1，[page 4]）中工作，但首先聚焦于6参数"vanilla"模型：$(\tau, \Omega_\Lambda, \omega_d, \omega_b, A_s, n_s)$。WMAP单独约束下，这6个参数形成一个拉长的"香蕉形"允许区域（Figures 3, 5, [page 7, 11]）。作者明确指出，这个简并没有深刻的物理根源，而是因为用6个参数去拟合5个基本观测量：前三个声学峰的高度、大尺度归一化和角峰位置 [page 5]。

简并的工作机制被清晰地拆解：增大$\tau$和$A_s$使$A_p \equiv A_s e^{-2\tau}$保持不变，则峰高不变，唯一效应是大尺度功率增加；通过增大$n_s$可将大尺度功率相对第一峰降回观测值；再通过增大$\omega_b$压低第二峰。沿香蕉移动时，所有6个参数连同$h$一起增大 [page 5]。

**关键推理步骤**：既然简并涉及所有参数，那么"任何额外的信息片段都能打破它"（"essentially any extra piece of information will break it"）[page 6]。SDSS测量的是物质功率谱$P(k)$的形状，其"形状参数"$\Gamma \equiv h\Omega_m = 0.21 \pm 0.03$（2$\sigma$）[page 7]在$(\Omega_m, h)$平面上与CMB香蕉以一定角度相交（Figure 5, [page 11]），从而有效地切断简并。

## 证据如何支撑结论

### 参数约束的定量收紧

Table 2和Table 3分别给出WMAP单独和WMAP+SDSS联合的1$\sigma$约束 [page 7, 8]。最关键的对比在于：

- **Hubble参数**：WMAP单独给出$h = 0.74^{+0.18}_{-0.07}$，加入SDSS后变为$h = 0.695^{+0.039}_{-0.031}$，误差缩小约4倍 [page 8, Table 3]。
- **物质密度**：从$\Omega_m = 0.25 \pm 0.10$收紧到$0.301 \pm 0.045$ [page 8]。
- **重子密度和暗物质密度**：$\omega_b$和$\omega_d$的约束对理论先验选择相当稳健，因为约束它们的主要是前三个声学峰的相对高度，这些高度不受其他参数（除$\alpha$外）影响 [page 8]。

作者还给出了一个简洁的拟合公式：香蕉区域可近似为$h = 0.7(\Omega_m/0.3)^{-0.35}$，由此得到$h(\Omega_m/0.3)^{0.35} = 0.697^{+0.012}_{-0.011}$（68%）[page 7]。

### 与独立测量的交叉验证

论文通过多重独立交叉检验来增强结论的可信度：

1. **与2dFGRS的一致性**：WMAP团队联合2dFGRS得到$h \approx 0.73 \pm 0.03$，本文得到$h \approx 0.70^{+0.04}_{-0.03}$，约低1$\sigma$。作者解释这一差异源于SDSS功率谱的斜率略蓝于2dFGRS，偏好略高的$\Omega_m$值 [page 8]。
2. **与BBN的一致性**：WMAP+SDSS给出的$\omega_b = 0.023 \pm 0.001$与最新BBN测量$\omega_b = 0.022 \pm 0.002$吻合良好 [page 7]。
3. **与HST Key Project的一致性**：$h \approx 0.70^{+0.04}_{-0.03}$与HST的$h = 0.72 \pm 0.07$一致，且误差更小 [page 8]。
4. **与pre-WMAP CMB数据的一致性**：用pre-WMAP CMB数据替代WMAP，结果和误差条仍然相似（Table 3最后一列）[page 8]。

### 对先验假设的系统性检验

论文的一个重要贡献是系统检验了结论对理论先验的敏感性。作者明确指出WMAP团队的分析使用了四个强先验：$\tau < 0.3$、零张量模和空间曲率、从2dFGRS双谱已知的星系偏置、以及可靠的红移畸变模型 [page 2]。本文逐一放松这些假设：

- **曲率**：放松平坦假设后，$h$和$t_0$的约束显著变弱。WMAP单独甚至允许$\Omega_{tot} \sim 1.5$（95%），只要$h \sim 0.3$且$t_0 \sim 20$ Gyr [page 11]。加入SDSS后曲率不确定度缩小约3倍，再加入SN Ia后达到$\Omega_{tot} = 1.01 \pm 0.02$（1$\sigma$）[page 11]。
- **张量模**：加入张量模对其他参数影响很小，主要只是将$n_s$从0.98提升到1.01 [page 18]。
- **中微子质量**：允许$f_\nu$自由时，$\sigma_8$下降10%，$\Omega_m$增加25% [page 18]。
- **暗能量状态方程**：$w$的约束在20%水平，所有数据与$w = -1$一致 [page 17]。

## 关键推理的桥接与隐含假设

论文从证据到结论的推理中，有几个关键步骤值得明确：

**第一，为什么SDSS的$P(k)$形状能打破CMB简并？** 作者的解释是：CMB简并本质上是5个观测量约束6个参数，而SDSS独立测量了物质功率谱的形状参数$h\Omega_m$，这在$(\Omega_m, h)$平面上提供了一个与CMB香蕉相交的约束 [page 7, Figure 5]。这一步的隐含假设是：星系功率谱的形状确实追踪物质功率谱的形状，即线性偏置$b$是尺度无关的。作者通过将$b$作为自由参数边缘化来处理这一点，只使用$P(k)$的形状而非振幅 [page 4]。

**第二，为什么约束对某些先验稳健而对另一些敏感？** 作者给出了物理分类：$\omega_b$、$\omega_d$和$n_s$的约束主要来自声学峰相对高度，这些不受$\Omega_k$、$r$、$w$、$f_\nu$影响（它们只水平移动峰位置或改变大尺度功率）[page 8]。而$h$和$\Omega_m$的约束则关键依赖于平坦假设 [page 9]。

**第三，中微子质量约束的物理机制**：WMAP本身对中微子质量无约束（与中微子占100%暗物质一致），但WMAP强约束了其他参数，使得SDSS能够测量大质量中微子引起的小尺度$P(k)$压低 [page 15]。这一推理的关键是：中微子自由流导致小尺度功率压低，而SDSS的$P(k)$形状对此敏感。

## 结论成立的条件与边界

论文明确承认了几个影响结论的关键条件：

1. **平坦假设是$h$和$\Omega_m$精确约束的关键**。放松平坦假设后，$h$的约束从$\pm 0.03$退化到$\pm 0.09$（WMAP+SDSS），$t_0$的约束也大幅放宽 [page 11, Table 3 vs Table 4]。

2. **中微子质量上限依赖于标准冻结产出假设**。作者明确指出，宇宙学约束探测的是中微子质量密度$\rho_\nu$，将其转换为质量上限假设了标准模型冻结产出的数密度112 cm$^{-3}$。对非标准中微子，应引用的结论是$\rho_\nu < 4.8 \times 10^{-28}$ kg/m$^3$（95%）[page 16]。

3. **中微子质量检测声称的脆弱性**。作者展示了Allen等人声称的中微子质量检测$M_\nu \gtrsim 0.6$ eV关键依赖于特定的低星系团$\sigma_8$测量，当将星系团$\sigma_8$误差扩大到反映文献中的散布时，证据消失 [page 16-17, Figure 12]。

4. **系统误差与统计误差的关系**。Table 7显示，将$k_{max}$从0.2降到0.15 $h$/Mpc对$\Omega_m$最佳拟合值几乎无影响，误差条增加约20%；但降到0.1 $h$/Mpc则误差条翻倍以上 [page 19]。使用线性而非非线性功率谱会使$\Omega_m$上升约0.04（1.3$\sigma$）[page 19]。作者判断，只要非线性红移畸变和偏置的建模误差不超过非线性修正本身，$k_{max} = 0.2h$/Mpc的结果就由统计误差主导 [page 20]。

5. **先验选择的影响可能超过统计误差**。作者坦承，改变理论先验（如放弃零中微子或零曲率假设）会使$\Omega_m$变化0.08，远大于统计误差 [page 20]。MCMC中隐含的均匀先验选择也会对弱约束参数（如$\tau$）产生约1$\sigma$的偏移 [page 20]。

## 暴涨模型检验的论证结构

论文在$(n_s, r)$平面上检验暴涨模型（Figure 10, [page 14]）。三类慢滚暴涨模型——小场、大场、混合——仍然全部被允许。但具体模型面临更有趣的约束：$V \propto \phi^6$被CMB单独排除，$V \propto \phi^4$处于边缘，$V \propto \phi^2$（随机永恒暴涨）稳固处于允许区域 [page 14]。作者指出，随着数据改善，随机永恒暴涨的预测$(n_s, r) \approx (0.96, 0.15)$将与 negligible tensor 模型区分开来 [page 14]。

关于running spectral index $\alpha$，作者报告最佳拟合$\alpha$值与WMAP团队一致，但与$\alpha = 0$一致（95%误差条约0.1），$\chi^2$仅下降5，在释放3个参数的情况下不显著 [page 15]。作者还指出，任何running的迹象都来自CMB单独，最可能来自低四极矩功率 [page 15]。

## 总体判断

这篇论文的论证力量在于其系统性和透明度。作者不仅报告了联合约束的结果，更重要的是清晰地解释了"为什么"——SDSS通过测量$P(k)$形状参数$h\Omega_m$，在$(\Omega_m, h)$平面上以一定角度切断CMB香蕉简并。论文通过逐步放松先验假设，量化了每个假设对结论的影响，使读者能够判断哪些结论是稳健的、哪些依赖于特定假设。

论文最诚实的部分是对局限性的交代：$h$和$\Omega_m$的精确约束关键依赖于平坦假设；中微子质量上限依赖于标准冻结产出；先验选择的影响可能超过统计误差。这些限定并不削弱论文的价值，反而使结论的适用范围更加清晰。

一个值得注意的边界是：论文的所有约束都在绝热、高斯原初扰动框架内，不包含等曲率模。作者在结论中明确列出了"我们不知道什么"：不知道暗物质、暗能量和近尺度不变种子扰动的物理起源 [page 21]。这种对知识边界的清晰划定，本身就是论证严谨性的一部分。
