# 2D 与 3D 细胞培养：不同肿瘤细胞培养类型的比较

**原文题名**：2D and 3D cell cultures – a comparison of different types of cancer cell cultures
**年份**：2016（Arch Med Sci 2018; 14, 4: 910–919）
**DOI**：https://doi.org/10.5114/aoms.2016.63743

这是一篇综述（state of the art paper），不是单一实验报告。它的核心主张可以概括为：在肿瘤生物学研究中，传统二维（2D）单层培养因丢失细胞—细胞、细胞—细胞外环境相互作用而系统性偏离体内肿瘤状态；三维（3D）培养在形态、极性、基因表达、信号与代谢等方面更接近实体瘤，因而在药物反应、放疗反应、侵袭转移和肿瘤起始细胞研究中是更合适的模型，但它并非万能，不同 3D 系统各有代价，理想模型并不存在。作者用一张对比表、若干自制的 FaDu/SCC-040/SCC-25/MSU-1.1 细胞系图片，以及大量文献证据来支撑这一主张。

## 论证的起点：2D 培养的“系统性失真”

作者先确立一个前提：细胞培养是研究细胞生物学、组织形态、疾病机制、药物作用与组织工程的核心体外工具 [page 1]。培养方式分贴壁与悬浮两类，而最常用的是 2D 贴壁模型 [page 2]。随后作者集中论证 2D 的缺陷，这是整篇论证的支点。

2D 的优点是操作简单、成本低、便于功能检测 [page 2]。但作者指出，贴壁细胞以单层形式贴在塑料表面生长，无法模拟组织或肿瘤的自然结构（Figure 2 A）[page 2]。关键推理在于：细胞—细胞和细胞—细胞外环境的相互作用负责细胞分化、增殖、活力、基因与蛋白表达、刺激应答、药物代谢等功能 [page 2]。一旦这些相互作用在 2D 中被破坏，下游后果是连锁的——形态改变、分裂方式改变、表型多样性丢失、极性丧失，进而影响凋亡应答、胞内结构组织、分泌与信号传导 [page 2]。作者还强调 2D 中细胞对氧气、营养、代谢物和信号分子的获取是“无限制的”，而体内肿瘤因自身结构导致这种获取是可变的 [page 2]。此外，2D 通常为单培养，只能研究一种细胞类型，缺失体内肿瘤起始细胞所需的微环境或“niche” [page 2–3]。

这些论点大多以文献引用支撑（如 [9, 11–13]、[23–26]），属于综述对既有证据的归纳，而非本文新实验。Table I 把这些差异整理为八个维度：培养形成时间、培养质量、体内模拟度、细胞相互作用、细胞特征、必需化合物获取、分子机制、维持成本 [page 4]。这张表是全文论证的骨架，读者可据此看到 2D 与 3D 的对照逻辑。

## 3D 培养为何更接近体内：从结构到分子

作者随后转向 3D。历史起点是 1970 年代 Hamburg 和 Salmon 的软琼脂三维培养 [page 3]。作者主张 3D 条件下细胞在形态和行为上与肿瘤块中细胞高度相似 [page 3]。

3D 模型按制备方式分为三类：非黏附板上的悬浮培养（Figure 2 C）、浓缩培养基或凝胶状物质中的培养（Figure 2 B）、支架上的培养（Figure 2 E）[page 3]。Table II 逐一列出三类的描述、优点与缺点 [page 5]。这里的关键论证是：3D 中细胞能获得来自局部环境的刺激，形态与极性得以维持，甚至可让先前在 2D 中培养的细胞恢复这些特征 [page 4]。在腺泡样球体中还观察到管腔形成，这是球体中心细胞凋亡的结果，增殖则集中在周边 [page 4]。作者据此认为 3D 在细胞拓扑、基因表达、信号和代谢上更接近体内 [page 4]。

Figure 3 提供了本文自制的形态学证据：SCC-040 和 FaDu 细胞在 2D 与 3D 条件下的 H&E 与 DAPI 染色切片对比 [page 6]。这是作者实验室的工作，用于直观展示 3D 球体的结构层次，而非定量证明。读者应注意，这类图片支持“结构不同”的观察，但不能单独支撑“3D 更接近体内”的普遍结论——后者依赖作者引用的更广泛文献。

## 药物与放疗反应：3D 论证中最有分量的证据

全文最有说服力的推理出现在药物敏感性和放疗部分。作者指出，3D 中肿瘤细胞对药物不如 2D 敏感，可能原因包括化合物获取减少、缺氧等病理生理差异，或细胞周期改变 [page 5]。这里作者用了“may be caused by”的谨慎语气，说明这是可能解释而非确定机制。

关键的一步来自 Hsieh 等人的工作：在 2D、3D 和球体模型中，只有细胞密度与天然组织相同的 3D 培养，其药物反应与实体瘤可比 [page 5]。这条证据把“3D 更像体内”从形态学层面推进到功能层面——如果药物反应能对上，3D 作为药敏测试平台的价值就有了直接支撑。

放疗方面，作者引用 Storch 等人的机制研究：3D 结构通过影响 DNA 异染色质化（组蛋白 H3 去乙酰化、HP1α 高表达）带来放射存活增加，异染色质部分保护 DNA 免受辐射诱导的双链断裂；用 HDAC 1/2/4 敲低或 HDAC 抑制剂 LBH589 可克服这一现象，但生长条件与 HDAC 修饰都不影响 ATM 磷酸化 [page 6]。这是一个有明确分子机制的论证，比单纯的形态对比更强。作者还引用 TAE226（FAK/IGF-IR 抑制剂）在 3D 条件下显示强放射增敏潜力，以及 cetuximab 与 TAE226 联合靶向可在无需额外照射下诱导细胞死亡 [page 6–7]。这些结果被作者用来论证 3D 模型在临床前放疗研究中的潜在价值。

## 3D 的代价与边界：作者主动承认的局限

作者没有把 3D 写成无条件的更优选择。相反，多处明确列出其缺点：

- 3D 需要蛋白酶降解单层来分离单细胞，耗时数小时到数天 [page 7]。
- 许多 3D 方法在效率、寿命、重复性和操作舒适度上不如 2D [page 7]。
- 球体可能由几个细胞簇而非单细胞形成；但作者随即辩护：即使由多细胞聚集形成，仍具三维形式，比扁平贴壁培养更好 [page 7]。
- 低重复性问题被 Vinci 等人的 96 孔超低黏附板方案部分解决，每孔一个球体，尺寸可重复且呈高斯分布 [page 7]。
- Table II 列出各系统的具体缺点：悬浮培养中部分细胞系需昂贵包被板；凝胶培养中软琼脂制备繁琐、重复性低、从琼脂中提取细胞和免疫荧光染色困难，Matrigel 含内源性生物活性成分影响结构形成；支架培养中支架尺度与拓扑、材料本身都会影响细胞黏附、生长和行为，且细胞观察与提取受限 [page 5]。

作者最终明确表态：“Clearly, the ideal 3D model does not exist.”（理想的 3D 模型并不存在）[page 7]。3D 系统选择主要取决于研究性质，选错模型可能影响结果 [page 7]。这是全文对结论边界最重要的限定。

## 共培养：论证的延伸与一个诚实的负面观察

作者把共培养作为独立一节，因为肿瘤是多种细胞类型构成的团块 [page 7]。共培养分直接（细胞混合）和间接（物理屏障分隔）两类，均可在 2D 或 3D 中进行 [page 7]。直接共培养可观察细胞—细胞、细胞—微环境和旁分泌信号三类相互作用 [page 7]。

值得注意的是，作者报告了一个来自自身经验的负面观察：不同表型的细胞即使直接共培养也不互相生长。Figure 4 显示间充质成纤维细胞（绿色）与上皮肿瘤细胞（红色）在 2D 和 3D 中都各自生长在自身细胞系范围内；在 3D 条件下，SCC-25（红）形成三维结构，MSU-1.1（绿）作为辅助细胞围绕在已形成的结构周围 [page 7–8]。这个观察与“共培养能模拟体内多种细胞相互作用”的乐观预期形成张力，作者没有回避，而是如实呈现。共培养的缺点还包括必须优化众多变量（群体相似度与分离度、培养基成分、体积、培养时长），操作困难 [page 8]。

## 结论成立的条件

综合来看，作者的结论在以下条件下成立：

第一，结论是“3D 在多数肿瘤研究场景中比 2D 更接近体内”，而非“3D 全面优于 2D”。作者明确说“In some cases the use of a 2D culture system is enough”（某些情况下 2D 已足够）[page 7]。

第二，3D 的优势证据强度不均。形态、极性、基因表达等有较多文献支持；药物反应与实体瘤可比这一关键论断主要依赖 Hsieh 等人的单一研究 [page 5]；放疗机制有 Storch、Hehlgans、Eke 等人的分子层面证据 [page 6–7]。读者应区分这些证据的层级。

第三，3D 的“更接近体内”是程度问题，不是全有或全无。作者承认球体可能由细胞簇形成、Matrigel 含内源性活性成分、支架材料本身影响细胞行为，这些都意味着 3D 系统引入了新的混杂因素 [page 5, 7]。

第四，本文是 2016 年投稿的综述，其引用的具体数据（如 40 个肿瘤细胞系分为紧密球体、致密聚集体、松散聚集体三组 [page 4]）来自他人研究，本文未重复验证。Figure 2、3、4 是作者实验室自制，用于形态学展示，不构成定量证据。

最后需要指出，作者对未来持谨慎乐观：3D 会因自动化和成本降低而更频繁使用，是通向个性化医疗的潜在更好路径 [page 8]。这是展望性判断，不是已证结论。整篇论证的力量在于把“2D 失真—3D 更真—但 3D 有代价—理想模型不存在”这条链条讲得清楚，而不是宣称 3D 是终点。
