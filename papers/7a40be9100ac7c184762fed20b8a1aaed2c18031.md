# 用纠缠纯化与 CSS 码为 BB84 搭一座安全证明的桥

**原文题名**：Simple Proof of Security of the BB84 Quantum Key Distribution Protocol
**作者**：Peter W. Shor, John Preskill
**年份**：2000（arXiv:quant-ph/0003004v2, 12 May 2000）

## 这篇论文要解决的是一个"证明缺口"

BB84 是 1984 年 Bennett 和 Brassard 提出的第一个量子密钥分发协议，其安全性直觉来自"无法同时测量两个共轭基"这一量子力学事实。但正如作者在开篇指出的，原始论文只证明了协议能抵抗某些特定攻击，包括当时实验技术可行的攻击；在很长一段时间里，没有人严格证明它能抵抗任何量子力学允许的物理操作 [page 1]。到 2000 年，已经出现了三个安全性证明，但作者认为"没有一个完全令人满意"：Lo-Chau 的证明 [2] 容易理解，却要求协议本身使用量子计算机；Mayers [3] 和 Biham 等人 [4] 的证明适用于接近实用的 BB84 类协议，但都相当复杂 [page 1]。

Shor 和 Preskill 的目标因此很明确：给出一个**更简单**的 BB84 安全性证明。他们的策略不是直接攻击 BB84，而是先构造一个基于纠缠纯化的协议（Protocol 1，即修改版 Lo-Chau），借助 Lo-Chau 已有的安全性结果证明它安全；再通过一系列"测量时机可以前后移动"的等价变换，把这个协议逐步改写成 CSS 码协议（Protocol 2），最终改写成 BB84（Protocol 3），从而把安全性"传递"给 BB84 [page 1][page 3][page 4]。整篇论文的论证骨架就是这条等价链。

## 为什么 CSS 码是这座桥的关键

要理解这条等价链，先要理解作者为什么选中 CSS 码。一个量子 CSS 码 $Q$ 由两个嵌套的二元经典码 $C_2 \subset C_1$ 定义，其码字由 $v \in C_1$ 按式 (1) 生成 [page 1]：

$$v \longrightarrow \frac{1}{|C_2|^{1/2}} \sum_{w \in C_2} |v + w\rangle.$$

这个码保护一个维度为 $2^{\dim C_1 - \dim C_2}$ 的 Hilbert 空间。作者随后引入了一族由两个 $n$ 比特向量 $x, z$ 参数化的等价码 $Q_{x,z}$，其码字如式 (2) [page 2]：

$$v \longrightarrow \frac{1}{|C_2|^{1/2}} \sum_{w \in C_2} (-1)^{z \cdot w} |x + v + w\rangle.$$

CSS 码真正被用到的性质，是**比特翻转纠错与相位翻转纠错彼此解耦**：用 $C_1$ 的校验矩阵 $H_1$ 测量 $\sigma_z^{[r]}$ 得到比特翻转的 syndrome，用 $C_2^\perp$ 的校验矩阵 $H_2$ 测量 $\sigma_x^{[r]}$ 得到相位翻转的 syndrome，两者互不干扰 [page 2]。正是这一解耦，使得后面 Bob 可以完全不需要 $z$——因为 $z$ 只用于相位纠正，而 Bob 只关心密钥的比特值 [page 3]。这一步是整条等价链能够从"需要量子计算机的纠缠纯化协议"走到"只需单光子测量的 BB84"的技术枢纽。

## 从纠缠纯化到密钥：Protocol 1 如何被证明安全

Protocol 1（修改版 Lo-Chau）的流程是：Alice 制备 $2n$ 个处于 $(\Phi^+)^{\otimes n}$ 的 EPR 对，随机选一个 $2n$ 比特串 $b$ 并对 $b$ 为 1 的位置做 Hadamard 变换，把每个 EPR 对的第二半发给 Bob；Alice 从中选 $n$ 个作为校验比特，公布 $b$ 和校验比特位置；Bob 做相应 Hadamard 后，双方测量校验比特并比对结果，若不一致太多就中止；对剩下的码比特，双方测量 $\sigma_z^{[r]}$（$r \in H_1$）和 $\sigma_x^{[r']}$（$r' \in H_2$），共享结果、计算 syndrome、纠正错误，得到 $m$ 个近乎完美的 EPR 对；最后测量这些 EPR 对得到共享密钥 [page 2–3]。

安全性论证的核心是一个"抽样估计"论证。作者要证明的是：Alice 和 Bob 在密钥上一致、而 Eve 只能获得指数小信息的概率是指数接近 1 的。他们援引 Lo 和 Chau 的结果：如果 Alice 和 Bob 共享的态与 $(\Phi^+)^{\otimes m}$ 的保真度为 $1 - 2^{-s}$，则 Eve 与密钥的互信息至多为 $2^{-c} + 2^{O(-2^s)}$，其中 $c = s - \log_2(2m + s + 1/\log_e 2)$ [page 3]。

关键的推理步骤在于把"校验比特上的错误率"和"码比特上的错误率"联系起来。作者先指出两个恒等式 [page 3]：

$$|\Psi^+\rangle\langle\Psi^+| + |\Psi^-\rangle\langle\Psi^-| = |01\rangle\langle 01| + |10\rangle\langle 10|,$$
$$|\Phi^-\rangle\langle\Phi^-| + |\Psi^-\rangle\langle\Psi^-| = |+-\rangle\langle +-| + |-+\rangle\langle -+|.$$

这两个式子说明：Alice 和 Bob 从校验比特测量中估计出的比特翻转率和相位翻转率，与他们在 Bell 基下测量会得到的估计相同。接着，作者用投影算符 $\Pi$（投影到"比特翻转和相位翻转各不超过 $t$ 个"的 Bell 对张成空间）给出保真度下界（式 3）[page 3]：

$$F \equiv \langle(\Phi^+)^{\otimes m}|\rho'|(\Phi^+)^{\otimes m}\rangle \geq \mathrm{tr}(\Pi\rho).$$

也就是说，纯化协议最终的保真度至少等于"若对所有 $n$ 对做 Bell 测量、发现错误数不超过 $t$"的概率。而由于 Eve 在 Alice 公布哪些是校验比特之前无法区分校验比特和码比特，校验比特就相当于对全部量子比特的**经典随机抽样**。于是可以用经典概率估计：在码比特上出现超过 $\delta n$ 个比特（或相位）错误、而校验比特上错误少于 $(\delta - \epsilon)n$ 的概率，渐近小于 $\exp[-\frac{1}{4}\epsilon^2 n/(\delta - \delta^2)]$ [page 3]。结论是：只要 Alice 和 Bob 通过校验的概率大于指数小量，他们最终态与 $(\Phi^+)^{\otimes m}$ 的保真度就指数接近 1，从而 Eve 的信息指数小。

这里有一个作者明确依赖但未展开的桥接：**为什么"保真度高"就意味着"Eve 信息少"**。作者用一句话点出直觉——"对于足够低的错误率，CSS 码以极高保真度传输其编码的信息，因此由不可克隆原理，能泄漏给 Eve 的信息极少" [page 3]。严格的安全性则来自前面引用的 Lo-Chau 定理。这是原文明说的推理，不是分析者的补充。

## 等价变换：测量可以前后移动

Protocol 1 到 Protocol 2 的转换，靠的是一系列"测量时机无关紧要"的观察 [page 3]：

- Alice 在校验比特上先测量还是先发送，结果一样——先测量等价于随机选一个 $|0\rangle$ 或 $|1\rangle$。
- Alice 先测量 syndrome 还是先发送，结果一样——先测量等价于发送由 CSS 码 $Q_{x,z}$ 编码的 $m$ 个 EPR 对的半部分，其中 $x$ 由 $\sigma_z^{[r]}$ 的 syndrome 决定，$z$ 由 $\sigma_x^{[r']}$ 的 syndrome 决定。
- Alice 先测量她那一半编码 EPR 对还是先发送，结果一样——先测量等价于随机选一个密钥 $k$ 并用 $Q_{x,z}$ 编码。

由此得到 Protocol 2（CSS 码协议）：Alice 制备 $n$ 个随机校验比特、一个随机 $m$ 比特密钥 $k$、一个随机 $2n$ 比特串 $b$，随机选 $x, z$，用 $Q_{x,z}$ 编码密钥，把校验比特和码比特放到 $2n$ 个位置，对 $b$ 中为 1 的位置做 Hadamard，发送给 Bob；Bob 确认收到后，Alice 公布 $b$、校验比特位置及其值、以及 $x, z$；Bob 做相应 Hadamard，检查校验比特是否被过度篡改，然后解码密钥 [page 3]。

## 从 CSS 码协议到 BB84：消去 $z$ 与 $x$

Protocol 2 到 Protocol 3 的转换，是整篇论文最精巧的一步。作者指出，Bob 只关心编码密钥的比特值，而 $z$ 只用于纠正相位，所以 Bob 根本不需要 $z$ [page 3–4]。既然 Bob 不用 $z$，就可以假设 Alice 不发送它。对 $z$ 取平均后，Alice 实际发送的是混合态（式 4）[page 4]：

$$\frac{1}{2^n |C_2|} \sum_z \left[ \sum_{w_1, w_2 \in C_2} (-1)^{(w_1 + w_2) \cdot z} |k' + w_1 + x\rangle\langle k' + w_2 + x| \right] = \frac{1}{|C_2|} \sum_{w \in C_2} |k' + w + x\rangle\langle k' + w + x|,$$

即 $|k' + x + w\rangle$ 的混合，其中 $w$ 在 $C_2$ 中随机选取。把整个协议看作一个整体：Alice 给 Bob 的纠错信息是 $x$，她通过量子信道发送 $|k' + x + w\rangle$；在多次迭代中，这些量是 $\mathbb{F}_2^n$ 上均匀随机的变量，约束是 $k' + w \in C_1$。Bob 收到 $k' + w + x + \epsilon$ 后减去 $x$，纠正到 $C_1$ 中的码字，几乎必然是 $k' + w$；密钥是 $k' + w$ 关于 $C_2$ 的陪集。

作者接着把 BB84 的对应量摆出来：Alice 发送 $|v\rangle$，纠错信息是 $u + v$，其中 $u$ 是 $C_1$ 中的随机码字；Bob 得到 $v + \epsilon$，减去 $u + v$，纠正到 $C_1$ 中的码字，高概率得到 $u$；密钥是 $u + C_2$ 的陪集。作者由此断言："这两个协议完全等价" [page 4]。这一步的推理是：两个协议中 Alice 发送的量子态、Bob 收到的经典信息、以及最终密钥的代数结构一一对应，因此 Protocol 2 的安全性直接传递给 BB84。

Protocol 3（BB84）的具体流程是：Alice 制备 $(4 + \delta)n$ 个随机比特，随机选一个 $(4 + \delta)n$ 比特串 $b$，按 $b$ 的对应位在 $|0\rangle, |1\rangle$ 基或 $|+\rangle, |-\rangle$ 基制备量子态，发送给 Bob；Bob 随机选基测量；Alice 公布 $b$；Bob 丢弃基不匹配的结果（高概率至少剩 $2n$ 比特，否则中止）；Alice 随机选 $2n$ 比特用于协议，其中 $n$ 个作为校验比特；双方公布校验比特值，若一致太少则中止；Alice 公布 $u + v$（$v$ 是剩余非校验比特串，$u$ 是 $C_1$ 中随机码字）；Bob 从 $v + \epsilon$ 中减去 $u + v$，把 $u + \epsilon$ 纠正到 $C_1$ 中的码字；双方用 $u + C_2$ 的陪集作为密钥 [page 4]。

## 结论成立的条件与作者承认的边界

这篇论文的结论有明确的适用条件，作者也主动交代了局限。

**码率与错误率阈值**。Protocol 3 使用最小距离大的二元码 $C_1$ 和 $C_2^\perp$，可以达到 CSS 码的量子 Gilbert-Varshamov 界 [page 4]。若要达到更好的 Shannon 界，需要使用"随机小量相位错误和比特错误几乎总能被纠正"的码。为此作者增加了一个步骤：Alice 在发送前用随机置换 $\pi$ 打乱量子比特，Bob 确认收到后 Alice 发送 $\pi$，Bob 解扰。作者指出，只要测得的比特和相位错误率低于 **11%**——即 Shannon 率 $1 - 2H(\delta)$ 降为 0 的点——这个做法就可行 [page 4]。对于实用密钥分发，经典码 $C_1$ 需要高效可解码；作者援引 [3] 指出，可以令 $C_2$ 是高效可解码码 $C_1$ 的随机子码，高概率得到好的 $C_2^\perp$；已知的高效可解码码虽未达到 Shannon 界，但相当接近 [page 4]。

**光源必须是理想单光子源**。作者明确承认，本文的证明和 [3,4] 的证明都有一个弱点：**不适用于非理想光源，光源必须是完美的单光子源** [page 4]。他们提到 Ben-Or 最近发现了一个避开这一困难的证明，表明任何足够接近单光子源的光源仍然安全；但大多数实验量子密钥分发系统使用弱相干光源，而"目前没有已知的证明覆盖这种情况" [page 4]。这是作者亲口承认的、影响结论适用范围的重要边界。

**一个被作者搁置的技术细节**。在讨论经典纠错时，作者在脚注 [7] 中承认，从 syndrome 计算最可能的错误值"可能相当困难，但目前我们忽略这个实际复杂性" [page 5]。这意味着论文的安全性论证在纠错效率这一环上做了简化处理。

## 论证的力度与限度

从整体看，这篇论文的贡献不在于提出新的安全性定理，而在于**重新组织已有的安全性结果**，用 CSS 码的解耦性质把 Lo-Chau 的纠缠纯化证明"翻译"成 BB84 的语言。它的说服力来自等价链的每一步都相对初等：测量时机的交换、对 $z$ 取平均、代数结构的对应，都是可以直接验证的。作者也明确指出，这个证明"可能阐明先前证明 [3,4] 的某些性质"，并解释了为什么这些证明得到的码率与 CSS 码的码率相关——因为 CSS 码"隐藏在 [3] 证明的内部运作中" [page 1]。

需要留意的是，论文的严格安全性最终仍依赖 Lo-Chau 定理（保真度与 Eve 互信息的关系）和经典概率估计（抽样误差的指数小概率），作者对这两者都只做了引用或简述，没有在本文中重新证明。因此，这篇论文的"简单"是相对于 [3,4] 的复杂性而言的，它把复杂性集中转移到了两个被引用的外部结果上。此外，11% 的错误率阈值、Shannon 界与 Gilbert-Varshamov 界的区分、以及高效可解码码的实际性能，都是影响协议实际可用性的参数，作者对这些的讨论是简短的，读者若要把结论用于具体系统，需要回到 [3,6] 等文献核对细节。
