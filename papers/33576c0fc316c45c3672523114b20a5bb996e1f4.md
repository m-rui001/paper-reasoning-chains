# 从关节空间到操作空间：Khatib 的运动与力统一控制框架

**原文题名**：A Unified Approach for Motion and Force Control of Robot Manipulators: The Operational Space Formulation
**作者**：Oussama Khatib
**发表**：IEEE Journal of Robotics and Automation, Vol. RA-3, No. 1, February 1987, pp. 43–52
**DOI**：10.1109/JRA.1987.1087068

---

## 一、问题意识：为什么关节空间模型不够用

这篇论文的出发点是一个工程与理论上的错位。机器人动力学的传统研究几乎都围绕关节运动方程展开，关节空间模型也成为各类动力学控制方法的基础 [page 1]。但作者指出，任务本身——无论是运动轨迹还是接触力——是在末端执行器（end-effector）层面被指定、被感知、被评价的。当机械臂在运动中进行装配、接触、插入等操作时，末端执行器承受惯性力、离心力和科里奥利力；这些动态力的量级在大加速度和快速运动下不可忽略。更关键的是，在某个方向上进行力控制时，正交方向上由运动产生的耦合力会显著干扰该方向的力控制效果 [page 1]。

作者由此提出一个明确的判断：关节空间模型只描述关节运动之间的相互作用，无法刻画"沿不同轴的运动如何相互影响"以及"末端执行器的等效惯量如何随位形和方向变化" [page 1]。这正是操作空间（operational space）表述要解决的问题。论文的核心主张可以概括为：**以末端执行器的动态行为为对象建立运动方程，可以在同一框架下统一处理自由运动、约束运动、主动力控制、冗余机构以及运动学奇异，而无需回到关节空间逐一化解任务**。

## 二、任务描述：广义任务规范矩阵

论文首先处理的是"任务如何被描述"这一问题。末端执行器的位形由 $m$ 个参数 $x_1, x_2, \ldots, x_m$ 表示，自由运动时其自由度为 $m_0$，即完全确定位置和姿态所需的独立参数个数 [page 2]。在约束运动中，几何约束（假定为完整约束）减少运动自由度，但不影响静态力和力矩的施加——约束只限制运动，不限制力 [page 2]。图 1 给出了五、四、三自由度的约束末端执行器示例 [page 2]。

作者引入的关键工具是**任务规范矩阵**。设 $\mathbf{f}_d$ 为期望施加力的单位向量，则位置自由方向位于与 $\mathbf{f}_d$ 正交的子空间中。在由旋转 $S_f$ 得到、使 $z_f$ 与 $\mathbf{f}_d$ 对齐的坐标系 $\mathfrak{R}_f$ 中，位置规范矩阵定义为

$$\Omega_f = \begin{pmatrix} \sigma_x & 0 & 0 \\ 0 & \sigma_y & 0 \\ 0 & 0 & \sigma_z \end{pmatrix} \tag{1}$$

其中 $\sigma_x, \sigma_y, \sigma_z$ 为二值数，当沿相应轴指定自由运动时取 1，否则取 0 [page 2]。力规范矩阵则定义为

$$\bar{\Omega}_f = I - \Omega_f \tag{2}$$

即运动方向与力控制方向互补 [page 2]。对旋转和力矩，作者用类似方式定义 $\Omega_r$ 和 $\bar{\Omega}_r$，并组合成广义任务规范矩阵 $\Omega$ 和 $\bar{\Omega}$ [page 3]。

这里有一个值得注意的设计选择：作者刻意把选择过程放在与机械臂几何、运动学、动力学模型相同的参考系 $\mathfrak{R}_0$ 中完成，而不是在任务坐标系中。理由是实时实现效率——若只在任务坐标系中指定，控制系统需要频繁进行昂贵的坐标变换 [page 3]。这一动机贯穿全文：**操作空间表述的一个核心卖点就是计算结构上的可行性**。

## 三、末端执行器运动方程：从拉格朗日到操作空间

论文的论证重心在第三节。对非冗余机械臂（$n = m_0$），作者先讨论一个前提条件：要使末端执行器参数成为机械臂的广义坐标，必须把几何模型 $x = G(q)$ [式 (5)] 限制在使 $G$ 为一一对应的定义域内，并排除雅可比矩阵 $J(q)$ 奇异的位形 [page 3–4]。在这些限制下，操作坐标构成广义坐标系，动能可写为

$$T(x, \dot{x}) = \frac{1}{2}\dot{x}^T A(x)\dot{x} \tag{10}$$

用拉格朗日形式导出末端执行器运动方程

$$A(x)\ddot{x} + p(x, \dot{x}) + p(x) = F \tag{14}$$

其中 $p(x, \dot{x})$ 是离心与科里奥利力向量，$p(x)$ 是重力向量，$F$ 是操作力向量 [page 4]。式 (15)–(16) 给出 $p$ 的分量与 Christoffel 符号的关系。

论证的关键一步在于**把操作空间量与关节空间量联系起来**。作者通过动能二次型在两种广义速度下相等的恒等式，得到

$$A(x) = J^{-T}(q)A(q)J^{-1}(q) \tag{18}$$

并进一步导出 $p(x, \dot{x})$ 与关节空间科里奥利力 $b(q, \dot{q})$ 的关系 [式 (24)]，以及重力项的关系 [式 (25)] [page 4–5]。最终得到操作力与关节力的基本关系

$$\tau = J^T(q)F \tag{28}$$

作者称式 (28) 为"操作空间实际控制的基础" [page 5]。这一步的推理意义在于：它把操作空间模型中的动态参数全部用关节坐标表达，从而消除了"末端执行器位形对应哪个机械臂位形"的歧义，使模型定义域可以扩展到 $G$ 非一一对应的区域（只要排除奇异位形）[page 5]。

## 四、运动控制与力控制的统一

有了式 (28)，控制问题转化为：选择操作力 $F$ 作为指令向量，再通过式 (28) 映射为关节力。作者采用非线性动态解耦结构

$$F = F_m + F_{ccg} \tag{29}$$

其中 $F_m = A(x)F_m^*$，$F_{ccg} = p(x, \dot{x}) + p(x)$ [page 5]。在完美解耦下，末端执行器等效于一个在 $m_0$ 维空间中运动的单位质量。随后可在解耦后的系统上选择线性控制律，例如

$$F_m^* = \ddot{x}_d - k_p(x - x_d) - k_v(\dot{x} - x_d) \tag{31}$$

或用于大范围点到点运动的直线运动律 [式 (32)–(33)] [page 5]。

对应的关节力指令为

$$\tau = J^T(q)A(q)F_m^* + \hat{b}(q, \dot{q}) + \hat{g}(q) \tag{34}$$

其中 $\hat{b}(q, \dot{q})$ 是末端执行器科里奥利与离心力映射到关节空间后的向量，与关节空间自身的 $b(q, \dot{q})$ 不同，二者关系由式 (35) 给出 [page 5–6]。作者进一步把 $\hat{b}$ 分解为与位形相关和与速度相关的部分 [式 (36)–(40)]，从而支持**两级控制架构**：低速层更新动态参数，高速层计算指令向量 [page 6]。这一架构后来在 COSMOS 系统中实现，低层伺服 200 Hz、高层动力学 100 Hz [page 10]。

力控制的统一体现在式 (45)–(47)：操作指令向量由运动项 $F_m$、主动力控制项 $F_a$ 和补偿项 $F_{ccg}$ 组成，其中

$$F_a = \bar{\Omega}F_f^* + A_0(q)\bar{\Omega}F_v^* \tag{46}$$

$F_f^*$ 是力指令，$F_v^*$ 是沿力控制方向的速度阻尼项 [page 7]。图 3 给出控制系统架构 [page 7]。作者还提出一种从自由运动过渡到约束运动的策略：在碰撞瞬间采用纯耗散控制 $F_a = A_0(q)\bar{\Omega}F_v^*$ [式 (48)]，过渡时间通常为几十毫秒 [page 7]。

## 五、冗余机构：末端执行器方程与零空间稳定

冗余机械臂的位形无法仅由末端执行器参数确定，因此操作坐标不构成广义坐标系，整个冗余系统的动态行为不能用仅含末端执行器坐标的模型表示 [page 7]。但作者指出，**末端执行器本身的动态行为仍可描述**。通过把关节力取为 $\tau = J^T(q)F$ [式 (28)]，并利用关节运动方程和 $\ddot{x} = J(q)\ddot{q} + h(q, \dot{q})$ [式 (49)]，可导出末端执行器运动方程

$$\Lambda_r(q)\ddot{x} + p_r(q, \dot{q}) + p_r(q) = F \tag{50}$$

其中 $\Lambda_r(q) = [J(q)A^{-1}(q)J^T(q)]^{-1}$ 可解释为末端执行器在操作空间中的"伪动能矩阵" [page 7–8]。

一个关键引理（Lemma）指出：末端执行器受操作力 $F$ 作用，当且仅当机械臂受关节力

$$\tau = J^T(q)F + [I_n - J^T(q)\bar{J}^T(q)]\tau_0 \tag{55}$$

其中 $\bar{J}(q) = A^{-1}(q)J^T(q)\Lambda_r(q)$ 是与动力学一致的广义逆，$\tau_0$ 为任意关节力向量 [page 8]。第二项对应零操作力——它不产生末端执行器力，但可改变机械臂内部位形。这一分解是冗余控制的理论基础。

作者随后分析冗余机构的稳定性。在指令向量 (58) 下，耗散项为

$$D(q) = -k_v J^T(q)\Lambda_r(q)J(q) \tag{60}$$

Lyapunov 分析给出条件 $\dot{q}^T D(q)\dot{q} \leq 0$ [式 (61)]，该条件满足，因为 $D(q)$ 是秩为 $m$ 的负半定矩阵 [page 8]。但系统仍可能存在满足 $\dot{q}^T D(q)\dot{q} = 0$ [式 (62)] 的运动——图 4(a) 展示了一个仿真例子：三自由度平面机械臂的末端执行器目标位置与当前位置重合，但三个关节初始速度非零（0.5 rad/s），机构仍在运动 [page 8]。

为实现渐近稳定，作者在雅可比零空间中添加耗散关节力

$$\tau_{ns} = [I_n - J^T(q)\bar{J}^T(q)]\tau_s \tag{63}$$

取 $\tau_s = -k_{v_s}A(q)\dot{q}$ [式 (64)]，最终关节力指令为式 (67)，对应的 $D(q)$ 变为负定 [式 (68)]，系统渐近稳定 [page 8]。图 4(b) 展示了稳定化效果 [page 9]。作者强调，这一形式**避免了对雅可比矩阵广义逆的显式计算** [page 8]。

## 六、运动学奇异：把奇异邻域当作冗余问题处理

论文最后一部分提出对运动学奇异的新处理方式。奇异位形是雅可比矩阵列向量线性相关的位形，末端执行器在某个"奇异方向"上失去运动能力，表现为无限惯性质量或惯量；在正交子空间中运动仍然自由 [page 9]。作者用雅可比行列式中对应某类奇异的因子 $s(q)$ 来定义奇异邻域

$$\mathcal{D}_s = \{q \mid |s(q)| \leq s_0\} \tag{70}$$

其中 $s_0 > 0$ [page 9]。

核心思想是：**在奇异邻域内，把机械臂视为相对于末端执行器在正交子空间中运动的冗余机构**。对正交子空间中的运动，按冗余机构控制；沿奇异方向的运动，则通过零空间中选择的关节力来控制，具体做法是控制 $s(q)$ 的变化率，使其在 $|s(q)| = s_0$ 时达到期望速度对应的值 [page 9]。选择 $s(q)$ 变化率的符号可以决定机械臂从奇异位形退出时采取哪种姿态。图 5 展示了一个二自由度仿真机械臂进出奇异位形并呈现两种不同姿态的例子 [page 9–10]。

作者指出，该方法可通过极分解或奇异值分解扩展到冗余系统，也可处理多个奇异同时涉及的情形 [page 9]。

## 七、结论成立的条件与边界

这篇论文的论证有几个明确的适用条件和边界，需要与结论一起理解。

**第一，非冗余情形下操作坐标作为广义坐标系的合法性依赖于定义域限制。** 作者明确要求 $G$ 为一一对应且排除奇异位形 [page 3–4]。虽然后来通过把动态参数用关节坐标表达，把定义域扩展到 $G$ 非一一对应的区域，但奇异位形始终被排除在常规操作空间模型之外——这正是第八节单独处理奇异的理由。

**第二，动态解耦的"完美"性依赖于模型参数的准确估计。** 式 (29)–(30) 中的 $A(x)$、$p(x, \dot{x})$、$p(x)$ 均以估计值出现，作者在推导中为简化记号去掉了估计符号 [page 5]。实验部分提到，PUMA 560 动态参数的准确辨识"贡献了近乎完美的动态解耦" [page 10]，这暗示解耦质量对参数辨识精度敏感。

**第三，力控制性能受关节力矩控制能力的限制。** 作者在总结实验时明确写道，所观察到的性能"是在控制机械臂关节力矩方面存在限制的情况下获得的" [page 10]。这是一个作者承认的硬件层面局限。

**第四，冗余机构的渐近稳定需要额外注入零空间耗散。** 仅靠末端执行器层面的速度阻尼只能保证 $\dot{q}^T D(q)\dot{q} \leq 0$，存在非零关节速度而末端执行器静止的运动模式 [page 8]。式 (63)–(68) 的稳定化是必要的补充，而非可选优化。

**第五，奇异处理的有效性以奇异邻域定义 (70) 为前提。** 该定义依赖于能把雅可比行列式分解为对应各类奇异的因子乘积，作者称这可以直接从行列式表达式识别 [page 9]。对于行列式结构复杂或奇异类型难以分离的机构，这一前提是否普遍成立，论文未作讨论。

## 八、实验证据与论证力度

论文的实验证据集中在总结部分 [page 10]：在 COSMOS 系统上用 PUMA 560 和腕部、指部传感完成了接触、滑动、插入、柔顺等基本装配操作；碰撞过渡控制策略有效消除了与高刚度表面接触时的弹跳，碰撞法向速度最高达 4.0 in/s；方波力输入实验观察到上升时间小于 0.02 s、稳态力误差小于 12%。这些数据支持"操作空间表述能实现高动态性能的实时运动与主动力控制"这一结论。

需要指出的是，论文对实验的描述相当简略，详细内容引向参考文献 [19] 和 [17]。因此，从提取文本本身能确认的是：作者报告了这些性能指标，并归因于操作空间框架和参数辨识；但实验条件、可重复性、与其他方法的定量对比等，不在本文范围内。此外，4.0 in/s 这一数值在 OCR 文本中写作 "4.0 in/ s"，单位应为英寸每秒，但原文未给出换算或与其他单位的对照。

## 九、整体评价

这篇论文的论证力量在于一条清晰的逻辑链：任务在末端执行器层面指定 → 关节空间模型无法描述末端执行器的动态耦合 → 建立操作空间运动方程 → 通过 $\tau = J^T F$ 把操作力映射为关节力 → 在操作空间实现动态解耦与统一控制 → 把同一框架扩展到冗余和奇异。每一步都有公式推导支撑，关键关系（式 18、24、25、28、50、55）都有明确的来源或推导过程。

论文的局限也内在于这条链中：操作空间模型的定义域受限于非奇异位形；解耦质量依赖参数辨识；力控制精度受关节力矩控制能力约束；冗余稳定需要额外零空间项。作者对这些边界有明确交代，没有把结论推广到未验证的情形。从后续影响看，操作空间表述成为机器人控制的一个标准框架，但这属于论文之外的评价，不应混入对论文本身论证的分析。

值得注意的一个论证转折是第八节对奇异的处理：作者没有试图消除奇异或绕过它，而是把奇异邻域重新解释为冗余问题，用零空间控制沿奇异方向的运动。这一"问题转化"而非"问题消除"的思路，与全文把任务从关节空间搬到操作空间的整体策略一致——**换一个描述层面，原本棘手的问题可能变成已有工具能处理的形式**。
