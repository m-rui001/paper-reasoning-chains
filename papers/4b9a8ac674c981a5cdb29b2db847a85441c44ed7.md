# PTAA 如何改善钙钛矿电池的电压与填充因子

**原文题名**：Efficient inorganic–organic hybrid heterojunction solar cells containing perovskite compound and polymeric hole conductors（2013，DOI: 10.1038/nphoton.2013.80）

## 性能差距主要来自电压与填充因子

这篇论文的核心主张可以概括为一句话：在介孔TiO₂/CH₃NH₃PbI₃钙钛矿异质结中，用聚合物空穴导体（尤其是PTAA）替代小分子spiro-OMeTAD，能显著提升开路电压Voc和填充因子FF，从而把全固态电池的效率推到12.0% [page 1, page 5]。

这个主张包含两个层次。第一层是器件性能层面的：PTAA器件在标准AM 1.5条件下给出Jsc = 16.5 mA cm⁻²、Voc = 0.997 V、FF = 72.7%、PCE = 12.0%，而同等条件下spiro-OMeTAD器件为Jsc = 16.7 mA cm⁻²、Voc = 0.855 V、FF = 58.8%、PCE = 8.4% [page 4]。两者Jsc几乎相同，差距集中在Voc和FF上——这正是作者要解释的关键现象。

第二层是机理层面的：作者认为性能提升来自PTAA更高的空穴迁移率、更大的功函数，以及一种特殊的"柱状"（pillared）三维复合形貌，使TiO₂/CH₃NH₃PbI₃界面和CH₃NH₃PbI₃/HTM界面都能有效分离电荷 [page 2, page 3]。

## SEM 与元素分布揭示的柱状结构

论证的起点是器件长什么样。作者用截面SEM（Fig. 1a）和倾斜SEM（Fig. 1b）显示，CH₃NH₃PbI₃既渗入mp-TiO₂孔道，又在顶部形成微米级岛状覆盖层 [page 2]。但SEM只能看形貌，不能证明元素分布。于是作者用EDS mapping和XPS深度剖析（Supplementary Fig. S2、S3）追踪Pb、I、C等元素：Pb和I在mp-TiO₂底部仍有分布，说明钙钛矿渗入充分；而C信号主要集中在柱状结构表面附近，说明PTAA主要停留在TiO₂/CH₃NH₃PbI₃复合层表面和未被钙钛矿覆盖的区域 [page 2]。

这里有一个作者明确点出的对比：小分子spiro-OMeTAD比高分子量PTAA更容易渗入mp-TiO₂ [page 2]。换句话说，PTAA的"渗入不足"在传统介孔电池里是缺点，但在这个体系里反而形成了柱状结构——钙钛矿填充孔道、PTAA包裹柱体表面，两者各司其职。作者据此画出器件结构示意图（Fig. 1c）[page 2]。

需要指出的是，"柱状结构是性能关键"这一判断，作者是从形貌观察和元素分布推断出来的，并没有做形貌控制实验来直接验证。这是一个基于相关性的合理推断，而非因果证明。

## 光致发光显示电荷分离发生在哪里

如果钙钛矿既吸光又导空穴，那么电荷到底在哪个界面分离？作者用光致发光（PL）光谱做了对照实验（Supplementary Fig. S6）[page 3]。设计很巧妙：用Al₂O₃替代TiO₂。由于Al₂O₃导带与CH₃NH₃PbI₃能级不匹配，电子无法注入Al₂O₃，所以mp-Al₂O₃/CH₃NH₃PbI₃的PL几乎不淬灭。加上PTAA后，PL略有下降，说明CH₃NH₃PbI₃/PTAA界面能分离少量电荷。而mp-TiO₂/CH₃NH₃PbI₃的PL大幅淬灭，说明电荷主要在TiO₂/CH₃NH₃PbI₃界面分离。关键的一步是：再加PTAA后PL没有进一步淬灭，这与电荷主要在 TiO₂/CH₃NH₃PbI₃ 界面分离的解释相符，但不能据此断言全部电荷都在那里分离；PTAA 在该结构中的主要作用更可能是输运 [page 3]。

这条推理路径清楚，但依赖一个隐含假设：PL淬灭程度直接对应电荷分离效率。作者没有讨论PL淬灭是否可能来自其他非辐射复合通道。这是该证据的一个边界。

## 聚合物能级与输运性质如何关联器件性能

作者比较了四种聚合物HTM：P3HT、PCPDTBT、PCDTBT、PTAA（Fig. 2a, Table 1）[page 3, page 4]。在这轮聚合物筛选中，PTAA 的 PCE 为 9.0%，P3HT 次之，为 6.7% [page 3]。后文报告的 12.0% 来自优化后的最佳 PTAA 器件，并非同一轮筛选中的同一器件数据。作者给出两条解释：

第一，PTAA空穴迁移率约1×10⁻²到1×10⁻³ cm² V⁻¹ s⁻¹，比其他聚合物（约1×10⁻⁴ cm² V⁻¹ s⁻¹）高一个数量级 [page 3]。迁移率高→串联电阻小→FF高。这一点在Supplementary Table S1中得到支持：PTAA器件串联电阻5.4 Ω cm²，spiro-OMeTAD器件12.7 Ω cm² [page 5]。

第二，Voc随聚合物HOMO能级加深而增大：P3HT（−5.2 eV）→0.73 V，PCPDTBT（−5.3 eV）→0.77 V，PCDTBT（−5.45 eV）→0.92 V [page 3]。这个趋势是自洽的：HOMO越深，与钙钛矿价带顶的能级差越大，理论上可达到的Voc上限越高。

但PTAA的Voc（0.90 V，Table 1）并不完全遵循这个趋势——它的HOMO能级在Supplementary Table S1中给出，但正文没有直接列出数值。作者对PTAA高Voc的解释是"更大的功函数" [page 5]，而非HOMO能级。这里存在一个术语上的滑动：功函数和HOMO能级在有机半导体中相关但不完全等同。作者没有详细说明两者如何统一，这是论证中一个未完全桥接的环节。

## 介孔厚度带来的性能折中

作者测试了0 nm、600 nm、1000 nm三种mp-TiO₂厚度（Fig. 2b, Table 2）[page 3, page 4]。600 nm给出最高PCE 9.1%，0 nm仅0.4%，1000 nm为4.2%。作者的解释是一个双重权衡：

- 0 nm时，没有介孔层，钙钛矿覆盖层厚达500–1000 nm，激子扩散长度不足以到达bl-TiO₂界面，复合严重 [page 3]。
- 1000 nm时，TiO₂/CH₃NH₃PbI₃界面面积足够，但空穴需要穿越1000 nm + 80–100 nm才能到达HTM，路径过长，且扩展的界面增加了TiO₂中电子与钙钛矿中空穴的复合概率 [page 4]。
- 600 nm是两者之间的最优折中：界面面积足够，空穴路径适中（600 nm + 200–300 nm）[page 4]。

这个论证逻辑清晰，但有一个值得注意的细节：三种厚度的漫反射谱相似（Fig. 2c），说明光吸收差异不大；IPCE谱与Jsc趋势一致（Fig. 2d）[page 3]。这排除了"厚度影响光吸收"这一替代解释，把差异归因于电荷收集效率。这是一个有效的对照。

## PTAA 与 spiro-OMeTAD 的直接对照

这是全文最关键的对照（Fig. 3a, Supplementary Table S1）[page 4, page 5]。两者Jsc几乎相同（16.5 vs 16.7 mA cm⁻²），说明光吸收和电荷分离效率相近。差异在Voc（0.997 vs 0.855 V）和FF（72.7% vs 58.8%）。作者将FF差异归因于串联电阻（5.4 vs 12.7 Ω cm²），将Voc差异归因于PTAA更大的功函数 [page 5]。

这里有一个逻辑上的不对称：串联电阻影响FF但不影响Voc，这是二极管模型的常识，作者也明确说了 [page 5]。那么Voc的提升必须有独立解释。作者给出的是"更大的功函数"，但没有给出PTAA和spiro-OMeTAD功函数的具体数值对比，也没有讨论功函数如何定量转化为Voc差异。这是论证中一个可以补强但原文未充分展开的环节。

在可重复性方面，100个PTAA器件中约80%超过9%，约30%超过10%（Fig. 3c）；34个spiro-OMeTAD器件平均约7%，最高8.4%（Fig. 3d）[page 5]。这组数据支持PTAA器件的可重复性优势，但注意：spiro-OMeTAD的统计样本量（34）远小于PTAA（100），两者分布的直接比较需要谨慎。

## 结论的适用范围与未闭合处

这些结果针对 FTO/bl-TiO₂/mp-TiO₂/CH₃NH₃PbI₃/HTM/Au 这一器件构型和所测试的材料浓度、约 600 nm 介孔层厚度。PTAA 的高分子量（17,500 g mol⁻¹）与其较难进入介孔的形貌解释相符，但论文没有通过改变分子量或控制形貌来单独验证因果关系。SEM、EDS、XPS 和 PL 提供了结构及电荷分离位置的相互支撑；PL 淬灭是否完全由有效电荷分离造成，仍缺少对非辐射复合等替代过程的排除。

PTAA 器件的初始效率达到 12.0%，作者没有报告长期稳定性测试，因此不能由此推出长期运行表现。PTAA 与 spiro-OMeTAD 的器件对照显示，电流密度相近，而开路电压和填充因子更高；填充因子的变化与串联电阻差异相符，电压提升则被归因于 PTAA 较大的功函数，但文中没有给出两者功函数的直接数值或定量模型。重复器件的统计也支持 PTAA 表现较稳定（100 个器件中约 80% 超过 9%），不过 spiro-OMeTAD 的样本数只有 34 个，分布比较需保留这一差别。

因此，论文有力展示的是：在所测结构中，PTAA 与介孔钙钛矿形成的复合形貌伴随更高的初始器件效率。形貌带来的性能优势和功函数影响开路电压的机制都有证据支持，但因果环节尚未被独立控制实验完全闭合。
