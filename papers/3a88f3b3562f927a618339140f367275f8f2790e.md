# 用“局部—周边—全局”三级上下文换取轻量分割：CGNet 的论证分析

**原文题名**：CGNet: A Light-Weight Context Guided Network for Semantic Segmentation（IEEE TIP, 2021, DOI: 10.1109/TIP.2020.3042065）

## 论文要解决的是一个“两头不讨好”的困境

语义分割要在移动端落地，但现有方法分成两类，各自都有硬伤。作者在 Fig. 1 [page 1] 用一张“精度—参数量”散点图把问题摆出来：高精度方法（蓝色点）如 DFN（44.8 M）、DeepLabv3+（54.6 M）、DenseASPP（28.6 M）参数巨大，无法上移动设备；小内存方法（红色点）如 ICNet、ESPNet、ENet 参数少，但精度低。作者给出的诊断是：这些小模型“只遵循图像分类的设计原则，忽略了语义分割的固有特性” [page 1]。CGNet 的目标因此被设定为：在参数量与 ENet 相当（<0.5 M）的前提下，把精度显著拉高。

## 核心主张：分割的“固有特性”是上下文，而上下文应贯穿整个编码阶段

论文最关键的一步不是某个模块的工程细节，而是一个关于“语义分割与图像分类有何不同”的判断。作者主张：图像分类是图像级识别，而语义分割同时涉及像素级分类与目标定位，因此**空间依赖与上下文信息**对精度至关重要 [page 2]。由此推出两个设计决策：

其一，上下文不应只在编码器之后（语义层）使用，而应在**所有阶段**使用，同时覆盖浅层的空间上下文与深层的语义上下文。Fig. 2 [page 2] 用三种架构对照说明这一点：(a) FCN 型忽略上下文；(b) FCN-CM 型只在编码后加一个上下文模块；(c) CGNet 在所有阶段捕获上下文。这是全文的架构主张。

其二，主流分割网络有五个下采样阶段、特征图降到 1/32，会学到过于抽象的特征、丢失判别性空间信息，导致边界过度平滑；CGNet 只用三个下采样阶段、特征图降到 1/8，以保留空间信息 [page 2]。

## CG 块：把“看局部—看周边—看全局”拆成可实现的算子

CG 块是全文的论证枢纽，其设计动机用 Fig. 3(a)–(c) [page 4] 的视觉类比讲清楚：只看黄色小区域难以分类；加上红色周边区域后更容易；再加上紫色全局区域后置信度更高。对应到结构（Fig. 3(d) [page 4]），CG 块包含四个提取器，分两步：

**特征学习步**：局部特征提取器 $f_{loc}(\ast)$ 用 3×3 标准卷积，从 8 个邻域特征学习局部特征（对应黄色区域）；周边上下文提取器 $f_{sur}(\ast)$ 用 3×3 空洞/膨胀卷积，因空洞卷积感受野较大，可高效学习周边上下文（对应红色区域）；联合特征提取器 $f_{joi}(\ast)$ 把两者拼接，后接 BN 与 PReLU [page 4]。

**特征改进步**：全局上下文提取器 $f_{glo}(\ast)$ 用全局平均池化加多层感知机（两个全连接层）提取全局上下文，再通过一个 scale 层对联合特征做**通道级重加权**，强调有用通道、抑制无用通道 [page 4]。作者明确说这一步受 SENet 启发，且因为全局上下文由输入图像生成，所以具有注意力模型的自适应性；同时强调特征学习步在空间维度、特征改进步在通道维度，二者“正交” [page 4]。

这里有一个容易被忽略但很关键的论证：作者把 CG 块定位为 MobileNet 单元的**推广**——当 $f_{sur}(\ast)=0$ 且 $f_{glo}(\ast)=1$ 时，CG 块退化为 MobileNet 单元 [page 6]。这个“退化关系”是作者用来论证 CG 块并非凭空堆叠、而是有清晰设计谱系的桥接步骤（属于作者明说的内容）。

## 消融实验：每个组件都被单独“关掉”验证

论文用 Cityscapes 验证集做了一系列消融，这是支撑“上下文有用”这一主张的主要证据。需要提醒的是，这些消融大多在 M=3、N=15 或 N=21 的特定配置下进行，结论的强度应限定在该配置范围内。

- **周边上下文提取器**（Tab. II [page 6]）：不用 $f_{sur}$ 时精度最低；只在最后一个块用，提升 0.8%；在所有块用，比不用高 5.1%。作者据此说“在所有块中使用周边上下文有显著提升”。
- **全局上下文提取器**（Tab. III [page 6]）：把精度从 58.9% 提到 59.7%。
- **输入注入机制**（Tab. IV [page 6]）：把 1/4、1/8 下采样输入分别注入 stage 2、stage 3，精度从 59.4% 到 59.7%。作者的解释是“增加了网络中的信息流动”，这是**推断性解释**，实验本身只给出相关性。
- **激活函数**（Tab. V [page 6]）：PReLU 相比 ReLU 把 58.1% 提到 59.7%。
- **残差学习**（Tab. VIII [page 8]）：这是消融中差距最大的一项——LRL 57.2% vs GRL 63.5%。作者推测 GRL 更强地促进信息流动，用词是“one possible reason”，属于谨慎的可能解释。
- **通道间交互**（Tab. IX [page 8]）：这一项是**负面结果**，值得单独注意。作者尝试在 CG 块中加入 1×1 卷积（MobileNet 的做法）以促进通道间信息流动，结果精度从 63.5% 掉到 53.3%。作者的解释是局部特征与周边上下文需要保持**通道独立性**，因此移除 1×1 卷积反而大幅提升。这个反直觉结果恰恰是 CG 块区别于 MobileNet 单元的关键证据。
- **空洞率**（Tab. X [page 8]）：stage 2、3 分别取 2、4 时最佳，更大空洞率反而下降，作者推测周边上下文分支会丢失细节。
- **网络深度**（Tab. VII [page 7]）：固定 M 增大 N，精度持续上升；但固定 N 增大 M（3→6），mean IoU 反而降 0.2 点，故取 M=3。M=3、N=21 时验证集最高 63.5%。

## 与现有方法的对比：效率与精度的双重定位

Tab. VI [page 7] 给出 FLOPS、内存、运行时间与参数量的对比（FLOPS 与内存按 3×640×360 输入估计，运行时间按 2048×1024 计算）。作者的定位是：CGNet 的 FLOPS 与参数量非常接近当时最小的 ENet，但精度高 6.5%；比 ESPNet 高 4.5%。CGNet_M3N21 比 PSPNet 小 131 倍、比 DenseASPP 小 57 倍，而类别精度只低 5.4% 和 5.5%；内存 334.0 M，约为 DenseASPP（3997.5 M）的 1/10。作者也**主动承认** ICNet 参数更少、速度更快，原因是 ICNet 从计算流角度优化（多分辨率分支，避免原图过所有层），而 CGNet 是从模型设计角度做轻量 [page 9]。这是一个诚实的边界交代。

精度方面（Tab. XII [page 9]）：在 Cityscapes 测试集上，不做任何预处理、后处理、解码模块（如 ASPP、PPM），仅用 fine 标注训练，CGNet_M3N21 达到 64.8% mean IoU，且只用单尺度测试。作者强调它甚至定量优于一些在 ImageNet 上预训练、不考虑内存与速度的方法（如 SegNet），参数量约为其 1/60。CamVid 上（Tab. XI [page 8]），CGNet 参数量接近 ENet，精度高 14.3%，仅比 FCN(Res101, output stride 8) 低 1.9%，而参数量少 110 倍（0.5 M vs 56.8 M）。

## 结论成立的条件与边界

把上述证据串起来，CGNet 的核心推理链是：语义分割需要上下文 → 上下文应覆盖局部、周边、全局三个层次 → 应在所有阶段而非仅编码后使用 → 用空洞卷积、全局池化加通道重加权、深度可分离卷积等轻量算子实现 → 消融显示各组件确有贡献 → 最终在 <0.5 M 参数下取得 64.8% mean IoU。这条链的每一环都有实验或结构对照支撑，但成立范围需要限定：

第一，**精度主张绑定在特定配置与数据集上**。64.8% 是 Cityscapes 测试集、M=3/N=21、单尺度、无后处理的结果；消融中的具体数值（如 5.1%、0.8%）来自验证集特定配置，不宜外推为普适增益。

第二，**“上下文有用”的因果解释部分是作者推测**。输入注入、GRL 优势、空洞率过大导致性能下降等，作者均用“one possible reason”“intuitively”等措辞，属于可能解释而非确证机制。

第三，**通道独立性这一反直觉结论有明确适用前提**。移除 1×1 卷积带来大幅提升，作者归因于局部与周边特征需保持通道独立；这一结论是在 CG 块这一特定结构下得到的，不能直接推广到其他架构。

第四，**效率对比存在口径差异**。Tab. VI 中 FLOPS 与内存按 3×640×360 估计，运行时间按 2048×1024 计算，且多数对比方法使用多尺度测试而 CGNet 用单尺度 [page 7]，跨方法比较时需注意这一不对等。

第五，**论文未讨论的限制不应替作者补上**。例如训练稳定性、不同硬件上的实际延迟、对其他分割数据集（如 ADE20K）的泛化，论文均未涉及，因此不能作为对 CGNet 的批评或补充结论。

总体而言，CGNet 的论证力量不在于某个单点创新，而在于把“分割需要多尺度上下文”这一直觉，落实为可消融、可对照、可退化为已知单元的具体结构，并用一组消融（尤其是通道交互的负面结果）划出了它与 MobileNet 类轻量单元的边界。它的结论在“移动端、资源受限、Cityscapes/CamVid 类街景分割”这一范围内成立得最扎实。
