# 用“第五种成分”替代宇宙学常数：Caldwell、Dave 与 Steinhardt 的 quintessence 论证

**原文题名**：Cosmological Imprint of an Energy Component with General Equation-of-State
**作者**：R. R. Caldwell, Rahul Dave, Paul J. Steinhardt（University of Pennsylvania）
**年份**：1998（arXiv:astro-ph/9708069v2, 6 Feb 1998）

---

## 一、论文要解决的问题与核心主张

论文的出发点是一个观测上的张力：暴胀宇宙学预言宇宙空间平坦、总能量密度等于临界密度，而当时的观测证据却显示总物质密度显著低于临界密度 [page 1]。若两者都成立，就必须存在一种非物质的额外能量成分。通常的候选者是宇宙学常数 Λ（真空能），ΛCDM 模型也确实能较好拟合当时的观测数据。但作者强调，这种拟合主要依赖于“低物质密度 + 空间平坦”这两个特征，而**并不是对额外能量成分是否为真空能的敏感检验** [page 1]。

由此，作者提出用一类动力学、随时间演化、且空间不均匀的成分来替代 Λ。该成分的物态方程参数 w 定义为其压强与能量密度之比，作者称之为“quintessence”或 Q-component，并聚焦于 −1 < w < 0 的范围，因为这一范围最符合当时的宇宙学观测 [page 1]。

论文的核心主张可以概括为三点：

1. **一个“光滑”（空间均匀）的、随时间演化的成分在物理上是不自洽的**，因为它依赖于规范选择，并违反等效原理——忽略新成分对周围宇宙流体的响应是不合法的。因此，只有包含扰动的非均匀成分才是引入额外能量成分的有效方式 [page 1–2]。
2. **一旦把 Q 成分的扰动纳入计算，CMB 各向异性谱和物质功率谱会留下独特的印记**，从而打破此前文献中“光滑成分”与 ΛCDM 之间在大范围 w 上的近似简并 [page 2]。
3. **QCDM 模型能拟合当时的 CMB 与大尺度结构观测**，并在高红移超新星、引力透镜和大红移结构形成等方面相对 ΛCDM 具有优势 [page 3]。

## 二、从“光滑成分不合法”到“必须包含扰动”：论证的关键转折

论文最具方法论意义的一步，是先否定此前一类流行做法，再据此确立自己的计算框架。

此前一些研究（如文献 3、4、8）假设了一个“光滑”的、随时间演化但空间均匀的成分（有时称为 xCDM），它不响应暗物质和重子—光子—中微子流体中的不均匀性。在这种假设下，CMB 各向异性对很宽范围的 w 与 ΛCDM 近似简并 [page 2]。作者指出，这种简并是**人为的**：光滑性本身是规范依赖的，而且忽略新成分对周围密度扰动的响应违反等效原理。因此，光滑成分与 Q 成分并不是两个相互竞争的模型——前者根本不是一个良定义的物理情景 [page 2]。

这一否定性论证为后续计算设定了必要性：**只有把 Q 的扰动 δQ 纳入，得到的 CMB 和功率谱才是有效的**。作者随后用数值方法实现了这一点。

## 三、模型构建与扰动方程：证据如何被生成

作者考虑的是空间平坦的 FRW 时空，包含重子、中微子、辐射、冷暗物质和 Q 成分（即 QCDM 模型）。Q 成分被建模为一个标量场 Q，具有自相互作用势 V(Q) [page 2]。平均能量密度和压强分别为

ρ_Q = (1/2a²)Q′² + V，p_Q = (1/2a²)Q′² − V，

其中撇号表示对共形时间 η 的导数。当 Q 沿势能滚动时，动能与势能之比会变化，从而导致随时间变化的 w ≡ p_Q/ρ_Q [page 2]。

一个潜在的技术障碍是：对于 w < 0 的理想绝热流体，声速平方 c_s² = w < 0，短波扰动会在流体力学上不稳定。作者指出，标量场并非这种意义上的理想流体——其声速是波长的函数，长波扰动可取负值，而小于视界的短波扰动趋近 c_s² = 1，因此所考虑的短波模式保持稳定 [page 2]。这一澄清是模型物理合理性的前提。

扰动层面，标量场涨落 δQ 满足方程

δQ″ + 2(a′/a)δQ′ − ∇²δQ + a²V,QQ δQ = −(1/2)h′Q′，　(3)

其中 h 是空间度规扰动的迹 [page 2]。能量密度、压强和动量扰动由式 (4) 给出：

δρ_Q = (1/a²)Q′δQ′ + V,Q δQ，
δp_Q = (1/a²)Q′δQ′ − V,Q δQ，
(ρ_Q + p_Q)(v_Q)_i = −(1/a²)Q′(δQ),_i。　(4)

这些量必须被纳入 h、总密度反差 δ 和总速度扰动 v 的演化中 [page 3]。

这里有一个对理解全文至关重要的细节：作者在所有展示的例子中都取初始条件 δQ = δQ′ = 0（同步规范下）。在这种初始条件下，**如果不包含式 (3) 中 h′Q′ 这一源项所描述的 Q 对物质密度扰动的响应，δQ 对 CMB 各向异性的印记将可以忽略**。对于 ΛCDM，Q′ = 0，标量场保持无扰动 [page 2]。换言之，Q 成分的扰动并非来自初始涨落，而是由物质扰动通过引力源项**动态诱导**出来的。这正是“光滑成分”假设会遗漏的物理。

作者采用了两套数值方法：一套显式给定 w(η)，由式 (1) 计算 ρ_Q，并反推有效势；另一套直接指定 V(Q)，适用于粒子物理动机的具体模型 [page 2]。他们修改了标准的 Boltzmann 代码，覆盖同步规范与共形牛顿规范 [page 2]。

## 四、CMB 与物质功率谱的印记：证据与推理

**CMB 谱。** 图 1 展示了 COBE 归一化的 CMB 各向异性谱，采用绝热初始条件、倾斜 n = 1、H₀ = 100h km s⁻¹ Mpc⁻¹（h = 0.65）、Ω_b h² = 0.02 [page 3]。由于模型空间平坦，最后散射时声视界的角尺度几乎相同，因此声学振荡峰的位置与 SCDM 几乎一致。但低 ℓ 平台的形状和高 ℓ 声学峰的形状被三种效应扭曲：早期和晚期积分 Sachs-Wolfe 效应（源于存在 w ≠ 0 的流体成分），以及 δρ_Q 对 CMB 的直接贡献 [page 3]。

具体而言：
- 图 1(a)–(b) 显示固定 w 时谱随 Ω_Q 的变化。w = −1/6 时第一声学峰先升后降；w = −2/3 时声学峰随 Ω_Q 单调上升 [page 3]。
- 图 1(c) 直接对比了“光滑无扰动成分”与包含 Q 扰动的完整谱，在大角尺度上差异显著 [page 3]。这是对前述方法论主张的定量支持。
- 图 1(d) 固定 Ω_Q = 0.6、变化 w。当不包含 Q 扰动时，−1 < w < −1/2 的曲线几乎简并；而包含 Q 扰动后，简并被大角尺度上的贡献显著打破，且幅度远大于宇宙方差 [page 3]。这是论文最关键的定量论断之一。
- 图 1(e) 展示时间变化的 w(η)，来自指数势 V(Q) = m⁴ exp[−βQ] 和余弦势 V(Q) = m⁴(1 + cos[Q/f])。特别值得注意的是，两个“今天 w 相同但过去 w 不同”的模型（常数 w = −1/6 与从 −1 演化到 −1/6 的指数势模型）产生明显可区分的 CMB 功率谱 [page 3]。这意味着 CMB 测量不仅能定出今天的 w，还能定出 w 的演化历史。
- 图 1(f) 展示极化谱，其参数变化趋势与温度各向异性类似 [page 3]。

**物质功率谱。** 图 2(a) 显示功率谱对所有参数都敏感：w 的值、w 的时间依赖、有效势 V(Q) 与初始条件、以及 Ω_Q [page 3]。图 2(b) 显示 σ₈（8h⁻¹ Mpc 处的均方根质量涨落）随 Ω_Q 的变化。QCDM 相对 SCDM 对物质功率谱和 σ₈ 的压低，使其更好地拟合当时的观测 [page 3]。图中灰色带表示来自 X 射线星系团丰度的约束（针对 ΛCDM），作者注明该约束一般是弱模型依赖的 [page 3]。

## 五、结论成立的条件、边界与作者承认的局限

**关键假设。** 论文的结论建立在几个明确的假设之上：

1. **纯引力耦合**：作者隐含假设 Q 场与其他场的耦合可忽略，只通过引力与其余物质相互作用 [page 2]。若存在非引力耦合，扰动演化和谱印记都会改变。
2. **标量场可模拟性**：分析适用于任何其流体力学性质可被“在势中演化的标量场”模拟的成分。作者明确说，对于 w 和 c_s² 不能由标量场加某个势得到的其他物质—能量形式，处理不适用 [page 2]。
3. **初始条件**：所有展示的例子取 δQ = δQ′ = 0（同步规范）。作者称观测谱对广泛的初始条件不敏感，包括暴胀设定的 δQ、δQ′ 振幅，但这一“不敏感”本身是他们的数值发现，而非先验保证 [page 2]。
4. **空间平坦与特定背景参数**：图 1 的谱基于 n = 1、h = 0.65、Ω_b h² = 0.02 等具体取值 [page 3]。改变这些背景参数会改变定量细节。

**作者承认或明示的边界。** 论文是一封 Letter，作者明确说这里只展示“代表性谱”，虽然他们检查了许多模型，详细结果留待后续工作（文献 18，in preparation）[page 3]。X 射线星系团丰度约束被描述为“一般是弱模型依赖的” [page 3]，因此图 2(b) 中的灰色带不应被当作对 QCDM 的精确排除线。此外，作者指出 QCDM 与 ΛCDM 在拟合当前 CMB 和大尺度结构方面**都表现良好** [page 3]——QCDM 的优势是在高红移超新星、引力透镜和大红移结构形成等**额外**约束上体现的，而非在当前数据上决定性地胜出。

**一个需要谨慎对待的推理。** 作者称 QCDM 在 w ≈ −1/2 或更大时，对基于经典宇宙学检验（超新星、透镜）的 Λ 约束“显著放松” [page 3]，并称结构形成停止得更早、因此预言更多大尺度结构和类星体形成，与深红移图像更一致。这些是比较性的、依赖具体模型的论断，其强度受限于当时高红移数据的质量。论文没有给出这些优势的定量显著性检验。

**关于“简并被打破”的强度。** 图 1(d) 的论断——简并被 Q 扰动显著打破，且效应远大于宇宙方差——是论文最核心的可检验预言。但这一论断的定量强度依赖于所选的 Ω_Q = 0.6 和所考虑的 w 范围。作者没有在此 Letter 中给出未来实验能多好地分辨 Q 成分的定量 forecast，而是明确将其列为“正在进行中的后续研究” [page 3]。

## 六、总体论证结构的一个观察

这篇论文的论证有一个值得注意的结构：它先做一个**概念性否定**（光滑成分不合法），再由此推出**方法论要求**（必须包含扰动），然后用数值计算展示**包含扰动后的可观测后果**（简并打破、独特印记），最后将模型与当时观测对比并列出优势。概念否定与数值结果之间由扰动方程 (3)–(4) 桥接：正是 h′Q′ 源项使得 Q 对物质扰动有响应，从而产生图 1(c)–(d) 中“光滑 vs. 含扰动”的显著差异。

因此，论文的说服力并不主要来自“QCDM 比 ΛCDM 拟合得更好”（作者承认两者当前拟合相当），而来自一个更精细的主张：**此前文献中“光滑成分与 ΛCDM 简并”的结论是建立在一个不自洽的假设上的；一旦修正这个假设，简并消失，Q 成分留下可被未来实验探测的独特印记**。这一主张的成立，依赖于标量场扰动确实由引力源项诱导、且其 CMB 印记确实大于宇宙方差——这两点由图 1(c)–(d) 的数值结果支持，但其精确可探测性留待后续定量分析。
