# 用密度泛函几何与频率改造 CBS-Q：CBS-QB3 的论证逻辑

**原文题名**：A complete basis set model chemistry. VI. Use of density functional geometries and frequencies
**作者**：J. A. Montgomery, Jr., M. J. Frisch, J. W. Ochterski, G. A. Petersson
**期刊/年份**：J. Chem. Phys. 110, 2822 (1999)
**DOI**：10.1063/1.477924

## 一、论文要解决的问题

CBS-Q 是 Petersson 等人发展的复合模型化学方法之一，其设计思路是把低水平方法得到的几何构型和零点能（ZPE）与高水平单点能计算组合起来，得到接近化学精度（1–2 kcal/mol）的分子能量 [page 2]。CBS-Q 在 G2 测试集上的平均绝对误差（MAD）约为 1.0 kcal/mol，通常比 G2(MP2) 更快、比 G2 略准 [page 2]。

但作者指出，CBS-Q 沿用了 G2 系列的一个惯例：用 UHF/6-31G† 计算频率和零点能，用 MP2/6-31G† 优化几何 [page 3]。这一组合在两类情形下会出问题。其一，SCF 频率并非普遍准确，某些体系需要引入电子相关；而 MP2 虽然引入了相关，却在大 UHF 自旋污染情形下几何和频率都不可靠 [page 2]。其二，更关键的是，几何优化与零点能来自不同方法，当 UHF 与 MP2 的驻点性质定性不同（一个给出极小点、另一个给出鞍点）时，零点能所参照的反应路径位置可能与高水平单点能计算的位置不一致 [page 2]。对过渡态研究而言，这尤其麻烦，因为若想沿反应路径考察零点能变化（如变分过渡态理论 VTST），几何与频率必须自洽 [page 2]。

因此论文的核心主张是：把 CBS-Q 中的几何优化和频率计算统一替换为 B3LYP 密度泛函方法，并相应调整若干能量项，可以在几乎不损失计算速度的前提下，同时提高方法的准确性和可靠性，并使其适用于过渡态 [page 2, page 6]。

## 二、CBS-Q 的原始构造与经验参数

要理解改造的幅度，先看 CBS-Q 的能量构成。原始 CBS-Q 需要五步计算 [page 3]：

1. UHF/6-31G† 几何优化与频率；
2. MP2(FC)/6-31G† 几何优化；
3. UMP2/6-311+G(3d2f,2df,2p) 能量与 CBS 外推；
4. MP4(SDQ)/6-311G(d(f),p) 能量；
5. QCISD(T)/6-311G† 能量。

其中第 3–5 步都在第 2 步得到的 MP2 几何上进行 [page 3]。总能量为

E(CBS-Q) = E(UMP2) + ΔE(CBS) + ΔE(MP4) + ΔE(QCI) + ΔE(ZPE) + ΔE(emp) + ΔE(spin)，

其中 ΔE(CBS) 来自 CBS 外推，ΔE(MP4) 和 ΔE(QCI) 是相应方法的能量差，ΔE(ZPE) 由第 1 步频率乘以标度因子 0.91844 得到 [page 3]。

两个经验项值得注意。ΔE(emp) 是"重叠-干涉"（overlap-interference）双电子修正，形式为 −5.33 mE_h 乘以若干项之和，其中涉及最相似 α、β 轨道间的绝对重叠积分 |S_ii| 和干涉因子 [page 3]。作者解释，当键被拉伸时原子间绝对重叠平滑趋于零，这给出了"电子对数"修正的尺寸一致推广 [page 3]。ΔE(spin) = −9.20 mE_h Δ⟨S²⟩，按 UHF 的 ⟨S²⟩ 误差成比例修正 [page 3]。此外还有针对钠原子的核心相关能二次修正 E(core) = 3.92 Q_Na + 2.83 Q_Na² [page 3]。

这些经验系数由实验数据确定：双电子参数通过最小化 G2 测试集中 55 个解离能的 rms 误差得到，最优值 −5.33 mE_h 把 55 个分子的 rms 误差从 3.8 降到 1.0 kcal/mol；自旋修正的八个能量差取自 HCN、C₂H₄、C₂H₂ 的 C–H 解离能，CS 和 CO 的电离势，以及 CN、NO、PO 的电子亲和能，最优值 −9.20 mE_h Δ⟨S²⟩ 把八个测试案例的 rms 误差从 2.0 降到 1.0 kcal/mol [page 3–4]。两项经验修正合起来把 CBS-Q 对 G2 测试集 125 个化学能差的 rms 误差从 2.80 降到 1.3 kcal/mol，最大误差从 10.6 kcal/mol（肼的原子化能）降到 3.8 kcal/mol（O₂ 的电离势）[page 4]。

## 三、改造的第一步及其失败：PO 电子亲和能的警示

作者最初的改造很直接：用 B3LYP/6-31G† 几何优化和零点能替换 CBS-Q 的第 1、2 步，对全 G2 测试集计算，重新优化三个经验参数，再与实验比较 [page 4]。结果总体不错，但出现了一个严重异常：PO 的电子亲和能误差从 0.9 升到 9.5 kcal/mol [page 4]。由于 CBS-Q 在 G2 测试集中的最大误差仅为 3.8 kcal/mol，作者认为这是可靠性上不可接受的代价 [page 4]。

进一步检查发现，这 9.5 kcal/mol 的能量误差只源于 B3LYP/6-31G† 几何中 0.022 Å 的键长误差 [page 4]。作者由此提出一个明确的设计约束：几何误差必须小于 0.01 Å [page 4]。对 PO 的几何收敛性做了多水平计算（Table I），结果显示 UMP2/6-31G† 通过误差抵消给出了极好的 PO 几何，而"最低可接受的 DFT 水平"需要在第二行原子上有两个 d 函数、第一行原子上有一个 d 极化函数 [page 4–5]。作者进一步选择在氢上也加极化函数，因为这对氢转移反应的过渡态结构更好 [page 5]。

这里的关键推理是：高自旋污染物种（如 PO）对几何误差极其敏感，因此几何方法的选择不能只看一般分子的平均表现，必须考虑最坏情形。这一判断直接决定了后续采用 6-311G(2d,d,p) 基组。

## 四、为什么选 B3LYP/6-311G(2d,d,p)

作者用两组小测试集支持基组选择。Table II 比较了 HF、MP2、B3LYP、QCISD 在四个基组下对十个第一行双原子分子（H₂、HF、OH、NH、N₂、CH、CO、O₂、CF、F₂）平衡键长的 rms 误差 [page 4]。B3LYP/6-311G(d,p) 的 rms 误差为 0.005 Å，与 QCISD 相当；基组缩到 6-31G(d) 时误差翻倍，扩到 6-311+G(2df,2pd) 也不改善 [page 5]。Table III 给出同一测试集上标度谐振频率的 rms 误差，B3LYP 在 6-311G(d,p) 下为 49.9 cm⁻¹，在 6-311+G(2df,2pd) 下为 54.9 cm⁻¹，而 6-31G(d) 下为 87.5 cm⁻¹ [page 4]。作者据此判断 6-311G(2d,d,p) 是"达到 B3LYP-DFT 频率全部潜力的最小基组" [page 5]。

作者还提到 Bauschlicher 和 Partridge 曾指出 B3LYP/6-31G(d) 几何对原子化能计算已足够，但作者发现对完整 G2 测试集而言 6-311G(2d,d,p) 是必要的 [page 5]。这是一个明确的方法学分歧点，作者用 PO 案例和上述两表作为依据。

## 五、CBS-QB3 的最终构造

最终模型 CBS-QB3 在 CBS-Q 基础上做了四项改动 [page 5–6]：

1. 用 B3LYP/6-311G(2d,d,p) 几何和频率替换 UHF/6-31G† 频率与 MP2/6-31G† 几何；
2. 用 CCSD(T) 替换 QCISD(T)；
3. 加入原子自旋-轨道相互作用修正（数值取自 Curtiss 等人的 G3 论文）；
4. 重新优化三个经验参数。

第二项改动的依据来自 Bauschlicher 和 Partridge 以及 Mayer 等人对自旋污染自由基的观察 [page 6]。第三项改动的理由是：计算分子生成热时使用原子的实验生成热，因此原子能量应与实验一致，而自旋-轨道修正使二者自洽；作者发现这一修正对 CBS-Q 比对 G2 更重要 [page 6]。

重新优化后的经验参数为：零点能标度因子 0.99，重叠-干涉项系数 −5.79 mE_h，自旋修正参数 −9.54 mE_h [page 6]。

## 六、性能证据

改造后的结果：PO 电子亲和能误差回到 0.9 kcal/mol；G2 测试集最大误差从 CBS-Q 的 3.8 kcal/mol 降到 2.8 kcal/mol（氯分子的电子亲和能）；平均误差、平均绝对误差、rms 误差分别为 0.20、0.87、1.08 kcal/mol，对应 CBS-Q 的 0.15、0.98、1.23 kcal/mol [page 6]。

Table VIII 按能量类型汇总了 CBS-Q、CBS-QB3 和 G3 的误差 [page 6]。分项看：解离能（D0）的 MAD 从 0.80 降到 0.58，最大误差从 2.3 降到 1.9；电离势（IP）的 MAD 从 1.03 微降到 1.00，最大误差从 3.9 降到 2.3；电子亲和能（EA）的 MAD 从 1.24 微升到 1.26，最大误差从 3.2 降到 2.8；质子亲和能（PA）的 MAD 从 1.23 降到 1.01，最大误差从 2.2 降到 1.6 [page 6]。总计 MAD 从 0.98 降到 0.87，最大误差从 3.9 降到 2.8 [page 6]。

作者的结论措辞是谨慎的：CBS-QB3 相对 CBS-Q 是"小的准确性改进"（small improvement in accuracy），但"显著提高了可靠性"（significantly increases its reliability）[page 6]。这一区分很重要——平均误差的改善幅度不大，真正的卖点是最坏情形误差的降低和几何/频率步骤的自洽性。

## 七、关键边界与作者承认的局限

论文明确记录了一个 B3LYP 完全失效的案例：反应 H₂ + F → H + HF 是高度放热反应，过渡态出现很早，势垒仅 1.7 kcal/mol [page 5]。作者发现，本文考虑的所有基组下，B3LYP-DFT 势能面从反应物到产物都没有势垒，因此无法给出过渡态几何或反应路径信息 [page 5]。作者认为这是 B3LYP-DFT 普遍低估化学反应过渡态能量的一个极端例子，并建议在使用 B3LYP 几何和频率处理过渡态时一般应配合 IRCMax 方法 [page 5–6]。

这一负面结果直接限定了 CBS-QB3 的适用范围：它对稳定分子的热化学表现良好，对过渡态提供了几何与频率的自洽性，但当 B3LYP 本身无法描述势垒时，方法失效。作者并未声称 CBS-QB3 能解决所有过渡态问题，而是把它定位为"适合与 IRCMax 过渡态方法结合使用" [page 2, page 6]。

另一个隐含边界是经验参数的性质。ΔE(emp) 和 ΔE(spin) 的系数由 G2 测试集的实验数据拟合而来 [page 3–4]，CBS-QB3 的系数又针对新几何重新优化 [page 6]。这意味着方法的精度在训练集覆盖的化学空间内得到验证，对训练集之外的体系（如更重的元素、强多参考特征体系）的表现不在本文证据范围内。论文没有讨论这一外推问题，因此不应把它当作作者的结论。

## 八、论证结构小结

整篇论文的推理链条可以概括为：CBS-Q 的几何与零点能方法不统一，导致自旋污染体系和过渡态研究中的可靠性问题（动机）→ 用 B3LYP 替换几何与频率，但初始的 6-31G† 基组在 PO 上产生 9.5 kcal/mol 误差（反例）→ 由此确定几何误差须小于 0.01 Å，并通过 Table I–III 选定 6-311G(2d,d,p)（基组选择）→ 同时用 CCSD(T) 替换 QCISD(T)、加入自旋-轨道修正、重新优化经验参数（配套改动）→ 在 G2 测试集上验证，MAD 从 0.98 降到 0.87，最大误差从 3.9 降到 2.8（验证）→ 承认 B3LYP 对 H₂ + F 势垒完全失效，建议配合 IRCMax（边界）。

其中最关键的一步是 PO 案例：它把一个看似合理的直接替换方案否决掉，迫使作者提高基组要求，并由此确立了"几何误差 < 0.01 Å"这一设计准则。没有这一步，CBS-QB3 可能就停留在 B3LYP/6-31G† 水平，而那个版本在自旋污染物种上的可靠性是不可接受的。
