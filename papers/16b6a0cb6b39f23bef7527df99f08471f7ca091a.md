# 用更小的基组算准阴离子：3-21+G 的论证逻辑

**原文题名**：Efficient Diffuse Function-Augmented Basis Sets for Anion Calculations. III. The 3-21+G Basis Set for First-Row Elements, Li–F（1983，DOI: 10.1002/jcc.540040303）

## 问题与主张

这篇论文要解决的是一个很实际的计算化学难题：从头算（ab initio）方法处理阴离子一直不可靠。作者在引言里点明，标准分裂价基组（split-valence basis sets）虽然能凑合给出阴离子的几何构型，但能量比较即使加上极化基组和电子相关校正也仍然不可信 [page 1]。已知的补救办法是给基组添加一组弥散函数（diffuse functions），但此前没有人系统评估过"小基组 + 弥散函数"的组合。

作者的核心主张有两层。第一层是具体的：他们新构造的 3-21+G 基组能够充分描述阴离子几何构型和质子亲和能（proton affinities），效果与更大的 4-31+G 相当，但计算更省时。第二层是推广性的：他们推荐一套统一的弥散 sp 轨道指数（Table I 中的 B 组），用于增广所有基组 [page 7]。

## 基组是怎么造出来的

理解这篇论文的关键，是先看清 3-21+G 的构造逻辑，因为后面所有证据都依赖这个构造。

作者的做法是：以 H⁻、Li⁻、BeH⁻、BH₄⁻、CH₃⁻、NH₂⁻、OH⁻、F⁻ 这些单重态基态阴离子为对象，优化弥散指数。几何构型固定不动（4-31+G 用 4-31G 优化几何，3-21+G 用 3-21G 优化几何），只优化指数 [page 1]。具体操作是往 6-31G 和 6-21G 基组上各加一个弥散 sp 壳层，对阴离子总能量优化，得到两套指数：第一套（A 组）加到 4-31G 上成为 4-31+G；第二套（B 组）用于 3-21+G、6-21+G 和 6-31+G* [page 2]。此外还有 3-21++G 等变体，是在氢上再加一个弥散 s 函数。

Table I 把得到的指数与 Dunning 和 Hay 的已有值做了对比 [page 2]。这里有一个值得注意的细节：作者最终推荐的是 B 组（6-21G 衍生值），而不是 4-31+G 用的 A 组。这个选择本身就是论文的一个结论性判断，而非单纯的技术细节。

## 证据链：从能量降低到质子亲和能

论文的论证不是靠单一证据，而是几条线索汇聚到同一个结论。

**能量降低作为诊断工具。** Table V 列出加入弥散函数后 XH 和 X⁻（X = Li–F）的总能量降低值 [page 3]。逻辑是：如果原基组已接近 Hartree-Fock 极限，加函数不会显著降能；降得越多，说明原基组越不充分。结果显示，中性分子中 Li–C 降能不大，但 NH₃、H₂O、HF 降能明显更大，因为后者有孤对电子。阴离子的降能普遍大于中性分子，最小的是 CH₂Li⁻，最大的是 CH₂F⁻。作者由此推断，标准基组对 N、O、F 的孤对电子描述不充分 [page 3, page 6]。

这里有一个关键的对照：3-21G→3-21+G 对 N、O、F 的降能是 4-31G→4-31+G 的 2–3 倍，说明较大的 4-31G 对电负性元素描述得明显更好。但反过来，4-31G→4-31+G 对 Li、Be、B 的降能异常大，作者认为这可能是 4-31G（Li、Be 用 5-21G）在原始优化中"塌陷"（falling in）的表现 [page 3]。这个观察很重要：它暗示 4-31+G 的优势并非全面，而 3-21+G 在某些元素上反而更均衡。

**几何构型。** Table IV 比较了 OH⁻、NH₂⁻、FHF⁻、BH₄⁻、CN⁻、NO₂⁻、NO₃⁻、CH₃COO⁻、N₃⁻、HCOO⁻、NCN²⁻、CO₃²⁻ 等的优化几何 [page 4]。作者确认了 Radom 的结论：4-31G 已能合理再现阴离子几何。加入弥散函数后几何变化通常不大，少数显著变化（如 CH₂X⁻ 系列）源于对孤对轨道描述的改善。一个实用的推论是：对许多应用，可以用 3-21G 几何做 3-21+G 单点计算 [page 3, page 7]。

**质子亲和能——最核心的证据。** Table VII 是全文最有分量的数据 [page 5]。它比较了 4-31G、4-31+G、3-21G、3-21+G 四种基组算出的质子亲和能，覆盖了从 NO₂⁻（324.6 kcal/mol）到 LiO⁻（448 ± 15 kcal/mol）的整个已知范围。

结果很清晰：4-31G 与实验的平均偏差是 30.5 kcal/mol，3-21G 更差，达 42 kcal/mol。而且除 Li⁻ 外，所有 4-31G 和 3-21G 的质子亲和能都偏高，说明误差是系统性的。加入弥散函数后，4-31+G 的平均偏差降到 5.6 kcal/mol，3-21+G 更是只有 3.1 kcal/mol。3-21+G 最小二乘拟合的斜率是 1.25，相关系数 0.96 [page 6]。

这里有一个推理上的关键点需要点明：作者明确指出这些计算值未做零点能校正，而零点能校正平均会再降低 6–8 kcal/mol（Table VII 脚注 b）[page 5]。也就是说，3-21+G 的 3.1 kcal/mol 平均偏差是在"未校正"状态下取得的，加上校正后与实验的吻合会进一步改善。作者在结论中说"包含零点能校正后，质子亲和能可再现到约 5 kcal/mol 以内" [page 7]，这个表述与 Table VII 的数字需要对照理解——3.1 是未校正偏差，5 是校正后的预期精度，两者不矛盾但语境不同。

## 反转能垒：一个诚实的负面结果

Table VI 报告了 CH₃⁻ 和 NH₃ 的反转能垒 [page 5]。加入弥散函数后，两者的能垒都急剧下降。但作者没有把这当作好消息：NH₃ 的实验能垒本就被分裂价基组严重低估，加弥散函数后低估得更厉害。要得到可靠的 NH₃ 反转能垒，必须加极化函数——6-31+G*//6-31+G* 给出 5.5 kcal/mol，加上 MP2 相关校正后是 5.0 kcal/mol [page 3]。

对 CH₃⁻，虽然没有实验值，但高等级理论给出 1–2 kcal/mol。以 MP2/6-31+G*//6-31+G* 的 2.4 kcal/mol 为参照，不含弥散函数的基组给出的能垒偏大 [page 3]。作者由此指出，弥散函数对反转能垒和旋转能垒（如乙烯基阴离子、烯丙基阴离子）的改善是真实但有限的，不能替代极化函数和相关校正。

这一段的价值在于：它划定了 3-21+G 的适用边界。3-21+G 擅长的是能量差（质子亲和能），不擅长的是需要极化函数才能描述好的能垒问题。

## 氟亲和能与氢弥散函数

Table VIII 转向氟亲和能 [page 6]。这里实验数据本身就不确定：HF 的 F⁻ 亲和能实验估计从 30 到 60 kcal/mol 不等，作者取"所有报道值的平均"50.7 kcal/mol，恰好与 3-21+G 的 50.8 kcal/mol 吻合——但作者自己用"fortuitously"（偶然地）来形容这个吻合，态度是谨慎的。H₂O、HCN、CO₂ 的值吻合尚可，但 H₃N、F₂CO、LiF 的实验值远低于计算值。作者指出 F₂CO 的实验上限基于已被修正的 D(O₂S–F⁻) 值（从 40 改为 59 kcal/mol），LiF 的实验值也有大不确定性 [page 6]。因此作者只说 3-21+G"可能适合"计算氟亲和能，没有下强结论。

关于氢上的弥散函数，Table V 显示 3-21+G→3-21++G 的降能只对 H⁻ 重要（53.4 kcal/mol），对其他体系影响很小 [page 3]。作者据此建议：除非涉及氢化物离子，否则不必在氢上加弥散函数，因为那会显著增加计算时间而收效甚微 [page 7]。

## 计算成本

Table 中给出的 CH₃⁻ 优化耗时数据（Erlangen CYBER 173）：4-31G 601 秒，3-21G 348 秒，4-31+G 861 秒，3-21+G 545 秒 [page 2]。弥散增广基组平均比对应的分裂价基组多约 60% 时间。3-21+G 比 4-31+G 快 37%，但这个幅度随体系在 10%–50% 间变化。作者还提到，使用弥散增广基组时 SCF 收敛慢，通常需要阻尼（damping）[page 2]。

## 结论成立的条件与边界

把整条论证链串起来看，3-21+G 的结论建立在几个条件之上。

第一，它针对的是阴离子的**能量差**（质子亲和能），而非绝对能量或能垒。几何构型方面，作者明确说 3-21G 几何可用于 3-21+G 单点计算，但承认 CH₂Li⁻ 等例外 [page 3, page 7]。

第二，弥散函数解决的是"系统性高估质子亲和能"这个问题，它不能替代极化函数和相关校正。反转能垒的例子清楚说明了这一点 [page 3]。

第三，氢弥散函数只在涉及 H⁻ 时才必要 [page 7]。

第四，氟亲和能的适用性受限于实验数据本身的不确定性，作者的推荐语气明显弱于质子亲和能部分 [page 6]。

第五，作者推荐用统一的 B 组指数增广所有基组，这是一个标准化建议，其依据是 B 组在 3-21+G 上的表现，但论文并未系统比较 A、B 两组在所有基组上的表现差异——这个推广有一定外推成分。

最后需要指出，论文中 Table VII 的数值排版在提取文本中较为混乱，部分数值的列对应关系存在 OCR 疑点（如某些行的基组归属），但作者在正文中给出的平均偏差（30.5、42、5.6、3.1 kcal/mol）和相关系数（0.96）是明确的文字陈述，这些结论性数字的可信度高于表格中单个数值的逐项核对。
