# 用多个欠采样子集“探索”被丢弃的多数类：EasyEnsemble 与 BalanceCascade 的论证分析

**原文题名**：Exploratory Undersampling for Class-Imbalance Learning（2008，DOI: 10.1109/TSMCB.2008.2007853；期刊卷期标注为 IEEE TSMC-B, VOL. 39, NO. 2, APRIL 2009）

## 论文要解决的问题与核心主张

论文处理的是二分类中的类别不平衡问题：多数类样本远多于少数类，以至于以错误率为目标的普通学习器会倾向于把样本都判为多数类，从而在少数类上完全失效 [page 1]。作者把欠采样（undersampling）作为出发点：它只取多数类的一个子集，使训练集变平衡、训练变快，但代价是丢弃了大量多数类样本中可能包含的信息 [page 1]。论文的核心主张是：可以通过“多次采样 + 集成”的方式，在保持欠采样训练速度的同时，把被丢弃的多数类信息重新利用起来。为此提出两个算法——EasyEnsemble 和 BalanceCascade [page 1, page 2]。

需要先厘清一个术语：论文中的“探索”（exploratory）不是指主动学习式的查询，而是指用多个多数类子集去覆盖原本被单次欠采样忽略的多数类样本。EasyEnsemble 用独立随机采样实现这种覆盖，BalanceCascade 则用已训练分类器指导后续采样 [page 2, page 3]。

## 两个算法各自“利用被丢弃数据”的机制

**EasyEnsemble** 的做法最直接：从多数类 N 中独立地随机抽取 T 个子集 $N_1,\dots,N_T$，每个子集大小等于少数类 $|P|$；对每个子集用全部 P 训练一个 AdaBoost 集成 $H_i$（含 $s_i$ 个弱分类器 $h_{i,j}$ 及权重 $\alpha_{i,j}$、阈值 $\theta_i$）；最后把所有弱分类器汇总成一个总集成，输出为 $\mathrm{sgn}\left(\sum_{i=1}^{T}\sum_{j=1}^{s_i}\alpha_{i,j}h_{i,j}(x)-\sum_{i=1}^{T}\theta_i\right)$ [page 2, Algorithm 1]。作者给出的一个关键解释是：可以把每个弱分类器 $h_{i,j}$ 看作由集成学习“抽取”出的二值特征，$H_i$ 就是建立在这些特征上的线性分类器；不同子集 $N_i$ 抽出的特征反映多数类不同侧面的信息，因此最终不是对 $\{H_i\}$ 投票，而是把所有 $h_{i,j}$ 汇成一个集成 [page 3]。这一步是理解 EasyEnsemble 为何“比单次欠采样信息更多”的核心推理。

**BalanceCascade** 则是有监督地探索：先训练 $H_1$，把被 $H_1$ 正确判为多数类的样本从 N 中删除，再在缩小的 N 上采样训练 $H_2$，如此级联 [page 3, Algorithm 2]。它引入一个目标假正率 $f=\sqrt[T-1]{|P|/|N|}$，并在每轮调整阈值 $\theta_i$ 使 $H_i$ 的假正率达到 $f$ [page 3, Algorithm 2 第 2、7 行]。这样经过 $T-1$ 次收缩后，N 的规模变为 $|N|\cdot f^{T-1}=|P|$，第 T 轮之后 N 已小于 $|P|$，训练即可停止 [page 3]。作者强调，这与 Viola–Jones 的级联分类器不同：后者的级联主要用于加速测试，而 BalanceCascade 的序贯依赖主要用于削减多数类中的冗余信息，为后续欠采样留出更有针对性的样本空间 [page 3]。

## 从证据到结论：实验如何支撑主张

实验在 16 个 UCI 数据集上进行，采用十折分层交叉验证，每折内重复 10 次以应对采样随机性，整个交叉验证重复 5 次取平均 [page 4]。评价指标为 AUC、F-measure 和 G-mean，作者明确说明错误率在不平衡/不等代价场景下不合适，而 AUC 被证明对不平衡和代价敏感问题可靠 [page 4]。对比方法共 15 种，包括 CART、Bagging、AdaBoost、AsymBoost、SMOTEBoost、欠采样+AdaBoost（Under）、过采样+AdaBoost（Over）、SMOTE+AdaBoost、Chan 与 Stolfo 方法、Random Forests 系列，以及本文的 Cascade 和 Easy [page 5]。

一个对结论范围有决定性影响的处理是：作者按 AdaBoost 的 AUC 是否高于 0.95，把 16 个数据集分成 6 个“easy”任务和 10 个“hard”任务 [page 6]。这个划分本身就是一条重要论证：在 easy 任务上，类别不平衡并不真正有害，多数类不平衡学习方法（除 Asym 外）的 AUC 和 F-measure 反而低于 Ada [page 9]；在 hard 任务上，不平衡学习方法普遍优于 Ada [page 9]。因此论文的核心性能主张实际上限定在 hard 任务上。

在 hard 任务上，作者报告的关键证据是：Under 表现不佳，其 AUC 和 F-measure 低于 Ada、Asym 以及许多其他不平衡方法，作者推测原因正是被忽略的多数类信息 [page 9]；而 Easy 和 Cascade 都能在 easy 和 hard 任务上改进 Under，这被作者用来支持“两个算法确实有效探索了多数类样本”的论点 [page 9]。Chan 使用全部多数类样本，其 AUC 和 F-measure 一般高于 Under，但在 hard 任务上其 AUC、F-measure、G-mean 与 Cascade 相当或略低，且多数数据集上低于 Easy [page 9]。由此作者得出一个反直觉的结论：并不需要使用全部多数类样本 [page 9, page 10]。Easy 和 Cascade 在 hard 任务上取得几乎最高的平均 AUC、F-measure 和 G-mean，同时训练时间与 Under 相近、快于其他方法 [page 10]。

训练时间方面，作者先做理论分析：所有 CART 系方法用相同弱学习器和相同数量弱分类器，训练时间主要取决于训练样本数；Under 用 $2|P|$ 个样本最快，而 Cascade、Easy、Chan 每个弱分类器也用 $2|P|$ 个样本，额外采样/切分时间可忽略，因此与 Under 近似同速 [page 5, page 6]。表 III 的运行时间记录（3.0-GHz Intel Xeon）显示 Chan、Easy、Cascade 与 Under 一样高效，最昂贵的是 SMB 和 Over [page 6]。作者还指出，当不平衡度极高（如 1000）时，Chan 需要远多于本文方法的训练时间，而 Easy 的每个欠采样过程可并行 [page 6]。

## 关键推理步骤与作者承认的边界

从证据到“Easy 优于 Cascade”这一结论，关键推理在于 BalanceCascade 的采样方式可能过拟合：被早期轮次正确分类而删除的多数类样本，可能在后来的轮次中仍有用，因为其他样本被删除后它们可能变得有用 [page 10]。作者据此解释 hard 任务上 Cascade 逊于 Easy [page 10]。但作者同时给出 Cascade 更可取的情形：在 easy 任务上 Cascade 的 AUC、F-measure、G-mean 几乎都高于 Easy，说明它能聚焦更有用的数据；在少数类极小的 balance 和 wpbc 数据集上 Cascade 更优，因为此时单靠欠采样难以取得有代表性的子集 [page 10]。此外，对极高不平衡问题（如人脸检测中 5000 正例对 22.84 亿负例），Easy 需要极大的 T 才能覆盖 N 的信息且 T 难以确定，而 Cascade 只需把假正率设在 0.5 左右，$T=20$ 即可（$\log_2(2.284\times10^9/5000)\approx19$）[page 10]。因此“Easy 优于 Cascade”并非无条件结论，而是限定在实验所用数据集（不平衡度均低于 40）的 hard 任务上。

关于集成策略，作者用表 XIII 比较 stacking 与本文的集成方式：在 hard 任务上 Cascade 的当前策略在所有数据集上优于 stacking，Easy 仅在一个数据集上 stacking 更好；在 easy 任务上差异较小 [page 10]。作者据此推断 stacking 在少数类样本被每个弱分类器重复使用时容易过拟合，并认为这可能是 Chan 逊于 Easy 的主要原因 [page 10]。这是一个由对比实验支撑的推断，而非直接证明。

作者明确承认的局限包括：当前方法直接使用弱学习器返回的 $\alpha_{i,j}$，未来可通过学习 $\alpha_{i,j}$ 改进 [page 11]；作为集成方法，它们继承了集成方法的弱点，最明显的是缺乏可理解性，即使基分类器是可理解的符号学习器，集成仍是黑箱 [page 11]。作者还提出一个方法论层面的观察：类别不平衡学习方法应只用于确实受不平衡困扰的任务，因此需要先判断任务是否受不平衡影响，这留作未来工作 [page 10, page 11]。

## 结论成立的条件

综合来看，论文的性能结论成立需要几个条件同时满足：任务确实受类别不平衡困扰（即属于 hard 任务，AdaBoost 的 AUC 低于 0.95）；不平衡度在实验范围内（表 II 中均低于 40）；评价采用 AUC、F-measure、G-mean 而非错误率；比较对象是 CART 系方法且弱分类器数量相同。在这些条件下，Easy 和 Cascade 在 hard 任务上优于几乎所有对比方法，且训练时间与 Under 相当。超出这些条件——例如 easy 任务、极高不平衡度、或需要模型可解释性——论文的结论要么不适用，要么作者自己给出了不同的取舍建议。
