# Tricine–SDS-PAGE：小分子蛋白与疏水蛋白的分离方案
*Tricine–SDS-PAGE · Hermann Schägger · 2006 · https://doi.org/10.1038/nprot.2006.4*

这是一篇实验方案论文，核心价值在于说明何时选用 Tricine–SDS-PAGE，并给出凝胶制备、染色和转印的可执行流程。它特别适合小于约 30 kDa 的蛋白和肽段，也能帮助转印一些在高丙烯酰胺凝胶中难以转出的疏水蛋白。它并不取代 Laemmli 系统：两种体系各有分工，合起来覆盖更宽的分子量范围。

选择凝胶时，均匀 Tricine 胶在分离范围和分辨率之间取舍。文中示例显示，10% T、3% C 凝胶覆盖约 1–100 kDa，16% T、3% C 覆盖约 1–70 kDa；若重点是更小的蛋白，可提高交联剂比例至 16% T、6% C，并在凝胶中加入 6 M 尿素以进一步改善分辨。需要同时分开较宽分子量范围时，作者建议考虑梯度胶，而不是期待单一均匀胶兼顾所有目标。上述范围是文中的实验示例，不是对所有样品和设备都成立的绝对界限。

方案也把下游检测纳入选择。作者给出不使用甲醇的考马斯染色流程，并提供与质谱分析兼容的改良银染方法；约 0.2 μg 的条带通常适合考马斯染色，银染可显示约低百倍的蛋白量。极疏水蛋白可能染色偏弱，因此染色强度不总能直接代表亚基比例。对难转印的疏水蛋白，较低丙烯酰胺浓度有助于从凝胶转出；文中半干转印方案采用高离子强度缓冲液、低电压和较长时间，覆盖指定厚度与浓度的 Laemmli 或 Tricine 凝胶。实际转印仍需按蛋白性质、膜和设备条件优化。

Tricine–SDS-PAGE 还有两类组合用途：在双重 SDS-PAGE（dSDS-PAGE）中利用不同凝胶条件下疏水蛋白的异常迁移实现正交分离，以便质谱鉴定；在 BN-PAGE 或 CN-PAGE 后作为第二维，将天然复合物拆分为亚基。这些是特定工作流中的用途，详细的二维连接步骤并非本文单独完整展开。

操作上，作者提供凝胶配方、缓冲液、样品处理、跑胶、染色和电印迹步骤，并给出大致 1–2 天的完成时间。选型时应先明确目标分子量范围、是否需要转印或质谱，以及样品是否含极疏水蛋白，再决定凝胶浓度与后续检测流程。方案使用丙烯酰胺和双丙烯酰胺；原文特别提示其神经毒性，配制时需采取相应防护。

**书目信息：** Hermann Schägger，*Nature Protocols*，2006，1(1)，16–22。文中凝胶质量范围、灵敏度和转印适用性来自作者所列条件与示例，应结合目标样品验证。
