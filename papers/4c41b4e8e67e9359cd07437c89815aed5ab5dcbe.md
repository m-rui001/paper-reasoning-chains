# ROMS 的数值内核：分裂显式、自由表面与地形跟随坐标下的时间步进设计

**原文题名**：The regional oceanic modeling system (ROMS): a split-explicit, free-surface, topography-following-coordinate oceanic model
**年份**：2004（Ocean Modelling 9 (2005) 347–404）
**DOI**：https://doi.org/10.1016/j.ocemod.2004.08.002

## 一、这篇论文要解决的核心问题

ROMS 是一类区域海洋模式，采用 Boussinesq、静力近似、自由表面和地形跟随（σ 或 S）垂直坐标。它的时间积分把三维场分解为正压（深度平均）和斜压（余项）两部分，正压部分用远小于斜压步长的时间步推进，这就是所谓“分裂显式”（split-explicit）方法 [page 2]。这种做法的动机很直接：外重力波相速远大于内重力波，若用同一个满足外波 CFL 的小步长推进全部方程，代价过高；若用满足内波 CFL 的大步长，则必须对正压部分单独处理 [page 2]。

作者的主张是：分裂显式模式中真正限制时间步长的，往往不是单条方程的 CFL 条件，而是整个耦合系统（正压—斜压相互作用）的稳定性 [page 3]。因此他们不是孤立地优化某一条方程的时间格式，而是重新设计整个计算内核：时间步进算法、正压模态对非均匀密度的处理、正压模态的时间平均滤波、以及示踪物的守恒与常数保持。论文的结论是，这套内核在保持计算效率的同时，允许比同类地形跟随模式（SCRUM/SPEM、POM）以及 z 坐标（MOM、POP）和等密度坐标（MICOM）模式更大的时间步长，且不显著增加计算成本 [page 51]。

## 二、从“同步推进”到“前向—后向反馈”：时间步进算法的论证

论文的算法分析从两个最简单的模型方程出发：一维线性平流方程 (2.1) 和一维双曲系统 (2.2)，后者是正压模态在无科氏力、无地形时的类比 [page 9]。作者用傅里叶变换把问题化为特征多项式根的稳定性分析，并引入一个关键量——效率因子，即最大允许 Courant 数除以每步右端项计算次数 [page 11, 脚注 7]。

论证的关键一步在于：对系统 (2.2)，如果两个方程的右端项在同一时刻计算、再分别加到各自的预报变量上（即“同步”推进，式 2.10），那么它的稳定极限与单方程 (2.3) 完全相同，没有任何效率增益 [page 10–11]。而简单的前向—后向（FB）步 (2.13) 却能把稳定极限提高到 a = 2，原因是 f 更新后立即参与 u 的更新，而不是等到下一步 [page 11]。FB 的特征根 (2.16) 在 a ≤ 2 时模恒为 1，且两个根都对应物理波，没有计算模态 [page 11–12]。

但 FB 有一个致命弱点：对单振荡方程 (2.1)，前向步是无条件不稳定的 [page 12]。在自由表面模式中，这意味着除非把自由表面方程线性化（把 U = (h+ζ)ū 改成 U = hū，式 2.17），否则算法会因自由表面方程中的平流特征而不稳定；而线性化会破坏三维连续方程的相容性，最终导致示踪物失去守恒或常数保持 [page 12]。科氏力项也需要特殊处理。因此作者的目标是：把 FB 的“即时反馈”思想推广到更高阶，同时让第一个子步对单振荡方程也稳定。

### 广义预测—校正算法

作者先构造了带反馈系数的 RK2 型预测—校正格式 (2.18)–(2.21)，其中 β 和 ε 控制预测步和校正步中“新值立即参与”的程度 [page 13]。通过把 k = e^{ia} 代入特征方程 (2.22) 并做泰勒展开，得到 (2.24)：要消去 O(a⁴) 项需 ε = 4/3 − 2β；剩下的 O(a⁵) 项无法用实 β 消去，但 β = 1/3 使其最小 [page 13–14]。这个 β = 1/3 同时给出该族中最大的稳定极限 a_max = √(6(3−√5)) ≈ 2.140932539 [page 14]。作者指出，这个值超过所有同类预测—校正格式，但相对 FB 的 2 仍不算大，因为计算量翻倍；不过它不需要历史时刻信息，适合作为启动步 [page 14]。

接着作者把同样的方法用于 LF–TR 预测—校正格式，引入 β、ε、c 三个系数 (2.27)–(2.30) [page 15]。泰勒展开 (2.34) 显示，O(a²) 和 O(a³) 项对任意系数都自动消去，而 O(a⁴) 项为 −a⁴(1/6 − 2c)，因此 c = 1/12 保证三阶精度，与 β、ε 无关 [page 17]。在此基础上，消去 O(a⁵) 需 β = 7/30 − ε/6，消去 O(a⁶) 需另一个条件 (2.37)，但后者无实解，只能最小化误差，得到 ε = 11/20、β = 17/120，对应四阶精度和 a_max = 1.851640 [page 17]。作者随后放弃三阶精度、把 c 作为自由参数扫描，发现 c 减小甚至为负时稳定极限可升到 2.8，但负 c 对计算模态阻尼差，实际不可取；折中取 c = 0 得 a_max = 2.41，比标准 LF–TR 效率高 70% [page 19–20]。

### 广义前向—后向算法

作者进一步构造 AB2 型外推加 AM3 型插值的广义 FB 格式 (2.42)，其特征方程 (2.43) 的泰勒展开 (2.44) 给出：至少二阶精度要求 β = c + 2ε，这实际上约束了两个方程右端项的时间中心位置必须关于半步对称 [page 21–22]。同时消去 O(a³) 和 O(a⁴) 得到 (2.45)，形成单参数三阶精度族；稳定极限 a_max = √3 / √(1 + β/2 + 6β³) 随 β 增大而减小 [page 22–23]。消去全部三项领头项得到唯一四阶格式 β = 0.3737076，但超过此值会出现极弱的渐近不稳定（|k| = 1.0015）[page 23]。

作者特别讨论了 β = 1/2（即 ζ 方程用 AB2）的情形：虽然 AB2 对纯双曲项渐近不稳定，但比前向 Euler 弱得多，且能自然结合科氏力和平流项 [page 23]。此时取 ε = 1/3 给出该族中最大稳定极限 a_max = √(3/2) ≈ 1.2247，仍明显小于 FB 的 2，且物理模态仍有弱渐近不稳定 [page 24]。

最后是 AB3–AM4 型格式 (2.49)，用于正压模态的实际时间步进 [page 24]。泰勒展开 (2.51) 显示 O(1)、O(ia)、O(a²) 项对任意系数自动消去；消去 O(a³) 需 d = 1/2 + c + 2ε（把 u 方程右端项中心定在 n+1/2）[page 25]。追求最高精度时，消去 O(a⁴)、O(a⁵) 得 (2.54)，再消 O(a⁶) 得 ε = −1/3 ± √190/60，但该格式稳定极限仅约 1 且有渐近不稳定，不实用 [page 25]。放弃 O(a⁶) 消去、保留 (2.54)，在 ε = 0.083 时得到四阶格式的最大稳定极限 a_max = 1.727 [page 25]。进一步放弃 O(a⁵) 消去，用 (2.57) 把 c 表示为 β 和 ε 的函数，则可在保持三阶精度的同时双参数调优：β = 0.232、ε = 0.00525 给出 a_max = 1.939，接近 FB 但精度升到三阶 [page 28]；稍作修改 (β = 0.21, ε = 0.0115) 可改善稳定区间后半段的相位误差和阻尼，a_max = 1.875 [page 28]。作者最终为正压模态选定的折中参数是 β = 0.281105、c = 0.088、ε = 0.013，理由是 β = 0.281105 是 AB2–AB3 族中单方程最大稳定极限对应的值，可避免为平流项和压力梯度项分别设置系数 [page 28, 40]。

**关键推理的桥接**：作者反复使用“把 k = e^{ia} 代入特征多项式并泰勒展开”这一手法，把稳定性问题转化为“展开式中各阶项的系数是否为零”的问题。消去低阶项意味着提高相位精度，而稳定极限则由某个模态（物理或计算）离开单位圆的位置决定。作者明确指出，稳定极限总是由某个模态沿负实轴离开单位圆所限制，因此代入 k = −1 求解 a 即可得到 a_max [page 14, 23]。这一手法是全文算法论证的技术核心。

## 三、正压模态对非均匀密度的处理：消除分裂误差

分裂显式方法的一个固有问题是“分裂误差”。在 Blumberg–Mellor、Killworth 等人的做法中，正压方程 (3.1) 把 SWE 型压力梯度 −gD∇ζ 与一个“冻结”的耦合项相加，后者来自三维压力梯度的垂直积分 [page 28]。当正压时间步进结束、新的自由表面 ζ′ 代入完整斜压压力梯度时，其垂直积分不再等于“用新 ζ 算的 SWE 项 + 仍基于旧 ζ 的耦合项”，即 (3.4) 不成立 [page 29]。作者强调，这个误差不只是精度问题，它会在下一个斜压步作为扰动出现，破坏正压质量通量与垂直积分压力梯度的平衡，从而影响稳定性 [page 29]。Higdon 和 de Szoeke (1997) 在等密度坐标下已证明，若两个模态都用无耗散格式（LF 或 FB），耦合系统不可避免不稳定 [page 29]。

作者的解决方案是把正压压力梯度重新定义为三维压力梯度的垂直积分，并显式考虑非均匀密度。他们从流体元受力 (3.7) 出发，把压力梯度力写成 F_{i+1/2} = I_i − I_{i+1} − I_{i+1/2}，其中 I 是压力沿垂直线的积分 [page 30]。关键观察是：F 同时依赖 ζ 和密度，且这种依赖是非线性的（(3.10)），因此不能简单拆成只依赖 ζ 和只依赖密度的两部分 (3.11) [page 31]。作者引入两个垂直平均量：平均密度 ρ̄ (3.12) 和“动力学密度”ρ* (3.13)，并证明在 σ 型坐标下它们不依赖 ζ，只要密度剖面 ρ = ρ(r) 不变 [page 31]。于是 (3.7) 化为 (3.14)，进而得到垂直积分动量方程中的压力梯度 (3.15)：当 ρ* = ρ̄ = ρ₀ 时回到熟悉的 SWE 形式，否则多出两个斜压性质的项 [page 31–32]。

为了从离散密度场计算 ρ̄ 和 ρ*，作者采用分段抛物线重构 (3.16)，保证每个网格盒的平均密度等于 ρ̄_k (3.17)，并由此得到 ρ̄ 的离散式 (3.18) 和 ρ* 的离散式 (3.23) [page 32–33]。他们证明 I_i = ½ g ρ*_i D_i² (3.25)，与连续定义一致 [page 33]。对界面项 I_{i+1/2} 采用线性假设得到 (3.26)，最终压力梯度离散为 (3.27)，其中前三项是 O(Δx)，第四项是 O(Δx³) 可忽略 [page 33–34]。

作者随后把 (3.27) 拆成 F = F⁽⁰⁾ + F′ (3.31)，其中 F⁽⁰⁾ (3.28) 是 ζ = 0 时的残余项，F′ (3.32) 包含所有含 ζ 的项 [page 34]。他们总结了四条性质：(i) F′ 的第一行是 SWE 压力梯度的推广，ρ* 扮演“有效密度”角色；第二行是层化和地形存在时压力梯度对 ζ 扰动的响应，在均匀密度、平坦海底或无自由表面扰动时消失，作者指出这是层化流体越过地形坡度的基本性质，与垂直本征模态不再正交有关（Munnich, 1993; Maas, 1997a,b），也是潜在的分裂误差来源 [page 34–35]。(ii) ρ̄ 和 ρ* 不依赖 ζ，因为 ζ 扰动使所有 H_k 按 (1+ζ/h) 比例伸缩 (3.34)，分子分母的同比例变化保证了 (3.4) 型分裂误差被避免 [page 35]。(iii) 稳定层化下 ρ* ≤ ρ̄ (3.35)，意味着层化流体的有效正压压力梯度系统性地小于同 ζ 下的均匀密度情形 [page 35]。(iv) 水平均匀层化时斜压压力梯度应消失，但 F⁽⁰⁾ = 0 需要 ρ* 和 ρ̄ 之间的特殊关系，除常数、线性、二次密度剖面外只能近似满足，这就是“静力不相容”（Haney, 1991）；提高积分阶数只能减小误差而不能消除 [page 35]。

## 四、正压模态的时间平均：守恒与常数保持的兼容

分裂显式模式的另一个微妙问题是正压模态的时间平均。正压步长远小于斜压步长，正压过程在斜压步内被解析但斜压步无法分辨，若不平均就会发生时间混叠（aliasing）[page 8]。但平均又带来新问题：用快速时间平均的 ζ 替换 n+1 时刻的 ζ 后，慢时间离散连续方程 (1.20) 只在时间精度阶内成立，不再精确成立，于是无法通过 (1.19) 重构垂直速度使顶部运动学边界条件 (1.23) 精确满足，示踪物的常数保持性质随之丢失 [page 8–9]。

作者的解决方案是设计两套权重。第一套 {a_m} 用于计算 ⟨ζ⟩^{n+1} 和 ⟨U⟩^{n+1} (3.38)，满足离散归一化和质心条件 (3.37) [page 36]。第二套 {b_m} 由 {a_m} 通过 (3.43) 唯一确定，用于计算 ⟨⟨U⟩⟩^{n+1/2} (3.45)，使得慢时间自由表面方程 (3.39) 精确成立 [page 37–38]。推导的关键是把快速时间 ζ 的递推 (3.41) 求和后代入平均，交换求和次序，发现需要 b_{m'} = (1/M) Σ_{m≥m'} a_m [page 37–38]。作者强调，只要积分从 ζ⁰ = ⟨ζ⟩ⁿ 开始，(3.39) 就精确成立；这意味着每个斜压步结束后，瞬时 ζ 和 U 被其快速时间平均替换，作为下一步正压模态的初始条件 [page 38]。

在完成正压时间步进后，垂直坐标系统通过 (1.10) 用 ⟨ζ⟩^{n+1} 更新，新的 H^{n+1} 用于完成三维时间步 [page 38]。三维速度的垂直积分与 ⟨U⟩^{n+1} 的差被均匀分配到整列，保证更新后的三维速度垂直积分精确等于 ⟨U⟩^{n+1} [page 38]。示踪物更新前，三维速度在 n 和 n+1 之间插值得到 n+1/2 的质量通量，并再次校正使其垂直积分精确等于 ⟨⟨U⟩⟩^{n+1/2}；这保证 (1.17) 精确成立，示踪物时间步既守恒又常数保持 [page 38]。

## 五、滤波形状的选择

作者用连续积分 (3.51) 近似离散平均，把滤波后的步进乘子写成 k(a) = ∫ e^{−ias} A(s) ds [page 40–41]。泰勒展开 (3.52) 显示，任何正定形状函数 A(s) 最多给出一阶精度，因为 I₂ = 1 + δ 且 δ > 0（除非 A 是 δ 函数），δ 对应数值耗散 [page 41]。要消除相位误差（非色散），最简单是取关于 s = 1 对称的形状 (3.56) [page 41]。作者进一步给出消除 O(ia³) 色散项的条件 I₃ = 3I₂ − 2 (3.59) [page 42]。

论文比较了几种滤波：矩形滤波（2Δt 平坦平均）的 k(a) = (sin a / a) e^{−ia} (3.60)，其截断误差与权重 2/3 的隐式格式相当，意味着常用的后向 Euler（权重 1）精度更差 [page 42–43]。ROMS 历史上使用的 cos 型滤波 (3.63) 虽然仍是一阶，但领头耗散 δ = (π²−6)/(12π²) ≈ 0.0326，比后向 Euler 小一个半量级 [page 43]。为了进一步提高精度，作者定义允许部分权重为负的形状函数 (3.64)，通过 Newton 迭代满足归一化、一致性和二阶精度条件 (3.65) [page 43]。图 17 左侧是二阶精度滤波，右侧是按 (3.59) 最小化色散优化的滤波 [page 43–44]。作者指出，允许负权重还能缩短滤波超出 n+1 的范围，提高计算效率；所有左侧滤波都不超过 Δt/4 或 Δt/3 [page 43]。实际经验表明滤波对稳定性是必需的（不能把 a_m 设为 δ 函数），但即使图 17 中耗散最小的滤波也能给出稳定模式，无需在正压模态中显式加粘性 [page 44]。

## 六、斜压步的混合预测—校正与示踪物处理

斜压模态的时间步进与正压类似，但必须保证示踪物的守恒和常数保持。作者指出，多数海洋模式用单步格式（LF 或 AB3），有两个弱点 [page 45]：(i) 动量和示踪物同步推进，动量方程只能在下一步感受到示踪物分布变化带来的反馈；在 LF 下，偶数步速度主要与奇数步示踪物耦合，奇—奇和偶—偶耦合弱得多，线性化系统中这两种模态完全独立 [page 45]。(ii) 自由表面模式中 H^{n+1} 由正压模态用完全不同的时间格式设定，LF 下难以构造守恒且常数保持的示踪物平流格式，因为 LF 从 n−1 推进到 n+1 而通量在 n 时刻，离散连续方程 (1.17) 却关联 H^{n+1} 和 H^n [page 45]。

作者的做法是：质量通量和界面示踪物值都必须时间中心在 n+1/2，于是连续方程写成 (4.1)，示踪物方程写成 (4.2) [page 45]。他们强调 (4.1) 不是用来计算 H^{n+1}，而是对质量通量集合的约束，通过强制 U^{n+1/2}、V^{n+1/2} 的垂直积分等于 ⟨⟨U⟩⟩^{n+1/2}、⟨⟨V⟩⟩^{n+1/2} 来满足 [page 45]。示踪物界面值可以通过 AB2/AB3 外推 (4.3) 得到，也可以采用 UTOPIA/COSMIC 类算法；作者指出 COSMIC 最可能，但全三维 UTOPIA 不实用 [page 46]。另一种预测步用平流形式 (4.4) 加三点插值 (4.5)，合并为 (4.6) [page 46–47]。最后，作者提出“伪可压缩”算法 (4.7)–(4.8)：构造两个辅助网格盒高度场 H⁻ 和 H⁺，用 LF 步加三点插值更新示踪物；若 q^{n−1} = q^n = const，则 q^{n+1/2} 也取同一常数，与质量通量散度无关，从而实现常数保持 [page 47]。代价是这个更新不守恒，因为 H⁺ 与正压模态设定的实际 H^{n+1} 无关；作者明确说这是用守恒性换取常数保持，对应连续恒等式 (4.9) 中丢掉最后一项 [page 47]。

空间插值提供三种选项：中心四阶 (4.10)–(4.12)、调和平均 (4.13)（保证插值有界）、以及迎风抛物线插值（耗散主导）[page 47–48]。垂直方向避免迎风偏置以减小人工跨密度面通量，优先用守恒抛物线样条 [page 48]。

## 七、耦合系统的完整时间步进

第 5 节把上述组件串成六阶段流程（图 18）[page 48–50]：

- **Stage 1**：用 n 时刻右端项（压力梯度、科氏力、平流）以 LF 加 AM3 半步后向插值推进三维动量到 n+1/2；因无 H^{n+1}，用伪可压缩算法；因违反正压 CFL 且无 n+1/2 正压通量，把新通量的垂直平均设回 ⟨U⟩ⁿ [page 48–49]。
- **Stage 2**：用类似伪可压缩 LF 加 AM3 推进示踪物到 n+1/2（常数保持但不守恒，可接受，因为这些值只用于计算校正步的通量）[page 49]。
- **Stage 3**：用 n+1/2 的质量通量和示踪物（经密度）计算三维动量右端项，加上旧步速度的侧向粘性；垂直积分并存储 n+1/2 的 ρ̄、ρ* [page 49]。
- **Stage 4**：用 (3.32) 计算正压右端项，从 Stage 3 的垂直积分中减去，得到斜压到正压的强迫项；推进正压变量 M* 步（略超过 n+1，取决于滤波形状），同时做双向快速时间平均；正压压力梯度每步用 ρ̄、ρ* 重算；完成后用 ⟨ζ⟩^{n+1} 更新垂直坐标 [page 49–50]。
- **Stage 5**：用可用的 H^{n+1} 完成 Stage 3 开始的三维质量通量计算，垂直平均设为 ⟨U⟩^{n+1} [page 50]。
- **Stage 6**：把三维速度插值回 n+1/2（结合新步值、预测步值和旧步值，实现动量与示踪物之间的前向—后向反馈），垂直平均设为 ⟨⟨U⟩⟩^{n+1/2}；用该速度场和 n+1/2 示踪物计算示踪物通量，推进到 n+1（守恒且常数保持）[page 50]。

## 八、结论成立的条件与边界

作者在结论中明确列出内核的几项设计目标及其实现 [page 50–51]：带前向—后向反馈的时间步进算法（把 FB 推广到更高阶，Euler 步 (2.13) 是第一成员，AB2–AM3 (2.42) 是第二，AB3–AM4 (2.49) 是第三）；斜压模态用 LF–AM3 型预测—校正（三时间层），但预测子步只用于获得 n+1/2 的临时变量，模式分裂只发生在校正步，校正步始终是两时间层格式；正压模态重新定义以考虑非均匀密度，压力梯度取三维压力梯度对 ζ 扰动的垂直积分，保证有地形时的分裂精度；通过正压有限体积通量的双向时间平均，保证三维离散连续方程在两个斜压步之间精确成立，从而实现示踪物的守恒与常数保持；正压模态的时间加权平均允许准确表示斜压步能解析的正压运动（潮汐、正压 Rossby 波）；计算昂贵的混合参数化放在预测—校正主流程之外以降低代价 [page 50–51]。

表 1 给出几个实际应用的允许时间步长和分裂比：大西洋 DAMEE 128×128×20、0.75°、8640 s、分裂比 60（广义 FB），主要限制是科氏力；256×256×20、0.375°、5760 s、分裂比 92，限制是科氏力/内波；太平洋 384×224×30、0.5°、7200 s、分裂比 78，限制是科氏力；美国西海岸 83×168×20、15 km、2880 s、分裂比 50（LF–TR），限制是内波；10 km、2160 s、分裂比 60；Monterey Bay 5 km、960 s、分裂比 60 [page 51]。作者称 ROMS 允许比地形跟随原型（SCRUM/SPEM、POM）以及 z 坐标（MOM、POP）和等密度坐标（MICOM）模式显著更大的时间步长，且不显著增加计算成本，也未观察到因时间步长接近理论稳定极限而导致解质量下降 [page 51]。

需要交代的边界和作者承认的局限：

1. **滤波是稳定性所必需的**。作者明确说不能把 a_m 设为 δ 函数，否则模式会弱不稳定；即使耗散最小的滤波也足以稳定，无需正压显式粘性 [page 44]。这意味着结论依赖于滤波的存在，而非“无平均也能稳定”。

2. **伪可压缩预测步不守恒**。作者明确承认 (4.7)–(4.8) 的更新不守恒，因为 H⁺ 与实际 H^{n+1} 无关；这是用守恒性换取常数保持的有意取舍，且只用于计算 n+1/2 的通量，这些值随后被丢弃 [page 47]。

3. **静力不相容无法消除**。水平均匀层化时 F⁽⁰⁾ = 0 需要 ρ* 和 ρ̄ 的特殊关系，除少数密度剖面外只能近似满足；提高积分阶数只减小误差 [page 35]。这是地形跟随坐标的固有局限，作者没有声称解决。

4. **F′ 第二行的完整后果未分析**。作者说这一项是层化流体越过地形坡度的基本性质，与垂直本征模态不再正交有关，是潜在的分裂误差来源，但“完整分析超出本文范围” [page 34–35]。这是一个明确标注的未决问题。

5. **滤波的定量稳定性分析未完成**。作者说按 Higdon 和 de Szoeke (1997) 方式做完整定量分析超出本文范围，实际经验表明滤波一般对稳定性是必需的 [page 44]。

6. **负 c 算法实际不可取**。虽然 c < 0 可把 a_max 提到 2.8，但计算模态阻尼差，实际表现不好，因此折中取 c = 0 [page 19–20]。

7. **AB2 的弱渐近不稳定**。β = 1/2 时物理模态仍有弱渐近不稳定，a_max = √(3/2) 明显小于 FB 的 2 [page 24]。

8. **四阶格式的渐近不稳定**。β = 0.3737076 的四阶格式超过该值后渐近不稳定，虽然极弱（|k| = 1.0015）[page 23]。

## 九、总体评价

这篇论文的论证风格是“从线性稳定性分析出发，逐步构造并筛选算法，再用实际应用验证”。它的核心贡献不在于提出某个单一的新格式，而在于把分裂显式模式中几个相互纠缠的问题——时间步进的稳定极限、正压—斜压耦合的分裂误差、自由表面变化下的示踪物守恒与常数保持、正压模态的时间混叠——放在同一个框架下处理，并给出可操作的参数选择。论证的关键推理是：把稳定性问题转化为特征多项式根的分布问题，用泰勒展开的阶数控制相位精度，用根离开单位圆的位置确定稳定极限；同时用“两套权重”的构造把时间平均与慢时间连续方程的精确相容性统一起来。结论的成立条件主要是：滤波必须存在且形状适当；伪可压缩预测步的守恒性被有意放弃；静力不相容和 F′ 第二行的完整影响未被解决。表 1 的实际应用数据支持“时间步长可显著增大”这一主张，但作者也承认这些是特定配置下的经验值，而非普适定理。
