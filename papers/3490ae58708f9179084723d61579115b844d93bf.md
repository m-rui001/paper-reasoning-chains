# 单调不平衡约束的多元匹配方法：MIB 类如何把“平衡”从期望承诺变成可调上界

**原文题名**：Multivariate Matching Methods That Are Monotonic Imbalance Bounding（2011）
**DOI**：https://doi.org/10.1198/jasa.2011.tm09599

## 一、作者要解决的是什么问题

在观察性研究中，研究者无法控制处理分配，因此因果推断的可靠性很大程度上取决于能否让处理组与控制组在预处理协变量上尽可能平衡。匹配（matching）正是为此而设：为每个处理单元寻找一个或多个协变量相近的控制单元，从而减少推断对模型的依赖 [page 2]。

在本文之前，文献中唯一被严格刻画过的匹配方法类，是 Rubin 提出的“等比例偏差缩减”（Equal Percent Bias Reducing, EPBR）。EPBR 的核心含义是：改善某一个变量上的均值不平衡，会按同一比例改善所有其他变量（及其线性组合）上的均值不平衡。作者引用 Rubin 1976b 的话指出，EPBR 只是“最简单的多元起点”，应当被推广到更一般的情形；但三十多年过去，文献中并未出现这样的推广类 [page 2]。本文的任务就是填补这一空白，提出 **单调不平衡约束**（Monotonic Imbalance Bounding, MIB）类，并给出一个具体成员——粗化精确匹配（Coarsened Exact Matching, CEM）——的详细分析。

## 二、EPBR 的承诺与它的代价

EPBR 的定义是：匹配后处理组与控制组均值差的期望，等于原始均值差的一个标量倍数 γ（0<γ<1），即
E( X̄_mT − X̄_mC ) = γ(μ₁−μ₀) [page 3, 式(1)]。

这里 γ 是标量，意味着所有变量上的不平衡按同一比例缩减。但这一性质并非无条件成立。作者明确指出，EPBR 只有在以下假设下才真正可用：(a) X 从指定总体中随机抽取；(b) 总体分布为椭球对称密度，或成比例的椭球对称混合分布；(c) 匹配算法对 X 的仿射变换不变 [page 3]。这些条件在观察性数据中“很少成立，而且几乎从不知道是否成立” [page 3]。

更关键的是，EPBR 只处理均值不平衡，对其他矩、交互项、非线性关系不置一词（除非研究者事先把这些项显式加入 X）[page 3]。而且 EPBR 要求匹配前就固定匹配控制单元的数量 m_C，γ 事后计算 [page 3]。这意味着研究者先决定样本量，再检查平衡——在观察性数据中，这恰恰把优先次序搞反了。

## 三、MIB 的六步构造：从期望到样本内、从等式到不等式、从标量到逐变量

作者用六步把 EPBR 推广为 MIB [page 3–4]：

1. **放弃数据假设**：不再要求 (a)(b) 成立。
2. **转向样本内不平衡**：EPBR 关注期望平衡，MIB 关注实际样本中的不平衡。作者的理由是，最终因果量的效率取决于样本内平衡而非期望平衡，这也解释了为何基于估计倾向得分的匹配有时比真实得分更有效 [page 3]。
3. **等式改为不等式**：把 |X̄_mT,j − X̄_mC,j| ≤ δ_j 作为逐变量的上界，其中 δ_j = γ_j|X̄_nT,j − X̄_nC,j| [page 3, 式(3)]。
4. **δ_j 事前选定，m_T、m_C 由算法决定**：这与 EPBR 正好相反。
5. **从均值推广到一般不平衡度量**：引入一般距离 D(·,·) 和样本函数 f(·)，得到中间定义 IB：D(f(X_mT), f(X_mC)) ≤ δ [page 4, 式(4)]。作者列举了若干特例：f 为样本均值、方差、k 阶中心矩、q 分位数、经验分布函数（此时 D 为 sup 范数即 Kolmogorov 距离）、协方差等 [page 4]。
6. **引入单调性**：定义 MIB 为存在单调递增函数 γ_{f,D}(·)，使得对任意 π ∈ R^k₊，
D(f(X_mT(π)), f(X_mC(π))) ≤ γ_{f,D}(π) [page 4, 式(5)]。

这里 π = (π₁,…,π_k) 是逐变量的调节参数（如 caliper），匹配单元数 m_T(π)、m_C(π) 是 π 的函数，而非事前固定。γ_{f,D} 只依赖 π，不依赖样本量，代表给定调节参数下的最坏情形 [page 4]。

**关键推理步骤**在于：如果 f 可分解为逐变量的 f_j，且 γ 可分解为 γ_j(π_j)，那么改变某一个变量的调节参数 π₁ → π₁−ε，只会收紧第一个不等式，其余变量的最大不平衡上界不变 [page 5]。这正是 MIB 相对于 EPBR 的核心优势：**无需数据假设，就能保证调整一个变量的平衡不会恶化其他变量的最大不平衡**。作者用实际例子说明这一性质的意义：体重可容忍 2 磅差异、年龄可容忍 5 岁差异、教育可容忍一两年差异——一旦设定这些阈值，MIB 保证无论其他变量如何调整，这些上限都不会被突破 [page 5]。

## 四、MIB 与 EPBR 的对照：谁属于哪个类

作者明确指出，常见的倾向得分最近邻匹配和 Mahalanobis 距离最近邻匹配**不是 MIB**，因为它们事前固定匹配数 (m_T, m_C)，而非让匹配数成为调节参数的结果 [page 5]。带标量 caliper 的最近邻匹配也不是 MIB，因为 MIB 定义要求调节参数 π 的维数为 k，才能实现式(5)那样的可分离性 [page 5]。Cochran 和 Rubin (1973) 的 caliper matching 因正交化和重叠区域的处理也不是 MIB；但若不做正交化，且距离中每个变量都有各自的调节参数，则是 MIB [page 5]。

CEM 是 MIB 的一个成员：先对每个变量分别粗化，再在粗化后的空间做精确匹配 [page 5]。此外，在 CEM 的粗化层内或在逐变量 caliper 内应用非 MIB 方法（如倾向得分、Mahalanobis 距离），所得方法仍是 MIB [page 5]。

两个类的设计目标都是避免“改善某些变量的平衡却恶化其他变量”这一实际问题。但机制不同：EPBR 在额外数据假设下让所有变量按同一比例变化；MIB 不依赖数据假设，让改变一个变量的调节参数不影响其他变量的最大不平衡 [page 5]。作者还指出，两个类都不能同时保证不平衡水平和匹配样本量：EPBR 事前选样本量、事后算平衡；MIB 事前选最大不平衡、事后产生样本量。后者在观察性分析中通常更可取，因为数据通常充足但不受研究者控制，减少偏差比减少低效更重要 [page 5]。

## 五、MIB 如何约束模型依赖与估计误差

这是本文理论贡献中最关键的一步。作者证明，MIB 方法的调节参数可以直接控制模型依赖的最大程度，并进一步约束因果效应估计误差 [page 6]。

**模型依赖的界定**：在单元层面，精确匹配用 X_j = X_i 的控制单元 j 的 Y 值来估计处理单元 i 的反事实 Y_i(0)。当精确匹配不可行时，用模型 m_ℓ 来跨越剩余不平衡。模型依赖定义为：给定协变量向量，不同模型 m_ℓ 的预测值之间的差异 |m₁(X̃_j) − m₂(X̃_j)| [page 6]。

作者限定在一类竞争模型 M_h 中：每个模型满足 Lipschitz 条件 |m_ℓ(x) − m_ℓ(y)| ≤ K_ℓ d(x,y)，且任意两个模型在同一观测点的预测差异不超过 h [page 6]。在这个框架下，对 MIB 方法（取 D(x,y)=d(x,y)，f(x)=x），有：

|m₁(X̃_j) − m₂(X̃_j)| ≤ (K₁+K₂)d(X_i, X̃_j) + h ≤ (K₁+K₂)γ(π) + h [page 6]。

因此，模型依赖的程度被 π（通过 γ(π)）直接约束。这是此前 EPBR 方法或除精确匹配外的任何方法都未被证明过的性质 [page 6]。

**估计误差的约束**：作者进一步证明（Proposition 1），在 g(x,0) 可微且偏导数有界的条件下，|τ_mT − τ̂_mT| ≤ γ(π)K + o(γ(π))，其中 K = ΣK_h [page 6–7]。证明用 Taylor 展开，将 g(X̃_j,0) 在 X_i 处展开，利用 MIB 的 d(X̃_j, X_i) ≤ γ(π) 得到界 [page 7]。作者指出，若可微性条件过强，可改用局部 Lipschitz 条件，结论不变 [page 7]。

这一结果的意义在于：MIB 方法的估计误差上界是调节参数 π 的显式函数，而 γ(π) 可以单调控制，因此对于给定的 g(·,0)，界可以足够紧 [page 7]。

## 六、CEM 作为 MIB 的具体实现

CEM 分三步：(1) 按分析者愿意的程度粗化每个变量；(2) 对粗化后的 C(X) 做精确匹配，将观测分入层 s ∈ S；(3) 只含控制单元的层丢弃，含处理和控制单元的层保留，只含处理单元的层或用外推控制值，或丢弃并相应缩小估计量 [page 7]。

匹配后，处理单元权重 w_i = 1（若 i ∈ T^s），控制单元权重 w_i = (m_C/m_T)·(m_T^s/m_C^s)（若 i ∈ C^s），未匹配单元权重为 0 [page 7]。

作者证明 CEM 是 MIB 类成员，具体地：

- **Proposition 2**：|X̄^w_mT,j − X̄^w_mC,j| ≤ ε_j，即加权均值差被粗化区间长度约束 [page 8]。
- **Proposition 3**：|μ̄^k_T,j − μ̄^k_C,j| ≤ ε_j^k(θ_j+1)^k，其中 θ_j = max_{ε_j≥ε*_j} ⌈R_j/ε_j⌉，R_j 为变量 X_j 的范围 [page 8]。
- **Proposition 4**：一对一匹配下，|X^q_mT,j − X^q_mC,j| ≤ ε_j，即分位数差被约束 [page 8]。
- **Proposition 5**：加权经验分布下，|X^{q,w}_mT,j − X^{q,w}_mC,j| ≤ ε_j [page 8]。

这些命题的证明在附录中给出 [page 17–18]。核心思路是：在同一粗化层内，处理单元和控制单元的协变量值最多相差 ε_j，而 CEM 的加权机制保证层内处理和控制单元的权重总和相等，因此各阶矩和分位数的差异都被 ε_j 约束。

**关于维度诅咒**：作者承认，在高维独立正态数据中，CEM 可能产生很少匹配。例如 10,000 个观测、20 个变量、每个变量仅 2 个区间，就有 2²⁰ 个可能层，很多层可能只有处理单元或只有控制单元 [page 8]。但作者认为这在实际中不是大问题，因为真实数据中变量高度相关，CEM 通常能产生合理数量的匹配 [page 8]。作者还引用 Abadie 和 Imbens (2009) 的证明思路指出，若控制单元数 n_C 以 n_C = O(n_T^{1/r}) 增长（r ≥ k），则只含未匹配处理单元的层数会以指数速度趋于零 [page 8]。

**计算效率**：尽管可能的层数是指数级的（如 k=20, m=6 时 6²⁰ ≈ 3.66×10¹⁵），但 CEM 最多产生 n 个层（若所有观测落入不同层），因此算法只需关注至多 n 个层。作者用整数编码和字符串表示特征向量，使 CEM 匹配的复杂度与简单频率列表相当，为 O(n) [page 8]。

## 七、不平衡的度量：L₁ 与 L₁ 轮廓

作者提出用 L₁ 范数度量处理组和控制组多元经验分布之间的距离。将每个变量的支撑切成区间，构造多维直方图，设 f 和 g 分别为处理组和控制组的相对经验频率分布，定义
L₁(f,g;H) = ½ Σ_{ℓ₁…ℓ_k ∈ H(X)} |f_{ℓ₁…ℓ_k} − g_{ℓ₁…ℓ_k}| [page 9, 式(6)]。

L₁ = 1 表示两个分布完全分离，L₁ = 0 表示完全重合，L₁ = 0.6 表示 40% 的直方图面积重叠 [page 9]。空单元不影响 L₁，求和最多有 n 个非零项 [page 9]。

由于 L₁ 依赖分箱选择 H，作者研究 L₁ 轮廓——L₁(H) 在所有可能分箱定义上的分布。用 Lalonde (1986) 数据，抽取 250 个随机分箱，比较原始数据、倾向得分匹配（PSC）、Mahalanobis 最优匹配（MAHO）和 CEM [page 9]。结果显示，在几乎所有分箱定义下，CEM 的 L₁ 最低，PSC 和 MAHO 次之，原始数据最高 [page 9–10, Figure 2]。作者据此建议固定 H 为原始数据 L₁ 轮廓的中位数对应的分箱 H̄，记 L̄₁ = L₁(H̄) [page 10]。在 Figure 2 中，L̄₁ 对 Mahalanobis 为 0.43，对倾向得分为 0.41，对 CEM 为 0.26 [page 10]。

**均值平衡是否足够？** 作者用 Lalonde 数据说明：倾向得分加权可以消除所有均值不平衡（加权均值差几乎为零），但全局不平衡 L̄₁ 仅从 0.54 降到 0.53，几乎不变；而 CEM 匹配后 L̄₁ 降到 0.34 [page 10, Table 1]。这说明仅控制一维分布不足以控制联合分布的整体不平衡（除非在多变量高斯等特殊情形下）[page 10]。

## 八、模拟证据：CEM 在 EPBR 友好数据中仍占优

作者做了多组模拟，数据生成过程特意满足 EPBR 的要求，然后比较 CEM 与 EPBR 类方法。

**第一组**（Gu 和 Rosenbaum 1993 的复制）：五维多元正态，共同方差 (6,2,1,2,1)，协方差 (2,1,0.4,−1,−0.2,1,−0.4,0.2,0.4,1)，均值 μ_T=(0,0,0,0,0)，μ_C=(1,1,1,1,1)。n_T=1000，n_C=3000。CEM 每个协变量粗化为 8 个等长区间 [page 11]。结果（Table 2）：CEM 的均值差 I₁ 在 0.04–0.08 之间，MAH 为 1.00，MAHO 为 0.45，PSC 为 0.32，PSC2 为 0.14–0.16；局部不平衡 I₂ 和全局 L̄₁ 也是 CEM 最低（L̄₁=0.21，MAHO=0.34，PSC=0.31，PSC2=0.26）[page 11, Table 2]。作者指出，EPBR 方法在这些数据中仅在期望意义上最优，CEM 的额外优势来自 MIB 的样本内多元不平衡缩减性质 [page 11]。

**第二组**（一维情形）：处理组 X~N(1,1)，控制组 X~N(5,1)，n_T=200，n_C=400，六种不同的 g_k(x,t) 函数（常数、线性、多种非线性处理效应）[page 14, Figure 5]。1000 次 Monte Carlo 重复。结果（Figure 6）：CEM 在 60 个实验中有 59 个 RMSE 低于 PS0，最后一个约持平 [page 14]。当目标量改为局部 PATT 时（Figure 7），CEM 的 RMSE 不随粗化加剧、匹配数下降而上升，反而下降，因为异质性被匹配缩减 [page 14]。

**第三组**（五维高斯，含倾向得分模型选择）：n_T=n_C=5000，处理组 N(0,I)，控制组 N(2,I)，五种 g_k(x,t) 函数 [page 15]。CEM 考虑 50 种随机粗化，每个变量切点数为 U([3,7]) 的随机整数 [page 15]。结果（Figure 8）：CEM 在所有实验中 RMSE 低于所有倾向得分方案 [page 15]。局部 PATT 下（Figure 9），RMSE 同样不随匹配数下降而上升 [page 15]。

**第四组**（Lalonde 数据）：以 Lalonde 数据为总体，n_T=150，n_C=300，四种 g_k(x,t) 函数 [page 16]。结果（Figure 10–11）与前类似：CEM 明显优于其他方法，RMSE 更低，且不随匹配变严而上升 [page 16]。

## 九、实证案例：女儿对国会投票的影响

作者复制 Washington (2008) 的研究：有女儿（而非儿子）的众议员是否投票更自由。数据为第 105 届国会 430 名议员的 NOW 评分（0–100），处理变量为是否有女儿，控制变量包括种族、性别、子女数、党派、宗教、资历及其平方、年龄及其平方、民主党得票率 [page 11]。

Washington 的回归给出效应为 2.23（标准误 1.02）[page 11]。作者运行所有 656 种可能的线性回归（主效应、三阶以内交互、连续变量的平方项），得到处理效应估计的范围为 [−3.03, 6.11] [page 12, Figure 3 黑线]。这意味着仅选择一种设定，就可能“证明”从大负到大正的任何结论。

用 CEM 预处理（三个连续变量各粗化为 10 个等长区间）后，不平衡从 L₁=0.818（n=430）降到 L₁=0.762（n=175）[page 12]。重新运行所有 656 种回归，处理效应范围缩小到 [3.04, 4.80]，且区间内每一点都支持 Washington 的假设 [page 12, Figure 3 红虚线]。点估计从 2.2 增加到 3.2，增加了 45%，且模型依赖大幅降低 [page 12]。

但作者强调，这个更可靠的因果效应是仅对匹配子集的平均效应，估计的是不同的估计量（局部 SATT）[page 12]。Figure 4 的平行坐标图显示，匹配后的处理单元（有女儿的议员）中，年轻、白人、男性共和党人的比例更高：男性多 10 个百分点，年龄平均小 4 岁，资历少 2.5 年，白人比例高 12 个百分点，共和党比例高 24 个百分点 [page 12]。因此，由于 1996 年选举中当选的特定人群，我们只能对这个子集做出较可靠的推断 [page 12]。

## 十、估计误差的进一步缩减：局部 SATT 与加权组合

作者定义两个量：SATT = (1/n_T)Σ_{i∈T}[Y_i(1)−Y_i(0)]（样本平均处理效应），PATT = E_{i∈T*}[Y_i(1)−Y_i(0)]（总体平均处理效应）[page 13]。当某些处理单元没有合理匹配时，分析者有三种选择：(a) 外推建模，(b) 放弃，(c) 改变估计量为有良好匹配的子集的 SATT 或 PATT [page 13]。

作者提出四步法：(1) 预处理去除最差潜在匹配；(2) 运行 CEM 得到 m_T ≤ n_T 和 m_C ≤ n_C；(3) 将处理单元分为匹配的 m_T 个和未匹配的 n_T−m_T 个；(4) 分别计算两组的 SATT，然后加权平均：
τ̂_nT = [τ̂_mT · m_T + τ̂_{nT−mT} · (n_T−m_T)] / n_T [page 13, 式(7)]。

这样保持总体估计量不变，同时隔离出模型依赖的部分，使其可被单独研究 [page 13]。

## 十一、结论成立的条件与边界

MIB 的核心优势——调整一个变量的调节参数不影响其他变量的最大不平衡——成立的条件是：f 可分解为逐变量的 f_j，且 γ 可分解为 γ_j(π_j) [page 5]。这不是所有 MIB 方法都自动满足的，而是 CEM 等具体方法所具有的性质。

模型依赖和估计误差的界依赖于 Lipschitz 常数 K_ℓ 或偏导数界 K_i，这些常数对给定的 g(·,0) 是固定的，但可能很大，从而界可能不够紧 [page 7]。作者承认这一点，但指出 γ(π) 可以单调控制，因此界可以足够紧 [page 7]。

CEM 在高维独立数据中可能产生很少匹配，这是 MIB 方法的一个潜在局限 [page 8]。作者认为实际数据中变量高度相关，因此这不是大问题，但这一判断基于作者的经验而非理论保证 [page 8]。

CEM 丢弃处理单元会改变估计量，从 SATT/PATT 变为局部 SATT/PATT [page 12–13]。作者强调所有匹配分析都应明确报告匹配子集的协变量分布，但这一建议在文献中很少被实践 [page 12]。

L₁ 度量依赖分箱选择 H，作者通过 L₁ 轮廓和固定 H̄ 来缓解这一问题，但 L₁ 轮廓的稳定性是经验观察而非理论保证 [page 9–10]。作者指出“在几乎所有我们分析的数据集中，这种近似不变性是一个极其常见的经验规律”，但建议在具体应用中检查 [page 9]。

模拟中 CEM 的优势是在特定数据生成过程下得到的，虽然这些过程特意设计为满足 EPBR 要求，但真实数据的复杂性可能超出模拟范围。作者在 Lalonde 数据上的结果提供了额外的经验支持，但 Lalonde 数据本身也有其特殊性 [page 16]。

## 十二、总体评价

本文的核心贡献是提出了一个比 EPBR 更一般、更灵活的匹配方法类 MIB，并给出了一个具体可实现的成员 CEM。MIB 的关键创新在于：不依赖数据分布假设，将平衡从期望承诺变为样本内可调上界，并证明调节参数可以直接约束模型依赖和估计误差。CEM 作为 MIB 的实现，在 EPBR 友好数据中仍能优于 EPBR 方法，在实证案例中大幅降低模型依赖。但 MIB 方法的代价是可能丢弃处理单元、改变估计量，且在高维稀疏数据中可能匹配不足。这些边界条件在应用中需要被明确认识和报告。
