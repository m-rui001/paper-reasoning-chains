# 可穿戴与可拉伸应变传感器：材料、传感机制与应用

**原文题名：** Wearable and Stretchable Strain Sensors: Materials, Sensing Mechanisms, and Applications
**年份：** 2020
**DOI：** 10.1002/aisy.202000039

这是一篇综述。它的核心主张不是提出某个新器件，而是对可穿戴/可拉伸应变传感器领域做一次分类学式的整理，并在此基础上给出一个带有取舍判断的总体结论：电阻式、电容式、光学式三条技术路线各有明确的性能优势与短板，而"高拉伸性、高灵敏度、高线性度"三者难以同时满足，是当前领域最根本的瓶颈。下面按这篇综述实际展开论证的方式，说明它如何从材料与机制走向这一结论，以及这个结论在什么条件下成立。

## 分类先于比较：为什么只谈三类传感器

作者在开篇就做了一个筛选动作，而不是罗列所有应变传感类型。可拉伸应变传感器包括电阻式、电容式、压电式、摩擦电式和光学式，但压电与摩擦电传感器"通常在高频下工作，且由于快速电荷转移无法捕捉静态应变"，因此作者认为它们在多尺度、可穿戴应变传感中的实用性"仍然存疑" [page 2]。于是综述只聚焦电阻式、电容式和光学式三类。

这一步是整篇论证的地基：后面的所有性能比较，都只在被保留下来的三类之间进行。读者需要意识到，这个筛选本身是一个判断而非事实——它依赖"可穿戴场景需要静态与动态应变兼顾"这一前提。如果应用场景只关心高频动态信号，压电/摩擦电路线未必被排除。作者没有展开这一反事实，但结论的适用范围实际上被这个前提限定了。

## 三条路线的机制差异，决定了它们性能差异的方向

综述用第5节集中处理机制，这是理解全文的关键。三类传感器的传感原理并不在同一层面上：

- **电阻式**的电阻变化来自几何效应、材料本征电阻响应、纳米材料间的断连、导电薄膜中的微裂纹、以及隧穿效应等多种机制的叠加 [page 2, page 8]。作者明确指出，几何效应对于纳米材料基可拉伸传感器的整体性能"贡献可能并不显著" [page 9]，真正主导的是断连、裂纹和隧穿这些结构性机制。
- **电容式**的响应几乎完全由几何变化决定。作者给出推导：当传感器被拉伸 ε 时，长度变为 (1+ε)l₀，宽度和厚度分别收缩为 (1−ν_electrode ε)w₀ 和 (1−ν_dielectric ε)d₀，在假设电极与介电层泊松比相等的前提下，电容简化为 C = (1+ε)C₀（式4）[page 9]。这个推导直接给出两个后果：电容式理论上最大 GF 为 1，且响应天然线性。
- **光学式**依赖波导拉伸时光传输的衰减。由 Beer–Lambert 定律 A = ecL（式5）出发，作者推出输出功率损耗 a = 10ecL₀ε（式7），即损耗与应变成线性关系 [page 9]。

这里有一个值得点出的推理结构：作者并不是先测量再归纳，而是先用几何/光学关系**推导出**电容式和光学式应当线性、且电容式灵敏度有上限，然后再用文献数据去印证。式4和式7是全文少数的解析推导，它们承担的是"解释为什么这两类传感器表现出高线性"的角色，而不是预测新现象。读者应把这两式理解为对已知行为的机制说明。

## 性能参数比较：证据如何支撑"取舍关系"这一核心结论

第6节逐一讨论拉伸性、灵敏度、线性度、迟滞、响应/恢复时间、过冲和动态耐久性，并用 Table 1（聚合物基传感器）和 Table 2（纺织基电阻式传感器）汇总大量文献数据 [page 12–13]。这些表格是全文最主要的证据载体。

几个关键的数据点及其作用：

- **拉伸性**跨度极大，从 2% 到 1400% [page 11]。作者归纳出一个趋势：使用 2D 或 3D 纳米材料比 1D 纳米材料更容易获得高拉伸性，因为高长径比有利于在大应变下维持渗流网络 [page 11]。这是从表格数据中提炼的规律，属于作者的归纳而非单篇文献的结论。
- **灵敏度**用 GF 衡量。电阻式可极高：碎片化 CNT 纸–PDMS 达 10⁷（50% 应变）[page 11]，3D 打印石墨烯/PDMS 达 88 443（350% 应变）[page 11]，天然纤维基传感器 GF 从 1.2 到 102 351 不等 [page 11]。电容式理论上限为 1，多数低于此值，但作者也举出通过几何工程和材料配方突破该上限的例子：褶皱 Au 薄膜电极达 GF≈3（140% 应变）[page 11]，Ag 纳米纤维/离子水凝胶达 GF 165（1000% 应变）[page 11]。
- **线性度**用 R² 衡量。作者明确判断：电容式和光学式的线性度总体优于电阻式 [page 12]。电阻式的非线性被归因于传感薄膜在拉伸时"非均匀的微观结构和形貌变化" [page 12]，多数电阻式传感器只在两个或三个区间内线性。

正是在汇总这些数据之后，作者给出全文最重要的判断："高拉伸性与线性度"和"高灵敏度"之间普遍存在取舍关系（trade-off）[page 14]。高灵敏度传感器通常非线性（或多区间线性）且拉伸性有限，反之亦然。以微裂纹和断连机制为基础的传感器灵敏度更高，但非线性也更强 [page 14]。

这个取舍关系是**归纳性**的：它来自对 Table 1、Table 2 中大量器件的横向比较，而不是某个受控实验的直接结论。因此它的强度应被理解为"在当前已报道的器件中普遍观察到"，而非"物理上不可能同时实现"。作者自己也没有把它表述为不可能性定理。

## 迟滞、过冲与耐久性：机制解释而非独立发现

迟滞和过冲这两节，作者主要在做机制归因，而非报告新数据。

迟滞方面，作者判断电容式总体小于电阻式和光学式，理由是电容式性能依赖电极间稳定的重叠面积 [page 14]。电阻式的迟滞则来自聚合物基底的粘弹性以及活性纳米材料与基底的相互作用；强界面结合可减小迟滞，但过强又会导致纳米材料屈曲和断裂，因此存在一个最优界面粘附 [page 15]。这是一个典型的"双向约束"论证：不是越强越好，而是有最优点。

过冲方面，作者认为电阻式通常比电容式和光学式更明显，因为聚合物基底突然受载时的应力释放会改变导电纳米材料的位置，直接影响电阻；而对电容式而言，这些内部运动对介电层介电常数影响很小 [page 15]。作者随后提出一个**推断性**建议：通过调控聚合物基底在较大应变下的分子或分子链段运动，可能最小化过冲 [page 15]。这里用了"we believe"，应视为作者的观点而非已验证结论。

动态耐久性方面，作者报告了多个器件达到 20 000 次拉伸–释放循环 [page 15]，并特别提到 CNTs/棉/TPU 芯纺纱在 40% 应变下耐久达 300 000 次循环 [page 15]。天然纤维基方面，碳化丝乔其纱/PDMS 达 10 000 次循环（Figure 8c）[page 15]。

## 应用部分：能力展示，而非性能验证

第7节按医疗健康、运动监测、交互游戏与虚拟现实、软体机器人与神经力学四个方向展示应用。这些内容主要是"某传感器能检测某信号"的演示性证据，例如：

- 贴于腕部桡动脉监测脉搏，能识别 percussion、tidal、diastolic 波 [page 16]；
- 心尖搏动图（ACG）传感器能捕捉房室瓣开闭（O、C 点）、快速心室充盈波（O–F）、缓慢充盈波（F–L）等参数，并与常规 ECG 交叉验证 [page 16]；
- 运动前后呼吸率从 12 min⁻¹ 升至 26 min⁻¹，心动周期从 0.85 s 降至 0.54 s [page 16]；
- 碳化棉织物传感器贴于喉部，对不同单词产生可区分的波形 [page 16–17]；
- 软体假手用集成光电应变传感器区分成熟与未成熟番茄 [page 18]。

需要提醒的是，这些应用演示证明的是"该器件在特定条件下能产生可读信号"，并不等于临床级或产品级的可靠性验证。作者在结论中也承认，可穿戴应变传感器"仍处于原型阶段" [page 1, page 22]。因此应用部分的证据力度应被理解为可行性展示，而非性能保证。

## 结论成立的条件与作者承认的边界

作者在第8节集中列出挑战，这些同时也是核心结论的适用边界：

1. **多方向、多平面解耦应变测量仍困难** [page 21]。这意味着当前多数器件只能测量单一方向或复合应变，无法区分应变来源。
2. **非线性与迟滞使高应变应用（如人体运动检测）的标定复杂化** [page 21]。
3. **输出信号易受压力和温度、湿度等环境因素干扰**。作者引用研究指出温湿度对 CNTs–PDMS 传感器有显著影响 [page 22]，并提到温度自补偿混合薄膜、超疏水涂层、Ecoflex 夹层等应对策略 [page 22]。
4. **与皮肤的共形粘附**是另一难题，弱界面粘附会导致滑动和分层；作者举出 PDMS 微纤维/乙烯基硅氧烷尖端实现约 18 kPa 粘附强度的例子 [page 22]。
5. **生物相容性与长期佩戴安全性**：多数器件为聚合物薄膜和平面结构，可能阻碍空气流通，增加皮肤刺激和细菌感染风险 [page 22]。
6. **系统集成困难**：无线通信、储能、电路、显示、存储等组件的紧凑可靠集成仍受制造复杂性制约 [page 22]。

这些限制中，第2、3条直接削弱了"高灵敏度"这一优势的实际价值——如果高灵敏度伴随强非线性和环境敏感性，那么它在真实可穿戴场景中的可用性就要打折扣。这是作者论证中一个隐含的转折：性能表格里的高 GF 数字，并不自动转化为实用优势。

## 总体判断

这篇综述的论证力量主要来自**分类 + 横向比较 + 机制归因**三者的配合。它没有做元分析或统计检验，Table 1、Table 2 是文献数据的汇编而非受控对比，因此"取舍关系"这一核心结论的强度是归纳性的、依赖已报道器件样本的。式4和式7提供了电容式与光学式线性行为的解析基础，是全文推理链中最"硬"的一环。

作者最终的立场是审慎的：三条路线各有明确短板——电容式拉伸性、线性度、低迟滞好但灵敏度差；电阻式灵敏度和拉伸性经材料与结构工程大幅提升，但常受迟滞和非线性困扰；光学式的短板是动态性能、长期耐久性和相对较慢的响应 [page 22]。这一结论在"可穿戴场景需要兼顾静态与动态、大应变与小应变"的前提下成立；若应用场景收窄（例如只测高频动态信号，或只测单一方向小应变），各路线之间的取舍格局可能不同。作者没有讨论这些收窄情形，因此结论的普适性应被限定在其设定的可穿戴应用框架内。
