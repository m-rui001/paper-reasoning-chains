# 碱在C-A-S-H中的摄取：一项以钙硅比为主线的实验论证

**原文题名**：Alkali uptake in calcium alumina silicate hydrate (C-A-S-H)
**年份**：2016
**DOI**：https://doi.org/10.1016/j.cemconres.2016.03.009

## 论文要解决的分歧

这篇论文的出发点不是某个空白，而是一堆互相矛盾的既有结果。作者在引言中把矛盾摆得很清楚：关于碱（K、Na）被C-S-H摄取的量，文献中既有"低Ca/Si摄取更多"的一致观察，也有关于钠钾谁优先的完全相反报道——Taylor [19] 和部分合成实验 [15] 支持钠优先，Bach等 [1] 却测到钾优先；关于铝的影响，Hong和Glasser [20] 报告C-A-S-H比C-S-H摄取显著增加，Stade [11] 报告减少，而Chappex、Scrivener [8] 和Bach等 [1] 报告无显著差别 [page 1]。作者提出的解释是：这些分歧可能来自测量误差、合成协议差异，或者碱摄取本身由多种机制控制，因而依赖碱浓度、C-S-H组成和其他离子/固体的存在 [page 1]。论文的目标就是用一个统一的合成与表征方案，把Ca/Si、Al/Si、碱种类、碱浓度、平衡时间这几个变量系统扫一遍，看哪些因素真正影响摄取。

## 核心结论与支撑它的证据链

论文的结论可以概括为一条主线加几个否定性发现。主线是：**碱摄取强烈依赖Ca/Si比和溶解碱浓度，而铝的存在、碱的种类、平衡时间都没有显著影响**。这条主线在结论部分被明确重述 [page 9]。

支撑主线的第一组证据是摄取随Ca/Si的变化。图12 [page 8] 显示在0.5 mol/L KOH、182天平衡下，K/Si随目标Ca/Si从0.6升到1.6而单调下降；图15 [page 9] 用91、182、365天三组数据重复了这一趋势，并同时给出K/Si对实测钙浓度的关系。作者给出的机制解释是：C-S-H表面硅醇基去质子化产生负电荷，钙离子和碱离子竞争补偿这些负电荷，而二价钙因更强的静电作用被优先吸附 [page 8]。因此高Ca/Si体系平衡在高钙浓度下，碱摄取被抑制；低Ca/Si体系钙浓度低，碱摄取被增强。这个机制不是本文新提出的，作者引用了Labbez等 [57] 的实验和Monte Carlo模拟以及 [58] 作为依据 [page 8]。

第二组证据是摄取随碱浓度的非线性增长。图14A [page 8] 显示低浓度时K/Si与初始KOH浓度近似线性，而在250和500 mmol/L时摄取增长明显放缓。作者用Langmuir等温线 θi = α·Ci / (1+α·Ci) 拟合，给出α = 0.0065，并解释为低浓度时可用位点远多于碱离子，高浓度时碱离子数量与去质子化硅位点总量相当 [page 8]。结论部分给出了一个具体数值：名义Ca/Si = 0.6的C-A-S-H，K/Si从10 mmol/L KOH下的0.03升到500 mmol/L下的0.27 [page 9]。

第三组证据是碱种类无差别。图13 [page 8] 把0.05和0.1 mol/L的KOH与NaOH数据并列，K/Si和Na/Si落在同一区间。作者承认文献中钠钾优先性的报道互相矛盾，但认为这些差异可能归因于高浓度下质量平衡计算的误差或实验协议，且未能在结果与方法之间找到清晰规律 [page 8]。

## 铝的角色：一个被实验否定的假设

铝的影响是论文着墨较多的一个论证转折。Hong和Glasser [20] 的假设是：SiO2被AlO2⁻取代会引入额外负电荷，为维持电荷平衡应增加碱摄取 [page 1]。本文的图12 [page 8] 直接对比了Al/Si = 0和0.05的样品，K/Si没有显著差异。作者进一步用Zeta电位证据反驳这个假设：低Ca/Si下含铝样品的Zeta电位仅略微更负，高钙下差别更小，这点负电荷增加不足以显著增强钾摄取 [page 6]。作者还指出，判断碱摄取不能只看Al³⁺与Si⁴⁺的电荷差，还要考虑羟基的去质子化倾向和钙浓度 [page 6]。这里作者对Hong和Glasser以及Stade结果的差异给出了一个方法学解释：这两项工作都未报告固相分析，而如果样品中存在无定形硅、stratlingite或katoite等其它固相，C-S-H中的硅分数会改变，从而干扰基于溶液浓度下降的间接法结果 [page 6]。这是一个基于文本的重建性推断——作者没有直接证明这些副相确实存在于那两项研究中，只是指出可能性。

## 测量方法本身是一个论证环节

论文没有把方法当作中性工具，而是把两种测量方法的差异本身作为结果来讨论。间接法由溶液碱浓度下降经质量平衡反推固相摄取量；直接法把过滤后的固体溶于HCl再测碱含量。图11 [page 6] 显示直接法给出的K/Si比间接法低20–50%。作者的解释是：水-乙醇和乙醇洗涤会带走扩散层中松散结合的碱，Viallis等 [63] 对铯离子有类似报道 [page 6]。作者选择间接法作为主方法，理由是孔隙溶液中的碱浓度影响pH和传输性质，因此包含扩散层离子的间接法更相关 [page 6]。但作者同时明确警告：高碱浓度下间接法的相对误差很大——离子色谱约10%的相对误差，在500 mmol/L KOH下对应50 mmol/L的绝对误差，换算成K/Si（以Ca/Si = 1.0计）就是0.3的误差，甚至可能导致表观负摄取 [page 3, page 6]。这个警告很重要，因为附录C中确实出现了若干负的(K或Na)/Si值（如Ca/Si = 1.4、0.05 M KOH下的−0.0060到−0.0079，Ca/Si = 1.6、0.5 M KOH下的−0.34和−0.37）[page 13–14]。这些负值不应被读作"碱被排出"，而应理解为方法误差的量级指示。

## 结构重排：摄取不是被动填充

论文的一个有意思的发现是碱摄取伴随C-A-S-H结构重组。XRD显示碱氢氧化物使平均基面间距减小：Ca/Si = 1.2时从12.7 Å降到约12.1 Å，Ca/Si = 0.8时降到约13.3 Å（图6 [page 5]）。²⁹Si NMR显示碱使Q¹相对强度增加，即dreierketten链变短（表1 [page 5]，图7 [page 6]）。表1中Ca/Si = 1.0样品在无碱时MCL为9，在0.5 mol/L KOH或NaOH下都降到5。作者的解释是：碱取代了层间和表面的部分钙，被取代的钙进入主CaO层，导致硅链重排为更多二聚体 [page 5]。图8 [page 6] 用示意图表达了这一"钙从层间向主层再分配"的过程。作者也承认，基面间距减小的精确机制目前还不清楚 [page 3–4]。

## 热力学模型的边界

作者用GEMS-Selektor和Kulik的CSHQ固溶体模型 [35] 计算了无碱体系的平衡，与实测钙、硅浓度吻合较好，说明体系接近无定形硅和C-S-H饱和 [page 5]。但加入碱后，CSHQ模型系统性高估硅浓度、低估钙浓度，因为该模型基于无碱C-S-H数据开发，未包含碱摄取 [page 5]。作者明确表示，包含铝和碱摄取的C-K-N-A-S-H子晶格固溶体模型超出本文范围，将在别处描述 [61] [page 5]。这意味着本文的结论是实验性的，其热力学解释依赖于一个尚未发表的模型。

## 结论成立的条件与未决问题

把上述证据放在一起，本文结论的适用范围可以界定如下。第一，结论建立在20 °C、水固比45、91天至1年平衡的合成体系上；作者报告平衡时间对摄取无显著影响（图15 [page 9]），但这只覆盖了91–365天，更短或更长的时间尺度未被检验。第二，碱摄取的主线结论（Ca/Si和浓度控制）在Al/Si = 0和0.05之间都成立，但Al/Si = 0.1的样品只做了²⁹Si NMR，未做系统的摄取测量 [page 2]，因此"铝无影响"的结论严格说只适用于Al/Si ≤ 0.05。第三，钠钾无差别的结论受限于间接法在高浓度下的误差，作者自己指出这可能掩盖真实差异 [page 8]。第四，结构重排的证据（XRD基面间距、NMR链长）来自有限样品，且基面间距减小的机制未被确定 [page 3–4]。第五，TGA中约400 °C的额外失重被暂定为C-K-N-A-S-H相，但XRD中无对应晶相，作者用"tentatively assigned"限定 [page 3]，这是一个待确认的物相归属。

论文没有讨论温度对碱摄取的影响（除引用50 °C的对比数据 [38]），也没有讨论氯盐、硫酸盐等其它阴离子存在时的竞争，这些是文本未覆盖的边界，不宜作为作者结论来陈述。
