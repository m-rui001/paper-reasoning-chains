# 八种正态性检验的功效比较：一项蒙特卡洛研究

**原文题名**：Comparisons of various types of normality tests（2011）
**DOI**：https://doi.org/10.1080/00949655.2010.520163

## 论文要解决的问题

正态性是许多参数统计方法的前提假设，因此分析者需要判断样本是否来自正态总体。图形方法（Q–Q 图、直方图、箱线图）虽然直观，却带有主观性，无法给出形式化的结论，于是正式的正态性检验成为必要。然而文献中正态性检验种类繁多，既有研究在检验选择、样本量、临界值来源上各不相同，导致"哪种检验最优"始终没有一致答案，反而让使用者困惑 [page 3]。

Yap 与 Sim 的做法是：从主流统计软件（SAS、SPSS、MINITAB、SPLUS、STATISTICA、STATA、MATLAB、R、IMSL 等）实际提供的检验中选出八种，在统一的模拟框架下比较它们的功效（power）。这八种是：Shapiro–Wilk（SW）、Kolmogorov–Smirnov（KS）、Lilliefors（LL）、Cramer–von Mises（CVM）、Anderson–Darling（AD）、D'Agostino–Pearson（DP）、Jarque–Bera（JB）和卡方（CSQ）检验 [page 2, page 4]。作者在引言中明确，比较的前提是各检验在真实正态分布下具有相同的 Type I error（即显著性水平 α），功效则定义为从非正态分布抽样时拒绝正态原假设的样本比例 [page 3–4]。

## 检验的分类与选择逻辑

论文按构造原理把正态性检验分为回归与相关类（SW、Shapiro–Francia、Ryan–Joiner）、卡方类、经验分布函数（EDF）类（KS、LL、AD、CVM）、矩类（偏度、峰度、DP、JB）、间距类（Rao、Greenwood）以及特殊检验 [page 4]。这一分类本身就解释了作者为何选这八种：它们覆盖了软件中最常见的几大流派，且各自代表不同的检验思想。

其中几个检验的关系值得点明，因为它们决定了后续功效差异的解释。LL 是 KS 的修正版：KS 要求原假设分布完全已知（均值、标准差给定），而 LL 在均值与标准差需从样本估计时使用，统计量形式仍是式 (4) 的最大垂直距离，只是用样本均值和标准差替代了已知参数 [page 5–6]。AD 是 CVM 的加权版本：CVM 的统计量式 (5) 对经验分布与假设分布之差的平方做等权积分，而 AD 的式 (7) 用权重 $\psi(F(x))=\{F(x)(1-F(x))\}^{-1}$ 放大尾部差异，因此对尾部更敏感，代价是临界值必须针对每个具体分布单独计算 [page 6]。DP 与 JB 都同时利用偏度 $\sqrt{b_1}$ 和峰度 $b_2$：DP 的式 (13) 是两个标准化量的平方和，JB 的式 (12) 是 $n[(\sqrt{b_1})^2/6+(b_2-3)^2/24]$，二者在正态下都近似服从 2 自由度的卡方分布 [page 7–8]。作者引用 D'Agostino 等 [13] 的观点，认为 DP 的 $K^2$ 检验在广泛的非正态分布上具有良好功效，这为把 DP 纳入比较提供了依据 [page 4]。

## 模拟设计：证据如何产生

模拟的核心逻辑是：对每个备择分布、每个样本量，生成 10,000 个样本，计算每个检验拒绝原假设的比例，即为功效 [page 4, page 8]。样本量取 $n=10(5)100(100)500, 1000, 1500, 2000$，显著性水平取 5% 和 10% [page 8]。

一个关键的方法细节是临界值的确定。作者先用 50,000 个来自标准正态的模拟样本，对每个检验、每个样本量构造经验分布，再取相应分位数作为临界值：SW 等左尾检验取 $100\alpha$ 百分位，AD、KS、LL、CVM、DP、JB 取 $100(1-\alpha)$ 百分位 [page 8]。这一步保证了各检验在正态原假设下具有相同的实际 Type I error，从而使功效比较公平——这正是引言中"所有检验应有相同 α"这一要求的落实 [page 3–4]。对 CSQ 检验，作者在满足 $c < M = 4(2n^2/z_\alpha^2)^{1/5}$ 的多个分类数 $c$ 中计算统计量，取其中最高的功效作为该检验的功效 [page 8]。这里 $M$ 的公式来自 Schorr [33]，用于限制大样本下的最优分类数 [page 7]。

备择分布被分为三组，这一分组是理解全部结论的钥匙 [page 8–10]：

- **对称短尾分布**（6 个）：$U(0,1)$、GLD(0,1,0.25,0.25)、GLD(0,1,0.5,0.5)、GLD(0,1,0.75,0.75)、GLD(0,1,1.25,1.25)、Trunc(−2,2)；
- **对称长尾分布**（8 个）：Laplace、logistic、GLD(0,1,−0.10,−0.10)、GLD(0,1,−0.15,−0.15)、$t(10)$、$t(15)$、ScConN(0.2,9)、ScConN(0.05,9)；
- **非对称分布**（10 个）：gamma(4,5)、Beta(2,1)、Beta(3,2)、CSQ(4)、CSQ(10)、CSQ(20)、Weibull(3,1)、Lognormal、LoConN(0.2,3)、LoConN(0.05,3)。

GLD 是广义 lambda 分布，其分位数函数为式 (14) $Q(y)=\lambda_1+[y^{\lambda_3}-(1-y)^{\lambda_4}]/\lambda_2$，形状参数 $\lambda_3$、$\lambda_4$ 决定偏度和峰度 [page 10]。作者用 GLD 是因为 Karian 和 Dudewicz [38] 提供了给定偏度、峰度水平下的参数表，便于系统地覆盖不同的矩特征 [page 10]。ScConN(p,b) 是尺度污染正态（以概率 p 取自 $N(0,b^2)$，以 $1-p$ 取自 $N(0,1)$），LoConN(p,a) 是位置污染正态（以概率 p 取自均值 a、方差 1 的正态，否则取标准正态）[page 10]。这些混合分布让作者能在保持对称性的同时调节峰度，或引入可控的偏度。

## 三组分布下的功效格局

**对称短尾分布**：Figure 1 和 Table 2 显示 DP 与 SW 功效最好，KS 和 CSQ 表现很差 [page 9, page 10, page 14]。以 $U(0,1)$ 为例（Table 2，$\sqrt{\beta_1}=0$，$\beta_2=1.8$），$n=50$ 时 SW 功效 0.7447、DP 0.7800，而 KS 仅 0.1618、CSQ 0.1164；$n=100$ 时 SW 0.9970、DP 0.9965，KS 0.2562、CSQ 0.7015 [page 10]。值得注意的是 Trunc(−2,2) 这一组：在 $n=10$ 到 50 时所有检验功效都接近 α（约 0.04–0.06），说明该分布与正态非常接近，检验难以区分；直到 $n=300$ 以上 DP 和 SW 才明显上升（$n=300$ 时 DP 0.819、SW 0.7884）[page 10]。这提示"短尾"并不自动意味着容易检测，截断程度决定了可检测性。

**对称长尾分布**：Figure 2 和 Table 3 显示 JB 和 DP 的功效与 SW 相当 [page 11, page 12, page 14]。以 logistic 为例（Table 3，$\beta_2=4.2$），$n=100$ 时 SW 0.2971、DP 0.3292、JB 0.3866；$n=500$ 时 SW 0.8327、DP 0.8441、JB 0.8870 [page 12]。在 $t(15)$ 上（$\beta_2=3.55$），JB 甚至略优于 SW：$n=2000$ 时 JB 0.9240、DP 0.903、SW 0.8677 [page 12]。Laplace（$\beta_2=6.0$）则显示 AD 和 CVM 在中等样本下与 SW 接近，$n=100$ 时 AD 0.8267、CVM 0.8224、SW 0.7966 [page 12]。这与 AD 对尾部加权敏感的设计一致。

**非对称分布**：Figure 3 和 Table 4 显示 SW 最强，AD 紧随其后 [page 13, page 14]。以 Lognormal 为例（$\sqrt{\beta_1}=1.07$，$\beta_2=5.10$），$n=50$ 时 SW 0.6577、AD 0.5608、JB 0.5853；$n=100$ 时 SW 0.9297、AD 0.8586 [page 14]。在 LoConN(0.2,3) 上（$\sqrt{\beta_1}=0.68$），$n=100$ 时 SW 0.9285、AD 0.9425、CVM 0.9294，三者接近 [page 14]。Weibull(3,1) 是一个有意思的对照：其偏度仅 0.17、峰度 2.73，接近正态，因此在小样本下所有检验功效都接近 α，直到 $n=1000$ 以上 SW 和 CSQ 才明显上升（$n=1000$ 时 SW 0.9279、CSQ 0.9279）[page 14]。这里 CSQ 在 Weibull 上的表现与它在其他分布上的糟糕表现形成反差，说明 CSQ 的功效高度依赖分布形状与分类方式，不宜一概而论。

## 从证据到结论的关键推理

作者的核心结论是 [page 14–15]：

1. 若怀疑分布非对称（偏斜），SW 最佳，AD 紧随其后；
2. 若分布对称且峰度低（短尾），DP 和 SW 功效好；
3. 若分布对称且样本峰度高（长尾），可用 JB、SW 或 AD。

这些结论直接来自上述三组 Table 2–4 和 Figure 1–3 的功效数值比较。推理的桥梁是：功效越高，意味着在相同 α 下越能识别出偏离正态的分布，因此对使用者越有利。作者还指出，结果支持 D'Agostino 等 [13] 关于 KS 和 CSQ 功效差的发现，也支持 Oztuna 等 [6] 关于 SW 在非正态下最强的发现，并特别说明 KS、LL 和 AD 都没有超过 SW [page 14]。

一个需要读者自己补足的推理环节是：为什么 SW 在非对称分布上特别强？论文没有直接解释机制，但从 SW 的构造看，它基于正态顺序统计量的期望与协方差（式 (1)–(2)），对分布的整体形状（包括偏度和尾部）都敏感，而不仅仅是某一个矩 [page 4]。这是分析者的重建，不是原文的明说。同样，DP 和 JB 在长尾分布上表现好，与它们直接使用峰度 $b_2$ 有关——长尾分布的超额峰度大，$b_2$ 偏离 3 明显，因此基于 $(b_2-3)^2$ 的统计量有较大功效 [page 7–8]。这也是分析者的推断。

## 结论成立的条件与边界

论文的结论有几层限制，读者需要留意。

**第一，结论绑定于所选的备择分布集合。** 作者明确说这些分布是"为覆盖各种标准化偏度和峰度值而选" [page 8–10]，但并未声称覆盖所有非正态情形。例如，Weibull(3,1) 和 Trunc(−2,2) 这类接近正态的分布，在小样本下所有检验都几乎无功效，此时"SW 最佳"的说法没有实际区分度。因此结论应理解为：在所考察的分布族和样本量范围内，SW、DP、JB、AD 相对更优。

**第二，结论绑定于临界值的模拟方式。** 作者用 50,000 个正态样本的经验分位数作为临界值 [page 8]，这保证了模拟内部各检验的 α 一致，但实际应用中使用者往往依赖软件内置的临界值或 p 值算法，二者可能不同。论文在引言中已指出不同软件对 SW 的处理方式不同（SPSS 用插值，SAS 等用 AS R94 算法）[page 3]，这意味着模拟中的"SW"特指 Royston [11] 的 AS R94 算法 [page 5]，换用其他实现可能改变数值。

**第三，CSQ 的功效定义特殊。** 作者对 CSQ 取多个分类数 $c$ 下的最高功效 [page 8]，这实际上给了 CSQ 一个"最优分类"的优势，但即便如此它在多数分布上仍表现不佳。反过来说，如果实际使用者没有优化 $c$，CSQ 的表现可能比表中更差。这一点论文没有展开讨论，属于分析者的推断。

**第四，论文只报告了 α=0.05 的详细结果。** 作者说 α=0.10 得到"相似的模式"，因此不再重复 [page 14]。这意味着结论的稳健性只在两个 α 水平上被检验，且 0.10 的具体数值未给出，读者无法核对。

**第五，论文没有讨论检验的稳健性、计算成本或小样本下的精确性。** 例如 SW 在 $n<7$ 时的行为、各检验在极端样本量下的数值稳定性，都不在讨论范围内。作者在结论中承认"工作正在进行中"，将比较基于 EDF 的检验与基于间距的检验（如 Rao 间距检验）[page 15]，说明本文的比较范围是有限的。

## 总体评价

这篇论文的贡献不在于提出新检验，而在于在一个统一的模拟框架下，用一致的 α 和统一的功效定义，对软件中最常见的八种正态性检验做了系统的功效比较。它的论证链条清晰：先按构造原理分类并选出代表，再用模拟生成临界值保证公平比较，然后在三类备择分布上分别计算功效，最后按分布类型给出推荐。关键推理步骤是"相同 α 下的功效高低决定检验优劣"，而这一步骤的成立依赖于模拟设计的内部一致性。

结论的适用边界也清楚：它适用于所考察的分布族和样本量范围，适用于 α=0.05 和 0.10，适用于作者所采用的临界值算法。超出这些条件，结论的强度需要重新评估。对实践者而言，最直接的启示是：SW 在广泛的非对称和短尾情形下表现稳健，DP 和 JB 在长尾情形下可与 SW 竞争，而 KS 和 CSQ 在多数情形下功效偏低，不宜作为首选。
