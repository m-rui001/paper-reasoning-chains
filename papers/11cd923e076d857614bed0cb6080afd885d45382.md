# 用 WRS2 做稳健统计：一篇教程论文的论证结构

**原文题名**：Robust statistical methods in R using the WRS2 package（2019，DOI: 10.3758/s13428-019-01246-w）

## 一、这篇论文想证明什么

这不是一篇提出新方法的论文，而是一篇教程式的方法推介文章。它的核心主张可以概括为一句话：**当经典推断方法所依赖的正态性与方差齐性假设无法被合理辩护时，研究者应当改用稳健方法，而 WRS2 包让这些方法在 R 中变得可用** [page 1]。

这个主张由两层支撑。第一层是**诊断性主张**：违反假设不是可以忽略的小问题，经典方法（尤其是基于均值的 ANOVA F 检验和最小二乘回归）在一般条件下可能功效偏低、置信区间不准、甚至无法刻画组间差异的真实形态；而且这种问题在大样本下依然存在，中心极限定理并不能拯救它 [page 1]。第二层是**处方性主张**：稳健方法族提供了应对框架，其代价通常很小——在正态数据下，20% 截尾均值（trimmed mean）的功效与均值几乎相同，而在有离群值时标准误可以显著更小 [page 2]。

值得注意的是作者对"检验假设再决定"这一常见策略的否定态度。他们引用 Wilcox (2017) 的综述指出，先检验方差齐性、不拒绝就假定齐性，这种做法"不能令人满意"，因为这类检验的功效不足以侦测到那些真正会造成严重后果的偏离 [page 1]。数据变换同样被判定为在一般条件下不可靠。这构成了论文的方法论立场：**不要试图修补经典方法的前提，而是换用不依赖这些前提的方法**。

## 二、从稳健位置测度到检验：论证的骨架

论文的展开顺序本身就是一条论证链：先建立稳健的位置、离散度和相关测度，再用它们替换经典检验中的均值和方差，从而构造出稳健版的 t 检验、ANOVA、ANCOVA 和中介模型。

**位置测度**部分给出了三种替代方案。截尾均值丢弃分布两端各一定比例后取算术平均，10% 截尾时有效样本量 h = 8（式 1）[page 2]；Winsorized 均值不丢弃极值，而是把它们替换为相邻的未截尾值再求平均（式 2）[page 2]；M 估计量则通过最小化一个一般化的可微损失函数（式 3）来定义，Huber 提出的 ψ 函数在 |x| ≤ K 时取 x、否则取 K·sign(x)，K = 1.28（式 4）[page 3]。作者用同一组自评数据（Dana, 1990）演示了这些测度的差异：算术均值 448.11、标准误 136.42，而 10% 截尾均值 342.71、标准误 103.27，M 估计量 285.16、标准误 52.59 [page 2-3]。这组数字直观展示了稳健测度如何压缩尾部观测的影响。

**相关测度**部分引入 percentage bend 相关 ρ_pb 和 Winsorized 相关 ρ_w，两者都是"对边缘分布中的离群值有防护作用"的 M 型测度 [page 3]。作者用 hangover 数据展示了稳健相关矩阵与 Pearson 相关的明显差异（图 1 上三角面板报告 Pearson 相关，正文报告稳健相关）[page 3-4]。这里有一个值得注意的细节：两组相关系数的比较检验（twocor）给出的置信区间是 bootstrap 得到的，p = 0.942，说明控制组与酗酒组在时间 1/时间 2 的相关上没有显著差异 [page 4]。

## 三、检验方法的推广逻辑

论文的主体是把上述稳健测度嵌入各种经典检验框架。这里的论证逻辑是一致的：**凡是经典方法用均值和方差的地方，就换成截尾均值和 Winsorized 方差**。

**两独立样本**用 Yuen 检验（式 5），其统计量是截尾均值之差除以基于 Winsorized 数据的标准误，近似服从 t 分布 [page 5]。作者特别指出，当截尾水平 γ = 0 时，该方法退化为 Welch 的不等方差 t 检验 [page 5]；而当 γ = 0.5（即比较中位数）时，标准误会变得高度不准确，因此不建议使用 [page 5 脚注 2]。这是一个重要的边界条件。足球数据的例子中，Yuen 检验给出 p = 0.4135，截尾均值差 -0.11494，95% CI [-0.405, 0.1751]，结论是两国联赛的进球数截尾均值无显著差异 [page 6]。效应量方面，Algina 等 (2005) 的稳健 Cohen's d（式 6）给出 -0.281，属于小效应；Wilcox 和 Tian (2011) 的解释性效应量 ξ（式 7-8）给出 0.155，同样偏小 [page 6]。

**配对样本**把 Yuen 检验推广为式 9，自由度变为 h-1 [page 7]。厌食症数据中，家庭治疗组的前后体重差异检验给出 t = -3.829、p = 0.00332、截尾均值差 -8.56、解释性效应量 0.6（大效应）[page 8]。分位数比较（Dqcomhd）进一步显示，体重下降在第二和第三四分位显著，但第一四分位不显著 [page 8]。

**单因素 ANOVA** 用 t1way 实现截尾均值的 Welch 型检验 [page 9]。厌食症数据的体重差异在三组间显著（F = 5.6286, p = 0.00962），解释性效应量 0.53 [page 9]。事后两两比较（lincon）显示 CBT vs. FT 和 Cont vs. FT 显著，CBT vs. Cont 不显著 [page 9]。作者在这里插入了一个方法论提醒：**做线性对比不需要先得到显著的 omnibus 检验**，研究者有特定预测时可以直接检验对比 [page 10]。

**中位数比较**（med1way）和**一般分位数比较**（Qanova）处理的是截尾均值之外的位置参数 [page 10-11]。作者指出 med1way 的一个技术问题：按附录中的自由度评估统计量会导致实际水平低于名义水平（0.05 水平下实际约 0.02-0.025），因此实现中改用模拟临界值 [page 10-11]。当数据中有大量并列值时，标准误会变得不准确，此时 Qanova 是更好的选择 [page 11]。

**高阶设计**（t2way、t3way）把上述逻辑推广到多因素情形 [page 11-15]。啤酒护目镜数据的二因素分析显示性别与酒精摄入量存在显著交互（p = 0.001），事后比较进一步定位了差异来源 [page 11-13]。三因素游泳数据的分析中，关键的 Optim:Sex 交互显著（p = 0.023），作者解释为女性中乐观者与悲观者的时间比差异不大，而男性中差异显著 [page 15]。

**重复测量和混合设计**（rmanova、bwtrim、sppba/sppbb/sppbi）处理被试内和被试间效应 [page 15-18]。hangover 数据的混合设计给出显著的组别效应（p = 0.0218）和时间效应（p = 0.0290），但交互不显著（p = 0.5790）[page 16]。essays 数据的三个 bootstrap 检验（sppbb、sppba、sppbi）均不显著 [page 16-18]。

## 四、ANCOVA 和中介：稳健方法的延伸

**稳健 ANCOVA** 是论文中方法上最有特色的部分之一。它不假设回归斜率同质，也不假设方差齐性，甚至不对回归做任何参数假设，而是对每个子组使用 running interval smoother（基于截尾均值）[page 19]。其工作原理是：对每个感兴趣的 x 值，取 X 落在 x ± f × MADN 邻域内的所有观测，计算其 Y 的截尾均值作为该点的拟合值 [page 18]。平滑参数 f 控制邻域大小，f 太小会过拟合，太大会忽略重要模式 [page 18]。

电视节目数据的分析在六个设计点上比较处理组和控制组 [page 20]。在控制多重检验后，只有 pre-test = 90 这一个点上组间差异显著（p = 0.0006）[page 20]。图 9 同时展示了非参数回归线和 OLS 拟合线，直观呈现了两者的差异 [page 20]。

**稳健中介**用 ZYmediate 实现 Zu 和 Yuan (2010) 的方法，用稳健回归（如 M 估计）替代 OLS 来估计中介模型的各条路径 [page 21]。Leerkes 数据的标准中介分析给出 ACME = 0.0531、95% CI [0.0152, 0.10]、p = 0.006；稳健版本给出中介效应 0.0513、95% CI [0.016, 0.0979]、p = 0.001 [page 21-22]。两者结论一致，作者指出在这个例子中稳健方法与 OLS 结果相似 [page 22]。

## 五、结论在什么条件下成立

论文的结论有明确的适用范围和边界。

**适用条件**方面，稳健方法应当在"经典方法所要求的分布假设无法被合理辩护时"使用 [page 22]。这不是说稳健方法在所有情况下都优于经典方法——作者明确承认"在某些情况下，稳健方法几乎没有实际差别" [page 1]。判断是否需要稳健方法的唯一已知方式是"实际使用稳健方法并与经典方法的结果比较" [page 1]。

**技术边界**方面，论文提到了若干限制。Yuen 检验不建议用于 γ = 0.5 的截尾水平 [page 5]；中位数标准误在存在并列值时可能高度不准确，此时应改用基于百分位 bootstrap 的方法 [page 2]；med1way 在样本量小时实际水平可能低于名义水平 [page 10-11]；qcomhd 建议每组至少 20 个观测 [page 7 脚注 4]；ancova 当前实现仅限于一个二分类因子和一个协变量 [page 19]；ANCOVA 中设计点附近的组样本量建议至少为 12 [page 20]。

**方法覆盖范围**方面，WRS2 的稳健 ANOVA 函数只支持完整模型（包含所有交互），更简约的模型和特定事后对比需要使用原始 WRS 包 [page 11]。对于更复杂的混合效应设计，作者建议使用 robustlmm 包；对于复杂的中介-调节结构或路径模型，建议使用 lavaan [page 22]。

**一个需要留意的技术细节**：附录中 binband 的检验统计量公式里，Storer-Kim 方法的定义使用了"Stoner–Kim"的拼写 [page 23]，与正文中的"Storer and Kim (1990)"[page 8] 不一致，这可能是笔误。此外，附录中部分公式的 OCR 提取存在符号缺失或格式问题（如式 3 的求和符号、部分上下标），在依赖这些公式进行精确计算时需要核对原文。

总的来看，这篇论文的论证力量不在于提出新理论，而在于系统性地展示了一个替代性分析框架的完整性和可操作性。它的说服策略是：先论证问题严重，再展示解决方案的广度，最后用真实数据演示每个方法的使用方式和输出解读。对于应用研究者而言，论文的价值在于降低了稳健方法的进入门槛；对于方法论者而言，论文的贡献在于把散落在 Wilcox (2017) 等文献中的方法整合为一个用户友好的 R 包。
