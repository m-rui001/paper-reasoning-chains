# 用局部条件更新重建“脏图”：Besag 的 ICM 论证

**原文题名**：On the Statistical Analysis of Dirty Pictures（J. R. Statist. Soc. B, 1986, 48(3), 259–302）

## 问题与两条信息源

论文处理的是这样一类图像重建问题：连续二维区域被划分为细密的矩形像素阵列，每个像素取有限颜色集中的一个颜色；真实着色 $x^*$ 未知，但每个像素带有一个（可能多维的）观测记录 $Y_i$，其条件分布已知。作者把可用信息分成两路：一路是记录本身，通过条件密度 $f(y_i|x_i)$ 提供关于颜色的不完美信息；另一路是“相邻像素倾向于同色或近色”这一空间先验，用一个非退化的马尔可夫随机场（Markov random field, M.r.f.）$\{p(x)\}$ 来概率化 [page 1–3]。

在 Assumption 1 下，给定真实场景 $x$，各记录条件独立，联合密度为 $l(y|x)=\prod_i f(y_i|x_i)$（式 (1)）[page 3]。Assumption 2 则把 $x^*$ 视为局部依赖 M.r.f. 的一次实现，其条件分布只依赖邻居：$P(X_i|X_{S\setminus i})=p_i(x_i|x_{\partial i})$（式 (2)）[page 4]。两路信息经贝叶斯定理合并，得到后验 $P(x|y)\propto l(y|x)p(x)$（式 (3)）[page 4]。

## 全局准则为何被放弃

按标准准则，最自然的重建有两类：一是最大化整体后验概率的 MAP 估计（式 (3)），二是逐像素最大化后验边缘概率 [page 4–5]。作者对二者都提出保留意见，理由有两条。

其一是计算量。典型场景约 $2^{16}=256\times256$ 像素，全局优化规模巨大；只有 Markov mesh 这类特殊子类例外，但作者认为这类模型在空间语境下不自然且限制性强 [page 2]。Geman 与 Geman 的模拟退火（simulated annealing）配合 Gibbs 采样器原则上能逼近全局最大，但需要极慢的降温日程和极长的运行时间 [page 4–5]。

其二是模型的大尺度性质不受欢迎。作者指出，为保证局部特征而选用的非退化场，会诱导出不良的全局行为：以两色 Ising 模型为例，当相邻像素很可能同色时，任意远距离上都存在正相关，无限格点上强烈倾向于形成无限大的单色斑块 [page 2]。这一点是理解全文转折的关键——它意味着即使 MAP 准则在数学上正确，其解也可能被先验的全局缺陷所污染。

## ICM：把全局问题拆成局部更新

作者提出的替代方案是迭代条件众数（Iterated Conditional Modes, ICM）。其单步思想很朴素：设 $\hat{x}$ 是当前的重建，只更新像素 $i$ 的颜色，取使 $P(x_i|y,x_{S\setminus i})$ 最大的颜色。由贝叶斯定理与式 (1)、(2) 可得

$$P(x_i|y,x_{S\setminus i})\propto f(y_i|x_i)\,p_i(x_i|x_{\partial i}),$$

即式 (5) [page 7]。对任何局部依赖的 M.r.f.，这一步实现起来都极其简单：只需 $y_i$ 和邻居的当前颜色。逐像素轮流更新构成一个循环；初始值通常取最大似然分类器（逐像素选使 $f(y_i|x_i)$ 最大的颜色），然后迭代固定次数或直到收敛 [page 7]。

收敛性有一个干净的论证：因为 $P(x|y)=P(x_i|y,x_{S\setminus i})P(x_{S\setminus i}|y)$，每次单像素更新都不会降低 $P(x|y)$，故收敛有保证，且收敛到 $P(x|y)$ 的某个局部极大 [page 7]。作者报告实践中收敛极快，约第六个循环后几乎没有变化。他还指出，ICM 与模拟退火中的“瞬时冻结”等价（同步更新除外），这既说明了它的来历，也说明了它放弃了什么——不再有跳出局部极大的机制 [page 7]。

## 两个模拟：证据如何支撑主张

Section 3 用两个已知场景检验 ICM，记录由独立高斯噪声叠加在颜色标签上生成，先验取最简单的非退化形式：$c$ 个无序颜色、二阶邻域，条件概率为

$$p_i(k|\cdot)=e^{\beta u_i(k)}\Big/\sum_l e^{\beta u_i(l)},$$

即式 (6)，其中 $u_i(l)$ 是 $i$ 的邻居中颜色为 $l$ 的个数，$\beta>0$ 鼓励同色相邻；重建中取 $\beta=1.5$ [page 8]。单循环 ICM 等价于逐像素最小化

$$\{y_i-\mu(x_i)\}^2/\kappa - 2\beta u_i(x_i),$$

即式 (7)：第一项让颜色均值贴合记录，第二项奖励平滑 [page 8]。

例 1 是 $90\times98$ 的三色场景，初始最大似然分类错误率 40%（Fig. 1b），六循环 ICM 后错误率低于 5%（Fig. 1c），且保留了场景下方的半岛状结构 [page 9]。例 2 是 $120\times120$ 的六色手绘场景，噪声标准差 $\sqrt{\kappa}=0.6$，初始错误率 34%；固定 $\beta=1.5$ 时，1、2、4、6 循环后错误率分别为 3.6%、2.7%、2.0%、1.7%；改用 $\beta$ 从 0.5 逐步升到 1.5 的变体后，1、2、4、6、8 循环错误率降至 6.4%、2.7%、1.3%、1.0%、0.9%（Fig. 2c）[page 10]。

这些数字支撑的核心主张是：ICM 能把空间信息有效并入记录所提供的信息，其重建质量不太可能通过对初始分类结果做直接视觉或自动平滑获得 [page 10]。但作者也明确承认例子的简化：真实场景与所假设的随机场并无直接关系，且例 2 的场景“有点不诚实”，相邻色块倾向于不取相邻颜色标签，这反而有利于恢复 [page 10]。

## 模型族与适用条件

Section 4 把先验推广到成对交互 M.r.f.：$p(x)\propto\exp\{\sum_i G_i(x_i)+\sum_{i<j}G_{ij}(x_i,x_j)\}$（式 (9)），并给出 $c$ 色分布

$$p(x)\propto\exp\Big(\sum_k \alpha_k n_k-\sum_{k\le l}\beta_{kl}n_{kl}\Big),$$

即式 (10)，其中 $n_k$ 是颜色 $k$ 的像素数，$n_{kl}$ 是颜色对 $(k,l)$ 的相邻对数；$\beta_{kl}>0$ 抑制 $k$ 与 $l$ 相邻 [page 11]。对应的单像素条件概率为式 (11)。作者强调，归一化常数一般不可解，但 MAP 与 ICM 都不需要它；ICM 被特意设计为对 $\{p(x)\}$ 的大尺度特征不敏感 [page 12]。

对无序颜色取公共 $\beta$ 得式 (12)；若颜色可交换则 $\alpha$ 相等并可置零，回到式 (6) [page 12]。若已知某两色不能相邻，可令相应 $\beta_{12}\to\infty$，但这违反 Hammersley–Clifford 定理的正性条件，此时应避免同步更新并逐循环增大该参数 [page 12]。对灰阶场景，可取 $\beta_{kl}=b_{|k-l|}$，$b$ 序列严格递增以鼓励平滑，快速达到最大值以容许突变 [page 13]。作者提到在 gamma 相机的肺、肝扫描上用过 8 或 16 灰阶，结果满意，但认为医学例子实际需要 256 灰阶，而当时缺乏相应计算设备 [page 13]。

连续强度方面，作者给出自正态（auto-normal）模型：$X_i$ 的条件密度为式 (13)，$p(x)\propto\exp(-\frac12 x^TQx)$，$Q=A^{-1}B$，要求 $Q$ 对称正定 [page 13]。若记录为均值 $x_i^*$、方差 $\kappa$ 的独立高斯，则 MAP 估计最小化式 (14)，解为 $\hat{x}=(I+\kappa Q)^{-1}y$（式 (15)）；由于式 (14) 只有单一极小，ICM 必收敛到同一解，其逐像素更新为式 (16) 的线性组合 [page 14]。作者指出，这种 MAP 与 ICM 的等价在此并不尴尬，因为高斯模型无法维持无限距离上的正相关；但式 (13) 是为平滑变化量身定做的，非线性版本显然更有实用价值 [page 14]。对鼓励强度突变的分布，作者引 Geman 与 McClure 的形式 $\phi_{ij}(z)=\beta_{ij}/\{1+(z/\delta)^2\}$，并提醒此时全局模态准则可能可疑，而 Geman 与 McClure 的漂亮结果来自梯度下降而非全局最优（脚注更正为实际使用了 ICM）[page 14]。

## 参数估计与若干推广

Section 5 处理若干复杂化。参数估计分两种情形：有训练数据时，$\theta$ 可由最大似然直接估计，但 $\phi$ 的最大似然除 Markov mesh 和简单 Ising 模型外计算上不可行，替代方案是编码法（coding method）和最大伪似然（maximum pseudo-likelihood）[page 15]。无训练数据时，作者提出交替迭代：给定当前 $\hat{x}$ 估计 $\theta$，用最大伪似然估计 $\phi$，再做一轮 ICM，循环往复 [page 15]。作者坦言该过程的收敛性质所知甚少，尤其在多参数情形，但有限经验令人鼓舞 [page 16]。

例 3 取 Fig. 2a 的 $64\times64$ 子块，初始错误率 32%。$\kappa$ 已知、$\beta=1.5$ 时六循环后错误率 2.1%，逐步增大 $\beta$ 后第八循环为 1.2%（Fig. 3c）；仅估计 $\beta$ 得 1.1%（$\hat{\beta}=1.80$，Fig. 3d）；同时估计 $\beta$ 与 $\kappa$ 仍为 1.2%（$\hat{\beta}=1.83$，$\hat{\kappa}=0.366$）[page 16]。作为对照，多数投票式局部重建在六次迭代后错误率 9.3%，收敛后 8.6%，所有真实的小像素群都被消除 [page 16]。作者还指出一个有趣后果：在 $p(x;\phi)$ 中估计参数会使恢复早期场强逐渐增大，这正好呼应了先前“逐步增大 $\beta$”的建议 [page 16]。

其他推广包括：像素重叠（记录 $Y_i$ 依赖 $x_i$ 及邻域 $v_i$ 中的 $x_j$，更新时需额外考虑 $j\in\rho_i$ 的项，计算负担轻但恢复效果下降）[page 16]；条件依赖记录（高斯情形下可用局部自正态形式，Kittler 等与 Kiiveri、Campbell 已用于卫星数据分类）[page 16–17]；块重建（以 $2\times2$ 块为单位最大化式 (17)，计算量大得多）[page 17–18]。

## 块重建的负面结果与 $\beta$ 的尺度依赖

块重建的例子值得单独看，因为它给出了一个明确的负面结果。Fig. 4a 是 $88\times100$ 的两色场景，$\kappa=0.9105$，初始错误率 30%。逐像素 ICM 固定 $\beta=1.5$ 六循环得 9%，逐步增大 $\beta$ 后 6.2%，估计 $\beta$ 后 5.7%（Fig. 6c，即 Fig. 4c）[page 18]。但 $2\times2$ 块重建固定 $\beta=1.5$ 六循环时畸变严重，错误率 13%（Fig. 4d）；最佳结果是 $\beta=0.5$ 常数，第三次迭代收敛，错误率 5.6%（Fig. 4e）[page 18]。作者由此推断：不同块大小可能需要相当不同的 $\beta$ 最优值，因为模式在不同尺度上被模仿；同理，最大伪似然估计聚焦于无序颜色的边界，对 MAP 重建可能并不合适 [page 18]。这里还有一个值得注意的细节：逐像素重建中，虽然第四循环后重建变化极小（1.5% 像素），最大伪似然估计却从 $\hat{\beta}=1.3$ 变到 1.9 再到 $\infty$（4、6、8 循环），最终落入多数投票形式 [page 18]。

## 结论的边界与作者自陈的局限

ICM 的结论在以下条件下成立：记录给定真实场景条件独立且分布已知（或可参数化估计）；真实场景的局部特征与所选 $\{p(x)\}$ 大致一致（作者只要求局部而非全局一致）[page 3]；采用异步或部分同步更新以保证 $P(x|y)$ 单调不减 [page 7]。同步更新虽更快且消除方向性伪影，但收敛不再有保证，可能出现小振荡 [page 7]。

作者在结尾明确承认，ICM 已不再有严格的数学基础：它偏离了全局准则，部分出于计算，部分为了避开 $\{p(x)\}$ 可能鼓励的不良大尺度效应 [page 20]。他进而提出一个尖锐的问题：既然 ICM 本身并不要求真正的 M.r.f.，为何还要把自己限制在真正的 M.r.f. 上？例如，能否直接把像素 $i$ 取颜色 $k$ 的条件几率取为与同色邻居数 $u_i(k)$ 成正比，而非式 (6) 的 $\exp\{\beta u_i(k)\}$，尽管后者严格来说不合法？作者只给出部分回答：坚持真正的 M.r.f. 能消除一些任意性并有助于解释 [page 20]。

其他未决问题包括：Assumption 1 及其向像素重叠的推广在实践中的相关性；每个像素有唯一真实颜色这一假设在现实中不成立（Kent 与 Mardia 允许混合像素，Hjort 与 Mohn 引入“存疑”类）；对全局重建准则的疑虑是否正当；在空间建模如此粗糙的情况下能否对重建做有效的推断陈述；真实场景中的特殊特征（如细线）应如何建模——作者指出成对交互模型对此不够，需要 Grenander 或 Geman 与 Geman 式的建议 [page 14, 20]；以及算法应如何比较，因为错误率有严重局限且不聚焦于颜色边界 [page 20]。

## 论证的关键一步

整篇论文的推理枢纽在于：作者先建立严格的贝叶斯全局框架（MAP 与后验边缘），然后论证这个框架的两个实际困难——计算不可行，以及先验的全局性质会污染解——再提出 ICM 作为放弃全局最优、只保留局部条件更新的替代。ICM 的合法性来自 $P(x|y)$ 在单像素更新下单调不减这一简单事实，而它的“无基础”也正来自同一处：它只保证局部极大，且刻意对 $\{p(x)\}$ 的大尺度行为不敏感。模拟结果（错误率从 30%–40% 降到 1%–6%）支撑了它在这些人工场景上的有效性，但作者反复提醒这些场景比实际简单，且真实场景与假设随机场并无直接关系。因此，论文的主张应被理解为：在记录条件独立、局部先验大致合理、且可接受局部最优的前提下，ICM 是一种计算上可行、对先验全局缺陷免疫的重建方法；它不声称提供全局最优解，也不声称其推断具有严格基础。
