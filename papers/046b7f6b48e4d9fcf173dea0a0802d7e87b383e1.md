# Bagging：重复抽样如何让不稳定预测器更稳
*Bagging Predictors · Leo Breiman · 1996 · Machine Learning 24, 123–140*

一棵决策树换一批训练样本，分裂点和整棵树都可能明显改变；如果把这些不同模型的预测综合起来，是否能减少测试误差？Breiman 的回答是：对这类对数据扰动敏感的学习方法，通常可以。Bagging（bootstrap aggregating）从原始训练集有放回抽取多个同样大小的 bootstrap 样本，分别训练预测器；数值预测取平均，分类预测选票数最多的类别（相对多数投票）。它用有限数据模拟“如果能重新抽到许多份训练集，模型会怎样变化”。

论文的理论解释分两层。若真的能从同一总体反复抽取独立训练集，对数值预测，把模型预测取期望不会比单次模型预测的平均平方误差更差；直观上，平均抵消了训练样本变化带来的波动。分类时，作者给出一个更强但有条件的结论：在某个输入点上，如果单个预测器预测各类别的频率排序与真实类别概率排序一致（order-correct），那么理想化的无限聚合会选择真实概率最高的类别，达到该点的贝叶斯最优分类率。这个条件不要求预测频率数值本身准确，但要求最高类别排序正确。

现实中只有一份训练集，所以算法用其经验分布代替未知总体分布，再抽取 bootstrap 样本近似重复训练。于是实际 bagging 既获得了平均带来的方差降低，也引入经验分布与真实总体之间的近似误差，且通常只计算有限个模型。两者谁占上风，取决于基学习器对样本变化有多敏感：不稳定树或变量子集选择会产生差异较大的模型，平均有机会明显降方差；稳定方法的模型本来就相近，平均收益很小，bootstrap 近似误差反而可能抵消收益。这也是论文的核心边界，而不是“集成必然提升准确率”。

实验把这一点具体化。分类树在七个中等规模数据集上的测试错误率均有所下降，例如 waveform 从 29.1% 降到 19.3%，heart 从 4.9% 降至 2.8%；在四个较大的 Statlog 数据集上，降幅从约 19% 到 77%。回归树在五个数据集上的测试均方误差降低约 21%–46%。这些不是单次划分的结果：分类实验反复随机划分训练与测试集并对 100 轮结果取平均，每轮对 50 个 bootstrap 树投票。数值支持“这些不稳定树在这些数据上受益”，但提升幅度因数据集而异；例如 diabetes 分类错误率只降低约 6%，作者认为可能因为原错误率已接近该数据集可达到的下限。

反例同样重要。最近邻分类器对 bootstrap 扰动较稳定，六个数据集上的错误率在表中完全不变。线性回归前向子集选择则呈现交叉：选择变量较少时，选择过程更不稳定，bagging 能改善误差；变量数增多、模型趋稳后，聚合可能不再有益，甚至增大误差。由此，是否使用 bagging 应结合基学习器的稳定性判断，而不是只看它是否属于某一算法类别。

论文还讨论了实用选择：在 waveform 例子中，约 10 到 25 次 bootstrap 已获得大部分收益，继续增加到 50 或 100 次几乎没有变化；将 bootstrap 样本扩大到原训练集的两倍也未见精度改善。这些是特定实验的计算成本观察，不能保证其他任务具有相同的最佳重复数。树的集成也会牺牲单棵树易于解释的结构。

因此，这篇论文建立的推理不是“重采样本身会带来更好的模型”，而是：训练数据扰动会暴露学习器的不稳定性；当这种扰动造成的预测方差足够大时，bootstrap 重训并聚合可以抵消部分波动；当基学习器稳定时，平均几乎没有方差可降，近似误差可能让结果不变或变差。理论上的不劣结论针对理想化总体聚合及特定损失/条件，实际有限样本 bagging 的效果仍需由目标数据上的独立评估确认。

## 阅读边界

实验结论来自论文报告的分类树、回归树、最近邻和线性回归子集选择及其数据集/划分方案，不代表任意模型都能获得相同增益。理想化聚合取总体期望；可运行的算法只从经验分布抽取有限个 bootstrap 样本。分类的贝叶斯最优结论还依赖 order-correct 条件。bagging 降低的是对训练样本扰动造成的变化，不能单凭该方法保证消除偏差或获得总体最优预测。
