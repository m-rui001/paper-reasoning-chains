# 高阶张量的多线性奇异值分解：HOSVD 的论证结构与适用边界

**原文题名**：A Multilinear Singular Value Decomposition
**作者**：Lieven De Lathauwer, Bart De Moor, Joos Vandewalle
**年份**：2000
**DOI/出处**：SIAM J. Matrix Anal. Appl., Vol. 21, No. 4, pp. 1253–1278

## 一、论文要解决的核心问题

矩阵的奇异值分解（SVD）是线性代数与信号处理中最有力的工具之一。当数据对象从矩阵（二阶）上升到三阶或更高阶张量时，是否存在一个"恰当的" SVD 推广？作者的核心主张是：存在，而且它就是心理测量学中早已出现的 Tucker 模型，作者将其重新命名为高阶奇异值分解（HOSVD）[page 2]。

这个主张的关键在于"恰当"二字。作者并非随意构造一个张量分解，而是从一个明确的出发点推导：**n-模向量（n-mode vectors）应当在张量分解中扮演与矩阵的列向量、行向量完全相同的角色** [page 3]。正是这个出发点决定了分解的形式——它迫使"奇异值矩阵"的角色由一个满足"全正交性"（all-orthogonality）的核张量来承担，而非一个伪对角矩阵。

## 二、为什么不能直接要求核张量伪对角

一个自然的疑问是：为什么不直接要求核张量 S 是伪对角的（即只有 $i_1=i_2=\cdots=i_N$ 时元素非零），从而最直接地模仿矩阵 SVD？作者用自由度计数给出了否定回答 [page 9]。若核张量有 $I$ 个非零元素，分解的自由度不超过 $I(\sum I_n + 1 - N(I+1)/2)$，而原始张量有 $I_1 I_2 \cdots I_N$ 个独立元素。只有当阶数为 2 且 $I=\min(I_1,I_2)$ 时两者才相等。换言之，**用正交变换把一般高阶张量化为伪对角形式，在一般情况下是不可能的**——这不是技术困难，而是自由度不够。

因此作者将条件"放松"为全正交性：核张量的任意两个固定某一索引得到的子张量互相正交（式 (6)），且这些子张量的 Frobenius 范数按索引递减（式 (7)）[page 8]。作者特别指出，"放松"一词其实过重：Property 5 表明，矩阵 SVD 本身也可以用"行/列互相正交"来定义，得到的分解与传统定义完全一致 [page 10]。所以全正交性不是对 SVD 的弱化，而是 SVD 的一个等价刻画在张量上的自然延伸。

## 三、存在性证明的关键一步

HOSVD 的存在性（Theorem 2）不是靠构造一个优化问题来证明的，而是靠**把张量分解与矩阵展开的 SVD 联系起来** [page 8, page 11]。

证明的核心逻辑是：对张量 A 的每一个 n-模矩阵展开 $A_{(n)}$ 做标准矩阵 SVD，$A_{(n)} = U^{(n)} \Sigma^{(n)} V^{(n)T}$，取左奇异矩阵 $U^{(n)}$ 作为第 n 个正交变换。然后令 $S = A \times_1 U^{(1)T} \times_2 \cdots \times_N U^{(N)T}$。关键的一步在于：由于 (15) 中的 Kronecker 因子是正交的，比较 (15) 与 (16) 可以直接推出 $S_{(n)} = \Sigma^{(n)} V^{(n)T} \times (\text{正交 Kronecker 因子})$，从而 $S_{(n)}$ 的行互相正交、行范数恰为 $\sigma_i^{(n)}$ [page 11–12]。这就同时给出了全正交性和排序条件。

这个证明结构决定了 HOSVD 的一个根本特征：**计算 N 阶张量的 HOSVD 归结为计算 N 个矩阵的 SVD** [page 12]。核张量随后由 (22) 或 (23) 算出。作者强调，这种基于矩阵展开的方式在数值上比心理测量学文献中的"操作流程"更可靠，尤其对病态张量 [page 12]。

## 四、从证据到结论：哪些矩阵性质被成功继承

作者用一整节（Section 4）论证 HOSVD 继承了矩阵 SVD 的大量性质，其论证策略几乎都是**通过 Property 12（HOSVD 与矩阵展开 SVD 的等价）把张量问题化归为矩阵问题**。

- **唯一性**（Property 4）：n-模奇异值唯一；奇异值互异时奇异向量确定到单位模因子；重根时可做酉线性组合 [page 13]。这与矩阵情形本质相同，差别仅在于归一化约定更弱。
- **n-秩**（Property 6）：$R_n = \text{rank}_n(A) = r_n$，即非零 n-模奇异值的个数等于 n-秩 [page 14]。这直接来自 Property 12 与 Property 1 的组合。作者指出这在估计"问题维度"（如源数目、滤波器长度）时可能起与矩阵秩类似的作用。
- **范数**（Property 8）：$\|A\|^2 = \sum_i (\sigma_i^{(n)})^2 = \|S\|^2$，对所有 n 成立 [page 14]。
- **定向能量**（Property 9）：极值 n-模定向能量方向对应 n-模奇异向量，极值等于对应奇异值的平方 [page 15]。
- **与矩阵 EVD 的联系**（Property 11）：$H_{(n)} = A_{(n)} A_{(n)}^H$ 的 EVD 给出 n-模奇异向量 [page 16]。

这些性质的证明都被作者归为"对 Section 3 推导的进一步分析"，关键工具始终是 Property 12 [page 17]。

## 五、两个关键边界：HOSVD 做不到什么

论文最有价值的部分之一，是作者明确划出了 HOSVD 与矩阵 SVD 的两处本质差异，这两处差异都源于核张量一般是满张量而非伪对角。

**第一，近似性质被削弱。** 矩阵 SVD 的截断给出最优低秩近似。HOSVD 的对应性质（Property 10）只给出一个**上界**：丢弃最小的 n-模奇异值后，误差满足式 (24) 的不等式 [page 15]。作者明确指出，这样得到的 $\hat{A}$ 一般**不是**在给定 n-秩约束下的最优近似。Example 5 用具体数值展示了这一点：丢弃 $\sigma_3^{(2)}$ 和 $\sigma_3^{(3)}$ 得到的近似误差为 1.0880，而真正最优的、三个 n-秩都为 2 的张量 $A'$ 的误差是 1.0848 [page 17]。差距虽小，但方向明确——HOSVD 截断不是最优的。作者补充说，若奇异值之间存在大间隙，$\hat{A}$ 仍可视为好的近似，必要时可作为进一步优化算法的初值。

**第二，秩的信息是粗糙的。** HOSVD 只能估计 n-秩，而 n-秩一般只是张量真正秩（Definition 4，最小秩-1 分解项数）的**下界** [page 5, page 14]。Example 3 给出一个 (2×2×2) 张量，三个 n-秩都等于 2，但秩等于 3 [page 5]。作者在结论中重申：HOSVD 不允许用最小秩-1 展开来解释，这是多线性代数结构固有的局限；在秩相关问题上，CANDECOMP/PARAFAC 可能更有信息量 [page 23, page 24]。

## 六、对称性如何影响分解

Section 5 处理一个在应用中极为常见的情形：张量对指标置换不变（或映射到复共轭）。高阶矩和累积量就是典型例子 [page 18]。

Theorem 3 的结论是：若张量在置换 P 下不变，则 HOSVD 的奇异向量矩阵在 P 的置换循环内相等（实对称）或交替等于复共轭（Hermite 对称）；奇数长度循环对应的奇异向量矩阵为实 [page 18]。核张量 S 具有与 A 相同的置换对称性。

由此作者定义"两两对称"（pair-wise symmetry，Definition 10）：每一对指标都由某个置换循环连接 [page 19]。对这类张量，Theorem 4 给出高阶特征值分解（HOEVD）：$A = S \times_1 U \times_2 U \cdots \times_N U$，其中所有奇异向量矩阵相同（或按对称类型取复共轭），S 保持相同的两两对称性，其子张量的 Frobenius 范数就是"N 阶特征值" [page 19]。Example 7 展示了复随机向量四阶累积量的情形，其 HOSVD 结构为 $C = S \times_1 U \times_2 U^* \times_3 U^* \times_4 U$ [page 19–20]。

作者在结论中承认一个未解决的问题：两两对称 N 阶 $(I \times \cdots \times I)$ 张量的 HOEVD 归结为一个 $(I \times I^{N-1})$ 矩阵的 SVD，但如何利用该矩阵的高度对称性加速计算，仍是开放问题 [page 24]。

## 七、扰动分析与解析性

Section 6 给出 HOSVD 的一阶扰动理论。作者首先指出一个技术困难：由于 n-模奇异值被定义为非负范数并施加了排序，在奇异值为零或奇异值交叉处，解析性可能丧失 [page 20]。为恢复解析性，作者引入"无序无号 HOSVD"（UHOSVD，Theorem 5），去掉符号和排序约定，从而保证奇异值函数是实解析的 [page 20]。

Theorem 7 给出主要结果：n-模奇异值函数的斜率由 $B$ 的对角元给出；奇异向量的一阶展开为 $U^{(n)} + \epsilon U^{(n)} \Omega$，其中 $\Omega$ 是斜 Hermite 矩阵，其元素由式中的分式给出，分母为 $\sigma_i^{(n)2} - \sigma_j^{(n)2}$ [page 21–22]。这个结构直接来自矩阵扰动理论，作者明确说 HOSVD 的扰动分析可以建立在数值线性代数已有结果之上 [page 20]。

作者给出这一分析的一个具体动机：在许多应用中（如独立分量分析），人们先验地知道某个张量可以通过酉变换化为伪对角。但由于测量误差，估计得到的张量的 HOSVD 核张量只是全正交而非精确伪对角。要分析这种偏差的影响，就需要一阶扰动结果 [page 20]。

## 八、结论成立的条件与作者承认的局限

综合全文，HOSVD 作为一个"恰当的 SVD 推广"这一结论，在以下条件下成立：

1. **"恰当"的标准是 n-模向量扮演列/行向量的角色。** 这是作者明确选择的出发点 [page 3]。若换一个出发点（例如强调最小秩-1 展开），会得到不同的分解（CANDECOMP），其与矩阵 SVD 的类比不如 HOSVD 显著 [page 22–23]。作者在 Section 7 列出了三种替代方案，并说明它们各自适用于不同问题。

2. **全正交性替代伪对角性是必要的，不是任意的。** 自由度计数表明伪对角在一般情况下不可达 [page 9]；而全正交性在矩阵情形下与伪对角等价 [page 10]。

3. **近似性质只在奇异值有大间隙时才实用。** 截断不是最优的，误差只有上界 [page 15, page 17]。

4. **秩的信息是下界，不是精确值。** n-秩一般小于真正秩 [page 5, page 14]。

5. **扰动分析要求奇异值孤立且非零，或通过 UHOSVD 去掉符号和排序约定。** 在奇异值重根或为零处，需要特殊处理 [page 20–22]。

作者在结论中坦承，HOSVD 的核心局限——核张量一般是满张量——导致两个主要差异（近似非最优、秩信息粗糙），并指出这是多线性代数结构固有的，而非 HOSVD 定义的缺陷 [page 24]。这一自我限定使论文的论证力度与其结论强度保持一致：HOSVD 是 n-模向量空间性质分析的正确工具，但不是秩相关问题的万能工具。
