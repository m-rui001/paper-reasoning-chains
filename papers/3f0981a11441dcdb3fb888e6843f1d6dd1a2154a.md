# 用高强度超声在金属3D打印中控制晶粒结构

**原文题名：** Grain structure control during metal 3D printing by high-intensity ultrasound
**年份：** 2020（Nature Communications 11:142）
**DOI：** https://doi.org/10.1038/s41467-019-13874-z

## 问题与主张

金属增材制造（AM，即金属3D打印）的熔池小、固–液界面到液态金属的温度梯度陡，凝固时倾向于逐层外延生长，而形核事件有限，因此在多数已成形金属中形成沿建造方向的柱状晶。柱状晶带来力学性能各向异性、降低力学性能并增加热裂倾向，所以用细小的等轴晶替代粗大柱状晶是金属AM的一个核心目标 [page 2]。

作者提出的解决方案是：**不改变合金成分**，在激光定向能量沉积（DED）过程中向熔池引入高强度超声，通过声空化激活熔体中天然存在的形核质点，从而实现从柱状晶到等轴晶的完全转变，并改善力学性能。作者以Ti-6Al-4V为模型合金，进一步在Inconel 625上验证方法的普适性 [page 1, page 2]。

## 超声如何进入熔池，以及它为什么"够强"

实验装置的核心是把超声换能器与建造基板合二为一：样品直接沉积在20 kHz振动的Ti-6Al-4V超声变幅杆（sonotrode）工作面上（Fig. 1）[page 2]。变幅杆材料按被打印合金选择——打印Ti-6Al-4V用Ti-6Al-4V变幅杆，打印Inconel 625则换成4140不锈钢变幅杆 [page 2, page 4]。

作者用式(1)估算变幅杆–熔体界面的名义超声强度：

$$I = \frac{1}{2}\rho c (2\pi f A)^2 \quad (1)$$

取熔融Ti的 $\rho = 4208\ \mathrm{kg\,m^{-3}}$、$c = 4407\ \mathrm{m\,s^{-1}}$，在振幅 $A = 30\ \mu\mathrm{m}$ 时 $I > 13\times10^3\ \mathrm{W\,cm^{-2}}$，比熔融轻金属的空化阈值（$I_c \approx 100\ \mathrm{W\,cm^{-2}}$）高两个数量级 [page 3]。这是整条论证链的物理前提：只有强度远超阈值，空化才可能发生，而空化是作者归因的晶粒细化主因。

## 微观结构证据：从柱状到等轴

**Ti-6Al-4V。** 无超声样品呈现数毫米长、约0.5 mm宽的柱状先β晶，横跨多个沉积层；有超声样品则是约100 μm的细小等轴先β晶（Fig. 2a–d）[page 3]。定量指标是先β晶数量密度：从 $3.3\ \mathrm{mm^{-2}}$ 增至 $65.0\ \mathrm{mm^{-2}}$，作者据此认为超声增强了凝固过程中的形核 [page 3]。晶粒尺寸与长宽比分布也发生显著变化（Fig. 2e, f）[page 3]。

**α–β组织未受扰动。** SEM显示两种样品的先β晶内部都是篮网状α–β组织，α板条厚度沿建造高度基本一致，且两组样品的α板条厚度分布无统计差异（Fig. 3e, f）[page 3]。作者据此推断：控制β→α转变的热条件基本不受超声影响，这与"该强度水平的超声不预期影响固态相变"的预期一致 [page 3]。这一步很关键——它把超声的作用限定在凝固阶段，排除了"超声改变了后续固态组织"这一替代解释。

**织构弱化。** EBSD结果显示，无超声时α相最大MUD为4.5，先β晶最大MUD为6.0，且先β晶呈强<001>取向；有超声时分别降至2.0和2.7，等轴先β晶有效避免了特征<001>织构，也未检测到其他择优织构（Fig. 4）[page 4]。这与"等轴晶结构无择优结晶织构"的理解一致 [page 4]。

## 力学性能：12%提升从何而来

拉伸工程应力–应变曲线显示，超声使屈服应力 $\sigma_y$ 和抗拉强度 $\sigma_{TS}$ 均提高约12%（例如 $\sigma_y$ 从 $980 \pm 13\ \mathrm{MPa}$ 升至 $1094 \pm 18\ \mathrm{MPa}$），两组样品断裂应变均约5%（Fig. 5a）[page 4]。作者强调这一提升是在杂质水平未增加的前提下实现的（补充表2）[page 4]。

作者进一步拆解这12%的来源，这是论证中最需要读者跟住的一步：

- 已有研究显示织构对增材制造α–β Ti-6Al-4V拉伸屈服应力的影响为3–5% [page 4]，不到观测增幅的一半。
- 作者把文献数据与本研究数据绘成屈服应力对先β晶尺寸倒数平方根 $d^{-1/2}$ 的关系图，观察到近似的Hall–Petch关系（Fig. 5c），据此推断等轴先β晶尺寸对屈服应力提升起主要作用，约贡献12%中的7% [page 4]。

这里需要区分原文明确说的与推断的：Hall–Petch拟合是作者基于文献与自身数据给出的经验关系（$\sigma_y = 710 + 3.31\,d^{-1/2}$，虚线为 $\pm0.15\sigma_0$，$\sigma_0 = 710\ \mathrm{MPa}$）[page 6]；"7%来自晶粒细化"是作者由该关系作出的归因，而非直接测量。剩余约5%的增幅，作者并未在正文中完全归因，织构弱化（3–5%）是与之量级相符的候选因素，但作者没有明确把两者相加等于12%——读者应把这一分解理解为近似而非精确闭合。

作者还指出，常见的β转变温度以下后处理（包括热等静压）不改变先β晶结构，因此超声诱导的等轴先β晶、细化晶粒和弱化织构预计能在常规后处理后保留（Fig. 5）[page 4]。这是对结论适用性的一项外推，属于作者基于文献的判断。

## 普适性验证与"可编程"晶粒结构

在Inconel 625上，无超声样品为长500 μm、宽150 μm的柱状初生γ晶，具强<001>织构；有超声样品为仅数微米（比Ti-6Al-4V更细）的等轴初生γ晶，织构接近随机（Fig. 6a–d）[page 4, page 5]。作者据此确认方法的普适性 [page 5]。

更具展示性的是，作者通过简单开关超声，制得沿建造高度呈柱状/等轴/柱状交替的梯度晶粒结构（Fig. 6e）[page 5]。这既是对"超声是晶粒结构控制手段"的直观佐证，也提示该方法可用于制造梯度晶粒结构。

## 超声场随建造高度的衰减：一个被作者主动暴露的限制

讨论部分把超声场作为建造高度 $z$ 的函数来分析。变幅杆工作面的振幅随高度变化，由波动方程描述：

$$A(z) = A_0 \cos\left(\frac{2\pi f}{v} z\right) \quad (2)$$

其中 $A_0 = 30\ \mu\mathrm{m}$，$v$ 为固态Ti-6Al-4V声速（约5000–6100 m s⁻¹）[page 5]。结合式(1)得强度随高度：

$$I(z) = \frac{1}{2}\rho c \left(2\pi f A_0 \cos\left(\frac{2\pi f}{v} z\right)\right)^2 \quad (3)$$

计算至500 mm建造高度，强度呈周期约125 mm的波动（Fig. 7b）[page 6]。对10 mm高样品，强度基本恒定且比空化阈值高两个数量级，这解释了该样品的实验观察 [page 6]。但当高度从0增至约62.5 mm（声半波长）时强度从峰值降到零，到约125 mm（声波长）又回到峰值，如此重复——意味着产生空化所需的强度会间歇性不满足 [page 7]。

作者由此指出压电换能器的局限：它无法随建造高度维持恒定振幅。建议改用可自动调谐频率的磁致伸缩换能器，配合专门设计的宽输出面开槽块状变幅杆，以在大体积AM中维持峰值强度 [page 7]。作者同时承认，增材制造零件的几何形状可能影响超声处理条件，这在制造复杂形状时可能成为实际问题，值得进一步研究 [page 7]。

## 机制归因与适用边界

作者对细化机制的归因是：在常规大体积熔体超声细化中，空化对产生大量晶核/晶粒至关重要，声流负责把它们从变幅杆区域分布到熔体其余部分；但AM熔池极小（约0.8 mm），整个熔池实际上都被超声处理，声流的分布作用可视为最小 [page 7]。DED过程为熔池中空化发生（约0.00003 s）提供了远超所需的时间，且所用强度远超按熔融Ti-6Al-4V表面张力（约1.05 N m⁻¹）估算的空化阈值 [page 7]。因此作者假定空化是观测到的晶粒细化的主因 [page 7]。这是"假定"（can be assumed），不是直接观测到的因果证明。

作者明确划出的边界包括：

- 本工作限于DED [page 7]。
- 基于线材焊接与线材AM共享基本原理，作者预期该方案可扩展到线材AM，但振动变幅杆可能破坏粉末床熔融系统铺粉后的粉层，因此对粉末床熔融，晶粒细化的接种（inoculation）路径可能更适用 [page 7]。
- 对Inconel 625的普适性验证是成功的，但对其他金属材料的适用性只是"预期"（expect）[page 1, page 7]。

## 论证的关键一步与成立条件

整篇论文的推理骨架是：**超声强度远超空化阈值（式1，Fig. 7b）→ 空化激活熔体中天然形核质点 → 先β晶数量密度大幅增加（3.3→65.0 mm⁻²）→ 柱状晶完全转为约100 μm等轴晶（Fig. 2）→ 织构弱化（Fig. 4）→ 屈服应力与抗拉强度各提升约12%（Fig. 5a），其中约7%可归因于晶粒细化（Fig. 5c）。**

关键一步在于把"晶粒细化"与"强度提升"之间的因果链坐实。作者用两条证据支撑：一是α板条厚度不受超声影响（Fig. 3），排除固态组织变化的贡献；二是Hall–Petch关系（Fig. 5c），把强度与先β晶尺寸联系起来。但需注意，Hall–Petch图混合了文献数据与本研究数据，拟合本身是经验性的，且"7%贡献"是归因而非直接测量。

结论成立的条件可归纳为：超声强度须持续超过空化阈值（这在小建造高度成立，但随高度波动，Fig. 7b）；熔池须足够小以使声流分布作用可忽略；合金须在AM中本倾向形成柱状晶且熔体中存在可被空化激活的天然形核质点。作者未讨论的是：若合金缺乏可激活的形核质点，或零件几何导致超声场严重畸变，该方法是否仍有效——这些属于文本之外的推断空间，不应冒充作者结论。

## 数据可靠性提示

提取文本中个别数值需谨慎对待：式(1)在正文中写作 $I = \frac{1}{2}\rho c (2\pi f A)^2$，但OCR显示为"$I = \frac{1}{2}\rho c 2\pi f A$"形式，缺少平方符号；结合Fig. 7b的量级（$10^3$–$10^5\ \mathrm{W\,cm^{-2}}$）与正文"两个数量级高于阈值"的表述，可判断平方项应存在，但读者应以原文为准。此外，Fig. 5c中Hall–Petch拟合式 $\sigma_y = 710 + 3.31\,d^{-1/2}$ 的系数单位未在提取文本中明确给出，不宜直接引用。
