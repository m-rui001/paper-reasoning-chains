# 可拉伸自修复导电水凝胶应变传感器：从动态交联到人体运动检测

**原文题名**：Extremely Stretchable Strain Sensors Based on Conductive Self‐Healing Dynamic Cross‐Links Hydrogels for Human‐Motion Detection（2016，DOI: 10.1002/advs.201600190）

## 一、论文要解决的问题与核心主张

这篇通讯类论文的目标很明确：现有应变传感器大多只能承受有限拉伸（通常低于 200%），而少数能拉伸到 700% 的离子型软传感器又灵敏度偏低（如 Lewis 等人的电容式传感器 gauge factor 仅 0.348 ± 0.11）[page 1]。与此同时，自修复电子器件虽已有报道，但"没有一个能拉伸超过 100%" [page 1]。作者因此提出一个组合策略：用聚乙烯醇（PVA）与四官能团硼酸根离子形成的动态氢键交联水凝胶作为基体，掺入电子导体（单壁碳纳米管 SWCNT、石墨烯或银纳米线）构成导电传感通道，夹在商用透明弹性胶带（VHB 4010）之间，做成压阻式应变传感器 [page 1, page 3]。

作者的核心结论是：这种 SWCNT/水凝胶传感器能在室温、无外部刺激（热、pH、光、催化剂）条件下快速自修复（3.2 s 内恢复 98 ± 0.8% 初始电导），可承受高达 1000% 的应变，gauge factor 达 1.51，并能用于手指、膝盖、颈部、肘部等人体运动的实时监测 [page 1, page 4, page 5]。

## 二、自修复机制：论证的化学基础

论证的起点是材料设计。作者用硼砂（borax）在低浓度（0.02 m）下水解，生成三角平面的 B(OH)₃ 和四面体的 B(OH)₄⁻。关键的一步在于：B(OH)₃ 虽能与 PVA 络合，但只能与同一条聚合物链上的相邻醇基结合，无法形成交联；真正形成 3D 网络的是四官能团硼酸根离子与 PVA 的 –OH 基团作用 [page 1–2]。作者强调，这种交联是弱氢键，既非共价键也非酯化反应，因此可以轻易断裂和重组，赋予水凝胶自修复能力 [page 2]。

这一化学图像得到两项辅助证据支撑：FTIR 显示，与纯 PVA 相比，成胶后 –OH 伸缩峰（约 3400 cm⁻¹）向高波数移动且增强，说明 PVA 羟基与硼酸根之间形成了氢键 [page 2]；流变学测量（Figure S2）显示，加入 SWCNT 后储能模量 G′ 和损耗模量 G″ 均升高，且在整个频率范围内 G′ > G″，表明两种水凝胶都呈固态行为 [page 2]。这里需要说明的是，FTIR 和流变数据来自 Supporting Information，正文只给出结论性描述，读者无法从正文直接核验具体数值。

## 三、自修复性能的证据链

自修复能力通过三条证据线展示：

**光学显微观察**（Figure 2a1–a3）：水凝胶被手术刀完全切开后，两断面迅速接触，30 s 后切口部分愈合，60 s 后完全恢复，室温下无需任何外部辅助 [page 2]。

**电阻测量**（Figure 2b）：水凝胶被完全切断时形成开路，电阻变为无穷大；两段重新接触后电阻快速下降，3.2 s 内达到稳定值。自修复效率以 Rr/Ri 计算（Rr 为恢复电导，Ri 为初始电导），3.2 s 后为 98.6% [page 2]。作者还注意到，两段刚接触瞬间电阻低于原始值，归因于水凝胶中自由离子的转移，并引用还原氧化石墨烯水凝胶中的类似现象作为旁证 [page 3]。

**循环测试**（Figure 2c）：在同一位置重复切割–愈合五次，每次效率都很高，平均为 98 ± 0.8%，时间约 3.2 s [page 3]。此外，作者用 LED 电路做了直观演示（Figure 2d1–d3）：5 V 驱动下 LED 点亮，水凝胶完全断开时熄灭，部分接触后重新点亮 [page 3]。

这条证据链的推理是：氢键的动态断裂–重组 → 宏观切口愈合 → 电导恢复 → 可重复。逻辑上比较完整，但需要注意，自修复效率的定义是电导恢复率，而非力学性能的完全恢复；作者并未声称力学性能也恢复到初始状态。

## 四、应变传感性能：从 1000% 拉伸到灵敏度

传感器结构为三明治式：SWCNT/水凝胶夹在两层 VHB 4010 胶带之间，连接两个金属电极（Figure 3a）[page 3]。作者称 1000% 的拉伸应变是当时电子应变传感器的最高值 [page 3]。

**电阻–应变关系**（Figure 3b）：在 1000% 应变下，SWCNT/水凝胶的相对电阻变化 ΔR/R₀ 达 1514%，而不含电子导体的纯水凝胶仅为 533%，前者灵敏度约为后者三倍 [page 3]。作者用抛物线方程 y = Aε² + Bε + C 拟合数据（y 为相对电阻变化，ε 为拉伸应变），无应变时 C = 0，A 定义为灵敏度因子，A 越大灵敏度越高 [page 3]。SWCNT/水凝胶的 A 值大于纯水凝胶，与实验数据一致 [page 3]。

**压阻效应的来源**：作者提出两方面——水凝胶本身的压阻性，以及 SWCNT 接触条件的变化（接触面积、接触损失、间距变化等）[page 3]。纯水凝胶的电导来自离子传导（Na⁺、H⁺）[page 3]。这里的关键推理是：电子导体（SWCNT）的加入引入了额外的、对应变更敏感的导电通路，因此灵敏度显著提升。

**Gauge factor**：SWCNT/水凝胶在 100% 应变时为 0.24，1000% 应变时增至 1.51 [page 4]。作者将其与纯水凝胶（100% 时 0.09，1000% 时 0.53）、其他压阻式传感器（200% 应变时 0.06）和电容式离子传感器（700% 应变时 0.348 ± 0.11）对比，强调其优势 [page 4]。作者也承认，有些传感器 gauge factor 远高于此，但可拉伸性差且缺乏自修复能力 [page 4]。

**弯曲与扭转**（Figure 3c,d）：弯曲角度从 0° 增至 150° 时，电阻增至原始值的 118%；扭转角小于 540° 时仍符合抛物线方程，超过 540° 后 SWCNT 在扭转点分离，电阻快速上升，两圈（720°）后增至 457% [page 4]。误差棒基于三个器件的标准差 [page 4]。

**循环稳定性**（Figure S7）：在 0%–700% 应变间循环 700 次，电阻基本恒定，波动在 10% 以内；但 700 次后波动增大，作者归因于水凝胶部分水分蒸发，并指出可通过适当封装缓解，但"寻找理想封装材料和技术超出本文范围" [page 4]。

## 五、其他导体与人体运动检测

作者将策略推广到石墨烯/水凝胶和银纳米线/水凝胶：1000% 应变下，石墨烯体系相对电阻变化 916%、gauge factor 0.92；银纳米线体系 2249%、gauge factor 2.25，但银纳米线在水和空气中易氧化，稳定性差 [page 5]。这一对比说明高性能并非 SWCNT 独有，但银纳米线的化学不稳定性是一个明确的负面结果。

人体运动检测方面（Figure 4a–d）：传感器固定在棉手套、衣物或直接贴附皮肤上，监测食指弯曲（1 Hz 重复）、膝盖不同弯曲角度（79.8°、92.5°、122.7°）、颈部弯曲和肘部弯曲 [page 5]。作者报告传感器响应快速、可区分不同弯曲角度、保持角度时电阻恒定、伸直后恢复原值 [page 5]。作者也承认信号有轻微漂移，归因于传感器滞后（hysteresis），并指出 1000% 拉伸–释放循环中滞后显著，源于 CNT 在水凝胶基体中的重排和 VHB 胶带本身的滞后；但在 100% 应变内滞后可忽略 [page 5]。阶跃应变 100% 测试显示过冲 7.4%、蠕变恢复时间 0.7 s [page 5]。

## 六、关键推理步骤与边界条件

整篇论文的论证可以概括为一条链：**动态弱氢键交联 → 室温快速自修复 → 电导可恢复 → 与电子导体复合后灵敏度提升 → 高拉伸下稳定传感 → 人体运动检测可行**。其中最关键的一步是：水凝胶本身在极端应变下无法恢复到初始状态，但作者指出"附着在 VHB 胶带上时它能很好地工作" [page 3]。这意味着器件的可拉伸性和稳定性并非完全来自水凝胶，而是水凝胶与弹性基底的协同——VHB 胶带承担了部分机械支撑和封装功能。这一协调机制是结论成立的重要前提，但作者并未详细拆解两者的力学分工。

结论成立的条件和边界包括：

- **自修复**在室温、无外部刺激下实现，但效率以电导恢复衡量，力学性能恢复程度未报告 [page 2–3]。
- **1000% 拉伸**是器件整体（含水凝胶和 VHB）的表现，水凝胶单独在极端应变下不能恢复初始状态 [page 3]。
- **循环稳定性**在 700 次以内较好，之后因水分蒸发而退化；封装问题被明确列为未解决问题 [page 4]。
- **滞后**在 1000% 应变下显著，100% 以内可忽略 [page 5]。
- **银纳米线体系**虽灵敏度更高，但氧化导致不稳定，作者未将其作为推荐方案 [page 5]。
- 人体运动检测中信号有轻微漂移，作者归因于肌肉运动差异和传感器滞后，但未做定量分离 [page 5]。

## 七、总体评价

这篇论文的贡献在于把自修复水凝胶和高拉伸弹性基底结合，在一个器件中同时实现了快速自修复、1000% 可拉伸性和可用的灵敏度，并用多种导体和多种人体运动场景做了验证。论证的强项是证据类型多样（光学、电学、流变、FTIR、循环测试、演示），且作者对局限（水分蒸发、滞后、银纳米线氧化、封装难题）有明确交代。较弱之处在于：部分关键数据（FTIR、流变、循环效率、阶跃响应）放在 Supporting Information，正文只给结论；压阻效应的微观机制（SWCNT 接触变化与离子传导的各自贡献）只有定性描述，没有定量分离；自修复效率仅以电导定义，未涉及力学恢复。这些不影响核心结论的方向，但限制了对其普适性和长期可靠性的判断。
