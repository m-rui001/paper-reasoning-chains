# KITTI-360：用三维标注换取二维稠密语义，并以此搭建跨视觉、图形学与机器人学的基准

**KITTI-360: A Novel Dataset and Benchmarks for Urban Scene Understanding in 2D and 3D**（2022，arXiv:2109.13410v2）

## 论文要解决的核心矛盾

KITTI-360 的出发点不是"再做一个更大的数据集"，而是一个具体的标注经济学问题：自动驾驶需要 2D 与 3D 一致的稠密语义，但两条主流路线各有代价。纯 2D 标注（如 Cityscapes）逐像素标注一张图可达 1.5 小时，且帧与帧之间没有物理对象层面的时间一致性；纯 3D 标注（如 SemanticKITTI）覆盖点云却放弃图像域；少数同时提供 2D 和 3D 标签的数据集（如 nuScenes）则是在两个域独立标注，等于把标注成本翻倍 [page 1][page 4]。

作者的主张是：**先在 3D 空间用简单几何基元（cuboid/ellipsoid）标注场景，再用一个概率模型把这些粗标注"转移"成 2D 像素级语义实例标签**。这样一次 3D 标注同时产出 3D 点标签、2D 像素标签，以及跨帧、跨 2D/3D 的唯一实例 ID。整篇论文的论证链条就建立在这个"以 3D 为单一标注源"的枢纽上：标注效率、时间一致性、2D/3D 一致性都是它的推论，而标签转移方法的质量则决定了这个枢纽是否真的成立。

## 标注成本：一个可核算的对照

论文给出的成本对照是全文最直接的证据之一。一个 batch 约 240 帧，3D 标注约需 3 小时，折算到每张图约 0.75 分钟；而 Cityscapes 的粗语义实例标注约 7 分钟/图，像素级精确标注约 1.5 小时/图 [page 6]。在标签转移评估中，作者进一步把账算全：若 2D 方法每 10 帧标一张，一个 200 帧 batch 需约 20 小时，而对应的 3D 标注约 3 小时，且这个收益随帧率和相机数（本数据集 4 个相机）成倍放大 [page 10]。

这里有一个容易被忽略的推理环节：3D 标注之所以便宜，不是因为单次操作更快，而是因为**一个物理对象只被标一次，却投影进多帧多相机**。作者在方法部分明确利用了这一点——静态基元 $b_n$ 在所有时间戳可见时都参与，动态基元 $b_t^m$ 只在被标注出现的时间戳参与 [page 6][page 7]。这正是"时间一致性"和"标注省时"共享的同一个机制，而不是两个独立卖点。

## 标签转移：CRF 如何把粗基元变成稠密像素标签

这是论文技术论证最密的部分，也是结论成立与否的关键。

模型在每个时间戳独立构建一个条件随机场（CRF），变量集合是当帧所有像素 $P$ 和可见 3D 点 $L$，能量函数为式 (1) [page 7]：

$$E(s)=\sum_{i\in P}\phi_i^P(s_i)+\sum_{l\in L}\phi_l^L(s_l)+\sum_{i,j\in P}\psi_{ij}^{P,P}+\sum_{l,k\in L}\psi_{lk}^{L,L}+\sum_{i\in P,l\in L}\psi_{il}^{P,L}$$

四类势函数各自承担不同的推理职责，理解它们的分工就理解了整个方法：

- **像素一元势** $\phi_i^P$（式 2）由两部分组成：一是 3D 基元投影得到的"可容许标签"硬约束 $\xi_i^P$，二是 PSPNet 在稀疏 3D 投影 + Cityscapes 上训练得到的稠密类别先验 $p_i^P$ [page 7]。这里作者做了一个重要的工程选择：单靠稀疏 LiDAR 投影学不出好的物体边界，所以引入 Cityscapes 共训，并用 UPSNet 为 car/truck/pedestrian 补充实例假设 [page 7][page 23]。
- **3D 点一元势** $\phi_l^L$（式 3）用 $\xi_l^L$ 判断点是否落在某类基元内；"sky" 无法用基元建模，于是对不交任何基元的像素射线生成"虚拟天空点" [page 7]。这一步隐含了作者明说的假设：**场景被稠密标注，每个物体都至少被一个基元包住**——这是后面所有推理的前提。
- **像素对势** $\psi^{P,P}$（式 4）是标准的双边高斯核（位置 + 颜色），鼓励标签在图像上平滑 [page 7]。
- **3D 对势** $\psi^{L,L}$（式 5）用 3D 位置和法向 z 分量约束点标签一致，法向由局部 PCA 估计 [page 7]。
- **2D/3D 对势** $\psi^{P,L}$（式 6）把 3D 点和其投影像素绑在一起，但只对"可能可见"的点生效——作者用 ball-pivoting 网格化点云，只取网格前方的点 [page 8]。

**关键推理步骤**在于：单个势函数都不足以产生稠密准确标签，但把它们联合起来，粗基元提供的空间约束、神经网络的边界先验、以及 2D/3D 之间的相互校验可以互补。这一点由消融实验直接支撑（表 3，[page 10]）：从仅用外观分类器 LA（mIoU 67.6）出发，逐步加入 3D 点项（70.4）、像素对势（66.6，单独加入反而下降）、3D 基元约束（76.8）、3D 点+2D/3D 项（78.2），最终全模型达 81.2。作者特别指出，**最大的单项提升来自"3D 点与图像像素之间的关系"**，即 $\phi^L$ 与 $\psi^{P,L}$ 的联合作用 [page 10]。这正好印证了方法设计的核心直觉：价值不在 3D 或 2D 任一侧，而在两者的耦合。

推理用平均场近似 + 多场双边滤波（推广 [55] 到 P、L、P↔L 三组稠密连接变量）[page 8]。参数通过经验风险最小化、单变量 logistic 损失（式 7）学习，用 ADADELTA 优化、batch 16 [page 8][page 9]。由于模型是概率的，作者还能计算每个像素/点的标签熵作为不确定性估计——这不是装饰，而是被后续基准直接用作评估权重（见下）。

## 转移质量：与基线的对照说明了什么

表 2 [page 9] 是核心的定量证据。静态物体上，本方法 mIoU 81.2 / Acc 93.1，显著高于所有 2D 标签传播基线（Label Prop. 49.0、Sparse Track.+GC 51.2、3D Prop.+GC 72.1、Fully Conn. CRF 63.6、PSPNet 67.2）和所有 3D→2D 基线（3D Primitives+GC 49.4、3D Mesh+GC 66.8、3D Points+GC 72.6）。动态物体上，本方法 mIoU 63.5 / Acc 94.1，同样领先（Label Prop. 37.2、Sparse Track.+GC 仅 8.2、3D Prop.+GC 14.5）[page 9]。

这里有两个值得读者注意的论证细节。第一，作者坦承一个"反直觉"结果：通用的全连接 CRF 在静态物体上不输于专用标签传播方法，原因是光流在街道场景中因大位移、透视畸变、无纹理区域和光照变化而失效 [page 10]。这实际上削弱了"2D 传播"路线的说服力，间接支持了 3D 标注路线。第二，PSPNet 取得了最高 Acc 但 mIoU 更低，作者解释为它在大物体（如 Building）上强、在稀有类（Trailer、Gate）上弱 [page 10]——这说明单一指标会掩盖类别不均衡，读者不应只看 Acc。

**不确定性是否能筛出更可靠的标签**是另一条证据。作者按标签边缘分布的熵排序，只保留最确定的 70% 像素时，静态语义 mIoU 升至 94.3、准确率升至 98.4（表 3 下半，[page 10]）；实例分割也从 83.7 升至 92.7（表 11，[page 26]）。这表明熵能够把相对可靠的区域排在前面，作者据此称其不确定性估计“校准良好”。不过，这组选择性结果直接展示的是置信度排序的有效性；它本身没有检验概率数值与实际正确率是否逐档吻合。作者随后把不确定性用于伪标签的置信度加权评估，这一用途与上述排序结果相符 [page 10][page 24]。

## 从数据集到基准：结论的边界在哪里

作者用转移方法生成了 2×78k 张 2D 语义/实例图、1.0B 3D 语义点、172.4M 3D 实例点 [page 11]，并据此建立三类基准。这里必须区分**哪些是数据集贡献、哪些是方法结论**：

- **2D/3D 语义与实例分割、3D 检测**（表 4a–e，[page 12]）：这些是"在给定观测上直接推理"的任务，基线表现尚可。一个有意思的对照是：3D 语义分割（PointNet++ mIoU 35.7）明显弱于 2D 语义分割（PSPNet 64.9），作者据此推断解析不规则 3D 点云仍更难 [page 12]；而实例分割结论相反——3D 方法在 Car 上更好、在 Building 上更差，作者假设是因为 2D 中遮挡影响大、而 3D 中空间相连的建筑边界难分 [page 12][page 13]。这些是**基于基线表现的推断**，作者用 "we hypothesize" 措辞，读者不应读成定论。
- **语义场景补全、新视角合成、语义 SLAM**（表 4f、表 5、表 6，[page 12][page 14][page 15]）：这些是"需要联合恢复几何、外观与语义"的任务，所有基线都表现不佳。作者的核心结论是：**当任务要求联合推断而非直接观测时，现有方法远不够用** [page 16]。这是全文最有分量的判断，但它依赖的是作者自己实现的基线（如编码器-解码器、两阶段 PSPNet），而非社区公认的 SOTA，因此强度应限定为"在这些基线设定下"。

## 结论成立的条件与作者承认的局限

把散落在各处的限定条件集中起来，可以看清这套论证的适用边界：

1. **"场景被稠密标注"是硬假设**。虚拟天空点的构造、基元作为标签上界，都依赖每个物体至少被一个基元包住 [page 7]。若标注有遗漏，推理会系统性出错。
2. **动态物体是薄弱环节**。作者明确承认：动态点按基元跨帧累积，基元轻微错位会导致累积不准；可形变物体（Rider、Person）累积后点云噪声大 [page 10]。这解释了动态 mIoU（63.5）低于静态（81.2）。
3. **远距离与多孔物体是已知失败模式**。定性结果显示，远处建筑因缺 3D 点而错，栅栏/树等多孔物体边界本身标注就有歧义 [page 11]。作者用置信度图显示这些区域确实被标为低置信——即模型"知道自己不知道"。
4. **多帧联合推理未带来可测收益**。作者试过跨相邻帧推理，但"未观察到可测量的改进"，因此最终每帧独立推理 [page 6]。这是一个**负面结果**，值得如实记录：时间一致性来自共享的 3D 标注，而非帧间联合优化。
5. **基准结论受基线选择限制**。新任务的基线多为作者自建，结论"任务很难"成立，但"哪种方法更好"尚无社区共识。

## 总体判断

KITTI-360 的论证力量集中在一点：它把"标注"从 2D 像素域搬到 3D 物体域，用一个 CRF 把粗基元、神经先验和 2D/3D 耦合统一起来，从而在**同一份标注**上同时获得效率、时间一致性和跨域一致性。消融实验（表 3）和不确定性校准（表 3 下半）为这个枢纽提供了直接证据，与 2D/3D 基线的对照（表 2）则说明它确实优于替代方案。至于它开启的新基准，其价值不在于证明某个方法好，而在于用一组表现不佳的基线标定出"联合几何-外观-语义推断"这一空白地带——作者对此的措辞是谨慎的（"much harder"、"requires further research"），读者也应把结论限定在"在这些基线设定下、在这些任务上"。
