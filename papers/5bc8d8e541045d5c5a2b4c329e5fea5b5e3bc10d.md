# 用更少的参数换取更稳的分割：MultiResUNet 对 U-Net 的两处结构性改造

**原文题名**：MultiResUNet: Rethinking the U-Net Architecture for Multimodal Biomedical Image Segmentation
**年份**：2019（arXiv:1902.04049v1）
**DOI**：无（arXiv 预印本）

## 论文想解决什么

U-Net 是医学图像分割领域事实上的标准架构，作者并不否认这一点。他们的出发点是：在大量多模态医学图像上反复实验后，经典 U-Net 在某些方面"似乎有所欠缺"（seems to be lacking in certain aspects）[page 1]。论文的目标不是推翻 U-Net，而是识别出两个具体的结构性问题，各给一个修改方案，合成新架构 MultiResUNet，并在五类差异很大的数据集上验证它是否稳定优于 U-Net。

核心结论可以概括为一句：MultiResUNet 在全部五个数据集上都超过了 U-Net，而且参数量还略少；在"理想图像"上提升很小，在"困难图像"上提升显著 [page 1][page 13-14]。

## 两处改造分别针对什么

### 改造一：MultiRes block——应对尺度差异

作者的第一个观察是医学图像中待分割目标（细胞核、器官、肿瘤等）尺度变化很大，图 2 用 ISIC-2018 的皮肤镜图像展示了小、中、大三种病灶 [page 5]。U-Net 在每个池化/反卷积之后固定使用两个 3×3 卷积，而按作者引用的观点，两个连续的 3×3 卷积在感受野上近似一个 5×5 卷积 [page 5]。也就是说，U-Net 在每个层级上只用一个固定尺度的"视角"看图像。

改造思路借自 Inception：并行使用 3×3、5×5、7×7 卷积，再把输出拼接（图 3a）[page 5-6]。但并行大卷积核显存开销大，于是作者把 5×5 和 7×7 分解为连续的 3×3 卷积块——第二个和第三个 3×3 块的输出分别近似 5×5 和 7×7 卷积（图 3b）[page 6]。最终形态（图 3c）还做了两件事：三个卷积层的滤波器数从 1 到 3 逐渐增加（避免前层显存需求向深层二次放大），并加入残差连接和 1×1 卷积 [page 6]。

这里有一个值得注意的推理链：作者声称"紧凑块的结果与显存密集的 Inception 式块非常接近"，依据是"视觉网络相邻层应当相关"这一来自 [34] 的论点 [page 6]。这是一个基于类比的论证，而非本文自己给出的消融数据——论文没有报告 Inception 式块与紧凑块之间的定量对比。

### 改造二：Res path——弥合语义鸿沟

第二个观察更微妙。U-Net 的跳跃连接把编码器池化前的特征直接拼接到解码器反卷积后的特征上。作者指出，编码器这一侧是浅层特征（低层），解码器那一侧是深层特征（高层），两者经过的处理量不同，因此存在"语义鸿沟"（semantic gap）[page 6-7]。直接拼接这两组"可能不兼容"的特征，可能在训练中造成不一致，损害预测。

作者的假设是：鸿沟的严重程度随跳跃连接由外向内递减——因为越靠内的连接，编码器特征经过的处理越多，而解码器特征来自越浅的层 [page 7]。因此 Res path 的设计是：在跳跃连接上加入一串带残差连接的卷积层，先对编码器特征做额外非线性变换，再与解码器特征拼接（图 4）[page 7]。并且 Res path 的卷积块数量也由外向内递减，依次为 4、3、2、1 [page 8]。

## 架构参数如何对齐

为了让比较公平，作者用 $W = \alpha \times U$ 控制 MultiRes block 的滤波器数，其中 $U$ 是对应 U-Net 层的滤波器数（[32, 64, 128, 256, 512]），$\alpha = 1.67$ 使参数量略低于 U-Net [page 8]。块内三层滤波器数依次为 $\lfloor W/6 \rfloor$、$\lfloor W/3 \rfloor$、$\lfloor W/2 \rfloor$ [page 8]。最终 2D 模型参数量为 7,262,750，U-Net 为 7,759,521；3D 模型为 18,657,689 对 19,078,593（表 3）[page 11]。这个"参数更少却更好"的对照是论文论证力度的重要来源。

## 证据如何支撑结论

实验设计上，作者选了五类差异极大的数据集（表 2）[page 11]：荧光显微镜（Murphy Lab，97 张）、电子显微镜（ISBI-2012，30 张）、皮肤镜（ISIC-2018，2594 张）、内窥镜（CVC-ClinicDB，612 张）、MRI（BraTS17，210 HGG + 75 LGG，3D）。每个数据集做 5 折交叉验证，记录 150 轮中验证集上的最佳结果 [page 13]。评价指标是 Jaccard Index（式 4），作者明确选择它是因为它能同时惩罚欠分割和过分割 [page 12-13]。损失函数是二值交叉熵（式 2、3），优化器 Adam，无领域特定的预处理或后处理 [page 12]。

主要定量结果在表 4 [page 14]：内窥镜相对提升 10.1465%，皮肤镜 5.065%，荧光显微镜 2.6326%，MRI 1.4104%，电子显微镜 0.6161%。作者自己的解读是：提升幅度与图像难度正相关——图像越"不理想"，MultiResUNet 的优势越大 [page 19]。

除主表外，论文用四组定性证据补充论证：

- **收敛速度**（图 6）[page 15]：MultiResUNet 在所有数据集上收敛更快，且标准差更小。作者将此归因于残差连接与批归一化的协同 [page 14]。电子显微镜数据集上 MultiResUNet 初期落后但最终反超。
- **模糊边界**（图 7、8）[page 15-16]：边界清晰时两者接近（J.I. 0.9678 vs 0.9697），边界模糊时 U-Net 欠分割或过分割，MultiResUNet 明显更好。
- **扰动免疫**（图 9）[page 16-17]：前景不均匀时 U-Net 输出碎片化区域，背景粗糙时 U-Net 误判，前景背景差异极小时 U-Net 完全漏检。作者特别提到，在加入 Res path 之前，他们的模型也受这类扰动影响，因此推测 Res path 的额外非线性操作是鲁棒性的来源 [page 16]。这是一个基于实验过程观察的因果推测，不是受控实验的结论。
- **离群点拒绝**（图 10）[page 17]：荧光显微镜图像中有与细胞核视觉相似的亮颗粒，U-Net 将其误判为细胞核，MultiResUNet 能拒绝。作者指出这类误判对 Jaccard Index 影响不大（0.9317 vs 0.9643），但实际意义重要。

## 一个作者主动暴露的度量局限

第 7.6 节处理了一个对结论有实质影响的问题。电子显微镜数据集中，待分割区域占图像大部分（多数类），这导致 Jaccard Index 被"膨胀" [page 17-18]。图 11 显示：U-Net 和 MultiResUNet 的 Jaccard Index 很接近（0.8841 vs 0.8914），但视觉上 MultiResUNet 捕捉到了 U-Net 遗漏的细分离线和背景像素簇 [page 18]。作者据此承认，在这个数据集上"指标层面的提升不令人满意，但预测的分割在视觉上更准确" [page 18]。

这是论文中最重要的自我限定：当待分割区域是多数类时，Jaccard Index 不是准确性的良好代表。这也意味着表 4 中电子显微镜那一行 0.6161% 的相对提升，可能低估了实际分割质量的差距——但反过来说，其他数据集上的提升数字也可能受到类似度量偏差的影响，论文没有逐一检查。

## 结论在什么条件下成立

论文的结论有明确的适用边界，部分由作者说明，部分需要读者自己识别：

**作者明说的限制**：分割结果"并不完美"，只是在多数情况下大幅优于 U-Net [page 19]；参数量对齐是刻意约束，未来需要更详尽地搜索超参数 [page 19]；未使用领域特定的预处理/后处理，作者认为结合这些会进一步提升性能 [page 19]。

**从实验设计可以推出的边界**：所有图像都被降采样到 256×256 或更小（MRI 降到 80×80×48）[page 9-11]，因此结论严格来说适用于这些分辨率下的分割任务，不能直接外推到原始分辨率。5 折交叉验证的数据集规模差异很大（电子显微镜仅 30 张），小数据集上的折间方差可能较大，表 4 中电子显微镜的标准差（±0.7741 和 ±0.7071）相对于提升幅度（0.6161%）不可忽略。

**推断性边界**（分析者重建，非原文结论）：论文将 MultiResUNet 的优势归因于 MultiRes block 的多尺度能力和 Res path 的语义弥合，但没有做消融实验分别量化两个组件的贡献。第 7.4 节提到"加入 Res path 之前模型也受扰动影响"，这是唯一接近消融的观察，但它是过程性描述而非受控对比。因此，"哪个改造贡献了多少"在本文中没有被独立验证。

## 总体判断

这篇论文的论证结构是清晰的：两个结构性观察 → 两个对应改造 → 参数对齐的对照实验 → 五数据集验证 + 四组定性分析 → 一个度量局限的自我暴露。最有说服力的证据是"参数更少却全面更好"这一对照，以及困难图像上定性差异与定量提升方向一致。最需要保留的是：提升幅度的归因（哪个组件起作用）未被消融实验分离，电子显微镜数据集上的指标被作者自己指出不可靠，以及所有结论都建立在降采样后的图像上。作者对 MultiResUNet 作为"U-Net 潜在继任者"的定位 [page 19] 是一个有待后续工作检验的期望，而非本文已经证明的结论。
