# 分子磁体中的量子计算：用单脉冲多光子操控自旋态实现 Grover 搜索

**原文题名：** Quantum computing in molecular magnets
**作者：** Michael N. Leuenberger & Daniel Loss（巴塞尔大学）
**年份：** 2001（收稿 2000-11-24，接受 2001-02-14）

## 一、作者要证明什么

这篇论文的核心主张是：分子磁体（molecular magnets）可以作为实现 Grover 搜索算法的物理平台，并且由此可以构建高密度、高效率的存储器件。具体而言，作者提出用单个分子磁体的大自旋（如 Fe₈ 和 Mn₁₂ 的基态自旋 s = 10）的 2s+1 个自旋本征态作为计算态，通过一次包含多个匹配频率的相干磁脉冲，同时相干地布居和操控多个自旋态，从而完成 Grover 算法的读入（read-in）、解码（decoding）和读出（read-out）三个步骤 [page 1, page 2]。

这里需要先厘清一个关键的概念区分。Grover 算法本身只需要单粒子量子态的叠加，而不需要多粒子纠缠 [page 1]。分子磁体恰好提供了一个"天然的单粒子系统"：每个分子磁体单元表现为一个具有大自旋 s 的单自旋，其自旋本征态就是天然的计算基态。而单晶中大量（约 10¹² 到 10¹⁵ 个）几乎独立的分子磁体单元则提供了磁矩的天然放大，使得读出成为可能 [page 2, page 11]。

## 二、论证的起点：为什么不能直接用常规 ESR

论证的张力从一开始就很明确。Grover 算法要求所有计算态的布居幅度大致相等（可能带有不同相位），这意味着从初始态 |s⟩ 到各个态 |m⟩ 的跃迁幅度必须可比。但常规电子自旋共振（ESR）中，磁偶极跃迁只能以 Δm = ±1 的离散步长发生，选择定则排除了单步跨越两个或更多 ℏ 的跃迁 [page 2]。

一个自然的想法是用微扰论计算多光子虚跃迁。但作者指出，如果要求所有 k-光子跃迁（k = 1, 2, …, s−1）具有相同量级的幅度，那就要求微扰展开中 V¹, V², …, V^{s−1} 各阶项都可比——这恰恰意味着微扰论失效 [page 3]。这是论证中一个关键的转折点：作者没有回避这个困难，而是通过改变方案来绕过它。

## 三、关键一步：让所有跃迁幅度处于同一微扰阶

作者的解决方案是：不要求所有 k-光子跃迁幅度相等，而是让从 |s⟩ 到 |m⟩（m = 1, 2, …, s−1）的所有跃迁幅度都处于**同一微扰阶** V。这样微扰论仍然可用 [page 3]。

这个方案能成立的前提是**能级非等距**。分子磁体由于磁各向异性，能级天然非等距（与谐振子势不同）。作者利用这一点，选择一组计算态 m = m₀, m₀+1, …, s−1，其中 m₀ = 1, 2, …, s−1，则需要用到第 n = s − m₀ 阶微扰才能得到第一个非零贡献 [page 3]。以 s = 10, m₀ = 5 为例，n = 5，对应五阶过程，如图 2 的 Feynman 图所示 [page 3, page 12-13]。

具体机制是：低频场 H_z(t) = H₀(t)cos(ω₀t)e_z 沿易轴施加，通过 V_low(t) = gμ_B H₀(t)cos(ω₀t)S_z 耦合到自旋 [page 4, 公式 (1)]。这个场的 π 光子只提供能量、不传递角动量（Δm = 0），即产生虚跃迁。高频横向场则提供 σ⁻ 光子，传递角动量（Δm = −1），只作用于左势阱 [page 4, 公式 (2)]。通过精心选择频率使各阶失配恰好由 ω₀ 补偿（ℏω_m = ε_m − ε_{m+1} + ℏω₀），可以使得 j < n 阶的 S 矩阵元为零（能量不守恒，共振条件不满足），而 j > n 阶的贡献可忽略 [page 5]。

## 四、从 S 矩阵到可实验检验的数值

作者用 S 矩阵的微扰展开 [page 5, 公式 (3)] 计算了跃迁幅度。对于矩形脉冲，得到 m ≥ m₀ 时的 n 阶 S 矩阵元 [page 5, 公式 (4)]。这个表达式的结构值得注意：它包含对称因子 Ω_m = (m−m₀)!、Feynman 图的乘积项、以及宽度为 1/T 的 δ 函数 δ^{(T)}(ω)，后者保证 ωT ≫ 1 时的整体能量守恒（共振条件）[page 5]。

从"各态布居幅度大致相等"的要求 |S_{m,s}^{(n)}| ≈ |S_{s-1,s}^{(n)}| 出发，作者反推出所需的场幅度比 [page 6, 公式 (5)]：

|H₈/H₀| = 0.04, |H₇/H₀| = 0.25, |H₆/H₀| = 0.61, |H₅/H₀| = 1.12

这些比值彼此相差不大，作者将其归因于公式 (4) 中 (−1)^{q_F} 因子带来的部分抵消 [page 6]。这一点对实际应用很重要：如果所需场幅度差异悬殊，实验实现会困难得多。

接着作者估算跃迁速率 [page 6, 公式 (6)]，并代入具体参数：当 ω₀ = 5×10⁸ s⁻¹, T = 10⁻⁷ s, H₀ = H₉ = 20 G 时，w_{5,10} = 9×10⁶ s⁻¹，与寿命 τ_d 同量级（Tw_{5,10} = 1）；若取 ω₀ = 5×10⁷ s⁻¹, T = 10⁻⁷ s, H₀ = H₉ = 2 G，则 w_{5,10} = 9×10⁴ s⁻¹，Tw_{5,10} ≈ 0.01 [page 6]。作者据此论证所需场幅度和频率在实验上可达。

## 五、Grover 算法的三步实现

**读入（Read-in）：** 从基态 |s⟩ 出发，施加包含 n 个高频场和低频场的相干脉冲，通过选择相对相位 φ_m = 0 或 π 来编码二进制数。例如编码 13₁₀ = 1101₂ 时，需要 φ₉ = φ₈ = φ₇ = 0, φ₆ = φ₅ = π，其中态 m = 9,8,7,6,5 分别代表二进制位 2⁰, 2¹, 2², 2³, 2⁴ [page 7]。这样可存储 0 到 2ⁿ 之间的任意整数。

**解码（Decoding）：** 施加一个通用单脉冲，使 S_{m,s}^{(n)} = −η（m ≠ s−1），S_{s-1,s}^{(n)} = 2η，η > 0 [page 7]。这个脉冲放大翻转的位（幅度 −η），抑制其余位（幅度 +η）。累积误差约为 nη²，需小于 1，因此要求 n ≪ 1/η₀²，其中 η₀ 是探测精度 [page 7]。作者指出，即使各位幅度不同（但量级相近），解码仍然有效。

**读出（Read-out）：** 用脉冲 ESR 进行标准谱学测量。由于能级非等距，通过观察受激发射和受激吸收可以唯一确定被标记的能级 [page 7-8]。对于多个被标记态，吸收/发射强度由公式 (7) 给出 [page 8]。

整个 Grover 算法（读入、解码、读出）需要三个后续脉冲，每个持续 T，满足 τ_d ≫ T ≫ 1/ω₀, 1/|ω_{m-1,m} − ω_{m,m+1}| [page 8]。对 Mn₁₂ 而言，这给出约 10 GHz 的"时钟速度"，整个流程可在约 10⁻¹⁰ s 内完成 [page 8]。

## 六、存储容量的扩展与边界条件

作者进一步指出，由于两个势阱可以分别通过顺时针和逆时针旋转的磁场独立访问，单个分子磁体可表示一个两位数字。每位最多可存储 N = 2^{s-1} 个元素，因此自旋 s = 10 的单晶可存储 0 到 2^{2s-2} = 2.6×10⁵ 之间的数 [page 8]。如果可区分 M > 2 个相位，则可存储 0 到 M^{2s-2} 之间的数 [page 8]。Grover 搜索算法所需的实验开销仅涉及 log_M N 个频率的控制 [page 8]。

## 七、结论成立的条件与作者承认的局限

这篇论文的论证力度依赖于若干明确的假设和边界条件，作者在正文和图注中都有交代：

**能级非等距是方案成立的必要条件。** 图 2 的说明明确指出，如果能级等距，多光子吸收方案就不成立，因为共振会在更低阶的 S 矩阵中出现，导致能级的非相干布居 [page 13]。分子磁体的各向异性恰好提供了这种非等距性。

**隧穿必须被抑制。** 通过施加偏置场 δH_z 使 gμ_B δH_z > E_{mm'}，隧穿可以被完全抑制，H_T 可忽略 [page 11]。

**温度必须足够低。** 作者假设温度低于 1 K，使得自旋-声子相互作用导致的跃迁可以忽略 [page 11-12]。在此条件下，Fe₈ 和 Mn₁₂ 的能级寿命估计约为 τ_d = 10⁻⁷ s，主要受超精细和/或偶极相互作用限制 [page 12]。

**脉冲持续时间必须短于能级寿命。** 即 T < τ_d，这是相干操控的前提 [page 5]。

**自旋不能无限增大。** 作者明确承认，自旋越大，退相干越快，行为越经典，因此这类自旋系统不能标度到任意大的 s [page 9]。但这不影响用给定 s 的自旋系统构建高密度存储器件。

**方案不限于分子磁体。** 作者指出，该方案适用于任何具有非等距能级的电子或核自旋系统 [page 8]。

## 八、论证的整体评价

这篇论文的论证结构是：从 Grover 算法的物理要求出发，识别出常规 ESR 选择定则带来的根本障碍，然后通过"让所有跃迁处于同一微扰阶"这一关键设计绕过障碍，再用 S 矩阵微扰论给出定量预测，最后用具体参数估算证明实验可行性。论证的强度在于它没有停留在定性描述，而是给出了可检验的数值预测（场幅度比、跃迁速率、时钟速度）和明确的适用条件（非等距能级、低温、抑制隧穿、脉冲短于寿命）。

需要指出的是，论文中"从未有实验或理论尝试表明 s > 1/2 的自旋系统状态可以被相干布居"这一说法 [page 2] 是作者在其知识范围内的判断，属于 2001 年时的研究现状陈述。此外，公式 (4) 和 (6) 中的具体数值（如 p_{5,10} 的值）在提取文本中未完整给出，读者若需验证数值细节需查阅原文。图 2 中关于"更强磁场下原则上可以产生 s 与 s−1、s 与 s−2、s 与 s−3 等态之间 Rabi 振荡的叠加"的说法标注为"待发表" [page 13]，属于作者预告的后续工作，不在本文论证范围之内。
