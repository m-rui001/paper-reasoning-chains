# 稀疏约束线性反问题的迭代阈值算法：从代理泛函到收敛与稳定性

**原文题名**：An iterative thresholding algorithm for linear inverse problems with a sparsity constraint
**作者**：Ingrid Daubechies, Michel Defrise, Christine De Mol
**年份**：2003（arXiv:math/0307152v1）

## 问题与主张

论文处理的是线性反问题 $Kf = g$，其中 $K$ 是 Hilbert 空间 $H$ 到 $H'$ 的有界线性算子，观测 $g = Kf + e$ 带有噪声 $e$。经典 Tikhonov 正则化通过最小化 $\|Kf-g\|^2 + \mu\|f\|_H^2$ 来稳定求解，但作者指出这种方法有两个结构性缺陷：它产生线性估计，且对算子 $K$ 的奇异值分解施加"一刀切"的截断，与数据无关 [page 3]。当真实对象在某个正交基下具有稀疏展开（例如小波基下的分段光滑图像）时，这种平滑化会抹掉尖锐特征。

作者的核心主张是：将二次惩罚替换为系数在任意正交基 $(\phi_\gamma)_{\gamma\in\Gamma}$ 下的加权 $\ell^p$ 惩罚（$1\le p\le 2$），

$$\Phi_{w,p}(f) = \|Kf-g\|^2 + \sum_{\gamma\in\Gamma} w_\gamma |\langle f,\phi_\gamma\rangle|^p, \tag{3}$$

仍然构成一个合法的正则化方法；当 $p<2$ 时，其极小化子相对于该基具有更稀疏的展开 [page 4]。作者进一步提出一个 Landweber 型迭代算法——每步先做梯度下降，再施加非线性阈值（收缩）操作——并证明该迭代在范数意义下收敛到 $\Phi_{w,p}$ 的极小化子，且该极小化子具有正则化所需的稳定性。

## 从惩罚项到阈值操作

论证的起点是一个观察：当 $K$ 在 $\phi_\gamma$ 基下对角化时（$K\phi_\gamma = \kappa_\gamma\phi_\gamma$），泛函 (3) 分解为各分量独立的一维极小化问题。特别地，当 $K$ 是恒等算子、$w=\mu w_0$、$p=1$ 时，极小化子由软阈值操作给出：

$$S_\mu(x) = \begin{cases} x+\mu/2 & x\le -\mu/2 \\ 0 & |x|<\mu/2 \\ x-\mu/2 & x\ge \mu/2. \end{cases} \tag{5}$$

这正是 Donoho–Johnstone 小波去噪中的软阈值 [page 4]。但一般情形下 $K$ 不在该基下对角化，变分方程 (9) 中 $K^*Kf$ 项将所有分量耦合在一起，形成非线性方程组，无法直接求解。

作者的关键技术手段是引入"代理泛函"（surrogate functional）。选取常数 $C > \|K^*K\|$（论文为简化取 $C=1$，即假设 $\|K\|<1$），构造

$$\Phi^{\text{SUR}}_{w,p}(f;a) = \Phi_{w,p}(f) - \|Kf-Ka\|^2 + \|f-a\|^2. \tag{10}$$

由于 $I - K^*K$ 严格正定，这个泛函在 $f$ 上严格凸，且其变分方程中各分量解耦。展开后 $-\|Kf\|^2$ 项恰好抵消原泛函中的 $\|Kf\|^2$，剩下的是一族独立的一维问题 [page 9]。命题 2.1 证明其唯一极小化子为

$$f = S_{w,p}(a + K^*(g-Ka)), \tag{17}$$

其中 $S_{w,p}$ 是逐分量施加的收缩算子，$p>1$ 时由 $F_{w,p}(x)=x+\frac{wp}{2}\text{sign}(x)|x|^{p-1}$ 的逆给出，$p=1$ 时退化为 (16) 的软阈值。引理 2.2 进一步证明 $S_{w,p}$ 是非扩张的，这是后续收敛性证明反复使用的核心性质。

迭代格式由此自然产生：$f^n = S_{w,p}(f^{n-1} + K^*(g-Kf^{n-1}))$，即"Landweber 步 + 阈值" [page 12]。当 $w=0$ 时退化为经典 Landweber 迭代；当 $p=2$、$w=\mu w_0$ 时退化为阻尼 Landweber 迭代 $f^n = \frac{1}{1+\mu}[f^{n-1}+K^*(g-Kf^{n-1})]$，其收敛性由压缩映射直接保证 [page 10]。

## 收敛性证明的推理链

定理 3.1 是论文的核心数学结果：在 $\|K\|<1$、$1\le p\le 2$、$w_\gamma$ 有正下界的条件下，迭代 $f^n$ 强收敛到 $\Phi_{w,p}$ 的极小化子；若 $p>1$ 或 $N(K)=\{0\}$，极小化子唯一 [page 13]。

证明分两阶段。弱收敛阶段的关键是验证迭代算子 $T = S_{w,p}(I + K^*(g-K\cdot))$ 满足 Opial 定理的三个条件：非扩张性（引理 3.4，直接由 $S_{w,p}$ 非扩张和 $\|I-K^*K\|\le 1$ 得到）、渐近正则性（引理 3.8）、不动点集非空。渐近正则性的证明依赖一个能量递减论证：引理 3.5 证明 $\Phi_{w,p}(f^n)$ 和 $\Phi^{\text{SUR}}_{w,p}(f^{n+1};f^n)$ 均单调不增，引理 3.7 由此推出 $\sum_n \|f^{n+1}-f^n\|^2 < \infty$，故 $\|f^{n+1}-f^n\|\to 0$ [page 14-15]。引理 3.6 在此处用到 $p\le 2$：由 $\||f|\|_{w,p}$ 的一致有界性推出 $\|f\|$ 的一致有界性，其中不等式 (21) 的指数 $2-p$ 要求 $p\le 2$。作者在注 3.14 中明确指出，若能用其他方式建立范数有界性，$p\le 2$ 的限制可以去掉 [page 16]。

弱极限是不动点（引理 3.3），而不动点必为 $\Phi_{w,p}$ 的极小化子（命题 3.10）：若 $f^\star = Tf^\star$，则 $f^\star$ 极小化代理泛函 $\Phi^{\text{SUR}}_{w,p}(\cdot;f^\star)$，由命题 2.1 的强凸性得 $\Phi^{\text{SUR}}_{w,p}(f^\star+h;f^\star)\ge \Phi^{\text{SUR}}_{w,p}(f^\star;f^\star)+\|h\|^2$，展开即得 $\Phi_{w,p}(f^\star+h)\ge \Phi_{w,p}(f^\star)+\|Kh\|^2$。

强收敛阶段处理的是弱收敛不足以推出范数收敛的困难——这正是病态问题的特征。证明策略是：令 $u^n = f^n - f^\star$，先证 $\|Ku^n\|\to 0$（引理 3.15），再证 $\|S_{w,p}(h+u^n)-S_{w,p}(h)-u^n\|\to 0$（引理 3.17），最后引理 3.18 证明：若 $v^n$ 弱收敛到 0 且 $\|S_{w,p}(a+v^n)-S_{w,p}(a)-v^n\|\to 0$，则 $\|v^n\|\to 0$。引理 3.18 的证明对 $p>1$ 和 $p=1$ 分别处理，$p>1$ 时利用 $S_{w,p}$ 在有限区间上导数严格小于 1 的性质，$p=1$ 时利用阈值算子的分段结构 [page 18-19]。

## 稳定性与收敛速率

第 4 节回答的问题是：当噪声水平 $\epsilon\to 0$ 时，极小化子 $f^\star_{\mu,w,p;g}$ 是否收敛到真实解？定理 4.1 证明，若 $\mu(\epsilon)\to 0$ 且 $\epsilon^2/\mu(\epsilon)\to 0$，则对任意 $f_o\in H$，$\sup_{\|g-Kf_o\|\le\epsilon}\|f^\star_{\mu(\epsilon),w,p;g}-f^\dagger\|\to 0$，其中 $f^\dagger$ 是 $S = N(K)+f_o$ 中 $\||\cdot|\|_{w,p}$ 范数最小的元素 [page 20-21]。证明的核心估计是 (31)：由极小化性和 $\||f^\dagger|\|_{w,p}$ 的先验界，得到 $\|f^\star_{\mu_n;g_n}\|^p \le \frac{1}{c}(\epsilon_n^2/\mu_n + \||f^\dagger|\|_{w,p}^p)$，从而迭代解一致有界。随后通过弱收敛论证和 Fatou 引理建立范数收敛。

命题 4.5 给出收敛模与连续性模的关系：$M(\epsilon,\rho)\le M_\mu(\epsilon,\rho)\le M(\epsilon+\epsilon',\rho+\rho')$，其中 $\epsilon' = (\epsilon^2+\mu\rho^p)^{1/2}$，$\rho' = (\rho^p+\epsilon^2/\mu)^{1/p}$。优化上界建议取 $\mu = \epsilon^2/\rho^p$，此时 $\epsilon' = \sqrt{2}\epsilon$，$\rho' = 2^{1/p}\rho$ [page 24]。这意味着该方法的收敛速率与最优速率同阶（常数因子可能非最优）。

命题 4.7 将这一般框架应用于具体情形：若 $K$ 是 $\alpha$ 阶光滑算子（满足 (43) 的范数等价），先验为 Besov 空间 $B^s_{p,p}$，则 $M(\epsilon,\rho)$ 的衰减率为 $(\epsilon/A_u)^{\sigma/(\sigma+\alpha)}\rho^{\alpha/(\sigma+\alpha)}$，其中 $\sigma = s+d(1/2-1/p)$ [page 26]。$\sigma/(\sigma+\alpha)$ 接近 1 时问题轻度病态，$\alpha$ 大时稳定性退化。

## 数值示例与边界

第 5 节给出一个二维反卷积的简单示例：256×256 图像，四个椭圆状源，低通滤波后加 Poisson 噪声（共 10000 光子）。图 1 显示 $\ell^1$ 惩罚（$p=1$）的极小化子比 $\ell^2$ 惩罚（$p=2$）更好地分辨了两个靠近的源，且振铃更少 [page 27-28]。图 2 显示加入正性约束（投影到非负锥）后分辨率进一步提高。图 3 用压缩灰度范围突出振铃和噪声，确认 $p=1$ 在噪声抑制上优于 $p=2$ [page 29]。

作者明确声明这些示例仅用于说明 $p$ 的选择带来的差异，不构成算法最优性的主张；数据是"准点源"的简单 caricature，自然图像结构更丰富 [page 29]。作者也承认，对于 $\ell^2$ 惩罚，本例的重建可直接用正则化 Fourier 反卷积得到，无需迭代。

## 结论成立的条件与未决问题

论文的收敛性结论依赖几个关键假设：$\|K\|<1$（可通过重归一化满足）、$w_\gamma$ 有正下界、$1\le p\le 2$。$p\le 2$ 的限制来自引理 3.6 中范数有界性的证明，作者在注 3.14 中指出这可能是技术性的而非本质的 [page 16]。唯一性需要 $p>1$ 或 $N(K)=\{0\}$；当 $p=1$ 且 $N(K)\ne\{0\}$ 时，极小化子可能不唯一，但注 4.4 指出若 $S$ 中最小范数元素仍唯一（例如 $K$ 对角化且零特征值对应的分量可置零），稳定性证明仍适用 [page 23]。

稳定性定理 4.1 要求 $\epsilon^2/\mu(\epsilon)\to 0$，这比 $\mu\to 0$ 更强。命题 4.5 的框架在假设 (29)（$w_\gamma$ 趋于无穷）下可覆盖 $\epsilon^2/\mu$ 不趋于零的情形，因为此时 $B_{w,p}$ 球在 $H$ 中紧 [page 24]。收敛速率的推导（命题 4.7）额外假设 $K$ 满足 (43) 的光滑性条件，且先验为 Besov 空间。

第 6 节讨论了若干推广：非对称惩罚 (45)、复值情形的困难（相位与模耦合，不再解耦）、小波基下按位置和尺度调整权重、以及更一般的凸惩罚函数 $\tilde\Phi_W(f) = \|Kf-g\|^2 + \sum_\gamma W_\gamma(|f_\gamma|)$，后者需要 $W_\gamma$ 满足凸性和技术条件以保证收缩算子非扩张 [page 30-31]。计算复杂度方面，每步迭代 $O(N^2)$（稠密矩阵）或 $O(N\log N)$（小波+FFT），与经典 Landweber 算法相当 [page 31-32]。

总体而言，论文的主要贡献在于：将 $\ell^p$ 惩罚（$1\le p\le 2$）的正则化性质从有限维、统计框架推广到一般 Hilbert 空间中的有界算子，给出了收敛性和稳定性的完整证明，并提供了一个每步只需一次算子作用和一次逐分量阈值操作的实用算法。论证的关键转折在于代理泛函的构造——它通过添加 $-\|Kf-Ka\|^2+\|f-a\|^2$ 消去耦合项，将非线性方程组转化为可解的一维问题，同时保持与原泛函的足够联系以通过 Opial 定理建立收敛。
