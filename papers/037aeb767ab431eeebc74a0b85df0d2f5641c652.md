# 用整词掩码与“纠错式”预训练改造中文 BERT：MacBERT 的论证分析

**原文题名**：Pre-Training with Whole Word Masking for Chinese BERT（2021，arXiv:1906.08101v3）

## 论文要解决的两个问题

这篇论文同时承担两项任务。第一项是工程与基准性质的：把英文社区已经成熟的预训练语言模型（BERT、RoBERTa、ELECTRA 等）迁移到中文，构建并开源一整套中文预训练模型，作为后续研究的可比基线 [page 1]。第二项是方法创新：提出 MacBERT，用“把掩码语言模型改造成纠错任务”（MLM as correction, Mac）来缓解 BERT 预训练与微调之间的不一致 [page 3-4]。

两项任务在论证上互相支撑：只有先建立同一数据、同一流程下的中文基线，MacBERT 相对基线的增益才有意义。因此论文反复强调，除原始中文 BERT 外，所有对比模型都由作者自己训练，以保证预训练数据与流程的相对公平 [page 6]。

## 核心机制：整词掩码与 Mac 掩码

理解全文的关键在于区分“选哪些 token 掩码”和“用什么替换被选中的 token”这两件事。论文的 Table I 把各模型的差异归纳为掩码策略、语言模型任务、配对任务三个维度 [page 3]。

**整词掩码（whole word masking, wwm）** 处理的是“选谁”。原始 BERT 用 WordPiece 分词，一个词可能被切成多个片段，随机掩码只会遮住词的一部分，模型靠剩余片段就能猜出答案，任务偏易。wwm 改为一次性遮住整个词对应的所有 token [page 2]。中文的特殊性在于：汉字不由字母构成，WordPiece 不再把词切碎，所以作者改用中文分词工具 LTP 先切出词边界，再对整词做掩码；但分词器本身仍是 WordPiece，与原始 BERT 一致 [page 3]。Table II 用中英对照的例子直观展示了从原始掩码到 wwm、再到 N-gram 掩码、最后到 Mac 掩码的逐级变化 [page 3]。

**Mac 掩码** 处理的是“用什么替换”。作者指出 MLM 的根本缺陷：预训练阶段大量出现的 `[MASK]` 在微调阶段从不出现，造成预训练—微调不一致 [page 4]。Mac 的做法是不用任何预定义掩码符号，而是把被选中的词替换成它的近义词，把 MLM 变成“把错词改成对词”的文本纠错任务。具体设置是：用整词掩码加 N-gram 掩码选候选，word-level unigram 到 4-gram 的比例为 40%、30%、20%、10%；近义词由基于 word2vec 相似度的 Synonyms 工具包获得，找不到近义词时退化为随机词替换，且随机替换不超过全部被掩码 token 的 10%；整体沿用 15% 的掩码比例，其中 80% 换成近义词、10% 换成随机词、10% 保持原词 [page 4]。

配对任务上，MacBERT 用 ALBERT 提出的句子顺序预测（SOP）替代 NSP：正样本是两段连续文本，负样本是交换顺序后的两段文本 [page 4]。模型结构本身没有改动，仍是标准 Transformer 编码器加词/位置/类型三种嵌入，损失为 Mac 与 SOP 两项交叉熵之和（式 1–7）[page 4]。

## 证据如何支撑结论

**主结果**：论文在十个中文任务上评测，覆盖机器阅读理解（CMRC 2018、DRCD、CJRC）、单句分类（ChnSentiCorp、THUCNews、TNEWS）、句对分类（XNLI、LCQMC、BQ Corpus、OCNLI）[page 5]。每个实验跑十次，同时报告最高分与平均分 [page 5]。

在阅读理解上，MacBERT 的增益最明显。Table V 显示 MacBERT-large 在 CMRC 2018 挑战集上取得 F1 60.2，作者称达到当时的最优水平 [page 6]；DRCD 上 MacBERT-large 测试集 EM/F1 为 91.7/95.6，高于 RoBERTa-wwm-ext-large 的 89.6/94.5 [page 6]。CJRC 上 MacBERT-large 测试集 F1 为 82.5，略高于 RoBERTa-wwm-ext-L 的 82.2 [page 6]。

在分类任务上增益较小。Table VII 中 ChnSentiCorp、THUCNews 已接近饱和，MacBERT 只有温和提升；TNEWS 上 MacBERT-large 开发集 59.0，高于 RoBERTa-large 的 58.8 [page 7]。句对分类（Table VIII）中，XNLI 与 OCNLI 上 MacBERT 有一致且较明显的提升，但 LCQMC 与 BQ Corpus 上仅平均分略有改善，峰值不如 RoBERTa-wwm-ext-large [page 8]。

**消融**：Table X 逐一移除 MacBERT-large 的组件。移除 SOP、移除 Mac、移除 N-gram 掩码、把 SOP 换回 NSP，平均分都下降，说明每个改动都有贡献 [page 8]。作者进一步区分：N-gram 掩码在文本分类上更有效，近义词替换在阅读理解上更有效，两者互补 [page 7]。NSP 类任务整体不如 MLM 任务重要，SOP 优于 NSP 但差距不显著 [page 7-8]。

**掩码替换方式的直接对照**：Figure 2 在 CMRC 2018 和 DRCD 上比较四种替换策略——MacBERT（近义词）、Random Replace（全随机词）、Partial Mask（80% `[MASK]`+10% 随机）、All Mask（90% `[MASK]`）。依赖 `[MASK]` 的两种策略表现最差；完全弃用 `[MASK]`、改用随机词也能稳定优于 `[MASK]` 策略；而用近义词的 MacBERT 在四者中最好 [page 8-9]。这组对照是全文最直接的机制证据：它显示移除 `[MASK]` 的替换策略在这两个阅读理解基准上表现更好，且近义词优于随机词。不过，替换策略同时改变了输入分布和被破坏文本的可读性，因此曲线差异与“预训练—微调不一致”的解释相符，却不能单独证明性能变化就是由这一不一致所致。

**拼写检查的旁证**：Figure 3 在 SIGHAN-15 上用不同比例训练数据比较，MacBERT 在检测级和纠正级都稳定领先，ELECTRA 在纠正级明显落后。作者解释 ELECTRA 的 RTD 只需判断 token 是否被替换、不需还原原词，而 MLM/Mac 要求“识别并纠正”，因此更接近真实纠错 [page 9]。

## 关键推理链与作者补上的桥接

从证据到结论的核心推理是：`[MASK]` 在微调阶段缺席 → 预训练与微调存在分布不一致 → 用近义词替换可消除该符号、同时把任务变成更自然的纠错 → 性能提升。Figure 2 中 `[MASK]` 策略与随机词/近义词策略的差距，正是这条推理的实证支点。

作者还补了一层解释：为什么近义词优于随机词？因为随机词不符合上下文、破坏语言的自然流畅性，而近义词替换后句子仍通顺，任务更接近语法纠错 [page 9]。这属于作者明说的机制解释，而非仅由数据推出。

另一处推理是 MacBERT-base 的增益普遍大于 MacBERT-large。作者给出两个可能原因：base 由 BERT-base 初始化，继承了已有知识、避免冷启动；large 本身分数已高，进一步提升更难 [page 7]。这是作者明确标注为推测（might be caused by）的解释。

## 结论成立的条件与边界

**数据条件**：MacBERT 及多数对比模型使用 5.4B 词的扩展数据（百科、新闻、问答网页），远大于中文维基的 0.4B 词 [page 5]。Table III 显示 BERT 仅用 0.4B 词，因此 BERT 与 MacBERT 的差距中混有数据量因素；作者通过 BERT-wwm 与 BERT-wwm-ext 的对比说明扩展数据本身带来提升，并把扩展数据统一用于 RoBERTa、ELECTRA、MacBERT 以维持可比性 [page 6]。但严格说，MacBERT 相对同数据基线的净增益，应由 Table X 的消融而非 Table V 的横向对比来承担。

**任务类型边界**：增益在阅读理解上最大、在句对分类上最小。作者的解释是句对分类只需生成整体表示，对输入细微差异不敏感；而阅读理解要求定位精确答案跨度，Mac 的逐词替换迫使模型学习词边界 [page 7]。这意味着 Mac 的优势更可能出现在需要精细词级建模的任务上。

**领域边界**：CJRC 来自法律判决文书，BERT-wwm 相对 BERT 提升有限，作者据此指出非通用领域需要进一步的领域适配，但大规模通用数据可作为数据不足时的补救 [page 6]。

**方法自身的局限**：Mac 只用近义词替换，而真实拼写错误中近义词只占很小比例，作者据此解释为何在训练数据很少时 MacBERT 相对其他模型的优势不够大 [page 9]。此外，掩码比例仍是启发式设定，作者在结论中把“寻找确定掩码比例的有效方法”列为未来工作 [page 10]。

**小模型结论**：RBT 系列（Table IX）显示小模型性能低于常规模型，分类任务上的下降小于阅读理解；在参数量相近时，RBT6（60M，薄而高）明显优于 RBTL3（61M，宽而矮），作者据此提出“thin-and-tall 通常优于 wide-and-short” [page 7-8]。这一观察基于单一对照，属于作者明确表述的经验性结论，而非普遍定律。

## 需要留意的文本疑点

Table IX 中 RBTL3 在 CJRC 上的 EM/F1 为 64.6/74.9，高于参数量更大的 RoBERTa-base（59.0/79.0 的 EM 部分）与 RoBERTa-large（62.4/82.2）的 EM，这一反常数值在提取文本中未加说明，可能是排版或抽取问题，不宜作为确定证据使用。此外 Table III 中 BERT 的训练步数标为“?”，属原文缺失，不影响主要论证。

## 总体判断

论文的贡献是双重的：一套可复用的中文预训练基线，以及一个把 MLM 重构为纠错任务的 MacBERT。其论证最扎实的部分不是横向榜单，而是 Figure 2 对掩码替换方式的受控对照——它直接检验了“预训练—微调不一致”这一动机假设，并显示近义词替换优于 `[MASK]` 与随机词。结论的适用范围应限定为：在通用领域、数据充足、需要词级精细建模的任务上，Mac 的增益最可靠；在领域专有或数据稀缺的场景，作者本人也承认优势会收窄。
