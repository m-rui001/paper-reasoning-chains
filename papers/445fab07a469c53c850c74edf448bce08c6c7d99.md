# 从有限时间做功到自由能差：Jarzynski 等式的论证结构

**原文题名**：A nonequilibrium equality for free energy differences
**作者**：C. Jarzynski
**年份**：1996（arXiv:cond-mat/9610209v1）

## 一个不等式与一个等式的对照

论文的出发点是一个热力学常识：当外参量沿参数空间中的路径 γ 从 A 缓慢（无限慢）变到 B 时，对系统做的功等于 Helmholtz 自由能差，W = ΔF ≡ F_B − F_A [page 2]。而当参量以有限速率切换时，功 W 会依赖系统与热库的微观初始条件，其系综平均满足不等式 W̄ ≥ ΔF [page 2, Eq.1]。两者之差 W − ΔF 就是不可逆过程熵增对应的耗散功 W_diss。

作者要主张的核心结论是：把这个不等式升级为一个**等式**。对同样的有限时间切换过程，若每次测量前系统与热库先在温度 T、参量固定在 A 的条件下达到平衡，则

$$\overline{\exp(-\beta W)} = \exp(-\beta \Delta F), \quad \text{或等价地} \quad \Delta F = -\beta^{-1}\ln \overline{\exp(-\beta W)} \tag{2a, 2b}$$

其中 β ≡ 1/k_BT [page 2]。这个等式允许从非平衡（有限时间）做功测量的系综中提取平衡信息 ΔF，且**不依赖路径 γ，也不依赖切换速率** [page 3]。这是全文的中心主张，其余内容都是围绕它的证明、特例检验、边界讨论和应用前景。

## 从孤立系统到耦合热库：证明的关键两步

证明分两步走，理解这两步的衔接是理解整个论证的关键。

**第一步：先处理没有热库的孤立系统。** 系统在 H_λ(z) 下做确定性演化，λ 从 0 到 1 用时间 t_s 切换。初始条件取自正则分布 f(z,0) = Z_0^{-1} exp(−βH_0(z))，随后按 Liouville 方程演化 [page 4]。作者引入一个"累积功"函数 w(z,t)：对在时刻 t 经过相点 z 的那条轨迹，w(z,t) 是到 t 为止所做的功。由于演化是确定性的，每个 z 唯一对应一条轨迹，这个函数才有定义 [page 4]。于是

$$\overline{\exp(-\beta W)} = \int dz\, f(z,t_s)\exp(-\beta w(z,t_s)) \tag{6}$$

关键推理在于两个事实的合用：孤立 Hamiltonian 系统所做的功等于能量变化，即 w(z,t) = H_λ(z) − H_0(z_0)；而 Liouville 定理保证相空间密度沿轨迹守恒，f(z,t) = f(z_0,0) = Z_0^{-1} exp(−βH_0(z_0)) [page 5]。两者相乘得到

$$f(z,t)\exp(-\beta w(z,t)) = Z_0^{-1}\exp(-\beta H_\lambda(z)) \tag{7}$$

代入 Eq.6 后，积分恰好给出 Z_1/Z_0，于是 exp(−βW) 的平均等于 Z_1/Z_0 = exp(−βΔF) [page 5, Eq.8]。这一步是纯 Hamiltonian 力学的结果，没有引入任何额外假设。

**第二步：把热库纳入进来。** 作者假设系统与热库共同构成一个更大的孤立 Hamiltonian 系统，全相空间坐标 y = (z, z′)，总 Hamiltonian G_λ(y) = H_λ(z) + H(z′) + h_int(z, z′) [page 5]。初始条件取自全空间的正则分布 e^{−βG_0(y)}，对应每次切换前系统与热库在温度 T 下平衡。由于整体是孤立 Hamiltonian 系统，对系统所做的功等于系统加热库的总能量变化，于是把第一步的分析原样搬到 (y, G_λ, Y_λ) 上，得到

$$\overline{\exp(-\beta W)} = Y_1/Y_0 \tag{9}$$

右端只依赖初始和末态 Hamiltonian 以及温度 T，因此 exp(−βW) 的平均**与切换时间 t_s 和路径 γ 都无关** [page 6]。接下来是全文最关键的一步桥接：作者指出，在 t_s → ∞ 的准静态极限下，每条轨迹都有 W = ΔF，所以 exp(−βW) = exp(−βΔF)。既然左端对任意 t_s 都不变，那么它在所有 t_s 下都等于 exp(−βΔF)，中心结果 Eq.2 得证 [page 6]。

这里有一个值得读者注意的推理结构：Eq.9 本身是"恒真"的（在问题表述下必然成立），但从 Eq.9 到 Eq.10 用到了一个准平衡统计力学的结果，即弱耦合假设（h_int 足够小）[page 6]。作者明确承认这一点：只有当 h_int 可忽略时，Y_1/Y_0 才直接约化为 Z_1/Z_0 = exp(−βΔF)。因此 Eq.2 的成立条件是系统与热库之间**耦合足够弱**。

## 两个极限情形作为自洽性检验

作者用两个已知的平衡恒等式来检验中心结果，这既是验证也是直觉建立。

**无限慢切换（t_s → ∞）**：系统全程处于准静态平衡，每条轨迹的功都是 ∫_0^1 dλ ⟨∂H_λ/∂λ⟩_λ，Eq.2b 退化为

$$\Delta F = \int_0^1 d\lambda \left\langle \frac{\partial H_\lambda}{\partial \lambda} \right\rangle_\lambda \tag{4}$$

这是标准的自由能微扰公式 [page 4]。

**无限快切换（t_s → 0）**：切换瞬时完成，功就是 W = H_1 − H_0 ≡ ΔH，在初始正则分布下取值，Eq.2b 变为

$$\Delta F = -\beta^{-1}\ln \langle \exp(-\beta \Delta H) \rangle_0 \tag{5}$$

这是著名的 Zwanzig 自由能微扰恒等式 [page 4]。两个极限都给出已知正确的结果，说明中心等式在两端自洽。而中间有限 t_s 的情形，系综在相空间中滞后于平衡分布，Eq.2 才真正是一个非平衡结果 [page 4]。

## 不等式的重新导出与涨落-耗散关系

作者顺带指出，不等式 W̄ ≥ ΔF（Eq.1）可以直接从等式 Eq.2a 推出，只需应用数学恒等式 ⟨exp x⟩ ≥ exp⟨x⟩ [page 6]。这把热力学第二定律的这个特例从微观 Hamiltonian 基础重新建立起来，而不必诉诸熵增论证。在 t_s → 0 极限下，Eq.1 退化为 Gibbs-Bogoliubov-Feynman 下界 ⟨ΔH⟩_0 ≥ ΔF [page 6]。

另一个有价值的推论是累积量展开。Eq.2b 的右端可以写成 W 的系综分布的累积量之和：

$$\Delta F = \sum_{n=1}^{\infty} \frac{(-\beta)^{n-1}\omega_n}{n!} \tag{11}$$

其中 ω_n 是 W 的第 n 阶累积量 [page 6]。如果 W 的分布近似高斯（在足够慢的切换下可以预期），则只剩前两项：

$$\Delta F = \bar{W} - \beta\sigma^2/2 \tag{12}$$

其中 σ² ≡ ⟨W²⟩ − ⟨W⟩² 是 W 的系综方差。于是耗散功 W_diss = W̄ − ΔF = βσ²/2，这是一个涨落-耗散关系，与 Hermans 在数值模拟中得到的结果一致 [page 7]。

## 数值模拟中的推广：Nosé-Hoover 恒温器

论文后半部分讨论了一个实际问题：在计算机模拟中，热库需要用算法"模拟"出来，常用的是 Nosé-Hoover（NH）恒温器。作者问：如果系统在 NH 方程下演化，Eq.2 是否仍然成立？[page 7-8]

NH 方法用一个额外变量 ζ 替代热库，在扩展相空间 (z, ζ) 中运动，方程为

$$\dot{q} = p/m, \quad \dot{p} = -\nabla\Phi_\lambda - \zeta p \tag{13}$$
$$\dot{\zeta} = (K/K_0 - 1)/\tau^2 \tag{14}$$

其中 K = p²/2m 是系统总动能，K_0 = β^{−1}D/2 是 K 的热平均，τ 是弛豫时间参数 [page 8]。作者取扩展相空间中的"正则"分布 f(z,ζ,0) = cZ_0^{−1} exp(−βQ_0(z,ζ))，其中 Q_λ(z,ζ) ≡ H_λ(z) + Dζ²τ²/2β，c = (Dτ²/2π)^{1/2} [page 8, Eq.15]。在这个初始分布下，作者建立了两条关系：

$$f(z,\zeta,t) = f(z_0,\zeta_0,0)\exp\left[D\int_0^t \zeta(t')dt'\right] \tag{16}$$
$$w(z,\zeta,t) = Q_\lambda(z,\zeta) - Q_0(z_0,\zeta_0) + \beta^{-1}D\int_0^t \zeta(t')dt' \tag{17}$$

然后重复第一步的推导，再次得到 exp(−βW) 的平均等于 exp(−βΔF) [page 9]。作者强调，这个结果**恒真**：不需要弱耦合假设，也不需要假设演化是混沌的 [page 9]。类似地，若用 Metropolis Monte Carlo 算法实现恒温器，Eq.2 同样无需额外假设即可成立 [page 9]。

这里有一个值得注意的对比：物理热库情形需要弱耦合假设，而 NH 恒温器情形不需要。原因在于 NH 的扩展相空间分布是人为构造的，其"正则"分布 Eq.15 已经精确包含了恒温器变量，推导中不再需要把 Y_1/Y_0 约化为 Z_1/Z_0 这一步。

## 结论成立的条件与实用边界

作者在文末明确交代了 Eq.2 的适用条件和实际限制，这些限制对理解结论的适用范围至关重要。

**理论条件**：系统必须是经典的（量子效应可忽略），且与热库的耦合足够弱 [page 7]。对于 NH 恒温器情形，弱耦合条件不需要，但初始分布必须取 Eq.15 的形式 [page 9]。

**实用限制**：这是作者着墨最多的边界。如果 W 的涨落远大于 k_BT（即 σ ≫ β^{−1}），那么 exp(−βW) 的系综平均会被 W 比 W̄ 低很多个标准差的那些值所主导。这些值对应统计上极稀有的事件，需要数量多得不可理喻的测量才能准确确定 exp(−βW) [page 7]。因此，要实验验证 Eq.2，功的涨落不能远大于 k_BT。作者直言，这个条件"几乎排除了宏观系统"，但纳米尺度物体的直接操控和力测量近年来已经可行，这类系统可能是实验检验的最佳机会 [page 7]。

在数值模拟中，同样的警告适用：如果 W 的涨落远大于 k_BT，可能需要 prohibitive 多次模拟才能确定 exp(−βW) [page 9]。Eq.2 是否有用，取决于自由度数目、切换时间 t_s、切换路径 γ 以及热库的数值实现等因素 [page 9]。

**作者承认的局限**：论文没有讨论量子情形下的推广，也没有给出弱耦合假设的具体误差估计。作者只是指出 Eq.2 "应当相当普遍地成立，只要与热库的耦合足够弱，且量子效应可忽略" [page 7]。这是一个定性表述，没有定量边界。

## 论证的整体评价

这篇论文的论证力量在于其简洁性和自洽性。核心结果 Eq.2 的推导只用了 Hamiltonian 力学的基本性质（能量守恒、Liouville 定理）和准平衡统计力学的一个标准结果（弱耦合下 Y_1/Y_0 → Z_1/Z_0）。两个极限情形（Eq.4 和 Eq.5）作为已知恒等式，为中心结果提供了强有力的自洽性检验。不等式的重新导出和涨落-耗散关系 Eq.12 则是额外的推论，进一步展示了等式的丰富内涵。

论证的关键转折在于从 Eq.9 到 Eq.10 的那一步：Eq.9 告诉我们 exp(−βW) 的平均与 t_s 和 γ 无关，而准静态极限告诉我们这个不变量就是 exp(−βΔF)。这个推理的巧妙之处在于，它把一个非平衡问题（有限时间切换）通过一个不变量与平衡量联系起来。读者需要留意的是，这个不变量性质本身是恒真的，但它的具体值等于 exp(−βΔF) 则依赖于弱耦合假设。因此，Eq.2 的"非平衡等式"地位是建立在平衡统计力学的标准近似之上的。

从今天的视角看，这篇论文开创了后来被称为"Jarzynski 等式"的研究方向，但论文本身只给出了理论推导和数值模拟应用的前景讨论，没有实验验证。作者对实用限制的坦诚讨论——特别是涨落必须与 k_BT 可比这一条件——为后续的实验和模拟工作划定了清晰的适用范围。
