# 用坐标变换“拉伸”电磁场：Pendry、Schurig 与 Smith 的隐身斗篷设计论证

**原文题名**：Controlling Electromagnetic Fields（2006）
**DOI（登记信息）**：https://doi.org/10.1126/science.1126493

需要先说明一处登记信息与正文的错位：本次提供的抽取文本中，正文标题为 *Controlling Electromagnetic Fields*，作者为 J. B. Pendry、D. Schurig、D. R. Smith，DOI 为 10.1126/science.1126493；而登记题名“Optical Conformal Mapping”与 DOI 10.1126/science.1126493 并不对应同一篇正文。下文分析以抽取文本中的正文为准。

## 一、核心主张：不是“挡住”光，而是把空间本身重新布线

这篇文章要论证的，是一个比“造一种好透镜”更激进的设计范式：只要我们能任意独立地设计材料的介电常数 ε 和磁导率 μ，就可以把电磁场“拖拽”到几乎任何想要的构型中去 [page 2–3]。作者给出的最醒目例子，是让电磁波绕过一块被隐藏的区域，再从另一侧沿原方向射出，使外部观察者以为那里是空的——也就是隐身斗篷。

关键在于，作者强调这不是射线近似下的技巧，而是“对 Maxwell 方程的精确操作”，原则上涵盖所有电磁现象和所有尺度 [page 3]。这一点决定了整篇论证的性质：它首先是一个数学等价性论证，其次才是一个工程可行性讨论。

## 二、论证的枢纽：坐标变换等价于材料参数的重整定

论证的起点是一个思想实验（Fig. 1）[page 2–3]。设想初始场构型画在一张笛卡尔网格上，然后像拉伸弹性介质一样把这张网格连同场一起扭曲。扭曲本身可以记录为一个坐标变换

$$u(x,y,z),\ v(x,y,z),\ w(x,y,z) \tag{1}$$

作者指出，Maxwell 方程在任何坐标系中形式不变，但 ε 和 μ 会被一个公共因子重整定：

$$\varepsilon'_u = \varepsilon_u \frac{Q_u Q_v Q_w}{Q_u^2},\quad \mu'_u = \mu_u \frac{Q_u Q_v Q_w}{Q_u^2},\ \text{etc.} \tag{2}$$

其中 $Q_u^2 = (\partial x/\partial u)^2 + (\partial y/\partial u)^2 + (\partial z/\partial u)^2$，$Q_v$、$Q_w$ 同理 [page 3, Eq. 4]。场分量也相应缩放：$E'_u = Q_u E_u$，$H'_u = Q_u H_u$ [page 3, Eq. 3]。

这一步是整篇论文的推理枢纽。它把“如何让场走一条奇怪路径”这个物理问题，翻译成“如何选择 ε、μ 的空间分布”这个材料问题。作者明确说，这里假设正交坐标系以使公式简洁，一般情形见参考文献 (14) 和在线补充材料 (15) [page 3]。也就是说，从“坐标变换”到“材料参数”的桥接，依赖正交性这一简化；非正交情形虽然被声称可处理，但正文没有展开。

## 三、从一般框架到具体斗篷：球壳压缩变换

有了这个等价性，作者构造了一个具体变换来隐藏半径 $R_1$ 的球，斗篷区域为环壳 $R_1 < r < R_2$。做法是把 $r < R_2$ 内的所有场“压缩”进 $R_1 < r < R_2$：

$$r' = R_1 + r(R_2 - R_1)/R_2,\quad \theta' = \theta,\quad \phi' = \phi \tag{6}$$

代入变换规则后得到 [page 3, Eq. 7]：在 $R_1 < r < R_2$ 内，

$$\varepsilon'_{r'} = \mu'_{r'} = \frac{R_2}{R_2 - R_1}\frac{(r' - R_1)^2}{r'},$$
$$\varepsilon'_{\theta'} = \mu'_{\theta'} = \frac{R_2}{R_2 - R_1},\quad \varepsilon'_{\phi'} = \mu'_{\phi'} = \frac{R_2}{R_2 - R_1}$$

而在 $r < R_1$ 内，ε 和 μ “可以取任意值而不受限制，且不贡献电磁散射” [page 3]；在 $r > R_2$ 外，所有分量回到 1 [page 4, Eq. 8]。

这里有一个值得点出的论证细节：作者指出在 $r = R_2$ 外表面处，$\varepsilon'_{\theta'} = \varepsilon'_{\phi'} = 1/\varepsilon'_{r'}$，$\mu'_{\theta'} = \mu'_{\phi'} = 1/\mu'_{r'}$，这正是完美匹配层（PML）的条件，因此这个斗篷“按构造就是无反射的”，并与已被充分研究的无反射界面联系起来 [page 4]。这是把新结果锚定在已知物理上的关键一步。

## 四、证据如何支撑结论：两类数值验证

作者用两种互补的数值实验来支撑“场确实被排除且外部不受扰动”这一结论。

**射线追踪（Fig. 2）**：在 $R_2 \gg \lambda$ 的几何光学极限下，作者对由各向异性、非均匀介质的 Maxwell 方程几何极限得到的 Hamilton 方程组做数值积分，画出 Poynting 矢量轨迹 [page 4]。结果显示，射向球体的射线在环壳内被偏转，从远侧射出时“与原本的路径无偏离” [page 4]。作者称这提供了“独立确认”，即 Eq. 6 和 Eq. 7 所规定的构型确实把射线排除在内部区域之外 [page 4]。

**近场静电极限（Fig. 3）**：在 $R_2 \ll \lambda$ 时，作者在球附近放一个点电荷，画出电位移场 [page 4]。场被排除在斗篷区域之外，但从斗篷球体出来时“未受扰动”；作者特意把球附近的场线画得更密，以强调屏蔽效果 [page 4]。

这两类证据覆盖了远场波动和近场静态两个极端，与作者“不限于射线近似”的主张相呼应。但要注意：射线追踪本身是在几何光学极限下做的，它验证的是射线层面的排除；近场图验证的是静电/静磁近似。两者合起来支持“在各自适用极限下有效”，并不等于对任意频率、任意波长的完整波动验证。

## 五、结论成立的条件与作者承认的边界

作者对结论的限定相当明确，这些限定直接决定斗篷在什么条件下才成立。

**各向异性是必需的**。作者说，介质必须各向异性，因为“我们是以各向异性的方式压缩空间的” [page 4]。这意味着不能用简单的各向同性折射率梯度来实现。

**ε 和 μ 的极端值难以实现**。作者承认，虽然各向异性和连续变化对超材料不是问题，但“实现非常大或非常小的 ε 和 μ 值可能是个问题” [page 4]。因此“实际上，斗篷会因为我们未能满足 Eq. 7 而变得不完美”，不过“仍能实现物体截面的相当大缩减” [page 4]。这是对理想结论的重要降级：完美隐身依赖精确满足 Eq. 7，工程上只能逼近。

**单频限制**。作者用射线图像论证：每条穿过大球的射线要走一条弯曲、因而更长的路径，却要求它以相同相位到达远侧，这意味着相速度超过真空光速——这不违反物理定律；但如果同时要求无色散，群速度与相速度相等，而群速度不能超过光速，因此“斗篷参数必须随频率色散，从而只能在一个频率上完全有效” [page 4]。作者补充，群速度有时可以超过光速，但只在强色散存在时 [page 4]。另一方面，“如果系统嵌入在具有大折射率的介质中，原则上可以避免色散，斗篷就能在宽带宽上工作” [page 4]。这是一个条件性的例外，而非普遍结论。

**中心射线奇点**。作者指出射线追踪中存在一个不可避免的奇点：正对球心的射线“不知道该向上还是向下偏转”，邻近射线越靠近临界射线就被弯成越紧的弧，这反过来意味着 ε 和 μ 的极快变化 [page 4]。这是设计的内在特征，不是数值误差。

**与“完美隐身不可能”定理的关系**。作者最后主动回应：为什么不违反 Nachman 的数学定理（参考文献 3）？答案是波不仅在层间边界折射，也会反射，且器件造成时间延迟；但反射可以通过让层间过渡在远大于波长 $2\pi/k$ 的尺度上渐变，或使用抗反射涂层来大幅降低，从而使不完美“小到几何光学精度极限，即指数级小” [page 4]。作者的结论是：“人永远无法完全躲过波，但可以躲过射线” [page 4]。这句话精确地划定了结论的边界：射线层面的隐身是可达的，波动层面的完美隐身不是。

## 六、论证的整体评价

这篇论文的力量在于一个干净的等价性：坐标变换 ↔ 材料参数重整定。一旦接受这个等价性，隐身斗篷就从一个“能不能做到”的物理问题，变成一个“选哪个变换、怎么实现材料”的设计问题。作者用球壳压缩变换给出显式解，用射线追踪和近场图给出两类验证，并把结果与 PML 这一已知无反射结构联系起来，使论证既有新意又有锚点。

但结论的强度被作者自己严格限定：它依赖各向异性、依赖 ε 和 μ 的极端值、依赖单频（除非嵌入高折射率介质）、存在中心射线奇点，且只在几何光学精度内成立。作者没有声称造出了实物，也没有给出实验数据；这是一篇设计策略论文，其“证据”是数值解和解析变换，而非测量。因此，把这篇论文读成“隐身已被实现”会超出文本；读成“隐身被证明在精确 Maxwell 方程层面原则上可行，且给出了可工程逼近的设计路线”才贴合原文的因果力度。
