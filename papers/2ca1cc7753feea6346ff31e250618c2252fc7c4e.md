# 无线网络上的联邦学习：把丢包率写进收敛界，再据此分配资源

**原文题名**：A Joint Learning and Communications Framework for Federated Learning over Wireless Networks
**年份**：2020（IEEE Transactions on Wireless Communications 接收稿）
**DOI**：10.1109/TWC.2020.3024629

## 论文要解决的是一个耦合问题

联邦学习（federated learning, FL）的常规叙事是：用户各自用本地数据训练模型，只把模型参数传给基站（BS），由基站聚合成全局模型再发回。数据不出本地，隐私得以保留。但这篇论文盯住一个常被理想化处理的前提：参数是要通过无线链路传的。无线信道不可靠、带宽有限，于是本地模型在传输中可能出错；基站收到错误包后不会采用它，也不会要求重传，而是直接用剩下的正确模型聚合 [page 5]。这样一来，全局模型就带上了无线传输的烙印。

作者的主张因此不是"设计一个更好的FL算法"，而是：**FL的训练损失与底层无线因素（丢包率、资源分配、用户选择、发射功率）之间存在可解析的联系，因此可以把无线资源分配和用户选择当作最小化FL损失的手段来联合优化** [page 2]。这个主张的支撑链条是：先推导FL期望收敛速率的闭式上界，把丢包率显式地放进这个界里；再证明最小化训练损失等价于最小化一个只含丢包率和用户选择项的简化目标；最后用匈牙利算法求解用户—资源块（RB）匹配。

## 收敛界是整篇论证的枢纽

论文的核心技术贡献是定理1（Theorem 1）。在梯度下降更新、学习率取 $\lambda = 1/L$ 的设定下，作者给出

$$E\left(F(g^{t+1}) - F(g^*)\right) \le A^t E\left(F(g^0)-F(g^*)\right) + \frac{2\zeta_1}{LK}\sum_{i=1}^{U} K_i\left(1-a_i + a_i q_i(r_i,P_i)\right)\frac{1-A^t}{1-A}, \quad (17)$$

其中 $A = 1 - \frac{\mu}{L} + \frac{4\mu\zeta_2}{LK}\sum_{i=1}^{U} K_i(1-a_i + a_i q_i(r_i,P_i))$，$q_i(r_i,P_i)$ 是用户 $i$ 的丢包率，$a_i$ 是用户选择指示，$K_i$ 是用户 $i$ 的样本数 [page 6]。推导依赖四个假设：梯度Lipschitz连续（式14）、$F$ 强凸（式15）、Hessian 被 $\mu I$ 和 $LI$ 夹住（式16）、以及梯度范数有界 $\|\nabla f\|^2 \le \zeta_1 + \zeta_2\|\nabla F\|^2$ [page 6]。这些假设对均方误差、逻辑回归、交叉熵等常用损失成立，作者也明确说非凸损失留待未来工作 [page 6]。

这个界之所以关键，是因为它把"无线"和"学习"缝在了一起。式(17)右侧第二项是一个**收敛间隙**：即使迭代趋于无穷（$A^t \to 0$），$E(F(g^t))$ 与理想最优 $F(g^*)$ 之间仍隔着这个间隙，而间隙的大小由 $\sum_i K_i(1-a_i + a_i q_i)$ 决定 [page 6]。换句话说，丢包率越高、被选中的用户越少，间隙越大；丢包率下降还会让 $A$ 变小，从而加快收敛速度 [page 6-7]。这就是作者说"必须联合优化资源分配、用户选择和发射功率"的根据——不是直觉，而是从界里读出来的。

作为对照，引理1（Lemma 1）给出无丢包、无用户选择时的收敛界退化为 $(1-\mu/L)^t E(F(g^0)-F(g^*))$，间隙消失 [page 7]。这个退化情形与既有文献（如[32]）一致，起到校验作用：定理1在无线因素归零时回到已知结果。

命题1（Proposition 1）进一步给出保证收敛的条件：$\zeta_2$ 必须满足 $0 < \zeta_2 < \frac{K}{\max_{P,R} 4\sum_i K_i q_i(r_i,P_i)}$（式18），本质是要求 $A<1$ [page 7]。这里有一个值得注意的推理细节：作者在后续优化中**没有把式(18)作为约束加入问题**，理由是"总存在满足该约束的 $\zeta_1$ 和 $\zeta_2$" [page 7]。这是一个省略的桥接——它意味着优化问题是在"收敛已由参数选择保证"的前提下求解的，而非在优化中同时保证收敛。

## 从收敛界到可解问题：两步简化

有了定理1，原始问题(11)——在时延约束(11c)、能耗约束(11d)、每用户单RB(11b)、每RB单用户(11e)、功率上限(11f)下最小化训练损失——就可以简化。作者论证：当 $t$ 足够大（刻画渐近收敛），$A^t=0$，最小化间隙(20)只需最小化 $\sum_i K_i(1-a_i + a_i q_i)$；又因 $a_i = \sum_n r_{i,n}$ 且 $q_i \le 1$，有 $a_i q_i = q_i$，于是问题化为式(21) [page 7]。这一步是整篇论证从"学习指标"转向"无线指标"的转折点：**最小化FL损失被等价地替换为最小化一个丢包率与用户选择的加权和**。

接下来分两步求解。命题2（Proposition 2）在给定RB分配下给出最优发射功率 $P_i^* = \min\{P_{\max}, P_{i,\gamma_E}\}$（式22），其中 $P_{i,\gamma_E}$ 使能耗恰好等于 $\gamma_E$ [page 8]。证明的关键是能耗 $e_i(r_i,P_i)$ 对 $P_i$ 单调递增（附录B给出导数恒正），因此功率不能超过能耗约束允许的上限；同时丢包率随功率下降，所以取到约束边界最优 [page 13]。这里有一个物理直觉：本地模型越大，训练耗能越多，留给传输的能量越少，训练损失随之上升 [page 8]。

然后，式(23)被转化为二部图匹配问题：用户集合与RB集合构成二分图，边权 $\psi_{in} = K_i(q_{i,n}-1)$（当且仅当时延和能耗约束满足，否则为0，式24），用匈牙利算法求最小权匹配 [page 8]。算法1总结了整个流程 [page 8]。复杂度方面，最坏 $O(U^2R)$，最好 $O(UR)$ [page 9]。作者强调，相比传统凸优化，匹配算法不需要计算梯度或动态调步长 [page 8]。

## 仿真证据与它的边界

仿真用两个任务：线性回归（前馈神经网络，20个神经元，数据由 $y=-2x+1+n\times0.4$ 生成）和手写数字识别（MNIST，50神经元FNN，以及CNN）[page 9, 11]。对比三个基线：(a) 最优用户选择+随机资源分配；(b) 随机用户选择+随机资源分配（标准FL，类似[12]）；(c) 最小化总丢包率但无视FL参数的无线优化算法 [page 9]。

图3显示所提算法在线性回归上比基线a)、b)拟合更准，且达到与"最优FL"（启发式搜索得到）相同的性能，作者据此认为匈牙利算法找到了最优解 [page 9]。图4显示训练损失随每用户样本数增加而下降，超过30后趋于平缓，作者解释为梯度近似已足够 [page 9-10]。图6是定理1的直接检验：理论分析与仿真结果的差距小于9%，作者称这"证实了定理1的有效性" [page 10]。图7-9给出识别精度：随迭代增加先升后稳（收敛），随用户数和RB数增加而提升；在9个RB时，所提算法相比基线a)、b)、c)分别提升1.4%、3.5%、4.1% [page 11]。图10给出一个具体例子：36个手写数字中，所提算法正确识别30个，基线b)识别27个 [page 11]。

这些证据支持"联合优化优于忽略无线因素"的结论，但需要注意几点。第一，**提升幅度是特定仿真配置下的**（15用户、半径500m、表II参数），作者没有声称普适性。第二，图6的"9%差异"是理论与仿真的吻合度，不是性能提升。第三，作者在图10处指出，即使CNN非凸，所提算法仍能提升性能，并称这是"假设仍适用于实际FL方案"的又一证据 [page 11]——这是一个**推断性主张**，因为定理1的收敛保证建立在凸性假设上，非凸情形下的提升是经验观察而非理论保证。第四，论文承认的局限主要是：非凸损失函数的扩展留待未来工作 [page 6]；此外，作者假设 $Z(w_i)=Z(g)$（本地与全局模型数据量相同）[page 5]，以及每个本地模型作为单包传输（但指出可扩展到多包，只需把 $q_i$ 替换为多包错误率）[page 7]。

## 结论在什么条件下成立

把整条论证链摊开看，结论"联合优化无线资源可最小化FL损失"依赖几个条件。**理论上**，它依赖定理1的四个假设（Lipschitz、强凸、Hessian夹逼、梯度有界），以及 $A<1$ 的收敛条件；当这些不满足（如非凸损失），式(17)的界不再有保证，仿真中的提升只能算经验证据。**建模上**，它依赖"错误包被直接丢弃、不重传"的聚合规则(8)，以及"用户选择与资源分配在整个训练过程中不变"的设定 [page 5]。**求解上**，它依赖把渐近间隙最小化等价为 $\sum_i K_i(1-a_i+a_iq_i)$ 最小化，这一步用了 $t$ 足够大和 $a_iq_i=q_i$ 两个简化 [page 7]。**实现上**，它依赖基站能获知各RB的SINR、FL模型数据量、用户设备信息（如CPU）[page 8]。

作者没有讨论的限制包括：用户移动性对信道估计的影响、多基站协作场景、以及 $\zeta_1,\zeta_2$ 在实际任务中如何取值（论文只论证其存在性）。这些不是论文的结论，也不应被读成论文的缺陷——它们只是界定了这篇工作所覆盖的范围。总体而言，这篇论文的论证力度在于把"无线因素影响FL"从定性直觉提升为可推导、可优化的定量关系，并用仿真验证了理论界与实验的一致性；它的谨慎之处在于对非凸情形只作经验陈述，未越界宣称理论保证。
