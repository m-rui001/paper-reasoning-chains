# 三维点集的最小二乘拟合：SVD 解法及其退化边界

**原文题名**：Least-Squares Fitting of Two 3-D Point Sets
**作者**：K. S. Arun, T. S. Huang, S. D. Blostein
**出处**：IEEE Transactions on Pattern Analysis and Machine Intelligence, Vol. PAMI-9, No. 5, September 1987, pp. 698–700
**DOI**：10.1109/TPAMI.1987.4767965

## 问题与主张

论文处理的是计算机视觉中一个反复出现的数学问题：给定两组三维点 $\{p_i\}$ 和 $\{p'_i\}$（$i=1,\dots,N$），二者由刚体运动加噪声联系，

$$p'_i = R p_i + T + N_i \tag{1}$$

其中 $R$ 是 $3\times 3$ 旋转矩阵，$T$ 是平移向量，$N_i$ 是噪声向量。目标是求 $R$ 和 $T$，使残差平方和

$$E^2 = \sum_{i=1}^{N} \| p'_i - (R p_i + T) \|^2 \tag{2}$$

最小 [page 1]。作者的核心主张是：这个最小二乘问题可以非迭代地求解，只需对一个 $3\times 3$ 矩阵做奇异值分解（SVD），并且该解在一般情况下就是所需的旋转矩阵。作者进一步主张，SVD 方法在计算时间上与已有的四元数方法相当，而明显快于迭代方法 [page 1, page 3]。

## 解耦平移与旋转

论证的第一步是把 $T$ 从问题中剥离出去。作者引用 Huang、Blostein 和 Margerum 的结果：若 $R$、$T$ 是最小二乘解，则两组点的质心重合，即 $\bar{p}' = \bar{p}$（式 (3)），其中 $\bar{p}$、$\bar{p}'$ 分别是两组点的质心（式 (4)–(6)）[page 1]。令

$$q_i = p_i - \bar{p}, \qquad q'_i = p'_i - \bar{p}' \tag{7,8}$$

则残差可写成

$$E^2 = \sum_i \| q'_i - R q_i \|^2 \tag{9}$$

于是原问题被分解为两步：先求使 (9) 最小的 $R$，再由

$$T = \bar{p}' - R \bar{p} \tag{10}$$

恢复平移 [page 1]。这一步的关键在于：质心重合是**最小二乘解的必要条件**，因此把数据去中心化不会损失最优性。作者没有在此展开证明，而是直接引用文献 [3]；读者需要接受这一引用作为后续推导的前提。

## 从最大化到 SVD：关键的一步

展开 (9) 后，作者指出最小化 $E^2$ 等价于最大化

$$F = \sum_i q'^t_i R q_i = \operatorname{Trace}(R H) \tag{14}$$

其中

$$H = \sum_{i=1}^{N} q_i q'^t_i \tag{11}$$

是一个 $3\times 3$ 矩阵 [page 2]。这是整个论证的枢纽：原本关于 $R$ 的二次型最小化问题，被转化为一个关于 $R$ 的线性迹最大化问题。

接下来作者引入一个引理：对任意正定矩阵 $AA^t$ 和任意正交矩阵 $B$，有 $\operatorname{Trace}(AA^t) \ge \operatorname{Trace}(BAA^t)$。证明用 Schwarz 不等式逐列处理，属于标准技巧 [page 2]。设 $H$ 的 SVD 为

$$H = U \Lambda V^t \tag{12}$$

其中 $U$、$V$ 是 $3\times 3$ 正交矩阵，$\Lambda$ 是非负对角矩阵。令

$$X = V U^t \tag{13}$$

则 $XH = V\Lambda V^t$ 是对称正定的，由引理可知，对任意正交矩阵 $B$，$\operatorname{Trace}(XH) \ge \operatorname{Trace}(BXH)$ [page 2]。因此 $X$ 在所有正交矩阵中最大化 $F$。

**关键的一步在这里**：$X$ 是正交矩阵，但正交矩阵既包含旋转（$\det = +1$），也包含反射（$\det = -1$）。只有当 $\det(X) = +1$ 时，$X$ 才是所要求的旋转矩阵。作者明确承认：若 $\det(X) = -1$，算法直接失败 [page 1]。因此，SVD 算法给出的最优正交矩阵是否等于最优旋转矩阵，取决于 $X$ 的行列式符号——这正是论文后半部分集中讨论的退化问题。

## 退化情形：无噪声与有噪声

作者分两种情形讨论 $\det(X) = -1$ 何时出现、如何处理。

**无噪声情形**（$N_i = 0$）[page 2]。此时存在使 $E^2 = 0$ 的旋转解。作者按 $\{q_i\}$ 的几何构型分三种情况：

1. **不共面**：旋转解唯一，且不存在能使 $E^2 = 0$ 的反射，SVD 算法必给出所需旋转。
2. **共面但不共线**：存在唯一的旋转解，也存在唯一的反射解，二者都使 $E^2 = 0$，SVD 算法可能给出其中任一个。
3. **共线**：有无穷多个旋转和反射使 $E^2 = 0$。

对共面情形，作者给出一个可操作的判据：$\{q_i\}$ 共面当且仅当 $H$ 的三个奇异值中有一个为零。设奇异值为 $\lambda_1 \ge \lambda_2 \ge \lambda_3 = 0$，则

$$H = \lambda_1 u_1 v^t_1 + \lambda_2 u_2 v^t_2 + 0 \cdot u_3 v^t_3 \tag{17}$$

改变 $u_3$ 或 $v_3$ 的符号不改变 $H$。因此若 $X = VU^t$ 是反射，则令

$$V' = [v_1, v_2, -v_3] \tag{18}$$

后得到的 $X' = V'U^t$ 是旋转，且同样最小化 $E^2$ [page 2]。作者还顺带指出：$\{q_i\}$ 共线当且仅当 $H$ 的三个奇异值中有两个相等。

**有噪声情形** [page 2]。若 $\{q_i\}$ 或 $\{q'_i\}$ 共面，上述共面情形的讨论仍然成立，只是 $E^2$ 的最小值不再为零。特别地，当 $N = 3$ 时，两组点都自动共面。作者明确指出**无法处理**的情形是：SVD 算法给出 $\det(X) = -1$，且 $H$ 的所有奇异值都不为零。这意味着两组点都不共面，却不存在比反射解更优的旋转解。作者判断这"只可能在噪声 $N_i$ 非常大时发生"，并认为此时最小二乘解本身"可能已经无用"，建议改用 RANSAC 类方法（每次取 3 个点）来对抗外点 [page 2]。

## 算法总结与计算时间

作者在第六节把算法整理为：计算 $X = VU^t$；若 $\det(X) = +1$，$X$ 即所求旋转；若 $\det(X) = -1$，则检查 $H$ 是否有奇异值为零——若有（设为 $\lambda_3$），通过翻转 $V$ 的第三列得到 $X' = V'U^t$；若没有奇异值为零，则转向 RANSAC 类方法 [page 2]。

第七节报告了在 VAX 11/780 上的计算机模拟 [page 3]。实验设置：$\{p_i\}$ 随机分布在中心在原点、边长 6 的立方体内；$\{p'_i\}$ 由 $\{p_i\}$ 绕方向余弦为 $(0.6, 0.7, 0.39)$ 的轴旋转 $75°$、平移 $(80, 60, 70)$、再加均值零标准差 $0.5$ 的高斯噪声生成。表 I 列出三种方法（SVD、四元数、迭代）在不同点数下的 CPU 时间（毫秒）。SVD 与四元数方法时间相当（约 37–55 ms 与 27–48 ms），迭代方法明显更长（约 94–135 ms），括号内为迭代次数 [page 3]。作者补充：迭代方法的解算到 7 位精度；若只要求 10% 精度，迭代次数可减少 2–3 倍，且可用超松弛加速收敛 [page 3]。

## 结论成立的条件与边界

综合来看，SVD 算法的结论在以下条件下成立：

- **质心重合**是解耦平移与旋转的前提，作者引用文献 [3] 而未在此证明 [page 1]。
- **$\det(X) = +1$** 是算法直接给出旋转解的条件；$\det(X) = -1$ 时算法"失败" [page 1]。
- 当 $\det(X) = -1$ 且 $H$ 有奇异值为零（即点集共面）时，可通过翻转 $V$ 的第三列修正为旋转解 [page 2]。
- 当 $\det(X) = -1$ 且 $H$ 无奇异值为零时，作者承认无法处理，并判断这通常对应噪声极大的情形，此时最小二乘解可能已不适用 [page 2]。

需要指出的是，作者对"噪声极大时最小二乘解无用"的判断是**定性推断**，论文没有给出噪声水平与 $\det(X)$ 符号之间关系的定量分析，也没有报告在实验中是否实际遇到这一退化情形。表 I 的实验只报告了 CPU 时间，没有报告估计精度或退化发生的频率。因此，SVD 算法在噪声下的实际稳健性，论文提供的证据是有限的。

此外，作者提到在投稿后得知 B. K. P. Horn 独立开发了类似算法但未发表 [page 1]，这属于学术优先权的说明，不影响论证本身。

从论证结构看，这篇论文的贡献不在于提出一个全新的优化框架，而在于把迹最大化与 SVD 联系起来，从而得到一个非迭代的闭式解，并清楚地划出了该解失效的边界。其推理的薄弱环节在于退化情形的处理依赖于点集的几何构型（共面性）与噪声水平的交互，而这一交互在论文中只得到定性讨论，未做定量刻画。
